PCIe는 PC의 메인보드에서 그래픽 카드와 SSD가 꽂히는 버스입니다. 5에는 이 버스의 선 한 가닥이 작은 납작 케이블 단자로 나와 있습니다. USB를 거치지 않고 SoC에 바로 붙는 길이어서, SSD와 가속기처럼 빠른 장치가 여기에 붙습니다. 4와 Zero 2 W에는 이 단자가 없습니다.

## 레인과 세대

- **레인**: 보내는 선 한 쌍과 받는 선 한 쌍을 묶은 것이 레인 하나입니다. x1, x4의 숫자가 레인의 수입니다. PC의 M.2 슬롯은 대개 x4이고 5의 단자는 x1입니다
- **세대**: 레인 하나의 속도를 정합니다. 1.0이 2.5GT/s, 2.0이 5GT/s, 3.0이 8GT/s입니다. GT/s는 선 위를 지나는 비트의 수이고, 그 가운데 일부는 부호화에 쓰입니다
- **낮은 쪽에 맞춘다**: 두 장치는 둘 다 되는 가장 높은 세대와 가장 많은 레인으로 말을 맞춥니다. x4짜리 SSD를 x1 단자에 달면 x1로 돕니다

## 5의 단자

- **생김새**: 16핀에 0.5mm 간격인 납작 케이블 단자입니다. 보드의 왼쪽 가장자리에 있고, PCIe 2.0 한 레인이 나옵니다
- **케이블**: 규격은 길이를 50mm 안쪽으로 권합니다. 양 끝의 접점이 서로 반대 면에 난 케이블이어야 하고, 같은 면에 난 것은 보드나 장치를 합선시킬 수 있다고 적습니다. 판에 딸려 온 케이블을 씁니다
- **전원**: 단자의 5V 핀 둘이 500mA씩, 모두 1A를 줍니다. 그보다 많이 쓰는 장치의 판은 40핀 헤더의 5V 핀에서도 전원을 받습니다
- **꽂고 뽑기 전에**: 전원을 뗍니다. 문서는 M.2 슬롯에 장치를 꽂거나 뽑기 전에 늘 그렇게 하라고 적습니다

## 켜기

```text
dtparam=pciex1
```

- **HAT+는 적지 않아도 된다**: 공식 M.2 HAT+처럼 HAT+ 규격을 따르는 판은 저절로 알아봅니다. 그렇지 않은 판은 `config.txt`에 위 줄을 적고 다시 시작합니다. `dtparam=nvme`는 같은 뜻의 다른 이름입니다
- **확인**: `lspci`에 장치가 보이면 연결된 것입니다. SSD라면 `lsblk`에 `nvme0n1`이 나타납니다([「microSD와 NVMe」](#/read/sbc-start/prt-storage))
- **여기서 부팅하려면**: 부트로더의 `BOOT_ORDER`에 NVMe가 들어 있어야 하고, HAT+가 아닌 판은 `PCIE_PROBE=1`도 적습니다([「부트로더 EEPROM과 부팅 순서」](#/read/sbc-start/cfg-eeprom))

```sh
lspci                             # 버스에 보이는 장치들
sudo lspci -vv | grep -E 'LnkCap|LnkSta'   # 할 수 있는 속도와 지금 맺은 속도
```

- **LnkCap과 LnkSta**: 앞의 것이 장치가 할 수 있는 속도와 레인, 뒤의 것이 지금 맺은 속도와 레인입니다. 5의 단자에 붙은 장치는 `Speed 5GT/s, Width x1`로 나와야 합니다
- **RP1도 보인다**: 5에서 `lspci`를 치면 내가 붙인 장치 말고도 줄이 더 있습니다. 보드 안의 RP1이 PCIe로 이어져 있기 때문입니다([「라즈베리파이 5의 RP1」](#/read/sbc-start/hdr-rp1))

## 상한 속도 견주기

선의 속도에서 부호화에 드는 비트를 빼면 데이터가 지날 수 있는 상한이 나옵니다. 2.0까지는 10비트를 보내 8비트를 싣고, 3.0부터는 130비트를 보내 128비트를 싣습니다. 아래 예제는 이 계산으로 몇 가지 연결을 견줍니다.

```c
// 연결마다의 상한 속도: 선의 속도에서 부호화에 드는 비트를 빼고 레인 수를 곱한다
#include <stdio.h>

struct link {
    const char* name;
    double gbps;                             // 레인 하나의 선 속도(Gb/s)
    int data, coded;                         // coded비트를 보내면 data비트가 실린다
    int lanes;
    const char* where;
};

static double mb_per_s(const struct link* l) {
    return l->gbps * 1000 / 8 * l->data / l->coded * l->lanes;
}

int main(void) {
    const struct link links[] = {
        {"PCIe 1.0 x1", 2.5, 8, 10, 1, "첫 세대"},
        {"PCIe 2.0 x1", 5.0, 8, 10, 1, "5의 PCIe 단자"},
        {"PCIe 3.0 x1", 8.0, 128, 130, 1, "5에서 인증받지 않은 설정"},
        {"PCIe 3.0 x4", 8.0, 128, 130, 4, "PC의 M.2 슬롯"},
        {"USB 3.0", 5.0, 8, 10, 1, "5와 4의 파란 단자"},
        {"UHS-I", 0.832, 1, 1, 1, "microSD"},
    };
    const double image_mb = 16000;           // 옮길 것: 16GB 이미지
    const double ssd_mb = 3500;              // SSD 상자에 적힌 순차 읽기 속도
    printf("연결         상한      16GB 옮기기  상자에 3500MB/s라 적힌 SSD\n");
    for (size_t i = 0; i < sizeof links / sizeof links[0]; ++i) {
        const struct link* l = &links[i];
        double top = mb_per_s(l);
        printf("%-11s  %4.0fMB/s  %4.0f초       %4.0fMB/s  %s\n", l->name, top,
               image_mb / top, ssd_mb < top ? ssd_mb : top, l->where);
    }
}
```

```text
연결         상한      16GB 옮기기  상자에 3500MB/s라 적힌 SSD
PCIe 1.0 x1   250MB/s    64초        250MB/s  첫 세대
PCIe 2.0 x1   500MB/s    32초        500MB/s  5의 PCIe 단자
PCIe 3.0 x1   985MB/s    16초        985MB/s  5에서 인증받지 않은 설정
PCIe 3.0 x4  3938MB/s     4초       3500MB/s  PC의 M.2 슬롯
USB 3.0       500MB/s    32초        500MB/s  5와 4의 파란 단자
UHS-I         104MB/s   154초        104MB/s  microSD
```

- **상자의 숫자는 5에서 나오지 않는다**: 3500MB/s라고 적힌 SSD도 5에서는 500MB/s를 넘지 못합니다. 5에 달 SSD를 고를 때 순차 속도가 높은 비싼 것을 살 까닭이 없습니다
- **USB 3.0과 상한이 같다**: 숫자로는 5의 PCIe와 USB 3.0이 같습니다. 다만 USB로 단 SSD는 사이에 변환 칩과 USB의 절차를 거치고, NVMe는 그런 것 없이 SoC에 바로 붙습니다. 어댑터에 따라 말썽이 나는 일도 USB 쪽에 있습니다
- **microSD와는 다섯 배쯤**: 한꺼번에 읽는 속도만으로도 차이가 크고, 임의 읽기의 차이는 더 큽니다
- **이것은 상한이다**: 파일 시스템과 장치의 사정으로 실제 속도는 이보다 낮습니다

## PCIe 3.0으로 올리는 설정

```text
dtparam=pciex1_gen=3
```

- **인증받지 않은 속도다**: 문서는 5가 3.0 속도로 인증받지 않았고 연결이 불안정할 수 있다고 적습니다. `raspi-config`의 Advanced Options > PCIe Speed가 같은 일을 합니다
- **기록을 쌓는 장치에는 쓰지 않는다**: 저장 장치의 연결이 가끔 끊기면 파일 시스템이 깨집니다. 속도를 재 보는 실험이 아니라면 기본인 2.0으로 둡니다

## SSD 말고 붙는 것

- **AI 가속기**: 신경망 추론을 맡는 칩을 얹은 공식 AI HAT+가 이 단자를 씁니다
- **M.2 카드들**: M.2 슬롯으로 바꿔 주는 판에 다른 종류의 카드를 꽂을 수 있습니다. 도는지는 그 카드의 드라이버가 커널에 있는지에 달렸습니다
- **하나뿐인 단자**: 레인이 하나라서 SSD와 가속기를 함께 달려면 레인을 나눠 주는 스위치 칩이 든 판이 있어야 합니다. 문서는 스위치 뒤의 장치를 알아보는 것이 일부 장치에서만 된다고 적습니다
- **4**: PCIe 레인을 USB 3.0 칩이 쓰고 있어서 밖으로 나온 단자가 없습니다

<Note>
단자와 설정은 공식 문서와 PCIe 단자 규격서에서 옮겼습니다. 세대마다의 선 속도와 부호화는 PCIe와 USB 규격의 값이고, 예제는 그것으로 상한만 계산합니다. `lspci`는 리눅스의 일반 명령이며, 5의 단자에 장치를 달아 돌려 본 것은 아닙니다.
</Note>

## 정리

- 5의 PCIe 단자는 2.0 한 레인이고, 데이터가 지나는 상한은 500MB/s다
- HAT+ 규격의 판은 저절로 켜지고, 그렇지 않은 판은 `dtparam=pciex1`을 적는다. `lspci`로 붙었는지 본다
- 3.0으로 올리는 설정은 인증받지 않은 것이라 저장 장치에는 쓰지 않는다
