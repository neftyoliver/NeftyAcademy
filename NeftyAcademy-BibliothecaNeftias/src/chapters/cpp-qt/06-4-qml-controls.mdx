[「QML 문법」](#/read/cpp-qt/qml-syntax)의 `Rectangle`과 `Text`만으로도 버튼을 만들 수는 있지만, 눌림 상태, 키보드 초점, 접근성, 플랫폼다운 모양까지 챙기려면 일이 많습니다. **Qt Quick Controls**는 QML용 표준 컨트롤 모음입니다. `Button`, `TextField`, `Slider`, `Switch`, `ComboBox`, `Dialog`, `Drawer`, `TabBar` 같은 것들이 들어 있고, 하나의 코드에 여러 **스타일**을 입힐 수 있습니다.

## 주문 양식

```cpp qt=Quick,QuickControls2
#include <QGuiApplication>
#include <QQmlApplicationEngine>
#include <QQuickStyle>
#include <QTimer>
#include <cstdio>

void toStdout(QtMsgType, const QMessageLogContext&, const QString& m) {
    std::printf("[console] %s\n", qPrintable(m));
}

int main(int argc, char** argv) {
    qInstallMessageHandler(toStdout);
    QGuiApplication app(argc, argv);
    // Basic, Fusion, Material, Universal …
    QQuickStyle::setStyle("Fusion");
    QQmlApplicationEngine engine;
    engine.loadData(R"(
import QtQuick
import QtQuick.Controls
import QtQuick.Layouts

ApplicationWindow {
    width: 320; height: 220; visible: true
    title: "주문"
    ColumnLayout {
        anchors.fill: parent; anchors.margins: 12
        TextField { id: name; objectName: "name"; placeholderText: "이름"
                    Layout.fillWidth: true }
        RowLayout {
            Label { text: "수량" }
            Slider { id: qty; objectName: "qty"; from: 1; to: 10; stepSize: 1
                     value: 1; Layout.fillWidth: true }
            Label { text: qty.value }
        }
        Switch { id: gift; objectName: "gift"; text: "선물 포장" }
        ComboBox { id: size; objectName: "size"; model: ["작게", "보통", "크게"]
                   currentIndex: 1 }
        Button {
            objectName: "order"
            text: "주문하기"
            enabled: name.text.length > 0                 // 바인딩으로 켜고 끈다
            Layout.fillWidth: true
            onClicked: console.log("주문:", name.text, qty.value + "개",
                size.currentText, gift.checked ? "포장" : "포장 안 함")
        }
    }
}
)");
    QObject* win = engine.rootObjects().value(0);
    auto find = [&](const char* n) { return win->findChild<QObject*>(n); };
    std::printf("스타일 %s, 주문 버튼 처음 %s\n", qPrintable(QQuickStyle::name()),
                find("order")->property("enabled").toBool() ? "켜짐" : "꺼짐");

    QTimer::singleShot(0, [&] {               // 사람 대신 조작한다
        find("name")->setProperty("text", "네프티");
        QMetaObject::invokeMethod(find("qty"), "increase");   // 한 칸 올리기
        QMetaObject::invokeMethod(find("qty"), "increase");
        find("gift")->setProperty("checked", true);
        find("size")->setProperty("currentIndex", 2);
        std::printf("이름 입력 뒤 주문 버튼 %s\n",
                    find("order")->property("enabled").toBool() ? "켜짐" : "꺼짐");
        QMetaObject::invokeMethod(find("order"), "clicked");  // 눌림 시그널을 낸다
        app.quit();
    });
    return app.exec();
}
```

```text
스타일 Fusion, 주문 버튼 처음 꺼짐
이름 입력 뒤 주문 버튼 켜짐
[console] 주문: 네프티 3개 크게 포장
```

사람 대신 C++에서 `objectName`으로 컨트롤을 찾아 속성을 바꾸고, 슬라이더의 `increase()`를 두 번 부르고, 버튼의 `clicked` 시그널을 냈습니다.

## 컨트롤과 레이아웃

- **ApplicationWindow**는 Controls용 창으로, `header`, `footer`, `menuBar` 자리를 가집니다. 위젯의 [「메인 윈도우, 메뉴, 도구 모음, 도킹」](#/read/cpp-qt/wid-mainwindow)에 해당합니다
- **ColumnLayout, RowLayout**(QtQuick.Layouts)은 위젯의 레이아웃처럼 자식을 쌓고, `Layout.fillWidth: true`로 남는 폭을 가져가게 합니다. 좌표를 직접 주는 `x`, `y`나 `anchors`와 섞을 수 있지만, 같은 항목에 둘을 함께 쓰면 안 됩니다
- 주문 버튼의 `enabled: name.text.length > 0`은 바인딩이라서, 이름을 넣자 저절로 켜졌습니다. 위젯 판에서는 [「기본 위젯」](#/read/cpp-qt/wid-basic)처럼 `textChanged`에 연결하는 코드가 필요했던 일입니다
- 슬라이더의 값 표시 `Label { text: qty.value }`도 바인딩입니다. `stepSize: 1`이라서 `increase()`가 정수 단위로 움직였습니다

## 스타일

Controls는 같은 QML에 다른 **스타일**을 입힙니다.

| 스타일 | 모양 |
| --- | --- |
| Basic | 가볍고 단순, 모든 플랫폼에서 같음 |
| Fusion | 데스크톱 위젯의 Fusion과 비슷한 중립적 모양 |
| Material | 구글 머티리얼 디자인, 밝은·어두운 테마와 강조색 |
| Universal | 마이크로소프트 플루언트 이전의 유니버설 디자인 |

스타일은 예제처럼 엔진을 만들기 전에 `QQuickStyle::setStyle`로 고르거나, 자원에 넣은 `qtquickcontrols2.conf` 파일, 또는 `QT_QUICK_CONTROLS_STYLE` 환경 변수로 정합니다. Qt 6에는 Windows와 macOS에서 그 플랫폼의 네이티브 모양을 흉내 내는 스타일도 있습니다. 브랜드 디자인이 있다면 컨트롤마다 `background`와 `contentItem`을 바꿔 끼워 완전히 다른 모양을 만들 수 있습니다.

<Note>
`AbstractButton`의 `click()` 메서드는 Qt 6.8에서 생겼습니다. 이 예제를 돌린 Qt 6.4에는 없어서 `clicked` 시그널을 직접 냈습니다. 테스트에서 버튼을 누를 때는 [「Qt Test」](#/read/cpp-qt/qtest-unit)의 마우스 이벤트나 Qt Quick Test 모듈을 쓰는 것이 실제 사용자 입력에 가깝습니다.
</Note>

## 정리

- Qt Quick Controls는 QML용 표준 컨트롤을 제공하며, ApplicationWindow와 QtQuick.Layouts로 화면을 짠다
- 컨트롤의 상태는 바인딩으로 서로 묶어 이벤트 코드 없이 켜고 끄며 값을 보여 준다
- Basic, Fusion, Material, Universal 같은 스타일을 엔진을 만들기 전에 고르고, 필요하면 background와 contentItem을 바꿔 디자인을 입힌다
