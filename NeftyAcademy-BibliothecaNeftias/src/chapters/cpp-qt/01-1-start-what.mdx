Qt는 하나의 C++ 코드로 Windows, macOS, Linux, Android, iOS, 임베디드 장치에서 도는 앱을 만드는 프레임워크입니다. 창과 버튼만 있는 것이 아니라 문자열, 컨테이너, 파일, 네트워크, 데이터베이스, 스레드까지 앱에 필요한 거의 모든 것을 같은 스타일로 제공합니다. 이 책은 Qt 6을 기준으로, 데스크톱 위젯 앱과 QML로 만드는 현대적인 UI 둘 다를 다룹니다.

## 지금 쓰는 Qt 들여다보기

```cpp qt=Sql
#include <QCoreApplication>
#include <QLibraryInfo>
#include <QSqlDatabase>
#include <QSysInfo>
#include <cstdio>

int main(int argc, char** argv) {
    QCoreApplication app(argc, argv);
    // 실행 중인 Qt 라이브러리의 판(컴파일할 때의 판은 QT_VERSION_STR)
    std::printf("Qt 실행 %s, 컴파일 %s\n", qVersion(), QT_VERSION_STR);
    std::printf("플러그인 폴더: %s\n",
                qPrintable(QLibraryInfo::path(QLibraryInfo::PluginsPath)));
    std::printf("운영체제 종류: %s, CPU: %s\n",
                qPrintable(QSysInfo::kernelType()),
                qPrintable(QSysInfo::currentCpuArchitecture()));
    // 모듈마다 따로 링크한다. Sql 모듈의 드라이버도 플러그인으로 따로 있다
    std::printf("SQLite 드라이버: %s\n",
                QSqlDatabase::isDriverAvailable("QSQLITE") ? "있음" : "없음");
}
```

```text
Qt 실행 6.4.2, 컴파일 6.4.2
플러그인 폴더: /usr/lib/x86_64-linux-gnu/qt6/plugins
운영체제 종류: linux, CPU: x86_64
SQLite 드라이버: 있음
```

이 책의 예제는 Ubuntu 24.04에 들어 있는 **Qt 6.4.2**로 실제로 빌드하고 실행해 확인했습니다. 창을 띄우는 예제는 화면이 없는 환경에서 돌리기 위해 `offscreen` 플랫폼 플러그인으로 실행했습니다. 6.4보다 나중에 생긴 기능을 설명할 때는 그렇다고 따로 적었습니다. 위 출력에서 보듯 같은 프로그램이라도 실행되는 Qt 라이브러리의 판(`qVersion()`)과 컴파일할 때 머리 파일의 판(`QT_VERSION_STR`)이 다를 수 있습니다. Qt는 같은 주 판(6.x) 안에서 이전 판으로 빌드한 프로그램이 새 판 라이브러리에서도 돌도록 이진 호환성을 지킵니다.

## 모듈

Qt는 하나의 거대한 라이브러리가 아니라 필요한 것만 골라 링크하는 **모듈**의 모음입니다.

| 모듈 | 하는 일 |
| --- | --- |
| Core | QObject, 시그널과 슬롯, 이벤트 루프, 문자열, 컨테이너, 파일, 스레드 |
| Gui | 창, 이미지, 글꼴, QPainter, OpenGL·Vulkan 연결 |
| Widgets | 버튼, 표, 대화 상자 같은 전통적인 데스크톱 위젯 |
| Qml, Quick | QML 언어와 그것으로 만드는 GPU 가속 UI |
| Network, Sql | HTTP와 소켓, 데이터베이스 |

이 밖에도 WebSockets, SerialPort, Test, Multimedia, Quick 3D 같은 모듈이 있습니다. 예제처럼 SQLite 드라이버나 이미지 형식, 플랫폼 지원(Windows, X11, Wayland, `offscreen`)은 모듈 안에서도 다시 **플러그인**으로 나뉘어 실행 중에 불러옵니다. 배포할 때 이 플러그인 폴더를 빠뜨리면 "플랫폼 플러그인을 찾을 수 없다"는 유명한 오류가 납니다. [「데스크톱 배포 도구」](#/read/cpp-qt/dep-desktop)에서 다시 봅니다.

## 판과 장기 지원

Qt는 1년에 두 번(봄과 가을) 부 판(6.10, 6.11, …)을 냅니다. 6.8부터는 네 번째 부 판마다 **장기 지원(LTS)** 판이 되어 5년간 유지 보수됩니다. 2026년 9월 30일에 나온 6.12가 최신 LTS이고, 그 앞의 LTS는 6.8입니다. 오래 유지할 제품이라면 LTS 판을 기준으로 잡는 것이 보통입니다.

## 라이선스

Qt는 **오픈 소스 라이선스와 상용 라이선스** 두 가지로 제공됩니다.

- 오픈 소스판의 대부분 모듈은 **LGPLv3**입니다. 동적 링크로 쓰고, 사용자가 Qt 라이브러리를 다른 판으로 바꿔 끼울 수 있게 하는 등 라이선스의 조건을 지키면 비공개 상용 앱에도 쓸 수 있습니다
- 일부 모듈과 도구는 **GPLv3**로만 열려 있어서, 그것을 쓰면 앱 전체를 GPL 조건으로 공개해야 합니다
- **상용 라이선스**는 이런 조건 없이 쓸 수 있고, 정적 링크와 LTS 판의 추가 패치, 기술 지원이 포함됩니다

<Note>
라이선스 조건은 앱을 어떻게 배포하느냐(정적 링크인지, 잠긴 임베디드 장치인지)에 따라 의무가 달라지고, 모듈마다 라이선스가 다를 수 있습니다. 실제 제품에 쓰기 전에는 Qt 공식 라이선스 안내에서 쓰려는 모듈의 라이선스를 확인하고, 필요하면 법률 전문가와 상의하세요. 이 책의 설명은 법률 조언이 아닙니다.
</Note>

## 정리

- Qt는 Core, Gui, Widgets, Qml·Quick, Network, Sql 같은 모듈과 플러그인으로 이루어지며 필요한 것만 링크한다
- 1년에 두 번 부 판이 나오고, 6.8부터 네 번째 판마다 5년 지원의 LTS가 되며, 최신 LTS는 6.12이다
- 대부분 모듈은 LGPLv3, 일부는 GPLv3, 그리고 상용 라이선스가 있으며, 이 책의 예제는 Qt 6.4.2로 확인했다
