## 겹쳐 쌓은 레이아웃

```cpp qt=Widgets
#include <QApplication>
#include <QGridLayout>
#include <QHBoxLayout>
#include <QLabel>
#include <QLineEdit>
#include <QListWidget>
#include <QPushButton>
#include <QVBoxLayout>
#include <cstdio>

void geom(const char* name, QWidget* w) {
    QRect g = w->geometry();
    std::printf("  %s x=%3d y=%3d  %3d x %3d\n",
                name, g.x(), g.y(), g.width(), g.height());
}

int main(int argc, char** argv) {
    QApplication app(argc, argv);
    QWidget win;
    auto* outer = new QVBoxLayout(&win);
    outer->setContentsMargins(10, 10, 10, 10);  // 창 가장자리 여백
    outer->setSpacing(6);                       // 위젯 사이 간격

    // 위: 검색 줄 = 라벨 + 입력 칸(늘어남) + 버튼
    auto* top = new QHBoxLayout;
    auto* findLabel = new QLabel("찾기");
    auto* find = new QLineEdit;
    auto* go = new QPushButton("검색");
    top->addWidget(findLabel);
    top->addWidget(find, 1);                    // 늘어나는 몫 1
    top->addWidget(go);

    // 가운데: 목록(늘어남) + 오른쪽 버튼 기둥
    auto* middle = new QHBoxLayout;
    auto* list = new QListWidget;
    auto* side = new QVBoxLayout;
    auto* add = new QPushButton("추가");
    auto* del = new QPushButton("삭제");
    side->addWidget(add);
    side->addWidget(del);
    side->addStretch();                         // 남는 세로 공간을 아래로 밀어 둔다
    middle->addWidget(list, 1);
    middle->addLayout(side);

    // 아래: 격자 2x2
    auto* grid = new QGridLayout;
    grid->addWidget(new QLabel("총"), 0, 0);
    grid->addWidget(new QLabel("0개"), 0, 1);
    auto* ok = new QPushButton("확인");
    grid->addWidget(ok, 1, 0, 1, 2);            // 두 칸에 걸침

    outer->addLayout(top);
    outer->addLayout(middle, 1);                // 가운데 줄이 세로로 늘어난다
    outer->addLayout(grid);

    for (QSize s : {QSize(400, 300), QSize(600, 400)}) {
        win.resize(s);
        win.show();
        outer->activate();                      // 지금 바로 배치를 계산시킨다
        std::printf("창 %d x %d\n", win.width(), win.height());
        geom("입력", find); geom("검색", go); geom("목록", list);
        geom("추가", add); geom("확인", ok);
    }
}
```

## 읽는 법

창을 400×300에서 600×400으로 키우자 무엇이 바뀌고 무엇이 그대로인지 보세요.

- **늘어난 것**: 입력 칸 폭(265 → 465), 목록 크기(294×192 → 494×292), 확인 버튼 폭(380 → 580). 늘어난 200만큼을 `addWidget(find, 1)`, `addWidget(list, 1)`처럼 **늘어나는 몫**(stretch)을 준 위젯이 가져갔습니다. 세로로는 `addLayout(middle, 1)`을 준 가운데 줄이 100을 모두 가져갔습니다
- **그대로인 것**: 버튼들은 80×26 그대로 오른쪽으로 옮겨 갔습니다. 버튼은 기본적으로 "적당한 크기 이상은 원하지 않는" 크기 정책을 가지기 때문입니다
- **빈 공간**: 오른쪽 기둥의 `addStretch()`는 보이지 않는 늘어나는 칸입니다. 이것이 없으면 추가·삭제 버튼이 세로로 퍼져 목록 높이에 맞춰 띄엄띄엄 놓입니다
- **여백과 간격**: `setContentsMargins(10, …)` 때문에 목록과 확인 버튼이 x=10에서 시작하고, `setSpacing(6)` 때문에 찾기 줄(높이 약 26)과 목록(y=42) 사이가 6만큼 떨어졌습니다
- **격자**: `QGridLayout`의 `addWidget(ok, 1, 0, 1, 2)`는 1행 0열에서 시작해 1행 2열에 걸치게 놓습니다. 표 모양 양식이나 계산기 자판에 씁니다

## 크기 정책

위젯마다 **크기 힌트**(가장 알맞은 크기)와 **크기 정책**(그보다 커지거나 작아져도 되는지)이 있습니다. 목록과 입력 칸은 "늘어나도 좋다", 버튼과 라벨은 "힌트 크기가 좋다"가 기본입니다. 기본값이 마음에 들지 않으면 `setSizePolicy(QSizePolicy::Expanding, QSizePolicy::Fixed)`처럼 바꾸거나, `setMinimumWidth`, `setMaximumHeight`로 한계를 둡니다. 대부분은 늘어나는 몫과 `addStretch`만으로 원하는 모양이 나옵니다.

<Note>
레이아웃 계산은 보통 이벤트 루프 안에서 위젯이 보이거나 크기가 바뀔 때 일어납니다. 예제는 이벤트 루프 없이 바로 결과를 보려고 `outer->activate()`를 불렀습니다. 실제 앱에서는 부를 일이 거의 없습니다. 또 Qt Designer로 화면을 그리면 이 레이아웃 코드를 `.ui` 파일로 만들어 주고, 빌드할 때 `uic`가 C++ 코드로 바꿉니다.
</Note>

## 정리

- 위젯의 좌표 대신 가로·세로·격자 레이아웃을 겹쳐 배치 규칙을 정하면, 레이아웃이 창 크기에 맞춰 좌표를 계산한다
- 늘어나는 몫을 준 위젯이 남는 공간을 가져가고, addStretch는 빈 공간을 만들며, 여백과 간격으로 숨 쉴 틈을 둔다
- 위젯마다 크기 힌트와 크기 정책이 있어 버튼은 그대로, 목록과 입력 칸은 늘어나는 것이 기본이다
