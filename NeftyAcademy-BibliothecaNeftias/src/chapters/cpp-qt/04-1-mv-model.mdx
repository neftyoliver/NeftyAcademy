목록이나 표를 화면에 보여 줄 때, 데이터를 위젯 안에 직접 넣어 두면(`QTableWidget`에 칸마다 글을 넣는 식) 데이터가 바뀔 때마다 화면 칸을 찾아 고쳐야 하고, 같은 데이터를 두 곳에 보여 주면 두 벌을 맞춰야 합니다. Qt의 **모델/뷰**는 이것을 나눕니다. **모델**은 데이터를 갖고 "몇 행, 몇 열이고, 이 칸의 값은 이것"이라고 답만 하고, **뷰**는 모델에게 물어 화면을 그립니다. 데이터가 바뀌면 모델이 알리고, 붙어 있는 모든 뷰가 스스로 다시 그립니다.

## 재고 표 모델

```cpp qt=Test
#include <QAbstractItemModelTester>
#include <QAbstractTableModel>
#include <QCoreApplication>
#include <QVector>
#include <cstdio>

struct Item { QString name; int qty; double price; };

class Inventory : public QAbstractTableModel {
public:
    QVector<Item> items{{"사과", 3, 1.2}, {"배", 1, 2.5}};

    int rowCount(const QModelIndex& parent = {}) const override {
        return parent.isValid() ? 0 : items.size();   // 표: 자식 없음
    }
    int columnCount(const QModelIndex& parent = {}) const override {
        return parent.isValid() ? 0 : 3;
    }
    QVariant data(const QModelIndex& i, int role) const override {
        const Item& it = items[i.row()];
        if (role == Qt::DisplayRole || role == Qt::EditRole) {
            switch (i.column()) {
                case 0: return it.name;
                case 1: return it.qty;
                case 2:
                    if (role == Qt::EditRole) return it.price;
                    return QString::number(it.price, 'f', 2) + "€";
            }
        }
        if (role == Qt::TextAlignmentRole && i.column() > 0)
            return int(Qt::AlignRight | Qt::AlignVCenter);
        return {};
    }
    QVariant headerData(int s, Qt::Orientation o,
                        int role = Qt::DisplayRole) const override {
        if (role != Qt::DisplayRole || o != Qt::Horizontal) return {};
        return QStringList{"이름", "수량", "값"}.value(s);
    }
    Qt::ItemFlags flags(const QModelIndex& i) const override {
        auto f = QAbstractTableModel::flags(i);
        // 수량만 고칠 수 있다
        return i.column() == 1 ? f | Qt::ItemIsEditable : f;
    }
    bool setData(const QModelIndex& i, const QVariant& v,
                 int role = Qt::EditRole) override {
        if (role != Qt::EditRole || i.column() != 1 || v.toInt() < 0) return false;
        items[i.row()].qty = v.toInt();
        emit dataChanged(i, i, {role});                 // 뷰에게 알린다
        return true;
    }
    void add(const Item& it) {
        // 들어갈 자리를 먼저 알리고
        beginInsertRows({}, items.size(), items.size());
        items.push_back(it);
        endInsertRows();                                 // 다 넣었다고 알린다
    }
};

int main(int argc, char** argv) {
    QCoreApplication app(argc, argv);
    Inventory m;
    QAbstractItemModelTester tester(&m);   // 모델 규칙 위반을 잡아 주는 검사기

    QObject::connect(&m, &QAbstractItemModel::rowsInserted,
                     [](auto&, int a, int b) {
                         std::printf("  [뷰가 받을 알림] 행 %d~%d 추가\n", a, b);
                     });
    QObject::connect(&m, &QAbstractItemModel::dataChanged, [](auto& tl, auto&) {
        std::printf("  [뷰가 받을 알림] (%d,%d) 바뀜\n", tl.row(), tl.column());
    });

    auto dump = [&] {                              // 뷰가 하는 일을 글자로 흉내
        QStringList head;
        for (int c = 0; c < m.columnCount(); ++c)
            head << m.headerData(c, Qt::Horizontal).toString();
        std::printf("  %s\n", qPrintable(head.join(" | ")));
        for (int r = 0; r < m.rowCount(); ++r) {
            QStringList row;
            for (int c = 0; c < m.columnCount(); ++c)
                row << m.index(r, c).data().toString();
            std::printf("  %s\n", qPrintable(row.join(" | ")));
        }
    };
    dump();
    m.add({"감", 7, 0.8});
    bool ok1 = m.setData(m.index(1, 1), 5);
    bool ok2 = m.setData(m.index(1, 0), "망고");      // 이름 칸은 고칠 수 없다
    std::printf("수량 고치기 %s, 이름 고치기 %s\n",
                ok1 ? "성공" : "실패", ok2 ? "성공" : "실패");
    dump();
    std::printf("편집용 값(EditRole) %.1f, 화면용 값(DisplayRole) %s\n",
                m.index(0, 2).data(Qt::EditRole).toDouble(),
                qPrintable(m.index(0, 2).data(Qt::DisplayRole).toString()));
}
```

## 모델이 답하는 질문

- **rowCount, columnCount**: 몇 행, 몇 열인가. `parent`가 유효하면(어떤 칸의 자식을 물으면) 표에는 자식이 없으므로 0을 돌려줍니다. 나무 모델에서는 여기서 자식 수를 답합니다
- **data(index, role)**: 이 칸의 값은. 핵심은 **역할**(role)입니다. 같은 칸이라도 화면에 보일 글(`DisplayRole`, "1.20€"), 편집할 때의 값(`EditRole`, 1.2), 정렬(`TextAlignmentRole`), 글자색(`ForegroundRole`), 아이콘(`DecorationRole`), 풍선 도움말(`ToolTipRole`)을 따로 답할 수 있습니다. 모르는 역할에는 빈 `QVariant`를 돌려줍니다
- **headerData**: 머리글. 가로 머리글은 열 이름, 세로 머리글은 보통 행 번호입니다
- **flags**: 이 칸으로 무엇을 할 수 있나. 수량 칸에만 `ItemIsEditable`을 주었습니다

## 바꿀 때의 규칙

모델이 데이터를 바꾸면 반드시 뷰에게 알려야 합니다. 알리는 방법이 정해져 있습니다.

- **값이 바뀌면** `dataChanged(왼쪽 위, 오른쪽 아래, 역할들)`을 냅니다. `setData`가 수량을 5로 바꾸고 (1,1)이 바뀌었다고 알렸습니다. 이름 칸은 편집 불가라서 `false`를 돌려주었습니다
- **행을 넣을 때는** 넣기 **전에** `beginInsertRows(부모, 첫 행, 끝 행)`, 넣은 **뒤에** `endInsertRows()`를 부릅니다. 뷰는 begin에서 선택 상태와 스크롤 위치를 저장하고, end에서 새 행을 받아 다시 그립니다. 지우기(`beginRemoveRows`), 옮기기(`beginMoveRows`)도 같은 짝이 있습니다
- 데이터를 통째로 바꿀 때는 `beginResetModel()`과 `endResetModel()`로 감쌉니다. 간단하지만 뷰의 선택과 스크롤이 초기화됩니다

`QAbstractItemModelTester`는 Qt Test 모듈에 들어 있는 검사기로, 모델에 붙여 두면 이 규칙을 어길 때(행 수와 알림이 맞지 않을 때, 잘못된 인덱스에 값을 돌려줄 때) 바로 경고하거나 멈춥니다. 직접 만든 모델을 개발하는 동안에는 늘 붙여 두는 것이 좋습니다. 예제는 아무 경고 없이 통과했습니다.

<Note>
간단한 목록이라면 직접 모델을 만들지 않아도 됩니다. 문자열 목록은 `QStringListModel`, 칸마다 값을 넣는 범용 모델은 `QStandardItemModel`이 있습니다. 데이터가 이미 C++ 컨테이너나 데이터베이스에 있고 양이 많다면, 그 데이터를 복사하지 않고 그대로 들여다보는 직접 만든 모델이 메모리와 속도 모두에서 유리합니다.
</Note>

## 정리

- 모델은 데이터를 갖고 행 수, 열 수, 칸 값, 머리글, 칸 플래그에 답하며, 뷰는 그것을 물어 화면을 그린다
- 칸 값은 역할별로 따로 답해 화면용 글, 편집용 값, 정렬, 색 등을 구분한다
- 값이 바뀌면 dataChanged, 행을 넣고 지울 때는 begin/end 짝으로 알리며, QAbstractItemModelTester로 규칙 위반을 잡는다
