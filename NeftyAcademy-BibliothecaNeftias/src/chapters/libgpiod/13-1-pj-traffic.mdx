이 장에서는 앞에서 배운 것을 모아 네 가지를 만듭니다. 첫 번째는 보행자 단추가 달린 신호등입니다. 등 셋을 쓰는 출력, 단추를 듣는 에지 이벤트, 시한이 있는 기다림이 한 반복문에 모입니다. 이 쪽에 새 함수는 없습니다.

## 만들 것과 배선

차를 향한 등은 보통 초록입니다. 보행자가 단추를 누르면 노랑을 거쳐 빨강이 되고, 얼마 뒤 초록으로 돌아옵니다.

```text
핀 11 (GPIO 17) ----[ 330Ω ]---- 빨간 LED ---- GND
핀 15 (GPIO 22) ----[ 330Ω ]---- 노란 LED ---- GND
핀 16 (GPIO 23) ----[ 330Ω ]---- 초록 LED ---- GND
핀 13 (GPIO 27) ---- 단추 ---- GND
```

- **LED마다 저항 하나**: 저항 하나를 셋이 나눠 쓰지 않습니다. 켜진 등의 수에 따라 전류가 달라지기 때문입니다([「LED 켜기」](#/read/libgpiod/out-led))
- **단추는 풀업으로 읽는다**: 바깥 저항 없이 핀 안의 풀업을 켭니다. 누르면 LOW입니다([「단추 읽기」](#/read/libgpiod/in-button))
- **시간은 줄였다**: 초록을 지키는 시간 3초, 노랑 1초, 빨강 3초입니다. 책에 싣는 출력이 길어지지 않게 고른 값입니다

## 프로그램

```c gpiosim=traffic
// 보행자 단추가 달린 신호등: 초록이다가 단추가 눌리면 노랑, 빨강을 거쳐 돌아온다
#define _POSIX_C_SOURCE 200809L              // clock_gettime을 쓰려고
#include <errno.h>
#include <gpiod.h>
#include <signal.h>
#include <stdint.h>
#include <stdio.h>
#include <time.h>

enum { RED = 17, YELLOW = 22, GREEN = 23 };  // 핀 11, 15, 16
enum { BUTTON = 27 };                        // 핀 13. 건너편은 GND
enum phase { GO, WARN, STOP };               // 초록, 노랑, 빨강
static const int64_t SECOND = 1'000'000'000;
static const int64_t MIN_GO = 3 * SECOND;    // 초록은 적어도 이만큼 지킨다
static const int64_t WARN_TIME = 1 * SECOND;
static const int64_t STOP_TIME = 3 * SECOND;

static volatile sig_atomic_t stop;
static void on_signal(int) { stop = 1; }

static int64_t now_ns(void) {
    struct timespec now;
    clock_gettime(CLOCK_MONOTONIC, &now);
    return now.tv_sec * SECOND + now.tv_nsec;
}

// 등 셋은 꺼진 출력으로, 단추는 풀업을 켠 입력으로 한 번에 요청한다
static struct gpiod_line_request* request_lines(struct gpiod_chip* chip) {
    struct gpiod_line_settings* lamp = gpiod_line_settings_new();
    struct gpiod_line_settings* button = gpiod_line_settings_new();
    struct gpiod_line_config* config = gpiod_line_config_new();
    struct gpiod_request_config* request_config = gpiod_request_config_new();
    struct gpiod_line_request* request = nullptr;
    if (lamp && button && config && request_config) {
        gpiod_line_settings_set_direction(lamp, GPIOD_LINE_DIRECTION_OUTPUT);
        gpiod_line_settings_set_direction(button, GPIOD_LINE_DIRECTION_INPUT);
        gpiod_line_settings_set_bias(button, GPIOD_LINE_BIAS_PULL_UP);
        gpiod_line_settings_set_edge_detection(button, GPIOD_LINE_EDGE_FALLING);
        gpiod_line_settings_set_debounce_period_us(button, 10'000);
        const unsigned int lamps[] = {RED, YELLOW, GREEN};
        gpiod_line_config_add_line_settings(config, lamps, 3, lamp);
        gpiod_line_config_add_line_settings(config, &(unsigned int){BUTTON}, 1,
                                            button);
        gpiod_request_config_set_consumer(request_config, "traffic");
        request = gpiod_chip_request_lines(chip, request_config, config);
    }
    gpiod_request_config_free(request_config);
    gpiod_line_config_free(config);
    gpiod_line_settings_free(button);
    gpiod_line_settings_free(lamp);
    return request;
}

// 세 등을 한 번에 바꾼다. 켜진 등이 둘이 되는 순간이 없다
static void show(struct gpiod_line_request* lines, enum phase phase,
                 int64_t origin) {
    static const char* const names[] = {"초록", "노랑", "빨강"};
    const unsigned int lamps[] = {RED, YELLOW, GREEN};
    const enum gpiod_line_value values[] = {
        phase == STOP ? GPIOD_LINE_VALUE_ACTIVE : GPIOD_LINE_VALUE_INACTIVE,
        phase == WARN ? GPIOD_LINE_VALUE_ACTIVE : GPIOD_LINE_VALUE_INACTIVE,
        phase == GO ? GPIOD_LINE_VALUE_ACTIVE : GPIOD_LINE_VALUE_INACTIVE,
    };
    gpiod_line_request_set_values_subset(lines, 3, lamps, values);
    printf("%5.2fs %s\n", (double)(now_ns() - origin) / 1e9, names[phase]);
}

int main(void) {
    struct gpiod_chip* chip = gpiod_chip_open("/dev/gpiochip0");
    if (!chip) {
        perror("/dev/gpiochip0");
        return 1;
    }
    struct gpiod_line_request* lines = request_lines(chip);
    gpiod_chip_close(chip);
    struct gpiod_edge_event_buffer* buffer = gpiod_edge_event_buffer_new(4);
    if (!lines || !buffer) {
        perror("요청");
        return 1;
    }
    signal(SIGINT, on_signal);
    signal(SIGTERM, on_signal);

    const int64_t origin = now_ns();
    enum phase phase = GO;
    bool wanted = false;                     // 건너려는 사람이 있다
    int64_t since = origin;                  // 지금 등이 켜진 때
    show(lines, phase, origin);
    while (!stop) {
        // 지금 등을 끝낼 때. 초록은 건너려는 사람이 있을 때만 끝이 있다
        const int64_t length =
            phase == GO ? MIN_GO : phase == WARN ? WARN_TIME : STOP_TIME;
        int64_t wait = since + length - now_ns();
        if (phase == GO && !wanted) wait = -1;    // 단추가 올 때까지 잔다
        else if (wait < 0) wait = 0;
        int ready = gpiod_line_request_wait_edge_events(lines, wait);
        if (ready < 0) {
            if (errno == EINTR) continue;
            perror("기다리기");
            break;
        }
        if (ready == 0) {                    // 때가 됐다. 다음 등으로
            phase = phase == GO ? WARN : phase == WARN ? STOP : GO;
            if (phase == WARN) wanted = false;
            since = now_ns();
            show(lines, phase, origin);
            continue;
        }
        int count = gpiod_line_request_read_edge_events(lines, buffer, 4);
        if (count < 0) {
            perror("읽기");
            break;
        }
        for (int i = 0; i < count; ++i) {
            // 규칙: 초록일 때 누른 것만 받는다. 이미 바뀌는 중이면 넘긴다
            const bool taken = phase == GO && !wanted;
            if (taken) wanted = true;
            printf("%5.2fs 단추%s\n", (double)(now_ns() - origin) / 1e9,
                   taken ? ": 받았다" : ": 넘긴다");
        }
    }
    // 모두 끄고 놓는다
    const unsigned int lamps[] = {RED, YELLOW, GREEN};
    const enum gpiod_line_value off[3] = {};
    gpiod_line_request_set_values_subset(lines, 3, lamps, off);
    printf("%5.2fs 모두 껐다\n", (double)(now_ns() - origin) / 1e9);
    gpiod_edge_event_buffer_free(buffer);
    gpiod_line_request_release(lines);
}
```

```text
 0.00s 초록
 1.01s 단추: 받았다
 3.00s 노랑
 4.00s 빨강
 4.51s 단추: 넘긴다
 7.00s 초록
 9.01s 단추: 받았다
10.00s 노랑
11.00s 빨강
14.00s 초록
14.50s 모두 껐다
```

- **요청은 하나다**: 등 셋과 단추를 한 요청에 담았습니다. 설정 객체는 출력용과 입력용 둘이고, 같은 줄 설정에 오프셋을 적어 넣습니다([「설정 객체 셋: line_settings, line_config, request_config」](#/read/libgpiod/rq-objects))
- **등은 한 번에 바꾼다**: `show`는 세 줄의 값을 `gpiod_line_request_set_values_subset` 한 번으로 씁니다. 하나씩 쓰면 그 사이에 등 둘이 함께 켜지거나 모두 꺼진 순간이 생깁니다([「여러 줄 한꺼번에 쓰기」](#/read/libgpiod/out-multi))
- **기다림 하나가 두 일을 한다**: `gpiod_line_request_wait_edge_events`에 지금 등이 끝날 때까지 남은 시간을 줍니다. 1이 돌아오면 단추이고, 0이 돌아오면 때가 된 것입니다([「기다리고 읽기」](#/read/libgpiod/ed-wait))
- **남은 시간은 매번 다시 센다**: 단추 때문에 일찍 깨어도 등이 켜진 때(`since`)에서 다시 셈하므로, 등의 길이는 달라지지 않습니다. 4.51초에 단추가 눌렸어도 빨강은 7.00초에 끝났습니다
- **초록에는 끝이 없다**: 건너려는 사람이 없으면 시한에 -1을 주고 단추가 올 때까지 잡니다
- **떨림은 커널이 거른다**: 단추 줄에 거르는 기간 10ms를 적었습니다. 대본의 단추는 누를 때마다 접점이 떨리지만 이벤트는 한 번씩 왔고, 그 시각은 눌린 지 10ms 뒤입니다([「디바운스」](#/read/libgpiod/ed-debounce))

## 단추를 받는 규칙

언제 누른 단추를 받을지는 배선이 아니라 프로그램이 정합니다. 이 예제의 규칙은 셋입니다.

| 누른 때 | 하는 일 | 출력에서 |
| --- | --- | --- |
| 초록이 3초를 채우기 전 | 기억해 두고 3초를 채운 뒤 바꾼다 | 1.01초에 받고 3.00초에 노랑 |
| 초록이 3초를 넘긴 뒤 | 받는 대로 바꾼다 | 이 대본에는 없다 |
| 노랑이나 빨강일 때 | 넘긴다 | 4.51초 |

- **초록을 지키는 시간**: 단추를 누를 때마다 곧바로 바뀌면 차가 지나갈 틈이 없습니다. 9.01초의 단추는 초록이 켜진 지 2초 뒤여서, 10.00초까지 기다렸다가 바뀌었습니다
- **넘긴 단추는 사라진다**: 빨강일 때는 이미 건널 차례이므로 받지 않았습니다. 빨강 끝에 누른 사람은 초록이 된 뒤 다시 눌러야 합니다. 이것을 기억해 주려면 `taken`의 조건을 고칩니다
- **이 규칙은 커널에 맡길 수 없다**: 에지를 세거나 거르는 일은 커널이 하지만, 받은 에지로 무엇을 할지는 프로그램의 몫입니다([「커널 드라이버에 맡길 것들」](#/read/libgpiod/tm-kernel))

## 끝낼 때와 고쳐 볼 것

- **끄고 나서 놓는다**: Ctrl+C가 오면 기다림이 `EINTR`로 깨고, 반복문이 끝나 세 등을 끈 뒤 줄을 놓습니다. 끄지 않고 놓으면 라즈베리파이의 커널에서는 마지막 등이 켜진 채로 남습니다([「놓아주기」](#/read/libgpiod/rq-release))
- **죽으면 등이 남는다**: 프로그램이 신호 처리 없이 죽으면 끄는 줄을 거치지 못합니다. 등 하나가 켜진 채로 멈춘 신호등이 됩니다
- **보행자 등을 더한다**: 줄 둘을 더 요청해 차의 빨강 동안 보행자의 초록을 켭니다. `show`가 쓰는 줄이 다섯이 될 뿐 반복문은 그대로입니다
- **깜빡임을 더한다**: 빨강이 끝나기 전 1초를 깜빡이게 하려면 상태를 하나 더 두고, 그 상태의 시한을 0.25초로 잡아 올 때마다 값을 뒤집습니다

<Note>
예제는 이 책의 흉내 칩에서 돌린 것이고, 단추가 눌리는 때와 접점의 떨림, 14.5초의 Ctrl+C는 대본으로 넣었습니다. 흉내 칩의 시간은 가상이라 출력의 시각이 100분의 1초까지 고릅니다. 진짜 libgpiod 2.2.4의 머리 파일로 x86-64와 aarch64에서 컴파일되는지 확인했고, 보드에 LED와 단추를 달아 돌려 보지는 못했습니다. 이 예제는 연습용입니다. 사람이나 차의 안전이 걸린 신호를 이런 프로그램 하나에 맡겨서는 안 됩니다.
</Note>

## 정리

- 상태 하나와 그 상태가 켜진 때를 들고, 남은 시간만큼 에지 이벤트를 기다리면 시한과 단추를 한 반복문에서 다룬다
- 등은 한 번의 쓰기로 함께 바꾸고, 끝낼 때에는 모두 끄고 나서 줄을 놓는다
- 단추를 언제 받고 언제 넘길지는 프로그램의 규칙이다. 규칙을 표로 적어 두면 고치기 쉽다
