줄을 요청하지 않고도 그 줄에 대해 알 수 있는 것이 있습니다. 이름, 방향, 누가 쥐고 있는지, 어떤 설정으로 쥐었는지입니다. 이것을 줄 정보라고 하고, `gpioinfo`가 보여 주던 것이 바로 이것입니다. 한 번 읽을 수도 있고, 바뀔 때마다 알려 달라고 할 수도 있습니다.

## 읽기와 지켜보기

아래 예제는 GPIO 17의 지금 모습을 읽고, 그 뒤로 다른 프로그램이 그 줄을 쥐고 바꾸고 놓는 것을 지켜봅니다.

```c gpiosim=holder
// 줄 하나의 정보를 읽고, 그 줄이 쥐이고 바뀌고 놓이는 것을 지켜본다
#include <gpiod.h>
#include <inttypes.h>
#include <stdio.h>

enum { LINE = 17 };                          // GPIO 17, 헤더의 핀 11

// 줄 정보를 한 줄로 적는다: 이름, 방향, 임자
static void describe(struct gpiod_line_info* info) {
    const char* name = gpiod_line_info_get_name(info);
    const char* who = gpiod_line_info_get_consumer(info);
    bool out = gpiod_line_info_get_direction(info) == GPIOD_LINE_DIRECTION_OUTPUT;
    printf("%s %s", name ? name : "unnamed", out ? "output" : "input");
    if (gpiod_line_info_is_used(info))
        printf(" consumer=%s\n", who ? who : "?");
    else
        printf(" (임자 없음)\n");
}

int main(void) {
    struct gpiod_chip* chip = gpiod_chip_open("/dev/gpiochip0");
    if (!chip) {
        perror("/dev/gpiochip0");
        return 1;
    }
    // 지금의 모습을 받으면서 지켜보기를 시작한다
    struct gpiod_line_info* now = gpiod_chip_watch_line_info(chip, LINE);
    if (!now) {
        perror("지켜보기");
        gpiod_chip_close(chip);
        return 1;
    }
    printf("처음                    ");
    describe(now);
    gpiod_line_info_free(now);

    static const char* const kind[] = {
        [GPIOD_INFO_EVENT_LINE_REQUESTED] = "requested   ",
        [GPIOD_INFO_EVENT_LINE_RELEASED] = "released    ",
        [GPIOD_INFO_EVENT_LINE_CONFIG_CHANGED] = "reconfigured",
    };
    const int64_t quiet_ns = 5'000'000'000;  // 이만큼 소식이 없으면 끝낸다
    while (gpiod_chip_wait_info_event(chip, quiet_ns) == 1) {
        struct gpiod_info_event* event = gpiod_chip_read_info_event(chip);
        if (!event) break;
        uint64_t ms = gpiod_info_event_get_timestamp_ns(event) / 1'000'000;
        printf("%" PRIu64 ".%03" PRIu64 "  %s  ", ms / 1000, ms % 1000,
               kind[gpiod_info_event_get_event_type(event)]);
        describe(gpiod_info_event_get_line_info(event));   // 이벤트에 딸린 정보
        gpiod_info_event_free(event);                      // 정보도 함께 풀린다
    }
    printf("5초 동안 소식이 없어 끝낸다\n");
    gpiod_chip_unwatch_line_info(chip, LINE);
    gpiod_chip_close(chip);
}
```

```text
처음                    GPIO17 input (임자 없음)
5001.000  requested     GPIO17 output consumer=blinker
5002.500  reconfigured  GPIO17 input consumer=blinker
5004.000  released      GPIO17 input (임자 없음)
5초 동안 소식이 없어 끝낸다
```

- **`gpiod_chip_get_line_info`**: 줄의 지금 모습을 새 객체로 돌려줍니다. 다 쓰면 `gpiod_line_info_free`로 풀어 줍니다
- **`gpiod_chip_watch_line_info`**: 같은 것을 돌려주면서 그 줄을 지켜보기 시작합니다. 예제는 이쪽을 썼습니다. 읽기와 지켜보기 사이에 생긴 변화를 놓치지 않으려면 둘을 따로 부르지 않고 이 함수 하나로 합니다
- **정보는 받은 순간의 것이다**: 객체는 줄이 바뀌어도 그대로입니다. 새 모습은 다시 읽거나 이벤트로 받습니다
- **`gpiod_chip_wait_info_event`**: 소식이 있으면 1, 시간이 다 되면 0, 오류면 -1입니다. 시간은 나노초이고 0이면 바로 돌아오며 음수면 끝없이 기다립니다
- **`gpiod_chip_read_info_event`**: 이벤트 하나를 읽습니다. 없으면 생길 때까지 막히므로 기다린 뒤에 부릅니다
- **이벤트에 든 것**: 종류, 시각, 그때의 줄 정보입니다. 시각은 커널의 단조 시계로 잰 나노초입니다
- **딸린 정보는 풀지 않는다**: `gpiod_info_event_get_line_info`가 준 객체는 이벤트의 것이라 `gpiod_info_event_free`가 함께 풉니다. 이벤트보다 오래 두려면 `gpiod_line_info_copy`로 베낍니다
- **끝낼 때**: `gpiod_chip_unwatch_line_info`로 지켜보기를 거둡니다. 칩을 닫아도 끝납니다

## 정보에 든 것

| 함수 | 돌려주는 것 |
| --- | --- |
| `gpiod_line_info_get_offset` | 오프셋 |
| `gpiod_line_info_get_name` | 줄의 이름. 없으면 `nullptr` |
| `gpiod_line_info_is_used` | 쓰이고 있는지 |
| `gpiod_line_info_get_consumer` | 쥔 쪽이 적어 낸 이름. 없으면 `nullptr` |
| `gpiod_line_info_get_direction` | 입력인지 출력인지 |
| `gpiod_line_info_is_active_low` | 액티브 로로 쥐었는지 |
| `gpiod_line_info_get_bias` | 풀업, 풀다운, 끔, 모름 가운데 하나 |
| `gpiod_line_info_get_drive` | 푸시풀, 오픈 드레인, 오픈 소스 가운데 하나 |
| `gpiod_line_info_get_edge_detection` | 없음, 올라감, 내려감, 양쪽 가운데 하나 |
| `gpiod_line_info_get_event_clock` | 이벤트의 시각을 재는 시계 |
| `gpiod_line_info_get_debounce_period_us` | 디바운스 기간. 없으면 0 |

- **모두 쓰는 예**: [「gpiodetect와 gpioinfo」](#/read/libgpiod/tl-detect)의 예제가 이 함수들로 `gpioinfo`의 한 줄을 만들었습니다
- **쓰이고 있다는 것까지만 안다**: 쥔 쪽이 다른 프로그램인지 커널인지는 알려 주지 않습니다. 요청할 수 없다는 사실만 같습니다
- **바이어스의 모름**: 요청에 바이어스가 실리지 않았다는 뜻입니다. 핀에 풀이 없다는 뜻이 아닙니다
- **글자열은 객체에 딸려 있다**: 이름과 소비자 이름의 포인터는 정보 객체를 풀면 쓸 수 없습니다

## 줄 정보를 믿는 한계

- **값은 들어 있지 않다**: 줄의 전압이 높은지 낮은지는 정보에 없습니다. 값은 줄을 요청해야 읽습니다([「값 읽기」](#/read/libgpiod/in-read))
- **지켜봐도 값의 변화는 오지 않는다**: 오는 것은 쥐임, 놓임, 설정 바뀜 셋뿐입니다. 전압이 바뀌는 것을 알려면 에지를 요청합니다([「에지 감지 켜기」](#/read/libgpiod/ed-request))
- **읽은 뒤에 바뀔 수 있다**: 임자가 없다고 나온 줄도 내가 요청하는 사이에 남이 쥘 수 있습니다. 그래서 미리 확인하고 요청하는 대신, 바로 요청하고 실패를 다룹니다([「이미 쓰이는 줄」](#/read/libgpiod/rq-busy))
- **커널이 아는 데까지만**: 커널을 거치지 않고 바뀐 핀은 정보에 비치지 않습니다([「pinctrl」](#/read/libgpiod/tl-pinctrl))

## 어디에 쓰나

- **요청이 실패했을 때의 안내**: busy로 실패하면 그 줄의 정보를 읽어 누가 쥐고 있는지를 오류 글귀에 넣어 줍니다
- **다른 프로그램을 기다릴 때**: 줄이 놓이기를 기다렸다가 쥐거나, 어떤 프로그램이 줄을 쥐었는지를 확인합니다. `gpionotify`가 이 함수들로 짜여 있습니다([「gpiomon」](#/read/libgpiod/tl-mon))
- **다른 일과 함께 기다릴 때**: `gpiod_chip_get_fd`가 주는 파일 서술자를 `poll`에 넣습니다([「poll, epoll과 함께 쓰기」](#/read/libgpiod/ed-poll))

<Note>
예제는 이 책의 흉내 칩에서 돌린 것이고, 다른 프로그램이 줄을 쥐고 바꾸고 놓는 것은 대본으로 넣었습니다. 시각이 5000초 언저리인 것은 흉내 칩의 단조 시계가 거기서 시작하기 때문입니다. 놓은 뒤에 방향이 `input`으로 남은 것은 그 프로그램이 마지막에 입력으로 바꿔 두었기 때문입니다. 진짜 libgpiod 2.2.4의 머리 파일로 x86-64와 aarch64에서 컴파일되는지 따로 확인했고, 보드에서 돌려 보지는 못했습니다.
</Note>

## 정리

- 줄 정보는 요청 없이 읽는 줄의 모습이다. 이름, 방향, 임자, 요청에 실린 설정이 들어 있고 값은 없다
- `gpiod_chip_watch_line_info`로 지켜보면 쥐임, 놓임, 설정 바뀜이 이벤트로 온다. 이벤트에 딸린 정보는 이벤트와 함께 풀린다
- 정보는 받은 순간의 것이다. 줄이 비었는지는 미리 묻지 말고 요청해서 안다
