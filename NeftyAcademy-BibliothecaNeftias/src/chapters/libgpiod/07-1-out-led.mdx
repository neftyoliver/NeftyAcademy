출력의 첫 예제입니다. 「라즈베리파이 시작하기」의 [「첫 프로젝트: LED 하나 켜기까지」](#/read/sbc-start/first-project)에서 한 번 돌려 본 프로그램을, 이번에는 함수 하나하나가 무엇을 약속하는지 따져 가며 다시 짭니다. 여기서 만든 꼴이 이 장의 나머지 쪽과 뒤의 프로젝트들에서 그대로 쓰입니다.

## 회로

```text
핀 11 (GPIO 17) ----[ 330Ω ]----(긴 다리) LED (짧은 다리)---- 핀 9 (GND)
```

- **HIGH를 내면 켜진다**: 핀에서 나온 전류가 저항과 LED를 지나 GND로 흐릅니다. 빨간 LED와 330Ω이면 4.5mA쯤이고, 핀 하나의 한도인 16mA에 한참 못 미칩니다
- **저항을 빠뜨리지 않는다**: 저항이 없으면 전류를 막는 것이 없습니다([「3.3V, 전류 한계, 보호 저항」](#/read/libgpiod/gp-electrical))

## 깜빡이기

```c gpiosim
// LED 하나를 세 번 깜빡인다: 칩 열기, 출력으로 요청하기, 값 쓰기, 놓기
#include <gpiod.h>
#include <stdio.h>
#include <threads.h>

enum { LED = 17 };                           // GPIO 17, 헤더의 핀 11

// 줄 하나를 출력으로 요청한다. first는 요청과 함께 핀에 나가는 첫 값이다
static struct gpiod_line_request* request_output(struct gpiod_chip* chip,
                                                 unsigned int offset,
                                                 enum gpiod_line_value first,
                                                 const char* consumer) {
    struct gpiod_line_settings* settings = gpiod_line_settings_new();
    struct gpiod_line_config* config = gpiod_line_config_new();
    struct gpiod_request_config* request_config = gpiod_request_config_new();
    struct gpiod_line_request* request = nullptr;
    if (settings && config && request_config) {
        gpiod_line_settings_set_direction(settings, GPIOD_LINE_DIRECTION_OUTPUT);
        gpiod_line_settings_set_output_value(settings, first);
        gpiod_line_config_add_line_settings(config, &offset, 1, settings);
        gpiod_request_config_set_consumer(request_config, consumer);
        request = gpiod_chip_request_lines(chip, request_config, config);
    }
    gpiod_request_config_free(request_config);
    gpiod_line_config_free(config);
    gpiod_line_settings_free(settings);
    return request;
}

int main(void) {
    struct gpiod_chip* chip = gpiod_chip_open("/dev/gpiochip0");
    if (!chip) {
        perror("/dev/gpiochip0");
        return 1;
    }
    struct gpiod_line_request* led =
        request_output(chip, LED, GPIOD_LINE_VALUE_INACTIVE, "blink");
    gpiod_chip_close(chip);                  // 요청을 받았으면 칩은 닫아도 된다
    if (!led) {
        perror("GPIO 17 요청");
        return 1;
    }
    const struct timespec quarter = {.tv_nsec = 250'000'000};
    for (int i = 0; i < 3; ++i) {
        if (gpiod_line_request_set_value(led, LED, GPIOD_LINE_VALUE_ACTIVE) < 0) {
            perror("값 쓰기");
            break;
        }
        thrd_sleep(&quarter, nullptr);
        gpiod_line_request_set_value(led, LED, GPIOD_LINE_VALUE_INACTIVE);
        thrd_sleep(&quarter, nullptr);
    }
    gpiod_line_request_release(led);         // 꺼 둔 채로 놓는다
}
```

```text
핀|   0.000s  GPIO 17 → HIGH
핀|   0.250s  GPIO 17 → LOW
핀|   0.500s  GPIO 17 → HIGH
핀|   0.750s  GPIO 17 → LOW
핀|   1.000s  GPIO 17 → HIGH
핀|   1.250s  GPIO 17 → LOW
```

- **`request_output`**: 앞 장에서 본 설정 객체 셋을 꾸미고 요청해서 풀어 주기까지를 함수 하나로 묶었습니다. 줄 하나를 출력으로 쥐는 일은 늘 이 꼴이라, 이 책의 예제들은 이런 도우미를 하나씩 둡니다
- **첫 값을 요청에 싣는다**: `gpiod_line_settings_set_output_value`로 inactive를 적었습니다. 요청이 받아들여지는 순간 핀은 꺼진 채로 출력이 됩니다
- **`gpiod_line_request_set_value`**: 요청 객체, 오프셋, 값을 받고 성공하면 0, 실패하면 -1을 돌려줍니다
- **값은 둘뿐이다**: `GPIOD_LINE_VALUE_ACTIVE`와 `GPIOD_LINE_VALUE_INACTIVE`입니다. 켜짐과 꺼짐이라는 뜻이고, 이 회로에서는 그것이 HIGH와 LOW입니다. 둘이 어긋나는 회로는 [「액티브 로」](#/read/libgpiod/out-active-low)에서 다룹니다
- **쓴 값은 그대로 남는다**: 다음에 다른 값을 쓸 때까지 핀은 그 값을 냅니다. 되풀이해 써 줄 필요가 없습니다
- **놓기 전에 꺼 두었다**: 반복이 inactive를 쓰고 끝나므로 등이 꺼진 채로 줄을 놓습니다([「놓아주기」](#/read/libgpiod/rq-release))

## 쓰기가 거절될 때

```c gpiosim=quiet
// 값 쓰기가 거절되는 두 경우와, 출력에 쓴 값을 되읽기
#include <errno.h>
#include <gpiod.h>
#include <stdio.h>
#include <string.h>

enum { LED = 17, BUTTON = 27 };              // 헤더의 핀 11과 13

int main(void) {
    struct gpiod_chip* chip = gpiod_chip_open("/dev/gpiochip0");
    struct gpiod_line_settings* settings = gpiod_line_settings_new();
    struct gpiod_line_config* config = gpiod_line_config_new();
    if (!chip || !settings || !config) return 1;

    // 요청 하나에 출력 줄 하나와 입력 줄 하나를 담는다
    unsigned int led = LED, button = BUTTON;
    gpiod_line_settings_set_direction(settings, GPIOD_LINE_DIRECTION_OUTPUT);
    gpiod_line_config_add_line_settings(config, &led, 1, settings);
    gpiod_line_settings_set_direction(settings, GPIOD_LINE_DIRECTION_INPUT);
    gpiod_line_config_add_line_settings(config, &button, 1, settings);
    struct gpiod_line_request* request =
        gpiod_chip_request_lines(chip, nullptr, config);
    gpiod_line_config_free(config);
    gpiod_line_settings_free(settings);
    gpiod_chip_close(chip);
    if (!request) return 1;

    const enum gpiod_line_value on = GPIOD_LINE_VALUE_ACTIVE;
    int result = gpiod_line_request_set_value(request, LED, on);
    printf("LED(17)에 쓰기     %d\n", result);
    printf("LED(17) 되읽기     %d\n", gpiod_line_request_get_value(request, LED));

    result = gpiod_line_request_set_value(request, BUTTON, on);
    printf("단추(27)에 쓰기    %d  %s\n", result, strerror(errno));

    result = gpiod_line_request_set_value(request, 22, on);
    printf("요청에 없는 22번   %d  %s\n", result, strerror(errno));
    gpiod_line_request_release(request);
}
```

```text
LED(17)에 쓰기     0
LED(17) 되읽기     1
단추(27)에 쓰기    -1  Operation not permitted
요청에 없는 22번   -1  Invalid argument
```

- **입력인 줄에는 쓸 수 없다**: `EPERM`입니다. 방향을 출력으로 요청한 줄에만 값을 씁니다
- **오프셋은 칩에서의 번호다**: 요청 안에서 몇째 줄인지가 아닙니다. 요청에 담지 않은 번호를 넘기면 `EINVAL`입니다
- **출력도 읽을 수 있다**: `gpiod_line_request_get_value`는 출력인 줄에도 통합니다. 다만 돌아오는 것이 마지막에 쓴 값인지 핀의 실제 전압인지는 드라이버에 달렸다고 커널 문서가 적습니다. 내가 쓴 값이 필요하면 변수에 두고 씁니다
- **반환값은 언제 살피나**: 요청이 살아 있는 한 쓰기가 실패하는 일은 드뭅니다. 처음 쓸 때 한 번 확인해 두면 오프셋이나 방향을 틀린 것이 거기서 드러납니다

## 깜빡임의 박자

- **조금씩 밀린다**: 예제는 값을 쓰고 0.25초를 잡니다. 쓰는 데 든 시간과 깨어나는 데 든 시간이 한 바퀴마다 더해지므로 주기는 0.5초보다 조금 깁니다. 등을 깜빡이는 데에는 아무 문제가 없고, 박자를 지켜야 하는 신호에는 다른 방법을 씁니다([「사용자 공간에서 얼마나 정확한가」](#/read/libgpiod/tm-jitter))
- **자는 동안에는 CPU를 쓰지 않는다**: 시각을 거듭 재며 기다리는 반복문을 쓰지 않습니다
- **빠르게 깜빡이면 흐리게 켜진 것으로 보인다**: 눈은 1초에 수십 번을 넘는 깜빡임을 가려내지 못합니다. 그것을 써서 밝기를 조절하는 것이 PWM이고, 그 일은 「PWM」에서 다룹니다

<Note>
두 예제는 이 책의 흉내 칩에서 돌린 것이고, `핀|`으로 시작하는 줄은 흉내 칩이 핀의 전압이 바뀔 때 적은 것입니다. 흉내 칩의 시계는 프로그램이 자는 만큼만 가므로 박자가 밀리는 것은 출력에 보이지 않습니다. 출력인 줄을 되읽으면 흉내 칩은 마지막에 쓴 값을 돌려줍니다. 진짜 libgpiod 2.2.4의 머리 파일로 x86-64와 aarch64에서 컴파일되는지 따로 확인했고, 보드와 LED로 돌려 보지는 못했습니다.
</Note>

## 정리

- 줄을 출력으로 요청하면서 첫 값을 함께 싣고, `gpiod_line_request_set_value`로 active와 inactive를 쓴다
- 쓰기는 입력인 줄에 `EPERM`, 요청에 없는 오프셋에 `EINVAL`로 실패한다. 오프셋은 칩에서의 번호다
- 쓴 값은 다시 쓸 때까지 남는다. 끝낼 때는 꺼 두고 놓는다
