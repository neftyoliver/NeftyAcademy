active가 언제나 HIGH인 것은 아닙니다. 핀이 LOW일 때 일하는 회로가 적지 않습니다. 그런 줄에는 액티브 로라고 적어 둡니다. 그러면 프로그램은 켜짐과 꺼짐만 말하고, 그것이 어느 전압인지는 설정 한 곳에만 남습니다.

## 논리값과 전압

| 액티브 로 | active를 쓰면 | inactive를 쓰면 |
| --- | --- | --- |
| 꺼짐(기본) | HIGH | LOW |
| 켜짐 | LOW | HIGH |

- **값은 논리값이다**: 쓰는 값도 읽는 값도 active와 inactive입니다. 커널이 줄마다의 설정을 보고 전압으로 바꿉니다
- **입력에도 같이 듣는다**: 액티브 로로 요청한 입력은 핀이 LOW일 때 active로 읽힙니다([「단추 읽기」](#/read/libgpiod/in-button))

## 같은 코드, 반대인 배선

LED 둘을 서로 반대로 답니다. 하나는 핀이 전류를 내보내 켜고, 하나는 3.3V에서 온 전류를 핀이 받아들여 켭니다.

```c gpiosim
// 배선이 반대인 LED 둘을 같은 코드로 켠다: 하나는 HIGH에, 하나는 LOW에 켜진다
#include <gpiod.h>
#include <stdio.h>
#include <threads.h>

enum {
    LED_SOURCE = 17,                         // 핀 11 → 저항 → LED → GND
    LED_SINK = 22,                           // 3.3V → LED → 저항 → 핀 15
};

// 켜고 끄는 쪽은 배선을 모른다. active가 켜짐이라는 것만 안다
static void light(struct gpiod_line_request* leds, bool on) {
    enum gpiod_line_value v =
        on ? GPIOD_LINE_VALUE_ACTIVE : GPIOD_LINE_VALUE_INACTIVE;
    gpiod_line_request_set_value(leds, LED_SOURCE, v);
    gpiod_line_request_set_value(leds, LED_SINK, v);
}

int main(void) {
    struct gpiod_chip* chip = gpiod_chip_open("/dev/gpiochip0");
    struct gpiod_line_settings* settings = gpiod_line_settings_new();
    struct gpiod_line_config* config = gpiod_line_config_new();
    if (!chip || !settings || !config) {
        perror("준비");
        return 1;
    }
    // 둘 다 출력이고 첫 값은 꺼짐. 배선이 반대인 쪽에만 액티브 로를 적는다
    unsigned int source = LED_SOURCE, sink = LED_SINK;
    gpiod_line_settings_set_direction(settings, GPIOD_LINE_DIRECTION_OUTPUT);
    gpiod_line_settings_set_output_value(settings, GPIOD_LINE_VALUE_INACTIVE);
    gpiod_line_config_add_line_settings(config, &source, 1, settings);
    gpiod_line_settings_set_active_low(settings, true);
    gpiod_line_config_add_line_settings(config, &sink, 1, settings);

    puts("요청한다. 첫 값은 둘 다 inactive");
    struct gpiod_line_request* leds =
        gpiod_chip_request_lines(chip, nullptr, config);
    gpiod_line_config_free(config);
    gpiod_line_settings_free(settings);
    gpiod_chip_close(chip);
    if (!leds) {
        perror("요청");
        return 1;
    }
    thrd_sleep(&(struct timespec){.tv_sec = 1}, nullptr);
    puts("둘 다 active로");
    light(leds, true);
    printf("읽은 값: %d %d\n", gpiod_line_request_get_value(leds, LED_SOURCE),
           gpiod_line_request_get_value(leds, LED_SINK));

    thrd_sleep(&(struct timespec){.tv_sec = 1}, nullptr);
    puts("둘 다 inactive로");
    light(leds, false);
    gpiod_line_request_release(leds);
}
```

```text
요청한다. 첫 값은 둘 다 inactive
핀|   0.000s  GPIO 22 → HIGH
둘 다 active로
핀|   1.000s  GPIO 17 → HIGH
핀|   1.000s  GPIO 22 → LOW
읽은 값: 1 1
둘 다 inactive로
핀|   2.000s  GPIO 17 → LOW
핀|   2.000s  GPIO 22 → HIGH
```

- **`gpiod_line_settings_set_active_low`**: `true`를 주면 그 줄의 논리가 뒤집힙니다. 예제는 22번에만 적었습니다
- **요청하는 순간 22번이 HIGH가 됐다**: 첫 값이 inactive이고, 액티브 로인 줄에서 inactive는 HIGH입니다. 등은 꺼진 채로 시작합니다. 17번은 원래 LOW였으므로 바뀐 것이 없습니다
- **`light`는 배선을 모른다**: 두 줄에 같은 값을 썼는데 핀은 반대로 움직였습니다. 배선을 바꾸게 되면 설정 한 줄만 고칩니다
- **읽은 값도 논리값이다**: 핀은 HIGH와 LOW로 갈렸지만 둘 다 1로 읽혔습니다
- **`gpioinfo`에 보인다**: 22번의 줄에 `active-low`가 붙습니다

## LOW에서 일하는 것들

- **전류를 받아들이는 배선의 LED**: 예제의 22번입니다
- **릴레이 모듈**: 입력이 LOW일 때 붙는 것이 많습니다([「릴레이와 트랜지스터 몰기」](#/read/libgpiod/out-relay))
- **칩의 리셋과 선택 신호**: 이름 끝에 `_N`이 붙거나 이름 위에 줄이 그어진 신호들입니다. 4의 줄 이름 `SPI_CE0_N`이 그 꼴입니다
- **GND로 가는 단추**: 풀업을 건 입력에서 눌림은 LOW입니다
- **커널도 이렇게 쓴다**: libgpiod 문서에 실린 4의 예에서 전원 LED를 맡은 `PWR_LED_OFF` 줄은 커널이 액티브 로로 쥐고 있습니다

## 조심할 곳

- **값을 손으로 뒤집지 않는다**: 액티브 로를 적지 않고 코드에서 `!on`을 쓰기 시작하면 쓰는 곳마다 뒤집어야 하고, 한 곳을 빠뜨리면 그 자리만 거꾸로 돕니다. 첫 값도 그 가운데 하나라서, 잊으면 요청하는 순간 켜집니다
- **프로그램이 쥐기 전의 핀**: 보드가 켜지는 동안 핀은 입력이고 기본 풀에 끌려 있습니다. 기본이 풀다운인 핀에 LOW에서 일하는 것을 달면 그동안 켜질 수 있습니다. 기본이 풀업인 핀을 고르거나 바깥에 풀업 저항을 답니다([「풀업과 풀다운」](#/read/libgpiod/gp-pull))
- **에지의 이름도 뒤집힌다**: 액티브 로인 입력에서 올라가는 에지는 전압이 내려가는 순간입니다([「에지 감지 켜기」](#/read/libgpiod/ed-request))
- **`pinctrl`은 전압을 보여 준다**: 켜져 있는데 `op dl`로 나오면 고장이 아니라 액티브 로인 것입니다([「pinctrl」](#/read/libgpiod/tl-pinctrl))

<Note>
예제는 이 책의 흉내 칩에서 돌린 것이고, `핀|`으로 시작하는 줄은 흉내 칩이 핀의 전압이 바뀔 때 적은 것입니다. 논리값과 전압의 대응은 리눅스 커널 문서의 값 쓰기와 값 읽기 대목에 적힌 대로입니다. 진짜 libgpiod 2.2.4의 머리 파일로 x86-64와 aarch64에서 컴파일되는지 따로 확인했고, 보드와 LED로 돌려 보지는 못했습니다.
</Note>

## 정리

- 액티브 로인 줄에서는 active가 LOW, inactive가 HIGH다. 쓰는 값과 읽는 값은 언제나 논리값이다
- 전압의 방향은 `gpiod_line_settings_set_active_low` 한 곳에만 적고, 코드에서 값을 손으로 뒤집지 않는다
- 요청의 첫 값도 논리값이다. 액티브 로인 줄을 inactive로 요청하면 핀은 HIGH로 시작한다
