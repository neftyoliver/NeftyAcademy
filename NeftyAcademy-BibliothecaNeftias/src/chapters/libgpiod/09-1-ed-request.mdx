값을 읽는 함수는 읽은 순간의 값만 알려 줍니다. [「값 읽기」](#/read/libgpiod/in-read)에서 0.5초마다 읽던 프로그램은 0.1초 동안 켜졌던 신호를 통째로 놓쳤습니다. 에지 감지는 지켜보는 일을 커널에 넘깁니다. 줄의 값이 바뀌는 순간에 커널이 그 시각과 방향을 적어 두고, 프로그램은 자고 있다가 받아 갑니다.

## 에지 감지의 값 넷

| 값 | 뜻 |
| --- | --- |
| `GPIOD_LINE_EDGE_NONE` | 에지를 보지 않는다. 기본값 |
| `GPIOD_LINE_EDGE_RISING` | inactive에서 active로 가는 순간만 본다 |
| `GPIOD_LINE_EDGE_FALLING` | active에서 inactive로 가는 순간만 본다 |
| `GPIOD_LINE_EDGE_BOTH` | 두 방향을 다 본다 |

- **`gpiod_line_settings_set_edge_detection`**: settings에 위의 값 가운데 하나를 적습니다. 나머지는 여느 입력 요청과 같습니다([「gpiod_chip_request_lines」](#/read/libgpiod/rq-request))
- **에지를 켠 줄은 입력이다**: libgpiod는 에지 감지를 적은 줄에 입력 표시를 함께 붙여 커널에 보냅니다. 그래도 방향은 읽는 사람을 위해 적어 둡니다
- **줄마다 따로 정한다**: 한 요청 안에서도 settings를 달리 붙이면 어떤 줄은 올라가는 에지만, 어떤 줄은 둘 다 봅니다([「설정 객체 셋: line_settings, line_config, request_config」](#/read/libgpiod/rq-objects))
- **줄 정보에 보인다**: 프로그램이 도는 동안 다른 터미널의 `gpioinfo`는 이 줄에 `edges=both`를 적습니다([「gpiodetect와 gpioinfo」](#/read/libgpiod/tl-detect))

## 훑어서는 놓쳤던 신호 잡기

아래 예제는 [「값 읽기」](#/read/libgpiod/in-read)의 감지기를 다시 지켜봅니다. 감지기는 그때처럼 한 번은 1.5초 동안, 한 번은 0.1초 동안 HIGH를 냅니다.

```c gpiosim=pir
// 감지기의 출력이 바뀌는 순간을 커널이 잡게 하고, 잡힌 것을 차례로 적는다
#include <gpiod.h>
#include <inttypes.h>
#include <stdio.h>
#include <string.h>

enum { SENSOR = 23 };                        // GPIO 23, 헤더의 핀 16

// 줄 하나를 입력으로 요청하면서 에지 감지를 켠다
static struct gpiod_line_request* request_edges(struct gpiod_chip* chip,
                                                unsigned int offset,
                                                enum gpiod_line_edge edge,
                                                const char* consumer) {
    struct gpiod_line_settings* settings = gpiod_line_settings_new();
    struct gpiod_line_config* config = gpiod_line_config_new();
    struct gpiod_request_config* request_config = gpiod_request_config_new();
    struct gpiod_line_request* request = nullptr;
    if (settings && config && request_config) {
        gpiod_line_settings_set_direction(settings, GPIOD_LINE_DIRECTION_INPUT);
        gpiod_line_settings_set_edge_detection(settings, edge);
        gpiod_line_config_add_line_settings(config, &offset, 1, settings);
        gpiod_request_config_set_consumer(request_config, consumer);
        request = gpiod_chip_request_lines(chip, request_config, config);
    }
    gpiod_request_config_free(request_config);
    gpiod_line_config_free(config);
    gpiod_line_settings_free(settings);
    return request;
}

int main(int argc, char** argv) {
    // 인수가 없으면 두 에지를 다 보고, rising이나 falling을 주면 그쪽만 본다
    enum gpiod_line_edge edge = GPIOD_LINE_EDGE_BOTH;
    if (argc > 1 && strcmp(argv[1], "rising") == 0) edge = GPIOD_LINE_EDGE_RISING;
    if (argc > 1 && strcmp(argv[1], "falling") == 0) edge = GPIOD_LINE_EDGE_FALLING;

    struct gpiod_chip* chip = gpiod_chip_open("/dev/gpiochip0");
    if (!chip) {
        perror("/dev/gpiochip0");
        return 1;
    }
    struct gpiod_line_request* sensor = request_edges(chip, SENSOR, edge, "motion");
    gpiod_chip_close(chip);
    struct gpiod_edge_event_buffer* buffer = gpiod_edge_event_buffer_new(1);
    if (!sensor || !buffer) {
        perror("요청");
        return 1;
    }
    // 에지는 바뀌는 순간만 알려 준다. 지금의 값은 한 번 읽어서 안다
    bool active = gpiod_line_request_get_value(sensor, SENSOR) ==
                  GPIOD_LINE_VALUE_ACTIVE;
    printf("처음 값은 %s\n", active ? "active" : "inactive");

    // 이벤트가 올 때까지 잔다. 3초 동안 아무 일이 없으면 끝낸다
    int events = 0;
    while (gpiod_line_request_wait_edge_events(sensor, 3'000'000'000) == 1) {
        if (gpiod_line_request_read_edge_events(sensor, buffer, 1) != 1) {
            perror("읽기");
            break;
        }
        struct gpiod_edge_event* event =
            gpiod_edge_event_buffer_get_event(buffer, 0);
        uint64_t ns = gpiod_edge_event_get_timestamp_ns(event);
        bool rising =
            gpiod_edge_event_get_event_type(event) == GPIOD_EDGE_EVENT_RISING_EDGE;
        printf("%" PRIu64 ".%03" PRIu64 "초  %s\n", ns / 1'000'000'000,
               ns / 1'000'000 % 1000, rising ? "rising" : "falling");
        ++events;
    }
    printf("받은 이벤트 %d개\n", events);
    gpiod_edge_event_buffer_free(buffer);
    gpiod_line_request_release(sensor);
}
```

```text
처음 값은 inactive
핀|   1.200s  감지기 → HIGH
5001.200초  rising
핀|   2.700s  감지기 → LOW
5002.700초  falling
핀|   4.100s  감지기 → HIGH
5004.100초  rising
핀|   4.200s  감지기 → LOW
5004.200초  falling
받은 이벤트 4개
```

- **넷을 모두 잡았다**: 0.1초짜리 신호의 시작과 끝이 둘 다 찍혔습니다. 프로그램이 한 일은 자다가 깨어 받아 적은 것뿐입니다
- **시각은 커널이 찍는다**: 찍힌 숫자는 프로그램이 읽은 때가 아니라 커널이 에지를 알아챈 때입니다. 보드가 켜진 뒤로 흐른 시간이고, 흉내 칩은 켠 지 5000초 된 보드로 꾸며져 있습니다([「타임스탬프와 시계 고르기」](#/read/libgpiod/ed-timestamp))
- **처음 값은 따로 읽는다**: 에지는 바뀌는 순간만 알려 줍니다. 요청할 때 이미 active였는지는 한 번 읽어야 압니다
- **기다리는 함수와 읽는 함수**: `gpiod_line_request_wait_edge_events`는 이벤트가 올 때까지 프로그램을 재우고, `gpiod_line_request_read_edge_events`가 꺼내 옵니다. 둘의 규칙은 다음 쪽에서 봅니다([「기다리고 읽기」](#/read/libgpiod/ed-wait))

같은 프로그램에 `rising`을 주어 돌리면 올라가는 에지 둘만 옵니다. 핀은 네 번 바뀌었지만 프로그램은 두 번만 깼습니다.

```text
처음 값은 inactive
핀|   1.200s  감지기 → HIGH
5001.200초  rising
핀|   2.700s  감지기 → LOW
핀|   4.100s  감지기 → HIGH
5004.100초  rising
핀|   4.200s  감지기 → LOW
받은 이벤트 2개
```

- **필요한 쪽만 켠다**: 누가 지나갔다는 사실만 쓰려면 올라가는 에지로 충분합니다. 얼마나 머물렀는지를 재려면 둘 다 봐야 합니다

## 에지는 논리값으로 따진다

- **올라가는 에지는 active가 되는 순간이다**: 방향은 전압이 아니라 논리값의 변화로 정해집니다. 액티브 로로 요청한 줄에서 올라가는 에지는 전압이 내려가는 순간입니다([「액티브 로」](#/read/libgpiod/out-active-low))
- **단추에서는**: GND로 가는 단추를 풀업과 액티브 로로 요청하면 누르는 순간이 올라가는 에지, 떼는 순간이 내려가는 에지입니다. 이벤트를 받는 코드는 회로가 어느 쪽으로 이어졌는지 몰라도 됩니다([「단추 읽기」](#/read/libgpiod/in-button))
- **접점은 에지를 여러 번 낸다**: 떨리는 접점은 한 번 누를 때 에지를 여러 개 만듭니다. 요청에 거르는 기간을 함께 적습니다([「디바운스」](#/read/libgpiod/ed-debounce))

## 켤 수 없는 줄과 한계

- **인터럽트를 못 내는 줄**: 에지 감지는 그 줄이 인터럽트를 낼 수 있어야 합니다. 그렇지 못한 줄에 켜면 요청이 `ENXIO`로 거절되고, 그런 줄은 훑어 읽는 수밖에 없습니다
- **출력과 함께는 안 된다**: 방향을 출력으로 적고 에지를 켜면 입력과 출력의 표시가 함께 가서 `EINVAL`입니다
- **두 방향을 다 볼 때의 방향**: 커널은 인터럽트를 처리하는 순간에 줄의 값을 읽어 방향을 정합니다. 그 사이에 값이 다시 바뀔 만큼 짧은 펄스에서는 방향이 실제와 다르게 적힐 수 있습니다
- **에지마다 인터럽트 하나다**: 에지가 올 때마다 커널이 인터럽트를 처리하고 프로그램을 깨웁니다. 신호가 빠를수록 그 일이 CPU를 더 차지하고, 받아 가는 것이 밀리면 버퍼가 넘쳐 이벤트를 잃습니다([「이벤트 버퍼」](#/read/libgpiod/ed-buffer))
- **빠른 신호는 커널의 몫이다**: 통신 선이나 빠른 펄스 열을 에지 이벤트로 풀려고 하지 않습니다([「커널 드라이버에 맡길 것들」](#/read/libgpiod/tm-kernel))

<Note>
예제는 이 책의 흉내 칩에서 돌린 것이고, 감지기의 출력은 「값 읽기」 때와 같은 대본입니다. `핀|`으로 시작하는 줄은 흉내 칩이 핀의 전압이 바뀔 때 적은 것입니다. 흉내 칩은 에지의 방향을 실제 변화에서 바로 알지만, 진짜 커널은 두 방향을 다 볼 때 처리하는 순간의 값을 읽습니다. 이것과 `ENXIO`, `EINVAL`은 리눅스 커널의 문서와 소스에서 읽은 것이고 보드에서 일으켜 보지는 못했습니다. 진짜 libgpiod 2.2.4의 머리 파일로 x86-64와 aarch64에서 컴파일되는지 따로 확인했습니다.
</Note>

## 정리

- 에지 감지는 `gpiod_line_settings_set_edge_detection`으로 켠다. 올라가는 쪽, 내려가는 쪽, 둘 다 가운데 고른다
- 커널이 바뀌는 순간의 시각과 방향을 적어 두고, 프로그램은 자다가 깨어 받아 간다
- 에지의 방향은 논리값으로 따진다. 인터럽트를 못 내는 줄에서는 켤 수 없다
