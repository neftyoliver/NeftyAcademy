핀 하나가 낼 수 있는 것은 3.3V에 16mA까지입니다. LED 하나는 켜지만 릴레이의 코일, 모터, 부저, LED 띠는 그보다 큰 전류나 높은 전압을 바랍니다. 그래서 사이에 스위치를 둡니다. 핀은 스위치를 움직이기만 하고, 부하가 쓰는 전류는 부하의 전원에서 따로 옵니다. 그 스위치가 트랜지스터이고, 릴레이는 트랜지스터가 움직이는 또 하나의 스위치입니다.

## 트랜지스터로 릴레이 켜기

```text
5V -------+----------------+
          |                |
     [릴레이 코일]     [다이오드]   띠가 있는 쪽이 5V
          |                |
          +-------+--------+
                  |
               컬렉터
GPIO 23 --[680Ω]-- 베이스     NPN 트랜지스터
               이미터
                  |
GND --------------+
```

- **핀은 베이스에 작은 전류만 넣는다**: 핀이 HIGH가 되면 저항을 거쳐 베이스로 몇 mA가 흐르고, 그것이 컬렉터와 이미터 사이를 이어 줍니다. 코일의 70mA는 5V에서 와서 트랜지스터를 지나 GND로 갑니다
- **GND는 하나로 잇는다**: 부하의 전원이 따로 있어도 그 GND와 보드의 GND를 이어야 핀의 신호가 뜻을 가집니다
- **다이오드를 빠뜨리지 않는다**: 코일은 전류가 끊기는 순간 높은 전압을 튀깁니다. 코일과 나란히, 띠가 있는 쪽을 전원 쪽으로 단 다이오드가 그것을 받아 줍니다. 없으면 트랜지스터가 상하거나 보드가 멋대로 다시 켜질 수 있습니다
- **코일의 전원은 3.3V 핀이 아니다**: 5V 핀이나 따로 둔 전원에서 가져옵니다
- **접점 쪽이 가정용 전기라면**: 감전과 불의 위험이 있습니다. 절연된 모듈과 규격에 맞는 선을 쓰고, 자신이 없으면 하지 않습니다

## 베이스 저항 고르기

| 부하의 전류 | 베이스에 넣을 전류 | 2.6V를 나눈 값 | 고르는 저항 |
| --- | --- | --- | --- |
| 20mA | 1mA | 2.6kΩ | 2.2kΩ |
| 70mA | 3.5mA | 743Ω | 680Ω |
| 200mA | 10mA | 260Ω | 220Ω |

- **부하 전류의 20분의 1을 넣는다**: 트랜지스터를 확실히 켜 두려고 넉넉히 잡는 어림입니다
- **2.6V는 3.3V에서 0.7V를 뺀 것이다**: 베이스와 이미터 사이에 0.7V쯤이 걸리므로 저항에 남는 전압이 그만큼입니다
- **고른 값은 계산한 값보다 조금 작게**: 파는 값 가운데 바로 아래 것을 고릅니다. 680Ω이면 3.8mA가 흘러 핀의 한도에 한참 못 미칩니다
- **셋째 줄은 핀에 부담이다**: 220Ω이면 핀에서 11.8mA가 나갑니다. 부하가 이만큼 커지면 MOSFET으로 넘어갑니다

## MOSFET과 릴레이 모듈

- **MOSFET은 전압으로 켠다**: 게이트로는 전류가 거의 흐르지 않아서 핀에 부담이 없습니다. 큰 전류의 부하와 빠르게 켜고 끄는 부하에 씁니다
- **3.3V에서 다 켜지는 것을 고른다**: 문턱 전압이 낮다는 말만으로는 모자랍니다. 데이터시트가 게이트 2.5V나 3.3V에서의 켜진 저항을 적어 둔 것이어야 합니다
- **게이트에 풀다운을 단다**: 핀이 입력으로 떠 있는 동안 게이트가 멋대로 켜지지 않게 10kΩ쯤으로 GND에 묶어 둡니다
- **릴레이 모듈**: 트랜지스터와 다이오드가 판에 올라가 있어서 전원, GND, 신호 세 선만 잇습니다. 신호가 LOW일 때 붙는 것이 많으므로 그 줄은 액티브 로로 요청합니다([「액티브 로」](#/read/libgpiod/out-active-low))
- **5V용 모듈과 3.3V 신호**: LOW에서 붙는 5V용 모듈 가운데에는 3.3V의 HIGH로는 다 떨어지지 않는 것이 있습니다. 3.3V 신호를 받는다고 적힌 것을 고릅니다

## 릴레이를 다루는 코드

아래 예제는 히터의 릴레이를 켜고 끕니다. 온도는 센서 대신 배열에 넣어 둔 값을 1초에 하나씩 꺼내 씁니다.

```c gpiosim
// 히터의 릴레이를 켜고 끈다. 온도에 폭을 두고, 한 번 바꾸면 얼마 동안은 그대로 둔다
#include <gpiod.h>
#include <stdio.h>
#include <threads.h>

enum {
    RELAY = 23,                              // GPIO 23, 핀 16. 트랜지스터로 간다
    ON_BELOW = 195,                          // 19.5도 아래면 켠다(0.1도 단위)
    OFF_ABOVE = 205,                         // 20.5도 위면 끈다
    MIN_HOLD_S = 3,                          // 바꾼 뒤 이만큼은 다시 바꾸지 않는다
};

// 줄 하나를 출력으로 요청한다. 첫 값은 inactive, 곧 릴레이가 떨어진 상태다
static struct gpiod_line_request* request_relay(struct gpiod_chip* chip) {
    struct gpiod_line_settings* settings = gpiod_line_settings_new();
    struct gpiod_line_config* config = gpiod_line_config_new();
    struct gpiod_request_config* request_config = gpiod_request_config_new();
    struct gpiod_line_request* request = nullptr;
    unsigned int offset = RELAY;
    if (settings && config && request_config) {
        gpiod_line_settings_set_direction(settings, GPIOD_LINE_DIRECTION_OUTPUT);
        gpiod_line_settings_set_output_value(settings, GPIOD_LINE_VALUE_INACTIVE);
        gpiod_line_config_add_line_settings(config, &offset, 1, settings);
        gpiod_request_config_set_consumer(request_config, "heater-relay");
        request = gpiod_chip_request_lines(chip, request_config, config);
    }
    gpiod_request_config_free(request_config);
    gpiod_line_config_free(config);
    gpiod_line_settings_free(settings);
    return request;
}

int main(void) {
    struct gpiod_chip* chip = gpiod_chip_open("/dev/gpiochip0");
    if (!chip) {
        perror("/dev/gpiochip0");
        return 1;
    }
    struct gpiod_line_request* relay = request_relay(chip);
    gpiod_chip_close(chip);
    if (!relay) {
        perror("요청");
        return 1;
    }
    // 센서 대신, 1초마다 잰 온도라고 치는 값들(0.1도 단위)
    const int temps[] = {192, 198, 207, 209, 202, 194, 193, 199, 206, 208};
    bool on = false;
    int held = MIN_HOLD_S;                   // 마지막으로 바꾼 뒤 흐른 초
    for (size_t i = 0; i < sizeof temps / sizeof temps[0]; ++i, ++held) {
        int t = temps[i];
        bool want = on ? t <= OFF_ABOVE : t < ON_BELOW;
        const char* note = "";
        if (want != on && held < MIN_HOLD_S) {
            note = "  바꿀 때가 됐지만 기다린다";
        } else if (want != on) {
            on = want;
            held = 0;
            note = on ? "  켠다" : "  끈다";
            enum gpiod_line_value value =
                on ? GPIOD_LINE_VALUE_ACTIVE : GPIOD_LINE_VALUE_INACTIVE;
            gpiod_line_request_set_value(relay, RELAY, value);
        }
        printf("%zu초  %d.%d도%s\n", i, t / 10, t % 10, note);
        thrd_sleep(&(struct timespec){.tv_sec = 1}, nullptr);
    }
    gpiod_line_request_set_value(relay, RELAY, GPIOD_LINE_VALUE_INACTIVE);
    gpiod_line_request_release(relay);       // 끄고 나서 놓는다
}
```

```text
핀|   0.000s  GPIO 23 → HIGH
0초  19.2도  켠다
1초  19.8도
2초  20.7도  바꿀 때가 됐지만 기다린다
핀|   3.000s  GPIO 23 → LOW
3초  20.9도  끈다
4초  20.2도
5초  19.4도  바꿀 때가 됐지만 기다린다
핀|   6.000s  GPIO 23 → HIGH
6초  19.3도  켠다
7초  19.9도
8초  20.6도  바꿀 때가 됐지만 기다린다
핀|   9.000s  GPIO 23 → LOW
9초  20.8도  끈다
```

- **켜는 온도와 끄는 온도를 벌린다**: 19.5도 아래에서 켜고 20.5도 위에서 끕니다. 한 온도를 기준으로 삼으면 그 언저리에서 릴레이가 쉴 새 없이 붙었다 떨어집니다
- **바꾼 뒤에는 얼마 동안 그대로 둔다**: 2초, 5초, 8초에는 바꿀 때가 됐는데도 3초가 차기를 기다렸습니다. 릴레이의 접점은 붙고 떨어질 때마다 닳고, 부하에 따라서는 켜자마자 끄면 상하는 것도 있습니다
- **첫 값은 떨어진 상태다**: 요청과 함께 inactive가 나갑니다. 요청하는 순간 릴레이가 찰칵 붙는 일이 없습니다([「gpiod_chip_request_lines」](#/read/libgpiod/rq-request))
- **끝낼 때는 끄고 놓는다**: 라즈베리파이에서는 놓은 핀이 마지막 값을 그대로 냅니다. 켜 둔 채 끝나면 히터는 켜진 채입니다([「놓아주기」](#/read/libgpiod/rq-release))
- **프로그램이 죽어도 꺼지게**: 베이스나 게이트에 단 풀다운은 보드가 켜지는 동안과 핀이 입력으로 돌아갔을 때 부하를 꺼 둡니다. 켜진 채로 남으면 위험한 것은 온도 퓨즈처럼 프로그램과 상관없이 끊는 장치를 함께 둡니다
- **빠르게 켜고 끄지 않는다**: 릴레이는 붙고 떨어지는 데 시간이 걸리는 기계입니다. 밝기나 속도를 조절하려고 빠르게 깜빡일 부하에는 MOSFET을 쓰고, 그 신호는 「PWM」에서 다룹니다

<Note>
예제는 이 책의 흉내 칩에서 돌린 것이고, `핀|`으로 시작하는 줄은 흉내 칩이 핀의 전압이 바뀔 때 적은 것입니다. 회로는 만들어 보지 못했습니다. 저항의 값은 표에 적은 어림으로 계산한 것이고, 코일의 전류 70mA는 흔한 5V 소형 릴레이를 두고 잡은 값입니다. 쓰려는 릴레이와 트랜지스터의 데이터시트에서 코일의 전류와 견디는 전류를 확인하고 정합니다. 진짜 libgpiod 2.2.4의 머리 파일로 x86-64와 aarch64에서 컴파일되는지 따로 확인했습니다.
</Note>

## 정리

- 핀은 트랜지스터를 움직이고 부하의 전류는 부하의 전원에서 온다. 코일에는 다이오드를 나란히 달고 GND는 하나로 잇는다
- 베이스 저항은 부하 전류의 20분의 1이 흐르게 잡고, 큰 부하와 빠른 부하에는 3.3V에서 다 켜지는 MOSFET을 쓴다
- 코드는 켜고 끄는 문턱을 벌리고, 바꾼 뒤 한동안 그대로 두고, 떨어진 상태로 시작해서 끄고 끝낸다
