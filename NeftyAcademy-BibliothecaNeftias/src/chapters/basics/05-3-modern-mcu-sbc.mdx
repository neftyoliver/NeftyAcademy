전자 공작이나 IoT 장치를 만들 때 고르는 두뇌는 크게 둘입니다. 아두이노나 ESP32 같은 **마이크로컨트롤러**, 그리고 라즈베리파이 같은 **싱글 보드 컴퓨터**(SBC)입니다. 둘 다 손바닥보다 작고 핀으로 센서와 LED를 잇지만, 속은 전혀 다른 물건입니다. 이 쪽은 그 차이와 고르는 기준을 봅니다.

## 두 갈래

| | 마이크로컨트롤러 | 싱글 보드 컴퓨터 |
| --- | --- | --- |
| 예 | 아두이노 우노, ESP32, 라즈베리파이 피코 | 라즈베리파이 5, 4, 제로 2 W |
| OS | 없다. 내 프로그램 하나만 돈다 | 리눅스 |
| 램 | 수 KB~수백 KB | 수 GB |
| 저장 | 칩 안의 플래시 수십 KB~수 MB | SD 카드, SSD |
| 켜지는 시간 | 순식간 | 수십 초(OS 부팅) |
| 전기 | mW 단위, 건전지로 몇 달도 된다 | 수 W |
| 할 수 있는 일 | 센서 읽기, 모터 돌리기처럼 한 가지 | 화면, 카메라, 웹 서버, 여러 프로그램 |

같은 "라즈베리파이"라는 이름이 붙어도 피코는 마이크로컨트롤러이고, 5와 제로 2 W는 리눅스가 도는 컴퓨터입니다.

## 마이크로컨트롤러

[「마이크로프로세서의 등장」](#/read/basics/history-microprocessor)에서 본 대로 마이크로컨트롤러는 CPU, 메모리, 입출력 회로를 칩 하나에 넣은 것입니다.

| 보드 | 칩, 클럭, 램 | 특징 |
| --- | --- | --- |
| 아두이노 우노 | ATmega328P(8비트), 16MHz, 2KB | 입문용의 대표. 하버드 구조 |
| 라즈베리파이 피코 | RP2040(Cortex-M0+ 2개), 133MHz, 264KB | 싸고 핀 다루기가 유연하다 |
| ESP32 | 32비트 듀얼 코어, 240MHz, 520KB | Wi-Fi와 블루투스가 들어 있다 |

램이 PC의 수백만분의 일입니다. 그래도 센서 값을 읽어 무선으로 보내는 정도는 충분합니다.

OS가 없으므로 전원이 들어오면 칩이 곧바로 내 프로그램의 첫 줄부터 실행하고, 프로그램이 끝나지 않도록 보통 무한 반복으로 짭니다. 다른 프로그램이 끼어들지 않으니 **정해진 시간 안에 반드시 반응**해야 하는 일, 예를 들어 모터를 1밀리초마다 정확히 조절하는 일에 강합니다. 이런 성질을 실시간성이라고 합니다. OS 없이 하드웨어를 직접 다루는 방식은 소형 기기 서가의 「베어메탈」에서 다룹니다.

## 싱글 보드 컴퓨터

라즈베리파이 5는 [「스마트폰과 ARM」](#/read/basics/modern-arm-mobile)에서 본 SoC 하나(브로드컴 BCM2712, 2.4GHz Cortex-A76 코어 4개)에 램(1GB부터 16GB까지 고를 수 있음)을 붙인 작은 컴퓨터입니다. HDMI로 모니터를 잇고 키보드를 꽂으면 리눅스 데스크톱이 뜹니다.

리눅스가 돌기 때문에 PC에서 배운 것이 그대로 통합니다. [「apt와 저장소」](#/read/basics/apt)로 프로그램을 깔고, [「Git 기초」](#/read/basics/git)로 코드를 받고, GCC로 컴파일하고, 파이썬을 씁니다. 카메라로 사진을 찍어 인공지능으로 분석하고 결과를 웹으로 보여 주는 일처럼, 마이크로컨트롤러로는 버거운 일을 할 수 있습니다.

대신 리눅스는 여러 프로그램을 번갈아 돌리므로, 내 프로그램이 언제 CPU를 받을지 정확히 약속할 수 없습니다. 보통은 밀리초 단위로 충분히 빠르지만 마이크로초 단위의 정확한 박자가 필요한 일에는 맞지 않습니다. 이 이야기는 [「프로세스와 메모리 관리」](#/read/basics/os-process-memory)에서 이어집니다.

## 같은 LED, 다른 코드

LED를 1초마다 깜빡이는 코드를 견주면 차이가 잘 보입니다. 아래 두 코드는 생김새를 보여 주기 위한 것이고, 이 책의 검사 기계에는 보드가 없어서 돌려 보지 못했습니다.

아두이노(C++ 문법 위에 아두이노가 준비한 함수):

```cpp nocheck
void setup() {
    pinMode(13, OUTPUT);           // 13번 핀을 출력으로
}

void loop() {                      // 끝없이 되풀이된다
    digitalWrite(13, HIGH);
    delay(500);
    digitalWrite(13, LOW);
    delay(500);
}
```

라즈베리파이(리눅스의 libgpiod 2.x에 든 명령 도구. 라즈베리파이 OS 트릭시 기준이고, 1.6이 든 북웜에서는 옵션이 다릅니다):

```sh
# GPIO17 핀을 0.5초마다 뒤집어 1초 주기로 깜빡인다. Ctrl+C로 멈춘다
gpioset --toggle 500ms GPIO17=1
```

아두이노는 핀 번호를 칩에 바로 쓰고, 프로그램이 칩 전체를 차지합니다. 라즈베리파이에서는 리눅스 커널이 GPIO를 맡고 있어서 내 프로그램은 커널에게 "이 핀을 켜 달라"고 부탁합니다. C로 이 부탁을 하는 법은 [「GPIO로 신호 주고받기」](#/read/c-mid/gpio)와 소형 기기 서가의 「libgpiod」에서 배웁니다.

<Note kind="warn">
라즈베리파이의 GPIO 핀은 3.3V입니다. 5V 센서나 5V로 동작하는 아두이노 우노의 핀을 바로 이으면 라즈베리파이가 망가질 수 있습니다. 전압이 다른 장치끼리는 전압 변환기를 거쳐야 합니다. 전기 이야기는 「전자공학 입문」에서 다룹니다.
</Note>

## 무엇을 고를까

| 하고 싶은 일 | 알맞은 쪽 |
| --- | --- |
| 건전지로 몇 달 버티는 센서 | 마이크로컨트롤러 |
| 모터, 서보를 정확한 박자로 | 마이크로컨트롤러 |
| 화면, 카메라, 웹 서버 | 싱글 보드 컴퓨터 |
| 파이썬과 리눅스 도구를 그대로 | 싱글 보드 컴퓨터 |

실제 제품은 둘을 함께 쓰는 경우가 많습니다. 라즈베리파이가 화면과 네트워크를 맡고, 박자가 중요한 모터 제어는 옆에 붙인 마이크로컨트롤러에 맡겨 둘이 [UART나 I2C](#/read/basics/arch-bus-io)로 이야기합니다.

## 정리

- 마이크로컨트롤러는 OS 없이 프로그램 하나만 돌리는 칩으로, 램은 KB 단위지만 전기를 적게 쓰고 박자를 정확히 지킨다
- 라즈베리파이 같은 싱글 보드 컴퓨터는 리눅스가 도는 작은 컴퓨터라 PC에서 배운 도구가 그대로 통하지만, 정확한 박자는 약속하지 못한다
- 전기를 아끼거나 정확한 박자가 필요하면 마이크로컨트롤러, 화면과 카메라, 네트워크가 필요하면 싱글 보드 컴퓨터를 고르고, 둘을 함께 쓰기도 한다
