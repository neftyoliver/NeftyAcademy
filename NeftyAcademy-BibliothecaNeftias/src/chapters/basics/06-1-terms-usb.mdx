USB 메모리, USB 충전기, USB-C 케이블처럼 "USB"는 어디에나 붙습니다. 그런데 같은 USB-C 케이블로 어떤 노트북은 충전되고 어떤 것은 안 되고, 어떤 케이블로는 모니터가 켜지는데 다른 케이블로는 안 켜집니다. 이 쪽은 USB라는 이름 안에 섞여 있는 서로 다른 것들을 떼어 봅니다.

## USB는 무엇의 이름인가

USB(Universal Serial Bus)는 **장치를 컴퓨터에 잇는 통신 규격**입니다. 1996년에 처음 나왔고, 그전에는 키보드, 마우스, 프린터, 모뎀이 저마다 다른 단자를 썼습니다. 이름 그대로 "하나로 다 되는(universal) 직렬 버스"를 만들려던 것입니다. 버스가 무엇인지는 [「버스와 입출력」](#/read/basics/arch-bus-io)에서 봤습니다.

USB라는 말에는 적어도 세 가지가 섞여 있습니다.

| 층 | 무엇 | 예 |
| --- | --- | --- |
| 데이터 속도 | 1초에 몇 비트를 보내는가 | 480Mbps, 5Gbps, 40Gbps |
| 단자 모양 | 꽂는 부분의 생김새 | Type-A, Type-B, Type-C |
| 전원 | 몇 와트까지 보내는가 | 2.5W부터 240W까지 |

이 셋은 서로 묶여 있지 않습니다. Type-C 단자인데 속도는 480Mbps인 기기도, Type-A 단자인데 10Gbps인 기기도 있습니다. 헷갈림은 대부분 여기서 나옵니다.

## 속도와 버전 이름

| 처음 나온 이름 | 나중에 바뀐 이름 | 속도 |
| --- | --- | --- |
| USB 1.1 | | 12Mbps |
| USB 2.0 | | 480Mbps |
| USB 3.0 | USB 3.1 Gen 1 → USB 3.2 Gen 1 | 5Gbps |
| USB 3.1 | USB 3.1 Gen 2 → USB 3.2 Gen 2 | 10Gbps |
| USB 3.2 Gen 2x2 | | 20Gbps |
| USB4 (버전 1) | | 40Gbps |
| USB4 버전 2 | | 80Gbps |

표의 가운데 칸이 문제입니다. 규격을 정하는 USB-IF가 새 판을 낼 때마다 옛 속도까지 새 판의 이름 아래로 다시 묶어서, 5Gbps짜리가 "USB 3.0", "USB 3.1 Gen 1", "USB 3.2 Gen 1"이라는 세 이름을 갖게 됐습니다. 그래서 상자에 "USB 3.2"라고만 적혀 있으면 5Gbps인지 20Gbps인지 알 수 없습니다.

USB-IF는 이제 소비자에게 버전 대신 **속도로** 알리라고 권합니다. "USB 5Gbps", "USB 10Gbps", "USB 40Gbps"처럼 적고, 포장의 로고에도 속도를 넣습니다. 물건을 살 때는 버전 이름 말고 Gbps 숫자를 보면 됩니다.

<Note>
"5Gbps"는 비트 단위입니다. 바이트로 바꾸려면 8로 나누고, 신호를 실어 보내는 데 드는 몫을 빼야 해서, 5Gbps USB 메모리가 실제로 내는 속도는 잘해야 1초에 400~450MB쯤입니다. 비트와 바이트는 [「비트와 바이트, GB와 GiB」](#/read/basics/terms-bits-bytes)에서 따로 봅니다.
</Note>

## 단자: Type-A, B, C

| 모양 | 생김새 | 흔한 곳 |
| --- | --- | --- |
| Type-A | 납작한 직사각형. 한쪽으로만 꽂힌다 | PC와 충전기의 옛 포트, USB 메모리 |
| Type-B, 마이크로 B | 사다리꼴, 작은 사다리꼴 | 프린터, 옛 안드로이드 폰, 아두이노 우노 |
| Type-C | 둥근 타원. 위아래 구분 없이 꽂힌다 | 요즘 노트북, 폰, 라즈베리파이 4와 5의 전원 |

Type-C는 단자 모양의 이름일 뿐입니다. 그 안으로 USB 2.0 신호만 다닐 수도, USB4 신호가 다닐 수도 있습니다. 게다가 Type-C 케이블로는 USB가 아닌 신호(디스플레이포트, 썬더볼트)도 보낼 수 있어서, 같은 모양의 포트라도 화면을 낼 수 있는지는 기기마다 다릅니다.

## 전원

USB는 처음부터 장치에 전기도 보냈습니다. 마우스나 USB 메모리는 그 전기로 움직입니다.

| 규격 | 최대 전력 |
| --- | --- |
| USB 2.0 포트 | 5V × 0.5A = 2.5W |
| USB 3.x 포트 | 5V × 0.9A = 4.5W |
| USB Type-C 전류 규격 | 5V × 3A = 15W |
| USB PD(전원 공급 규격) | 최대 100W, 3.1판부터 최대 240W |

노트북을 충전하는 높은 전력은 USB PD라는 규격으로 보냅니다. 충전기와 기기가 케이블로 먼저 대화해서 "20V로 3A까지 줄 수 있다", "그럼 그렇게 달라"고 정한 뒤에야 높은 전압을 보냅니다. 한쪽이 PD를 모르면 안전한 5V로 머무릅니다. 노트북이 어떤 충전기로는 느리게 충전되거나 아예 안 되는 까닭입니다. 케이블도 3A를 넘는 전류를 보내려면 그것을 알리는 작은 칩이 든 케이블이어야 합니다.

<Note kind="warn">
라즈베리파이 5는 5V 5A(25W)를 보낼 수 있는 전원을 권장합니다. 일반 폰 충전기로 켜면 전원이 모자라다는 경고를 띄우고 USB 포트로 보내는 전류를 줄입니다. 전원이 모자라면 원인을 알기 어려운 오동작이 생기므로, 보드에 맞는 전원부터 확인하는 것이 좋습니다.
</Note>

## 장치가 자기를 소개하는 법

USB 장치를 꽂으면 컴퓨터는 먼저 "너는 누구냐"고 묻습니다. 장치는 자기의 제조사 번호(VID)와 제품 번호(PID), 그리고 **장치 종류**(클래스)를 알려 줍니다. 키보드와 마우스는 HID, USB 메모리는 대용량 저장 장치, 웹캠은 비디오 클래스입니다. OS는 클래스마다 공통 드라이버를 갖고 있어서, 대부분의 장치는 드라이버를 따로 깔지 않아도 꽂자마자 동작합니다.

리눅스에서는 `lsusb`로 꽂힌 장치의 목록과 VID:PID를 볼 수 있습니다(이 책의 검사 기계는 가상 기계라 USB 장치가 없습니다). 직접 USB 장치와 이야기하는 프로그램은 [「USB로 신호 주고받기」](#/read/c-mid/usb)와 소형 기기 서가의 「libusb」에서 만들어 봅니다. 장치와 OS 사이를 잇는 드라이버는 [「장치 드라이버」](#/read/basics/os-drivers)에서 이어집니다.

## 정리

- USB는 통신 규격의 이름이고, 그 안에 속도, 단자 모양, 전원이라는 서로 묶이지 않은 세 가지가 섞여 있다
- 버전 이름이 여러 번 바뀌어 헷갈리므로, 살 때는 "USB 3.2" 같은 버전 대신 5Gbps, 10Gbps 같은 속도를 본다
- 높은 전력은 충전기와 기기가 먼저 대화하는 USB PD로 보내고, 장치는 꽂힐 때 클래스를 알려 OS의 공통 드라이버로 동작한다
