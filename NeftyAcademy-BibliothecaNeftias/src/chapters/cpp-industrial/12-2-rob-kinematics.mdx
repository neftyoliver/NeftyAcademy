로봇 팔의 제어기는 관절의 각도를 움직이지만, 사람이 원하는 것은 손끝(공구 끝)의 위치와 방향입니다. 관절 각도에서 손끝의 자세를 계산하는 것이 **정기구학**, 거꾸로 원하는 손끝 자세에서 관절 각도를 찾는 것이 **역기구학**입니다. [「여러 축 맞추기」](#/read/cpp-industrial/mot-multi-axis)의 직선 보간을 로봇 팔에 쓰려면, 경로 위의 점마다 역기구학으로 관절 값을 구해야 합니다.

## 두 관절 팔

평면에서 도는 관절 둘짜리 팔로 핵심을 다 볼 수 있습니다. 링크 길이가 L1, L2이면 손끝은 x = L1 cos q1 + L2 cos(q1 + q2), y = L1 sin q1 + L2 sin(q1 + q2)입니다. 역기구학은 코사인 법칙으로 cos q2 = (x² + y² − L1² − L2²) / (2 L1 L2)를 구하고, 그 각도의 부호에 따라 팔꿈치가 아래인 해와 위인 해가 나옵니다. 손끝 속도와 관절 속도를 잇는 행렬이 **야코비안**이며, 그 역행렬로 원하는 손끝 속도에 필요한 관절 속도를 얻습니다.

```cpp
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <numbers>
#include <optional>

constexpr double L1 = 0.40, L2 = 0.30;            // 링크 길이 (m)
constexpr double kDeg = 180.0 / std::numbers::pi;

struct Joints { double q1, q2; };                  // 관절 각 (rad)
struct Point { double x, y; };

Point forward(Joints j) {
    return {L1 * std::cos(j.q1) + L2 * std::cos(j.q1 + j.q2),
            L1 * std::sin(j.q1) + L2 * std::sin(j.q1 + j.q2)};
}

// elbow = +1이면 팔꿈치가 아래(q2 > 0), -1이면 위(q2 < 0)
std::optional<Joints> inverse(Point p, int elbow) {
    double c2 = (p.x * p.x + p.y * p.y - L1 * L1 - L2 * L2) / (2 * L1 * L2);
    if (c2 < -1 || c2 > 1) return std::nullopt;   // 팔이 닿지 않는다
    double q2 = elbow * std::acos(c2);
    double q1 = std::atan2(p.y, p.x) -
                std::atan2(L2 * std::sin(q2), L1 + L2 * std::cos(q2));
    return Joints{q1, q2};
}

// 손끝을 (vx, vy)로 움직이려면 필요한 관절 속도: 야코비안의 역
Joints joint_speed(Joints j, double vx, double vy) {
    double s1 = std::sin(j.q1), c1 = std::cos(j.q1);
    double s12 = std::sin(j.q1 + j.q2), c12 = std::cos(j.q1 + j.q2);
    double a = -L1 * s1 - L2 * s12, b = -L2 * s12;
    double c = L1 * c1 + L2 * c12, d = L2 * c12;
    double det = a * d - b * c;                    // = L1 * L2 * sin(q2)
    return {(d * vx - b * vy) / det, (-c * vx + a * vy) / det};
}

int main() {
    Joints q{30 / kDeg, 45 / kDeg};
    Point p = forward(q);
    std::printf("정기구학: q1=30도 q2=45도 -> (%.4f, %.4f) m\n", p.x, p.y);

    for (int elbow : {+1, -1}) {
        Joints s = *inverse(p, elbow);
        Point back = forward(s);
        bool exact = std::hypot(back.x - p.x, back.y - p.y) < 1e-12;
        std::printf("역기구학(팔꿈치 %s): q1=%6.2f도 q2=%6.2f도, 되돌리면 %s\n",
                    elbow > 0 ? "아래" : "위", s.q1 * kDeg, s.q2 * kDeg,
                    exact ? "같은 점" : "다른 점");
    }
    bool reach = inverse({0.80, 0.0}, +1).has_value();
    std::printf("(0.8000, 0.0000): %s\n\n", reach ? "닿음" : "닿지 않음");

    const double v = 0.10, limit = 180;      // 손끝 0.1 m/s, 관절 한계 180도/s
    std::printf("y=0.05 m 직선을 따라 x 방향으로 %.2f m/s\n", v);
    std::printf("    x   거리   q2(도)  관절 속도(도/s)  낼 수 있는 속도\n");
    for (double x : {0.30, 0.50, 0.60, 0.65, 0.68, 0.69, 0.695, 0.698}) {
        Point t{x, 0.05};
        Joints s = *inverse(t, +1);
        Joints w = joint_speed(s, v, 0);
        double fastest = std::max(std::abs(w.q1), std::abs(w.q2)) * kDeg;
        double allowed = v * std::min(1.0, limit / fastest);
        std::printf("%6.3f  %.3f  %7.2f  %15.1f  %9.4f m/s\n", x,
                    std::hypot(x, 0.05), s.q2 * kDeg, fastest, allowed);
    }
}
```

- **해가 둘**: 같은 손끝 위치에 팔꿈치 아래와 위의 두 자세가 있습니다. 실제 로봇은 지금 자세에서 가장 가까운 해를 골라야 경로 도중에 팔이 휙 뒤집히지 않습니다
- **닿지 않는 점**: cos q2가 −1과 1 사이를 벗어나면 해가 없습니다. 이 팔이 닿는 곳은 반지름 0.1 m(L1 − L2)에서 0.7 m(L1 + L2) 사이의 고리이고, 0.8 m 떨어진 점은 닿지 않았습니다
- **특이점**: 팔이 다 펴질수록(q2 → 0) 야코비안의 행렬식 L1·L2·sin q2가 0에 가까워집니다. 손끝을 바깥으로 0.1 m/s로 미는 데 0.3 m에서는 관절이 19도/s면 되었지만, 0.698 m에서는 671도/s가 필요했습니다. 관절 한계 180도/s를 지키려면 그 근처에서 손끝 속도를 0.027 m/s로 줄여야 합니다

특이점은 다 펴진 팔에만 있지 않습니다. 직선 경로가 특이점 근처를 지나면 제어기는 속도를 줄이거나, 경로를 멈추고 알람을 내거나, 관절 공간 경로로 바꿉니다. 그래서 작업 위치를 정할 때부터 자주 쓰는 경로가 특이점에서 떨어져 있게 로봇과 작업물을 배치합니다.

## 6축 로봇

산업용 로봇 팔은 보통 관절이 여섯이라 위치 셋과 방향 셋을 모두 정할 수 있습니다. 링크마다 네 개의 숫자(a, α, d, θ)로 이웃 관절 사이의 관계를 적는 **DH 파라미터**로 팔을 기술하고, 각 관절의 4×4 동차 변환 행렬을 차례로 곱해 정기구학을 계산합니다. 마지막 세 관절의 축이 한 점에서 만나는 구형 손목이면 역기구학을 식으로 풀 수 있으며, 어깨의 좌우, 팔꿈치의 위아래, 손목의 뒤집힘에 따라 한 자세에 해가 최대 8개 나옵니다. 5번 축이 0도가 되어 4번과 6번 축이 한 줄에 놓이는 손목 특이점은 실제 작업에서 가장 자주 만나는 특이점입니다.

구조가 특별해서 식으로 풀 수 없는 팔은 야코비안으로 조금씩 다가가는 수치 역기구학을 쓰고, 특이점 근처에서 관절 속도가 튀지 않도록 감쇠 최소 제곱(damped least squares)을 씁니다. C++에서는 Orocos KDL, TRAC-IK, Pinocchio 같은 라이브러리가 이 계산을 하고, [「ROS 2」](#/read/cpp-industrial/rob-ros2)의 MoveIt 2가 이들을 써서 경로를 계획합니다.

<Note>
실제 로봇에서는 기준 좌표계를 분명히 해야 합니다. 로봇 받침의 좌표계, 공구 끝(TCP)의 위치와 방향, 작업물의 좌표계가 따로 있고, 공구를 바꾸면 TCP 값도 바꿔야 합니다. 관절마다 움직일 수 있는 범위와 최대 속도가 있으므로, 역기구학의 해는 범위 안에 있는지까지 확인한 뒤에 씁니다.
</Note>

## 정리

- 정기구학은 관절 각도에서 손끝 자세를, 역기구학은 손끝 자세에서 관절 각도를 구하며, 역기구학에는 해가 여럿이거나 없을 수 있다
- 야코비안은 관절 속도와 손끝 속도를 잇고, 그 행렬식이 0에 가까운 특이점 근처에서는 같은 손끝 속도에 관절 속도가 치솟으므로 속도를 줄이거나 경로를 피한다
- 6축 로봇은 DH 파라미터와 동차 변환으로 기술하고, 구형 손목이면 역기구학을 식으로 풀어 최대 8개의 해 중 지금 자세에 가까운 것을 고른다
