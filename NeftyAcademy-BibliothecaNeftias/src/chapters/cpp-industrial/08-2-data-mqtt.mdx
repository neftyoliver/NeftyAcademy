[「폴링 설계」](#/read/cpp-industrial/plc-polling)에서는 프로그램이 장비에 끊임없이 물었습니다. **MQTT**는 반대입니다. 장비(또는 장비 옆의 게이트웨이)가 바뀐 값을 **브로커**에 발행하고, 데이터가 필요한 쪽은 브로커에 구독해 둡니다. 서로를 몰라도 되므로 장비가 늘어도 연결이 복잡해지지 않고, 방화벽 안쪽에서 바깥 브로커로 나가는 연결 하나면 되어 공장 데이터를 MES나 클라우드로 보내는 데 널리 쓰입니다(국제 표준 ISO/IEC 20922).

## MQTT의 세 가지 도구

- **주제**(topic): `plant/line1/oven/temp`처럼 빗금으로 나눈 이름입니다. 구독할 때는 `+`(한 단계)와 `#`(그 아래 전부)를 쓸 수 있습니다
- **QoS**: 0은 한 번 보내고 끝, 1은 받을 때까지 다시 보내기(중복 가능), 2는 정확히 한 번입니다. 측정값은 대개 0이나 1로 충분합니다
- **유언**(Last Will): 연결할 때 "내가 갑자기 끊기면 이 주제로 이 메시지를 보내 달라"고 브로커에 맡겨 둡니다. 장비가 정상적으로 연결을 끊지 않고 사라지면 브로커가 대신 알립니다

그런데 MQTT는 주제의 이름 짓는 법도, 메시지 안의 형식도 정하지 않습니다. 회사마다 제멋대로 정하면 다른 회사의 장비와 SCADA가 서로를 이해할 수 없습니다. 이것을 정한 것이 **Sparkplug**입니다(Eclipse 재단, 3.0판은 ISO/IEC 20237).

## Sparkplug B 한 바퀴

Mosquitto 브로커를 같은 기계에 띄우고, 에지 노드(라인 1의 게이트웨이)는 다른 프로세스로 만들어 BIRTH와 DATA를 보낸 뒤 갑자기 죽였습니다. Sparkplug B의 페이로드는 Protocol Buffers인데, 여기서는 필요한 필드만 손으로 인코딩했습니다.

```cpp flags=-lmosquitto
// Sparkplug B: 에지 노드가 BIRTH와 DATA를 보내고, 끊기면 브로커가 DEATH를 보낸다
#include <mosquitto.h>
#include <signal.h>
#include <spawn.h>
#include <sys/wait.h>
#include <unistd.h>
#include <atomic>
#include <cstdint>
#include <cstdio>
#include <cstring>
#include <optional>
#include <string>
#include <vector>

// ---- Sparkplug B 페이로드에 필요한 만큼만 쓴 protobuf 인코더 ----
void varint(std::string& b, uint64_t v) {
    do {
        const uint8_t c = v & 0x7F;
        v >>= 7;
        b += char(c | (v ? 0x80 : 0));
    } while (v);
}
void key(std::string& b, int field, int wire) {
    varint(b, uint64_t(field) << 3 | wire);
}

struct Metric {
    // BIRTH에서만 보내고, 그 뒤로는 별칭만
    std::string name;
    uint64_t alias;
    // Sparkplug 형식: 4 = Int64, 10 = Double
    int type;
    double d = 0;
    int64_t l = 0;
};
std::string encode(std::optional<uint64_t> seq,
                   const std::vector<Metric>& metrics) {
    std::string p;
    for (const Metric& m : metrics) {
        std::string mb;
        if (!m.name.empty()) {                   // 1: name
            key(mb, 1, 2);
            varint(mb, m.name.size());
            mb += m.name;
        }
        key(mb, 2, 0); varint(mb, m.alias);      // 2: alias
        key(mb, 4, 0); varint(mb, m.type);       // 4: datatype
        if (m.type == 10) {                      // 13: double_value(8바이트)
            key(mb, 13, 1);
            mb.append(reinterpret_cast<const char*>(&m.d), 8);
        } else {                                 // 11: long_value
            key(mb, 11, 0);
            varint(mb, uint64_t(m.l));
        }
        key(p, 2, 2); varint(p, mb.size()); p += mb;          // 2: metrics
    }
    if (seq) { key(p, 3, 0); varint(p, *seq); }               // 3: seq
    return p;
}

// ---- 받은 페이로드를 글로 풀기 ----
uint64_t readVarint(const uint8_t*& p) {
    uint64_t v = 0;
    for (int s = 0;; s += 7) {
        v |= uint64_t(*p & 0x7F) << s;
        if (!(*p++ & 0x80)) return v;
    }
}
std::string metricText(const uint8_t* m, const uint8_t* end) {
    std::string name, value;
    uint64_t alias = 0;
    while (m < end) {
        const uint64_t k = readVarint(m);
        const int field = int(k >> 3), wire = int(k & 7);
        if (wire == 2) {                         // 이름
            const uint64_t n = readVarint(m);
            name.assign(reinterpret_cast<const char*>(m), n);
            m += n;
        } else if (wire == 1) {                  // double
            double d;
            std::memcpy(&d, m, 8);
            m += 8;
            char buf[32];
            std::snprintf(buf, sizeof buf, "%.1f", d);
            value = buf;
        } else {
            const uint64_t v = readVarint(m);
            if (field == 2) alias = v;
            if (field == 11) value = std::to_string(int64_t(v));
        }
    }
    return name + "#" + std::to_string(alias) + "=" + value;
}
std::string payloadText(const uint8_t* p, const uint8_t* end) {
    std::string out;
    while (p < end) {
        const uint64_t k = readVarint(p);
        if ((k & 7) == 2) {                      // metrics
            const uint64_t n = readVarint(p);
            out += " [" + metricText(p, p + n) + "]";
            p += n;
        } else if ((k >> 3) == 3) {
            out += " seq=" + std::to_string(readVarint(p));
        } else {
            readVarint(p);
        }
    }
    return out;
}

std::atomic<int> received{0};

int main() {
    const int port = 18830;
    // 같은 기계에 Mosquitto 브로커를 띄운다
    pid_t broker;
    char prog[] = "mosquitto", flag[] = "-p", portArg[] = "18830";
    char* args[] = {prog, flag, portArg, nullptr};
    posix_spawnp(&broker, "mosquitto", nullptr, nullptr, args, environ);
    usleep(300000);

    // 에지 노드: 스레드를 만들기 전에 fork
    pid_t edge = fork();
    if (edge == 0) {
        usleep(500000);                          // 호스트가 구독할 때까지
        mosquitto_lib_init();
        mosquitto* n = mosquitto_new("line1-gw", true, nullptr);
        const std::string death = encode(std::nullopt, {{"bdSeq", 0, 4, 0, 7}});
        mosquitto_will_set(n, "spBv1.0/Plant/NDEATH/Line1", int(death.size()),
                           death.data(), 1, false);   // 끊기면 브로커가 보낼 유언
        mosquitto_connect(n, "127.0.0.1", port, 5);
        const std::string birth = encode(0, {{"bdSeq", 0, 4, 0, 7},
                                             {"Oven/Temp", 1, 10, 180.5},
                                             {"Oven/Count", 2, 4, 0, 1200}});
        mosquitto_publish(n, nullptr, "spBv1.0/Plant/NBIRTH/Line1",
                          int(birth.size()), birth.data(), 1, false);
        const std::string data = encode(1, {{"", 1, 10, 181.2}});   // 바뀐 것만
        mosquitto_publish(n, nullptr, "spBv1.0/Plant/NDATA/Line1", int(data.size()),
                          data.data(), 1, false);
        mosquitto_loop_forever(n, 1000, 1);
        _exit(0);
    }

    // 주 호스트 응용(SCADA, MES 쪽): 모든 Sparkplug 메시지를 구독한다
    mosquitto_lib_init();
    mosquitto* host = mosquitto_new("host", true, nullptr);
    mosquitto_message_callback_set(host, [](mosquitto*, void*,
                                            const mosquitto_message* m) {
        const std::string topic(m->topic);       // spBv1.0/그룹/종류/노드
        const size_t a = topic.find('/', 8) + 1, b = topic.find('/', a);
        const auto* p = static_cast<const uint8_t*>(m->payload);
        const std::string text = payloadText(p, p + m->payloadlen);
        std::printf("%s %s:%s\n", topic.substr(a, b - a).c_str(),
                    topic.substr(b + 1).c_str(), text.c_str());
        ++received;
    });
    mosquitto_connect(host, "127.0.0.1", port, 60);
    mosquitto_subscribe(host, nullptr, "spBv1.0/#", 1);
    mosquitto_loop_start(host);

    while (received < 2) usleep(10000);
    kill(edge, SIGKILL);                         // 전원이 나간 것처럼 갑자기 끊는다
    waitpid(edge, nullptr, 0);
    while (received < 3) usleep(10000);

    mosquitto_disconnect(host);
    mosquitto_loop_stop(host, false);
    mosquitto_destroy(host);
    mosquitto_lib_cleanup();
    kill(broker, SIGTERM);
    waitpid(broker, nullptr, 0);
}
```

```text
NBIRTH Line1: [bdSeq#0=7] [Oven/Temp#1=180.5] [Oven/Count#2=1200] seq=0
NDATA Line1: [#1=181.2] seq=1
NDEATH Line1: [bdSeq#0=7]
```

- **주제 규칙**: `spBv1.0/그룹/메시지 종류/에지 노드[/장치]`입니다. 구독하는 쪽은 주제만 보고 어느 공장, 어느 노드의 무슨 메시지인지 압니다
- **BIRTH**: 노드가 연결하면 먼저 자기가 가진 모든 지표의 이름, 형식, 현재 값, 그리고 **별칭**(#1, #2)을 알립니다. 호스트는 이것으로 노드의 데이터 목록을 만듭니다
- **DATA는 바뀐 것만, 별칭으로**: 그 뒤의 NDATA는 바뀐 지표만, 이름 대신 숫자 별칭으로 보냅니다. 메시지가 작아집니다. `seq`는 0~255를 도는 순번이라 호스트가 빠진 메시지를 알아챌 수 있고, 빠졌으면 다시 BIRTH를 요청합니다
- **DEATH**: 에지 노드는 연결할 때 NDEATH를 유언으로 맡겨 두었고, 프로세스가 죽자 브로커가 그것을 보냈습니다. `bdSeq`(7)가 BIRTH의 것과 같으므로 호스트는 "그 연결이 끊겼다"고 확신하고 그 노드의 모든 태그를 품질 불량으로 바꿉니다. 이것이 폴링 없이도 "값이 오래된 것인지 장비가 죽은 것인지"를 구별하는 방법입니다

<Note>
실제로는 Eclipse Tahu 같은 Sparkplug 라이브러리와 공식 `sparkplug_b.proto`로 생성한 코드를 씁니다. 이 예제를 돌리려면 Mosquitto 브로커와 libmosquitto가 필요합니다. 공장 밖의 브로커로 보낼 때는 TLS와 클라이언트 인증서를 쓰고, 명령(NCMD, DCMD)을 받아 장비를 움직이게 하는 경우에는 그 권한을 따로 엄격하게 관리합니다([「보안」](#/read/cpp-industrial/depl-security)).
</Note>

## 정리

- MQTT는 장비가 브로커에 발행하고 필요한 쪽이 구독하는 방식이며, 주제, QoS, 유언으로 데이터와 연결 상태를 다룬다
- Sparkplug B는 주제 규칙과 페이로드 형식을 정해, 노드가 BIRTH로 모든 지표를 알리고 DATA로 바뀐 것만 별칭과 순번을 붙여 보낸다
- 노드가 갑자기 사라지면 브로커가 유언으로 맡겨 둔 DEATH를 보내고, 호스트는 bdSeq로 확인해 그 노드의 태그를 품질 불량으로 바꾼다
