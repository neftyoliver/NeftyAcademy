## 사다리꼴과 S자

가장 흔한 것은 **사다리꼴 속도 궤적**입니다. 최대 가속도로 최대 속도까지 올리고, 그 속도로 가다가, 같은 가속도로 줄여 멈춥니다. 속도 그래프가 사다리꼴 모양입니다. 이동 거리가 짧아 최대 속도에 닿기 전에 줄이기 시작해야 하면 삼각형이 됩니다.

사다리꼴의 약점은 가속도가 0에서 1000으로 한순간에 바뀐다는 것입니다. 가속도가 바뀌는 빠르기를 **저크**라고 하는데, 사다리꼴의 저크는 이론상 무한대입니다. 이 충격이 기계의 고유 진동을 흔들어 멈춘 뒤에도 끝이 떨립니다. 저크를 제한해 가속도가 경사를 이루게 한 것이 **S자 궤적**입니다. 사다리꼴 속도를 일정 시간 창으로 이동 평균하면 간단히 S자가 됩니다.

```cpp
// 사다리꼴 속도 궤적과, 그것을 이동 평균으로 다듬은 S자 궤적을 1ms마다 만든다
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <vector>

// 0에서 출발해 dist만큼 가서 멈춘다
struct Trapezoid {
    double dist, vmax, amax;
    // 가속 시간, 등속 시간, 실제 최고 속도
    double ta, tc, v;
    Trapezoid(double d, double vm, double am) : dist(d), vmax(vm), amax(am) {
        ta = vmax / amax;
        // 최고 속도에 닿기 전에 감속해야 함
        if (amax * ta * ta > dist) {
            ta = std::sqrt(dist / amax);         // 삼각형 궤적
            tc = 0;
        } else {
            tc = (dist - amax * ta * ta) / vmax;
        }
        v = amax * ta;
    }
    double total() const { return 2 * ta + tc; }
    double velocity(double t) const {
        if (t <= 0 || t >= total()) return 0;
        if (t < ta) return amax * t;
        if (t < ta + tc) return v;
        return amax * (total() - t);
    }
};

int main() {
    const double dt = 0.001;                     // 1ms 주기로 목표 위치를 보낸다
    const Trapezoid move(100, 200, 1000);        // 100mm, 200mm/s, 1000mm/s²
    std::printf("사다리꼴: 가속 %.3fs, 등속 %.3fs, 감속 %.3fs, 전체 %.3fs\n",
                move.ta, move.tc, move.ta, move.total());
    const Trapezoid shortMove(10, 200, 1000);
    std::printf("10mm 이동: 최고 속도 %.1fmm/s(삼각형), 전체 %.3fs\n", shortMove.v,
                shortMove.total());

    // 속도를 50ms 이동 평균으로 다듬으면 가속도가 경사로 바뀌어 S자가 된다
    const int window = 50;
    const int n = int(std::lround(move.total() / dt)) + window;
    std::vector<double> vTrap(n), vS(n), pTrap(n), pS(n);
    for (int i = 0; i < n; ++i) vTrap[i] = move.velocity((i + 0.5) * dt);
    double sum = 0;
    for (int i = 0; i < n; ++i) {
        sum += vTrap[i] - (i >= window ? vTrap[i - window] : 0);
        vS[i] = sum / window;
    }
    double maxJerkTrap = 0, maxJerkS = 0;        // 가속도가 한 주기에 얼마나 바뀌나
    for (int i = 2; i < n; ++i) {
        maxJerkTrap = std::max(maxJerkTrap,
            std::fabs(vTrap[i] - 2 * vTrap[i - 1] + vTrap[i - 2]) / (dt * dt));
        maxJerkS = std::max(maxJerkS,
            std::fabs(vS[i] - 2 * vS[i - 1] + vS[i - 2]) / (dt * dt));
    }
    for (int i = 1; i < n; ++i) {                // 속도를 적분해 위치로
        pTrap[i] = pTrap[i - 1] + vTrap[i - 1] * dt;
        pS[i] = pS[i - 1] + vS[i - 1] * dt;
    }
    std::printf("S자: 전체 %.3fs, 최대 저크 %.0f mm/s³ (사다리꼴은 %.0f)\n",
                (n - 1) * dt, maxJerkS, maxJerkTrap);
    std::printf("  시각   사다리꼴   S자 (mm)\n");
    for (int i = 0; i < n; i += 100)
        std::printf("  %.1fs  %7.2f  %7.2f\n", i * dt, pTrap[i], pS[i]);
    std::printf("  끝     %7.2f  %7.2f\n", pTrap[n - 1], pS[n - 1]);
}
```

- **사다리꼴**: 200mm/s까지 오르는 데 0.2초, 그동안 20mm를 갑니다. 남은 60mm를 등속으로 0.3초, 다시 0.2초 감속해 0.7초에 도착합니다
- **삼각형**: 10mm는 최고 속도에 닿을 거리가 안 되어, 100mm/s까지만 올랐다가 바로 줄였습니다
- **S자의 대가**: 50ms 창으로 다듬자 저크가 1000/0.05 = 20000mm/s³로 묶였고, 대신 도착이 창의 길이만큼(50ms) 늦어졌습니다. 사다리꼴의 50만은 1ms로 잘라서 본 값이며, 주기를 줄일수록 더 커집니다
- **끝은 정확히**: 두 궤적 모두 마지막 점이 정확히 100mm입니다. 기계는 이 점들을 그대로 따라가므로, 실수 누적으로 끝이 99.98이 되면 그만큼 덜 갑니다. 긴 이동에서는 속도를 더해 가는 대신 시각에서 위치를 바로 계산하는 식을 씁니다

## 정리

- 마스터는 목적지를 한 번에 보내지 않고, 속도와 가속도의 한계를 지키는 궤적을 만들어 매 주기 목표 위치를 보낸다
- 사다리꼴 궤적은 가속, 등속, 감속으로 되고 짧은 이동에서는 삼각형이 되며, 가속도가 순간적으로 바뀌어 저크가 크다
- S자 궤적은 저크를 제한해 진동을 줄이고, 사다리꼴 속도의 이동 평균으로 만들 수 있으며, 그 창의 길이만큼 도착이 늦어진다
