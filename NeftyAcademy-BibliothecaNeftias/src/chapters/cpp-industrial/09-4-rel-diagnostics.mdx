## 구조화 로그와 블랙박스

로그 줄은 `키=값` 꼴로 남기고, 축의 전류와 위치는 10ms마다 고리 버퍼(블랙박스)에 덮어쓰며 기억하다가, 고장이 나면 직전 1.5초와 직후 0.5초를 떠 두었습니다.

```cpp
// 진단: 구조화된 로그 줄과, 고장 직전·직후를 남기는 블랙박스(고리 버퍼)
#include <array>
#include <cstdio>
#include <string>
#include <vector>

// 사람과 프로그램이 모두 읽기 좋은 "키=값" 로그. 시각은 UTC, 밀리초까지
void logLine(long ms, const char* level, const char* event, const std::string& kv) {
    std::printf("2026-11-22T03:14:%02ld.%03ldZ %-5s %s %s\n", ms / 1000 % 60,
                ms % 1000, level, event, kv.c_str());
}

struct Sample { long ms; float current, position; };

class BlackBox {                                 // 마지막 N개만 기억하는 고리 버퍼
    std::array<Sample, 200> buf{};               // 10ms × 200 = 2초
    size_t next = 0, count = 0;
public:
    void record(const Sample& s) {               // 할당 없이 덮어쓴다(실시간 안전)
        buf[next] = s;
        next = (next + 1) % buf.size();
        if (count < buf.size()) ++count;
    }
    std::vector<Sample> snapshot() const {       // 오래된 것부터 순서대로
        std::vector<Sample> out;
        for (size_t i = 0; i < count; ++i)
            out.push_back(buf[(next + buf.size() - count + i) % buf.size()]);
        return out;
    }
};

int main() {
    BlackBox box;
    logLine(0, "INFO", "batch_start", "batch=12 recipe=CRACKER-A/4 operator=kim");
    long faultAt = -1;
    std::vector<Sample> dump;
    for (long ms = 0; ms <= 6000; ms += 10) {    // 축 하나를 10ms마다 기록
        const float current =                    // 4.3초부터 축이 걸리기 시작한다
            2.0f + (ms > 4300 ? (ms - 4300) * 0.01f : 0.0f);
        box.record({ms, current, float(ms) * 0.05f});
        if (faultAt < 0 && current > 8.0f) {     // 전류가 한계를 넘어 고장
            faultAt = ms;
            char kv[96];
            std::snprintf(kv, sizeof kv, "axis=X current=%.1fA limit=8.0A batch=12",
                          current);
            logLine(ms, "ERROR", "overcurrent", kv);
        }
        // 고장 뒤 0.5초까지 더 담고 떠 둔다
        if (faultAt >= 0 && ms == faultAt + 500) {
            dump = box.snapshot();
            break;
        }
    }
    std::printf("블랙박스: %zu개, %.2f~%.2f초\n", dump.size(),
                dump.front().ms / 1000.0, dump.back().ms / 1000.0);
    for (const Sample& s : dump)
        if (s.ms % 500 == 0)
            std::printf("  %.1f초 전류 %.1fA 위치 %.1fmm\n", s.ms / 1000.0,
                        s.current, s.position);
    logLine(faultAt + 500, "INFO", "blackbox_saved",
            "file=bb-20261122-031404.csv rows=" + std::to_string(dump.size()));
}
```

```text
블랙박스: 200개, 3.42~5.41초
  3.5초 전류 2.0A 위치 175.0mm
  4.0초 전류 2.0A 위치 200.0mm
  4.5초 전류 4.0A 위치 225.0mm
  5.0초 전류 9.0A 위치 250.0mm
2026-11-22T03:14:05.410Z INFO  blackbox_saved file=bb-20261122-031404.csv rows=200
```

- **키=값**: "X축 과전류 발생!!" 같은 문장보다 `overcurrent axis=X current=8.1A limit=8.0A`가 낫습니다. 사람이 읽기에도 충분하고, 프로그램으로 "X축 과전류만" 걸러 세기도 쉽습니다. 사건 이름은 바꾸지 않는 고정된 낱말로 씁니다
- **잇는 열쇠**: 배치 번호, 레시피 판, 작업자, 제품 일련번호 같은 열쇠를 함께 남기면 로그를 [「추적성」](#/read/cpp-industrial/data-trace) 기록, 알람 기록과 이어 볼 수 있습니다
- **UTC와 밀리초**: 시각은 UTC로, 밀리초까지 남깁니다. 서머타임이나 장비마다 다른 시간대 설정 때문에 순서가 뒤바뀌는 일을 막습니다
- **블랙박스**: 10ms마다의 값을 모두 파일에 쓰면 디스크가 금방 찹니다. 메모리의 고리 버퍼에 마지막 2초만 덮어쓰며 기억하다가, 고장이 나면 그때만 떠서 저장합니다. 덕분에 4.3초부터 전류가 서서히 오르기 시작했다는, 고장 메시지 한 줄로는 알 수 없는 사실이 남았습니다. 덮어쓰기는 할당이 없어 실시간 스레드에서도 쓸 수 있습니다

## 진단 카운터

로그 말고도, 통신 재시도 횟수, 시간 초과, 주기 넘침, 버린 프레임 같은 숫자를 계속 세어 HMI의 진단 화면이나 [「OPC UA」](#/read/cpp-industrial/fb-opcua)로 내놓습니다. "통신 오류가 지난주부터 하루 3번에서 300번으로 늘었다"는 추세는 고장이 나기 전에 케이블이나 커넥터의 문제를 알려 줍니다.

<Note>
산업용 PC의 저장 장치는 작고, 플래시 메모리는 쓰기 횟수에 수명이 있습니다. 로그는 크기와 개수에 한도를 두고 돌려 쓰며(logrotate나 journald의 크기 제한), 높은 빈도의 디버그 로그는 평소에 끄고 원격으로 잠깐 켤 수 있게 합니다. 실시간 스레드는 로그를 직접 쓰지 않고 [「주기 작업」](#/read/cpp-industrial/rt-cyclic)의 큐에 넣기만 합니다. 개인 정보(작업자 이름 등)를 로그에 남길 때는 회사와 나라의 규정을 확인합니다.
</Note>

## 정리

- 로그는 고정된 사건 이름과 키=값으로 남기고, 배치·제품 같은 열쇠와 UTC 밀리초 시각을 붙여 다른 기록과 이어 볼 수 있게 한다
- 높은 빈도의 값은 메모리의 고리 버퍼에 덮어쓰며 기억하다가 고장이 나면 직전·직후를 떠 두는 블랙박스로 남긴다
- 재시도, 시간 초과, 넘침 같은 진단 카운터를 내놓아 고장 전의 추세를 보고, 작은 디스크와 플래시 수명에 맞춰 로그를 돌려 쓴다
