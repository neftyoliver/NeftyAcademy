사용자가 공들여 놓은 패널 배치는 다음에 켰을 때 그대로여야 합니다. 저장은 쉽습니다. [「도킹 패널」](#/read/cpp-complex-app/win-docking)의 트리를 글로 적으면 됩니다. 어려운 쪽은 읽기입니다. 저장본을 쓴 프로그램과 읽는 프로그램은 판이 다르고, 깔린 확장이 다르고, 모니터가 다릅니다. 저장본은 믿지 않고 읽어야 합니다.

```cpp
// 작업 공간 되살리기: 저장해 둔 배치를 믿지 않고 읽는다
#include <algorithm>
#include <cctype>
#include <format>
#include <memory>
#include <print>
#include <set>
#include <stdexcept>
#include <string>
#include <vector>

struct Node {                                    // 잎은 탭 묶음, 가지는 나눈 자리
    std::vector<std::string> tabs;
    bool row = true;
    std::vector<std::unique_ptr<Node>> kids;
    std::vector<double> share;
};
using Ptr = std::unique_ptr<Node>;
using Names = std::set<std::string>;

std::string text(const Node& n) {                // 저장하는 꼴이기도 하다
    std::string s;
    if (n.kids.empty()) {
        for (const auto& t : n.tabs) s += (s.empty() ? "" : "+") + t;
        return s;
    }
    for (std::size_t i = 0; i < n.kids.size(); ++i)
        s += std::format("{}{} {:.0f}", i ? ", " : "", text(*n.kids[i]),
                         n.share[i] * 100);
    return (n.row ? "row(" : "col(") + s + ")";
}

struct Parser {                                  // row(A 25, col(B+C 60, D 40) 75)
    std::string s;
    std::size_t i = 0;
    bool take(const std::string& word) {
        while (i < s.size() && s[i] == ' ') ++i;
        if (s.compare(i, word.size(), word) != 0) return false;
        i += word.size();
        return true;
    }
    std::string word() {
        take("");
        std::size_t from = i;
        while (i < s.size() && std::isalnum(static_cast<unsigned char>(s[i]))) ++i;
        if (from == i) throw std::runtime_error(std::format("{}번째 글자", i));
        return s.substr(from, i - from);
    }
    Ptr node() {
        auto n = std::make_unique<Node>();
        n->row = take("row(");
        if (!n->row && !take("col(")) {          // 잎: A+B+C
            do n->tabs.push_back(word());
            while (take("+"));
            return n;
        }
        do {
            n->kids.push_back(node());
            n->share.push_back(std::stod(word()) / 100);
        } while (take(","));
        if (!take(")")) throw std::runtime_error("닫는 괄호가 없음");
        return n;
    }
};

// 모르는 패널과 겹친 패널을 빼고, 빈 곳을 접고, 몫을 다시 맞춘다
Ptr clean(Ptr n, const Names& known, Names& seen) {
    if (n->kids.empty()) {
        std::erase_if(n->tabs, [&](const std::string& t) {
            return !known.contains(t) || !seen.insert(t).second;
        });
        return n->tabs.empty() ? nullptr : std::move(n);
    }
    std::vector<Ptr> kids;
    std::vector<double> share;
    double sum = 0;
    for (std::size_t i = 0; i < n->kids.size(); ++i)
        if (Ptr k = clean(std::move(n->kids[i]), known, seen)) {
            kids.push_back(std::move(k));
            share.push_back(std::clamp(n->share[i], 0.05, 1.0));
            sum += share.back();
        }
    if (kids.size() < 2) return kids.empty() ? nullptr : std::move(kids[0]);
    for (double& x : share) x /= sum;
    n->kids = std::move(kids), n->share = std::move(share);
    return n;
}

const char* fallback = "row(Files 25, Editor 75)";

std::string restore(const std::string& saved, const Names& known) {
    Ptr root;
    Names seen;
    try {
        Parser p{saved};
        root = clean(p.node(), known, seen);
        p.take("");
        if (p.i != saved.size()) throw std::runtime_error("뒤에 남은 글");
    } catch (const std::exception& e) {          // 깨진 파일에 실행이 막히면 안 됨
        std::println("  읽기 실패({}): 기본 배치를 쓴다", e.what());
        root = nullptr;
    }
    if (!root) seen.clear(), root = clean(Parser{fallback}.node(), known, seen);
    Node* last = root.get();                     // 저장본에 없던 패널은 끝에 탭으로
    while (!last->kids.empty()) last = last->kids.back().get();
    for (const std::string& name : known)
        if (!seen.contains(name)) last->tabs.push_back(name);
    return text(*root);
}

struct Rect {
    int x, y, w, h;
};
Rect fit(Rect r, Rect screen) {                  // 창이 지금 화면 안에 보이게
    r.w = std::clamp(r.w, 200, screen.w), r.h = std::clamp(r.h, 150, screen.h);
    r.x = std::clamp(r.x, screen.x, screen.x + screen.w - r.w);
    r.y = std::clamp(r.y, screen.y, screen.y + screen.h - r.h);
    return r;
}

int main() {
    const Names known = {"Editor", "Files", "Inspector", "Console"};
    for (const char* saved : {
             "row(Files 25, col(Editor 70, Console 30) 50, Inspector 25)",
             "row(Files 20, col(Editor 70, GitLens 30) 80)",
             "row(Editor 0, Editor 50, Files 500, Inspector 50)",
             "row(Files 25, col(Editor 70",
         }) {
        std::println("저장본 {}", saved);
        std::println("  -> {}", restore(saved, known));
    }
    Rect r = fit({2600, -40, 1200, 800}, {0, 0, 1920, 1080});
    std::println("둘째 모니터에 있던 창 -> ({}, {}) {}x{}", r.x, r.y, r.w, r.h);
}
```

```text
저장본 row(Files 25, col(Editor 70, Console 30) 50, Inspector 25)
  -> row(Files 25, col(Editor 70, Console 30) 50, Inspector 25)
저장본 row(Files 20, col(Editor 70, GitLens 30) 80)
  -> row(Files 20, Editor+Console+Inspector 80)
저장본 row(Editor 0, Editor 50, Files 500, Inspector 50)
  -> row(Editor 3, Files 65, Inspector+Console 32)
저장본 row(Files 25, col(Editor 70
  읽기 실패(닫는 괄호가 없음): 기본 배치를 쓴다
  -> row(Files 25, Editor+Console+Inspector 75)
둘째 모니터에 있던 창 -> (720, 0) 1200x800
```

- **저장하는 것은 트리를 적은 글이다**: `text`가 쓰고 `Parser`가 읽습니다. 첫 저장본은 그대로 돌아왔습니다
- **모르는 패널은 뺀다**: 지운 확장의 패널 GitLens는 지금 프로그램에 없습니다. 빼고 나서 빈 자리를 접으니 그 패널 때문에 있던 `col`도 사라졌습니다
- **저장본에 없던 패널에는 자리를 준다**: 새 판에서 생긴 패널은 옛 저장본에 없습니다. 마지막 잎에 탭으로 넣었습니다. 넣어 주지 않으면 새 기능이 화면 어디에도 나타나지 않습니다
- **숫자는 범위 안으로**: 몫이 0이거나 500이면 잘라 낸 뒤 합이 1이 되게 다시 나눕니다. 같은 패널이 두 번 나오면 뒤의 것을 뺍니다
- **깨진 파일은 기본 배치로**: 읽다가 실패하면 기본 배치를 씁니다. 배치 파일 하나가 깨졌다고 프로그램이 켜지지 않으면 사용자는 고칠 길이 없습니다
- **창은 지금 화면 안으로**: 둘째 모니터에 두었던 창은 그 모니터를 떼면 화면 밖에 놓입니다. 저장된 자리를 지금 화면에 맞춰 끌어옵니다

## 무엇을 어디에 두는가

| 저장하는 것 | 두는 곳 | 보기 |
| --- | --- | --- |
| 패널 배치와 창의 자리 | 사용자 설정 | 거의 모든 프로그램 |
| 이름 붙인 배치 여러 벌 | 사용자 설정 | Visual Studio의 창 배치 |
| 열어 둔 문서와 탭의 자리 | 프로젝트 옆 | Visual Studio의 `.vs` 폴더 |
| 일마다 다른 배치 | 문서 안 | Blender의 blend 파일 |

- **Visual Studio**: 닫을 때의 배치를 기억하고, 배치에 이름을 붙여 여러 벌 저장해 두었다가 바꿔 씁니다. 처음 열 개에는 단축키가 붙습니다. 열어 둔 문서와 문서 묶음의 배치는 17.9부터 솔루션 폴더의 `.vs` 아래에 JSON 파일로 둡니다. 모니터 둘에서 만든 배치를 모니터 하나에서 쓰면 둘째 모니터에 떠 있던 창이 본체 뒤로 숨는다고 문서가 적는데, 예제의 `fit`이 다루는 바로 그 문제입니다
- **Blender**: 작업 공간은 모델링, 애니메이션처럼 일마다 미리 짜 둔 창 배치이고 blend 파일에 저장됩니다. 파일을 열 때 Load UI를 켜면 파일에 든 배치를 쓰고, 끄면 지금 배치를 그대로 둡니다. 배치가 문서에 들어 있으면 남이 만든 파일을 열 때 내 화면이 바뀌므로 끌 수 있게 한 것입니다
- **VS Code**: 떠 있는 창도 다시 켜면 제자리로 돌아와 열어 두었던 편집기를 다시 엽니다
- **Dear ImGui**: 창의 자리와 도킹 배치를 ini 파일에 적어 둡니다
- **Qt**: 메인 윈도우의 `saveState`가 도킹과 도구 모음의 배치를 바이트 묶음으로 돌려줍니다([「메인 윈도우, 메뉴, 도구 모음, 도킹」](#/read/cpp-qt/wid-mainwindow))

## 오래 가는 저장본

- **판 번호를 적는다**: 형식이 바뀌면 옛 판을 새 판으로 옮기는 코드를 두고, 옮길 수 없으면 기본 배치를 씁니다([「버전과 호환」](#/read/cpp-complex-app/file-versions))
- **패널은 ID로 적는다**: 제목은 번역되고 판마다 바뀝니다. 저장본에는 바뀌지 않는 ID를 적고 제목은 화면에 그릴 때 찾습니다
- **끝낼 때만 저장하지 않는다**: 끝낼 때만 저장하면 프로그램이 죽었을 때 배치를 잃습니다. 배치가 바뀌면 조금 뒤에 저장합니다

<Note>
배치 파일은 임시 파일에 다 쓴 다음 이름을 바꿔서 제자리에 둡니다. 쓰는 도중에 전원이 나가면 반쯤 쓴 파일이 남는데, 다음 실행에서 그 파일을 읽다 실패해 기본 배치로 돌아가면 사용자는 배치를 통째로 잃습니다. 예제의 기본 배치는 마지막 안전망이고, 거기까지 가지 않게 하는 것이 먼저입니다([「자동 저장과 복구」](#/read/cpp-complex-app/file-autosave)).
</Note>

## 정리

- 배치의 저장은 트리를 글로 적는 일이고, 되살릴 때는 저장본을 쓴 프로그램과 지금 프로그램이 다르다고 보고 읽는다
- 모르는 패널은 빼고, 새 패널에는 자리를 주고, 숫자는 범위에 넣고, 창은 지금 화면 안으로 옮기며, 읽지 못하면 기본 배치를 쓴다
- 배치는 사용자 설정, 프로젝트 옆, 문서 안 가운데 어디에 둘지에 따라 성격이 달라지고, 판 번호와 패널 ID가 저장본을 오래 가게 한다
