아랍 글자와 히브리 글자는 오른쪽에서 왼쪽으로 씁니다. 그 안에 든 숫자와 영문은 왼쪽에서 오른쪽으로 갑니다. 한 줄에 두 방향이 섞입니다. 유니코드의 답은 메모리에는 읽는 순서대로 두고 화면에 낼 때만 순서를 바꾸는 것입니다. 그래서 편집기에는 글자의 번호와 화면의 자리라는 두 좌표가 생깁니다. 예제는 대문자를 오른쪽에서 왼쪽으로 가는 글자로 칩니다.

```cpp pkg=icu-uc
// 양방향 글: 글자마다 수준을 매기고 수준이 높은 구간부터 뒤집는다. ICU와 견준다
#include <algorithm>
#include <numeric>
#include <print>
#include <string>
#include <vector>
#include <unicode/ubidi.h>

enum class Kind { L, R, Num, Neutral };
Kind kind(char c) {                              // 소문자는 L, 대문자는 R인 셈 친다
    if (c >= 'a' && c <= 'z') return Kind::L;
    if (c >= 'A' && c <= 'Z') return Kind::R;
    return c >= '0' && c <= '9' ? Kind::Num : Kind::Neutral;
}

std::vector<int> levels(const std::string& t, int base) {
    std::size_t n = t.size();
    std::vector<Kind> k(n);
    Kind para = base ? Kind::R : Kind::L, strong = para;
    for (std::size_t i = 0; i < n; ++i) {        // 숫자: 앞의 글자가 L이면 L로 본다
        k[i] = kind(t[i]);
        if (k[i] == Kind::L || k[i] == Kind::R) strong = k[i];
        if (k[i] == Kind::Num && strong == Kind::L) k[i] = Kind::L;
    }
    auto side = [](Kind x) { return x == Kind::L ? Kind::L : Kind::R; };
    for (std::size_t i = 0, j = 0; i < n; i = j) {
        for (j = i; j < n && k[j] == Kind::Neutral;) ++j;
        if (j == i) { ++j; continue; }           // 중립: 양쪽이 같으면 그 방향,
        Kind left = i ? side(k[i - 1]) : para;   // 다르면 문단의 방향
        Kind right = j < n ? side(k[j]) : para;
        std::fill(k.begin() + i, k.begin() + j, left == right ? left : para);
    }
    std::vector<int> level(n);
    for (std::size_t i = 0; i < n; ++i) {        // 짝수면 왼쪽에서, 홀수면 반대로
        int up = k[i] == Kind::R ? 1 : k[i] == Kind::Num ? 2 : 0;
        level[i] = base + (base ? k[i] != Kind::R : up);
    }
    return level;
}

std::vector<std::size_t> reorder(const std::vector<int>& level) {
    std::vector<std::size_t> order(level.size());    // 화면 자리 -> 글자 번호
    std::iota(order.begin(), order.end(), 0);
    int top = *std::max_element(level.begin(), level.end());
    for (; top >= 1; --top)                      // 이 수준 이상인 구간을 뒤집는다
        for (std::size_t i = 0, j = 0; i < level.size(); i = j + 1) {
            for (j = i; j < level.size() && level[j] >= top;) ++j;
            std::reverse(order.begin() + i, order.begin() + j);
        }
    return order;
}

std::vector<int> icu_levels(const std::string& t, int base) {
    std::u16string u;                            // 대문자는 히브리 글자로 바꾼다
    for (char c : t)
        u += kind(c) == Kind::R ? char16_t(0x5D0 + c - 'A') : char16_t(c);
    UErrorCode error = U_ZERO_ERROR;
    UBiDi* bidi = ubidi_open();
    ubidi_setPara(bidi, u.data(), int(u.size()), UBiDiLevel(base), nullptr, &error);
    const UBiDiLevel* level = ubidi_getLevels(bidi, &error);
    std::vector<int> out(level, level + u.size());
    ubidi_close(bidi);
    return out;
}

void show(const std::string& t, int base) {
    std::string digits, screen;
    std::vector<int> level = levels(t, base);
    for (int v : level) digits += char('0' + v);
    for (std::size_t i : reorder(level)) screen += t[i];
    std::println("{} 문단\n  글자 {}\n  수준 {}\n  화면 {}", base ? "RTL" : "LTR",
                 t, digits, screen);
}

int main() {
    show("car means CAR.", 0);
    show("car means CAR.", 1);
    show("TOTAL 123 ok", 0);
    show("abc DEF 12 GHI jkl", 0);

    int same = 0, all = 0;
    for (const char* t : {"car means CAR.", "TOTAL 123 ok", "abc DEF 12 GHI jkl",
                          "he said CAR MEANS car, ok", "SHOW 12 AND 34 now",
                          "1 A 2", "a 1 B 2 c", " lead AND TRAIL ",
                          "MIX 12 abc 34 DEF"})
        for (int base : {0, 1})
            ++all, same += levels(t, base) == icu_levels(t, base);
    std::println("ICU와 견준 {}가지 가운데 {}가지가 같다", all, same);

    std::string t = "car means CAR.";            // 글자 7~11("ns CA")을 고르면
    std::string screen, picked;
    for (std::size_t i : reorder(levels(t, 0)))
        screen += t[i], picked += i >= 7 && i < 12 ? '^' : ' ';
    picked.erase(picked.find_last_not_of(' ') + 1);
    std::println("이어진 글자 7~11은 화면에서 두 토막\n  {}\n  {}", screen, picked);
}
```

  화면 123 LATOT ok

- **수준**: 글자마다 수를 하나 매깁니다. 짝수면 왼쪽에서 오른쪽으로, 홀수면 반대로 갑니다. 왼쪽에서 시작하는 문단(수준 0)에서 대문자는 1이 되고, 그 사이의 숫자는 2가 됩니다
- **중립 글자는 이웃을 따른다**: 빈칸과 문장 부호에는 제 방향이 없습니다. 양쪽의 방향이 같으면 그 방향을, 다르면 문단의 방향을 따릅니다. 첫 보기의 마침표가 CAR에 붙지 않고 0이 된 까닭입니다
- **문단의 방향이 결과를 바꾼다**: 같은 글이 문단의 방향에 따라 `car means RAC.`도 되고 `.RAC car means`도 됩니다. 문단의 방향은 방향이 뚜렷한 첫 글자에서 정하거나, 문서나 UI의 설정이 정해 줍니다
- **뒤집기는 높은 수준부터**: 가장 높은 수준에서 1까지 내려오면서, 그 수준 이상인 이어진 구간을 뒤집습니다. `TOTAL 123 ok`에서는 123을 먼저 뒤집고, 이어서 `TOTAL 321`을 통째로 뒤집습니다. 숫자는 두 번 뒤집혀 제 순서로 돌아옵니다
- **ICU와 같다**: 대문자를 히브리 글자로 바꿔 ICU에 넘긴 수준과 18가지가 모두 같았습니다. 다만 예제는 알고리즘의 일부입니다. 방향 문자, 괄호의 짝, 숫자 사이의 구분 기호를 다루는 규칙이 빠져 있습니다
- **이어진 선택이 화면에서는 끊긴다**: 글자 7에서 11까지는 메모리에서 이어져 있지만 화면에서는 두 토막입니다. 선택은 사각형 하나가 아니라 여러 개로 칠합니다

## 편집기가 맡는 일

- **줄을 나눈 뒤에 줄마다 뒤집는다**: 수준은 문단 전체를 보고 매기고, 뒤집기는 줄을 나눈 다음 줄마다 합니다. ICU에서는 `ubidi_setPara`로 문단을 넘기고, 줄을 나눈 뒤 줄마다 `ubidi_setLine`을 부릅니다
- **그리기는 런으로**: 수준이 같은 구간을 화면 순서대로 꺼내(`ubidi_getVisualRun`) 런마다 셰이핑해서 그립니다([「글꼴과 셰이핑」](#/read/cpp-complex-app/txt-shaping)). 오른쪽에서 가는 런에서는 구간의 첫 글자가 화면의 오른쪽 끝에 놓입니다
- **캐럿의 자리가 둘**: 방향이 바뀌는 경계에서는 글자 번호 하나가 화면의 두 자리에 걸립니다. 첫 보기에서 글자 10의 앞은 빈칸 바로 뒤이기도 하고 RAC의 오른쪽 끝이기도 합니다. 편집기는 방금 친 글자의 방향을 따라 하나를 고르거나 캐럿을 둘로 그립니다. 화살표 키가 화면 순서로 갈지 읽는 순서로 갈지도 정해야 합니다
- **거울 글자**: 괄호처럼 짝이 있는 글자는 방향이 오른쪽에서 왼쪽으로 정해지면 거울에 비친 글리프로 그립니다. 메모리의 여는 괄호가 화면에서도 여는 쪽을 보게 됩니다
- **보이지 않는 방향 문자**: 방향을 감싸거나 격리하거나 덮어쓰는 제어 문자가 있습니다. 화면에는 보이지 않으면서 순서를 바꿉니다. 유니코드 문서는 덮어쓰기 문자를 보안 문제 때문에 되도록 쓰지 말라고 적습니다. 소스 코드나 파일 이름을 보여 주는 프로그램은 이 문자들을 눈에 보이게 드러내야 합니다

<Note>
저장, 검색, 정렬, 복사는 모두 읽는 순서로 합니다. 화면 순서는 그릴 때와 마우스로 찍은 자리를 찾을 때만 쓰고, 문서 모델에는 들이지 않습니다. 오른쪽에서 가는 글을 읽지 못해도 시험은 할 수 있습니다. 예제처럼 대문자를 그런 글자로 치는 가짜 글을 넣으면, 캐럿과 선택과 줄 나눔이 두 방향에서 맞는지 눈으로 볼 수 있습니다. UI 전체를 오른쪽에서 왼쪽으로 놓는 일은 [「접근성과 국제화」](#/read/cpp-complex-app/accessibility)에서 다룹니다.
</Note>

## 정리

- 양방향 글은 메모리에 읽는 순서로 두고, 글자마다 수준을 매겨 화면에 낼 때만 순서를 바꾼다
- 뒤집기는 줄마다, 가장 높은 수준에서 내려오며 그 수준 이상인 구간을 뒤집는 것이다. 문단의 방향이 달라지면 결과도 달라진다
- 글자 번호와 화면 자리가 일대일로 이어지지 않으므로, 선택은 여러 토막이 되고 캐럿은 경계에서 두 자리를 가진다
