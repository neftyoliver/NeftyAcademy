같은 메시를 수천 번 그릴 때 그리기 명령을 그만큼 기록하면 CPU가 먼저 바빠집니다. **인스턴싱**은 명령 하나에 몇 번 그릴지를 적고, **간접 그리기**는 그 인자들을 버퍼에서 읽게 해서 서로 다른 메시까지 호출 하나에 묶으며, 그 버퍼를 GPU가 채우면 무엇을 그릴지도 GPU가 정합니다. 아래 프로그램은 막대 열둘을 세 가지로 그립니다.

```cpp vk with=vkx_instance.hpp,vkx_device.hpp,vkx_cmd.hpp,vkx_resource.hpp,vkx_bind.hpp,vkx_compute.hpp,vkx_pipeline.hpp,vkx_draw.hpp
#include <string>
#include "vkx_bind.hpp"
#include "vkx_cmd.hpp"
#include "vkx_compute.hpp"
#include "vkx_draw.hpp"
#include "vkx_pipeline.hpp"

// 물체마다 다른 값 둘: 칸 번호는 인스턴스마다 한 칸씩 넘어가는 정점 버퍼에서
// 받고, 밝기는 스토리지 버퍼에서 인스턴스 번호로 꺼낸다
const char* VS = R"(#version 450
layout(location = 0) in float column;
layout(set = 0, binding = 0) readonly buffer Shades { float shades[]; };
layout(location = 0) out float shade;
void main() {
    int v = gl_VertexIndex % 6;                // 정점 0~5는 긴 막대, 6~11은 짧다
    vec2 corner = vec2(v % 2, (v + 1) / 3 % 2);
    float top = gl_VertexIndex < 6 ? -1.0 : 0.0;
    gl_Position = vec4((column + corner.x) / 6.0 - 1.0, mix(top, 1.0, corner.y),
                       0.0, 1.0);
    shade = shades[gl_InstanceIndex];          // firstInstance부터 세는 번호
})";
const char* FS = R"(#version 450
layout(location = 0) in float shade;
layout(location = 0) out float color;
void main() { color = shade; })";
// 보이는 물체만 골라 그리기 명령을 앞에서부터 채우고, 몇 개인지도 적는다
const char* CULL = R"(#version 450
layout(local_size_x = 12) in;
struct Command { uint vertices, instances, first_vertex, first_instance; };
layout(set = 0, binding = 1) readonly buffer Columns { float columns[]; };
layout(set = 0, binding = 2) writeonly buffer Commands { Command commands[]; };
layout(set = 0, binding = 3) buffer Count { uint count; };
layout(push_constant) uniform Push { float left, right; };
void main() {
    uint i = gl_GlobalInvocationID.x;
    float c = columns[i];
    if (c < left || c >= right) return;      // 보이는 범위 밖
    uint slot = atomicAdd(count, 1u);        // 빈자리 번호를 하나 받는다
    commands[slot] = Command(6u, 1u, i < 6u ? 0u : 6u, i);
})";

int main() {
    vkx::Instance inst = vkx::make_instance();
    vkx::Device dev = vkx::make_device(inst.handle);
    vkx::Commands cmds = vkx::make_commands(dev);
    const VkExtent2D SIZE{24, 4};
    const uint32_t N = 12;
    vkx::Image target = vkx::make_image(
        dev, SIZE, VK_FORMAT_R8_UNORM,
        VK_IMAGE_USAGE_COLOR_ATTACHMENT_BIT | VK_IMAGE_USAGE_TRANSFER_SRC_BIT);
    vkx::Buffer pixels = vkx::make_buffer(dev, SIZE.width * SIZE.height,
                                          VK_BUFFER_USAGE_TRANSFER_DST_BIT, true);

    const auto STORAGE = VK_BUFFER_USAGE_STORAGE_BUFFER_BIT;
    const auto INDIRECT = VK_BUFFER_USAGE_INDIRECT_BUFFER_BIT;   // 간접 그리기용
    const auto VERTEX = VK_BUFFER_USAGE_VERTEX_BUFFER_BIT;
    const VkDeviceSize STRIDE = sizeof(VkDrawIndirectCommand);
    // 칸 번호는 정점 셰이더가 정점 버퍼로, 컬링 셰이더가 스토리지 버퍼로 읽는다
    vkx::Buffer columns = vkx::make_buffer(dev, N * 4, VERTEX | STORAGE, true);
    vkx::Buffer shades = vkx::make_buffer(dev, N * 4, STORAGE, true);
    vkx::Buffer commands =
        vkx::make_buffer(dev, N * STRIDE, STORAGE | INDIRECT, true);
    vkx::Buffer count = vkx::make_buffer(dev, 4, STORAGE | INDIRECT, true);
    for (uint32_t i = 0; i < N; ++i) {
        static_cast<float*>(columns.mapped)[i] = float(i);
        static_cast<float*>(shades.mapped)[i] = (i + 1) / 15.0f;
    }
    auto* command = static_cast<VkDrawIndirectCommand*>(commands.mapped);
    auto* counted = static_cast<uint32_t*>(count.mapped);

    const auto BUFFER = VK_DESCRIPTOR_TYPE_STORAGE_BUFFER;
    vkx::Bindings set = vkx::make_bindings(dev, {BUFFER, BUFFER, BUFFER, BUFFER});
    vkx::Buffer* bound[] = {&shades, &columns, &commands, &count};
    for (uint32_t i = 0; i < 4; ++i)
        vkx::bind_buffer(dev, set, i, BUFFER, *bound[i]);
    // 정점 입력: 바인딩 0은 인스턴스가 바뀔 때마다 4바이트씩 넘어간다
    VkVertexInputBindingDescription binding{0, 4, VK_VERTEX_INPUT_RATE_INSTANCE};
    VkVertexInputAttributeDescription attribute{0, 0, VK_FORMAT_R32_SFLOAT, 0};
    VkPipelineVertexInputStateCreateInfo input{
        .sType = VK_STRUCTURE_TYPE_PIPELINE_VERTEX_INPUT_STATE_CREATE_INFO,
        .vertexBindingDescriptionCount = 1, .pVertexBindingDescriptions = &binding,
        .vertexAttributeDescriptionCount = 1,
        .pVertexAttributeDescriptions = &attribute};
    VkPipelineLayout layout = vkx::make_layout(dev, {set.layout}, 8);
    auto shader = [&](const char* glsl, shaderc_shader_kind kind) {
        return vkx::make_shader(dev, vkx::compile(glsl, kind));
    };
    VkShaderModule modules[] = {shader(VS, shaderc_vertex_shader),
                                shader(FS, shaderc_fragment_shader),
                                shader(CULL, shaderc_compute_shader)};
    VkPipeline draw_bars = vkx::make_pipeline(
        dev, {.vertex = modules[0], .fragment = modules[1], .layout = layout,
              .color = target.format, .vertex_input = &input});
    VkPipeline cull = vkx::make_compute(dev, modules[2], layout);

    for (int way = 0; way < 3; ++way) {
        VkCommandBuffer cmd = vkx::begin(cmds);
        vkCmdBindDescriptorSets(cmd, VK_PIPELINE_BIND_POINT_GRAPHICS, layout, 0, 1,
                                &set.set, 0, nullptr);
        if (way == 1) {   // CPU가 명령 둘을 적는다: 긴 막대 여섯, 짧은 막대 여섯
            command[0] = {.vertexCount = 6, .instanceCount = 6, .firstVertex = 0,
                          .firstInstance = 0};
            command[1] = {.vertexCount = 6, .instanceCount = 6, .firstVertex = 6,
                          .firstInstance = 6};
        }
        if (way == 2) {   // GPU가 명령을 적는다: 3번부터 8번 칸까지만 보인다
            *counted = 0;
            const float visible[2] = {3, 9};
            vkCmdBindPipeline(cmd, VK_PIPELINE_BIND_POINT_COMPUTE, cull);
            vkCmdBindDescriptorSets(cmd, VK_PIPELINE_BIND_POINT_COMPUTE, layout, 0,
                                    1, &set.set, 0, nullptr);
            vkCmdPushConstants(cmd, layout, VK_SHADER_STAGE_ALL, 0, 8, visible);
            vkCmdDispatch(cmd, 1, 1, 1);
            VkMemoryBarrier2 b{   // 컴퓨트가 쓴 것을 간접 그리기와 CPU가 읽는다
                .sType = VK_STRUCTURE_TYPE_MEMORY_BARRIER_2,
                .srcStageMask = VK_PIPELINE_STAGE_2_COMPUTE_SHADER_BIT,
                .srcAccessMask = VK_ACCESS_2_SHADER_STORAGE_WRITE_BIT,
                .dstStageMask = VK_PIPELINE_STAGE_2_DRAW_INDIRECT_BIT |
                                VK_PIPELINE_STAGE_2_HOST_BIT,
                .dstAccessMask = VK_ACCESS_2_INDIRECT_COMMAND_READ_BIT |
                                 VK_ACCESS_2_HOST_READ_BIT};
            VkDependencyInfo dep{.sType = VK_STRUCTURE_TYPE_DEPENDENCY_INFO,
                                 .memoryBarrierCount = 1, .pMemoryBarriers = &b};
            vkCmdPipelineBarrier2(cmd, &dep);
        }
        vkx::begin_drawing(cmd, target);
        vkCmdBindPipeline(cmd, VK_PIPELINE_BIND_POINT_GRAPHICS, draw_bars);
        const VkDeviceSize zero = 0;
        vkCmdBindVertexBuffers(cmd, 0, 1, &columns.handle, &zero);
        if (way == 0)   // 정점 6개짜리 막대를 인스턴스 12개로
            vkCmdDraw(cmd, 6, N, 0, 0);
        if (way == 1)   // 버퍼에 적힌 명령 2개를 차례로
            vkCmdDrawIndirect(cmd, commands.handle, 0, 2, STRIDE);
        if (way == 2)   // 몇 개를 그릴지도 버퍼에서 읽는다(많아야 N개)
            vkCmdDrawIndirectCount(cmd, commands.handle, 0, count.handle, 0, N,
                                   STRIDE);
        vkx::end_drawing(cmd, target, pixels);
        vkx::submit_and_wait(dev, cmds);

        const char* names[] = {"vkCmdDraw 한 번, 인스턴스 12개",
                               "vkCmdDrawIndirect 한 번, 명령 2개",
                               "vkCmdDrawIndirectCount 한 번, 명령은 GPU가 고름"};
        std::puts(names[way]);
        const auto* px = static_cast<const unsigned char*>(pixels.mapped);
        for (uint32_t y = 0; y < SIZE.height; ++y) {
            std::string row;
            for (uint32_t x = 0; x < SIZE.width; ++x)
                row += ".123456789abc"[(px[y * SIZE.width + x] + 8) / 17];
            std::puts(row.c_str());
        }
        if (way == 2) std::printf("GPU가 적은 명령 수: %u\n", *counted);
    }

    vkDestroyPipeline(dev.handle, draw_bars, nullptr);
    vkDestroyPipeline(dev.handle, cull, nullptr);
    vkDestroyPipelineLayout(dev.handle, layout, nullptr);
    for (VkShaderModule m : modules) vkDestroyShaderModule(dev.handle, m, nullptr);
    vkx::destroy(dev, set);
    for (vkx::Buffer* b : {&columns, &shades, &commands, &count, &pixels})
        vkx::destroy(dev, *b);
    vkx::destroy(dev, target);
    vkx::destroy(dev, cmds);
    vkx::destroy(dev);
    vkx::destroy(inst);
}
```

- **인스턴싱**: `vkCmdDraw(cmd, 6, N, 0, 0)`은 정점 6개짜리 막대를 12번 그립니다. 물체마다 다른 값은 두 길로 줬습니다. 칸 번호는 `VK_VERTEX_INPUT_RATE_INSTANCE`로 인스턴스마다 넘어가는 바인딩에 두었고([「정점 버퍼와 인덱스 버퍼」](#/read/cpp-vulkan/buf-vertex)), 밝기는 스토리지 버퍼에서 `gl_InstanceIndex`로 꺼냈습니다
- **두 길의 차이**: 정점 속성은 정점 셰이더만 받지만 포맷을 줄여 담을 수 있습니다. 스토리지 버퍼는 구조체 배열을 어느 단계에서나 읽고(컬링 셰이더는 칸 번호를 이 길로 읽었습니다), 재질 번호로 재질 표를 다시 찾는 식으로 잇기 쉽습니다([「바인드리스」](#/read/cpp-vulkan/desc-bindless)). 둘 다 `firstInstance`부터 셉니다
- **간접 그리기**: `VkDrawIndirectCommand`는 `vkCmdDraw`의 인자 넷(정점 수, 인스턴스 수, 첫 정점, 첫 인스턴스)을 담은 16바이트이고, `vkCmdDrawIndirect`는 버퍼에서 `stride` 간격으로 `drawCount`개를 읽어 적힌 차례대로 그립니다. 두 명령은 `firstVertex`가 달라서 긴 막대와 짧은 막대, 곧 서로 다른 메시가 호출 하나에 들어갔고, 둘째는 `firstInstance`가 6이어서 6번 물체부터 읽었습니다
- **개수도 버퍼에서**: 컬링 셰이더는 보이는 범위(3~8번 칸)의 물체마다 `atomicAdd`로 자리 번호를 받아 명령을 적습니다. `vkCmdDrawIndirectCount`는 실행될 때 개수 버퍼의 값을 읽어 그만큼 그리되 `maxDrawCount`를 넘기지는 않습니다. CPU는 몇 개가 그려질지 모르는 채로 호출 하나만 기록합니다(6은 찍어 보려고 읽은 값입니다)
- **배리어**: 컴퓨트가 쓴 버퍼를 그리기가 인자로 읽으므로 사이에 `DRAW_INDIRECT` 단계, `INDIRECT_COMMAND_READ` 접근으로 받는 배리어를 둡니다([「파이프라인 배리어」](#/read/cpp-vulkan/vsync-barriers)). 빼면 동기화 검증이 READ_AFTER_WRITE를 알립니다

## 묶이는 조건과 기능

간접 그리기 한 번에 든 명령들은 파이프라인, 디스크립터 세트, 정점·인덱스 버퍼를 함께 씁니다. 그래서 메시들을 큰 버퍼 하나에 이어 담고 `firstVertex`로 고르며, 인덱스가 있으면 `vkCmdDrawIndexed`의 인자 다섯을 담는 `VkDrawIndexedIndirectCommand`와 `vkCmdDrawIndexedIndirect`를 씁니다. 명령 사이에 푸시 상수를 바꿀 수 없으니 물체의 값은 표에 두고 번호로 찾습니다([「푸시 상수」](#/read/cpp-vulkan/desc-push)). 그 번호가 이 예제의 `firstInstance`이거나, 몇 번째 명령인지 알려 주는 GLSL 4.60의 `gl_DrawID`입니다.

명령을 둘 이상 읽으려면 `multiDrawIndirect`, 0이 아닌 `firstInstance`를 적으려면 `drawIndirectFirstInstance`, 개수를 버퍼에서 읽으려면 `drawIndirectCount`, `gl_DrawID`에는 `shaderDrawParameters`가 켜져 있어야 합니다([「물리 장치와 논리 장치」](#/read/cpp-vulkan/setup-device)). 두 버퍼는 `VK_BUFFER_USAGE_INDIRECT_BUFFER_BIT`로 만들고, `stride`는 4의 배수이면서 명령 크기 이상, `maxDrawCount`는 버퍼에 들어가는 명령 수 이하로 줍니다.

<Note>
어느 실행이 먼저 자리를 받을지는 정해져 있지 않아 `atomicAdd`로 채운 명령의 차례는 돌릴 때마다 다를 수 있습니다. 불투명한 물체는 깊이 시험이 가려 주니 괜찮지만, 차례가 뜻을 갖는 반투명에는 맞지 않습니다. 물체마다 명령을 하나씩 두고 안 보이는 것은 인스턴스 수만 0으로 적는 방법도 있는데, 차례가 지켜지고 개수 버퍼가 필요 없는 대신 빈 명령도 하나씩 읽고 지나갑니다.
</Note>

## 정리

- 인스턴싱은 명령 하나로 같은 메시를 여러 번 그리며, 물체마다 다른 값은 인스턴스마다 넘어가는 정점 바인딩이나 `gl_InstanceIndex`로 고른 스토리지 버퍼에서 온다
- 간접 그리기는 그리기 인자를 버퍼에서 읽어, 서로 다른 메시의 그리기 여럿을 호출 하나로 묶는다
- 컴퓨트 셰이더가 명령과 개수를 적으면 `vkCmdDrawIndirectCount`가 그만큼만 그리고, 쓰기와 읽기 사이에는 배리어를 둔다
