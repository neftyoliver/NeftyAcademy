GLSL을 SPIR-V로 바꾸는 도구는 크게 두 갈래입니다. **glslang**은 Khronos가 관리하는 기준 앞단으로, GLSL과 HLSL을 읽는 라이브러리와 명령줄 도구 `glslangValidator`(별칭 `glslang`)가 있습니다. **shaderc**는 Google이 glslang과 SPIRV-Tools를 묶은 것으로, GCC처럼 쓰는 `glslc`와 실행 중에 부르는 라이브러리 `libshaderc`가 있습니다. 둘 다 벌칸 SDK와 리눅스 배포판 꾸러미에 들어 있습니다.

| 도구 | 하는 일 | 주로 쓰는 곳 |
| --- | --- | --- |
| `glslc` | GLSL·HLSL → SPIR-V, `-O`·`-g`·`-I`·`-D`·`-MD` | 빌드 단계 |
| `glslangValidator` | GLSL·HLSL → SPIR-V, 문법 검사 | 빌드, 기준 동작 확인 |
| `libshaderc` | 같은 번역을 함수로 | 실행 중 번역, 도구 |
| `spirv-opt`·`spirv-val`·`spirv-dis` | 최적화, 검증, 디스어셈블 | 번역 뒤 처리 |

```bash
glslc --target-env=vulkan1.3 -O blur.comp -o blur.spv
glslc -MD -MF blur.d blur.comp -o blur.spv   # blur.d에 포함한 파일 목록
glslangValidator -V --target-env vulkan1.3 blur.comp -o blur.spv
glslc -mfmt=c blur.comp -o blur.inc          # C 배열 초기화 꼴로
spirv-val --target-env vulkan1.3 blur.spv
```

아래 프로그램은 `libshaderc`로 같은 셰이더를 대상 환경과 옵션만 바꿔 번역하고, 나온 SPIR-V의 버전과 크기를 잽니다.

```cpp pkg=shaderc
#include <cstdio>
#include <cstring>
#include <shaderc/shaderc.h>

const char* CS = R"(#version 450
layout(local_size_x = 64) in;
layout(binding = 0) buffer Data { float v[]; };
float twice(float x) { return x * 2.0; }
void main() { v[gl_GlobalInvocationID.x] = twice(v[gl_GlobalInvocationID.x]); }
)";

// 대상 환경, 디버그 정보(-g), 최적화(-O)를 바꿔 번역하고 SPIR-V 버전과 크기를 잰다
void build(shaderc_compiler_t compiler, const char* label, uint32_t env, bool debug,
           bool optimize) {
    shaderc_compile_options_t o = shaderc_compile_options_initialize();
    shaderc_compile_options_set_target_env(o, shaderc_target_env_vulkan, env);
    if (debug) shaderc_compile_options_set_generate_debug_info(o);
    if (optimize)
        shaderc_compile_options_set_optimization_level(
            o, shaderc_optimization_level_performance);
    auto kind = shaderc_compute_shader;
    shaderc_compilation_result_t r = shaderc_compile_into_spv(
        compiler, CS, std::strlen(CS), kind, "twice.comp", "main", o);
    auto* w = reinterpret_cast<const uint32_t*>(shaderc_result_get_bytes(r));
    std::printf("%-12s %-5s SPIR-V %u.%u, %3zu낱말\n", label,
                debug ? "-g" : optimize ? "-O" : "", w[1] >> 16 & 0xFF,
                w[1] >> 8 & 0xFF, shaderc_result_get_length(r) / 4);
    shaderc_result_release(r);
    shaderc_compile_options_release(o);
}

int main() {
    shaderc_compiler_t compiler = shaderc_compiler_initialize();
    build(compiler, "vulkan1.0", shaderc_env_version_vulkan_1_0, false, false);
    build(compiler, "vulkan1.1", shaderc_env_version_vulkan_1_1, false, false);
    build(compiler, "vulkan1.2", shaderc_env_version_vulkan_1_2, false, false);
    build(compiler, "vulkan1.3", shaderc_env_version_vulkan_1_3, false, false);
    build(compiler, "vulkan1.3", shaderc_env_version_vulkan_1_3, true, false);
    build(compiler, "vulkan1.3", shaderc_env_version_vulkan_1_3, false, true);
    shaderc_compiler_release(compiler);
}
```

```text
vulkan1.0          SPIR-V 1.0, 276낱말
vulkan1.1          SPIR-V 1.3, 276낱말
vulkan1.2          SPIR-V 1.5, 277낱말
vulkan1.3          SPIR-V 1.6, 273낱말
vulkan1.3    -g    SPIR-V 1.6, 380낱말
vulkan1.3    -O    SPIR-V 1.6, 151낱말
```

- **대상 환경**: `--target-env`(라이브러리는 `set_target_env`)는 어느 벌칸에서 돌릴지 정하고, 그에 맞는 가장 높은 SPIR-V 버전을 고릅니다. 벌칸 1.0은 SPIR-V 1.0, 1.1은 1.3, 1.2는 1.5, 1.3은 1.6입니다. 아무것도 주지 않으면 vulkan1.0이므로, 1.3의 기능을 쓰는 셰이더는 대상을 밝혀야 합니다
- **크기 차이**: 버전마다 몇 낱말씩 다른 것은 진입점이 나열하는 변수의 규칙 같은 세부가 바뀌었기 때문입니다. `-g`는 원문과 줄 정보를 담아 커지고, `-O`는 [「왜 중간 표현인가」](#/read/cpp-vulkan/spv-why)에서 본 최적화를 거쳐 절반쯤으로 줄었습니다
- **라이브러리와 명령줄**: 옵션은 일대일로 대응합니다. `-D`는 `add_macro_definition`, `-I`와 `#include`는 포함 콜백([「전처리와 include」](#/read/cpp-vulkan/glsl-include)), `-O`는 `set_optimization_level`입니다

## 빌드에 넣기

셰이더도 빌드 산출물로 다루는 것이 좋습니다. CMake에서는 사용자 정의 명령으로 glslc를 부르고, `-MD`가 만든 의존성 파일을 `DEPFILE`로 넘기면 포함한 파일(`common.glsl`)만 고쳐도 다시 번역합니다(Makefile 생성기는 CMake 3.20부터 지원).

```cmake
add_custom_command(
  OUTPUT ${CMAKE_CURRENT_BINARY_DIR}/blur.spv
  COMMAND glslc --target-env=vulkan1.3 -O -MD -MF blur.d
          ${CMAKE_CURRENT_SOURCE_DIR}/blur.comp -o blur.spv
  DEPFILE ${CMAKE_CURRENT_BINARY_DIR}/blur.d
  DEPENDS ${CMAKE_CURRENT_SOURCE_DIR}/blur.comp)
add_custom_target(shaders ALL DEPENDS ${CMAKE_CURRENT_BINARY_DIR}/blur.spv)
```

만든 `.spv`는 실행 중에 파일로 읽거나, `glslc -mfmt=c`로 만든 낱말 목록을 C++ 배열 초기화에 `#include`해 실행 파일 안에 담습니다.

<Note>
벌칸 SDK에는 glslang, shaderc, SPIRV-Tools, SPIRV-Cross가 함께 들어 있고, 1.4.304부터는 Slang 컴파일러도 정식으로 들어 있습니다([「HLSL과 Slang에서 오기」](#/read/cpp-vulkan/spv-languages)). 이 책의 예제는 실행 중에 `libshaderc`로 번역하지만, 배포하는 프로그램은 대개 빌드 단계에서 미리 번역합니다.
</Note>

## 정리

- glslang은 Khronos의 기준 앞단(`glslangValidator`), shaderc는 그것을 묶은 GCC풍 도구(`glslc`)와 실행 중 번역 라이브러리다
- `--target-env`가 SPIR-V 버전을 정하고(1.3 → 1.6), `-g`는 디버그 정보를 더하고, `-O`는 최적화한다
- 빌드에서는 glslc의 `-MD` 의존성 파일을 CMake의 `DEPFILE`로 넘겨, 포함 파일이 바뀌어도 다시 번역되게 한다
