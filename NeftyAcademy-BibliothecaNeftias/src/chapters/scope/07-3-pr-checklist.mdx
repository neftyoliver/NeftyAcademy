이 책의 마지막 쪽입니다. 지금까지의 쪽들을 측정 한 번의 순서대로 다시 늘어놓습니다. 프로브를 들기 전에, 화면을 세우면서, 화면을 읽으면서, 그리고 화면을 남에게 보여 줄 때 하나씩 짚어 가는 표입니다.

## 물리기 전에

- **기대하는 모양을 적는다**: 높이는 몇 V인지, 주기나 속도는 얼마인지, 변은 곧을지 휘어 있을지를 먼저 적습니다. 화면이 그 기대와 다른 곳이 단서입니다
- **전압이 장비의 범위 안인지 본다**: 프로브와 입력이 견디는 전압은 장비에 적혀 있습니다. 무슨 선인지 모르면 V/칸을 가장 크게 놓고 시작합니다([「UART 프레임 읽기」](#/read/scope/bs-uart))
- **접지 집게가 물릴 곳을 정한다**: 집게는 회로의 GND에만 물립니다. 콘센트에 꽂는 장비의 집게는 건물의 접지에 이어져 있어서, 다른 곳에 물리면 그 자리가 접지에 합선됩니다([「접지 집게가 닿는 곳」](#/read/scope/pb-ground))
- **프로브의 배율을 맞춘다**: 프로브의 스위치와 채널 설정의 배율이 같은지 봅니다. 10배로 두고, 보정용 네모파가 반듯한지 확인합니다([「1배와 10배, 보정」](#/read/scope/pb-x10))
- **재는 점을 고른다**: 받는 칩의 핀 가까이가 기본입니다. 저항이 큰 마디라면 프로브가 값을 바꾼다는 것을 셈에 넣습니다([「어디에 대야 하나: 측정점 고르기」](#/read/scope/pb-points), [「프로브가 회로를 바꾼다」](#/read/scope/pb-loading))

## 화면을 세우는 순서

- **DC 결합으로 시작한다**: 0V의 자리가 보여야 높이를 읽을 수 있습니다. AC 결합은 큰 전압 위의 작은 물결을 볼 때에만 씁니다([「DC 결합, AC 결합, 접지 기준선」](#/read/scope/sc-coupling))
- **V/칸과 시간/칸을 기대한 값에서 고른다**: 아래의 셈처럼 높이가 여섯 칸 안에, 보고 싶은 시간이 열 칸 안에 들게 합니다([「칸, V/칸, 시간/칸」](#/read/scope/sc-grid))
- **트리거의 소스, 레벨, 모드를 차례로 정한다**: 소스는 보고 있는 채널이나 묶음의 시작을 알리는 선, 레벨은 파형의 가운데입니다. 자동 모드로 신호를 찾고, 드문 사건은 일반이나 단발로 기다립니다([「에지 트리거와 레벨」](#/read/scope/tr-edge), [「자동, 일반, 단발」](#/read/scope/tr-modes))
- **멈추고 읽는다**: 흐르는 화면에서 눈으로 어림하지 않습니다. 멈춘 화면에 커서를 놓습니다([「커서와 자동 측정」](#/read/scope/sc-cursors))

```python
import math

def step_125(x):                         # x보다 작지 않은 가장 가까운 1, 2, 5 값
    e = 10 ** math.floor(math.log10(x))
    return next(m * e for m in (1, 2, 5, 10) if m * e >= x * 0.999)

def eng(x, unit):
    for scale, prefix in ((1, ""), (1e-3, "m"), (1e-6, "µ"), (1e-9, "n")):
        if x >= scale * 0.999:
            return f"{x / scale:g}{prefix}{unit}"

def settings(what, span, height):        # 화면에 담을 시간과, 신호의 높이
    tdiv = step_125(span / 10)           # 가로 열 칸에 담기게
    vdiv = step_125(height / 6)          # 세로 여덟 칸 가운데 여섯 칸 안에 들게
    print(f"{what}: {eng(tdiv, 's')}/칸, {eng(vdiv, 'V')}/칸")

settings("서보의 펄스 두 주기", 2 / 50, 3.3)
settings("UART 9600bps의 글자 하나 반", 15 / 9600, 3.3)
settings("I2C 100kHz의 주소 바이트와 ACK", 12 / 100e3, 3.3)
settings("SPI 1MHz의 두 바이트", 18 / 1e6, 3.3)
settings("정류한 전원의 리플 여섯 주기(AC 결합)", 6 / 120, 0.71)
settings("전원이 켜지는 0.5초", 0.5, 3.3)
```

```text
서보의 펄스 두 주기: 5ms/칸, 1V/칸
UART 9600bps의 글자 하나 반: 200µs/칸, 1V/칸
I2C 100kHz의 주소 바이트와 ACK: 20µs/칸, 1V/칸
SPI 1MHz의 두 바이트: 2µs/칸, 1V/칸
정류한 전원의 리플 여섯 주기(AC 결합): 5ms/칸, 200mV/칸
전원이 켜지는 0.5초: 50ms/칸, 1V/칸
```

- **이 책의 그림들이 쓴 값이다**: 여섯 줄 모두 앞의 쪽들에서 그 신호를 그릴 때 쓴 칸 값과 같습니다. 기대한 주기와 높이만 알면 손잡이를 돌리기 전에 자리를 정할 수 있습니다
- **자동 설정 단추는 그다음이다**: 자동으로 맞춰 주는 단추는 편하지만 무엇을 기준으로 맞췄는지 알려 주지 않습니다. 기대한 값과 견주어 본 뒤에 믿습니다

## 읽을 때 묻는 것

| 묻는 것 | 볼 곳 |
| --- | --- |
| 0V는 어디이고 한 칸은 얼마인가 | 화면 구석의 칸 값과 배율, 채널의 0V 표시 |
| 평평한 곳은 문턱에서 얼마나 떨어져 있나 | [「논리 레벨과 문턱」](#/read/scope/bs-levels) |
| 변은 곧은가, 휘었나, 울리나 | [「RC 충전 곡선과 시정수」](#/read/scope/sh-rc), [「링잉과 오버슈트」](#/read/scope/sh-ringing) |
| 늘 그런가, 가끔 그런가 | [「펄스 폭 트리거로 드문 사건 잡기」](#/read/scope/tr-pulse) |
| 장비나 프로브가 만든 모양은 아닌가 | [「대역폭과 상승 시간」](#/read/scope/lm-bandwidth), [「샘플링 속도와 에일리어싱」](#/read/scope/lm-sampling) |

- **하나를 바꾸고 다시 본다**: 접지를 짧게 하거나, 시간/칸을 한 단 바꾸거나, 재는 점을 옮겨 봅니다. 그때 모양이 달라지면 회로가 아니라 재는 쪽이 만든 것입니다
- **다른 채널에 짝이 될 신호를 물린다**: 이상한 것이 늘 어떤 신호의 변 바로 뒤에 온다면 범인이 좁혀집니다([「잡음과 접지 루프」](#/read/scope/sh-noise))

## 화면을 남겨 도움을 청할 때

화면 한 장만으로는 한 칸이 얼마인지, 프로브가 몇 배인지, 어디를 쟀는지 알 수 없습니다. 사람에게 묻든 AI에게 묻든 아래의 것을 함께 적어야 화면이 읽힙니다.

```text
회로: 회로도나 배선 사진, 부품의 값, 전원 전압
재는 점: 어느 부품의 어느 다리인가, 접지 집게는 어디에 물렸나
프로브: 1배인가 10배인가, 채널 설정의 배율은 얼마인가
화면 설정: V/칸, 시간/칸, DC 결합인가 AC 결합인가, 트리거의 소스와 레벨과 모드
기대한 것: 높이, 주기나 속도, 모양
본 것: 어디가 어떻게 다른가, 늘 그런가 가끔 그런가
해 본 것: 접지를 짧게, 다른 점에서, 시간/칸을 바꿔서
```

- **화면은 장비의 저장 기능으로 남긴다**: 디지털 장비는 대개 화면 그림을 USB 메모리에 저장합니다. 그 그림에는 칸 값과 트리거 설정이 함께 찍힙니다
- **휴대폰으로 찍는다면 구석까지 담는다**: 파형만 크게 찍으면 화면 구석의 숫자가 잘립니다. 화면 전체가 반듯하게 들어가게 찍습니다
- **값도 함께 남긴다**: 파형을 CSV 파일로 내보낼 수 있으면 같이 보냅니다. 받는 쪽이 숫자로 주기와 높이를 다시 셈할 수 있습니다
- **넓게 본 것과 좁게 본 것 두 장**: 여러 주기가 담긴 화면 한 장과 문제의 변 하나를 늘린 화면 한 장이 있으면, 무엇이 되풀이되고 무엇이 그렇지 않은지가 드러납니다

## 정리

- 물리기 전에 기대하는 모양, 전압의 범위, 접지 집게의 자리, 프로브의 배율, 재는 점을 정한다
- 화면은 DC 결합, 칸 값, 트리거의 순서로 세우고, 멈춘 뒤에 커서로 읽는다. 이상하면 하나만 바꾸고 다시 본다
- 화면을 남에게 보일 때에는 회로, 재는 점, 프로브, 설정, 기대한 것과 본 것을 함께 적는다
