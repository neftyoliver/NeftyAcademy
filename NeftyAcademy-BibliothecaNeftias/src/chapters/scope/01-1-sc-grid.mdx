- **눈금은 가로 10칸, 세로 8칸**: 흔한 장비의 눈금입니다. 세로가 10칸이거나 가로가 더 넓은 장비도 있으니, 가진 장비의 칸을 한 번 세어 봅니다
- **가로는 시간, 세로는 전압**: 왼쪽이 먼저 일어난 일이고 오른쪽이 나중입니다. 위로 갈수록 전압이 높습니다
- **칸당 값은 화면에 적혀 있다**: 손잡이를 돌리면 "1V/칸", "0.2ms/칸" 같은 값이 화면 아래나 위에 나옵니다. 영어로는 V/div, s/div입니다
- **왼쪽의 작은 세모가 0V다**: 채널 번호가 붙은 표시가 그 채널의 0V 높이를 가리킵니다. 그림에서는 가운데보다 두 칸 아래에 있습니다

## 칸 수에 칸당 값을 곱한다

읽는 방법은 하나입니다. 칸을 세고, 칸당 값을 곱합니다.

```python
# 위 그림을 읽는다
v_div, t_div = 1.0, 0.2e-3          # 1V/칸, 0.2ms/칸
high_divs = 3.3                     # 0V 표시에서 윗변까지 3.3칸
period_divs = 5.0                   # 올라가는 변에서 다음 올라가는 변까지 5칸
on_divs = 2.5                       # 윗변의 길이 2.5칸

high = high_divs * v_div
period = period_divs * t_div
print(f"높이 {high:.1f}V")
print(f"주기 {period * 1e3:.1f}ms, 주파수 {1 / period:.0f}Hz")
on = on_divs * t_div
print(f"켜진 시간 {on * 1e3:.1f}ms, 듀티 {100 * on / period:.0f}%")
print(f"화면 전체는 가로 {10 * t_div * 1e3:.0f}ms, 세로 {8 * v_div:.0f}V")
```

```text
높이 3.3V
주기 1.0ms, 주파수 1000Hz
켜진 시간 0.5ms, 듀티 50%
화면 전체는 가로 2ms, 세로 8V
```

- **전압은 0V 표시에서 센다**: 윗변이 0V 표시보다 3.3칸 위에 있으므로 3.3V입니다. 가운데 줄에서 세면 틀립니다
- **주기는 같은 모양이 돌아올 때까지**: 올라가는 변에서 다음 올라가는 변까지가 한 주기입니다. 주파수는 주기의 역수입니다
- **작은 눈금으로 소수점을 읽는다**: 가운데 가로줄과 세로줄에는 한 칸을 다섯으로 나눈 작은 눈금이 있는 장비가 많습니다. 한 눈금이 0.2칸입니다
- **눈으로 읽으면 0.1칸쯤 틀린다**: 3.3칸인지 3.2칸인지는 눈으로 가리기 어렵습니다. 정확한 숫자가 필요하면 커서나 자동 측정을 씁니다([「커서와 자동 측정」](#/read/scope/sc-cursors))

## 알맞은 칸당 값

같은 신호를 칸당 값만 바꿔서 본 화면입니다.

<Figure caption="같은 신호를 세로 5V/칸, 가로 2ms/칸으로 본 화면">
  <Scope tdiv={2e-3} dt={5e-5} traces={[{ name: 'CH1 GPIO 17', data: squareFar, vdiv: 5, pos: -2 }]} />
</Figure>

- **너무 크게 잡으면 납작하다**: 5V/칸에서는 3.3V가 0.66칸입니다. 0.1칸을 틀리면 0.5V를 틀립니다
- **너무 촘촘하면 셀 수 없다**: 2ms/칸에서는 한 칸에 두 주기가 들어가 변이 붙어 보입니다
- **화면의 반 넘게 채운다**: 세로는 신호가 화면 높이의 반에서 4분의 3쯤을 차지하게, 가로는 한두 주기에서 서너 주기가 보이게 맞춥니다
- **칸당 값은 1, 2, 5로 바뀐다**: 손잡이는 1, 2, 5, 10, 20, 50처럼 넘어갑니다. 3.3V 신호에는 1V/칸이나 0.5V/칸이 맞습니다
- **화면 밖으로 나가면 잘린다**: 0.2V/칸으로 보면 3.3V는 16.5칸이라 윗변이 화면 밖입니다. 잘린 파형을 보고 값을 읽으면 안 됩니다
- **위치 손잡이로 옮긴다**: 세로 위치는 0V 표시를, 가로 위치는 시간의 기준을 옮깁니다. 칸당 값은 바뀌지 않습니다

<Note>
이 쪽의 화면은 진짜 장비를 찍은 것이 아니라, 0V와 3.3V를 0.5ms씩 오가는 값을 계산해 그린 그림입니다. 진짜 핀의 신호는 변이 완전히 곧지 않고 모서리가 조금 튀는데, 그 모양은 뒤의 장에서 봅니다. 눈금의 수와 작은 눈금의 생김새는 장비마다 다릅니다. 이 책은 가로 10칸, 세로 8칸으로 통일합니다.
</Note>

## 정리

- 화면의 값은 칸 수에 칸당 값을 곱해 읽는다. 전압은 그 채널의 0V 표시에서부터 센다
- 주기는 같은 모양이 돌아올 때까지의 칸 수에 시간/칸을 곱한 것이고, 주파수는 그 역수다
- 신호가 화면의 반 넘게 차도록 칸당 값을 고른다. 납작하거나 잘린 화면에서는 값을 읽지 않는다
