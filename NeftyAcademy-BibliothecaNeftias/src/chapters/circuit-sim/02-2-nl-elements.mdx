넷리스트의 줄 대부분은 소자 줄입니다. 이 쪽은 가장 바탕이 되는 다섯 가지, 곧 저항과 커패시터와 인덕터, 전압원과 전류원을 봅니다. 줄의 생김새는 다섯이 모두 같습니다. 달라지는 것은 마디를 적는 차례가 무엇을 뜻하느냐입니다.

## 줄의 생김새

| 첫 글자와 소자 | 줄 | 값의 단위 |
| --- | --- | --- |
| `R` 저항 | `R1 a b 4.7k` | Ω |
| `C` 커패시터 | `C1 a b 100n` | F |
| `L` 인덕터 | `L1 a b 10m` | H |
| `V` 전압원 | `V1 a b 5` | V |
| `I` 전류원 | `I1 a b 2m` | A |

- **첫 글자가 종류다**: `Rpull`, `R_load`, `R17`은 모두 저항입니다. 이름은 한 넷리스트 안에서 하나뿐이어야 하고, 같은 이름을 두 번 쓰면 오류로 멈춥니다
- **그 뒤는 마디 둘과 값이다**: 단위는 적지 않습니다. 종류가 단위를 정합니다. `k`, `m`, `n` 같은 접미사는 [「접미사와 단위의 함정」](#/read/circuit-sim/nl-units)에서 따로 봅니다
- **저항은 마디의 차례가 답을 바꾸지 않는다**: `R1 in out 10k`를 `R1 out in 10k`로 적어도 마디 전압은 같습니다. 소자의 표에 나오는 전류의 부호만 뒤집힙니다
- **전압원과 전류원은 차례가 곧 방향이다**: 아래에서 하나씩 돌려 봅니다
- **다른 글자들**: `D`는 다이오드, `Q`는 트랜지스터, `M`은 MOSFET, `X`는 여러 소자를 묶은 하위 회로입니다. 4장에서 씁니다([「다이오드와 .model」](#/read/circuit-sim/dv-diode))

## 전압원의 방향과 전류의 부호

<Figure caption="전압원 둘이 든 회로. 넷리스트에 먼저 적은 마디가 +다. Vsense는 0V라서 mid와 a를 그대로 잇는다">
  <Circuit spec="V 0,2 0,0 V1 5V; W 0,0 0.5,0; O 0.5,0 ^in; R 0.5,0 2,0 R1 1kΩ; O 2,0 ^mid; V 3.5,0 2,0 Vsense 0V; O 3.5,0 ^a; R 3.5,0 3.5,2 R2 2kΩ; W 3.5,0 5,0; R 5,0 5,2 R3 3kΩ; W 5,2 0,2; D 3.5,2; G 0,2" label="5볼트 전원 V1에서 마디 in, 1킬로옴 R1, 마디 mid, 0볼트 전압원 Vsense, 마디 a로 이어지고, a에서 2킬로옴 R2와 3킬로옴 R3이 나란히 접지로 가는 회로. Vsense의 플러스는 mid 쪽이다" />
</Figure>

```spice
전압원의 전류와, 전류를 재는 0V 전압원
V1 in 0 5
R1 in mid 1k
Vsense mid a 0
R2 a 0 2k
R3 a 0 3k
.op
.end
```

```text
$ ngspice -b ammeter.cir
a               2.727273e+00
mid             2.727273e+00
in              5.000000e+00
v1#branch       -2.27273e-03
vsense#branch   2.272727e-03
```

- **첫 마디가 +다**: `V1 in 0 5`는 `in`이 접지보다 5V 높다는 뜻입니다. `V1 0 in 5`로 적으면 `in`은 −5V가 됩니다
- **+에서 전원 속을 지나 −로 가는 전류가 양이다**: 회로에 전류를 내주는 전원의 속에서는 전류가 −에서 +로 흐릅니다. 그래서 `v1#branch`가 −2.27mA입니다
- **0V 전압원은 전류계다**: `Vsense mid a 0`은 두 마디를 그대로 이어 놓고(두 마디의 전압이 같습니다) 그 사이를 지나는 전류를 표에 올립니다. `mid`에서 `a`로 흐르는 2.27mA가 양수로 나옵니다
- **손으로 센 값**: 2kΩ과 3kΩ을 나란히 두면 1.2kΩ입니다. 5V ÷ 2.2kΩ은 2.2727mA이고, `a`는 2.2727mA × 1.2kΩ인 2.727V입니다
- **가지 하나의 전류를 재려면**: 그 가지에 0V 전압원을 한 줄로 끼웁니다. `R2`의 전류만 보려면 `R2 a 0 2k`를 `Vs2 a a2 0`과 `R2 a2 0 2k`로 바꿉니다

## 전류원의 방향

```spice
전류원이 미는 방향
I1 0 out 1m
R1 out 0 1k
.op
.end
```

```text
$ ngspice -b isource.cir
out         1.000000e+00
```

- **첫 마디에서 전류원 속을 지나 둘째 마디로 흐른다**: `I1 0 out 1m`은 접지에서 퍼 올린 1mA를 `out`으로 밀어 넣습니다. 1mA × 1kΩ이라 1V입니다
- **거꾸로 적으면 끌어간다**: `I1 out 0 1m`으로 적으면 `out`은 −1V가 됩니다
- **전압원과 같은 약속이다**: 둘 다 첫 마디에서 소자 속을 지나 둘째 마디로 가는 쪽이 양입니다
- **부하를 흉내 낼 때 쓴다**: 5V 전원에 10Ω을 거쳐 `Iload out 0 20m`을 달면 `out`에서 20mA를 끌어가는 부하가 됩니다. 돌려 보면 `out`이 4.8V입니다. 전원 회로가 전류를 내줄 때 전압이 얼마나 떨어지는지 이렇게 봅니다

## 동작점에서의 커패시터와 인덕터

```spice
동작점에서의 커패시터와 인덕터
V1 in 0 5
R1 in a 1k
C1 a 0 1u
R2 in b 1k
L1 b 0 10m
.op
.end
```

```text
$ ngspice -b clop.cir
b           0.000000e+00
a           5.000000e+00
in          5.000000e+00
v1#branch   -5.00000e-03
l1#branch   5.000000e-03
```

- **커패시터는 끊긴 곳이다**: 다 자리 잡고 나면 커패시터로는 전류가 흐르지 않습니다. `R1`에 전류가 없으니 `a`는 5V입니다
- **인덕터는 이어진 선이다**: `b`는 접지와 같은 0V이고, `R2`에 5mA가 흐릅니다. 인덕터의 전류는 `l1#branch`로 표에 나옵니다
- **값이 답에 나타나지 않는다**: 1µF와 10mH를 다른 값으로 바꿔도 동작점은 같습니다. 두 소자의 값은 시간이 흐르는 해석에서 드러납니다([「과도 해석 (.tran)」](#/read/circuit-sim/an-tran))

## 직류가 흐를 길이 없는 마디

```spice warns
커패시터 둘 사이의 마디
V1 in 0 5
C1 in mid 1u
C2 mid 0 1u
.op
.end
```

```text
$ ngspice -b floating.cir
Warning: singular matrix:  check node mid
...
mid         2.500000e+00
```

- **마디마다 접지까지 직류가 흐를 길이 있어야 한다**: `mid`에는 커패시터만 달려 있습니다. 동작점에서 커패시터는 끊긴 곳이므로 `mid`는 어디에도 이어지지 않은 마디입니다
- **ngspice 42는 경고를 내고 2.5V라고 답했다**: 이 숫자를 믿으면 안 됩니다. 실제 회로에서 이 마디의 전압은 처음에 쌓여 있던 전하와 새는 전류가 정합니다
- **새는 길을 적어 주면 답이 정해진다**: `Rleak mid 0 1G`를 더하면 경고 없이 0V가 나오고, `Rleak in mid 1G`를 더하면 5V가 나옵니다. 어느 쪽으로 새는지를 내가 정해 준 것입니다
- **반대쪽 규칙도 있다**: 전압원과 인덕터만으로 닫힌 고리는 만들 수 없습니다. `V1 a 0 5`와 `V2 a 0 3`을 나란히 적으면 `The operating point could not be simulated successfully`라는 오류로 멈춥니다
- **이런 오류를 읽는 법**: [「수렴 실패와 흔한 오류」](#/read/circuit-sim/ng-errors)에서 모아서 봅니다

<Note>
이 쪽의 넷리스트 넷과, 글머리에 적은 숫자들(−5V, −1V, 4.8V, 새는 저항을 단 0V와 5V, 나란한 전압원의 오류, 마디를 바꿔 적은 저항)은 모두 ngspice 42로 돌려 확인했습니다. 출력은 필요한 줄만 옮겼고, 소자의 값은 제가 고른 것입니다. 커패시터 둘 사이의 마디가 2.5V로 나온 것은 ngspice 42에서 본 결과이고, 다른 판이나 다른 프로그램은 다른 숫자를 내거나 오류로 끝날 수 있습니다.
</Note>

## 정리

- 소자 줄은 이름, 마디 둘, 값이다. 이름의 첫 글자가 종류를 정하고 단위는 적지 않는다
- 전압원은 첫 마디가 +이고, 전류원은 첫 마디에서 둘째 마디로 전류를 민다. 전류를 내주는 전원의 전류는 음수로 나온다
- 동작점에서 커패시터는 끊긴 곳이고 인덕터는 이어진 선이다. 마디마다 접지까지 직류가 흐를 길이 있어야 한다
