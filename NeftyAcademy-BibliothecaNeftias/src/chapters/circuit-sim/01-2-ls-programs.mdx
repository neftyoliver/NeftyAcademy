회로 시뮬레이터라고 불리는 프로그램은 많습니다. 이 쪽은 자주 만나는 여섯을 한자리에 놓고 성격을 가릅니다. 여섯은 크게 두 무리입니다. SPICE의 넷리스트를 받아 셈하는 것이 넷, 넷리스트 없이 화면에서 바로 꽂아 보는 것이 둘입니다.

## 여섯 프로그램

| 프로그램 | 무엇인가 | 도는 곳, 값과 소스 |
| --- | --- | --- |
| ngspice | 넷리스트를 받아 셈하는 엔진 | 윈도우, macOS, 리눅스. 무료, 소스 공개 |
| LTspice | 회로도 편집기, 엔진, 파형 창이 한 몸 | 윈도우, macOS. 무료, 소스 비공개 |
| KiCad | 회로도와 기판 설계 도구. 안에 ngspice가 들었다 | 윈도우, macOS, 리눅스. 무료, 소스 공개 |
| Qucs-S | 회로도 편집기. 엔진은 ngspice 같은 것을 따로 깐다 | 윈도우, macOS, 리눅스. 무료, 소스 공개 |
| Falstad의 시뮬레이터 | 전류가 움직이는 그림으로 보이는 회로 | 웹 브라우저. 무료 |
| Tinkercad Circuits | 브레드보드 그림에 부품을 꽂고 아두이노 코드까지 돌린다 | 웹 브라우저. 무료, 계정 필요 |

## 넷리스트를 받는 넷

- **ngspice**: 화면에 그리는 도구가 없습니다. 넷리스트 파일을 주면 셈해서 숫자와 파형을 내놓습니다. 다른 프로그램의 속에 엔진으로 들어가는 일이 많고, 글로만 다루므로 되풀이해 돌리거나 스크립트로 엮기에 좋습니다([「배치 실행과 대화형」](#/read/circuit-sim/ng-run))
- **LTspice**: 회로도를 그리고, 돌리고, 선을 눌러 파형을 보는 일을 한 창에서 합니다. Analog Devices의 부품 모델이 함께 들어 있습니다. 엔진은 SPICE를 고쳐 만든 이 회사의 것입니다([「회로도 그리기」](#/read/circuit-sim/lt-schematic))
- **KiCad**: 기판을 만드는 도구입니다. 회로도 편집기에 시뮬레이터 창이 달려 있어서, 기판으로 만들 바로 그 회로도를 돌려 봅니다. 셈은 안에 든 ngspice가 합니다([「회로도와 시뮬레이션 모델 붙이기」](#/read/circuit-sim/kc-schematic))
- **Qucs-S**: 회로도를 그리는 화면만 맡고, 셈은 따로 깐 ngspice나 Xyce에 넘깁니다. ngspice를 그림으로 다루고 싶을 때의 한 가지 길입니다

## 화면에서 바로 꽂는 둘

- **Falstad의 시뮬레이터**: 브라우저에서 열자마자 회로가 돕니다. 초록은 양의 전압, 빨강은 음의 전압, 회색은 접지이고, 움직이는 노란 점이 전류입니다. 부품의 값을 바꾸면 그 자리에서 달라지므로, 회로가 왜 그렇게 도는지를 눈으로 익히는 데에 좋습니다
- **Tinkercad Circuits**: Autodesk의 웹 도구입니다. 브레드보드 그림에 부품을 꽂고, 아두이노 보드에 코드를 넣어 함께 돌립니다. 멀티미터와 오실로스코프도 부품처럼 꽂습니다. 부품의 가짓수는 많지 않습니다
- **둘 다 숫자를 믿는 도구는 아니다**: 제조사의 모델을 넣어 "이 부품으로 이 회로가 되는가"를 따지는 일은 앞의 넷이 합니다. 이 둘은 개념을 잡고 배선을 미리 그려 보는 데에 씁니다

## 무엇이 같고 무엇이 다른가

| | 넷리스트를 받는 넷 | 화면에서 꽂는 둘 |
| --- | --- | --- |
| 회로를 적는 법 | 넷리스트, 또는 넷리스트로 바뀌는 회로도 | 화면의 그림 |
| 부품의 모델 | 제조사가 내놓는 SPICE 모델을 쓴다 | 프로그램에 든 부품만 쓴다 |
| 결과 | 숫자와 파형. 파일로 남는다 | 움직이는 화면 |
| 맞는 일 | 값을 정하고 확인하기 | 개념 익히기, 배선 미리 보기 |

- **넷리스트는 넷 사이를 오간다**: ngspice에서 돌린 넷리스트의 부품 줄과 `.tran` 같은 줄은 LTspice와 KiCad에서도 거의 그대로 통합니다. 프로그램마다 따로 있는 명령만 갈아 끼웁니다([「무엇을 고를까」](#/read/circuit-sim/ls-choose))
- **회로도는 오가지 않는다**: LTspice의 회로도 파일과 KiCad의 회로도 파일은 서로 다른 형식입니다. KiCad에는 LTspice의 회로도를 읽어 들이는 기능이 있습니다
- **라즈베리파이의 코드를 돌려 주는 것은 없다**: 여섯 가운데 리눅스가 도는 보드를 통째로 흉내 내는 것은 없습니다. 핀에 이어지는 분배기, 필터, 트랜지스터 같은 바깥 회로를 돌려 봅니다

## 정리

- ngspice, LTspice, KiCad, Qucs-S는 SPICE의 넷리스트로 셈한다. KiCad와 Qucs-S의 셈은 ngspice가 한다
- Falstad의 시뮬레이터와 Tinkercad Circuits는 브라우저에서 바로 꽂아 보는 도구다. 개념과 배선을 익히는 데에 쓴다
- 넷리스트는 프로그램 사이를 오가지만 회로도 파일은 그렇지 않다. 판에 따라 달라지는 것은 화면과 메뉴다
