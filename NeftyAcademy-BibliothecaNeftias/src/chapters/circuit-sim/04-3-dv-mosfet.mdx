MOSFET은 트랜지스터와 같은 자리에 쓰지만, 켜는 것이 전류가 아니라 전압입니다. 게이트에는 전류가 흐르지 않습니다. 그 대신 "이 게이트 전압으로 다 켜지는가"가 가장 먼저 확인할 일이 됩니다.

## 스위치 하나

<Figure caption="3.3V 핀(g)이 5V에 물린 50Ω 부하를 켜는 회로. 게이트에는 저항이 없어도 된다">
  <Circuit spec="V 0,3 0,0 V1 5V; W 0,0 4,0; R 4,0 4,2 R1 50Ω; M 4,2 4,3 M1; O 4,2 d; O 2,2.5 ^g; W 2,2.5 3.5,2.5; W 4,3 0,3; G 0,3" label="5볼트 전원에서 50옴 부하 R1을 지나 MOSFET M1의 드레인(마디 d)으로 이어지고, 소스는 접지에 닿으며, 입력 g가 게이트로 바로 들어가는 회로" />
</Figure>

```spice
MOSFET 스위치: 3.3V로 5V의 50Ω 켜기
V1 vcc 0 5
VG g 0 3.3
R1 vcc d 50
M1 d g 0 0 N7002
.model N7002 NMOS(LEVEL=1 VTO=2.1
+ KP=0.44 RD=0.91)
.op
.end
```

```text
$ ngspice -b mosfet.cir
d           2.804066e-01
vg#branch   0.000000e+00
...
device         m1
id      0.0943777
ig              0
vgs           3.3
von           2.1
```

- **`M1 드레인 게이트 소스 몸통 모델이름`**: 마디가 넷입니다. 낱개로 파는 부품은 몸통이 소스에 이어져 있으므로 소스와 같은 마디를 적습니다
- **게이트에는 전류가 흐르지 않는다**: `vg#branch`와 `ig`가 0입니다. 핀이 내줄 전류를 셈할 필요가 없습니다. 다만 켜고 끄는 순간에는 게이트의 커패시턴스를 채우고 비우는 전류가 잠깐 흐르는데, 이 모델에는 그 커패시턴스를 넣지 않았습니다
- **켜졌을 때는 작은 저항이다**: 94.4mA가 흐를 때 드레인이 0.28V입니다. 3Ω쯤 되는 저항처럼 굴고, MOSFET은 26mW를 열로 냅니다
- **모델의 숫자 셋**: `VTO`는 켜지기 시작하는 문턱 전압, `KP`는 켜지는 세기, `RD`는 드레인에 한 줄로 든 저항입니다. onsemi의 2N7002 데이터시트에 적힌 대푯값 셋(문턱 2.1V, 게이트 10V에서 1.2Ω, 5V에서 1.7Ω)에 맞도록 제가 정한 값입니다

## 다 켜지는가

<Figure caption="게이트 전압을 0V에서 5V까지 올릴 때 드레인의 전압. 문턱이 2.1V인 것과 3V인 것">
  <Plot x={mosVg} xUnit="V" xName="게이트 g" yUnit="V" yName="드레인" series={[{ name: '문턱 2.1V', data: mosVdLow }, { name: '문턱 3V', data: mosVdHigh }]} vmarks={[{ at: 3.3, label: '3.3V' }]} />
</Figure>

```spice
문턱이 다른 MOSFET 둘의 게이트를 훑기
V1 vcc 0 5
VG g 0 3.3
R1 vcc d1 50
M1 d1 g 0 0 N7002
R2 vcc d2 50
M2 d2 g 0 0 NHI
.model N7002 NMOS(LEVEL=1 VTO=2.1
+ KP=0.44 RD=0.91)
.model NHI NMOS(LEVEL=1 VTO=3
+ KP=0.44 RD=0.91)
.dc VG 0 5 0.01
.meas dc d1_33 FIND v(d1) AT=3.3
.meas dc d2_33 FIND v(d2) AT=3.3
.meas dc d2_50 FIND v(d2) AT=4.99
.end
```

```text
$ ngspice -b gate-sweep.cir
d1_33 = 2.804366e-01
d2_33 = 4.010000e+00
d2_50 = 2.001902e-01
```

- **문턱이 2.1V인 것은 3.3V에서 다 켜진다**: 드레인이 0.28V까지 내려옵니다
- **문턱이 3V인 것은 3.3V에서 켜지다 만다**: 드레인이 4.01V에 머뭅니다. 부하에는 1V도 걸리지 않고 20mA만 흐르며, 나머지 전압을 MOSFET이 떠안아 79mW를 열로 냅니다. 스위치가 아니라 전류를 조이는 꼭지가 되었습니다
- **같은 것이 5V에서는 다 켜진다**: 게이트가 5V이면 0.20V입니다. 문턱을 넘겼다는 것과 다 켜졌다는 것은 다릅니다
- **데이터시트에서 볼 것**: 켜졌을 때의 저항이 어떤 게이트 전압에서 잰 값인지를 봅니다. 2N7002는 5V와 10V에서 잰 값만 적혀 있습니다. 3.3V로 켤 부품은 그 전압이나 더 낮은 전압에서 잰 저항이 적힌 것을 고릅니다
- **부품마다 문턱이 다르다**: 2N7002의 문턱은 1V에서 2.5V 사이라고 적혀 있습니다. 모델의 `VTO`를 2.5로 바꿔 돌리면 드레인이 0.41V로 올라갑니다. 대푯값으로 맞춘 모델 하나의 답은 그 범위의 한가운데일 뿐입니다([「부품 오차와 몬테카를로」](#/read/circuit-sim/ts-tolerance))

## 모델의 꼴

- **`NMOS`와 `LEVEL=1`**: 위의 모델은 가장 단순한 꼴입니다. 숫자 셋으로 스위치의 모습은 흉내 내지만 그 밖의 것은 담지 못합니다
- **`VDMOS`**: 전력 MOSFET을 위한 종류입니다. LTspice에서 먼저 쓰였고 ngspice도 이 꼴을 읽습니다. `.model N7002V VDMOS(Vto=2.1 Kp=0.44 Rd=0.91)`로 적고 `M1 d g 0 N7002V`처럼 마디 셋으로 부르면 같은 0.28V가 나옵니다
- **제조사의 모델은 대개 하위 회로다**: MOSFET 하나에 저항, 다이오드, 커패시터를 덧붙여 한 덩어리로 만든 것입니다. `M`이 아니라 `X`로 부릅니다([「.subckt와 제조사 모델 가져오기」](#/read/circuit-sim/dv-subckt))
- **몸통의 다이오드**: MOSFET을 거꾸로 걸면 소스에서 드레인으로 다이오드처럼 전류가 흐릅니다. 위 모델에 1V를 10Ω을 거쳐 거꾸로 걸면 0.76V에서 24mA가 흐릅니다. 꺼 두어도 이 길은 열려 있습니다

<Note>
넷리스트 둘과 그림은 ngspice 42로 돌린 결과이고, `VTO`를 2.5로 바꾼 경우, `VDMOS`로 적은 경우, 거꾸로 건 경우도 따로 돌려 확인했습니다. 모델의 숫자는 onsemi 데이터시트의 대푯값(문턱 2.1V, 1.2Ω, 1.7Ω)에 맞춰 제가 정한 것이고, 제조사가 내놓은 모델이 아닙니다. 맞춘 모델로 다시 재 보면 10V에서 1.20Ω, 5V에서 1.70Ω, 3.3V에서 2.83Ω입니다. 문턱이 3V인 것은 견주려고 `VTO`만 바꾼 가상의 부품입니다. LTspice는 제가 돌려 보지 못했습니다.
</Note>

## 정리

- `M1 드레인 게이트 소스 몸통 모델`로 적는다. 게이트에는 전류가 흐르지 않고, 켜졌을 때는 작은 저항처럼 군다
- 게이트 전압이 문턱을 조금 넘는 것으로는 다 켜지지 않는다. 게이트를 훑어서 쓰려는 전압에서 드레인이 0V 가까이 내려오는지 본다
- 제조사의 MOSFET 모델은 대개 하위 회로이고, 대푯값으로 만든 모델의 답은 부품마다의 차이를 담지 않는다
