$-3$과 3은 방향이 반대일 뿐 0에서 떨어진 거리는 같습니다. 방향을 지우고 거리만 남긴 것이 절댓값입니다. 두 수가 얼마나 떨어져 있는지, 어림한 값이 참값에서 얼마나 벗어났는지를 말할 때마다 절댓값이 나옵니다.

## 0에서 떨어진 거리

<Figure caption="−3과 3은 모두 0에서 세 칸 떨어져 있습니다">
  <NumLine x={[-5.6, 5.6]} step={1} points={[{ at: -3, color: 1 }, { at: 3, color: 0 }]} jumps={[{ from: 0, to: -3, label: '3칸', color: 1, level: 0 }, { from: 0, to: 3, label: '3칸', color: 0, level: 0 }]} />
</Figure>

<Def title="절댓값">

수직선에서 0과 $a$ 사이의 거리를 $a$의 **절댓값**이라고 하고 $|a|$로 적습니다.

$$
|a| = \begin{cases} a & (a \ge 0) \\ -a & (a < 0) \end{cases}
$$

</Def>

- **$|3| = 3$, $|-3| = 3$, $|0| = 0$**: 양수와 0은 그대로이고, 음수는 반대인 수로 바꿉니다
- **둘째 줄의 $-a$는 양수이다**: $a$가 음수일 때 $-a$는 양수입니다([「0과 음수」](#/read/m-numbers/int-negative)). 절댓값은 음수가 되지 않습니다

## 성질

- **0 이상이다**: $|a| \ge 0$이고, $|a| = 0$인 것은 $a = 0$일 때뿐입니다
- **뒤집어도 같다**: $|-a| = |a|$입니다
- **곱은 곱으로**: $|ab| = |a| \, |b|$입니다. 부호를 떼고 곱하나, 곱하고 부호를 떼나 같습니다([「정수의 곱셈과 나눗셈」](#/read/m-numbers/int-mul))
- **사이에 끼운다**: $-|a| \le a \le |a|$입니다. $a$는 $|a|$나 $-|a|$ 가운데 하나이기 때문입니다

## 두 수 사이의 거리

<Def title="두 수 사이의 거리">
수직선에서 $a$와 $b$ 사이의 거리는 $|a - b|$입니다.
</Def>

<Figure caption="−2와 5 사이의 거리는 |−2 − 5| = 7입니다. 어느 쪽에서 빼도 같습니다">
  <NumLine x={[-4.6, 7.6]} step={1} points={[{ at: -2, color: 1 }, { at: 5, color: 0 }]} ranges={[{ from: -2, to: 5, color: 2, label: '7' }]} />
</Figure>

차 $a - b$는 방향이 있는 거리였습니다([「정수의 덧셈과 뺄셈」](#/read/m-numbers/int-add)). 절댓값을 씌우면 방향이 사라져 $|a - b| = |b - a|$입니다. $|a|$는 $a$와 0 사이의 거리 $|a - 0|$입니다.

## 삼각부등식

<Thm title="삼각부등식">
$|a + b| \le |a| + |b|$입니다. 등호는 $a$와 $b$의 부호가 같거나 어느 하나가 0일 때 성립합니다.
</Thm>

<Proof>

$-|a| \le a \le |a|$와 $-|b| \le b \le |b|$를 변끼리 더하면

$$
-(|a| + |b|) \le a + b \le |a| + |b|
$$

입니다. $a + b$가 $|a| + |b|$와 그 반대인 수 사이에 있으므로, 0에서 $a + b$까지의 거리는 $|a| + |b|$를 넘지 않습니다.

</Proof>

- **부호가 같으면**: 같은 방향으로 두 번 뛰므로 거리가 그대로 더해집니다. $|3 + 4| = 7$
- **부호가 다르면**: 갔다가 되돌아오므로 0에서 덜 멀어집니다. $|3 + (-4)| = 1$이고 $|3| + |-4| = 7$입니다
- **이름의 까닭**: 평면에서는 "삼각형의 한 변은 다른 두 변의 합보다 길지 않다"가 됩니다. 거리라는 것이 갖춰야 할 성질의 하나로, 해석학에서 내내 쓰입니다([「거리」](#/read/m-metric-spaces/metric))

## 절댓값이 든 식을 거리로 읽기

<Figure caption="|x − 2| < 3. 2에서 세 칸보다 가까운 수는 −1과 5 사이에 있습니다. 양 끝은 들지 않습니다">
  <NumLine x={[-3.6, 7.6]} step={1} points={[{ at: 2, color: 1 }]} ranges={[{ from: -1, to: 5, open: [true, true], color: 0 }]} />
</Figure>

| 식 | 거리로 읽으면 | 뜻 |
| --- | --- | --- |
| $|x| = 3$ | 0에서 꼭 세 칸 | $x = 3$ 또는 $x = -3$ |
| $|x| < 3$ | 0에서 세 칸보다 가깝다 | $-3 < x < 3$ |
| $|x - 2| < 3$ | 2에서 세 칸보다 가깝다 | $-1 < x < 5$ |

<Ex title="정수로 답하기">
$|x - 2| < 3$인 정수 $x$를 모두 구하세요.

<Sol>

2에서 세 칸보다 가까운 정수이므로 $-1 < x < 5$, 곧 $0, 1, 2, 3, 4$입니다.

</Sol>
</Ex>

절댓값이 든 방정식과 부등식은 이렇게 "어디에서 얼마나 떨어져 있나"로 읽으면 경우를 나누지 않고도 풀립니다([「부등식」](#/read/m-equations/inequality)).

## 컴퓨터의 정수에서는

C의 `int`가 32비트일 때 담을 수 있는 수는 $-2147483648$부터 $2147483647$까지입니다. 가장 작은 수의 절댓값 $2147483648$은 `int`에 담을 수 없습니다. 그래서 `abs(INT_MIN)`은 정해진 답이 없는 동작입니다. 수학의 정수와 달리 컴퓨터의 정수는 범위가 있고, 음수 쪽이 하나 더 많습니다.

<Note>
성질 넷과 삼각부등식, 등호가 성립하는 조건은 −40부터 40까지의 모든 정수 쌍에 넣어 프로그램으로 확인했습니다. $|{-2} - 5| = 7$, 표의 세 줄, 예제의 답 다섯 개도 프로그램으로 확인했습니다. 32비트 `int`의 범위는 $-2^{31}$부터 $2^{31} - 1$까지입니다. `abs`에 그 결과를 나타낼 수 없는 값을 넣었을 때의 동작이 정의되지 않는다는 것은 C 표준의 `abs` 설명에 있습니다.
</Note>

## 요점

- 절댓값 $|a|$는 수직선에서 0과 $a$ 사이의 거리이다. $a$와 $b$ 사이의 거리는 $|a - b|$이다
- 삼각부등식 $|a + b| \le |a| + |b|$는 부호가 다르면 되돌아오는 만큼 덜 멀어진다는 뜻이다
- $|x - c| < r$은 "$c$에서 $r$보다 가깝다"로 읽는다
