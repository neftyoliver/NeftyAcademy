이 책은 수를 넓힐 때마다 "법칙이 그대로 성립하도록" 셈을 정했습니다. 그 법칙을 모아 보면 아홉 줄입니다. 이제 방향을 뒤집습니다. 수가 무엇인지는 묻지 않고, 이 아홉 줄이 성립하는 것이면 무엇이든 같은 방법으로 다룹니다.

## 아홉 가지 규칙

| 덧셈의 규칙 | 식 |
| --- | --- |
| 결합법칙 | $(a + b) + c = a + (b + c)$ |
| 교환법칙 | $a + b = b + a$ |
| 더해도 그대로인 수 | $a + 0 = a$ |
| 되돌리는 수 | $a + (-a) = 0$ |

| 곱셈의 규칙 | 식 |
| --- | --- |
| 결합법칙 | $(ab)c = a(bc)$ |
| 교환법칙 | $ab = ba$ |
| 곱해도 그대로인 수 | $a \times 1 = a$ |
| 되돌리는 수 | $a \times \frac{1}{a} = 1$ |

곱셈을 되돌리는 수, 곧 역수는 $a$가 0이 아닐 때에만 있습니다. 여기에 덧셈과 곱셈을 잇는 분배법칙 $a(b + c) = ab + ac$를 더하면 아홉입니다.

<Def title="체">
덧셈과 곱셈에 닫혀 있고 위의 아홉 규칙이 성립하는 모임을 **체**라고 합니다. 0과 1은 서로 다른 수여야 합니다.
</Def>

| 모임 | 체인가 | 빠진 것 |
| --- | --- | --- |
| 자연수 | 아니다 | 0, 반대인 수, 역수 |
| 정수 | 아니다 | 역수(2의 역수가 정수가 아니다) |
| 유리수 | 체이다 | |
| 실수 | 체이다 | |

뺄셈과 나눗셈은 규칙에 따로 없습니다. 빼는 것은 반대인 수를 더하는 것이고, 나누는 것은 역수를 곱하는 것이기 때문입니다([「정수의 덧셈과 뺄셈」](#/read/m-numbers/int-add), [「분수의 곱셈과 나눗셈」](#/read/m-numbers/rat-mul)).

## 규칙만으로 증명하기

앞에서 그림이나 규칙의 이어짐으로 받아들였던 사실들이 아홉 줄에서 나옵니다.

<Thm title="0을 곱하면 0">
체의 어느 $a$에 대해서도 $a \times 0 = 0$입니다.
</Thm>

<Proof>

$0 + 0 = 0$이므로 분배법칙에 따라

$$
a \times 0 = a \times (0 + 0) = a \times 0 + a \times 0
$$

입니다. 양쪽에 $a \times 0$의 반대인 수를 더하면 $0 = a \times 0$입니다.

</Proof>

<Thm title="곱이 0이면 어느 하나가 0">
체에서 $ab = 0$이면 $a = 0$이거나 $b = 0$입니다.
</Thm>

<Proof>

$a$가 0이 아니라고 하면 역수 $\frac{1}{a}$이 있습니다.

$$
\begin{aligned}
b &= 1 \times b = \left(\frac{1}{a} \times a\right) b \\
&= \frac{1}{a} \times (ab) = \frac{1}{a} \times 0 = 0
\end{aligned}
$$

마지막 등호는 앞의 정리입니다.

</Proof>

음수와 음수의 곱이 양수라는 것도 같은 방법으로 증명했습니다([「정수의 곱셈과 나눗셈」](#/read/m-numbers/int-mul)). 그 증명에서 쓴 것은 분배법칙과 반대인 수뿐이었습니다.

## 규칙 넷 더: 순서

유리수와 실수에는 크기가 있습니다. 순서에 대한 규칙은 넷입니다([「유리수의 크기와 수직선」](#/read/m-numbers/rat-order)).

- **셋 가운데 꼭 하나**: $a < b$, $a = b$, $a > b$ 가운데 하나만 성립한다
- **이어진다**: $a < b$이고 $b < c$이면 $a < c$이다
- **더해도 그대로**: $a < b$이면 $a + c < b + c$이다
- **양수를 곱해도 그대로**: $a < b$이고 $c > 0$이면 $ac < bc$이다

음수를 곱하면 부등호가 뒤집힌다는 것, 제곱은 음수가 아니라는 것, $1 > 0$이라는 것이 모두 이 넷과 앞의 아홉에서 나옵니다. 순서의 규칙까지 갖춘 체를 순서체라고 합니다([「순서체」](#/read/m-number-construction/ordered-field)).

## 규칙 하나 더: 완비성

유리수와 실수는 둘 다 순서체입니다. 둘을 가르는 것은 마지막 한 줄입니다([「빈틈이 없다는 것」](#/read/m-numbers/real-complete)).

| 규칙 | 줄 수 | 갖춘 것 |
| --- | --- | --- |
| 덧셈, 곱셈, 분배 | 9 | 유리수, 실수, 그 밖의 여러 체 |
| 순서 | 4 | 유리수, 실수 |
| 완비성 | 1 | 실수뿐 |

열네 줄을 모두 갖춘 것은 사실상 실수 하나뿐입니다. 이름만 다르고 셈과 순서가 똑같은 것은 하나로 칩니다([「완비성과 유일성」](#/read/m-number-construction/completeness)). 해석학은 실수의 성질을 이 열네 줄에서 출발해 증명합니다([「실수의 공리」](#/read/m-real-sequences/reals)).

## 원소가 다섯 개인 체

5로 나눈 나머지 0, 1, 2, 3, 4만으로 셈을 합니다. 더하고 곱한 다음 5로 나눈 나머지를 답으로 삼습니다([「몫과 나머지」](#/read/m-numbers/div-remainder)).

| 셈 | 보통의 답 | 나머지로 |
| --- | --- | --- |
| $3 + 4$ | 7 | 2 |
| $2 \times 3$ | 6 | 1 |
| $4 \times 4$ | 16 | 1 |

- **역수가 있다**: $2 \times 3$이 1이므로 2와 3은 서로 역수이고, 4는 자기 자신의 역수입니다. 다섯 개의 수가 아홉 규칙을 모두 채웁니다
- **6으로 하면 안 된다**: 6으로 나눈 나머지에서는 $2 \times 3$이 0입니다. 0이 아닌 두 수의 곱이 0이므로 위의 둘째 정리가 깨지고, 체가 아닙니다. 나누는 수가 소수일 때에만 체가 됩니다([「합동식」](#/read/m-nt-elementary/congruence))
- **순서는 없다**: 순서의 규칙에서는 $1 > 0$이 나오고, 그러면 1을 더할 때마다 커져야 합니다. 그런데 여기서는 1을 다섯 번 더하면 0으로 돌아옵니다. 그래서 이 다섯 수에는 순서의 규칙 넷을 채우는 크기를 줄 수 없습니다

원소가 유한 개인 체는 부호 이론과 암호의 바탕입니다([「유한체」](#/read/m-fields-galois/finite)).

## 규칙에서 출발하는 까닭

아홉 줄만 써서 증명한 것은 아홉 줄이 성립하는 모든 곳에서 참입니다. 유리수에서 한 번, 실수에서 한 번, 나머지의 셈에서 한 번 따로 증명할 필요가 없습니다. 대상이 무엇인지보다 어떤 규칙을 따르는지를 보는 이 방법이 대수학의 출발점입니다([「환의 뜻과 예」](#/read/m-rings/ring), [「군의 뜻」](#/read/m-symmetry-groups/group)).

<Note>
아홉 규칙은 분자와 분모가 3 이하인 분수 열다섯 개의 모든 조합에 넣어 확인했고, 5로 나눈 나머지의 셈에서도 다섯 수의 모든 조합에 넣어 확인했습니다. 6으로 나눈 나머지에서 역수가 없는 수가 2, 3, 4라는 것과, 2부터 30까지에서 체가 되는 것이 소수일 때뿐이라는 것도 프로그램으로 확인했습니다. "열네 줄을 갖춘 것은 사실상 실수 하나뿐"이라는 것은 증명하지 않았습니다. 수의 구성을 다루는 책에 있습니다.
</Note>

## 요점

- 덧셈과 곱셈의 결합법칙, 교환법칙, 0과 1, 반대인 수와 역수, 그리고 분배법칙. 이 아홉이 성립하는 모임이 체이다
- 유리수와 실수는 순서의 규칙 넷까지 갖춘 순서체이고, 실수는 완비성까지 갖췄다
- 규칙만으로 증명한 것은 그 규칙이 성립하는 모든 곳에서 참이다. 나머지의 셈도 체가 될 수 있다
