자주 나오는 전개는 매번 다시 하지 않고 결과를 외워 씁니다. 그것이 곱셈 공식입니다. 외우는 것은 식이지만, 식이 어디서 나왔는지는 그림 한 장이면 됩니다. 가장 많이 쓰는 둘부터 봅니다.

## 합의 제곱

<Figure caption="한 변이 a + b인 정사각형. 정사각형 둘과 똑같은 직사각형 둘로 나뉩니다">
  <AreaModel rows={[10, 6]} cols={[10, 6]} rowLabels={['a', 'b']} colLabels={['a', 'b']} cells={[['a^2', 'a*b'], ['a*b', 'b^2']]} width={190} height={150} />
</Figure>

<Thm name="공식" title="합의 제곱">

$$
(a + b)^2 = a^2 + 2ab + b^2
$$

</Thm>

식으로는 $(a + b)(a + b)$를 전개해 $ab$와 $ba$를 모은 것입니다([「곱셈: 분배법칙과 넓이」](#/read/m-polynomials/am-mul)).

- **가운데 항을 잊지 않는다**: $(a + b)^2$은 $a^2 + b^2$이 아닙니다. 그림의 직사각형 둘이 빠집니다. $(1 + 2)^2 = 9$이고 $1^2 + 2^2 = 5$이며, 차이 4가 $2 \times 1 \times 2$입니다
- **문자 자리에 무엇이든 넣는다**: $a$와 $b$는 수여도 식이어도 됩니다. $(2x + 3y)^2 = 4x^2 + 12xy + 9y^2$입니다. 가운데 항은 $2 \times 2x \times 3y$입니다

## 차의 제곱

<Figure caption="한 변이 a인 정사각형을 a − b와 b로 잘랐습니다. 왼쪽 위의 정사각형이 (a − b)²입니다">
  <AreaModel rows={[9, 5]} cols={[9, 5]} rowLabels={['a−b', 'b']} colLabels={['a−b', 'b']} cells={[['(a−b)^2', ''], ['', 'b^2']]} width={190} height={150} />
</Figure>

<Thm name="공식" title="차의 제곱">

$$
(a - b)^2 = a^2 - 2ab + b^2
$$

</Thm>

- **그림으로**: 전체 $a^2$에서 폭이 $b$인 가로 띠와 세로 띠를 떼어 냅니다. 띠 하나의 넓이는 $ab$입니다. 두 띠가 겹치는 $b^2$을 두 번 뗐으므로 한 번 돌려줍니다. 그래서 $a^2 - 2ab + b^2$입니다
- **식으로**: 합의 제곱에서 $b$ 자리에 $-b$를 넣은 것입니다. $2a(-b) = -2ab$이고 $(-b)^2 = b^2$입니다
- **끝 항은 늘 더한다**: 바뀌는 것은 가운데 항의 부호뿐입니다

## 암산에 쓰기

- **$31^2$**: $(30 + 1)^2 = 900 + 60 + 1 = 961$입니다
- **$99^2$**: $(100 - 1)^2 = 10000 - 200 + 1 = 9801$입니다
- **$105^2$**: $(100 + 5)^2 = 10000 + 1000 + 25 = 11025$입니다

셈하기 쉬운 수와 작은 수로 쪼개는 것이 요령입니다.

## 완전제곱식

거꾸로, $a^2 + 2ab + b^2$ 꼴의 식은 제곱 하나로 묶입니다. 이런 식을 **완전제곱식**이라고 합니다.

| 식 | 제곱으로 |
| --- | --- |
| $x^2 + 6x + 9$ | $(x + 3)^2$ |
| $x^2 - 10x + 25$ | $(x - 5)^2$ |
| $4x^2 + 4x + 1$ | $(2x + 1)^2$ |

- **알아보는 법**: 양 끝이 제곱이고, 가운데가 그 둘의 곱의 2배입니다. $x^2 + 6x + 9$에서 $6x = 2 \times x \times 3$입니다
- **모자란 것을 채우기**: $x^2 + 6x$에 9를 더하면 완전제곱식이 됩니다. 곧 $x^2 + 6x = (x + 3)^2 - 9$입니다. 이차방정식을 푸는 방법이 여기서 나옵니다([「이차방정식」](#/read/m-equations/quadratic))
- **제곱은 음수가 아니다**: $(a - b)^2 \ge 0$이므로 $a^2 + b^2 \ge 2ab$입니다. 두 수의 제곱의 합은 곱의 2배보다 작을 수 없습니다

<Ex title="분수가 든 제곱">
$\left(3x - \frac{1}{2}\right)^2$을 전개하세요.

<Sol>

$a = 3x$, $b = \frac{1}{2}$로 놓습니다.

$$
\begin{aligned}
&\left(3x - \frac{1}{2}\right)^2 \\
&= (3x)^2 - 2 \times 3x \times \frac{1}{2} + \left(\frac{1}{2}\right)^2 \\
&= 9x^2 - 3x + \frac{1}{4}
\end{aligned}
$$

</Sol>
</Ex>

<Note>
두 공식은 $a$, $b$에 $-4$부터 4까지의 정수와 분수 셋을 넣은 모든 조합에서 양쪽이 같은지 확인했습니다. 두 문자에 대해 이차인 식이므로 이만큼의 수에서 같으면 식으로도 같습니다. 차의 제곱의 그림이 말하는 $a^2 = (a - b)^2 + 2(a - b)b + b^2$, 암산 셋, 표의 완전제곱식 셋, 예제의 답, $a^2 + b^2 \ge 2ab$($-20$부터 20까지의 정수)도 프로그램으로 확인했습니다. 넓이 그림은 $a$가 $b$보다 큰 양수일 때의 그림이고, 공식은 어떤 수에서도 성립합니다.
</Note>

## 요점

- $(a + b)^2 = a^2 + 2ab + b^2$이다. 정사각형을 넷으로 자른 그림에서 가운데 항 $2ab$는 직사각형 둘이다
- $(a - b)^2 = a^2 - 2ab + b^2$이다. 가운데 항의 부호만 바뀌고 끝 항은 더한다
- 양 끝이 제곱이고 가운데가 그 둘의 곱의 2배인 식은 제곱 하나로 묶인다. 이것이 완전제곱식이다
