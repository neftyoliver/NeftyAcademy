347은 $3 \times 10^2 + 4 \times 10 + 7$입니다. 10을 $x$로 바꾸면 $3x^2 + 4x + 7$입니다. 십진법으로 적은 수는 다항식에 $x = 10$을 넣은 값이고, 다항식은 묶는 크기를 정하지 않은 수입니다. 세로셈이 다항식의 셈과 닮은 까닭이 여기 있습니다([「자릿값과 십진법」](#/read/m-numbers/nat-place)).

## 수는 다항식의 값이다

| 다항식 | 넣는 수 | 값 |
| --- | --- | --- |
| $3x^2 + 4x + 7$ | $x = 10$ | 347 |
| $x^5 + x^3 + x^2 + 1$ | $x = 2$ | 45 |
| $2x + 13$ | $x = 16$ | 45 |

진법은 $x$에 넣는 수입니다. 둘째 줄은 이진수 $101101_{(2)}$이고, 셋째 줄은 십육진수 $2\mathrm{D}_{(16)}$입니다([「이진법과 십육진법」](#/read/m-numbers/nat-bases)).

## 덧셈: 자리끼리, 동류항끼리

```text
  123        x² + 2x + 3
+ 245     + 2x² + 4x + 5
-----     --------------
  368       3x² + 6x + 8
```

같은 자리의 숫자끼리 더하는 것이 같은 차수의 항끼리 계수를 더하는 것입니다. 오른쪽 식에 $x = 10$을 넣으면 왼쪽 셈이 됩니다.

## 곱셈: 조각끼리 곱해 모으기

<Figure caption="(2x + 3)(x + 4)의 넓이 그림. x = 10이면 23 × 14의 조각 200, 30, 80, 12가 됩니다">
  <AreaModel rows={[10, 4]} cols={[20, 3]} rowLabels={['x', '4']} colLabels={['2x', '3']} cells={[['2x^2', '3x'], ['8x', '12']]} />
</Figure>

$$
\begin{aligned}
(2x + 3)(x + 4) &= 2x^2 + 3x + 8x + 12 \\
&= 2x^2 + 11x + 12
\end{aligned}
$$

$x = 10$을 넣으면 $200 + 110 + 12 = 322$이고, $23 \times 14 = 322$입니다. 세로 곱셈에서 조각 넷을 구해 더하던 것과 같은 셈입니다([「덧셈과 곱셈을 그림으로」](#/read/m-numbers/nat-add)).

## 다른 점: 받아올림이 없다

수에서는 한 자리에 9까지만 둘 수 있어서, 넘치면 윗자리로 올립니다. 다항식의 계수에는 그런 한계가 없습니다. $47 + 38$을 다항식으로 옮기면 $(4x + 7) + (3x + 8)$이고, $23 \times 14$는 위에서 곱한 $(2x + 3)(x + 4)$입니다.

| 셈 | 수 | 다항식 |
| --- | --- | --- |
| 덧셈 | $47 + 38 = 85$ | $7x + 15$ |
| 곱셈 | $23 \times 14 = 322$ | $2x^2 + 11x + 12$ |

- **15를 그대로 둔다**: $7x + 15$의 15를 $x + 5$로 바꿀 수 있는 것은 $x = 10$일 때뿐입니다. $x$가 정해지지 않았으므로 올리지 않습니다
- **그래서 더 쉽다**: 한 자리의 셈이 옆자리에 영향을 주지 않습니다. 다항식의 셈은 받아올림 없는 세로셈입니다
- **계수는 어떤 수여도 된다**: 음수, 분수, 무리수도 계수가 됩니다. 수의 자리 숫자는 0부터 9까지뿐입니다

## 닮은 것과 다른 것

| 견줄 것 | 십진법의 수 | 다항식 |
| --- | --- | --- |
| 자리 | 10의 거듭제곱 | $x$의 거듭제곱 |
| 자리에 놓는 것 | 숫자 0부터 9 | 계수 |
| 빈자리 | 0을 적는다 | 항을 적지 않는다 |
| 받아올림 | 있다 | 없다 |
| 크기 | 견줄 수 있다 | 차수만 견준다 |

## 이 닮음이 가는 곳

수에서 한 일을 다항식에서 한 번씩 다시 합니다.

| 수에서 | 다항식에서 |
| --- | --- |
| 약수와 소인수분해 | 인수와 인수분해 |
| 몫과 나머지 | 다항식의 나눗셈 |
| 최대공약수와 호제법 | 다항식의 최대공약수 |
| 분수 | 유리식 |

차례로 이 책의 4장, 5장, 9장에 나옵니다([「공통인수로 묶기」](#/read/m-polynomials/fc-common), [「세로로 나누기」](#/read/m-polynomials/dv-long), [「다항식의 최대공약수」](#/read/m-polynomials/dv-gcd), [「유리식」](#/read/m-polynomials/re-define)).

<Ex title="1001을 다항식으로">
$x^3 + 1 = (x + 1)(x^2 - x + 1)$입니다. 이 식으로 1001을 두 수의 곱으로 적으세요.

<Sol>

$x = 10$을 넣으면 왼쪽은 1001이고 오른쪽은 $11 \times (100 - 10 + 1) = 11 \times 91$입니다. 그러므로 $1001 = 11 \times 91$입니다.

</Sol>
</Ex>

다항식의 인수분해 하나가 $x$에 넣는 수마다 수의 인수분해를 하나씩 줍니다. $x = 2$를 넣으면 $9 = 3 \times 3$입니다. 예제의 식은 뒤에서 다룹니다([「세제곱의 합과 차」](#/read/m-polynomials/fc-cubic)).

<Note>
표의 값 347, 45, 45와 두 세로셈, $(2x + 3)(x + 4)$의 전개와 $x = 10$에서의 322, 예제의 $1001 = 11 \times 91$과 $9 = 3 \times 3$은 프로그램으로 확인했습니다. $x^3 + 1 = (x + 1)(x^2 - x + 1)$은 오른쪽을 프로그램으로 전개해 확인했습니다. 넓이 그림은 조각의 크기를 고르게 그렸으므로 실제 비율과 다릅니다.
</Note>

## 요점

- 십진법의 수는 다항식에 $x = 10$을 넣은 값이다. 자리는 $x$의 거듭제곱에, 숫자는 계수에 해당한다
- 다항식의 덧셈과 곱셈은 받아올림이 없는 세로셈이다
- 약수, 나눗셈, 호제법, 분수가 다항식에서 인수, 나눗셈, 최대공약수, 유리식으로 다시 나온다
