두 수가 무엇인지는 몰라도 합과 곱을 알면 제곱의 합, 세제곱의 합, 차의 제곱을 구할 수 있습니다. 곱셈 공식의 항을 옮겨 적기만 하면 됩니다. 이 쪽은 공식을 전개하는 도구에서 식을 다른 식으로 바꿔 적는 도구로 바꿔 봅니다.

## 항을 옮겨 적기

| 구하는 것 | 합과 곱으로 적으면 |
| --- | --- |
| $a^2 + b^2$ | $(a + b)^2 - 2ab$ |
| $(a - b)^2$ | $(a + b)^2 - 4ab$ |
| $a^3 + b^3$ | $(a + b)^3 - 3ab(a + b)$ |

- **첫째 줄**: 합의 제곱에서 $2ab$를 넘긴 것입니다([「합의 제곱과 차의 제곱」](#/read/m-polynomials/fm-square))
- **둘째 줄**: $(a + b)^2$과 $(a - b)^2$은 가운데 항의 부호만 다르므로 차이가 $4ab$입니다
- **셋째 줄**: 합의 세제곱에서 $3a^2b + 3ab^2$, 곧 $3ab(a + b)$를 넘긴 것입니다([「세제곱 공식」](#/read/m-polynomials/fm-cube))

<Ex title="합이 5, 곱이 3">
$a + b = 5$, $ab = 3$일 때 $a^2 + b^2$, $a^3 + b^3$, $(a - b)^2$을 구하세요.

<Sol>

$$
\begin{aligned}
a^2 + b^2 &= 5^2 - 2 \times 3 = 19 \\
a^3 + b^3 &= 5^3 - 3 \times 3 \times 5 = 80 \\
(a - b)^2 &= 5^2 - 4 \times 3 = 13
\end{aligned}
$$

$a$와 $b$가 얼마인지는 구하지 않았습니다. 실제로는 $\frac{5 + \sqrt{13}}{2}$과 $\frac{5 - \sqrt{13}}{2}$이어서, 직접 넣어 셈하는 쪽이 훨씬 번거롭습니다.

</Sol>
</Ex>

## 맞바꿔도 그대로인 식

<Def title="대칭식">
문자를 서로 맞바꿔도 달라지지 않는 식을 **대칭식**이라고 합니다.
</Def>

| 식 | 맞바꾸면 | 대칭식인가 |
| --- | --- | --- |
| $a + b$ | $b + a$ | 대칭식이다 |
| $a^2 + b^2$ | $b^2 + a^2$ | 대칭식이다 |
| $a - b$ | $b - a$ | 아니다 |
| $(a - b)^2$ | $(b - a)^2$ | 대칭식이다 |

- **합과 곱이 바탕이다**: $a + b$와 $ab$는 가장 단순한 대칭식입니다. 두 문자의 대칭식은 모두 이 둘만으로 적을 수 있습니다. 맨 위의 표가 그 보기입니다([「근의 대칭식」](#/read/m-polynomials/rt-symmetric))
- **쓰이는 곳**: 이차방정식의 두 근은 따로 구하기 번거로워도 합과 곱은 계수에서 바로 읽힙니다. 그래서 근에 대한 대칭식의 값은 근을 구하지 않고 압니다([「이차식의 근과 계수」](#/read/m-polynomials/rt-quadratic))

## 역수와의 합

$x$와 $\frac{1}{x}$은 곱이 1인 짝입니다. $a = x$, $b = \frac{1}{x}$로 놓으면 $ab = 1$이어서 식이 짧아집니다.

$$
x^2 + \frac{1}{x^2} = \left(x + \frac{1}{x}\right)^2 - 2
$$

$x + \frac{1}{x} = 3$이면 $x^2 + \frac{1}{x^2} = 3^2 - 2 = 7$입니다. 같은 방법으로 $x^3 + \frac{1}{x^3} = 3^3 - 3 \times 3 = 18$입니다.

## 세 항의 제곱

<Figure caption="한 변이 a + b + c인 정사각형. 대각선에 정사각형 셋이 놓이고, 나머지 직사각형 여섯은 둘씩 짝을 이룹니다">
  <AreaModel rows={[9, 7, 5]} cols={[9, 7, 5]} rowLabels={['a', 'b', 'c']} colLabels={['a', 'b', 'c']} cells={[['a^2', 'a*b', 'c*a'], ['a*b', 'b^2', 'b*c'], ['c*a', 'b*c', 'c^2']]} width={210} height={170} />
</Figure>

$$
\begin{aligned}
(a + b + c)^2 &= a^2 + b^2 + c^2 \\
&\quad + 2ab + 2bc + 2ca
\end{aligned}
$$

- **모든 짝이 두 번씩 나온다**: 서로 다른 두 문자의 곱이 대각선의 양쪽에 한 번씩 놓입니다
- **이것도 옮겨 적는다**: $a^2 + b^2 + c^2$은 $(a + b + c)^2$에서 $2(ab + bc + ca)$를 뺀 것입니다

제곱의 합에서 둘씩의 곱을 빼면 다음과 같이 고쳐 적을 수 있습니다.

$$
\begin{aligned}
&a^2 + b^2 + c^2 - ab - bc - ca \\
&= \frac{1}{2}\bigl((a - b)^2 + (b - c)^2 + (c - a)^2\bigr)
\end{aligned}
$$

오른쪽은 제곱을 더한 것이므로 음수가 될 수 없습니다. 그래서 $a^2 + b^2 + c^2 \ge ab + bc + ca$이고, 같아지는 것은 $a = b = c$일 때뿐입니다.

<Note>
표의 세 식과 세 항의 제곱, 마지막 식은 문자마다 정수와 분수를 넣은 모든 조합에서 양쪽이 같은지 확인했습니다. 예제의 19, 80, 13은 $a$와 $b$에 $\frac{5 \pm \sqrt{13}}{2}$을 소수로 넣어 다시 셈한 값과 아홉 자리까지 같았습니다. $x + \frac{1}{x} = 3$일 때의 7과 18도 $x = \frac{3 + \sqrt{5}}{2}$를 넣어 확인했습니다. 두 문자의 대칭식이 모두 합과 곱으로 적힌다는 것은 증명하지 않았습니다.
</Note>

## 요점

- $a^2 + b^2 = (a + b)^2 - 2ab$처럼 공식의 항을 옮기면 합과 곱만으로 다른 식의 값을 구한다
- 문자를 맞바꿔도 그대로인 식이 대칭식이다. 두 문자의 대칭식은 합과 곱으로 적힌다
- $(a + b + c)^2$에는 제곱 셋과, 둘씩의 곱이 두 번씩 나온다
