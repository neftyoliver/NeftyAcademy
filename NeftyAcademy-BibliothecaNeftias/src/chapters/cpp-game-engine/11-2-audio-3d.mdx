[「믹싱」](#/read/cpp-game-engine/audio-mixing)에서는 소리마다 음량을 정해 더했습니다. 3차원 게임에서는 그 음량과 좌우 배분을 **소리가 난 위치와 듣는 이(보통 카메라)의 위치**로 매 프레임 계산합니다. 멀면 작게, 오른쪽에서 나면 오른쪽 스피커로, 다가오면 높게 들려야 플레이어가 화면 밖의 적도 소리로 찾을 수 있습니다.

## 위치에서 음량과 방향으로

```cpp
#include <algorithm>
#include <cmath>
#include <numbers>
#include <print>

struct V { double x, y; };
V operator-(V a, V b) { return {a.x - b.x, a.y - b.y}; }
double dot(V a, V b) { return a.x * b.x + a.y * b.y; }
double len(V a) { return std::sqrt(dot(a, a)); }

// 거리 감쇠: 기준 거리 안은 그대로, 밖은 거리에 반비례, 최대 거리 밖은 고정
double attenuate(double d, double ref = 1, double max_d = 50) {
    d = std::clamp(d, ref, max_d);
    return ref / d;
}

// 등전력 팬: 왼쪽²+오른쪽² = 1 이 되게
std::pair<double, double> pan(double side) {        // side: -1 왼쪽 ~ +1 오른쪽
    double a = (side + 1) * std::numbers::pi / 4;    // 0 ~ 90도
    return {std::cos(a), std::sin(a)};
}

int main() {
    V listener{0, 0}, right{1, 0};                  // 듣는 이는 +y를 본다
    std::println("소리 위치      거리   감쇠(dB)  왼쪽  오른쪽");
    for (V src : {V{0, 1}, V{0, 2}, V{0, 4}, V{3, 0}, V{-3, 0}, V{0, 100}}) {
        V d = src - listener;
        double dist = len(d);
        double g = attenuate(dist);
        double side = dot(d, right) / dist;          // 오른쪽 성분의 코사인
        auto [l, r] = pan(side);
        std::println("({:4.0f},{:4.0f})  {:6.1f}  {:7.1f}  {:.2f}  {:.2f}",
                     src.x, src.y, dist, 20 * std::log10(g), l, r);
    }

    // 도플러: 소리 쪽으로 다가오면 높게, 멀어지면 낮게
    const double c = 343;                            // 음속 m/s
    V car{-60, 10}, vel{30, 0};                      // 시속 108km로 지나가는 차
    std::println("지나가는 차(30m/s) 소리 높이 배율");
    for (int i = 0; i <= 4; ++i) {
        V p{car.x + vel.x * i, car.y};
        V to_listener = listener - p;
        double toward = dot(vel, to_listener) / len(to_listener);
        std::println("  x={:4.0f}  다가오는 속도 {:6.1f}  배율 {:.3f}",
                     p.x, toward, c / (c - toward));
    }
}
```

## 거리 감쇠

`attenuate`는 기준 거리(1) 안에서는 줄이지 않고, 그 밖에서는 거리에 반비례하게 줄입니다. 거리가 두 배가 될 때마다 6dB씩 줄어서 2에서 -6, 4에서 -12가 되었습니다. 실제 공기 중의 점 음원도 거리가 두 배면 진폭이 절반이므로 이것이 물리적인 기본값입니다.

그런데 물리 그대로면 먼 소리가 끝없이 작아지기만 하고, 가까운 소리는 너무 갑자기 커집니다. 그래서 소리마다 **최소 거리**와 **최대 거리**를 두고, 최대 거리(여기서는 50) 밖에서는 더 줄이지 않거나 아예 소리를 끕니다. 100 떨어진 소리가 -34dB(50에서의 값)로 멈춘 것이 그 때문입니다. 감쇠 곡선 모양도 소리마다 사운드 디자이너가 고칩니다. 발소리는 빨리 사라지게, 먼 포격은 멀리서도 들리게 합니다.

## 좌우 나누기

`pan`은 소리 방향의 오른쪽 성분(-1~1)을 0~90도 각도로 바꿔 왼쪽에 코사인, 오른쪽에 사인을 곱합니다. 정면의 소리는 양쪽 0.71이고, 옆의 소리는 한쪽에만 1입니다. 그냥 왼쪽 `1 - x`, 오른쪽 `x`로 나누면 정면에서 두 스피커가 각각 0.5가 되어 전력(제곱합)이 0.5로 줄고, 소리가 가운데를 지날 때 작아지는 구멍이 생깁니다. **등전력 팬**은 어느 방향에서든 제곱합이 1이어서 음량이 고르게 유지됩니다.

이 방식의 한계는 앞뒤를 구분하지 못한다는 점입니다. (0, 1)과 (0, -1)은 오른쪽 성분이 같아서 똑같이 들립니다. 헤드폰에서는 귀와 머리 모양이 소리를 걸러 내는 방식을 측정한 **HRTF**로 앞뒤와 위아래까지 표현합니다. 5.1이나 7.1 스피커에서는 소리를 둘러싼 스피커들에 나눠 보냅니다.

## 도플러

차가 시속 108km(30m/s)로 지나가면 다가올 때는 높게, 멀어질 때는 낮게 들립니다. 소리 높이 배율은 음속 `c`에 대해 `c / (c - 다가오는 속도)`입니다. 다가오는 속도는 차의 속도 중 듣는 이를 향한 성분이라서, 바로 앞을 지나는 순간(x=0)에는 0이 되어 배율이 1입니다. 실제 재생에서는 이 배율만큼 재생 속도를 바꿉니다. 게임에서는 효과를 일부러 줄여 쓰는 경우가 많은데, 카메라가 빠르게 움직일 때 모든 소리의 높이가 출렁이면 거슬리기 때문입니다.

<Note>
벽 너머의 소리는 작고 먹먹하게 들려야 합니다. 많은 엔진이 소리와 듣는 이 사이로 [「충돌 감지의 두 단계」](#/read/cpp-game-engine/phys-collision)의 물리 세계에 광선을 쏘아 가림 정도를 구하고, 음량을 낮추면서 높은 주파수를 깎는 필터를 겁니다. 동굴이나 성당 같은 공간의 울림은 구역마다 다른 잔향 효과를 버스에 걸어 표현합니다.
</Note>

## 정리

- 거리 감쇠는 거리가 두 배일 때 6dB씩 줄이는 것이 기본이고, 최소·최대 거리와 곡선은 소리마다 조정한다
- 좌우는 등전력 팬으로 나눠 가운데에서 음량이 꺼지지 않게 하고, 앞뒤 구분에는 HRTF나 다채널 스피커를 쓴다
- 도플러는 듣는 이를 향한 속도 성분으로 소리 높이를 바꾸고, 가림과 잔향은 물리 광선과 필터로 더한다
