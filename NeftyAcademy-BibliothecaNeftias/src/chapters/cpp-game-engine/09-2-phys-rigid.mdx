[「충돌 감지의 두 단계」](#/read/cpp-game-engine/phys-collision)는 접촉, 곧 법선과 깊이를 알려 줄 뿐입니다. 이제 닿은 두 물체가 어떻게 튕겨 나갈지 정해야 합니다. 게임 물리 엔진 대부분은 힘을 시간에 걸쳐 주는 대신, 닿는 순간 속도를 한 번에 바꾸는 **충격량**으로 이 문제를 풉니다. 모양이 변하지 않는 물체(**강체**)라고 가정하면 계산이 간단해집니다.

## 충격량 한 번

```cpp
#include <cmath>
#include <print>

struct V { double x, y; };
V operator+(V a, V b) { return {a.x + b.x, a.y + b.y}; }
V operator-(V a, V b) { return {a.x - b.x, a.y - b.y}; }
V operator*(double s, V a) { return {s * a.x, s * a.y}; }
double dot(V a, V b) { return a.x * b.x + a.y * b.y; }

struct Body { V p, v; double inv_m; };   // inv_m == 0 이면 움직이지 않는 벽

// 접촉 하나 풀기: 법선 n (a에서 b 쪽), 깊이 depth, 반발 계수 e
void resolve(Body& a, Body& b, V n, double depth, double e) {
    double vn = dot(b.v - a.v, n);           // 법선 방향 상대 속도
    if (vn < 0) {                            // 서로 다가올 때만
        double j = -(1 + e) * vn / (a.inv_m + b.inv_m);
        a.v = a.v - (j * a.inv_m) * n;       // 같은 크기, 반대 방향의 충격량
        b.v = b.v + (j * b.inv_m) * n;
    }
    // 위치 보정: 파고든 만큼을 질량 비율대로 떼어 놓는다
    const double slop = 0.01, k = 0.8;
    double c = std::fmax(depth - slop, 0.0) * k / (a.inv_m + b.inv_m);
    a.p = a.p - (c * a.inv_m) * n;
    b.p = b.p + (c * b.inv_m) * n;
}

double energy(const Body& b) {
    return b.inv_m ? 0.5 / b.inv_m * dot(b.v, b.v) : 0;
}

int main() {
    for (double e : {1.0, 0.5, 0.0}) {
        Body a{{0, 0}, {4, 0}, 1.0}, b{{1.9, 0}, {0, 0}, 1.0 / 3};
        double p0 = 1 * a.v.x + 3 * b.v.x, k0 = energy(a) + energy(b);
        resolve(a, b, {1, 0}, 0.1, e);
        double p1 = 1 * a.v.x + 3 * b.v.x, k1 = energy(a) + energy(b);
        std::println("e={:.1f}: 속도 {:+.2f} {:+.2f}  운동량 {}->{}  에너지 {}->{}",
                     e, a.v.x, b.v.x, p0, p1, k0, k1);
    }

    // 공 떨어뜨리기: 바닥은 질량 무한대(inv_m = 0)
    Body ball{{0, 5}, {0, 0}, 1.0}, ground{{0, 0}, {0, 0}, 0.0};
    const double dt = 1.0 / 240, g = -9.8, r = 0.5;
    double peak = ball.p.y;
    int bounces = 0;
    bool rising = false;
    for (int step = 0; step < 240 * 6 && bounces < 4; ++step) {
        ball.v.y += g * dt;
        ball.p = ball.p + dt * ball.v;
        double depth = r - ball.p.y;          // 바닥 y=0 아래로 파고든 정도
        if (depth > 0) resolve(ground, ball, {0, 1}, depth, 0.7);
        if (ball.v.y > 0) { rising = true; peak = ball.p.y; }
        else if (rising) {
            rising = false;
            std::println("튀어 오른 높이 {}: {:.2f}", ++bounces, peak);
        }
    }
}
```

```text
e=1.0: 속도 -2.00 +2.00  운동량 4->4  에너지 8->8
e=0.5: 속도 -0.50 +1.50  운동량 4->4  에너지 8->3.5
e=0.0: 속도 +1.00 +1.00  운동량 4->4  에너지 8->2
튀어 오른 높이 1: 2.68
튀어 오른 높이 2: 1.55
튀어 오른 높이 3: 1.00
튀어 오른 높이 4: 0.73
```

`resolve`의 계산은 세 줄입니다. 법선 방향의 **상대 속도** `vn`을 구하고, 서로 다가오는 중(음수)일 때만 충격량 `j`를 구해, 두 물체에 같은 크기를 반대 방향으로 나눠 줍니다. 같은 크기를 반대로 주므로 **운동량은 항상 보존**됩니다. 출력에서 세 경우 모두 운동량이 4로 그대로입니다.

- **반발 계수** `e`는 튕겨 나가는 상대 속도가 다가오던 상대 속도의 몇 배인지입니다. 1이면 에너지도 보존되는 완전 탄성 충돌, 0이면 둘이 같은 속도로 붙어 가는 충돌입니다. 질량 1인 공이 정지한 질량 3인 공에 부딪혔을 때, e=1이면 가벼운 공이 튕겨 돌아오고 e=0이면 둘이 속도 1로 함께 갑니다
- 질량은 **역질량** `inv_m`으로 저장합니다. 벽이나 바닥은 역질량 0으로 두면, 공식이 바뀌지 않으면서 벽은 충격량을 받아도 움직이지 않습니다. 무한대 질량을 따로 처리할 필요가 없습니다
- 떨어뜨린 공의 중심 높이는 바닥(반지름 0.5)을 기준으로 4.5에서 시작해, 튈 때마다 대략 `e² = 0.49`배씩 줄었습니다(2.18, 1.05, 0.50, 0.23 정도). 튀어 오르는 속도가 `e`배가 되면 올라가는 높이는 그 제곱에 비례하기 때문입니다. 이론값과 조금 다른 것은 시간 간격과 위치 보정 때문입니다

## 위치 보정

충격량은 속도만 바꾸므로, 이미 파고든 깊이는 남아 있습니다. 내버려 두면 물체가 바닥 속에 가라앉습니다. 예제는 깊이의 80%를 질량 비율대로 떼어 놓되, 아주 얕은 겹침(`slop`, 0.01)은 남겨 둡니다. 겹침을 완전히 0으로 만들면 다음 프레임에 접촉이 사라졌다 생기기를 반복해서 물체가 바닥 위에서 떨리기 때문입니다. 한 번에 100%를 고치지 않는 것도 같은 이유입니다.

## 회전과 여러 접촉

실제 강체는 접촉점이 무게 중심에서 벗어나 있으면 회전도 합니다. 그때는 상대 속도에 각속도에 의한 속도가 더해지고, 충격량 공식의 분모에 관성 모멘트 항이 들어갑니다. 원리는 같고 식이 길어질 뿐입니다. 마찰도 법선에 수직인 방향으로 같은 방식의 충격량을 주되, 크기가 법선 충격량에 마찰 계수를 곱한 값을 넘지 않게 자릅니다.

상자 더미처럼 접촉이 여러 개 얽히면 하나를 풀면 다른 것이 어긋납니다. 그래서 엔진은 모든 접촉을 한 번씩 푸는 일을 프레임마다 여러 번(보통 4~10번) 되풀이해 함께 맞아 들어가게 합니다. 이 방식을 **순차 충격량**이라고 부르고, 다음 장 [「물리 엔진 붙이기」](#/read/cpp-game-engine/phys-integrate)의 한 단계 안에서 돌아갑니다.

<Note>
예제는 이해를 위해 `double`을 썼지만, 게임 물리는 보통 `float`로 계산합니다. 그럴 때 위치 보정 계수, `slop`, 반복 횟수는 단위(미터인지 센티미터인지)에 따라 다시 맞춰야 합니다. 물리 엔진 문서들이 "1 단위 = 1미터, 물체 크기는 0.1~10 사이"를 권하는 이유입니다.
</Note>

## 정리

- 충돌 응답은 법선 방향 상대 속도로 충격량을 구해 두 물체에 반대 방향으로 나눠 주며, 그래서 운동량이 보존된다
- 반발 계수는 튕기는 정도를, 역질량은 질량 비율과 움직이지 않는 벽을 한 공식으로 다루게 해 준다
- 남은 겹침은 일부만 천천히 떼어 놓아 떨림을 막고, 여러 접촉은 반복해서 함께 풀며, 회전과 마찰도 같은 원리로 더한다
