C에서 문자열은 `\0`으로 끝나는 `char` 배열이었고, 길이도 메모리도 사람이 챙겼습니다. C++에서는 그 일을 `std::string`이 맡습니다. 문법을 배우기 전에 이 도구부터 손에 익힙니다. 이 책의 예제가 처음부터 이것을 쓰기 때문입니다.

## std::string

```cpp
#include <print>
#include <string>

int main()
{
    std::string s = "rasp";
    s += "berry";                       // 알아서 늘어난다
    std::string t = s + " pi";          // 이어 붙이면 새 문자열

    std::println("{} ({}바이트)", t, t.size());
    std::println("{}", t.substr(0, 4));
    std::println("{}", t.find("pi"));
    std::println("{} {}", t == "raspberry pi", t.starts_with("rasp"));
    std::println("{}", t.contains("berry"));     // C++23
}
```

```text
raspberry pi (12바이트)
rasp
10
true true
true
```

`strcpy`, `strcat`, `strcmp`, `strlen`이 하던 일이 `=`, `+=`, `==`, `.size()`가 됐습니다. 버퍼 크기를 계산할 일이 없고, 변수가 사라질 때 메모리도 함께 돌려줍니다.

| C | `std::string` |
| --- | --- |
| `strlen(s)` | `s.size()` (미리 알고 있어서 세지 않는다) |
| `strcmp(a, b) == 0` | `a == b` |
| `strcat(a, b)` | `a += b` |
| `strstr(a, "x")` | `a.find("x")`. 없으면 `std::string::npos` |
| `a[i]` | `a[i]`, 범위를 검사하려면 `a.at(i)` |
| C 함수에 넘기기 | `a.c_str()` (`\0`으로 끝나는 `const char *`) |

`"abc"` 같은 문자열 상수는 여전히 `const char[]`입니다. `std::string`에 넣는 순간 복사됩니다.

## std::string_view

함수가 문자열을 **읽기만** 한다면 복사할 이유가 없습니다. `std::string_view`는 "어디서부터 몇 글자"만 들고 있는 작은 값입니다(포인터 하나와 길이 하나).

```cpp
#include <print>
#include <string>
#include <string_view>

std::size_t count_spaces(std::string_view text)     // 복사 없이 본다
{
    std::size_t n = 0;
    for (char c : text)
        if (c == ' ')
            ++n;
    return n;
}

int main()
{
    std::string owned = "a b c";
    std::println("{}", count_spaces(owned));        // std::string도
    std::println("{}", count_spaces("x y"));        // 문자열 상수도 받는다

    std::string_view part = std::string_view(owned).substr(2);
    std::println("{}", part);                       // 복사 없이 뒷부분만
}
```

```text
2
1
b c
```

`std::string`의 `substr`은 새 문자열을 만들지만, `std::string_view`의 `substr`은 시작 위치와 길이만 바꿉니다.

## 어느 것을 쓰나

| 상황 | 타입 |
| --- | --- |
| 문자열을 만들고, 고치고, 보관한다 | `std::string` |
| 함수 인자로 받아서 읽기만 한다 | `std::string_view` |
| 구조체의 멤버로 오래 들고 있는다 | `std::string` |
| `\0`으로 끝나야 하는 C 함수에 넘긴다 | `std::string`의 `c_str()` |

`std::string_view`는 `\0`으로 끝난다는 보장이 없습니다. `printf("%s")`나 `fopen`에 그대로 넘기면 안 됩니다.

## 뷰는 주인보다 오래 살 수 없다

```cpp nocheck
std::string_view bad()
{
    std::string s = "temporary";
    return s;       // s는 여기서 사라진다. 돌려준 뷰는 죽은 메모리를 가리킨다
}
```

`std::string_view`는 메모리를 소유하지 않습니다. 가리키던 `std::string`이 사라지거나 고쳐져서 메모리를 옮기면, 뷰는 포인터와 똑같이 죽은 곳을 가리키게 됩니다. 인자로 받아서 그 함수 안에서만 쓰는 것이 안전한 쓰임새입니다.

<Note>
`size()`는 글자 수가 아니라 바이트 수입니다. UTF-8에서 한글 한 글자는 3바이트라서 `std::string("한글").size()`는 6입니다. `substr`이나 `[]`로 한글의 중간을 자르면 깨진 글자가 됩니다. 글자 단위로 다루는 방법은 STL 책의 유니코드 챕터에서 봅니다.
</Note>

## 숫자와 오가기

```cpp
#include <print>
#include <string>

int main()
{
    std::string a = std::to_string(42) + "번";
    int n = std::stoi("123") + 1;
    double d = std::stod("2.5") * 2;
    std::println("{} {} {}", a, n, d);
}
```

```text
42번 124 5
```

`std::stoi`는 숫자로 읽을 수 없으면 예외를 던집니다. 예외 없이 빠르게 바꾸는 `std::from_chars`도 있습니다.

## 정리

- `std::string`은 메모리를 스스로 관리하는 문자열. `=`, `+=`, `==`를 그대로 쓴다
- 읽기만 하는 함수 인자는 `std::string_view`
- 뷰는 소유하지 않는다. 주인이 사라지면 함께 죽는다
