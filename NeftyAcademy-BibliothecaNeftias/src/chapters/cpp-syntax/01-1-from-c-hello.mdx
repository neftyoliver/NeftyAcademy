## 가장 작은 프로그램

```cpp
#include <print>
#include <string>

int main()
{
    std::string name = "네프티";
    int year = 2026;

    std::println("안녕하세요, {}!", name);
    std::println("{}년에 쓰는 C++", year);
}
```

```text
안녕하세요, 네프티!
2026년에 쓰는 C++
```

```sh
g++ -std=c++23 -Wall -Wextra hello.cpp -o hello
./hello
```

C와 달라 보이는 곳은 네 군데입니다.

| 줄 | 뜻 |
| --- | --- |
| `#include <print>` | C++ 표준 헤더에는 `.h`가 붙지 않는다 |
| `std::string` | 길이를 스스로 아는 문자열 타입. `char` 배열을 직접 다루지 않는다 |
| `std::println` | `std::`는 표준 라이브러리의 이름이 모여 있는 네임스페이스 |
| `"{}"` | 값이 들어갈 자리. 타입은 적지 않는다 |

`main`의 끝에 `return 0;`이 없어도 됩니다. `main`에서만 통하는 규칙이고, 끝까지 가면 0을 돌려준 것으로 칩니다.

## printf와 무엇이 다른가

`printf("%d", x)`는 `%d`와 `x`의 타입이 맞는지를 사람이 책임집니다. 틀리면 정의되지 않은 동작입니다. `std::println`은 컴파일러가 인자의 타입을 알고 있어서 `{}`만 적으면 되고, 자리의 수와 인자의 수가 안 맞으면 컴파일 오류가 납니다.

```cpp
#include <print>

int main()
{
    double v = 3.14159;
    int n = 255;

    std::println("[{:8.2f}]", v);      // 폭 8, 소수 둘째 자리
    std::println("[{:<8}]", n);        // 왼쪽 정렬
    std::println("[{:08b}]", n);       // 2진수, 0으로 채워 8자리
    std::println("{:#x} {:#o}", n, n); // 0x, 0 접두어
    std::println("{1} {0} {1}", "a", "b");
}
```

```text
[    3.14]
[255     ]
[11111111]
0xff 0377
b a b
```

`{:…}` 안의 서식은 `채움·정렬·폭·정밀도·종류` 순서입니다. 문자열을 만들기만 하려면 `<format>`의 `std::format`이 같은 서식으로 `std::string`을 돌려줍니다.

## cout

`std::println`은 C++23에서 들어왔습니다. 그 전에 쓰인 코드는 거의 전부 `<iostream>`의 `std::cout`을 씁니다. 읽을 줄은 알아야 합니다.

```cpp
#include <iostream>

int main()
{
    int x = 42;
    std::cout << "x = " << x << '\n';
}
```

```text
x = 42
```

`<<`는 여기서 "왼쪽 스트림에 오른쪽 값을 넣는다"는 뜻으로 쓰입니다(시프트 연산자를 다른 뜻으로 다시 정의한 것입니다. [「출력 붙이기: formatter와 operator&lt;&lt;」](#/read/cpp-syntax/op-stream)에서 다룹니다). 줄 끝에 `std::endl`을 쓴 코드도 많은데, 줄바꿈에 더해 버퍼까지 비우므로 느립니다. `'\n'`이면 충분합니다.

## 입력

```cpp nocheck
#include <iostream>
#include <print>
#include <string>

int main()
{
    std::string line;
    std::print("이름: ");
    std::getline(std::cin, line);       // 한 줄 전체

    int age = 0;
    std::print("나이: ");
    if (!(std::cin >> age)) {           // 숫자가 아니면 실패
        std::println("숫자가 아닙니다");
        return 1;
    }
    std::println("{} ({}세)", line, age);
}
```

`std::cin >> age`는 읽기에 성공했는지를 알려 줍니다. `scanf`와 달리 버퍼 크기를 적을 일이 없고, `std::string`이 알아서 늘어납니다.

<Note kind="warn">
`<print>`는 C++23의 헤더라 컴파일러가 새로워야 합니다. GCC 14, libc++ 18, 비주얼 스튜디오 2022 17.7 이상이면 됩니다. `fatal error: print: No such file or directory`가 나오면 다음 챕터를 보고 컴파일러를 올리거나, 그동안은 `std::cout`을 쓰세요.
</Note>

## 정리

- C++ 표준 헤더는 `.h` 없이, 이름은 `std::` 안에
- 출력은 `std::println("{}", 값)`. 타입은 컴파일러가 맞춘다
- 옛 코드는 `std::cout << 값`. `std::endl`보다 `'\n'`
