`a + b`는 `int`에서는 덧셈 명령 하나지만, `std::string`에서는 이어 붙이기입니다. C++에서 연산자는 **이름이 특별한 함수**이고, 내가 만든 타입에 대해 정의할 수 있습니다.

## 벡터 하나

```cpp
#include <print>

struct Vec2 {
    double x = 0, y = 0;

    Vec2& operator+=(const Vec2& o)         // 복합 대입은 멤버로. *this를 돌려준다
    {
        x += o.x;
        y += o.y;
        return *this;
    }
    Vec2& operator*=(double k)
    {
        x *= k;
        y *= k;
        return *this;
    }
    Vec2 operator-() const { return {-x, -y}; }     // 단항 -

    friend Vec2 operator+(Vec2 a, const Vec2& b)    // + 는 += 로 만든다
    {
        a += b;
        return a;
    }
    friend Vec2 operator*(Vec2 v, double k)
    {
        v *= k;
        return v;
    }
    friend Vec2 operator*(double k, Vec2 v) { return v * k; }      // 2 * v 도 되게
};

int main()
{
    Vec2 a{1, 2}, b{10, 20};
    Vec2 c = a + b * 2;         // 우선순위는 그대로: b * 2 가 먼저
    c += -a;
    Vec2 d = 0.5 * c;
    std::println("{} {} / {} {}", c.x, c.y, d.x, d.y);
}
```

```text
20 40 / 10 20
```

`a + b`는 `operator+(a, b)`를 부르는 다른 표기입니다. 실제로 그렇게 적어도 컴파일됩니다.

## 멤버로 쓸까, 바깥 함수로 쓸까

| 연산자 | 두는 곳 | 까닭 |
| --- | --- | --- |
| `+=`, `-=`, `*=` 등 복합 대입 | 멤버 | 왼쪽을 고치고 `*this`를 돌려준다 |
| 단항 `-`, `!`, `++` | 멤버 | 인자가 자기 하나 |
| `+`, `-`, `*`, `==`, `<` 등 대칭인 것 | 바깥 함수 ([숨은 친구](#/read/cpp-syntax/class-static)) | 양쪽 인자를 똑같이 다룬다 |
| `=`, `[]`, `()`, `->` | 멤버만 된다 | 언어의 규칙 |

`2 * v`가 바깥 함수여야 하는 이유를 보여 줍니다. 멤버 `v.operator*(2)`는 왼쪽이 `Vec2`일 때만 불립니다. 왼쪽이 `double`인 경우는 바깥 함수로만 받을 수 있습니다.

`+`를 `+=`로 만드는 것은 관례입니다. 첫 인자를 **값으로** 받아 복사본을 만들고, 거기에 `+=`를 한 뒤 돌려줍니다. 두 연산이 어긋날 일이 없습니다.

## 바꿀 수 없는 것

- 새 연산자를 만들 수 없다 (`**`, `<>` 같은 것은 없다)
- 우선순위와 결합 방향, 인자의 개수는 그대로다
- 인자 가운데 적어도 하나는 내가 만든 타입이어야 한다 (`int + int`의 뜻은 못 바꾼다)
- `.`, `::`, `?:`, `sizeof`는 오버로딩할 수 없다

## 지킬 관례

연산자 오버로딩의 값어치는 "읽는 사람이 이미 아는 뜻"에서 나옵니다. 그 기대를 저버리면 함수 이름보다 못합니다.

| 기대 | 지키는 법 |
| --- | --- |
| `a + b`는 `a`와 `b`를 고치지 않는다 | 인자를 값이나 `const&`로 받고 새 값을 돌려준다 |
| `a += b` 뒤의 `a`는 `a + b`와 같다 | `+`를 `+=`로 만든다 |
| `a == b`면 `!(a != b)` | [기본 비교](#/read/cpp-syntax/op-compare)에 맡긴다 |
| 대입은 `*this`를 돌려준다 | `return *this;` |
| 수학이나 관례에 그 연산이 있다 | 없으면 이름 있는 함수로 (`dot(a, b)`, `append(x)`) |

`&&`, `||`, `,`는 오버로딩하지 않습니다. 내장 `&&`는 왼쪽이 거짓이면 오른쪽을 계산하지 않지만, 오버로딩하면 보통 함수 호출이 되어 양쪽을 다 계산합니다.

## 증가와 감소

```cpp nocheck
Counter& operator++()       // ++c: 올리고 자신을 돌려준다
{
    ++value_;
    return *this;
}
Counter operator++(int)     // c++: 옛 값을 돌려준다. int는 구분용 가짜 인자
{
    Counter old = *this;
    ++value_;
    return old;
}
```

뒤에 붙는 `c++`는 옛 값의 복사본을 만들어야 합니다. 반복자처럼 복사가 싸지 않을 수 있는 타입에서는 `++it`을 쓰는 습관이 여기서 나왔습니다.

<Note>
단위가 있는 값(`millivolt`, `std::chrono::milliseconds`)에 연산자를 주면 수식이 그대로 읽히면서도 단위가 섞이지 않습니다. `volt * ampere`가 `watt`를 돌려주게 만들 수도 있습니다. 연산자 오버로딩이 가장 값진 쓰임새입니다.
</Note>

## 정리

- 연산자는 `operator기호`라는 이름의 함수. 인자 하나는 내 타입이어야 한다
- 복합 대입은 멤버로, 대칭인 이항 연산자는 바깥 함수로 쓰고 `+`는 `+=`로 만든다
- 내장 타입에서의 뜻과 같게 움직이도록 한다. 아니면 이름 있는 함수가 낫다
