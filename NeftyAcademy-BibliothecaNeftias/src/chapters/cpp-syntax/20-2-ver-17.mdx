C++17은 "어휘 타입"의 판입니다. `optional`, `variant`, `string_view`처럼 함수의 서명에 쓰는 기본 단어들이 표준에 들어왔고, 템플릿을 쓰는 일이 한결 수월해졌습니다. 지금도 많은 프로젝트가 기준으로 삼는 판입니다. GCC는 11부터 15까지 C++17이 기본값이었습니다.

계산 순서도 일부 정해졌습니다. `a.b(c).d(e)`처럼 이어 부를 때 왼쪽이 먼저, `x = y`에서는 오른쪽이 먼저, `<<` 사슬은 왼쪽부터입니다. 그 전에는 `std::cout << f() << g();`에서 `g`가 먼저 불릴 수도 있었습니다.

## C++17의 모양

기능은 모두 C++17의 것이고, 출력만 이 책의 관례대로 `std::println`을 썼습니다.

```cpp
#include <filesystem>
#include <map>
#include <optional>
#include <print>
#include <string>
#include <string_view>
#include <type_traits>
#include <variant>

struct Off {};
struct Blink { int period_ms; };
struct Solid { bool high; };
using Mode = std::variant<Off, Blink, Solid>;           // 셋 가운데 하나

std::optional<int> find_pin(const std::map<std::string, int>& pins,
                            std::string_view name)
{
    // if 안에서 변수를 만들고 바로 검사한다
    if (auto it = pins.find(std::string(name)); it != pins.end())
        return it->second;
    return std::nullopt;
}

std::string describe(const Mode& mode)
{
    return std::visit([](const auto& m) -> std::string {
        using T = std::decay_t<decltype(m)>;
        if constexpr (std::is_same_v<T, Off>)           // 컴파일할 때 갈라진다
            return "off";
        else if constexpr (std::is_same_v<T, Blink>)
            return "blink " + std::to_string(m.period_ms) + "ms";
        else
            return m.high ? "high" : "low";
    }, mode);
}

int main()
{
    std::map<std::string, int> pins{{"led", 17}, {"button", 27}};

    for (const auto& [name, number] : pins)             // 구조적 바인딩
        std::println("{} -> {}", name, number);

    if (auto [it, inserted] = pins.try_emplace("led", 99); !inserted)
        std::println("led는 이미 {}", it->second);

    std::println("{}", find_pin(pins, "buzzer").value_or(-1));
    std::println("{}", describe(Blink{500}));
    std::println("{}", describe(Solid{true}));

    std::filesystem::path device = "/sys/class/gpio";
    std::println("{}", (device / "gpio17" / "value").string());
}
```

```text
button -> 27
led -> 17
led는 이미 17
-1
blink 500ms
high
/sys/class/gpio/gpio17/value
```

`std::variant`와 `std::visit`은 [가상 함수](#/read/cpp-syntax/inh-virtual) 없이 "종류에 따라 다르게"를 하는 방법입니다. 종류가 닫혀 있을 때 쓰고, 하나를 빠뜨리면 컴파일 오류가 납니다.

<Note>
GCC 7, Clang 5부터 언어 기능은 거의 다 되고, 라이브러리는 조금 늦었습니다. `<filesystem>`은 GCC 8(9부터는 따로 링크할 것이 없다), `std::from_chars`의 실수 판은 GCC 11, 병렬 알고리즘은 GCC에서 Intel TBB 라이브러리가 있어야 합니다.
</Note>

## 정리

- 언어: 구조적 바인딩, `if constexpr`, 접기 식, CTAD, `inline` 변수, 보장된 복사 생략
- 라이브러리: `optional`, `variant`, `string_view`, `filesystem`, `from_chars`, `pmr`
- `auto_ptr`, `throw()` 명세, `register`가 사라졌다
