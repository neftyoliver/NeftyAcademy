"모던 C++"은 C++11에서 시작합니다. 그 전의 C++(C++98, C++03)과는 다른 언어처럼 보일 만큼 많이 바뀌었고, 이 책의 앞쪽 절반이 사실상 C++11의 내용입니다. C++14는 3년 뒤에 그 모서리를 다듬었습니다.

## C++14의 모양

아래 프로그램은 `-std=c++14`로 컴파일됩니다. 그래서 출력에 `std::println`이 아니라 `std::cout`을 썼습니다.

```cpp
#include <iostream>
#include <memory>
#include <string>
#include <unordered_map>
#include <utility>
#include <vector>

enum class Level { low, high };                 // C++11: enum class

struct Pin {
    int number = 0;                             // C++11: 멤버의 기본값
    Level level = Level::low;
};

class Board {
public:
    Board(std::initializer_list<int> numbers)   // C++11: 중괄호 목록 받기
    {
        for (int n : numbers)                   // C++11: 범위 for
            pins_.push_back(Pin{n, Level::low});
    }
    Board(const Board&) = delete;               // C++11: = delete
    Board(Board&&) noexcept = default;          // C++11: 이동, = default, noexcept

    auto count() const { return pins_.size(); } // C++14: 반환 타입 추론

    template <typename F>
    void each(F visit) const
    {
        for (const auto& pin : pins_)           // C++11: auto
            visit(pin);
    }

private:
    std::vector<Pin> pins_;
};

int main()
{
    Board board{17, 27, 22};
    auto owned = std::make_unique<Board>(std::move(board));     // C++14

    int total = 0;
    owned->each([&total](const auto& pin) { total += pin.number; });    // C++14

    std::unordered_map<std::string, int> names{{"led", 17}, {"button", 27}};
    constexpr int mask = 0b1111'0000;           // C++14: 2진수와 자릿수 구분
    static_assert(mask == 240, "mask");         // C++11: static_assert

    std::cout << owned->count() << ' ' << total << ' ' << names.at("led") << '\n';
    int* nothing = nullptr;                     // C++11: nullptr
    std::cout << std::boolalpha << (nothing == nullptr) << '\n';
}
```

```text
3 66 17
true
```

## 왜 갈림길인가

C++11 이전의 코드는 `new`와 `delete`, 반복자를 손으로 돌리는 `for`, 긴 타입 이름으로 가득했습니다. C++11이 준 세 가지가 그것을 바꿨습니다.

| 도구 | 사라진 것 |
| --- | --- |
| 스마트 포인터와 이동 | 손으로 쓰는 `delete`, 깊은 복사를 피하려는 맨 포인터 |
| `auto`와 범위 `for` | `std::vector<int>::const_iterator it = v.begin();` |
| 람다 | 알고리즘에 넘기려고 따로 만드는 함수 객체 클래스 |

옛 문법은 여전히 컴파일됩니다. 오래된 코드를 읽는 법은 [「C++98과 C++03의 코드 읽기」](#/read/cpp-syntax/leg-98)에서 봅니다.

<Note>
컴파일러 지원은 오래전에 끝났습니다. GCC 5, Clang 3.4 이후면 C++14 전체를 씁니다. 지금 C++11이나 C++14에 머무는 까닭은 컴파일러가 아니라 대개 프로젝트의 정책이나 오래된 벤더 툴체인입니다. 마이크로컨트롤러용 벤더 컴파일러가 그런 경우가 있습니다.
</Note>

## 정리

- C++11: `auto`, 람다, 이동, 스마트 포인터, 범위 `for`, `constexpr`, 가변 인자 템플릿, 표준 스레드
- C++14: 제네릭 람다, `make_unique`, 넉넉해진 `constexpr`, 반환 타입 추론
- 이 둘이 지금 "C++답게 쓴다"고 할 때의 바탕이다
