지금까지의 멤버는 객체마다 하나씩 있었습니다. `static` 멤버는 **클래스에 하나**만 있고, `friend`는 클래스 바깥의 함수에게 `private`을 열어 줍니다.

## static 멤버

```cpp
#include <print>

class Sensor {
public:
    // 이름 있는 생성 함수: 단위를 이름으로 밝힌다
    static Sensor celsius(double c) { return Sensor(c + 273.15); }
    static Sensor kelvin(double k) { return Sensor(k); }
    static int count() { return count_; }

    double kelvin_value() const { return kelvin_; }

    friend bool hotter(const Sensor& a, const Sensor& b)    // 숨은 친구
    {
        return a.kelvin_ > b.kelvin_;                       // private에 접근한다
    }

private:
    explicit Sensor(double k) : kelvin_(k) { ++count_; }

    double kelvin_;
    static inline int count_ = 0;       // 객체마다가 아니라 클래스에 하나
};

int main()
{
    Sensor a = Sensor::celsius(25);
    Sensor b = Sensor::kelvin(300);
    std::println("{} {}", a.kelvin_value(), b.kelvin_value());
    std::println("{} {}", hotter(a, b), Sensor::count());
}
```

```text
298.15 300
false 2
```

| | 보통 멤버 | `static` 멤버 |
| --- | --- | --- |
| 변수 | 객체마다 하나 | 클래스에 하나. 전역 변수와 같은 곳에 놓인다 |
| 함수 | `this`가 있다. `객체.함수()` | `this`가 없다. `클래스::함수()` |
| 객체의 크기 | 차지한다 | 차지하지 않는다 |

`static` 멤버 변수는 이름이 클래스 안에 있고 접근 지정을 따르는 전역 변수입니다. `static inline`으로 적으면 클래스 안에서 바로 초깃값을 줄 수 있습니다(C++17). 상수라면 `static constexpr int max_pins = 40;`으로 씁니다.

## 이름 있는 생성 함수

생성자는 이름을 고를 수 없어서, 인자 타입이 같으면 구분할 수 없습니다. `Sensor(double)`은 섭씨인지 켈빈인지 말해 주지 않습니다. 위에서는 생성자를 `private`으로 숨기고 `static` 함수 두 개를 내놓았습니다. `Sensor::celsius(25)`는 읽는 그대로입니다.

`static` 멤버 함수는 `this`가 없으므로 보통 멤버를 직접 쓸 수 없지만, 클래스 안의 함수이므로 `private` 생성자는 부를 수 있습니다.

## static이라는 낱말의 세 뜻

| 자리 | 뜻 |
| --- | --- |
| 함수 밖의 변수·함수 앞 | 이 파일 안에서만 보인다 (C와 같다. C++에서는 [이름 없는 네임스페이스](#/read/cpp-syntax/ns-basic)를 쓴다) |
| 함수 안의 변수 앞 | 함수가 끝나도 살아 있다. 처음 지나갈 때 한 번 초기화된다 |
| 클래스 안 | 객체가 아니라 클래스에 속한다 |

## friend

`friend`로 선언한 함수나 클래스는 그 클래스의 `private` 멤버를 쓸 수 있습니다. 캡슐화에 구멍을 내는 것이라 아껴 쓰지만, 꼭 맞는 자리가 있습니다. **멤버 함수로 만들 수 없는 연산**입니다.

| 쓰는 곳 | 까닭 |
| --- | --- |
| `operator==`, `operator<<` 같은 연산자 | 왼쪽 인자가 내 타입이 아니거나, 양쪽을 대등하게 다뤄야 한다 |
| 두 객체의 속을 함께 보는 함수 | 위의 `hotter` |
| 시험 코드, 짝을 이루는 클래스 (컨테이너와 그 반복자) | 서로의 속을 알아야 한다 |

## 숨은 친구

`hotter`는 클래스 **안에** 본문까지 적은 `friend` 함수입니다. 이런 함수는 `Sensor`의 멤버가 아니라 바깥 네임스페이스의 함수이지만, 이름이 바깥에 드러나지 않습니다. `Sensor`를 인자로 넘길 때만 [ADL](#/read/cpp-syntax/ns-adl)로 찾아집니다.

- 관계없는 타입의 오버로드 후보에 끼어들지 않는다 (오류 메시지가 짧아지고 컴파일이 빨라진다)
- 암시적 변환으로 엉뚱한 타입이 끌려 들어오지 않는다

연산자는 이렇게 숨은 친구로 쓰는 것이 요즘의 기본입니다([「비교와 우주선 연산자」](#/read/cpp-syntax/op-compare)).

<Note kind="warn">
`static` 멤버 변수는 전역 변수입니다. 여러 스레드가 함께 고치면 경쟁 상태가 되고, 다른 전역 변수의 초기화에서 쓰면 [초기화 순서 문제](#/read/cpp-syntax/life-static-init)에 걸립니다. 상수가 아닌 `static` 멤버는 꼭 필요한지 한 번 더 생각하세요.
</Note>

## 정리

- `static` 멤버는 클래스에 하나. 함수는 `this` 없이 `클래스::함수()`로 부른다
- 생성자에 이름이 필요하면 `private` 생성자 + `static` 생성 함수
- `friend`는 연산자처럼 멤버로 만들 수 없는 함수에. 클래스 안에 정의하면 ADL로만 찾아진다
