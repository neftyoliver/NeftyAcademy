참조를 인자로 받는 것은 안전합니다. 부른 쪽의 변수는 함수가 도는 동안 살아 있습니다. 참조를 **돌려주는** 것은 다릅니다. 돌려준 참조가 가리키는 것이 함수보다 오래 살아야 합니다.

## 죽은 것을 가리키는 참조

```cpp nocheck
const std::string& make_label(int id)
{
    std::string s = "pin-" + std::to_string(id);
    return s;       // s는 여기서 사라진다
}

const std::string& label = make_label(3);
std::println("{}", label);      // 정의되지 않은 동작
```

C에서 지역 변수의 주소를 돌려주던 것과 같은 실수입니다([「흔한 실수」](#/read/c-basic/ptr-mistakes)). 컴파일러가 경고해 주지만 경로가 복잡하면 놓칩니다. **지역 변수는 값으로 돌려줍니다.** 뒤에서 보겠지만 값으로 돌려줘도 복사는 일어나지 않습니다.

## 돌려줘도 되는 경우

```cpp
#include <print>
#include <string>
#include <vector>

// 인자로 받은 컨테이너의 칸을 돌려준다. 컨테이너가 살아 있는 동안 유효하다
std::string& longest(std::vector<std::string>& names)
{
    std::size_t best = 0;
    for (std::size_t i = 1; i < names.size(); ++i)
        if (names[i].size() > names[best].size())
            best = i;
    return names[best];
}

int main()
{
    std::vector<std::string> names = {"led", "button", "fan"};
    longest(names) += "!";              // 돌려받은 참조로 원본을 고친다
    std::string copy = longest(names);  // 값으로 받으면 복사
    copy += "?";
    std::println("{} {}", names[1], copy);
}
```

```text
button! button!?
```

| 돌려주는 것 | 안전한가 |
| --- | --- |
| 지역 변수, 값으로 받은 인자 | 아니다 |
| 참조로 받은 인자, 또는 그 안의 일부 | 부른 쪽의 것이 살아 있는 동안 |
| 클래스 멤버 (멤버 함수에서) | 그 객체가 살아 있는 동안 |
| 전역 변수, `static` 지역 변수 | 언제나 |

`v[0] = 1;`이 되는 것도 `operator[]`가 칸의 참조를 돌려주기 때문입니다. 참조 반환은 "안에 있는 것을 꺼내 보여 준다"는 뜻으로 씁니다.

## 임시 객체를 거치면

```cpp nocheck
const int& m = std::min(count, 10);     // 위험
```

`std::min`은 인자를 `const int&`로 받아 그중 하나를 `const int&`로 돌려줍니다. `10`은 임시 객체이고, 그 문장이 끝나면 사라집니다. `count`가 10보다 크면 `m`은 죽은 임시 객체를 가리킵니다. [앞 챕터](#/read/cpp-syntax/ref-const)의 "수명이 늘어난다"는 규칙은 임시 객체를 **직접** 묶을 때만 통하고, 함수를 한 번 거치면 통하지 않습니다.

고치는 법은 간단합니다. 값으로 받습니다.

```cpp nocheck
int m = std::min(count, 10);            // 복사. 안전
```

같은 꼴의 실수가 하나 더 있습니다.

```cpp nocheck
// load_config()가 돌려준 임시 객체는 이 줄이 끝나면 죽는다
const std::string& name = load_config().name();

std::string name = load_config().name();           // 복사. 안전
```

## 값으로 돌려주는 것이 기본

C에서는 큰 구조체를 값으로 돌려주면 복사가 아까워서 출력 인자를 썼습니다. C++에서는 그럴 필요가 없습니다.

```cpp
#include <print>
#include <vector>

std::vector<int> squares(int n)
{
    std::vector<int> out;
    for (int i = 1; i <= n; ++i)
        out.push_back(i * i);
    return out;         // 복사되지 않는다
}

int main()
{
    std::vector<int> v = squares(4);
    std::println("{} {}", v.size(), v.back());
}
```

```text
4 16
```

`return out;`은 벡터를 복사하지 않습니다. 컴파일러가 `out`을 처음부터 `v`의 자리에 만들거나, 그러지 못하면 내용물을 옮깁니다([「std::move와 복사 생략」](#/read/cpp-syntax/sm-elision)).

<Note kind="tip">
참조를 받는 변수를 선언할 때마다 "이것이 가리키는 것은 누가 들고 있고, 이 변수보다 오래 사는가"를 물어보세요. 답이 바로 나오지 않으면 `auto&` 대신 `auto`로 복사해 두는 편이 안전합니다.
</Note>

## 정리

- 지역 변수의 참조를 돌려주지 않는다. 값으로 돌려준다
- 참조 반환은 인자나 멤버처럼 "함수보다 오래 사는 것"을 보여 줄 때만
- 함수가 돌려준 참조가 임시 객체에서 나온 것이면 그 문장이 끝날 때 죽는다
