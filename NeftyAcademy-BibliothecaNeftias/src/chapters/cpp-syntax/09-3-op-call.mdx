export const summary = 'operator[]로 칸 내주기, operator()로 함수처럼 불리는 객체';

`v[i]`와 `f(x)`도 연산자입니다. 이 둘을 정의하면 내 타입을 배열처럼, 함수처럼 쓸 수 있습니다. `std::vector`의 `[]`와 람다가 이렇게 만들어져 있습니다.

## 첨자와 호출

```cpp
#include <algorithm>
#include <array>
#include <cstddef>
#include <print>
#include <vector>

class Grid {
public:
    // C++23: 첨자를 여러 개 받는다
    int& operator[](std::size_t row, std::size_t col)
    {
        return cells_[row * 3 + col];
    }
    int operator[](std::size_t row, std::size_t col) const
    {
        return cells_[row * 3 + col];
    }

private:
    std::array<int, 9> cells_{};
};

class Above {                           // 함수처럼 부를 수 있는 객체
public:
    explicit Above(int limit) : limit_(limit) {}
    bool operator()(int v) const { return v > limit_; }

private:
    int limit_;
};

int main()
{
    Grid g;
    g[1, 2] = 7;
    const Grid& view = g;
    std::println("{} {}", view[1, 2], view[0, 0]);

    Above above20(20);
    std::println("{} {}", above20(25), above20(5));

    std::vector<int> temps = {18, 22, 25, 19};
    std::println("{}", std::count_if(temps.begin(), temps.end(), above20));
}
```

```text
7 0
true false
2
```

## operator[]

`g[1, 2] = 7;`이 되려면 `operator[]`가 **칸의 참조**를 돌려줘야 합니다. 값을 돌려주면 임시 값에 대입하는 것이 되어 원본이 바뀌지 않습니다.

[`const` 오버로드](#/read/cpp-syntax/class-const)를 짝으로 둡니다. `const` 객체에서는 고칠 수 없는 것(값이나 `const&`)을 돌려줍니다.

| 표준 | 첨자의 개수 | 2차원에 쓰던 방법 |
| --- | --- | --- |
| C++20까지 | 하나만 | `g(1, 2)`로 `operator()`를 빌려 쓰거나 `g[1][2]`가 되도록 줄을 나타내는 객체를 돌려줌 |
| C++23부터 | 여러 개 | `g[1, 2]` |

범위 검사를 넣을지는 설계의 몫입니다. 표준 컨테이너는 `[]`는 검사하지 않고 `at()`은 검사하는 두 길을 둡니다.

## operator()

`operator()`를 가진 객체를 **함수 객체**라고 합니다. 함수와 다른 점은 **상태를 들고 있다**는 것입니다. `Above`는 만들어질 때 받은 `limit_`를 기억합니다.

이것은 [람다](#/read/cpp-syntax/fn-lambda)의 정체이기도 합니다.

```cpp nocheck
int limit = 20;
auto above = [limit](int v) { return v > limit; };
```

컴파일러는 이 람다를 위의 `Above`와 거의 같은 클래스로 바꿉니다. 캡처한 변수가 멤버가 되고, 본문이 `operator()`가 됩니다. 람다가 나오기 전(C++03)에는 이런 클래스를 일일이 손으로 썼습니다.

지금 함수 객체 클래스를 직접 쓰는 것은 다음 경우입니다.

| 경우 | 예 |
| --- | --- |
| 타입에 이름이 필요하다 | `std::map<Key, Value, MyCompare>`의 비교자 |
| 호출 방법이 여럿이다 | `operator()`를 인자 타입별로 오버로드 |
| 상태를 밖에서 읽거나 고쳐야 한다 | 평균을 누적하는 객체에 `result()` 함수를 둔다 |

## 누적하는 함수 객체

```cpp
#include <print>
#include <vector>

class Average {
public:
    void operator()(double v)
    {
        sum_ += v;
        ++count_;
    }
    double result() const { return count_ ? sum_ / count_ : 0; }

private:
    double sum_ = 0;
    int count_ = 0;
};

int main()
{
    Average avg;
    for (double v : std::vector<double>{20.0, 21.0, 25.0})
        avg(v);
    std::println("{}", avg.result());
}
```

```text
22
```

## 포인터처럼 보이게 하는 연산자

`*p`와 `p->member`도 정의할 수 있습니다. 스마트 포인터와 반복자가 이것으로 포인터 흉내를 냅니다.

```cpp nocheck
T& operator*() const { return *ptr_; }
T* operator->() const { return ptr_; }      // 돌려준 포인터에 다시 -> 가 적용된다
```

`std::unique_ptr`, `std::optional`, 컨테이너의 반복자가 모두 이 둘을 가지고 있어서 포인터와 같은 문법으로 쓰입니다.

<Note>
표준 라이브러리에는 미리 만들어진 함수 객체들이 있습니다. `std::less<>`, `std::greater<>`, `std::plus<>` 등입니다. `std::sort(v.begin(), v.end(), std::greater<>());`는 내림차순 정렬입니다.
</Note>

## 정리

- `operator[]`는 칸의 참조를 돌려준다. `const` 판을 짝으로 둔다. C++23부터 첨자를 여러 개 받는다
- `operator()`를 가진 객체는 상태를 가진 함수. 람다가 바로 이것이다
- `*`와 `->`를 정의하면 포인터처럼 쓰이는 타입이 된다
