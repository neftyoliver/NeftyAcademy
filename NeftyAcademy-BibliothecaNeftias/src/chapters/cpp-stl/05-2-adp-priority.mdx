`std::priority_queue`는 넣은 순서와 상관없이 **가장 우선인 것**이 먼저 나오는 큐입니다. `<queue>` 헤더에 있고, [`stack`과 `queue`](#/read/cpp-stl/adp-stack)처럼 다른 컨테이너를 감싼 어댑터입니다. 속은 `vector`이고 그 위에 힙이라는 배치를 유지합니다.

| 연산 | 걸리는 시간 |
| --- | --- |
| `top()`: 가장 우선인 것 보기 | O(1) |
| `push`, `emplace`: 넣기 | O(log n) |
| `pop()`: 가장 우선인 것 빼기 | O(log n) |

## 기본은 큰 것이 먼저

```cpp
#include <functional>
#include <print>
#include <queue>
#include <vector>

int main()
{
    std::priority_queue<int> largest_first;
    std::priority_queue<int, std::vector<int>, std::greater<>> smallest_first;
    for (int v : {30, 10, 50, 20}) {
        largest_first.push(v);
        smallest_first.push(v);
    }

    while (!largest_first.empty()) {
        std::print("{} ", largest_first.top());
        largest_first.pop();
    }
    std::println("");
    while (!smallest_first.empty()) {
        std::print("{} ", smallest_first.top());
        smallest_first.pop();
    }
    std::println("");
}
```

```text
50 30 20 10
10 20 30 50
```

비교자의 기본값은 `std::less`인데 나오는 것은 **가장 큰 값**입니다. "비교자로 정렬했을 때 맨 뒤에 올 것이 먼저 나온다"고 기억합니다. 작은 것부터 받으려면 `std::greater<>`를 주고, 그러려면 둘째 인자(속의 컨테이너)까지 적어야 합니다.

## 타이머 줄 세우기

"가장 이른 시각의 일을 먼저"가 대표적인 쓰임입니다. 구조체를 넣고 비교자를 직접 줍니다.

```cpp
#include <print>
#include <queue>
#include <string>
#include <vector>

struct Timer {
    int due_ms;
    std::string name;
};

// "a 가 b 보다 나중이다"가 참이면 b 가 먼저 나온다
struct Later {
    bool operator()(const Timer& a, const Timer& b) const
    {
        return a.due_ms > b.due_ms;
    }
};

int main()
{
    std::priority_queue<Timer, std::vector<Timer>, Later> timers;
    timers.push({500, "LED 끄기"});
    timers.push({100, "센서 읽기"});
    timers.emplace(1000, "서버로 보내기");
    timers.push({100, "버튼 확인"});

    int now_ms = 0;
    while (!timers.empty()) {
        const Timer& next = timers.top();
        now_ms = next.due_ms;       // 실제 코드라면 여기서 그 시각까지 잔다
        std::println("{:5}ms {}", now_ms, next.name);
        timers.pop();               // next 는 이제 죽은 참조다
    }
}
```

```text
  100ms 센서 읽기
  100ms 버튼 확인
  500ms LED 끄기
 1000ms 서버로 보내기
```

- 도는 중에 새 타이머를 `push`해도 됩니다. 반복 타이머는 꺼낸 뒤 다음 시각으로 다시 넣습니다.
- 우선순위가 **같은 것끼리의 순서는 보장되지 않습니다.** 위에서 100ms의 두 일이 넣은 차례로 나온 것은 우연입니다. 넣은 순서를 지켜야 하면 구조체에 일련번호를 넣어 비교에 함께 쓰거나 [`multimap`](#/read/cpp-stl/assoc-multi)을 씁니다.
- 가운데 원소를 지우거나 우선순위를 고치는 연산이 없습니다. 취소는 "취소됨" 표시를 해 두고 꺼낼 때 건너뛰는 식으로 합니다.

## 상위 k개

끝없이 들어오는 값에서 가장 큰 세 개만 들고 있으려면, 거꾸로 **작은 것이 먼저 나오는** 큐를 크기 3으로 유지합니다. 넷이 되면 가장 작은 것을 버립니다.

```cpp
#include <functional>
#include <print>
#include <queue>
#include <vector>

int main()
{
    const std::size_t k = 3;
    std::priority_queue<int, std::vector<int>, std::greater<>> top;
    for (int reading : {41, 73, 12, 98, 55, 67, 30}) {
        top.push(reading);
        if (top.size() > k)
            top.pop();          // 넷 가운데 가장 작은 것을 버린다
    }
    while (!top.empty()) {
        std::print("{} ", top.top());
        top.pop();
    }
    std::println("");
}
```

```text
67 73 98
```

값이 100만 개여도 메모리는 k칸뿐이고, 값 하나에 O(log k)입니다. 전부 모아 정렬하는 것보다 훨씬 쌉니다.

## 옮겨 꺼낼 수 없다

`top()`은 `const` 참조를 돌려줍니다. 고치면 힙의 배치가 깨지기 때문입니다. 그래서 `std::string`이 든 원소를 꺼낼 때 복사가 일어나고, `std::unique_ptr` 같은 타입은 꺼낼 방법이 없습니다. 이럴 때는 어댑터를 쓰지 않고, 내 `vector`에 힙 알고리즘을 직접 부릅니다.

```cpp
#include <algorithm>
#include <memory>
#include <print>
#include <string>
#include <utility>
#include <vector>

struct Job {
    int priority;
    std::unique_ptr<std::string> payload;       // 복사할 수 없는 멤버
};

int main()
{
    const auto lower = [](const Job& a, const Job& b) {
        return a.priority < b.priority;
    };
    std::vector<Job> jobs;

    for (int priority : {2, 9, 5}) {
        jobs.push_back({priority, std::make_unique<std::string>("job")});
        std::ranges::push_heap(jobs, lower);    // 방금 넣은 것을 제자리로 올린다
    }

    while (!jobs.empty()) {
        std::ranges::pop_heap(jobs, lower);     // 가장 우선인 것을 맨 뒤로 보낸다
        Job job = std::move(jobs.back());       // 옮겨서 꺼낸다
        jobs.pop_back();
        std::println("{} {}", job.priority, *job.payload);
    }
}
```

```text
9 job
5 job
2 job
```

`priority_queue`가 속에서 하는 일이 바로 이 `push_heap`과 `pop_heap`입니다. 힙 알고리즘은 [「집합, 힙, 순열」](#/read/cpp-stl/alg-set-heap)에서 다시 봅니다.

<Note>
"차례로 꺼내기만 한다"면 `priority_queue`, "꺼내면서 가운데도 찾고 지운다"면 [`multiset`](#/read/cpp-stl/assoc-multi)입니다. `priority_queue`는 `vector` 한 덩어리여서 노드마다 할당하는 `multiset`보다 메모리와 속도에서 유리합니다.
</Note>

## 정리

- `priority_queue`는 `vector` 위의 힙이다. 기본은 가장 큰 것이 먼저, `std::greater<>`를 주면 가장 작은 것이 먼저
- 같은 우선순위끼리의 순서는 보장되지 않고, 가운데를 지우거나 고칠 수 없다
- `top()`은 `const`여서 옮겨 꺼내지 못한다. 그럴 때는 `vector`에 `push_heap`, `pop_heap`을 직접 쓴다
