지금까지 구간은 반복자 **둘**이었습니다. 처음과 끝이고, 둘은 같은 타입이었습니다. 그런데 끝이 꼭 "자리"일 필요는 없습니다. "가리키는 글자가 `\0`이면 끝", "100개를 읽었으면 끝"처럼 **조건**이어도 됩니다. C++20의 레인지는 끝의 타입이 처음과 달라도 되게 했고, 그런 끝을 센티널이라고 부릅니다.

## 길이를 모르는 문자열

C 문자열은 끝을 알려면 `\0`까지 가 봐야 합니다. 반복자 둘로 넘기려면 먼저 `strlen`으로 한 번 훑어 끝을 구하고, 알고리즘이 한 번 더 훑습니다. 센티널로는 한 번에 됩니다.

```cpp
#include <algorithm>
#include <iterator>
#include <print>
#include <ranges>

// 끝을 조건으로 나타낸다: 가리키는 글자가 \0 이면 끝
struct Nul {
    bool operator==(const char* p) const { return *p == '\0'; }
};
static_assert(std::sentinel_for<Nul, const char*>);

int main()
{
    const char* text = "GPIO17=HIGH";       // 길이를 모른다

    const char* eq = std::ranges::find(text, Nul{}, '=');   // 한 번만 훑는다
    std::println("= 의 자리 {}", eq - text);
    std::println("I 의 개수 {}", std::ranges::count(text, Nul{}, 'I'));

    for (char c : std::ranges::subrange(text, Nul{}))       // 범위 기반 for 에도
        std::print("{}", c == '=' ? ' ' : c);
    std::println("");
}
```

```text
= 의 자리 6
I 의 개수 2
GPIO17 HIGH
```

센티널이 되려면 반복자와 `==`로 견줄 수 있으면 됩니다. 알고리즘은 한 칸 갈 때마다 `it == 끝`을 묻고, 그때 `Nul`의 `operator==`가 불립니다. `std::ranges::subrange(처음, 끝)`은 그 둘을 묶어 범위 하나로 만들어 줍니다.

반복자가 못 찾았을 때 무엇을 돌려주는지가 달라집니다. `std::ranges::find`는 언제나 **반복자**를 돌려주므로, 못 찾으면 `\0`을 가리키는 포인터가 옵니다. `end`와 견주는 대신 `*eq == '\0'`인지를 봅니다.

## 표준이 주는 센티널

| 센티널 | 끝나는 때 | 짝이 되는 반복자 |
| --- | --- | --- |
| `std::default_sentinel` | 반복자 스스로 끝을 안다 | `std::counted_iterator`, `std::istream_iterator` |
| `std::unreachable_sentinel` | 끝나지 않는다 | 아무것이나 |

```cpp
#include <algorithm>
#include <iterator>
#include <print>
#include <ranges>
#include <vector>

int main()
{
    const std::vector<int> v = {5, 3, 8, 1, 9};

    // 앞에서 셋만: 개수를 세는 반복자와, 그것이 0이 되면 끝인 센티널
    const std::counted_iterator counted(v.begin(), 3);
    const auto first3 = std::ranges::subrange(counted, std::default_sentinel);
    std::println("앞의 셋 가운데 최대 {}", std::ranges::max(first3));

    // 8이 반드시 있다는 것을 안다. 끝 검사를 하지 않는다
    const auto it = std::ranges::find(v.begin(), std::unreachable_sentinel, 8);
    std::println("8의 자리 {}", it - v.begin());
}
```

```text
앞의 셋 가운데 최대 8
8의 자리 2
```

<Note kind="warn">
`std::unreachable_sentinel`은 "끝을 넘는 일은 없다"는 **내 약속**입니다. 칸마다 하던 끝 검사가 빠져서 조금 빨라지지만, 찾는 값이 없으면 배열 밖으로 계속 나갑니다. 찾는 값을 맨 끝에 미리 넣어 두는 식으로 약속을 구조로 지킬 수 있을 때만 씁니다.
</Note>

"앞에서 n개"나 "조건이 맞는 동안"은 대개 센티널을 직접 쓰지 않고 `std::views::take`, `std::views::take_while`로 씁니다. 그 뷰들이 속에서 이런 센티널을 씁니다([「뷰」](#/read/cpp-stl/rng-views)).

## 옛 알고리즘과 맞추기

`std::find`, `std::count`, `std::accumulate` 같은 옛 알고리즘과 컨테이너의 생성자는 처음과 끝이 **같은 타입**이어야 합니다. 센티널이 있는 범위를 넘기려면 `std::views::common`으로 타입을 맞춥니다.

```cpp
#include <algorithm>
#include <print>
#include <ranges>
#include <string>

struct Nul {
    bool operator==(const char* p) const { return *p == '\0'; }
};

int main()
{
    const char* text = "GPIO17=HIGH";
    auto chars = std::ranges::subrange(text, Nul{});

    // 오류: 두 인자의 타입이 다르다
    // std::count(chars.begin(), chars.end(), 'H');
    auto same_type = chars | std::views::common;
    std::println("{}", std::count(same_type.begin(), same_type.end(), 'H'));

    const std::string copy(same_type.begin(), same_type.end());    // 옛 생성자에도
    std::println("{} ({}글자)", copy, copy.size());
}
```

```text
2
GPIO17=HIGH (11글자)
```

범위 기반 for는 C++17부터 처음과 끝의 타입이 달라도 받습니다. 그래서 위의 첫 예제에서 `subrange`를 그대로 돌 수 있었습니다.

## 언제 직접 만드나

센티널을 직접 쓰는 일은 드뭅니다. 쓰게 되는 자리는 대개 **끝을 알려면 값을 읽어 봐야 하는 자료**입니다.

| 자료 | 끝의 조건 |
| --- | --- |
| C 문자열, `\0`으로 끝나는 표 | 가리키는 값이 0 |
| 길이 바이트 없이 종료 표시로 끝나는 프레임 | 가리키는 값이 종료 바이트 |
| 연결 리스트를 따라가는 포인터 | 포인터가 `nullptr` |
| 소켓이나 센서에서 오는 값 | 읽기가 실패 |

내 범위의 `end()`가 센티널을 돌려주게 하면, [반복자를 직접 만들 때](#/read/cpp-stl/it-own) "끝을 나타내는 반복자"를 억지로 꾸며 내지 않아도 됩니다.

## 정리

- 구간의 끝은 반복자와 `==`로 견줄 수 있는 것이면 된다. 그것이 센티널이다
- 끝을 알려면 읽어 봐야 하는 자료(C 문자열 등)를 한 번만 훑게 해 준다
- 옛 알고리즘에는 `std::views::common`으로 처음과 끝의 타입을 맞춰 넘긴다
