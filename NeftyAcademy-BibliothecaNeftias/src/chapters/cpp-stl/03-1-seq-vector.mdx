## 세 포인터

`std::vector<T>` 객체는 포인터 셋입니다. 원소가 시작하는 곳, 원소가 끝나는 곳, 잡아 둔 메모리가 끝나는 곳입니다. 64비트에서 24바이트이고, 원소는 힙의 한 덩어리에 **빈틈없이 줄지어** 있습니다.

이 "줄지어 있다"가 `vector`의 값어치입니다. 차례로 읽을 때 [캐시가 돕고](#/read/cpp-stl/ov-complexity), `v.data()`와 `v.size()`를 그대로 C 함수에 넘길 수 있습니다.

| 만드는 법 | 결과 |
| --- | --- |
| `std::vector<int> v;` | 비어 있다. 할당도 없다 |
| `std::vector<int> v(5);` | 0이 다섯 개 |
| `std::vector<int> v(5, 7);` | 7이 다섯 개 |
| `std::vector<int> v = {5, 7};` | 5와 7, 두 개 |
| `std::vector<int> v(first, last);` | 반복자 구간의 사본 |

## push_back과 emplace_back

둘 다 끝에 넣습니다. 차이는 **무엇을 받는가**입니다. `push_back`은 만들어진 객체를 받고, `emplace_back`은 생성자의 인자를 받아 그 칸에서 바로 만듭니다.

```cpp
#include <print>
#include <string>
#include <utility>
#include <vector>

struct Reading {
    std::string sensor;
    double value;

    Reading(std::string s, double v) : sensor(std::move(s)), value(v)
    {
        std::println("  생성 {}", sensor);
    }
    Reading(const Reading& other) : sensor(other.sensor), value(other.value)
    {
        std::println("  복사 {}", sensor);
    }
    Reading(Reading&& other) noexcept
        : sensor(std::move(other.sensor)), value(other.value)
    {
        std::println("  이동 {}", sensor);
    }
};

int main()
{
    std::vector<Reading> log;
    log.reserve(4);                         // 재할당이 끼어들지 않게

    std::println("push_back(임시 객체):");
    log.push_back(Reading("temp", 23.5));   // 만들고, 칸으로 옮긴다

    std::println("emplace_back(인자):");
    log.emplace_back("humid", 41.0);        // 칸에서 바로 만든다

    std::println("push_back(이름 있는 객체):");
    Reading r("press", 1013.2);
    log.push_back(r);                       // 복사
    log.push_back(std::move(r));            // 이동
}
```

```text
push_back(임시 객체):
  생성 temp
  이동 temp
emplace_back(인자):
  생성 humid
push_back(이름 있는 객체):
  생성 press
  복사 press
  이동 press
```

`emplace_back`이 이동 한 번을 아꼈습니다. 다만 이미 만든 객체를 넣을 때는 둘이 같습니다. `log.emplace_back(r)`은 `push_back(r)`과 똑같이 복사합니다.

<Note kind="warn">
`emplace_back`은 `explicit` 생성자도 부릅니다. `std::vector<std::vector<int>> rows;`에서 `rows.push_back(10)`은 컴파일되지 않지만 `rows.emplace_back(10)`은 "원소가 10개인 벡터"를 조용히 넣습니다. 객체가 손에 있으면 `push_back`, 인자로 그 자리에서 만들 때만 `emplace_back`으로 나눠 쓰면 이런 일이 줄어듭니다.
</Note>

가운데에 넣는 `insert(위치, 값)`과 `emplace(위치, 인자…)`도 있습니다. 넣은 자리 뒤의 원소를 모두 한 칸씩 밀어야 하므로 O(n)입니다.

## reserve와 resize

이름이 비슷해서 자주 바꿔 씁니다. `reserve`는 **자리**를 잡고, `resize`는 **원소**를 만듭니다.

```cpp
#include <print>
#include <vector>

void show(const char* label, const std::vector<int>& v)
{
    std::print("{:10}", label);
    for (int x : v)
        std::print("{} ", x);
    std::println("");
}

int main()
{
    std::vector<int> a;
    a.reserve(3);       // 자리만 잡았다. 원소는 아직 없다
    std::println("reserve 뒤 size {} capacity {}", a.size(), a.capacity());

    std::vector<int> b;
    b.resize(3);        // 0인 원소 셋을 만들었다
    std::println("resize 뒤  size {} capacity {}", b.size(), b.capacity());
    b[1] = 7;           // 된다. a[1] = 7 은 없는 원소에 쓰는 것이다

    std::vector<int> ids = {10, 20, 30, 40, 50};
    ids[1] = ids.back();    // 순서가 상관없으면: 마지막 원소로 덮고
    ids.pop_back();         // 끝을 뗀다. O(1)
    show("덮고 떼기", ids);

    ids.erase(ids.begin());     // 순서를 지키며 지운다. 뒤를 모두 당긴다. O(n)
    show("erase", ids);

    std::erase_if(ids, [](int x) { return x > 35; });   // 조건에 맞는 것 모두
    show("erase_if", ids);
}
```

```text
reserve 뒤 size 0 capacity 3
resize 뒤  size 3 capacity 3
덮고 떼기 10 50 30 40
erase     50 30 40
erase_if  30
```

- `a.reserve(3); a[1] = 7;`은 정의되지 않은 동작입니다. 메모리는 있지만 원소가 없습니다. `size()`도 0인 채입니다. C 함수가 채울 버퍼가 필요하면 `resize`, `push_back`을 여러 번 할 것이면 `reserve`입니다.
- 지우는 방법은 셋입니다. 순서가 상관없으면 **마지막 원소로 덮고 떼기**가 O(1)입니다. 입자나 연결 목록처럼 자주 지우는 곳에서 씁니다. 여러 개를 지울 때는 `erase`를 되풀이하지 말고 `std::erase_if` 한 번으로 합니다.
- 메모리는 스스로 줄지 않습니다. `clear()` 뒤에도 `capacity()`는 그대로이고, 돌려주려면 `shrink_to_fit()`을 부릅니다.

## 다시 할당될 때

용량이 모자라면 `vector`는 더 큰 덩어리를 잡고 원소를 옮깁니다. 이때 일어나는 일 셋을 기억합니다.

| 일어나는 일 | 다루는 곳 |
| --- | --- |
| 원소를 가리키던 포인터, 참조, 반복자가 모두 죽는다 | [「반복자 무효화 규칙」](#/read/cpp-stl/seq-invalidation) |
| 이동 생성자가 `noexcept`가 아니면 이동 대신 **복사**한다 | [「noexcept」](#/read/cpp-syntax/exc-noexcept) |
| 잠깐 옛 덩어리와 새 덩어리가 함께 있다 | 아래 |

셋째는 메모리가 작은 기기에서 중요합니다. 100MB짜리 `vector`가 자라는 순간에는 100MB와 200MB가 함께 필요합니다. 램이 512MB인 보드에서 큰 버퍼를 `push_back`으로 키우다가 여기서 죽는 일이 있습니다. 크기를 알면 처음에 `reserve`합니다.

## 2차원으로 쓰기

`std::vector<std::vector<int>>`는 행마다 따로 할당된 덩어리입니다. 행의 길이가 모두 같다면, 한 덩어리에 담고 첨자를 계산하는 편이 빠르고 할당도 한 번입니다.

```cpp
#include <cstddef>
#include <print>
#include <vector>

class Grid {
public:
    Grid(std::size_t rows, std::size_t cols) : cols_(cols), cells_(rows * cols) {}

    // C++23: 첨자 연산자가 인자를 여럿 받는다
    int& operator[](std::size_t row, std::size_t col)
    {
        return cells_[row * cols_ + col];
    }

    std::size_t rows() const { return cells_.size() / cols_; }
    std::size_t cols() const { return cols_; }

private:
    std::size_t cols_;
    std::vector<int> cells_;        // 행들을 이어 붙인 한 덩어리
};

int main()
{
    Grid grid(2, 3);
    grid[1, 2] = 5;
    for (std::size_t r = 0; r < grid.rows(); ++r) {
        for (std::size_t c = 0; c < grid.cols(); ++c)
            std::print("{} ", grid[r, c]);
        std::println("");
    }
}
```

```text
0 0 0
0 0 5
```

이 일을 표준이 해 주는 것이 `std::mdspan`이고 [「mdspan과 선형대수」](#/read/cpp-stl/num-linalg)에서 봅니다.

## 정리

- `vector`는 포인터 셋과 힙의 한 덩어리다. 줄지어 있어서 빠르고 C 함수에 그대로 넘어간다
- 객체가 있으면 `push_back`, 인자로 그 자리에서 만들면 `emplace_back`. `reserve`는 자리, `resize`는 원소
- 다시 할당되면 가리키던 것이 모두 죽고, 잠깐 메모리가 두 배로 든다
