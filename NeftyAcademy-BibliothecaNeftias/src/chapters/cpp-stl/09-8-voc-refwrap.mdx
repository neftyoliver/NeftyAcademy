[참조](#/read/cpp-syntax/ref-lvalue)는 한번 묶이면 다른 것을 가리키게 바꿀 수 없고, 컨테이너의 원소가 될 수 없습니다. `std::vector<int&>`는 컴파일되지 않습니다. `std::reference_wrapper<T>`는 참조처럼 쓰이면서 **평범한 값처럼 복사되고 대입되는** 타입입니다. 속은 포인터 하나이고, `std::ref(x)`와 `std::cref(x)`로 만듭니다.

## 컨테이너에 참조 담기

원본의 순서는 그대로 두고, **다른 순서로 본** 목록이 필요할 때가 있습니다.

```cpp
#include <algorithm>
#include <functional>
#include <print>
#include <string>
#include <vector>

struct Sensor {
    std::string name;
    double value;
};

int main()
{
    std::vector<Sensor> sensors = {
        {"temp", 23.5}, {"humid", 41.0}, {"press", 10.1},
    };

    // 원본을 가리키는 참조들의 목록. Sensor 를 복사하지 않는다
    using SensorRef = std::reference_wrapper<Sensor>;
    std::vector<SensorRef> by_value(sensors.begin(), sensors.end());
    std::ranges::sort(by_value, {}, [](const Sensor& s) { return s.value; });

    for (const Sensor& s : by_value)            // 저절로 Sensor& 로 바뀐다
        std::print("{} ", s.name);
    std::println("");

    by_value.front().get().value = 99.9;        // 멤버에 닿으려면 get()
    // 원본의 순서는 그대로, 값은 바뀌었다
    for (const auto& s : sensors)
        std::print("{}={} ", s.name, s.value);
    std::println("");
}
```

```text
press temp humid
temp=23.5 humid=41 press=99.9
```

`Sensor`가 복사하기 비싸거나 복사할 수 없는 타입이어도 됩니다. 정렬되는 것은 포인터 크기의 참조들입니다. 포인터의 `vector`(`std::vector<Sensor*>`)로도 같은 일을 할 수 있고, 차이는 뜻입니다. `reference_wrapper`는 **비어 있을 수 없습니다.** `nullptr` 검사가 필요 없다는 것을 타입이 말해 줍니다.

## 값을 복사하는 곳에 참조로 넘기기

표준 라이브러리의 여러 곳이 받은 인자를 **복사해** 둡니다. `std::thread`, `std::bind_front`, `std::make_pair`, 그리고 함수 객체를 받는 알고리즘이 그렇습니다. 복사가 아니라 원본을 쓰게 하려면 `std::ref`로 감싸 넘깁니다.

```cpp
#include <algorithm>
#include <functional>
#include <print>
#include <thread>
#include <vector>

void add_to(int& total, int amount) { total += amount; }

struct Counter {
    int calls = 0;
    void operator()(int) { ++calls; }
};

int main()
{
    int total = 0;
    // std::thread 는 인자를 복사해 새 스레드로 넘긴다. 참조로 받게 하려면 std::ref
    std::thread worker(add_to, std::ref(total), 5);
    worker.join();
    std::println("total {}", total);

    const std::vector<int> v = {1, 2, 3};
    Counter counter;
    std::ranges::for_each(v, counter);              // counter 의 사본이 불린다
    std::println("그냥 넘김: {}", counter.calls);
    std::ranges::for_each(v, std::ref(counter));    // counter 자체가 불린다
    std::println("std::ref:  {}", counter.calls);

    // total 을 참조로 묶는다
    const auto bound = std::bind_front(add_to, std::ref(total));
    bound(10);
    std::println("total {}", total);
}
```

```text
total 5
그냥 넘김: 0
std::ref:  3
total 15
```

`std::thread worker(add_to, total, 5);`라고 쓰면 컴파일되지 않습니다. 복사한 `int`를 `int&`에 묶을 수 없기 때문입니다. 막아 준 것입니다. 조용히 사본을 고치고 원본은 그대로인 것보다 낫습니다. 가운데의 `for_each`는 그렇게 조용히 틀리는 경우입니다. 상태를 가진 함수 객체를 알고리즘에 넘기면 사본이 불리고 원본의 `calls`는 0입니다.

## 참조와 다른 점

```cpp
#include <functional>
#include <print>

int main()
{
    int a = 1;
    int b = 2;

    int& plain = a;
    plain = b;                  // a 에 b 의 값을 넣는다. 여전히 a 를 가리킨다
    std::println("a {} b {}", a, b);

    a = 1;
    std::reference_wrapper<int> wrapped = a;
    wrapped = b;                // 이제 b 를 가리킨다. a 는 그대로다
    wrapped.get() = 20;         // 가리키는 것에 값을 넣으려면 get()
    std::println("a {} b {}", a, b);

    auto copy = wrapped;        // auto 는 int 가 아니라 reference_wrapper<int> 다
    copy.get() = 30;
    std::println("b {}", b);
}
```

```text
a 2 b 2
a 1 b 20
b 30
```

| | `T&` | `std::reference_wrapper<T>` |
| --- | --- | --- |
| `=`의 뜻 | 가리키는 것에 값을 넣는다 | **다른 것을 가리키게** 바꾼다 |
| 컨테이너의 원소, 멤버 | 원소는 안 된다. 멤버로 두면 대입이 막힌다 | 된다 |
| 멤버에 닿기 | `r.멤버` | `r.get().멤버` |
| `auto x = r;` | 값의 사본 | 감싼 것의 사본 (같은 것을 가리킨다) |

클래스의 멤버로 참조가 필요할 때도 쓸모가 있습니다. `T&` 멤버가 있는 클래스는 [복사 대입 연산자가 만들어지지 않습니다](#/read/cpp-syntax/sm-rules). `std::reference_wrapper<T>` 멤버는 그렇지 않습니다.

<Note kind="warn">
속이 포인터이므로 수명의 규칙은 포인터와 같습니다. 감싼 대상이 먼저 사라지면 죽은 것을 가리킵니다. 특히 `std::thread`에 `std::ref(지역변수)`를 넘기고 스레드가 그 함수보다 오래 살면 그렇게 됩니다. 그리고 `vector`의 원소를 가리키는 `reference_wrapper`는 그 `vector`가 [다시 할당될 때](#/read/cpp-stl/seq-invalidation) 함께 죽습니다. 위의 정렬 예제에서 `sensors`에 `push_back`을 하면 `by_value`는 통째로 못 쓰게 됩니다.
</Note>

## 정리

- `std::reference_wrapper<T>`는 복사와 대입이 되는 참조다. `std::ref`, `std::cref`로 만들고 속은 포인터 하나다
- 참조의 컨테이너를 만들 때, 그리고 인자를 복사해 두는 곳(`thread`, 알고리즘의 함수 객체)에 원본을 넘길 때 쓴다
- `=`는 다시 가리키기다. 멤버에는 `get()`으로 닿는다. 수명은 포인터처럼 내가 지킨다
