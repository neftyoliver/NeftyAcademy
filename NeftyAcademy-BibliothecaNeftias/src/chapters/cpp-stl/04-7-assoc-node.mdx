[`map`](#/read/cpp-stl/assoc-map), `set`, [`unordered_map`](#/read/cpp-stl/assoc-unordered)의 원소는 노드에 삽니다. C++17부터 그 노드를 컨테이너에서 **떼어 내** 손에 들 수 있습니다. 떼어 낸 것이 노드 핸들이고, [`list`의 `splice`](#/read/cpp-stl/seq-list)가 하던 일을 연관 컨테이너에서 하게 해 줍니다.

## 떼어 내고, 고치고, 다시 꽂기

[열쇠는 `const`](#/read/cpp-stl/assoc-map)여서 제자리에서 고칠 수 없습니다. 지우고 새로 넣으면 노드를 버리고 다시 할당합니다. 노드 핸들은 그 사이를 메웁니다.

```cpp
#include <map>
#include <print>
#include <string>
#include <utility>

void show(const char* label, const std::map<std::string, int>& m)
{
    std::print("{:11}", label);
    for (const auto& [name, pin] : m)
        std::print("{}={} ", name, pin);
    std::println("");
}

int main()
{
    std::map<std::string, int> pins = {{"led", 17}, {"buton", 22}, {"fan", 4}};
    const int* before = &pins.at("buton");

    // 1. 열쇠 고치기
    auto node = pins.extract("buton");      // 노드를 떼어 낸다. 원소는 살아 있다
    std::println("떼어 낸 뒤 size {}", pins.size());
    node.key() = "button";                  // 손에 든 동안에는 열쇠를 고칠 수 있다
    pins.insert(std::move(node));           // 다시 꽂는다
    show("고친 뒤", pins);
    std::println("값은 제자리인가: {}", before == &pins.at("button"));

    // 2. 다른 컨테이너로 옮기기
    std::map<std::string, int> spare;
    spare.insert(pins.extract("fan"));
    show("pins", pins);
    show("spare", spare);

    // 3. 통째로 합치기
    std::map<std::string, int> extra = {{"led", 99}, {"relay", 5}};
    pins.merge(extra);
    show("합친 pins", pins);
    show("남은 extra", extra);
}
```

```text
떼어 낸 뒤 size 2
고친 뒤    button=22 fan=4 led=17
값은 제자리인가: true
pins       button=22 led=17
spare      fan=4
합친 pins  button=22 led=17 relay=5
남은 extra led=99
```

- `extract`와 `insert`는 트리의 포인터만 고칩니다. 원소를 복사하지도 옮기지도 않고, 할당도 없습니다. 값의 주소가 그대로인 것이 그 증거입니다.
- `merge`는 상대 컨테이너의 노드를 모두 옮겨 오려 하고, **열쇠가 겹치는 것은 상대에 남겨 둡니다.** 위에서 `led=99`가 `extra`에 남았습니다. 값이 덮어써지지 않습니다.

## 노드 핸들이라는 것

`extract`가 돌려주는 타입은 `std::map<…>::node_type`입니다. 대개 `auto`로 받습니다.

| 하는 일 | 적는 법 |
| --- | --- |
| 비었는지 | `node.empty()`, `if (node)` |
| 열쇠와 값 (`map`) | `node.key()`, `node.mapped()` |
| 값 (`set`) | `node.value()` |
| 꽂기 | `m.insert(std::move(node))` |

노드 핸들은 그 노드의 **주인**입니다. 옮길 수만 있고 복사할 수 없으며, 꽂지 않은 채 사라지면 원소도 함께 지워집니다. 메모리가 새지 않습니다.

찾는 열쇠가 없으면 `extract`는 빈 핸들을 돌려주고, 빈 핸들을 `insert`하면 아무 일도 일어나지 않습니다. 열쇠가 이미 있는 `map`에 꽂으려 하면 꽂히지 않고, 핸들을 **되돌려 받습니다.**

```cpp
#include <map>
#include <print>
#include <string>
#include <utility>

int main()
{
    std::map<std::string, int> pins = {{"led", 17}};
    std::map<std::string, int> other = {{"led", 99}};

    auto result = pins.insert(other.extract("led"));    // "led" 는 이미 있다
    std::println("꽂혔나: {}", result.inserted);
    std::println("있던 것: {}={}", result.position->first, result.position->second);
    std::println("되돌려 받은 것: {}={}", result.node.key(), result.node.mapped());
    std::println("other 는 비었나: {}", other.empty());
}
```

```text
꽂혔나: false
있던 것: led=17
되돌려 받은 것: led=99
other 는 비었나: true
```

`result.node`를 그냥 두면 `main`이 끝날 때 `led=99`가 지워집니다. 버리면 안 되는 것이면 원래 자리에 다시 꽂습니다.

## set에서 옮겨 꺼내기

`set`의 원소는 `const`입니다. 그래서 `std::move(*it)`는 옮기지 못하고 **복사**합니다. 원소가 `std::unique_ptr`처럼 복사할 수 없는 타입이면 꺼낼 방법이 아예 없었습니다. 노드 핸들의 `value()`는 `const`가 아니어서 여기서 옮겨 낼 수 있습니다.

```cpp
#include <print>
#include <set>
#include <string>
#include <utility>

int main()
{
    std::set<std::string> jobs = {
        "calibrate the outdoor temperature sensor",
        "upload yesterday's readings to the server",
    };
    const char* inside = jobs.begin()->data();      // 가장 앞의 문자열이 든 곳

    std::string job = std::move(jobs.extract(jobs.begin()).value());
    std::println("{}", job);
    std::println("글자를 복사하지 않고 꺼냈는가: {}", job.data() == inside);
    std::println("남은 일 {}개", jobs.size());
}
```

```text
calibrate the outdoor temperature sensor
글자를 복사하지 않고 꺼냈는가: true
남은 일 1개
```

우선순위대로 정렬해 둔 작업 목록에서 가장 앞의 것을 **소유권째** 꺼내는 코드가 이 한 줄로 됩니다.

## 옮길 수 있는 사이

| 사이 | 되는가 |
| --- | --- |
| `map` ↔ `map`, 비교자가 달라도 | 된다 |
| `map` ↔ `multimap`, `set` ↔ `multiset` | 된다 |
| `unordered_map` ↔ `unordered_multimap` | 된다 |
| `map` ↔ `unordered_map` | 안 된다. 노드의 모양이 다르다 |

열쇠 타입, 값 타입, 할당자 타입이 같아야 합니다. `multimap`의 노드를 `map`으로 `merge`하면 열쇠마다 하나씩만 건너가고 나머지는 남으므로, 겹친 열쇠를 걸러 내는 데 쓸 수 있습니다.

<Note>
떼어 내는 순간 그 원소를 가리키던 **반복자**는 죽습니다. 원소를 가리키던 포인터와 참조는 원소가 다시 어느 컨테이너에 꽂힌 뒤에 쓸 수 있습니다. 핸들이 들고 있는 동안에는 쓰지 않습니다.
</Note>

## 정리

- `extract`는 노드를 떼어 내 핸들로 준다. 열쇠를 고쳐 다시 꽂거나 다른 컨테이너로 옮긴다. 할당과 복사가 없다
- `merge`는 통째로 옮기고, 겹치는 열쇠는 상대에 남긴다. 꽂지 못한 핸들은 되돌려 받는다
- `set`에서 복사 없이 꺼내려면 `extract(it).value()`를 옮긴다
