디렉터리 안을 훑는 도구는 반복자 둘입니다. `fs::directory_iterator`는 한 단계만, `fs::recursive_directory_iterator`는 아래까지 내려갑니다. 둘 다 [입력 반복자](#/read/cpp-stl/it-category)라서 한 번 지나가면 되돌아갈 수 없습니다.

## 한 단계

예제는 임시 디렉터리에 작은 프로젝트 모양을 만들어 놓고 훑습니다.

```cpp
#include <algorithm>
#include <cstddef>
#include <filesystem>
#include <fstream>
#include <print>
#include <string>
#include <vector>

namespace fs = std::filesystem;

void write_file(const fs::path& path, std::size_t bytes)
{
    fs::create_directories(path.parent_path());
    std::ofstream(path) << std::string(bytes, 'x');
}

int main()
{
    const fs::path root = fs::temp_directory_path() / "na-walk";
    fs::remove_all(root);
    write_file(root / "readme.md", 120);
    write_file(root / "src" / "main.cpp", 900);
    write_file(root / "src" / "gpio.cpp", 400);
    write_file(root / "build" / "main.o", 3000);

    std::vector<fs::directory_entry> entries;
    for (const fs::directory_entry& entry : fs::directory_iterator(root))
        entries.push_back(entry);

    // 나오는 순서는 정해져 있지 않다. 필요하면 직접 정렬한다
    std::ranges::sort(entries, {}, &fs::directory_entry::path);
    for (const auto& entry : entries) {
        const auto name = entry.path().filename().string();
        if (entry.is_directory())
            std::println("{:10} <dir>", name);
        else
            std::println("{:10} {}", name, entry.file_size());
    }
    fs::remove_all(root);
}
```

```text
build      <dir>
readme.md  120
src        <dir>
```

- `.`과 `..`은 나오지 않습니다
- **순서는 정해져 있지 않습니다.** 이름순도 만든 순서도 아니고, 파일 시스템이 내주는 대로입니다. 같은 디렉터리라도 기기마다 다를 수 있으므로, 순서가 뜻이 있는 일(번호가 붙은 로그를 차례로 읽기)은 모아서 정렬합니다
- 도는 중에 그 디렉터리에 파일을 만들거나 지우면, 그것이 보일지 안 보일지도 정해져 있지 않습니다

## directory_entry

반복자가 내주는 것은 `path`가 아니라 `fs::directory_entry`입니다. 경로와 함께 **훑으면서 얻은 정보**를 기억합니다.

| 멤버 | 주는 것 |
| --- | --- |
| `entry.path()` | 전체 경로. 훑기 시작한 경로가 앞에 붙어 있다 |
| `entry.is_regular_file()`, `is_directory()`, `is_symlink()` | 종류 |
| `entry.file_size()` | 바이트 수. 디렉터리에 부르면 오류 |
| `entry.last_write_time()` | 마지막으로 고친 때 |

`fs::is_directory(entry.path())`처럼 자유 함수에 경로를 넘기면 운영체제에 다시 묻습니다. `entry.is_directory()`는 리눅스에서 디렉터리를 읽을 때 함께 받은 **종류**를 그대로 씁니다. 파일 200개짜리 디렉터리로 세어 보면 자유 함수 쪽은 `stat` 호출이 200번, 멤버 쪽은 0번입니다. 크기와 시각은 리눅스에서는 멤버로 불러도 그때 묻습니다.

## 아래까지

```cpp
#include <algorithm>
#include <cstddef>
#include <cstdint>
#include <filesystem>
#include <format>
#include <fstream>
#include <map>
#include <print>
#include <string>
#include <vector>

namespace fs = std::filesystem;

void write_file(const fs::path& path, std::size_t bytes)
{
    fs::create_directories(path.parent_path());
    std::ofstream(path) << std::string(bytes, 'x');
}

int main()
{
    const fs::path root = fs::temp_directory_path() / "na-walk";
    fs::remove_all(root);
    write_file(root / "readme.md", 120);
    write_file(root / "src" / "main.cpp", 900);
    write_file(root / "src" / "hal" / "gpio.cpp", 400);
    write_file(root / "src" / "hal" / "gpio.h", 150);
    write_file(root / ".git" / "objects" / "ab12", 5000);
    write_file(root / "build" / "main.o", 3000);

    std::map<std::string, std::uintmax_t> bytes_by_extension;
    std::vector<std::string> lines;

    const fs::recursive_directory_iterator end;
    for (fs::recursive_directory_iterator it(root); it != end; ++it) {
        const auto name = it->path().filename().string();
        if (it->is_directory() && (name == ".git" || name == "build")) {
            it.disable_recursion_pending();     // 이 디렉터리 안으로는 가지 않는다
            continue;
        }
        if (it->is_regular_file()) {
            bytes_by_extension[it->path().extension().string()] += it->file_size();
            const auto relative = it->path().lexically_relative(root).string();
            lines.push_back(std::format("{} (깊이 {})", relative, it.depth()));
        }
    }

    std::ranges::sort(lines);
    for (const auto& line : lines)
        std::println("{}", line);
    for (const auto& [extension, bytes] : bytes_by_extension)
        std::println("{:5} {}", extension, bytes);
    std::println("지운 항목 {}", fs::remove_all(root));
}
```

```text
readme.md (깊이 0)
src/hal/gpio.cpp (깊이 2)
src/hal/gpio.h (깊이 2)
src/main.cpp (깊이 1)
.cpp  1300
.h    150
.md   120
지운 항목 12
```

범위 기반 `for`로도 돌 수 있지만, `depth()`와 `disable_recursion_pending()`은 **반복자의** 멤버라서 쓰려면 위처럼 반복자를 직접 다뤄야 합니다. `.git`이나 `build`처럼 크고 볼 필요 없는 가지를 통째로 건너뛰는 데 씁니다. 안에서 걸러 내는 것과 달리 그 아래를 읽지도 않습니다.

생성자에 줄 수 있는 선택지가 둘 있습니다.

| `fs::directory_options` | 뜻 |
| --- | --- |
| `skip_permission_denied` | 읽을 권한이 없는 디렉터리를 만나면 오류 없이 건너뛴다 |
| `follow_directory_symlink` | 디렉터리를 가리키는 심볼릭 링크 안으로도 들어간다. 기본은 들어가지 않는다 |

링크를 따라가게 하면 자기 조상을 가리키는 링크에서 끝없이 돌 수 있습니다. 기본값을 바꿀 때는 깊이에 한도를 둡니다.

## 레인지로 걸러 내기

두 반복자는 그 자체가 [레인지](#/read/cpp-stl/rng-views)이므로 뷰를 이어 붙일 수 있습니다.

```cpp
#include <algorithm>
#include <cstddef>
#include <filesystem>
#include <fstream>
#include <print>
#include <ranges>
#include <string>
#include <vector>

namespace fs = std::filesystem;

void write_file(const fs::path& path, std::size_t bytes)
{
    fs::create_directories(path.parent_path());
    std::ofstream(path) << std::string(bytes, 'x');
}

int main()
{
    const fs::path root = fs::temp_directory_path() / "na-walk";
    fs::remove_all(root);
    write_file(root / "src" / "main.cpp", 900);
    write_file(root / "src" / "big.cpp", 2400);
    write_file(root / "build" / "main.o", 3000);

    auto is_big_file = [](const fs::directory_entry& entry) {
        return entry.is_regular_file() && entry.file_size() >= 1000;
    };
    auto to_relative = [&](const fs::directory_entry& entry) {
        return entry.path().lexically_relative(root).string();
    };
    auto names = fs::recursive_directory_iterator(root)
               | std::views::filter(is_big_file)
               | std::views::transform(to_relative)
               | std::ranges::to<std::vector>();

    std::ranges::sort(names);
    for (const auto& name : names)
        std::println("{}", name);
    fs::remove_all(root);
}
```

```text
build/main.o
src/big.cpp
```

입력 레인지라서 결과를 두 번 돌 수 없고 `std::ranges::sort`에 바로 넣을 수도 없습니다. `std::ranges::to`로 벡터에 담은 다음 정렬합니다.

## 도는 중의 오류

훑는 도중에도 실패할 수 있습니다. 디렉터리가 그 사이에 지워졌거나, 권한이 없거나, SD 카드가 뽑혔을 때입니다. 범위 기반 `for`는 그때 `fs::filesystem_error` 예외를 던집니다. 예외 없이 받으려면 생성자와 `increment`에 [`std::error_code`](#/read/cpp-stl/fs-errors)를 넘깁니다.

```cpp
#include <filesystem>
#include <print>
#include <system_error>

namespace fs = std::filesystem;

int main()
{
    std::error_code ec;
    const auto options = fs::directory_options::skip_permission_denied;
    int count = 0;
    for (fs::recursive_directory_iterator it("/no/such/dir", options, ec), end;
         !ec && it != end; it.increment(ec))
        ++count;
    if (ec)
        std::println("멈춤: {} (본 것 {}개)", ec.message(), count);
}
```

```text
멈춤: No such file or directory (본 것 0개)
```

`++it` 대신 `it.increment(ec)`를 쓰는 것이 요점입니다. `++it`는 실패하면 예외를 던집니다.

<Note>
한 디렉터리에 파일이 수십만 개 있으면 훑는 것만으로 초 단위가 걸립니다. 로그를 날짜별 하위 디렉터리로 나누는 까닭이 이것입니다. 그리고 훑은 결과는 **그 순간의 모습**입니다. `entry.file_size()`를 읽은 뒤 파일이 커졌을 수 있으므로, 그 크기를 믿고 버퍼를 잡은 다음에는 [실제로 읽힌 바이트 수](#/read/cpp-stl/io-binary)를 따로 확인합니다.
</Note>

## 정리

- `directory_iterator`는 한 단계, `recursive_directory_iterator`는 아래까지 훑는다. 나오는 순서는 정해져 있지 않다
- `directory_entry`의 `is_directory()` 같은 멤버는 훑으면서 얻은 종류를 쓰므로 자유 함수에 경로를 넘기는 것보다 싸다. `disable_recursion_pending()`으로 가지를 통째로 건너뛴다
- 도는 중에도 오류가 난다. 예외를 피하려면 생성자와 `increment`에 `error_code`를 넘긴다
