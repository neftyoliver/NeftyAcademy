[`map`과 `set`](#/read/cpp-stl/assoc-map)은 같은 열쇠를 하나만 둡니다. `std::multimap`과 `std::multiset`은 같은 열쇠를 **여럿** 둘 수 있습니다. 나머지는 같습니다. 정렬된 트리이고, 헤더도 `<map>`과 `<set>` 그대로입니다.

## multimap: 열쇠 하나에 값 여럿

```cpp
#include <map>
#include <print>
#include <string>

int main()
{
    // 시각(초) -> 그때 할 일. 같은 시각에 여러 일이 있을 수 있다
    std::multimap<int, std::string> schedule;
    schedule.insert({30, "센서 읽기"});
    schedule.insert({10, "LED 켜기"});
    schedule.insert({30, "서버로 보내기"});
    schedule.insert({30, "로그 쓰기"});

    std::println("전체 {}개, 30초에 {}개", schedule.size(), schedule.count(30));

    const auto [first, last] = schedule.equal_range(30);    // 열쇠가 30인 구간
    for (auto it = first; it != last; ++it)
        std::println("  {}초: {}", it->first, it->second);

    // 가장 이른 일부터 꺼내 처리한다
    while (!schedule.empty()) {
        const auto next = schedule.begin();
        std::print("[{} {}] ", next->first, next->second);
        schedule.erase(next);
    }
    std::println("");
}
```

```text
전체 4개, 30초에 3개
  30초: 센서 읽기
  30초: 서버로 보내기
  30초: 로그 쓰기
[10 LED 켜기] [30 센서 읽기] [30 서버로 보내기] [30 로그 쓰기]
```

`map`과 달라지는 것은 셋입니다.

- `insert`는 언제나 성공합니다. 그래서 `bool`이 없이 반복자만 돌려줍니다.
- `[]`와 `at`이 없습니다. "이 열쇠의 값"이 하나가 아니기 때문입니다.
- 열쇠가 같은 원소들은 **넣은 순서대로** 놓입니다. 위에서 30초의 세 일이 넣은 차례로 나온 것은 우연이 아니라 표준이 정한 것입니다.

`equal_range(k)`는 열쇠가 `k`인 구간의 처음과 끝을 한 쌍으로 줍니다. `lower_bound(k)`와 `upper_bound(k)`를 한 번에 부른 것과 같습니다.

## multiset: 겹쳐도 되는 정렬된 묶음

```cpp
#include <print>
#include <set>

void show(const char* label, const std::multiset<int>& values)
{
    std::print("{:12}", label);
    for (int v : values)
        std::print("{} ", v);
    std::println("");
}

int main()
{
    std::multiset<int> scores = {70, 85, 70, 92, 70};
    show("처음", scores);

    scores.erase(scores.find(70));      // 반복자로: 하나만 지운다
    show("하나 지움", scores);

    const auto removed = scores.erase(70);      // 값으로: 그 값을 전부 지운다
    show("전부 지움", scores);
    std::println("지운 개수 {}", removed);
}
```

```text
처음        70 70 70 85 92
하나 지움   70 70 85 92
전부 지움   85 92
지운 개수 2
```

<Note kind="warn">
`scores.erase(70)`은 70을 **모두** 지웁니다. 하나만 지우려면 `scores.erase(scores.find(70))`처럼 반복자를 넘깁니다. "점수 하나를 뺀다"는 뜻으로 값을 넘겼다가 같은 점수가 다 사라지는 것이 `multiset`에서 가장 흔한 실수입니다. `find`가 `end()`를 돌려주었을 때 `erase(end())`를 부르는 것도 안 되므로, 없을 수 있으면 먼저 확인합니다.
</Note>

`multiset`은 "넣고 지우는 동안 늘 정렬되어 있어야 하는 묶음"에 씁니다. 가장 작은 값은 `*s.begin()`, 가장 큰 값은 `*s.rbegin()`으로 언제든 O(1)에 얻습니다. 최근 N개의 최댓값을 따라가는 창이나, 끝나는 시각 순으로 줄 세운 타이머 목록이 그런 예입니다.

## 대신 쓸 구조

같은 일을 `std::map<Key, std::vector<Value>>`로도 할 수 있습니다.

| | `multimap<K, V>` | `map<K, vector<V>>` |
| --- | --- | --- |
| 열쇠 하나의 값들을 모아 보기 | `equal_range`로 구간을 얻는다 | `m[k]`가 곧 묶음이다 |
| 열쇠의 종류 세기 | 직접 세야 한다 | `m.size()` |
| 값 하나마다 드는 것 | 노드 하나 | `vector`의 한 칸 |
| 가장 앞의 원소 하나 꺼내기 | `begin()`을 지우면 끝 | 묶음이 비면 열쇠도 지워야 한다 |

열쇠마다 값이 많고 묶음째로 다루는 일이 많으면 오른쪽이 메모리도 덜 들고 쓰기도 편합니다. 원소를 **하나씩** 차례로 꺼내는 줄 세우기에는 왼쪽이 맞습니다. 차례로 꺼내기만 하고 중간을 볼 일이 없다면 [`priority_queue`](#/read/cpp-stl/adp-priority)가 더 가볍습니다.

## 정리

- `multimap`과 `multiset`은 같은 열쇠를 여럿 둔다. 같은 열쇠끼리는 넣은 순서를 지킨다
- 한 열쇠의 원소들은 `equal_range`로 얻는다. `[]`와 `at`은 없다
- `erase(값)`은 전부, `erase(반복자)`는 하나를 지운다
