**JSON**은 서버와 기기가 데이터를 주고받는 가장 흔한 글자 형식입니다. [「HTTP」](#/read/c-mid/http) API의 몸통도, [「MQTT」](#/read/c-mid/iot-mqtt) 메시지의 내용도 대개 JSON입니다. C에는 JSON을 다루는 표준 기능이 없어서, 작고 파일 두 개짜리인 **cJSON**을 많이 씁니다.

## 여섯 가지 값

| 종류 | 예 | 메모 |
| --- | --- | --- |
| 객체 | `{"a": 1}` | 이름(항상 큰따옴표 글자)과 값의 묶음 |
| 배열 | `[1, 2, 3]` | 순서 있는 목록, 종류가 섞여도 됨 |
| 글자 | `"고양이"` | UTF-8, `\"`, `\n`, `\uXXXX` 같은 탈출 |
| 수 | `23.5`, `-1e3` | 정수와 실수를 구분하지 않음 |
| 참/거짓 | `true`, `false` | |
| 없음 | `null` | |

끝에 쉼표를 남기거나, 작은따옴표를 쓰거나, 주석을 넣는 것은 JSON에서 허용되지 않습니다. 사람이 손으로 쓴 설정 파일이 거부되는 흔한 까닭입니다.

## 읽고 만들기

```c flags=-I/usr/include/cjson,-lcjson
#include <stdio.h>
#include <stdlib.h>
#include <cjson/cJSON.h>

int main(void)
{
    // 서버가 보내온 설정이라고 치자
    const char *text =
        "{\"device\":\"sensor-7\",\"interval_s\":30,"
        "\"thresholds\":{\"temp\":[18.0,27.5]},\"enabled\":true,"
        "\"note\":\"거실 \\uace0\\uc591\\uc774 \\ud83d\\udc31\"}";

    cJSON *root = cJSON_Parse(text);
    if (!root) {
        printf("JSON이 잘못됨, 여기 근처: %.20s\n", cJSON_GetErrorPtr());
        return 1;
    }
    // 하나씩 꺼내며 종류를 확인한다
    const cJSON *dev = cJSON_GetObjectItemCaseSensitive(root, "device");
    const cJSON *iv = cJSON_GetObjectItemCaseSensitive(root, "interval_s");
    const cJSON *th = cJSON_GetObjectItemCaseSensitive(root, "thresholds");
    const cJSON *temp = cJSON_GetObjectItemCaseSensitive(th, "temp");
    const cJSON *note = cJSON_GetObjectItemCaseSensitive(root, "note");
    if (cJSON_IsString(dev) && cJSON_IsNumber(iv) && cJSON_IsArray(temp)
        && cJSON_GetArraySize(temp) == 2) {
        printf("장치 %s, %d초마다\n", dev->valuestring, iv->valueint);
        printf("온도 범위 %.1f ~ %.1f\n",
               cJSON_GetArrayItem(temp, 0)->valuedouble,
               cJSON_GetArrayItem(temp, 1)->valuedouble);
    }
    if (cJSON_IsString(note))
        printf("메모 %s\n", note->valuestring);
    const cJSON *missing = cJSON_GetObjectItemCaseSensitive(root, "owner");
    printf("owner가 있는가: %d\n", missing != nullptr);
    cJSON_Delete(root);

    // 보고서 만들기
    cJSON *rep = cJSON_CreateObject();
    cJSON_AddStringToObject(rep, "device", "sensor-7");
    cJSON_AddNumberToObject(rep, "temp", 23.5);
    cJSON *hist = cJSON_AddArrayToObject(rep, "last");
    const double v[] = {23.1, 23.4, 23.5};
    for (int i = 0; i < 3; i++)
        cJSON_AddItemToArray(hist, cJSON_CreateNumber(v[i]));
    cJSON_AddStringToObject(rep, "msg", "say \"hi\"");

    char *out = cJSON_PrintUnformatted(rep);
    printf("%s\n", out);
    free(out);                  // cJSON이 malloc으로 만든 글자
    cJSON_Delete(rep);

    // true를 잘못 쓴 JSON
    cJSON *bad = cJSON_Parse("{\"a\":1,\"ok\":tru}");
    printf("잘못된 JSON: %s, 여기부터 \"%s\"\n", bad ? "통과" : "거부",
           bad ? "" : cJSON_GetErrorPtr());
    cJSON_Delete(bad);
    return 0;
}
```

```text
장치 sensor-7, 30초마다
온도 범위 18.0 ~ 27.5
메모 거실 고양이 🐱
owner가 있는가: 0
{"device":"sensor-7","temp":23.5,"last":[23.1,23.4,23.5],"msg":"say \"hi\""}
잘못된 JSON: 거부, 여기부터 "tru}"
```

- **꺼낼 때마다 종류를 확인합니다**. 바깥에서 온 JSON은 믿을 수 없습니다. `interval_s`가 수가 아니라 글자로 오거나 아예 없을 수 있고, 확인 없이 `->valueint`를 읽으면 엉뚱한 값이나 널 포인터 접근이 됩니다. `cJSON_GetObjectItemCaseSensitive`는 없으면 `NULL`을 돌려주고, `cJSON_IsNumber` 같은 함수는 `NULL`을 넣어도 안전하게 거짓을 돌려줍니다
- `\uace0\uc591\uc774`가 "고양이"로, 서로게이트 쌍 `\ud83d\udc31`이 고양이 그림 문자 하나로 바뀌었습니다. cJSON이 UTF-8로 풀어 줍니다
- 만들 때는 `cJSON_Add…ToObject`로 값을 붙입니다. 글자 속의 큰따옴표는 내보낼 때 `\"`로 알아서 탈출됩니다. 손으로 `sprintf`해서 JSON을 만들면 이 탈출을 빠뜨려 깨진 JSON이 나오기 쉽습니다
- 잘못된 JSON은 `NULL`이 돌아오고, `cJSON_GetErrorPtr`가 원래 글자에서 문제가 난 곳을 가리킵니다

## 메모리의 주인

cJSON은 값마다 `malloc`으로 마디를 만들어 나무로 잇습니다. 그래서 주인을 분명히 해야 합니다.

- `cJSON_Parse`나 `cJSON_CreateObject`로 얻은 **뿌리**는 다 쓰고 `cJSON_Delete`로 지웁니다. 아래 마디들도 함께 지워집니다
- `cJSON_GetObjectItem…`으로 꺼낸 마디는 **빌린 것**입니다. 따로 지우면 두 번 해제가 됩니다
- `cJSON_AddItemToArray`처럼 무언가에 붙인 마디는 붙은 쪽이 주인이 됩니다
- `cJSON_Print…`가 돌려준 글자는 따로 `malloc`된 것이라 `free`해야 합니다

위 예제를 ASan으로 돌려도 새는 메모리가 없었습니다. [「GCC」](#/read/c-mid/cc-gcc)에서 본 `-fsanitize=address`로 이런 주인 관계를 확인하는 습관을 들이면 좋습니다.

<Note>
cJSON은 파일 하나 전체를 메모리에 나무로 만들기 때문에, 메모리가 수십 KB뿐인 마이크로컨트롤러에서는 큰 JSON을 다루기 어렵습니다. 그런 곳에서는 나무를 만들지 않고 글자를 한 번 훑으며 조각(token)만 알려 주는 jsmn 같은 작은 파서를 쓰기도 합니다. 반대로 큰 서버에서 빠르기가 중요하면 다른 라이브러리를 고릅니다. 또 JSON의 수는 C의 `double`로 읽히므로, 2⁵³을 넘는 큰 정수 ID는 정확히 담기지 않을 수 있어 글자로 주고받는 경우가 많습니다.
</Note>

## 정리

- JSON은 객체, 배열, 글자, 수, 참/거짓, null의 여섯 가지 값으로 되어 있고 끝 쉼표·작은따옴표·주석은 허용되지 않는다
- 바깥에서 온 JSON은 꺼낼 때마다 있는지와 종류를 확인하고, 만들 때는 손 대신 라이브러리 함수로 탈출까지 맡긴다
- cJSON은 뿌리를 `cJSON_Delete`로, 내보낸 글자를 `free`로 지우며, 꺼낸 마디는 빌린 것이라 따로 지우지 않는다
