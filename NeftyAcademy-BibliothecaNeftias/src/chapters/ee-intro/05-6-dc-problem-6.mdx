[「문제 5」](#/read/ee-intro/dc-problem-5)의 회로를 다른 방법으로 다시 풉니다. 저항 회로는 **선형**이라서, 전원이 여럿일 때 **하나씩만 켜고 구한 결과를 더하면** 전체 결과가 됩니다. 이것을 **중첩의 원리**(superposition)라고 합니다. 전원 하나짜리 회로는 [「문제 2」](#/read/ee-intro/dc-problem-2)의 줄이기로 풀리니, 마디 해석의 연립방정식을 피해 갈 수 있습니다.

## 문제

[「문제 5」](#/read/ee-intro/dc-problem-5)와 같은 회로입니다.

<Figure caption="문제 5와 같은 회로. 이번에는 전원을 하나씩 켠다">
  <Circuit spec="V 0,2 0,0 12V; R 0,0 2,0 R1 2kΩ; D 2,0; T 2,-0.32 A; R 2,0 2,2 R2 4kΩ; R 2,0 4,0 R3 2kΩ; D 4,0; T 4,-0.32 B; R 4,0 4,2 R4 3kΩ; R 4,0 6,0 R5 1kΩ; V 6,2 6,0 6V; W 6,2 0,2; D 2,2; D 4,2; G 0,2" label="문제 5와 같은 두 전원 회로" />
</Figure>

- (가) 12V 전원만 있을 때 A와 B의 전압은?
- (나) 6V 전원만 있을 때 A와 B의 전압은?
- (다) 둘을 더하면 문제 5의 답과 같은가? R3의 전력도 같은 방법으로 구할 수 있나?

<Note kind="tip">
실마리: 전압원을 "끈다"는 것은 0V로 만든다는 뜻이고, 0V짜리 전압원은 **도선**입니다. 그러면 그 전원과 이어진 저항이 땅에 바로 붙습니다.
</Note>

## 풀이

**(가) 12V만.** 6V 전원을 도선으로 바꾸면 R5(1k)가 B에서 땅으로 내려갑니다. B 아래는 R4 ∥ R5 = 3k ∥ 1k = 0.75k, 거기에 R3를 더하면 2.75k, 이것이 A에서 R2(4k)와 나란히 있으니 1.63k입니다. 이제 전압 나누기 두 번으로 A ≈ **5.388V**, B ≈ **1.469V**입니다.

**(나) 6V만.** 12V 전원을 도선으로 바꾸면 R1(2k)이 A에서 땅으로 내려갑니다. 같은 방식으로 줄이면 B ≈ **3.673V**, A ≈ **1.469V**입니다.

**(다)** 더하면 A = 5.388 + 1.469 = **6.857V**, B = 1.469 + 3.673 = **5.143V**로 문제 5와 같습니다.

## 코드로 확인

```python
def par(a, b):
    return a * b / (a + b)

R1, R2, R3, R4, R5 = 2e3, 4e3, 2e3, 3e3, 1e3

# 1) V1 12V만: V2를 0V(도선)로 -> R5가 B에서 땅으로
rb = par(R4, R5)
ra = par(R2, R3 + rb)
va1 = 12 * ra / (R1 + ra)
vb1 = va1 * rb / (R3 + rb)

# 2) V2 6V만: V1을 도선으로 -> R1이 A에서 땅으로
ra = par(R1, R2)
rb = par(R4, R3 + ra)
vb2 = 6 * rb / (R5 + rb)
va2 = vb2 * ra / (R3 + ra)

print(f"V1만: A {va1:.4f}V, B {vb1:.4f}V")
print(f"V2만: A {va2:.4f}V, B {vb2:.4f}V")
print(f"합:   A {va1 + va2:.4f}V, B {vb1 + vb2:.4f}V")

# 전력은 더해지지 않는다: R3의 전력
p_each = ((va1 - vb1) ** 2 + (va2 - vb2) ** 2) / R3
p_true = ((va1 + va2) - (vb1 + vb2)) ** 2 / R3
print(f"R3 전력: 따로 구해 더하면 {p_each * 1e3:.3f}mW, 실제 {p_true * 1e3:.3f}mW")
```

```text
V1만: A 5.3878V, B 1.4694V
V2만: A 1.4694V, B 3.6735V
합:   A 6.8571V, B 5.1429V
R3 전력: 따로 구해 더하면 10.106mW, 실제 1.469mW
```

## 전력은 더해지지 않는다

마지막 줄이 중요합니다. 전압과 전류는 더해지지만, **전력은 더해지지 않습니다**. 전력은 전압의 제곱(또는 전압 × 전류)이라 선형이 아니기 때문입니다. R3에서는 두 전원이 만든 전류가 서로 **반대 방향**이라(12V는 A→B로, 6V는 B→A로 밀어냄) 실제로는 상당히 상쇄되는데, 전력을 따로 구해 더하면 이 상쇄를 놓쳐 일곱 배 가까이 큰 값이 나옵니다. 중첩으로는 전압과 전류를 먼저 더한 다음, 그 합으로 전력을 구합니다.

## 시뮬레이션으로 확인

`alter`로 전원의 값을 바꿔 가며 같은 회로를 두 번 풀었습니다.

```spice

R3 a b 2k
R4 b 0 3k
R5 v2 b 1k
V2 v2 0 DC 6
.control

alter V2 dc = 6
alter V1 dc = 0
op

.endc
.end
```

```text
v(a) = 5.387755e+00
v(b) = 1.469388e+00
v(a) = 1.469388e+00
v(b) = 3.673469e+00
```

<Note>
(가)의 B와 (나)의 A가 똑같이 1.4694V인 것은 우연이 아닙니다. 두 전원을 노턴 전류원으로 바꾸면 둘 다 6mA(12V/2k, 6V/1k)이고, [「문제 5」](#/read/ee-intro/dc-problem-5)의 행렬 G가 대칭이라서 "A에 넣은 전류가 B에 만드는 전압"과 "B에 넣은 같은 전류가 A에 만드는 전압"이 같습니다. 이것을 **상반성**(reciprocity)이라고 합니다. 전류원을 끌 때는 0A, 곧 **끊긴 곳**으로 바꾼다는 것도 함께 기억해 둡니다.
</Note>

## 정리

- 선형 회로에서는 전원을 하나씩만 켜고 구한 전압·전류를 더하면 전체 결과가 된다
- 전압원을 끄면 도선(0V), 전류원을 끄면 끊긴 곳(0A)으로 바꾸고, 그러면 전원 하나짜리 회로를 줄이기로 풀 수 있다
- 전력은 선형이 아니라 더해지지 않으므로, 전압·전류를 먼저 더한 뒤 전력을 구한다
