전압 나누기 두 개를 나란히 세우고 그 가운데 점끼리의 차이를 보는 회로가 **휘트스톤 브리지**입니다. 1800년대부터 저항을 정밀하게 재는 데 썼고, 지금도 무게 센서(로드셀)와 압력 센서 속에 들어 있습니다. 이 문제는 [「문제 2」](#/read/ee-intro/dc-problem-2)의 줄이기가 **통하지 않는** 첫 회로이기도 합니다.

## 문제

<Figure caption="왼쪽 다리 R1·R2, 오른쪽 다리 R3·Rx. 가운데 점 A와 B 사이의 전압을 본다">
  <Circuit spec="B 0,2 0,0 10V; W 0,0 4,0; D 2,0; R 2,0 2,1 R1 1kΩ; D 2,1; O 2,1; T 1.7,1 A; R 2,1 2,2 R2 2kΩ; R 4,0 4,1 R3 3kΩ; D 4,1; O 4,1; T 3.7,1 B; R 4,1 4,2 Rx; W 4,2 0,2; D 2,2; G 0,2" label="10볼트 전지에 두 다리가 병렬로 이어진 브리지. 왼쪽은 1킬로옴과 2킬로옴, 오른쪽은 3킬로옴과 Rx이고 가운데 점이 A와 B" />
</Figure>

- (가) A와 B 사이 전압이 0이 되는(균형) Rx는?
- (나) Rx가 그보다 10% 큰 6.6kΩ이면 B − A는 몇 mV인가?
- (다) A와 B 사이에 1kΩ짜리 계기를 이으면 계기로 흐르는 전류는?

<Note kind="tip">
실마리: (가)와 (나)는 각 다리를 따로 된 전압 나누기로 보면 됩니다. (다)는 계기가 두 다리를 잇는 순간 어떤 두 저항도 직렬이나 병렬이 아니게 됩니다. 이럴 때는 모르는 마디 전압을 놓고 식을 세웁니다.
</Note>

## 풀이

**(가)** 왼쪽 다리의 A는 10 × R2/(R1+R2), 오른쪽의 B는 10 × Rx/(R3+Rx)입니다. 둘이 같으려면 비율이 같아야 하므로 **R1/R2 = R3/Rx**, 곧 Rx = R2 × R3 / R1 = 2k × 3k / 1k = **6kΩ**입니다. 전원 전압이 얼마든 균형 조건은 같다는 것이 브리지의 장점입니다. 전원이 흔들려도 0은 0입니다.

**(나)** A = 10 × 2/3 = 6.667V, B = 10 × 6.6/9.6 = 6.875V이므로 B − A = **약 208mV**입니다.

**(다)** 계기가 A와 B를 이으면, 예를 들어 R1과 R2 사이 마디 A에 계기가 붙어 있어 둘은 직렬이 아니고, R1과 R3도 아래 끝이 다른 마디라 병렬이 아닙니다. 그래서 A와 B의 전압을 모르는 값으로 놓고, **마디마다 들어오는 전류 = 나가는 전류**를 세웁니다(키르히호프 전류 법칙). 마디 A에서는

(10 − V_A)/R1 = V_A/R2 + (V_A − V_B)/R_m

이고 마디 B도 같은 꼴입니다. 모르는 값 두 개, 식 두 개이니 풀립니다. 이 방법은 [「문제 5」](#/read/ee-intro/dc-problem-5)에서 제대로 다룹니다.

## 코드로 확인

```python
import numpy as np

V, R1, R2, R3 = 10.0, 1e3, 2e3, 3e3

# (가) 균형: R1/R2 = R3/Rx
rx_bal = R2 * R3 / R1
print(f"(가) 균형이 되는 Rx {rx_bal:.0f}Ω")

# (나) Rx가 10% 크면: 두 전압 나누기의 차이
def v_ab(rx):
    va = V * R2 / (R1 + R2)
    vb = V * rx / (R3 + rx)
    return vb - va

print(f"(나) Rx 6600Ω일 때 B - A = {v_ab(6600.0) * 1000:.1f}mV")

# (다) A와 B 사이에 1kΩ 계기: 마디 A, B의 연립방정식
def bridge_with_meter(rx, rm=1e3):
    # 마디 A: (V-VA)/R1 = VA/R2 + (VA-VB)/Rm, 마디 B도 같은 꼴
    a = np.array([[1/R1 + 1/R2 + 1/rm, -1/rm],
                  [-1/rm, 1/R3 + 1/rx + 1/rm]])
    b = np.array([V / R1, V / R3])
    va, vb = np.linalg.solve(a, b)
    return va, vb, (vb - va) / rm

va, vb, i_ba = bridge_with_meter(6600.0)
print(f"(다) 계기를 달면 A {va:.4f}V, B {vb:.4f}V")
print(f"    계기로 B에서 A로 {i_ba * 1e6:.1f}µA")

# 작은 변화에 대한 감도: Rx가 0.1%만 바뀌어도
d = v_ab(rx_bal * 1.001)
print(f"Rx 0.1% 변화 -> {d * 1000:.3f}mV")
```

```text
(가) 균형이 되는 Rx 6000Ω
(나) Rx 6600Ω일 때 B - A = 208.3mV
(다) 계기를 달면 A 6.7039V, B 6.7598V
    계기로 B에서 A로 55.9µA
Rx 0.1% 변화 -> 2.221mV
```

- (다)에서 계기를 달자 A와 B의 차이가 208mV에서 56mV로 줄었습니다. 계기로 전류가 흐르며 두 점을 서로 끌어당기기 때문입니다. 계기의 저항이 클수록 (나)의 값에 가까워집니다
- 마지막 줄은 감도입니다. 균형에서 Rx가 **0.1% 만큼만** 바뀌어도 2.2mV가 나옵니다. 0에서 벗어난 작은 차이를 보는 것이라, 작은 변화를 크게 키워 볼 수 있습니다. 로드셀의 스트레인 게이지가 무게에 따라 아주 조금 늘어나는 것을 이렇게 잽니다

## 실험해 보기

1kΩ, 2kΩ(또는 2.2kΩ), 3kΩ(또는 3.3kΩ)과 10kΩ 가변 저항으로 Rx를 만들고, 멀티미터를 A와 B 사이에 대어 0V가 되도록 가변 저항을 돌립니다. 그때 가변 저항을 빼서 저항을 재 보면 R2 × R3 / R1에 가까울 것입니다. 이것이 브리지로 모르는 저항을 재는 원래의 방법입니다.

## 정리

- 휘트스톤 브리지는 R1/R2 = R3/Rx일 때 균형이 되어 가운데 전압이 0이고, 이 조건은 전원 전압과 무관하다
- 균형 근처에서는 저항의 작은 변화가 0에서 벗어난 작은 전압으로 나타나 센서에 쓰인다
- 가운데에 계기를 이으면 직렬·병렬이 아니게 되어 줄이기로 풀리지 않으며, 마디 전압을 놓고 전류 법칙으로 푼다
