전기와 자기에 관한 모든 것은 맥스웰 방정식 네 개에 들어 있습니다. 그런데 이 책은 지금까지 맥스웰 방정식을 한 번도 쓰지 않고 [「옴의 법칙」](#/read/ee-intro/ohm)과 회로도, 키르히호프의 두 법칙만으로 아홉 문제를 풀었습니다. 이 쪽은 그 두 세계가 어떻게 이어지는지, 그리고 왜 회로 쪽이 그렇게 편한지를 봅니다.

## 맥스웰 방정식

| 이름 | 식 | 말로 하면 |
| --- | --- | --- |
| 가우스 법칙 | ∇·E = ρ/ε₀ | 전하에서 전기장이 뻗어 나온다 |
| 자기 가우스 법칙 | ∇·B = 0 | 자기장에는 시작점도 끝점도 없다 |
| 패러데이 법칙 | ∇×E = −∂B/∂t | 변하는 자기장이 소용돌이치는 전기장을 만든다 |
| 앙페르-맥스웰 법칙 | ∇×B = μ₀J + μ₀ε₀ ∂E/∂t | 전류와 변하는 전기장이 자기장을 감아 돈다 |

여기에 물질의 성질 하나, 도체 속에서 전류 밀도가 전기장에 비례한다는 **J = σE**를 더합니다(σ는 전도도). 이 식들은 공간의 **모든 점, 모든 순간**의 E와 B를 다룹니다. 다음 장 [「전기와 자기장」](#/read/ee-intro/fields)에서 장(field) 자체를 더 봅니다.

## 회로 법칙은 세 가지 근사에서 나온다

[「집중 소자 (lumped elements)」](#/read/ee-intro/lumped)의 가정, 곧 회로가 파장보다 충분히 작다는 조건을 더하면 맥스웰 방정식이 회로 법칙으로 줄어듭니다.

**1. 키르히호프 전압 법칙(KVL).** 패러데이 법칙의 오른쪽 ∂B/∂t가 **소자 바깥에서 0**이라고 봅니다. 변하는 자기장은 인덕터 속에만 가둬져 있다고 보는 것입니다. 그러면 소자 바깥의 전기장은 소용돌이가 없어서, 두 점 사이의 전압이 **어느 길로 재든 같아집니다**. 한 바퀴 돌면 처음 자리로 오니 전압의 합은 0, 곧 KVL입니다. 인덕터 속에 가둬 둔 자기장의 변화는 V = L·dI/dt라는 소자의 식으로 따로 챙깁니다.

**2. 키르히호프 전류 법칙(KCL).** 앙페르-맥스웰 법칙에 발산을 취하면 전하 보존 ∇·J = −∂ρ/∂t가 나옵니다. 여기서 **마디에는 전하가 쌓이지 않는다**(∂ρ/∂t = 0)고 봅니다. 전하가 쌓이는 곳은 축전기 속에만 있다고 보는 것입니다. 그러면 마디로 들어온 전류는 모두 나가야 하니 KCL입니다. 축전기에 쌓이는 전하는 I = C·dV/dt로 챙깁니다.

**3. 옴의 법칙.** 길이 L, 단면적 A인 도체에 J = σE를 적용하면, 전류 I = JA, 전압 V = EL이므로 V = (L / σA)·I, 곧 **R = ρL/A**(ρ = 1/σ는 비저항)입니다. 도선은 σ가 아주 커서 R ≈ 0, 도선 위는 어디나 같은 전압으로 봅니다.

| 맥스웰 쪽 | 근사 | 회로 쪽 |
| --- | --- | --- |
| ∇×E = −∂B/∂t | 소자 밖에서 ∂B/∂t ≈ 0 | KVL, 인덕터 V = L dI/dt |
| ∇·J = −∂ρ/∂t | 마디에서 ∂ρ/∂t ≈ 0 | KCL, 축전기 I = C dV/dt |
| J = σE | 도체 모양으로 적분 | V = IR, R = ρL/A |

## 숫자로 보기

```python
import math

RHO_CU = 1.68e-8          # 구리의 비저항(Ω·m, 20°C)
Q = 1.602e-19             # 전자 하나의 전하(C)
N_CU = 8.5e28             # 구리 1m³ 속 자유 전자 수(대략)

# 1) 옴의 법칙은 J = σE에서: 선의 저항 R = ρL/A
for d_mm in (0.5, 0.644, 1.0):
    a = math.pi * (d_mm / 2 * 1e-3) ** 2
    print(f"지름 {d_mm}mm 구리선 1m: {RHO_CU * 1.0 / a * 1000:.1f}mΩ")

# 2) 전자는 아주 느리게 걷는다: 1mm² 구리선에 1A
a = 1e-6
v_drift = 1.0 / (N_CU * Q * a)
print(f"전자의 평균 이동 속력 {v_drift * 1000:.3f}mm/s"
      f" -> 1m 가는 데 {1 / v_drift / 3600:.1f}시간")

# 3) 셈의 양: 10cm 정육면체를 1mm 칸으로 나눠 장을 계산하면
cells = (100) ** 3
print(f"장 계산: 칸 {cells:,}개 × 장 성분 6개 = 모르는 값 {cells * 6:,}개")
print("회로 계산: 빵판 회로의 마디 몇 개 = 모르는 값 몇 개")
```

```text
지름 0.5mm 구리선 1m: 85.6mΩ
지름 0.644mm 구리선 1m: 51.6mΩ
지름 1.0mm 구리선 1m: 21.4mΩ
전자의 평균 이동 속력 0.073mm/s -> 1m 가는 데 3.8시간
장 계산: 칸 1,000,000개 × 장 성분 6개 = 모르는 값 6,000,000개
회로 계산: 빵판 회로의 마디 몇 개 = 모르는 값 몇 개
```

- **R = ρL/A**: 빵판 점퍼선 굵기(지름 0.5~0.64mm) 1m가 수십 mΩ입니다. kΩ 단위의 저항들 사이에서는 0으로 봐도 되는 크기라, "도선은 아무 일도 하지 않는다"는 가정이 맞습니다. 큰 전류가 흐르면 이야기가 달라져서, 1A에 85.6mΩ이면 85mV가 선에서 사라집니다
- **전자는 느리다**: 1mm² 구리선에 1A가 흐를 때 전자의 평균 이동 속력은 초당 0.07mm, 1m를 가는 데 거의 네 시간입니다. 그런데도 스위치를 켜면 전등은 바로 켜집니다. 전하를 실어 나르는 것은 느린 전자지만, **신호(전기장의 변화)는 빛에 가까운 속력**으로 선을 따라 퍼지기 때문입니다. 회로 이론은 이 "바로"를 "같은 순간"으로 근사합니다
- **셈의 양**: 10cm 상자를 1mm 칸으로만 나눠도 장 계산의 모르는 값은 600만 개이고, 시간에 따라 이것을 계속 다시 풀어야 합니다. 회로 이론은 같은 빵판 회로를 마디 몇 개짜리 연립방정식으로 바꿉니다. 이것이 회로도가 편한 진짜 까닭입니다

<Note>
그렇다고 맥스웰 방정식이 쓸모없는 것은 아닙니다. 안테나, 고속 기판의 선, 전자파 간섭, 무선 충전 코일처럼 [「집중 소자 (lumped elements)」](#/read/ee-intro/lumped)의 가정이 깨지는 곳에서는 장을 직접 계산하는 프로그램(전자기장 해석기)을 씁니다. 회로 이론은 "장을 다 풀지 않아도 되는 경우"를 위한 아주 잘 만든 지름길이고, 그 지름길이 언제 통하는지 아는 것이 공학입니다.
</Note>

## 정리

- 맥스웰 방정식은 모든 점·모든 순간의 전기장과 자기장을 다루고, 회로 법칙은 집중 소자 근사 아래에서 거기서 나온다
- 소자 밖의 ∂B/∂t ≈ 0에서 KVL, 마디의 ∂ρ/∂t ≈ 0에서 KCL, J = σE를 도체 모양으로 적분해 R = ρL/A와 옴의 법칙이 나온다
- 회로 이론은 수백만 개의 장 값을 마디 몇 개의 식으로 줄여 주며, 그 가정이 깨지는 높은 주파수와 큰 구조에서는 장을 직접 푼다
