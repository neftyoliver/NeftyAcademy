직류 문제의 마지막은 [「문제 5」](#/read/ee-intro/dc-problem-5)의 마디 해석과 짝을 이루는 **고리 해석**(mesh analysis)입니다. 마디 해석이 마디마다 **전류**의 합을 맞췄다면, 고리 해석은 고리마다 **전압**의 합을 맞춥니다. 같은 회로를 두 방법으로 풀어 보면 어느 쪽이 편한지 고르는 눈이 생깁니다.

## 문제

- (가) 고리 전류 I1, I2, I3는?
- (나) R2와 R4에 흐르는 전류와 마디 A, B의 전압은?
- (다) 5V 전원은 전력을 내고 있나, 받고 있나?

<Note kind="tip">
실마리: 고리를 한 바퀴 돌며 만나는 전압을 모두 더하면 0입니다(키르히호프 전압 법칙). 두 고리가 함께 쓰는 저항에는 **두 고리 전류의 차이**가 흐릅니다.
</Note>

## 풀이: 식 세우기

kΩ과 mA로 씁니다. 저항에서의 전압 강하를 "전원이 미는 전압"과 같다고 놓습니다.

- **고리 1**: 10 = 1·I1 + 2·(I1 − I2), 곧 **3I1 − 2I2 = 10**
- **고리 2**: 0 = 2·(I2 − I1) + 3·I2 + 4·(I2 − I3), 곧 **−2I1 + 9I2 − 4I3 = 0**
- **고리 3**: 5V 전원은 + 쪽이 위라서, 시계 방향으로 돌면 이 전원을 + 에서 − 로 내려가며 지납니다. 고리를 **거꾸로** 미는 셈이라 −5로 둡니다. 4·(I3 − I2) + 1·I3 = −5, 곧 **−4I2 + 5I3 = −5**

식을 행렬로 쓰면 [「문제 5」](#/read/ee-intro/dc-problem-5)의 G·V = I와 똑같이 생긴 **R·I = V**가 됩니다. 대각선은 그 고리를 도는 저항의 합, 옆 칸은 함께 쓰는 저항에 음수를 붙인 것입니다. 이번에도 행렬은 대칭입니다.

## 코드로 확인

```python
import numpy as np

# 단위: kΩ, V, mA (kΩ × mA = V)
R1, R2, R3, R4, R5 = 1, 2, 3, 4, 1
V1, V2 = 10, 5

# 고리 전류 I1, I2, I3는 모두 시계 방향
R = np.array([[R1 + R2, -R2,          0],
              [-R2,      R2 + R3 + R4, -R4],
              [0,        -R4,          R4 + R5]], dtype=float)
V = np.array([V1, 0, -V2], dtype=float)  # 고리를 시계 방향으로 밀면 +
i1, i2, i3 = np.linalg.solve(R, V)
print(f"I1 {i1:.4f}mA, I2 {i2:.4f}mA, I3 {i3:.4f}mA")

# 가지 전류: 함께 쓰는 저항에는 두 고리 전류의 차이가 흐른다
print(f"R2(아래로) {i1 - i2:.4f}mA, R4(아래로) {i2 - i3:.4f}mA")
va, vb = (i1 - i2) * R2, (i2 - i3) * R4      # 위쪽 두 마디의 전압
print(f"마디 A {va:.4f}V, 마디 B {vb:.4f}V")

# 검산: 마디 해석으로도 같은가
G = np.array([[1/R1 + 1/R2 + 1/R3, -1/R3],
              [-1/R3, 1/R3 + 1/R4 + 1/R5]])
I = np.array([V1 / R1, V2 / R5])
print("마디 해석으로", np.round(np.linalg.solve(G, I), 4))
```

```text
I1 3.7313mA, I2 0.5970mA, I3 -0.5224mA
R2(아래로) 3.1343mA, R4(아래로) 1.1194mA
마디 A 6.2687V, 마디 B 4.4776V
마디 해석으로 [6.2687 4.4776]
```

- **I3가 음수**입니다. 실제로는 오른쪽 칸에서 반시계 방향, 곧 5V 전원에서 R5를 지나 B로 0.522mA가 흘러 들어갑니다. 방향을 잘못 놓아도 부호가 바로잡아 줍니다
- R2에는 I1 − I2 = 3.134mA, R4에는 I2 − I3 = 1.119mA가 아래로 흐르고, 마디 전압은 A = 6.269V, B = 4.478V입니다
- 같은 회로를 마디 해석으로 풀어도(마지막 줄) 같은 값입니다
- (다) 5V 전원은 + 단자에서 전류를 **내보내고** 있으니(B가 4.48V로 5V보다 낮아서) 전력을 냅니다. 5V × 0.522mA ≈ 2.6mW입니다. 전압이 더 낮은 쪽 전원이라고 늘 전력을 받는 것은 아닙니다

## 마디 해석과 고리 해석, 무엇을 쓸까

| | 마디 해석 | 고리 해석 |
| --- | --- | --- |
| 모르는 값 | 땅이 아닌 마디의 전압 | 칸마다의 고리 전류 |
| 세우는 식 | 마디마다 전류의 합 = 0 | 고리마다 전압의 합 = 0 |
| 편한 경우 | 전류원이 많을 때, 마디가 적을 때 | 전압원이 많을 때, 칸이 적을 때 |

이 회로는 모르는 마디가 둘(A, B), 칸이 셋이라 마디 해석이 식 하나 적습니다. 고리 해석은 선이 엇갈리지 않게 평면에 그릴 수 있는 회로에서만 그대로 쓸 수 있고, 마디 해석은 어떤 회로에든 쓸 수 있어서 컴퓨터는 마디 해석을 씁니다. 손으로는 식이 적은 쪽을 고르면 됩니다.

<Note>
고리 위에 **전류원**이 있으면, 그 고리의 전류가 바로 정해지거나(바깥 가지에 있을 때), 두 고리를 하나로 합친 "초고리"(supermesh)로 다룹니다. 전류원 양 끝의 전압은 전원이 정하지 않고 회로가 정하므로 모르는 값입니다. 마디 해석에서 전압원이 비슷한 역할을 하는 것과 거울처럼 짝을 이룹니다.
</Note>

## 정리

- 고리 해석은 칸마다 고리 전류를 놓고 고리를 도는 전압의 합 = 0을 세우며, 함께 쓰는 저항에는 두 고리 전류의 차이가 흐른다
- 식은 대칭인 R·I = V 모양이 되고, 답의 부호가 실제 방향을 알려 주며, 마디 해석과 같은 결과를 준다
- 모르는 값이 적은 쪽을 고르되, 어떤 회로에든 쓸 수 있는 마디 해석이 컴퓨터의 표준이다
