화면에는 보통 가로 10칸, 세로 8칸의 눈금이 있습니다. 세로 손잡이(**V/칸**, volts/div)는 한 칸이 몇 볼트인지, 가로 손잡이(**시간/칸**, time/div)는 한 칸이 몇 초인지 정합니다. 값은 **칸 수 × 칸당 값**으로 읽습니다.

```python
import math

# 1) 화면 읽기: 칸 수 × 칸당 값
v_div, t_div = 0.5, 0.25e-3          # 0.5 V/칸, 0.25 ms/칸
pp_divs, period_divs = 3.2, 4.0      # 봉우리~골 3.2칸, 한 주기 4칸
vpp = pp_divs * v_div
period = period_divs * t_div
print(f"Vpp {vpp:.1f}V, 주기 {period * 1e3:.2f}ms, 주파수 {1 / period:.0f}Hz")

# 2) 너무 드물게 찍으면: 9kHz 사인을 초당 10,000번 찍기
f_sig, fs = 9000.0, 10000.0
alias = abs(f_sig - round(f_sig / fs) * fs)
print(f"{f_sig:.0f}Hz를 {fs:.0f}S/s로 찍으면 {alias:.0f}Hz처럼 보인다")
for n in range(5):
    t = n / fs
    real = math.sin(2 * math.pi * f_sig * t)
    fake = -math.sin(2 * math.pi * alias * t) + 0.0   # -0.0을 0.0으로
    print(f"  {n}번째 점: 9kHz {real:+.3f}, 거꾸로 선 1kHz {fake:+.3f}")
```

```text

9000Hz를 10000S/s로 찍으면 1000Hz처럼 보인다
  0번째 점: 9kHz +0.000, 거꾸로 선 1kHz +0.000
  1번째 점: 9kHz -0.588, 거꾸로 선 1kHz -0.588
  2번째 점: 9kHz -0.951, 거꾸로 선 1kHz -0.951
  3번째 점: 9kHz -0.951, 거꾸로 선 1kHz -0.951
  4번째 점: 9kHz -0.588, 거꾸로 선 1kHz -0.588
```

첫 줄이 위 그림의 처음 설정(0.5 V/칸, 0.25 ms/칸)을 읽은 것입니다. 봉우리에서 골까지 3.2칸이면 1.6V, 한 주기가 4칸이면 1ms이고 주파수는 1kHz입니다. 신호가 화면의 반쯤에서 서너 칸을 차지하도록 손잡이를 맞추면 가장 정확하게 읽힙니다. 요즘 디지털 오실로스코프는 측정(measure) 기능으로 이런 값을 자동으로 계산해 주지만, 칸으로 읽는 법을 알아야 숫자가 이상할 때 알아챕니다.

## 트리거: 그림을 멈춰 세우기

신호는 계속 흐르는데 화면이 같은 자리에 멈춰 보이는 것은 **트리거** 덕분입니다. "전압이 0V를 **올라가며** 지나는 순간"(레벨과 기울기)을 화면의 같은 자리(그림의 노란 표시)에 맞춰 그리기 때문입니다. 트리거가 맞지 않으면 파형이 옆으로 흘러가거나 겹쳐 보입니다.

- **Auto**: 트리거가 없어도 계속 그린다. 처음 신호를 찾을 때
- **Normal**: 트리거가 걸릴 때만 그린다. 가끔 오는 신호를 기다릴 때
- **Single**: 한 번 걸리면 멈춘다. 한 번뿐인 사건(전원을 켜는 순간 등)을 잡을 때

입력의 **DC/AC 결합**도 알아 둡니다. DC는 신호를 그대로, AC는 직류 성분(오프셋)을 빼고 변하는 부분만 보여 줍니다. 5V 위에 얹힌 작은 떨림을 크게 보고 싶을 때 AC 결합이 편합니다.

## 프로브: 1배와 10배

| | 1배(×1) | 10배(×10) |
| --- | --- | --- |
| 전압 | 그대로 | 1/10로 줄여 보냄 |
| 회로에 주는 부담 | 큼(약 1MΩ, 큰 정전 용량) | 작음(약 10MΩ) |
| 빠른 신호 | 잘 못 봄 | 잘 봄 |

보통은 **10배**로 씁니다. 회로를 덜 건드리고 빠른 신호를 더 잘 봅니다. 대신 오실로스코프 채널 설정도 ×10으로 맞춰야 숫자가 맞습니다. 10배 프로브는 처음 쓸 때 오실로스코프 앞의 **보정 단자**(보통 1kHz 네모파)에 대고, 프로브의 작은 나사를 돌려 네모파의 모서리가 둥글거나 뾰족 튀지 않고 반듯하게 보이도록 **보정**합니다.

<Note kind="warn">
책상용 오실로스코프의 프로브 **땅 집게는 콘센트의 접지와 이어져** 있는 경우가 대부분입니다. 콘센트 전기에 직접 물린 회로에서 땅 집게를 접지가 아닌 곳에 물리면, 그 순간 큰 전류가 땅 집게로 흘러 프로브와 회로, 오실로스코프가 망가지고 위험합니다. 이 책의 실험은 전지나 저전압 어댑터로만 합니다. 땅 집게는 항상 회로의 땅(0V)에 물립니다.
</Note>

## 대역폭과 샘플링

- **대역폭**: 오실로스코프가 제대로 보여 줄 수 있는 주파수의 한계입니다. 대역폭 근처의 신호는 실제보다 작게 보이고, 네모파의 모서리가 둥글어집니다. 보려는 신호의 가장 높은 주파수보다 몇 배(흔히 다섯 배) 넉넉한 것을 고릅니다
- **샘플링**: 디지털 오실로스코프는 전압을 일정한 간격으로 찍어 이어 그립니다. 너무 드물게 찍으면 위 계산처럼 **9kHz 신호가 1kHz처럼** 보입니다(앨리어싱). 찍은 점 다섯 개가 거꾸로 선 1kHz 사인과 소수 셋째 자리까지 같습니다. 신호의 가장 높은 주파수의 두 배보다 촘촘하게 찍어야 하고, 실제로는 훨씬 더 촘촘하게 찍습니다. 시간/칸을 크게 하면 찍는 간격도 넓어지니, 파형이 이상하게 느리면 시간/칸을 줄여 확인합니다

## 정리

- 화면은 가로 10칸, 세로 8칸 정도의 눈금으로, 값은 칸 수 × 칸당 값(V/칸, 시간/칸)으로 읽는다
- 트리거가 같은 순간을 같은 자리에 맞춰 파형을 멈춰 세우며, Auto·Normal·Single과 DC·AC 결합을 상황에 맞게 고른다
- 프로브는 보통 10배로 쓰고 보정하며, 땅 집게는 회로의 땅에만 물리고, 대역폭과 샘플링이 부족하면 파형이 거짓으로 보인다
