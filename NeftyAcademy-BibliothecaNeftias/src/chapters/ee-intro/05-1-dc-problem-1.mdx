직류 회로 문제의 첫 번째는 [「옴의 법칙」](#/read/ee-intro/ohm)의 **전압 나누기**에서 시작합니다. 식은 간단하지만, 그 출력에 무언가를 이으면 어떻게 되는지가 실제로 가장 자주 부딪히는 문제입니다.

## 문제

<Figure caption="12V를 4kΩ과 6kΩ으로 나누고, 출력에 부하 RL을 단다">
  <Circuit spec="B 0,2 0,0 12V; R 0,0 2,0 R1 4kΩ; D 2,0; O 2,0 ^출력; R 2,0 2,2 R2 6kΩ; W 2,0 3.5,0; R 3.5,0 3.5,2 RL; W 3.5,2 0,2; D 2,2; G 0,2" label="12볼트 전지, 4킬로옴 R1, 출력 마디 아래 6킬로옴 R2와 부하 RL이 병렬인 회로" />
</Figure>

- (가) 부하 RL을 떼었을 때 출력 전압은?
- (나) RL = 12kΩ을 달면 출력 전압과, R1·RL에 흐르는 전류는?
- (다) 출력이 (가)의 95% 이상으로 유지되려면 RL은 대략 얼마 이상이어야 할까?

<Note kind="tip">
실마리: 출력 마디 아래에 R2와 RL이 **나란히** 붙어 있습니다. 둘을 하나로 합치면 다시 저항 두 개짜리 전압 나누기가 됩니다.
</Note>

## 풀이

**(가)** 부하가 없으면 그냥 전압 나누기입니다. 12V × 6k / (4k + 6k) = **7.2V**입니다.

**(나)** R2(6k)와 RL(12k)의 병렬은 6×12 / (6+12) = **4kΩ**입니다. 그러면 위아래가 4k와 4k이므로 전원 전압이 반씩 나뉘어 출력은 **6.0V**로 내려갑니다. R1에는 12 − 6 = 6V가 걸리니 6V / 4k = **1.5mA**, 부하에는 6V / 12k = **0.5mA**가 흐릅니다. 나머지 1mA는 R2로 흐릅니다(6V / 6k). 마디에 들어온 1.5mA가 0.5mA와 1mA로 나뉘어 나가는 것도 맞습니다.

**(다)** 부하가 클수록 병렬 저항이 R2에 가까워져 출력이 7.2V로 돌아옵니다. 손으로는 여러 값을 넣어 보면 되고, 코드로 한꺼번에 봅니다.

## 코드로 확인

```python
def parallel(a, b):
    return a * b / (a + b)

VIN, R1, R2 = 12.0, 4000.0, 6000.0

# (가) 부하 없이
v_open = VIN * R2 / (R1 + R2)
print(f"(가) 부하 없음: {v_open:.2f}V")

# (나) 12kΩ 부하: R2와 병렬
RL = 12000.0
r_low = parallel(R2, RL)
v_load = VIN * r_low / (R1 + r_low)
print(f"(나) 12kΩ 부하: 아래쪽 {r_low:.0f}Ω, 출력 {v_load:.2f}V")
i_load = v_load / RL
i_r1 = (VIN - v_load) / R1
print(f"    부하 전류 {i_load * 1000:.2f}mA, R1 전류 {i_r1 * 1000:.2f}mA")

# (다) 부하를 바꿔 가며: 출력이 7.2V의 95% 이상이려면?
for rl in (12e3, 60e3, 120e3, 1e6):
    r = parallel(R2, rl)
    v = VIN * r / (R1 + r)
    print(f"    RL {rl / 1000:>6.0f}kΩ -> {v:.3f}V ({v / v_open * 100:.1f}%)")
```

```text
(가) 부하 없음: 7.20V
(나) 12kΩ 부하: 아래쪽 4000Ω, 출력 6.00V
    부하 전류 0.50mA, R1 전류 1.50mA
    RL     12kΩ -> 6.000V (83.3%)
    RL     60kΩ -> 6.923V (96.2%)
    RL    120kΩ -> 7.059V (98.0%)
    RL   1000kΩ -> 7.183V (99.8%)
```

60kΩ이면 96%를 넘습니다. 흔히 쓰는 어림법은 "부하를 나누기 저항(여기서는 R1과 R2를 병렬로 본 2.4kΩ)보다 **열 배 이상** 크게"인데, 이 회로에서 24kΩ이면 약 91%이고 스무 배쯤인 60kΩ에서 95%를 넘습니다. 원하는 정확도에 따라 배수를 정합니다.

## 실험해 보기

빵판에 4.7kΩ과 6.8kΩ처럼 가까운 표준 값으로 꾸미고 멀티미터로 출력을 잽니다. 부하 대신 10kΩ, 100kΩ, 1MΩ을 차례로 달아 보면 출력이 오르는 것이 보입니다. 멀티미터 자체도 보통 10MΩ쯤의 부하라서, 아주 큰 저항으로 만든 나누기를 재면 멀티미터가 출력을 끌어내립니다. **재는 도구도 부하**라는 것이 이 문제의 다른 교훈입니다.

<Note>
그래서 전압 나누기는 기준 전압을 "보여 주는" 데는 좋지만, 전류를 많이 쓰는 회로에 전원을 대 주는 데는 맞지 않습니다. 그런 곳에는 전압 조정기(레귤레이터)를 씁니다.
</Note>

## 정리

- 전압 나누기의 출력에 부하를 달면 부하가 아래쪽 저항과 병렬이 되어 출력이 내려간다
- 병렬로 합친 저항으로 다시 나누기를 계산하고, 마디에서 들어오고 나가는 전류의 합이 맞는지로 검산한다
- 출력을 지키려면 부하를 나누기 저항보다 훨씬(열 배, 스무 배) 크게 하고, 측정기도 부하라는 것을 기억한다
