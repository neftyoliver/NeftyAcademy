**빵판**(breadboard)은 납땜 없이 부품을 꽂았다 뺐다 하며 회로를 짜 보는 판입니다. 이 책의 실험은 거의 다 빵판 위에서 합니다. 겉으로는 구멍이 줄지어 있을 뿐이지만, 속에서 **어느 구멍끼리 이어져 있는지**를 알아야 회로를 생각한 대로 꽂을 수 있습니다.

## 속은 이렇게 이어져 있다

<Figure caption="구멍을 눌러 보세요. 속에서 함께 이어진 구멍이 밝아집니다">
  <Breadboard />
</Figure>

- 가운데 부분은 **세로로 다섯 구멍**(a~e, 또는 f~j)이 금속 집게 하나로 이어져 있습니다. 같은 열이라도 a~e와 f~j는 이어져 있지 않습니다
- 가운데의 **홈**은 IC 칩을 걸쳐 꽂으라고 있는 자리입니다. 칩의 왼쪽 다리와 오른쪽 다리가 서로 다른 줄에 들어가서 합선되지 않습니다
- 가장자리의 **전원 줄**(빨강 +, 파랑 −)은 가로로 길게 이어져 있습니다. 긴 빵판은 전원 줄이 **가운데에서 끊긴** 것도 있으니, 처음 쓰는 빵판은 멀티미터로 양 끝이 이어졌는지 확인합니다
- 구멍 사이는 2.54mm(0.1인치)로, 대부분의 부품 다리와 핀 헤더 간격과 같습니다. 흔한 830구멍짜리는 가운데 63열 × 10행에 전원 줄 4개 × 50구멍입니다

## 연결을 코드로 흉내 내기

어느 구멍이 같은 무리인지 정하는 규칙을 그대로 적어 보면, 흔한 실수가 왜 실수인지 분명해집니다.

```python
# 830구멍 빵판의 연결을 흉내 낸다.
# 가운데 구멍: 열 1~63, 행 a~e와 f~j. 같은 열의 a~e 다섯 개가 한 줄로 이어져 있다.
# 전원 줄: 위아래 가장자리의 +와 - 줄이 각각 길게 이어져 있다.

def net(hole):
    """구멍 이름(예: 'a12', 'top+')을 '이어진 무리'의 이름으로 바꾼다."""
    if hole in ("top+", "top-", "bot+", "bot-"):
        return hole
    row, col = hole[0], int(hole[1:])
    half = "위" if row in "abcde" else "아래"
    return f"{col}열 {half}"

def check(name, leg1, leg2):
    verdict = "두 다리가 이어짐(합선)!" if net(leg1) == net(leg2) else "괜찮음"
    print(f"{name}: {leg1}–{leg2} -> {verdict}")

# 흔한 실수: 저항을 한 줄(같은 열) 안에 세로로 꽂기
check("저항 1", "a10", "e10")
# 바른 꽂기: 서로 다른 열에 걸치기
check("저항 2", "a10", "a14")
# 칩은 가운데 홈을 걸쳐 꽂는다: 1번 다리 e20, 맞은편 f20
check("칩 다리 1과 16", "e20", "f20")

holes = 63 * 10 + 4 * 50
print(f"구멍 수 {holes}")
```

```text
저항 1: a10–e10 -> 두 다리가 이어짐(합선)!
저항 2: a10–a14 -> 괜찮음
칩 다리 1과 16: e20–f20 -> 괜찮음
구멍 수 830
```

가장 흔한 실수가 첫째 줄입니다. 저항을 **한 열 안에** 세로로 꽂으면 두 다리가 속에서 이어져, 저항이 없는 것과 같아집니다. 부품은 항상 서로 다른 무리에 걸쳐 꽂습니다.

## 첫 회로: LED 하나

5V 전원에 빨간 LED를 켜 봅니다. LED는 전류를 제한하지 못하므로 반드시 저항을 함께 답니다. 값은 다음 장의 [「옴의 법칙」](#/read/ee-intro/ohm)으로 구합니다.

<Figure caption="5V, 저항, LED를 한 바퀴로 잇는다. 삼각형이 가리키는 쪽으로 전류가 흐른다">
  <Circuit spec="B 0,2 0,0 5V; R 0,0 2,0 330Ω; E 2,0 2,2 LED; W 2,2 0,2; D 0,2; G 0,2" label="5V 전지, 330옴 저항, LED가 한 바퀴로 이어진 회로" />
</Figure>

```python
# 5V에 빨간 LED 하나를 저항과 함께 단다.
V_SUPPLY = 5.0     # 전원 전압(V)
V_LED = 2.0        # 빨간 LED가 켜질 때 걸리는 전압(V), 데이터시트의 대략값
I_WANT = 0.010     # 흘리고 싶은 전류 10mA

r_exact = (V_SUPPLY - V_LED) / I_WANT
print(f"필요한 저항 {r_exact:.0f}Ω")

# 가게에서 파는 저항 값(E12 계열)에서 그보다 크거나 같은 것 고르기
E12 = [1.0, 1.2, 1.5, 1.8, 2.2, 2.7, 3.3, 3.9, 4.7, 5.6, 6.8, 8.2]
values = [m * 10**k for k in range(0, 6) for m in E12]
r = min(v for v in values if v >= r_exact)
i = (V_SUPPLY - V_LED) / r
p = i * i * r
print(f"고른 저항 {r:.0f}Ω -> 전류 {i * 1000:.1f}mA, "
      f"저항이 쓰는 전력 {p * 1000:.0f}mW")
```

```text
필요한 저항 300Ω
고른 저항 330Ω -> 전류 9.1mA, 저항이 쓰는 전력 27mW
```

- 저항은 아무 값이나 만들지 않고 **E12 같은 표준 값**으로 팝니다. 계산값 300Ω보다 조금 큰 330Ω을 고르면 전류가 조금 줄어 안전한 쪽입니다
- 저항이 쓰는 전력 27mW는 흔한 1/4W(250mW) 저항이 넉넉히 견딥니다
- LED는 **방향**이 있습니다. 다리가 긴 쪽(+, 애노드)을 전원 쪽에, 짧은 쪽(−, 캐소드)을 땅 쪽에 꽂습니다. 거꾸로 꽂으면 켜지지 않을 뿐 보통 망가지지는 않습니다

빵판에 꽂는 순서로 옮기면, 전원 줄 +에서 점퍼선으로 10열 위쪽에, 330Ω을 10열에서 14열로, LED의 긴 다리를 14열, 짧은 다리를 18열에, 18열에서 전원 줄 −로 점퍼선을 잇습니다. 이렇게 꽂고 나면 전류가 지나는 길을 손가락으로 한 바퀴 따라가 보는 습관을 들입니다.

<Note kind="warn">
빵판은 큰 전류와 높은 전압용이 아닙니다. 속 집게가 얇아서 보통 1A 안팎을 넘기지 않고, 이웃 줄 사이에 작은 정전 용량이 있어 수십 MHz 같은 빠른 신호도 잘 다루지 못합니다. 콘센트 전기(220V)는 절대 빵판에 연결하지 않습니다. 다리가 굵은 부품을 억지로 꽂으면 집게가 벌어져 그 구멍이 헐거워지니, 그런 부품은 얇은 선을 납땜해 꽂습니다.
</Note>

## 정리

- 빵판 가운데는 세로 다섯 구멍씩 이어져 있고, 가운데 홈으로 위아래가 나뉘며, 가장자리 전원 줄은 가로로 이어져 있다(긴 빵판은 가운데에서 끊길 수 있다)
- 부품은 서로 다른 무리에 걸쳐 꽂고, 칩은 가운데 홈을 걸쳐 꽂으며, 한 열 안에 세로로 꽂으면 합선된다
- LED에는 옴의 법칙으로 고른 저항을 함께 달고 방향을 지키며, 빵판에는 큰 전류·높은 전압·빠른 신호를 쓰지 않는다
