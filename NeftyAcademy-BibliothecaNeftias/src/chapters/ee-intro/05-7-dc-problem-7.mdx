[「문제 5」](#/read/ee-intro/dc-problem-5)와 [「문제 6」](#/read/ee-intro/dc-problem-6)에서는 R4까지 포함해 회로 전체를 풀었습니다. 그런데 R4 자리에 여러 부하를 바꿔 달아 보고 싶다면, 매번 전체를 다시 풀어야 할까요? **테브난 정리**는 "두 단자에서 본 선형 회로는 어떤 것이든 **전압원 하나와 저항 하나**로 바꿀 수 있다"고 말합니다.

## 문제

R4를 떼어 내고, 그 자리(B와 땅)를 두 단자로 봅니다.

<Figure caption="왼쪽: R4를 뗀 원래 회로. 오른쪽: B에서 보면 똑같이 행동하는 테브난 등가 회로">

- (가) B에서 본 테브난 전압 V_th와 저항 R_th는?
- (나) 등가 회로에 3kΩ(원래의 R4), 1kΩ, 10kΩ을 달면 B의 전압은 각각? 원래 회로를 다 푼 값과 같은가?

<Note kind="tip">
실마리: V_th는 단자를 **열어 둔** 채 잰 전압입니다. R_th는 단자를 **땅에 이었을 때** 흐르는 전류 I_sc로 V_th / I_sc를 구하거나, 모든 전원을 끄고(전압원은 도선으로) 단자에서 본 저항으로 구합니다.
</Note>

## 풀이

**V_th.** R4가 없으니 B로는 R3과 R5로만 전류가 드나듭니다. 마디 해석을 하면 5V_A − 2V_B = 24, −V_A + 3V_B = 12에서 V_B = 84/13 ≈ **6.462V**입니다.

**R_th, 방법 1.** 전원 둘을 도선으로 바꾸면 R1과 R5가 땅에 붙습니다. B에서 보면 R5(1k)와, R3 + (R1 ∥ R2) = 2k + 1.333k = 3.333k가 나란히 있으니 1k ∥ 3.333k ≈ **769.2Ω**입니다.

**R_th, 방법 2.** B를 땅에 바로 이으면, R5로 6V/1k = 6mA, R3로는 A에서 2.4mA가 들어와 I_sc = **8.4mA**입니다. 6.462V / 8.4mA ≈ **769.2Ω**으로 같습니다. 회로 속이 보이지 않을 때(실제 장치)에는 이 두 번째 방법, 곧 열린 전압과 짧은 회로 전류를 재는 방법을 씁니다. 다만 실제 장치를 정말로 합선시키는 것은 위험할 수 있어서, 알려진 부하를 달고 전압이 얼마나 내려가는지로 구하기도 합니다.

**(나)** 등가 회로에서는 그냥 전압 나누기입니다. 3kΩ이면 6.462 × 3/(3 + 0.769) = **5.143V**로, 문제 5에서 구한 V_B와 같습니다.

## 코드로 확인

```python
import numpy as np

R1, R2, R3, R5 = 2e3, 4e3, 2e3, 1e3
V1, V2 = 12.0, 6.0

def solve_ab(r_load):
    """B에 부하 r_load(None이면 떼어 냄)를 달고 마디 A, B를 푼다."""
    g_load = 0.0 if r_load is None else 1 / r_load
    G = np.array([[1/R1 + 1/R2 + 1/R3, -1/R3],
                  [-1/R3, 1/R3 + 1/R5 + g_load]])
    I = np.array([V1 / R1, V2 / R5])
    return np.linalg.solve(G, I)

# 1) 열린 전압: 부하를 떼고 B의 전압
v_th = solve_ab(None)[1]
# 2) 짧은 회로 전류: B를 땅에 바로 이으면 B로 들어오는 전류
va = (V1 / R1) / (1/R1 + 1/R2 + 1/R3)        # B = 0V일 때 마디 A
i_sc = va / R3 + V2 / R5
r_th = v_th / i_sc
print(f"V_th {v_th:.4f}V, I_sc {i_sc * 1e3:.4f}mA, R_th {r_th:.1f}Ω")

# 3) 전원을 끄고 본 저항으로도 같은가
def par(a, b):
    return a * b / (a + b)
print(f"전원을 끄고 본 저항 {par(R5, R3 + par(R1, R2)):.1f}Ω")

# 4) 등가 회로 하나로 여러 부하를 한 번에
for rl in (3e3, 1e3, 10e3):
    v_eq = v_th * rl / (r_th + rl)
    v_full = solve_ab(rl)[1]
    print(f"부하 {rl / 1e3:>4.0f}kΩ: 등가 회로 {v_eq:.4f}V, "
          f"원래 회로 {v_full:.4f}V")
```

```text
V_th 6.4615V, I_sc 8.4000mA, R_th 769.2Ω
전원을 끄고 본 저항 769.2Ω
부하    3kΩ: 등가 회로 5.1429V, 원래 회로 5.1429V
부하    1kΩ: 등가 회로 3.6522V, 원래 회로 3.6522V
부하   10kΩ: 등가 회로 6.0000V, 원래 회로 6.0000V
```

어떤 부하를 달아도 등가 회로와 원래 회로의 답이 같습니다. 한 번 V_th와 R_th를 구해 두면, 부하가 바뀔 때마다 전압 나누기 한 번이면 됩니다.

<Note>
같은 회로를 **전류원 하나와 저항 하나가 나란히 있는** 꼴로도 바꿀 수 있는데, 이것이 **노턴 등가 회로**입니다. 전류원은 I_sc = 8.4mA, 저항은 같은 R_th입니다. 테브난과 노턴은 서로 바꿔 쓸 수 있고, [「문제 5」](#/read/ee-intro/dc-problem-5)에서 전압원+저항을 전류원으로 바꿔 행렬에 찍은 것이 바로 이 변환이었습니다. 다음 [「문제 8」](#/read/ee-intro/dc-problem-8)에서는 이 등가 회로로 부하가 가장 많은 전력을 받는 조건을 찾습니다.
</Note>

## 정리

- 두 단자에서 본 선형 회로는 테브난 전압 V_th(열린 전압)와 테브난 저항 R_th의 직렬 회로로 바꿀 수 있다
- R_th는 전원을 끄고(전압원은 도선, 전류원은 끊김) 본 저항이거나, V_th를 짧은 회로 전류 I_sc로 나눈 값이다
- 등가 회로를 한 번 구해 두면 부하가 바뀔 때마다 전압 나누기 한 번으로 답이 나오며, 같은 회로를 노턴 꼴로도 쓸 수 있다
