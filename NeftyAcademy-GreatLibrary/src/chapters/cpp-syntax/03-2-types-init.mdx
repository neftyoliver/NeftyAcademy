C++에는 초기화를 적는 방법이 여럿 있습니다. 역사가 쌓인 결과이고, C++11이 "어디서나 통하는 하나"로 중괄호를 더했습니다.

## 네 가지 모양

```cpp nocheck
int a = 1;      // 복사 초기화 (C에서 온 모양)
int b(2);       // 직접 초기화
int c{3};       // 중괄호 초기화 (C++11)
int d = {4};    // 중괄호 + =
```

`int` 하나에서는 넷이 같은 일을 합니다. 차이는 다음 두 가지에서 납니다.

## 좁아지는 변환을 막는다

```cpp nocheck
int x = 3.7;        // 된다. 조용히 3이 된다
int y{3.7};         // 오류: double에서 int로 좁아진다
char c{300};        // 오류: 300은 char에 들어가지 않는다
unsigned u{-1};     // 오류
```

값을 잃을 수 있는 변환을 **좁아지는 변환**이라 하고, 중괄호 초기화는 이것을 컴파일 오류로 만듭니다. C에서 흔하던 실수 한 갈래가 사라집니다.

## 빈 중괄호는 0

```cpp
#include <print>
#include <string>
#include <vector>

struct config {
    int baud = 115200;      // 기본 멤버 초기화
    bool parity{};          // false
    std::string port;       // 빈 문자열
};

int main()
{
    int a{};                            // 0
    double ratio{0.5};
    config c1;                          // 전부 기본값
    config c2{.baud = 9600, .port = "/dev/ttyAMA0"};    // C++20 지정 초기화

    std::vector<int> x(3, 7);           // 7이 3개
    std::vector<int> y{3, 7};           // 3과 7

    std::println("{} {}", a, ratio);
    std::println("{} {} [{}]", c1.baud, c1.parity, c1.port);
    std::println("{} {} [{}]", c2.baud, c2.parity, c2.port);
    std::println("{} {}", x.size(), y.size());
}
```

```text
0 0.5
115200 false []
9600 false [/dev/ttyAMA0]
3 2
```

`int a;`처럼 아무것도 적지 않은 지역 변수에는 쓰레기 값이 들어 있고, `int a{};`는 0입니다. 포인터는 `nullptr`, `bool`은 `false`가 됩니다. **초기값이 딱히 없으면 `{}`를 붙이는 습관**을 들이세요.

구조체의 멤버 옆에 적은 `= 115200`은 기본 멤버 초기화입니다. 초기화할 때 그 멤버를 건너뛰면 이 값이 들어갑니다.

## 지정 초기화

`config c2{.baud = 9600, .port = "/dev/ttyAMA0"};`는 C의 지정 초기화와 같은 문법이고 C++20에서 들어왔습니다. C보다 규칙이 빡빡합니다.

| | C | C++20 |
| --- | --- | --- |
| 순서 | 자유 | 선언한 순서대로만 (건너뛰는 것은 된다) |
| 배열 `[3] = 1` | 된다 | 안 된다 |
| 중첩 `.a.b = 1` | 된다 | 안 된다 (`.a = {.b = 1}`로 쓴다) |

## 괄호와 중괄호가 갈리는 곳

위 예제의 `x(3, 7)`과 `y{3, 7}`이 그 경우입니다. 중괄호를 쓰면 컴파일러는 "값의 목록을 받는 생성자"를 가장 먼저 찾습니다. `std::vector`에는 그런 생성자가 있어서 `{3, 7}`은 원소 두 개가 됩니다.

| 코드 | 결과 |
| --- | --- |
| `std::vector<int> v(3, 7);` | `7, 7, 7` |
| `std::vector<int> v{3, 7};` | `3, 7` |
| `std::vector<int> v(3);` | `0, 0, 0` |
| `std::vector<int> v{3};` | `3` |
| `std::string s(3, 'a');` | `"aaa"` |

컨테이너에서 "개수"를 줄 때는 괄호, "내용"을 줄 때는 중괄호라고 기억하면 됩니다.

## 함수 선언으로 읽히는 초기화

```cpp nocheck
Timer t();      // Timer를 돌려주는 함수 t의 선언으로 읽힌다
Timer t{};      // Timer 객체
Timer t;        // Timer 객체
```

괄호만 있는 초기화는 함수 선언과 모양이 같아서, C++은 함수 선언 쪽으로 읽습니다. 중괄호를 쓰면 이 문제가 없습니다.

<Note kind="tip">
이 책의 습관: 단순한 값은 `int n = 0;`, 구조체와 목록은 `{}`, 컨테이너의 개수 지정은 `()`. 팀마다 규칙이 다르지만 "초기화하지 않은 변수를 두지 않는다"는 것은 어디서나 같습니다.
</Note>

## 정리

- 중괄호 초기화는 어디서나 쓸 수 있고, 좁아지는 변환을 오류로 만든다
- `{}`는 0, `nullptr`, `false`. 초기화 안 한 지역 변수는 쓰레기 값
- 컨테이너에서는 `(개수, 값)`과 `{내용}`이 다르다
