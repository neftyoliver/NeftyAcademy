C에는 이름을 묶는 방법이 없어서 `gpio_set`, `sensor_read`처럼 접두어를 붙였습니다. C++의 네임스페이스는 그 접두어를 문법으로 만든 것입니다. `std::`가 그 예입니다.

## 만들고 쓰기

```cpp
#include <print>
#include <string>

namespace sensor {

int count = 0;

std::string label(int id) { return "sensor-" + std::to_string(id); }

namespace detail {      // 안쪽 네임스페이스
int next_id() { return ++count; }
}

}   // namespace sensor

namespace {             // 이름 없는 네임스페이스: 이 파일 안에서만 보인다
void note(const std::string& s) { std::println("[note] {}", s); }
}

int main()
{
    int id = sensor::detail::next_id();
    note(sensor::label(id));

    using sensor::label;            // 이 이름 하나만 꺼내 온다
    note(label(sensor::detail::next_id()));

    namespace sd = sensor::detail;  // 긴 이름에 별명
    std::println("{}", sd::next_id());
}
```

```text
[note] sensor-1
[note] sensor-2
3
```

- `namespace 이름 { … }` 안에서 선언한 것은 바깥에서 `이름::`을 붙여 부른다
- 같은 네임스페이스를 여러 파일에서 다시 열어 내용을 더할 수 있다
- `namespace a::b::c { … }`로 여러 겹을 한 번에 열 수 있다 (C++17)
- 네임스페이스 안에서는 같은 네임스페이스의 이름을 접두어 없이 쓴다

## using의 두 가지

| 문법 | 이름 | 하는 일 |
| --- | --- | --- |
| `using sensor::label;` | using 선언 | 이름 **하나**를 지금 범위로 가져온다 |
| `using namespace sensor;` | using 지시 | 그 네임스페이스의 이름을 **전부** 보이게 한다 |
| `namespace sd = sensor::detail;` | 별명 | 긴 이름을 줄인다 |

`using namespace std;`는 예제에서 흔히 보이지만 실제 코드에서는 피합니다. `std` 안에는 이름이 수천 개 있고, 표준이 바뀔 때마다 늘어납니다. 내가 만든 `count`, `distance`, `size`, `data`가 어느 날 표준의 이름과 부딪힙니다.

| 어디서 | `using namespace` |
| --- | --- |
| 헤더 파일의 전역 | **쓰지 않는다.** 포함한 모든 파일에 번진다 |
| `.cpp` 파일의 전역 | 되도록 쓰지 않는다 |
| 함수 안 | 괜찮다. 그 함수에만 영향이 있다 |
| 리터럴 접미어 (`std::chrono_literals`) | 괜찮다. 접미어만 들어 있다 |

`std::`를 적는 것은 다섯 글자의 수고이고, 읽는 사람에게는 "이것은 표준 라이브러리의 것"이라는 정보입니다.

## 이름 없는 네임스페이스

```cpp nocheck
namespace {
int retry_count = 0;
void backoff();
struct state { … };
}
```

이름을 적지 않은 네임스페이스 안의 것들은 **그 번역 단위 안에서만** 보입니다. C에서 파일 범위의 `static`이 하던 일입니다. 함수와 변수뿐 아니라 타입에도 통한다는 점이 다릅니다. `.cpp` 파일 안에서만 쓰는 도우미는 모두 여기에 넣습니다. 다른 파일의 같은 이름과 부딪히지 않고, [ODR 위반](#/read/cpp-syntax/fn-inline)도 생기지 않습니다.

헤더에는 이름 없는 네임스페이스를 쓰지 않습니다. 포함한 파일마다 따로 복사본이 생깁니다.

## 이름을 찾는 순서

컴파일러는 이름을 **안쪽 범위에서 바깥쪽으로** 찾아 나가고, 처음 찾은 곳에서 멈춥니다.

```cpp
#include <print>

int value = 1;

namespace outer {
int value = 2;

namespace inner {
int value = 3;

void show()
{
    int value = 4;
    std::println("{} {} {} {}", value, inner::value, outer::value, ::value);
}
}   // namespace inner
}   // namespace outer

int main() { outer::inner::show(); }
```

```text
4 3 2 1
```

앞에 아무것도 없는 `::value`는 전역 네임스페이스의 것입니다. 안쪽의 이름이 바깥의 같은 이름을 가리는 것을 "숨긴다"고 합니다.

<Note>
라이브러리를 만들 때는 모든 것을 자기 네임스페이스 하나에 넣는 것이 예의입니다. 밖으로 내놓지 않을 것은 그 안의 `detail` 네임스페이스에 두는 관습이 있습니다. "여기는 들여다보지 마세요"라는 뜻입니다.
</Note>
