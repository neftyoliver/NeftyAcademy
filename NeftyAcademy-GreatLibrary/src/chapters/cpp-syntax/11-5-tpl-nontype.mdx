템플릿의 빈칸에는 타입뿐 아니라 **값**도 올 수 있습니다. `std::array<int, 4>`의 `4`가 그것입니다. 값은 컴파일할 때 정해져 타입의 일부가 됩니다.

## 크기가 타입에 든 버퍼

```cpp
#include <array>
#include <cstddef>
#include <print>

template <typename T, std::size_t N>
class RingBuffer {
public:
    void push(const T& value)
    {
        items_[head_] = value;
        head_ = (head_ + 1) % N;
        if (size_ < N)
            ++size_;
    }
    std::size_t size() const { return size_; }
    constexpr std::size_t capacity() const { return N; }
    const T& newest() const { return items_[(head_ + N - 1) % N]; }

private:
    std::array<T, N> items_{};
    std::size_t head_ = 0;
    std::size_t size_ = 0;
};

template <typename T, std::size_t N>
std::size_t length(const T (&)[N]) { return N; }    // 배열의 길이를 추론한다

int main()
{
    RingBuffer<int, 4> recent;
    for (int i = 1; i <= 6; ++i)
        recent.push(i * 10);

    std::println("{} / {}", recent.size(), recent.capacity());
    std::println("{}", recent.newest());
    std::println("{}", sizeof(recent));

    int pins[] = {17, 27, 22};
    std::println("{}", length(pins));
}
```

```text
4 / 4
60
32
3
```

`RingBuffer<int, 4>`는 `int` 네 개(16바이트)와 `size_t` 두 개(16바이트)가 전부입니다. 힙을 쓰지 않고, 통째로 스택이나 전역에 놓입니다.

- `N`은 컴파일할 때의 상수다. `% N`은 `N`이 2의 거듭제곱이면 컴파일러가 비트 연산으로 바꾼다
- `RingBuffer<int, 4>`와 `RingBuffer<int, 8>`은 **다른 타입**이다. 서로 대입되지 않는다
- 인자는 상수식이어야 한다. 실행 중에 정해지는 값은 넣을 수 없다

메모리 할당이 실패해서는 안 되거나 할당 시간이 들쭉날쭉하면 안 되는 곳(인터럽트 처리, 실시간 루프)에서 이런 고정 크기 컨테이너가 쓰입니다. 표준에는 `std::array`가 있고, C++26에 `std::inplace_vector`가 [들어옵니다](#/read/cpp-syntax/ver-26).

## 배열 길이 추론

`length`의 매개변수 `const T (&)[N]`은 "원소가 `T`이고 길이가 `N`인 배열의 참조"입니다. 배열을 넘기면 `T`와 `N`이 함께 [추론](#/read/cpp-syntax/tpl-deduction)됩니다. C의 `sizeof(a) / sizeof(a[0])`와 달리 포인터를 넘기면 **컴파일 오류**가 나서 실수할 수 없습니다. 표준의 `std::size(배열)`이 이렇게 만들어져 있습니다.

## 무엇이 올 수 있나

| 종류 | 예 | 비고 |
| --- | --- | --- |
| 정수, `bool`, `char`, 열거형 | `template <int Pin>`, `template <bool Fast>` | 가장 흔하다 |
| 포인터와 참조 | `template <void (*Handler)()>` | 전역 객체나 함수의 주소여야 한다 |
| 부동소수점 | `template <double Scale>` | C++20부터 |
| 단순한 클래스 타입 | `template <Config C>` | C++20부터. 모든 멤버가 `public`이고 위 종류로만 이루어진 타입 |
| `auto` | `template <auto Value>` | C++17부터. 값의 타입까지 추론한다 |

문자열 리터럴은 직접 넘길 수 없습니다(`Tag<"led">`는 오류). 글자 배열을 멤버로 가진 클래스 타입에 담아 넘기는 우회가 쓰입니다.

## 핀 번호를 타입에

```cpp
#include <print>

template <int Pin>
struct Led {
    static void on() { std::println("pin {} H", Pin); }
};

using StatusLed = Led<17>;
using ErrorLed = Led<27>;

int main()
{
    StatusLed::on();
    ErrorLed::on();
}
```

```text
pin 17 H
pin 27 H
```

핀 번호가 변수에 저장되지 않고 **코드에 박힙니다.** 객체가 차지하는 메모리가 없고, 컴파일러는 `Pin`을 상수로 보고 최적화합니다. 마이크로컨트롤러용 C++ 라이브러리들이 레지스터 주소와 핀 번호를 이렇게 다룹니다. 대가는 핀마다 코드가 따로 찍혀 나온다는 것, 그리고 핀 번호를 실행 중에 바꿀 수 없다는 것입니다.

<Note>
값이 컴파일할 때 정해지므로 검사도 컴파일할 때 할 수 있습니다. `template <int Pin> requires (Pin >= 0 && Pin <= 27)`이라고 적으면 `Led<40>`은 컴파일되지 않습니다. [콘셉트와 제약](#/read/cpp-syntax/con-requires)에서 봅니다.
</Note>

## 정리

- 템플릿 인자로 정수 같은 값을 받을 수 있다. 값은 타입의 일부가 된다
- 크기를 인자로 받으면 힙 없는 고정 크기 컨테이너를 만들 수 있다 (`std::array`)
- 값이 다르면 다른 타입이고, 코드도 따로 찍힌다
