멤버 함수는 "어느 객체에 대해 불렸는가"를 숨은 인자로 받습니다. 그 인자의 이름이 `this`이고, 함수 끝에 붙는 `const`는 그 인자의 타입을 바꿉니다.

## this와 const 멤버 함수

```cpp
#include <print>
#include <string>
#include <vector>

class Log {
public:
    Log& add(std::string line)          // 고친다 → const 아님
    {
        lines_.push_back(std::move(line));
        return *this;                   // 자기 자신을 돌려줘서 이어 부를 수 있게
    }
    std::size_t size() const            // 읽기만 → const
    {
        ++reads_;                       // mutable 멤버는 const 함수에서도 고친다
        return lines_.size();
    }
    const std::string& at(std::size_t i) const { return lines_[i]; }
    std::string& at(std::size_t i) { return lines_[i]; }
    int reads() const { return reads_; }

private:
    std::vector<std::string> lines_;
    mutable int reads_ = 0;
};

void report(const Log& log)             // const 참조로는 const 함수만 부를 수 있다
{
    std::println("{}줄, 첫 줄 {}", log.size(), log.at(0));
}

int main()
{
    Log log;
    log.add("boot").add("ready");
    log.at(0) += "!";                   // const 아닌 at
    report(log);
    std::println("{}", log.reads());
}
```

```text
2줄, 첫 줄 boot!
1
```

## this

`this`는 그 함수가 불린 객체를 가리키는 포인터입니다. 멤버 이름 `lines_`는 `this->lines_`의 줄임말입니다. 직접 적을 일은 많지 않고, 주로 두 가지에 씁니다.

| 쓰임 | 예 |
| --- | --- |
| 자기 자신을 돌려주기 | `return *this;` (`add`를 이어 부르기, 대입 연산자) |
| 자기 주소를 넘기기 | `registry.attach(this);` |

## const 멤버 함수

함수 선언 뒤의 `const`는 "이 함수는 객체를 고치지 않는다"는 약속입니다.

| | `this`의 타입 | 멤버를 고칠 수 있나 | `const` 객체에서 부를 수 있나 |
| --- | --- | --- | --- |
| `void add(…)` | `Log*` | 있다 | 없다 |
| `std::size_t size() const` | `const Log*` | 없다 | 있다 |

[「const 참조와 임시 객체」](#/read/cpp-syntax/ref-const)에서 인자를 `const Log&`로 받으라고 했습니다. 그렇게 받은 객체에서는 `const` 멤버 함수만 부를 수 있습니다. 그래서 **고치지 않는 멤버 함수에는 빠짐없이 `const`를 붙여야** 합니다. 하나라도 빠뜨리면 그 함수를 부르는 모든 곳이 `const&`를 쓸 수 없게 되고, 그 영향이 위로 번집니다.

`const` 함수 안에서는 멤버들도 `const`로 보입니다. `lines_.push_back(…)`을 부르면 컴파일 오류입니다.

## const로 오버로드하기

`at`은 두 벌입니다. 객체가 `const`면 첫째가, 아니면 둘째가 불립니다.

```cpp nocheck
const std::string& at(std::size_t i) const;   // 읽기용: 고칠 수 없는 참조를 준다
std::string& at(std::size_t i);               // 쓰기용: 고칠 수 있는 참조를 준다
```

안의 것을 꺼내 주는 함수가 `const` 함수인데 고칠 수 있는 참조를 돌려준다면, `const` 객체의 속을 고칠 길이 열립니다. 그래서 "`const` 객체에는 `const` 참조를"이 짝을 이룹니다. `std::vector`의 `operator[]`, `front()`, `data()`가 모두 이렇게 두 벌입니다.

## mutable

`mutable` 멤버는 `const` 함수 안에서도 고칠 수 있습니다. 밖에서 보기에 객체의 상태가 달라지지 않는 것에만 씁니다.

| 쓸 만한 곳 | 까닭 |
| --- | --- |
| 계산 결과의 캐시 | 처음 물을 때 계산해 두지만, 답은 언제나 같다 |
| 뮤텍스 | 읽기 함수도 잠가야 하는데, 잠그는 것은 뮤텍스를 고치는 일이다 |
| 통계, 디버그용 카운터 | 위 예제의 `reads_` |

"비트 하나 안 바뀐다"가 아니라 "쓰는 쪽에서 관찰할 수 있는 상태가 안 바뀐다"가 `const`의 뜻입니다.

<Note>
C++23에는 `this`를 인자 목록에 드러내 적는 문법이 생겼습니다. `auto& at(this auto& self, std::size_t i) { return self.lines_[i]; }` 한 줄이 `const` 판과 아닌 판을 모두 대신합니다. [「재귀 람다와 명시적 this」](#/read/cpp-syntax/lam-recursive)에서 봅니다.
</Note>

## 정리

- `this`는 함수가 불린 객체의 주소. `return *this;`로 이어 부르기를 만든다
- 고치지 않는 멤버 함수에는 반드시 `const`. 그래야 `const&`로 받은 객체에서 부를 수 있다
- `mutable`은 겉으로 드러나지 않는 상태(캐시, 뮤텍스)에만
