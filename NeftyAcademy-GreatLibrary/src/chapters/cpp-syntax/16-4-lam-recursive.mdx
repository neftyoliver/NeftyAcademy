export const summary = '자기 자신을 부르는 람다, this를 매개변수로 드러내기, const 판 중복과 CRTP를 대신하기';

람다에는 이름이 없습니다. 그래서 람다 안에서 **자기 자신을 부를 방법**이 없었습니다. C++23의 "명시적 `this`"가 그것을 풀었고, 덤으로 클래스의 오래된 불편 두 가지도 함께 풀었습니다.

## 예제

```cpp
#include <cstddef>
#include <print>
#include <string>
#include <utility>
#include <vector>

struct Node {
    std::string name;
    std::vector<Node> children;
};

class Lines {
public:
    // const 판과 아닌 판을 한 번에. self의 타입이 부른 객체를 따라간다
    auto& at(this auto& self, std::size_t i) { return self.lines_[i]; }
    void add(std::string line) { lines_.push_back(std::move(line)); }

private:
    std::vector<std::string> lines_;
};

int main()
{
    auto factorial = [](this auto self, int n) -> int {
        return n <= 1 ? 1 : n * self(n - 1);
    };
    std::println("{}", factorial(5));

    Node root{"/", {{"dev", {{"gpiochip0", {}}, {"i2c-1", {}}}}, {"sys", {}}}};
    auto print_tree = [](this const auto& self, const Node& node, int depth)
        -> void {
        std::println("{:{}}{}", "", depth * 2, node.name);
        for (const Node& child : node.children)
            self(child, depth + 1);
    };
    print_tree(root, 0);

    Lines lines;
    lines.add("first");
    lines.at(0) += "!";                 // self는 Lines&
    const Lines& view = lines;
    std::println("{}", view.at(0));     // self는 const Lines&
}
```

```text
120
/
  dev
    gpiochip0
    i2c-1
  sys
first!
```

## 명시적 this

멤버 함수에는 [숨은 인자 `this`](#/read/cpp-syntax/class-const)가 있습니다. C++23부터는 첫 매개변수 앞에 `this`를 적어 그것을 **드러낼** 수 있습니다.

```cpp nocheck
struct Pin {
    int number;
    int twice_old() const { return number * 2; }              // 숨은 this
    int twice_new(this const Pin& self) { return self.number * 2; }   // 드러낸 this
};
```

- 부르는 법은 같다: `pin.twice_new()`. `pin`이 `self`로 들어간다
- 함수 안에 `this`가 없다. 멤버는 반드시 `self.`를 거쳐 쓴다
- 뒤에 `const`를 붙이지 않는다. `self`의 타입이 그 일을 한다
- `self`는 이름일 뿐이다. 관례로 그렇게 부른다

요점은 `self`가 **보통의 매개변수**라는 것입니다. 그래서 `auto`가 될 수 있고, 값으로 받을 수도 있고, 람다에서도 쓸 수 있습니다. GCC 14, Clang 18부터 지원합니다.

## 재귀 람다

`this auto self`의 `self`는 람다 객체 **자신**입니다. `self(…)`로 자기를 부릅니다.

그 전에는 이렇게 했습니다.

| 옛 방법 | 문제 |
| --- | --- |
| `std::function<int(int)> f = [&f](int n) { … f(n - 1) … };` | [간접 호출과 힙 할당](#/read/cpp-syntax/lam-function). `f`를 참조로 캡처해서 복사하면 깨진다 |
| `auto f = [](auto& self, int n) { … self(self, n - 1) … };` 그리고 `f(f, 5)` | 부를 때마다 자기를 인자로 넘겨야 한다 |

반환 타입을 `-> int`로 적은 것은 필요해서입니다. 재귀 호출 `self(n - 1)`의 타입을 알려면 반환 타입이 먼저 정해져 있어야 하는데, `auto` 추론은 본문을 다 봐야 끝나기 때문입니다.

`this auto self`(값)와 `this const auto& self`(참조)의 차이는 람다가 캡처를 품고 있을 때 드러납니다. 값이면 재귀할 때마다 람다 객체가 복사됩니다. 캡처가 있으면 참조로 받습니다.

재귀 람다는 트리나 디렉터리를 훑는 짧은 도우미를 **쓰는 자리 바로 옆에** 둘 수 있게 해 줍니다.

## const 판 중복 없애기

`Lines::at`은 원래 둘을 써야 했습니다.

```cpp nocheck
std::string& at(std::size_t i) { return lines_[i]; }
const std::string& at(std::size_t i) const { return lines_[i]; }
```

`this auto& self`에서 `self`의 타입은 [추론](#/read/cpp-syntax/tpl-deduction)됩니다. `Lines` 객체로 부르면 `Lines&`, `const Lines`로 부르면 `const Lines&`입니다. 반환 타입 `auto&`가 그것을 따라가서 한 함수가 두 판을 대신합니다.

우측값까지 구별하려면 [전달 참조](#/read/cpp-syntax/tpl-deduction)로 받습니다.

```cpp nocheck
template <typename Self>
auto&& value(this Self&& self) { return std::forward<Self>(self).value_; }
// 임시 객체에서 부르면 멤버를 옮겨 내준다. & / const& / && 세 판이 하나로
```

## CRTP 대신

부모의 함수가 **자식의 타입**을 알아야 할 때가 있습니다. 예전에는 부모를 템플릿으로 만들고 자식이 자기 자신을 인자로 넘기는 [CRTP](#/read/cpp-syntax/tpl-class)를 썼습니다. 명시적 `this`로는 템플릿 없는 부모 하나면 됩니다.

```cpp nocheck
struct Describable {
    void describe(this const auto& self)        // self는 실제(자식) 타입이다
    {
        std::println("{} (pin {})", self.name(), self.pin());
    }
};

struct Led : Describable {
    std::string name() const { return "led"; }
    int pin() const { return 17; }
};

Led{}.describe();       // 가상 함수 없이 자식의 name()과 pin()을 부른다
```

`self`의 타입이 부른 객체의 타입(`Led`)으로 추론되므로, 부모에 없는 `name()`을 부를 수 있습니다. [가상 함수](#/read/cpp-syntax/inh-virtual)와 달리 컴파일할 때 정해지고 vptr이 없습니다. 대신 `Describable*`로 가리킨 채 부르면 `self`는 `Describable`이 되어 통하지 않습니다.

## 값으로 받기

`this Self self`처럼 값으로 받으면 호출할 때 객체가 복사(또는 이동)되어 들어옵니다.

| 쓰임 | 까닭 |
| --- | --- |
| 작은 타입(`string_view`, 핀 번호 하나짜리 구조체)의 멤버 함수 | 포인터를 거치지 않고 레지스터로 넘어간다 |
| 설정을 이어 붙이는 빌더 `Config{}.with_baud(9600).with_parity(…)` | 임시 객체가 단계마다 옮겨지며 흘러간다 |

<Note>
명시적 `this`를 쓴 함수는 `virtual`이 될 수 없고, `static`과 함께 쓸 수 없습니다. 주소를 얻으면 멤버 함수 포인터가 아니라 **보통 함수 포인터**가 나옵니다(`&Pin::twice_new`의 타입은 `int (*)(const Pin&)`).
</Note>

## 정리

- C++23부터 `this`를 첫 매개변수로 드러내 적을 수 있다: `void f(this auto& self)`
- 람다에서 `[](this auto self, …)`로 받으면 `self(…)`로 자기를 부를 수 있다
- `self`의 타입이 추론되므로 `const` 판 중복과 CRTP를 대신한다
