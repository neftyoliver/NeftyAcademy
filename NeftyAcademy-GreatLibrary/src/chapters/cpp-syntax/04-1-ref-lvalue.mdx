참조는 이미 있는 변수에 붙이는 **다른 이름**입니다. C에서 포인터로 하던 일 가운데 "저 변수를 직접 다루게 해 달라"는 부분을 문법으로 떼어 낸 것입니다.

## 다른 이름

```cpp
#include <print>
#include <string>

void add_suffix(std::string& s) { s += "!"; }       // 부른 쪽의 변수를 고친다

void swap_values(int& a, int& b)
{
    int t = a;
    a = b;
    b = t;
}

int main()
{
    int x = 1;
    int& r = x;         // r은 x의 다른 이름
    r = 10;
    std::println("{} {} {}", x, r, &x == &r);

    int y = 2;
    swap_values(x, y);  // 부르는 쪽에 &가 없다
    std::println("{} {}", x, y);

    std::string msg = "hi";
    add_suffix(msg);
    std::println("{}", msg);
}
```

```text
10 10 true
2 10
hi!
```

`int& r = x;` 뒤로 `r`과 `x`는 같은 칸의 두 이름입니다. 주소도 같습니다. 선언문의 `&`는 "주소 구하기"가 아니라 "참조 타입"이라는 표시입니다. `*`가 선언문과 사용문에서 뜻이 달랐던 것과 같은 사정입니다([「선언문에서의 *」](#/read/c-basic/ptr-declaration)).

## 포인터와 나란히 놓으면

| | 포인터 | 참조 |
| --- | --- | --- |
| 선언 | `int* p = &x;` | `int& r = x;` |
| 값 쓰기 | `*p = 10;` | `r = 10;` |
| 멤버 | `p->name` | `r.name` |
| 초기화 없이 | 된다 | 안 된다. 선언할 때 반드시 묶는다 |
| 아무것도 안 가리킴 | `nullptr` | 없다 |
| 다른 것을 가리키게 | `p = &y;` | 안 된다. `r = y;`는 **값을 대입**한다 |
| 산술 | `p + 1` | 없다 |

기계어로 내려가면 참조는 포인터와 똑같이 주소 하나로 구현됩니다. 달라지는 것은 컴파일러가 지켜 주는 약속입니다. 참조는 반드시 무언가에 묶여 있고, 평생 그것만 가리킵니다.

```cpp nocheck
int a = 1, b = 2;
int& r = a;
r = b;          // r이 b를 가리키게 되는 것이 아니다. a에 2가 들어간다
```

## 인자로 넘기기

C에서 함수가 부른 쪽의 변수를 고치려면 주소를 넘겼습니다([「사용문에서의 * 와 &」](#/read/c-basic/ptr-usage)).

```cpp nocheck
void reset(int* v) { *v = 0; }      // C의 방식. 부를 때 reset(&n);
void reset(int& v) { v = 0; }       // 참조. 부를 때 reset(n);
```

참조로 받으면 함수 안에서 `*`를 쓸 일이 없고, 널 검사도 필요 없습니다. 대신 부르는 자리만 봐서는 `n`이 바뀌는지 알 수 없습니다. 그래서 요즘은 이렇게 나눕니다.

- 결과는 **반환값**으로 돌려준다 (`int next = increment(n);`)
- 큰 것을 읽기만 할 때는 `const` 참조 ([다음 챕터](#/read/cpp-syntax/ref-const))
- 받은 것을 고쳐야 할 때만 `&`. 함수 이름에서 고친다는 것이 드러나게 짓는다

## 좌측값이라는 말

참조에는 두 종류가 있고, 지금까지 본 `T&`의 정식 이름은 **좌측값 참조**입니다. 좌측값(lvalue)은 대략 "이름이 있고 주소를 물을 수 있는 것"입니다. 변수, 배열의 칸, 구조체의 멤버가 그렇습니다. `5`나 `a + b`처럼 계산하고 나면 사라지는 값은 우측값입니다.

```cpp nocheck
int& r1 = x;        // 된다
int& r2 = 5;        // 오류: 사라질 값에 고칠 수 있는 이름을 붙일 수 없다
int& r3 = x + 1;    // 오류
```

우측값에 붙이는 참조 `T&&`는 [「우측값 참조」](#/read/cpp-syntax/sm-rvalue)에서 다룹니다.

## 범위 기반 for의 참조

```cpp nocheck
for (auto& name : names)        // 각 칸의 다른 이름
    name += ".local";
```

[「vector와 범위 기반 for」](#/read/cpp-syntax/ft-vector)에서 쓴 `auto&`가 이것입니다. `name`은 돌 때마다 다음 칸에 새로 묶이는 참조입니다.

<Note>
`int& r`, `int &r`, `int & r`은 모두 같은 선언입니다. 이 책은 타입 쪽에 붙여 `int& r`로 씁니다. 한 줄에 여러 개를 선언하면 `int& a, b;`에서 `b`는 참조가 아니라 `int`가 되므로, 한 줄에 하나씩 선언합니다.
</Note>

## 정리

- 참조는 다른 이름. 선언할 때 묶이고 다시 묶을 수 없다
- 인자를 `T&`로 받으면 부른 쪽의 변수를 직접 고친다
- 구현은 포인터와 같고, 널이 없다는 약속이 더해진 것
