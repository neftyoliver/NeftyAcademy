`10`이 10밀리초인지 10초인지는 숫자만 봐서는 알 수 없습니다. C++은 리터럴 뒤에 접미어를 붙여 타입을 만드는 길을 열어 두었고, 표준 라이브러리가 먼저 그것을 씁니다.

## 표준 라이브러리의 접미어

```cpp
#include <chrono>
#include <print>
#include <string>
#include <thread>

using namespace std::chrono_literals;
using namespace std::string_literals;

struct millivolt {
    long long value;
};
constexpr millivolt operator""_mV(unsigned long long v)
{
    return {static_cast<long long>(v)};
}
constexpr millivolt operator""_V(unsigned long long v)
{
    return {static_cast<long long>(v) * 1000};
}

int main()
{
    auto s = "abc"s + "def";            // std::string. 그래서 +가 된다
    auto timeout = 1500ms;              // std::chrono::milliseconds
    std::println("{} {}", s, timeout);
    std::println("{}", std::chrono::duration_cast<std::chrono::seconds>(timeout));

    millivolt a = 3300_mV;
    millivolt b = 5_V;
    std::println("{} {}", a.value, b.value);

    std::this_thread::sleep_for(10ms);  // 단위를 틀릴 수 없다
}
```

```text
abcdef 1500ms
1s
3300 5000
```

| 접미어 | 타입 | 켜는 법 |
| --- | --- | --- |
| `"…"s` | `std::string` | `using namespace std::string_literals;` |
| `"…"sv` | `std::string_view` | `using namespace std::string_view_literals;` |
| `10ns`, `10us`, `10ms`, `10s`, `10min`, `10h` | `std::chrono`의 시간 | `using namespace std::chrono_literals;` |
| `2i` | `std::complex<double>` | `using namespace std::complex_literals;` |

`"abc" + "def"`는 포인터 둘의 덧셈이라 오류지만, `"abc"s + "def"`는 `std::string`의 `+`입니다.

`std::this_thread::sleep_for(10ms)`는 `usleep(10000)`과 달리 단위가 타입에 들어 있습니다. `sleep_for(10)`은 컴파일되지 않습니다. 초와 밀리초를 섞어 더해도 알아서 맞춰 줍니다(`1s + 500ms`는 `1500ms`).

## 나만의 접미어

위의 `operator""_mV`가 **사용자 정의 리터럴**입니다. `3300_mV`라고 쓰면 컴파일러가 `operator""_mV(3300)`을 부릅니다.

| 리터럴의 모양 | 연산자가 받는 인자 |
| --- | --- |
| 정수 `10_x` | `unsigned long long` |
| 실수 `1.5_x` | `long double` |
| 문자열 `"ab"_x` | `const char*`, `std::size_t` |
| 글자 `'a'_x` | `char` |

직접 만드는 접미어는 **밑줄로 시작**해야 합니다. 밑줄 없는 이름은 표준 라이브러리의 몫입니다.

## 단위를 타입으로

접미어 자체보다 중요한 것은 그것이 만드는 타입입니다. `millivolt`와 `milliamp`를 서로 다른 타입으로 만들면 둘을 더하는 실수가 컴파일 오류가 됩니다.

```cpp nocheck
struct millivolt { long long value; };
struct milliamp { long long value; };

void set_limit(milliamp limit);

set_limit(500_mA);      // 된다
set_limit(3300_mV);     // 오류: millivolt는 milliamp가 아니다
set_limit(500);         // 오류: 단위가 없다
```

센서 값과 물리량을 다루는 코드에서 단위 실수는 흔하고 찾기 어렵습니다. 타입으로 단위를 지키는 방법은 연산자 오버로딩과 템플릿을 배운 뒤에 제대로 만들 수 있고, `std::chrono`가 그 본보기입니다.

<Note kind="warn">
`using namespace std::chrono_literals;`는 접미어만 꺼내 오므로 `.cpp` 파일이나 함수 안에서 써도 괜찮습니다. 헤더 파일의 전역에 쓰는 것은 피하세요. 그 헤더를 포함한 모든 파일에 영향을 줍니다.
</Note>

## 정리

- `"…"s`, `"…"sv`, `10ms` 같은 표준 접미어는 `using namespace std::…_literals;`로 켠다
- `operator""_이름`으로 나만의 접미어를 만든다. 이름은 밑줄로 시작
- 접미어의 쓸모는 숫자에 단위라는 타입을 입히는 데 있다
