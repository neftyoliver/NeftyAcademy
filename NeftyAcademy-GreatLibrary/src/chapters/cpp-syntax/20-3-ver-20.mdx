C++20은 C++11 이후 가장 큰 판입니다. "네 기둥"이라 불리는 콘셉트, 범위, 모듈, 코루틴이 들어왔고, 그 밖에도 매일 쓰는 것이 많습니다. GCC 16부터는 옵션을 주지 않으면 C++20으로 컴파일됩니다.

## 네 기둥

| 기능 | 하는 일 | 본 곳 |
| --- | --- | --- |
| 콘셉트 | 템플릿이 받을 타입의 조건을 서명에 적는다 | [콘셉트와 제약](#/read/cpp-syntax/con-requires) |
| 범위 (`<ranges>`) | 컨테이너를 통째로 넘기는 알고리즘, 게으른 파이프라인 | 아래 예제. STL 책에서 자세히 |
| 모듈 | `#include` 대신 `import` | [C++20 모듈](#/read/cpp-syntax/mod-modules) |
| 코루틴 | 중간에 멈췄다가 이어서 도는 함수 (`co_await`, `co_yield`, `co_return`) | 이 책에서는 다루지 않는다 |

코루틴은 언어 장치만 들어왔고, 그것을 쓰기 쉽게 감싼 라이브러리는 C++23의 `std::generator`부터입니다.

## C++20의 모양

```cpp
#include <algorithm>
#include <compare>
#include <concepts>
#include <format>
#include <numeric>
#include <print>
#include <ranges>
#include <span>
#include <string>
#include <vector>

struct Reading {
    int channel;
    double value;
    auto operator<=>(const Reading&) const = default;   // 비교 여섯 개를 한 줄로
};

template <std::floating_point T>                        // 콘셉트
T average(std::span<const T> values)                    // span
{
    return std::accumulate(values.begin(), values.end(), T{}) / values.size();
}

int main()
{
    std::vector<Reading> readings{
        {.channel = 2, .value = 3.5},                   // 지정 초기화
        {.channel = 1, .value = 9.0},
        {.channel = 3, .value = 1.5},
    };

    std::ranges::sort(readings, {}, &Reading::channel); // 범위 알고리즘과 프로젝션

    auto high = readings
        | std::views::filter([](const Reading& r) { return r.value > 2.0; })
        | std::views::transform(&Reading::channel);     // 게으른 파이프라인
    for (int channel : high)
        std::println("{}", channel);

    std::vector<double> values{3.5, 9.0, 1.5};
    std::string line =
        std::format("{:6.2f}|{:<6}|{:#x}", average<double>(values), "ok", 255);
    std::println("{}", line);
    std::println("{}", Reading{1, 2.0} < Reading{1, 3.0});
}
```

```text
1
2
  4.67|ok    |0xff
true
```

(출력의 `std::println`만 C++23입니다. C++20에서는 `std::cout << std::format(…)`으로 씁니다.)

## 범위

`std::ranges::sort(readings, {}, &Reading::channel)`에는 세 가지가 들어 있습니다.

| 달라진 것 | 옛 방식 | 범위 방식 |
| --- | --- | --- |
| 컨테이너를 통째로 | `std::sort(v.begin(), v.end())` | `std::ranges::sort(v)` |
| 프로젝션 | 비교 람다 안에서 멤버를 꺼낸다 | 셋째 인자로 "무엇을 기준으로"를 준다 |
| 뷰와 파이프 | 중간 결과를 담을 벡터를 만든다 | `v \| filter(…) \| transform(…)`. 복사 없이, 돌 때 계산한다 |

뷰는 원본을 **가리키기만** 합니다. 그래서 원본이 뷰보다 먼저 죽으면 [수명 문제](#/read/cpp-syntax/ubc-lifetime)가 됩니다. 임시 컨테이너에 파이프를 걸면 컴파일러가 막아 주는 경우가 많지만(`std::ranges::dangling`), 뷰를 변수나 멤버로 오래 들고 있지 않는 것이 원칙입니다.

## 컴파일러

| | GCC | Clang |
| --- | --- | --- |
| 콘셉트, `<=>` | 10 | 10 |
| `consteval` | 10 | 17 |
| `<ranges>` | 10 | 16 |
| `<format>` | 13 | 17 |
| 모듈 | 실험적 (11부터, 옵션 필요) | 16 |

GCC는 16부터 옵션 없이 C++20으로 컴파일하고, C++20 지원을 "실험적"에서 뗐습니다. 그 과정에서 표준 라이브러리 일부의 내부 배치가 바뀌었으므로, C++20으로 빌드한 라이브러리를 GCC 15 이하와 16 이상 사이에 섞어 링크할 때는 조심해야 합니다.

<Note>
`<format>`이 컴파일러에 늦게 들어와서, 그 전부터 쓰이던 `{fmt}` 라이브러리가 지금도 널리 쓰입니다. 문법이 같고(`fmt::format`, `fmt::print`) 표준보다 기능이 앞서 있습니다. 표준의 `std::format`과 `std::print`가 이 라이브러리에서 온 것입니다.
</Note>

## 정리

- 네 기둥: 콘셉트, 범위, 모듈, 코루틴
- 매일 쓰는 것: `<=>`, 지정 초기화, `std::format`, `std::span`, `consteval`/`constinit`, `std::erase_if`, `contains`
- GCC 13과 Clang 17이면 거의 다 된다. 모듈만 사정이 다르다
