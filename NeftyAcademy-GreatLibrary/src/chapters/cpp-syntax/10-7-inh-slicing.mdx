자식 객체를 **부모 타입의 값**에 넣으면 부모 부분만 복사되고 자식 부분은 버려집니다. 오류도 경고도 없이 일어나서 객체 잘림(slicing)이라는 이름이 붙었습니다.

## 잘리는 순간

```cpp
#include <print>
#include <string>

struct Shape {
    virtual ~Shape() = default;
    virtual std::string name() const { return "shape"; }
};

struct Circle : Shape {
    double radius = 1.0;
    std::string name() const override { return "circle"; }
};

void by_value(Shape s) { std::println("값: {}", s.name()); }
void by_ref(const Shape& s) { std::println("참조: {}", s.name()); }

int main()
{
    Circle c;
    by_value(c);        // Shape 부분만 복사된다
    by_ref(c);

    Shape copy = c;     // 여기서도 잘린다
    std::println("{}", copy.name());
}
```

```text
값: shape
참조: circle
shape
```

`by_value`의 매개변수 `s`는 `Shape` 크기의 새 객체입니다. `Shape`의 복사 생성자가 `c`의 `Shape` 부분을 복사해 만들었고, `radius`가 들어갈 자리는 처음부터 없습니다. 새 객체는 진짜 `Shape`이므로 vptr도 `Shape`의 표를 가리키고, `name()`은 `"shape"`를 돌려줍니다.

## 잘림이 숨는 곳

| 코드 | 일어나는 일 |
| --- | --- |
| `void f(Shape s)` | 인자가 잘린다 |
| `std::vector<Shape> v; v.push_back(circle);` | 들어가면서 잘린다 |
| `catch (std::exception e)` | 던져진 예외가 잘려 `what()`의 내용을 잃는다 |
| `Shape& a = c1; a = c2;` | `c1`의 `Shape` 부분만 `c2`의 것으로 바뀐다. **반쯤 섞인 객체**가 된다 |
| `Shape s = *ptr;` | 포인터가 가리키던 것이 자식이면 잘린다 |

넷째가 가장 고약합니다. `c1`은 여전히 `Circle`인데 부모 부분과 자식 부분이 서로 다른 객체에서 온 값이 됩니다.

다형적인 객체는 **포인터나 참조로** 다룹니다. 컨테이너에 담을 때는 `std::vector<std::unique_ptr<Shape>>`, 예외는 `catch (const std::exception& e)`입니다.

## 컴파일러가 막게 하기

| 방법 | 효과 |
| --- | --- |
| 부모를 [추상 클래스](#/read/cpp-syntax/inh-abstract)로 만든다 | `Shape` 타입의 값을 만들 수 없으니 `void f(Shape s)`부터 컴파일되지 않는다 |
| 부모의 복사를 [`= delete`](#/read/cpp-syntax/inh-dtor)한다 | 복사하려는 모든 곳이 오류가 된다 |

둘을 함께 쓰는 것이 흔합니다. "맨 아래 클래스만 구체적이고 그 위는 모두 추상"으로 설계하면 잘림은 구조적으로 일어나지 않습니다.

## 그래도 복사해야 한다면: clone

부모 포인터만 가지고 실제 타입 그대로 복사하려면, 복사하는 일 자체를 가상 함수로 만듭니다.

```cpp
#include <memory>
#include <print>
#include <string>

class Shape {
public:
    virtual ~Shape() = default;
    virtual std::string name() const = 0;
    virtual std::unique_ptr<Shape> clone() const = 0;
};

class Circle : public Shape {
public:
    std::string name() const override { return "circle"; }
    std::unique_ptr<Shape> clone() const override
    {
        return std::make_unique<Circle>(*this);     // 자기 타입으로 복사한다
    }
};

int main()
{
    std::unique_ptr<Shape> a = std::make_unique<Circle>();
    std::unique_ptr<Shape> b = a->clone();
    std::println("{}", b->name());
}
```

```text
circle
```

`Circle::clone` 안에서 `*this`의 타입은 `Circle`입니다. 그래서 `Circle`의 복사 생성자가 불리고 온전한 복사본이 나옵니다. 자식마다 `clone`을 한 줄씩 적어야 한다는 것이 값입니다.

<Note>
값처럼 복사하고 담으면서 종류도 여럿이어야 한다면 상속 대신 `std::variant<Circle, Square>`가 맞을 수 있습니다. 힙 할당도 가상 함수도 없고, 잘림이라는 개념이 아예 없습니다. 종류가 미리 정해져 있을 때 쓸 수 있습니다.
</Note>

## 정리

- 자식을 부모 타입의 값에 넣으면 자식 부분과 가상 동작이 사라진다
- 다형적 객체는 포인터나 참조로 다루고, 예외는 `const` 참조로 받는다
- 부모를 추상으로 만들거나 복사를 지워서 컴파일러가 막게 한다. 복사가 필요하면 `clone`
