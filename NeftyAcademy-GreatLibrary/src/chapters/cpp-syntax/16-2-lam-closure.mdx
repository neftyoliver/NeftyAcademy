export const summary = '람다는 컴파일러가 만든 클래스의 객체, 크기와 타입, auto 매개변수';

람다는 마법이 아닙니다. 컴파일러가 **이름 없는 클래스를 하나 만들고 그 객체를 하나 만드는** 문법입니다. 그 클래스를 클로저 타입이라고 합니다. 이것을 알면 크기, 비용, 타입에 관한 질문이 모두 풀립니다.

## 컴파일러가 만드는 것

```cpp nocheck
int offset = 100;
auto add = [offset](int x) { return x + offset; };

// 컴파일러는 대략 이런 것을 만든다
class Closure_1 {
public:
    int operator()(int x) const { return x + offset; }

private:
    int offset;         // 캡처한 것이 멤버가 된다
};
auto add = Closure_1{offset};
```

| 람다의 부분 | 클래스에서 |
| --- | --- |
| 캡처 목록 | 멤버 변수. 값 캡처는 값, 참조 캡처는 참조 |
| 매개변수와 본문 | [`operator()`](#/read/cpp-syntax/op-call) |
| `mutable`이 없다 | `operator()`가 `const`다 |
| 람다 식 자체 | 그 클래스의 객체 하나를 만드는 식 |

## 확인해 보기

```cpp
#include <print>
#include <set>
#include <string>

int main()
{
    int offset = 100;
    double scale = 0.5;
    auto plain = [](int x) { return x + 1; };
    auto with_state = [offset, scale](int x) { return (x + offset) * scale; };
    std::println("{} {}", sizeof(plain), sizeof(with_state));
    std::println("{}", with_state(20));

    int (*fp)(int) = plain;             // 캡처가 없으면 함수 포인터로 바뀐다
    std::println("{}", fp(1));

    auto twice = [](auto x) { return x + x; };      // 제네릭 람다
    std::println("{} {}", twice(21), twice(std::string("ab")));

    auto same = []<typename T>(const T& a, const T& b) { return a == b; };
    std::println("{}", same(3, 3));
    // same(3, 3.0);    // 오류: 두 인자의 타입이 같아야 한다

    using Descending = decltype([](int a, int b) { return a > b; });
    std::set<int, Descending> sorted{3, 1, 2};
    std::println("{}", *sorted.begin());
}
```

```text
1 16
60
2
42 abab
true
3
```

## 크기와 비용

- 캡처가 없는 람다는 멤버가 없는 클래스다. 크기는 1(빈 클래스의 최소 크기)
- `int`와 `double`을 캡처하면 `int`(4) + 채움(4) + `double`(8) = 16바이트
- **힙을 쓰지 않는다.** 람다 객체는 지역 변수처럼 스택에 놓인다
- 부르는 것은 보통의 멤버 함수 호출이다. 컴파일러가 본문을 볼 수 있으므로 대부분 인라인된다

`std::sort(v.begin(), v.end(), [](int a, int b) { return a > b; })`가 C의 `qsort`보다 빠른 까닭이 여기 있습니다. `qsort`는 비교 함수를 포인터로 받아 매번 간접 호출하고, `std::sort`는 람다의 **타입**을 템플릿 인자로 받아 비교를 정렬 코드 안에 녹여 넣습니다.

## 타입

람다마다 **서로 다른 타입**입니다. 글자가 똑같은 람다 둘도 타입이 다릅니다.

| 하려는 일 | 방법 |
| --- | --- |
| 변수에 받는다 | `auto f = […] { … };` 타입의 이름을 적을 방법이 없다 |
| 함수의 인자로 받는다 | 템플릿으로: `template <typename F> void run(F f)` 또는 `void run(auto f)` |
| 타입이 필요한 자리에 쓴다 | `decltype(f)`, 또는 `decltype([]{ … })` (C++20) |
| 서로 다른 람다를 한 변수, 한 컨테이너에 | [`std::function`](#/read/cpp-syntax/lam-function) |

위 예제의 `std::set<int, Descending>`은 비교 **타입**이 필요한 자리에 람다의 타입을 넣은 것입니다. 캡처 없는 람다는 C++20부터 기본 생성이 되어, `std::set`이 그 타입의 객체를 스스로 만들 수 있습니다.

## 함수 포인터로

캡처가 **없는** 람다는 같은 서명의 함수 포인터로 저절로 바뀝니다. C 라이브러리의 콜백 자리에 람다를 넘길 수 있습니다.

```cpp nocheck
std::signal(SIGINT, [](int) { stop_requested = 1; });
std::qsort(data, n, sizeof(int), [](const void* a, const void* b) {
    return *static_cast<const int*>(a) - *static_cast<const int*>(b);
});
```

캡처가 있으면 바뀌지 않습니다. 품은 값을 둘 곳이 함수 포인터에는 없기 때문입니다. C API가 `void* user_data`를 함께 받는다면, 거기에 객체의 주소를 넘기고 캡처 없는 람다 안에서 [`static_cast`](#/read/cpp-syntax/cast-static)로 되찾는 것이 정해진 방법입니다.

## 제네릭 람다

매개변수에 `auto`를 쓰면 `operator()`가 [템플릿](#/read/cpp-syntax/tpl-function)이 됩니다. 한 람다 객체를 여러 타입으로 부를 수 있습니다.

| 꼴 | 뜻 |
| --- | --- |
| `[](auto x)` | 어떤 타입이든. `auto`마다 독립된 타입 |
| `[](const auto& x)` | 복사 없이 |
| `[](auto&&... args)` | [전달 참조의 묶음](#/read/cpp-syntax/tpl-variadic). `std::forward<decltype(args)>(args)...`로 넘긴다 |
| `[]<typename T>(T a, T b)` | 템플릿 인자를 드러내 적는다 (C++20). 타입에 이름이 필요하거나 두 인자가 같은 타입이어야 할 때 |
| `[](std::integral auto x)` | [콘셉트](#/read/cpp-syntax/con-requires)로 제한한다 |

## 덧붙일 수 있는 것

```cpp nocheck
auto f = [](int x) -> double { return x / 2.0; };       // 반환 타입을 적는다
auto g = [](int x) noexcept { return x + 1; };          // noexcept
auto h = [](int x) static { return x * 2; };            // C++23: this 없는 호출
constexpr auto sq = [](int x) { return x * x; };        // 컴파일할 때도 쓸 수 있다
static_assert(sq(4) == 16);
```

람다는 조건이 맞으면 저절로 [`constexpr`](#/read/cpp-syntax/ct-constexpr)입니다(C++17). `-> 타입`은 `return`이 여럿이고 타입이 서로 다를 때, 또는 참조를 돌려줄 때(`-> auto&`) 필요합니다.

<Note>
"람다를 변수에 담아 두면 느린가"라는 걱정은 필요 없습니다. `auto`로 받은 람다는 타입이 그대로 남아 있으므로 직접 부르는 것과 같습니다. 느려지는 것은 `std::function`에 넣어 타입을 지웠을 때입니다.
</Note>

## 정리

- 람다는 캡처를 멤버로, 본문을 `operator()`로 가진 이름 없는 클래스의 객체다
- 크기는 캡처한 것의 합. 힙을 쓰지 않고, 호출은 인라인된다
- 캡처 없는 람다는 함수 포인터로 바뀐다. `auto` 매개변수는 호출 연산자를 템플릿으로 만든다
