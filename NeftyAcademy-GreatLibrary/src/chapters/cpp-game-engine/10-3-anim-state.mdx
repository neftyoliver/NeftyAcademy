## 서기, 걷기, 달리기, 점프

```cpp
#include <functional>
#include <print>
#include <string>
#include <vector>

struct Params { float speed = 0; bool grounded = true; bool jump = false; };

struct Transition {
    int from, to;                       // from == -1 이면 어느 상태에서든
    float fade;                         // 섞어 넘어가는 시간(초)
    std::function<bool(const Params&)> when;
};

struct Machine {
    std::vector<std::string> names;
    std::vector<Transition> edges;
    int current = 0, previous = -1;
    float fade_t = 0, fade_len = 0;     // 진행 중인 전환

    void update(const Params& p, float dt) {
        if (previous >= 0) {            // 전환 중이면 섞는 비율을 진행
            fade_t += dt;
            if (fade_t >= fade_len) previous = -1;
        }
        for (auto& e : edges) {         // 위에 적은 전환이 우선
            if ((e.from == current || e.from == -1) && e.to != current
                && e.when(p)) {
                previous = current;     // 전환 도중이면 그 자리에서 다시 시작
                current = e.to;
                fade_t = 0;
                fade_len = e.fade;
                break;
            }
        }
    }
    std::string describe() const {
        if (previous < 0) return names[current];
        float w = fade_t / fade_len;
        return std::format("{} {:.0f}% + {} {:.0f}%", names[previous],
                           (1 - w) * 100, names[current], w * 100);
    }
};

int main() {
    enum { Idle, Walk, Run, Jump };
    Machine m;
    m.names = {"서기", "걷기", "달리기", "점프"};
    m.edges = {
        {-1, Jump, 0.1f, [](auto& p) { return p.jump && p.grounded; }},
        {Jump, Idle, 0.2f, [](auto& p) { return p.grounded && !p.jump; }},
        {Idle, Walk, 0.2f, [](auto& p) { return p.speed > 0.1f; }},
        {Walk, Idle, 0.3f, [](auto& p) { return p.speed <= 0.1f; }},
        {Walk, Run, 0.25f, [](auto& p) { return p.speed > 3; }},
        {Run, Walk, 0.25f, [](auto& p) { return p.speed <= 3; }},
    };

    Params p;
    const float dt = 0.05f;
    struct Event { float at; const char* what; std::function<void()> f; };
    std::vector<Event> script = {
        {0.10f, "속도 2", [&] { p.speed = 2; }},
        {0.40f, "속도 5", [&] { p.speed = 5; }},
        {0.50f, "속도 1 (달리기로 넘어가는 중에)", [&] { p.speed = 1; }},
        {0.90f, "점프", [&] { p.jump = true; }},
        {0.95f, "공중", [&] { p.grounded = false; p.jump = false; }},
        {1.30f, "착지, 속도 0", [&] { p.grounded = true; p.speed = 0; }},
    };
    std::size_t next = 0;
    for (int f = 0; f <= 34; ++f) {
        float t = f * dt;
        if (next < script.size() && t >= script[next].at - 1e-4f) {
            std::println("{:.2f}초  -- {}", t, script[next].what);
            script[next++].f();
        }
        m.update(p, dt);
        if (f % 2 == 0 || m.previous >= 0)
            std::println("{:.2f}초  {}", t, m.describe());
    }
}
```

## 전환과 섞는 시간

- **전환**은 출발 상태, 도착 상태, 조건, 섞는 시간으로 이루어집니다. 속도가 0.1을 넘자 서기에서 걷기로 0.2초 동안 섞어 넘어갔습니다. 섞는 동안의 자세는 앞 장의 블렌딩으로 계산합니다
- 걷기에서 서기로는 0.3초, 점프로는 0.1초처럼 전환마다 시간이 다릅니다. 멈출 때는 천천히, 점프는 버튼에 바로 반응하도록 짧게 잡습니다. 조작감과 자연스러움 사이의 이런 조정이 애니메이터의 몫입니다
- 점프 전환은 출발 상태가 `-1`, 곧 **어느 상태에서든** 갈 수 있습니다. 상태마다 점프 화살표를 그리지 않아도 됩니다. 또 전환 목록의 앞에 적어서, 같은 프레임에 다른 조건도 맞으면 점프가 이깁니다. 우선순위는 이런 그래프에서 자주 버그가 숨는 곳입니다

## 전환 도중 끼어들기

0.40초에 속도를 5로 올려 걷기에서 달리기로 넘어가던 중, 0.50초에 속도를 1로 낮췄습니다. 그 순간 화면의 자세는 "걷기 80% + 달리기 20%"였는데, 다음 줄은 "달리기 100% + 걷기 0%"입니다. 새 전환이 출발 상태를 그냥 `current`(달리기)로 잡았기 때문에, 20%만 섞여 있던 달리기 자세로 한 프레임 만에 **튀었습니다.** 사람이 아주 잘 알아차리는 결함입니다.

고치는 방법은 여럿입니다.

- **자세 고정**: 끼어드는 순간의 섞인 자세를 한 장 찍어 두고, 그 고정된 자세에서 새 상태로 섞습니다. 가장 흔한 방법입니다
- **끼어들기 금지**: 일부 전환은 끝날 때까지 다른 전환을 받지 않게 합니다. 공격 동작처럼 중간에 끊기면 안 되는 것에 씁니다
- **관성 블렌딩**: 섞는 대신 끼어드는 순간의 뼈 위치와 속도 차이를 기록해 두고, 그 차이를 짧은 시간에 0으로 줄여 가며 새 동작에 더합니다. 두 동작을 동시에 계산하지 않아도 되어 저렴합니다

<Note>
상태가 많아지면 화살표가 거미줄이 됩니다. 그래서 상태 안에 다시 상태 기계를 넣는 계층 상태 기계, 속도처럼 연속인 값에 따라 여러 클립을 자동으로 섞는 블렌드 공간(1차원이면 걷기와 달리기 사이 비율을 속도로 정하는 식)을 함께 씁니다. 예제의 걷기와 달리기 전환도 실제로는 블렌드 공간 하나로 만드는 경우가 많습니다.
</Note>

## 정리

- 게임 코드는 매개변수만 넘기고, 상태와 전환 조건, 섞는 시간은 애니메이터가 그래프로 정한다
- 전환마다 섞는 시간과 우선순위가 있고, 어느 상태에서든 가는 전환으로 화살표를 줄인다
- 전환 도중 끼어들면 자세가 튈 수 있으므로 자세 고정, 끼어들기 금지, 관성 블렌딩으로 막는다
