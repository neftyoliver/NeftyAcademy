`<chrono>`의 타입은 [`std::format`](#/read/cpp-stl/str-format)과 `std::println`에 그대로 들어갑니다. 서식 문자열의 `:` 뒤에 `%`로 시작하는 지정자를 적습니다. `strftime`을 써 봤다면 낯익은 글자들입니다.

## 지정자

| 지정자 | 찍히는 것 | 예 |
| --- | --- | --- |
| `%Y` `%m` `%d` | 연, 월, 일 | `2026` `11` `20` |
| `%H` `%M` `%S` | 시(24시간), 분, 초 | `13` `05` `09` |
| `%F` | `%Y-%m-%d` | `2026-11-20` |
| `%T`, `%R` | `%H:%M:%S`, `%H:%M` | `13:05:09`, `13:05` |
| `%I` `%p` | 시(12시간), 오전·오후 | `01` `PM` |
| `%a` `%A`, `%b` `%B` | 요일과 달의 이름, 짧게와 길게 | `Fri` `Friday`, `Nov` `November` |
| `%j`, `%u` | 그 해의 몇째 날, 요일 번호(월요일이 1) | `324`, `5` |
| `%Z`, `%z` | 시간대의 이름, UTC와의 차이 | `KST`, `+0900` |
| `%Q` `%q` | 기간의 수, 기간의 단위 | `1500` `ms` |

```cpp
#include <chrono>
#include <print>

using namespace std::chrono;
using namespace std::chrono_literals;

int main()
{
    const sys_time<milliseconds> moment =
        sys_days{2026y / November / 20} + 13h + 5min + 9s + 250ms;

    std::println("{}", moment);
    std::println("{:%F %T}", moment);
    std::println("{:%Y년 %m월 %d일 %H시 %M분}", moment);
    std::println("{:%A %d %B %Y, %I:%M %p}", moment);
    std::println("{:%d.%m.%Y} / {:%y%m%d-%H%M%S}", moment, floor<seconds>(moment));
    std::println("{:%j}번째 날, 요일 번호 {:%u}", moment, moment);
}
```

```text
2026-11-20 13:05:09.250
2026-11-20 13:05:09.250
2026년 11월 20일 13시 05분
Friday 20 November 2026, 01:05 PM
20.11.2026 / 261120-130509
324번째 날, 요일 번호 5
```

지정자가 아닌 글자는 그대로 찍힙니다. 날짜만 있는 타입(`year_month_day`)에 `%H`를 쓰거나 기간에 `%Y`를 쓰는 것처럼 **그 타입에 없는 것을 요구하면 컴파일 오류**입니다. `strftime`과 달리 잘못된 서식이 실행 중에 쓰레기를 찍는 일이 없습니다.

## 초 아래 자릿수는 타입이 정한다

`%S`와 `%T`는 초 아래를 **시각의 타입이 가진 정밀도만큼** 찍습니다. 자릿수를 서식으로 정하는 것이 아니라 타입을 바꿔서 정합니다.

```cpp
#include <chrono>
#include <print>

using namespace std::chrono;
using namespace std::chrono_literals;

int main()
{
    const auto base = sys_days{2026y / November / 20} + 13h + 5min + 9s;
    const sys_time<nanoseconds> fine = base + 123'456'789ns;

    std::println("{:%T}", fine);
    std::println("{:%T}", floor<microseconds>(fine));
    std::println("{:%T}", floor<milliseconds>(fine));
    std::println("{:%T}", floor<seconds>(fine));
    std::println("{:%R}", fine);

    // 로그에 쓰기 좋은 꼴: ISO 8601, UTC, 밀리초까지
    std::println("{:%FT%T}Z", floor<milliseconds>(fine));
}
```

```text
13:05:09.123456789
13:05:09.123456
13:05:09.123
13:05:09
13:05
2026-11-20T13:05:09.123Z
```

리눅스에서 `system_clock::now()`는 나노초 시각이라 그대로 찍으면 아홉 자리가 붙습니다. 로그에는 `floor<milliseconds>`나 `floor<seconds>`를 거쳐 찍습니다. 마지막 줄의 `2026-11-20T13:05:09.123Z` 꼴은 글자 순서가 곧 시간 순서라서 정렬이 되고, 어느 나라에서 읽어도 헷갈리지 않습니다. 기기가 남기는 시각은 이 꼴로 통일해 두면 편합니다.

## 기간 찍기

```cpp
#include <chrono>
#include <print>

using namespace std::chrono;
using namespace std::chrono_literals;

int main()
{
    std::println("{} / {:%T} / {:%M:%S}", 3723s, 3723s, 90s);
    std::println("{:%T} / {:%T}", 1500ms, 90061s);
    std::println("{:%Q} {:%q} / [{:>8}]", 1500ms, 1500ms, 90s);

    // 실수 초로 찍기
    const duration<double> seconds_f = 1234ms;
    std::println("{:.2f}초", seconds_f.count());
}
```

```text
3723s / 01:02:03 / 01:30
00:00:01.500 / 25:01:01
1500 ms / [     90s]
1.23초
```

기간에 `%T`를 쓰면 경과 시간을 `시:분:초`로 볼 수 있습니다. 24시간을 넘어도 0으로 돌아가지 않고 `25:01:01`처럼 이어집니다. 지정자 없이 찍으면 수에 단위가 붙고(`3723s`), 너비와 맞춤은 보통의 서식처럼 줍니다.

## 로캘

요일과 달의 이름은 기본으로 영어입니다. 프로그램의 로캘이 무엇이든 그렇습니다. 로캘을 따르게 하려면 지정자 앞에 `L`을 붙이고, `std::format`에 로캘을 넘깁니다.

```cpp
#include <chrono>
#include <format>
#include <locale>
#include <print>

using namespace std::chrono;
using namespace std::chrono_literals;

int main()
{
    const auto moment = sys_days{2026y / November / 20} + 13h + 5min;
    try {
        const std::locale korean("ko_KR.UTF-8");
        std::println("{}", std::format(korean, "{:%A %B}", moment));
        std::println("{}", std::format(korean, "{:L%A %B}", moment));
        const std::locale german("de_DE.UTF-8");
        std::println("{}", std::format(german, "{:L%A, %d. %B %Y}", moment));
    } catch (const std::runtime_error&) {
        std::println("이 기계에 그 로캘이 깔려 있지 않다");
    }
}
```

```text
Friday November
금요일 11월
Freitag, 20. November 2026
```

기본이 영어로 고정되어 있는 것은 장점입니다. 로그나 파일 이름에 찍는 시각이 기계의 언어 설정에 따라 달라지지 않습니다. 사람에게 보여 줄 화면에서만 `L`을 씁니다. 로캘은 [운영체제에 깔려 있어야](#/read/cpp-stl/str-convert) 하고, 없으면 `std::locale`의 생성자가 예외를 던집니다.

## 되읽기

글로 된 시각을 타입으로 되돌리는 것은 `std::chrono::parse`입니다. [스트림](#/read/cpp-stl/io-string)의 `>>`와 함께 쓰고, 같은 지정자를 받습니다.

```cpp
#include <chrono>
#include <print>
#include <sstream>
#include <string>

using namespace std::chrono;

int main()
{
    std::istringstream first("2026-11-20 13:05:09");
    sys_seconds moment;
    first >> parse("%F %T", moment);
    std::println("{} / 실패 {}", moment, first.fail());

    std::istringstream second("20/11/2026");
    year_month_day date;
    second >> parse("%d/%m/%Y", date);
    std::println("{} / 실패 {}", date, second.fail());

    // UTC 와의 차이가 붙은 시각: 차이를 빼서 UTC 로 준다
    std::istringstream third("2026-11-20T22:05:09+09:00");
    third >> parse("%FT%T%Ez", moment);
    std::println("{} / 실패 {}", moment, third.fail());

    std::istringstream broken("not a date");
    broken >> parse("%F", date);
    std::println("실패 {}", broken.fail());
}
```

```text
2026-11-20 13:05:09 / 실패 false
2026-11-20 / 실패 false
2026-11-20 13:05:09 / 실패 false
실패 true
```

읽지 못하면 [스트림의 `failbit`](#/read/cpp-stl/io-streams)가 켜지고 변수는 바뀌지 않습니다. `%z`는 `+0900`, `%Ez`는 `+09:00` 꼴의 차이를 읽습니다. 차이가 붙은 글을 `sys_time`으로 읽으면 그만큼을 빼서 UTC로 돌려줍니다. 셋째 줄에서 서울의 22시가 UTC 13시가 됐습니다.

<Note>
`parse`는 GCC 14에서 됩니다. Clang 20의 libc++에는 아직 없습니다(확인한 것). 두 구현에서 다 돌아야 하면 숫자를 [`from_chars`](#/read/cpp-stl/str-convert)로 직접 읽어 `year_month_day`를 조립합니다. 옛 코드의 `std::put_time`과 `strftime`은 `std::tm` 구조체를 거쳐야 하고 초 아래를 찍지 못합니다. 새 코드에서는 쓸 까닭이 없습니다.
</Note>

## 정리

- 시각과 기간은 `std::format`에 `%F`, `%T` 같은 지정자로 찍는다. 타입에 없는 것을 요구하면 컴파일 오류다
- 초 아래 자릿수는 서식이 아니라 타입이 정한다. `floor<milliseconds>`나 `floor<seconds>`를 거쳐 찍는다
- 이름은 기본으로 영어이고 `L`을 붙여야 로캘을 따른다. 글에서 시각으로 되돌리는 것은 `std::chrono::parse`다
