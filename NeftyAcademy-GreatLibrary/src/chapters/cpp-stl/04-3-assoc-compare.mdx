`std::map<Key, Value>`의 온전한 모양은 `std::map<Key, Value, Compare, Alloc>`입니다. 셋째 인자 `Compare`가 "무엇이 앞인가"를 정하고, 기본값은 `<`로 견주는 `std::less<Key>`입니다. 이 자리를 바꾸면 순서뿐 아니라 **무엇을 같은 열쇠로 볼지**도 바뀝니다.

## 순서 바꾸기

```cpp
#include <functional>
#include <print>
#include <set>
#include <string>

// 1. 함수 객체: 길이 순, 길이가 같으면 사전 순
struct ByLength {
    bool operator()(const std::string& a, const std::string& b) const
    {
        if (a.size() != b.size())
            return a.size() < b.size();
        return a < b;
    }
};

int main()
{
    std::set<int, std::greater<>> descending = {3, 1, 2};       // 2. 표준 함수 객체
    for (int v : descending)
        std::print("{} ", v);
    std::println("");

    std::set<std::string, ByLength> words = {"zero", "pi", "a", "to"};
    for (const auto& w : words)
        std::print("{} ", w);
    std::println("");

    // 3. 람다 (C++20): 타입을 decltype 으로 넘긴다
    auto by_last_letter = [](const std::string& a, const std::string& b) {
        return a.back() < b.back();
    };
    std::set<std::string, decltype(by_last_letter)> by_last = {"zero", "pi", "a"};
    for (const auto& w : by_last)
        std::print("{} ", w);
    std::println("");
}
```

```text
3 2 1
a pi to zero
a pi zero
```

비교자는 [함수 호출 연산자](#/read/cpp-syntax/op-call)를 가진 타입이면 됩니다. 타입이 컨테이너 타입의 일부가 되므로 `std::set<int>`와 `std::set<int, std::greater<>>`는 서로 다른 타입입니다.

## 비교자가 "같다"를 정한다

`map`과 `set`은 `==`를 쓰지 않습니다. **`a`가 `b`보다 앞도 아니고 `b`가 `a`보다 앞도 아니면** 둘을 같은 열쇠로 봅니다. 그래서 비교자를 바꾸면 "같다"의 뜻이 따라 바뀝니다.

```cpp
#include <algorithm>
#include <cctype>
#include <map>
#include <print>
#include <string>
#include <string_view>

// 대소문자를 가리지 않는 순서
struct NoCase {
    bool operator()(std::string_view a, std::string_view b) const
    {
        const auto lower_less = [](unsigned char x, unsigned char y) {
            return std::tolower(x) < std::tolower(y);
        };
        return std::ranges::lexicographical_compare(a, b, lower_less);
    }
};

int main()
{
    std::map<std::string, int, NoCase> pins;
    pins["LED"] = 17;
    pins["led"] = 27;           // "LED" 와 같은 열쇠로 본다. 새로 생기지 않는다
    pins["Button"] = 22;

    std::println("size {}", pins.size());
    for (const auto& [name, pin] : pins)
        std::println("{} = {}", name, pin);
    std::println("{}", pins.contains("BUTTON"));
}
```

```text
size 2
Button = 22
LED = 27
true
```

`"led"`로 넣은 값 27이 `"LED"`라는 열쇠에 들어갔습니다. 열쇠는 처음 넣은 것이 남습니다.

## 엄격한 순서의 규칙

비교자는 아무 함수나 되는 것이 아니라 **엄격한 약한 순서**여야 합니다.

| 규칙 | 뜻 |
| --- | --- |
| 자기 자신보다 앞이 아니다 | `comp(a, a)`는 언제나 `false` |
| 한쪽 방향뿐이다 | `comp(a, b)`가 참이면 `comp(b, a)`는 거짓 |
| 이어진다 | `a`가 `b` 앞, `b`가 `c` 앞이면 `a`가 `c` 앞 |
| "같다"도 이어진다 | `a`와 `b`가 같고 `b`와 `c`가 같으면 `a`와 `c`도 같다 |

가장 흔한 위반은 `<` 자리에 `<=`를 쓰는 것입니다. 첫째 규칙이 깨집니다.

```cpp
#include <functional>
#include <print>
#include <set>

int main()
{
    std::set<int, std::less_equal<>> broken = {1, 2, 2, 3};    // <= 는 규칙 위반
    std::println("size {}, contains(2) {}", broken.size(), broken.contains(2));
    for (int v : broken)
        std::print("{} ", v);
    std::println("");
}
```

```text
size 4, contains(2) false
1 2 2 3
```

`set`인데 2가 둘 들어갔고, 들어 있는 2를 찾지 못합니다. `<=`로는 "2는 2보다 앞이다"가 되어 어떤 2도 다른 2와 같다고 판정되지 않기 때문입니다. 이것은 GCC 14에서 본 결과일 뿐이고 표준으로는 정의되지 않은 동작입니다. `std::sort`에 이런 비교자를 주면 배열 밖을 읽기도 합니다.

<Note kind="warn">
멤버 여럿으로 견줄 때 손으로 `a.x < b.x && a.y < b.y`라고 쓰면 규칙을 어깁니다. (1, 5)와 (2, 3)이 서로 앞이 아니어서 "같다"가 되는데, 그 "같다"가 이어지지 않습니다. `std::tie(a.x, a.y) < std::tie(b.x, b.y)`로 쓰거나, 타입에 [`operator<=>`를 `= default`](#/read/cpp-syntax/op-compare)로 주고 기본 비교자를 씁니다. 실수(`double`)의 NaN도 어떤 값과도 앞뒤가 정해지지 않아 열쇠로 쓰면 같은 문제를 일으킵니다.
</Note>

## 투명 비교: 임시 객체 없이 찾기

`std::map<std::string, int>`에서 `m.find("name")`을 부르면, 비교하기 전에 `"name"`으로 임시 `std::string`이 만들어집니다. `find`가 `const std::string&`만 받기 때문입니다. 비교자를 `std::less<>`로 바꾸면 `find`가 **견줄 수 있는 아무 타입**이나 받습니다.

```cpp
#include <cstdlib>
#include <functional>
#include <map>
#include <new>
#include <print>
#include <string>
#include <string_view>

static int allocations = 0;
void* operator new(std::size_t n)
{
    ++allocations;
    if (void* p = std::malloc(n))
        return p;
    throw std::bad_alloc{};
}
void operator delete(void* p) noexcept { std::free(p); }
void operator delete(void* p, std::size_t) noexcept { std::free(p); }

int main()
{
    const char* name = "temperature_sensor_outdoor";    // 26글자: 힙이 필요한 길이
    std::map<std::string, int> plain = {{name, 1}};
    std::map<std::string, int, std::less<>> transparent = {{name, 1}};
    const std::string_view view = name;

    allocations = 0;
    const bool a = plain.find(name) != plain.end();         // 임시 std::string
    std::println("less<string>: 찾음 {}, 할당 {}번", a, allocations);

    allocations = 0;
    const bool b = transparent.find(name) != transparent.end();
    const bool c = transparent.contains(view);      // string_view 로도 찾는다
    std::println("less<>:       찾음 {} {}, 할당 {}번", b, c, allocations);
}
```

```text
less<string>: 찾음 true, 할당 1번
less<>:       찾음 true true, 할당 0번
```

`std::less<>`(꺾쇠 안이 빈 것)는 "양쪽 타입을 그대로 받아 `<`로 견준다"는 비교자이고, 안에 `is_transparent`라는 표지가 있습니다. 컨테이너는 그 표지를 보고 `find`, `contains`, `count`, `lower_bound`, `equal_range`의 템플릿 판을 켭니다. 문자열을 열쇠로 쓰는 `map`과 `set`은 처음부터 `std::less<>`로 선언해 두는 것이 좋습니다.

내 비교자에도 표지를 달 수 있습니다. 객체의 `set`을 그 객체의 번호만으로 찾는 구조가 됩니다.

```cpp
#include <print>
#include <set>
#include <string>

struct Device {
    int id;
    std::string name;
};

struct ById {
    using is_transparent = void;        // 이 표지가 다른 타입으로 찾기를 켠다
    bool operator()(const Device& a, const Device& b) const { return a.id < b.id; }
    bool operator()(const Device& a, int id) const { return a.id < id; }
    bool operator()(int id, const Device& b) const { return id < b.id; }
};

int main()
{
    std::set<Device, ById> devices = {{17, "led"}, {22, "button"}, {4, "fan"}};
    // 번호만으로 찾는다. Device 를 만들지 않는다
    if (const auto it = devices.find(22); it != devices.end())
        std::println("{} -> {}", it->id, it->name);
    std::println("{}", devices.contains(5));
}
```

```text
22 -> button
false
```

`std::map<int, Device>`로 번호를 따로 들지 않아도 되므로, 번호가 객체 안과 열쇠에 두 번 적혀 어긋나는 일이 없습니다.

## 정리

- 비교자는 컨테이너 타입의 셋째 인자다. 순서와 함께 "같은 열쇠"의 뜻을 정한다
- 비교자는 엄격한 순서여야 한다. `<=`와 `a.x < b.x && a.y < b.y`는 규칙 위반이다
- `std::less<>`나 `is_transparent` 표지를 단 비교자는 임시 객체 없이 다른 타입으로 찾게 해 준다
