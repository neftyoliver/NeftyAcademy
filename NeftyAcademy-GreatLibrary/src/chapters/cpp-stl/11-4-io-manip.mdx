스트림은 "지금 몇 진법으로, 몇 자리로, 어느 쪽에 맞춰 찍는가"를 [자기 안에 상태로](#/read/cpp-stl/io-streams) 가지고 있습니다. `<<`로 흘려 넣어 그 상태를 바꾸는 것이 **조작자**(manipulator)입니다. `std::hex`처럼 인자가 없는 것은 `<ios>`에, `std::setw(8)`처럼 인자가 있는 것은 `<iomanip>`에 있습니다.

## 표 찍기

```cpp
#include <iomanip>
#include <iostream>
#include <utility>

int main()
{
    std::cout << std::left << std::setw(8) << "name"
              << std::right << std::setw(8) << "value" << '\n';

    std::cout << std::fixed << std::setprecision(1);
    const std::pair<const char*, double> rows[] = {
        {"temp", 21.46},
        {"humid", 40.0},
        {"press", 1013.3},
    };
    for (const auto& [name, value] : rows)
        std::cout << std::left << std::setw(8) << name
                  << std::right << std::setw(8) << value << '\n';

    // setw 는 바로 다음 한 번에만 듣는다
    std::cout << std::setw(8) << 42 << 43 << '\n';
}
```

```text
name       value
temp        21.5
humid       40.0
press     1013.3
      4243
```

`std::fixed`와 `std::setprecision(1)`은 루프 앞에서 한 번 했는데 모든 줄에 들었습니다. `std::setw(8)`은 줄마다, 칸마다 다시 써야 했습니다. 이 차이가 조작자를 쓸 때 가장 헷갈리는 점입니다.

| 조작자 | 바꾸는 것 | 남는가 |
| --- | --- | --- |
| `std::setw(n)` | 다음 출력의 최소 너비 | **한 번만** |
| `std::setfill(c)` | 너비를 채우는 글자 | 남는다 |
| `std::left`, `std::right`, `std::internal` | 맞추는 쪽 | 남는다 |
| `std::hex`, `std::oct`, `std::dec` | 정수의 진법 | 남는다 |
| `std::showbase`, `std::uppercase`, `std::showpos` | `0x` 붙이기, 대문자, `+` 붙이기 | 남는다 |
| `std::fixed`, `std::scientific`, `std::defaultfloat` | 실수 표기 | 남는다 |
| `std::setprecision(n)` | 실수의 자릿수 | 남는다 |
| `std::boolalpha` | `bool`을 `true`, `false`로 | 남는다 |

## 숫자 서식

```cpp
#include <iomanip>
#include <iostream>

int main()
{
    std::cout << std::fixed << std::setprecision(2) << 3.14159 << ' ' << 2.0
              << '\n';
    std::cout << std::scientific << 12345.678 << '\n';
    std::cout << std::defaultfloat << std::setprecision(6) << 12345.678 << '\n';

    std::cout << std::hex << 255 << ' ' << std::showbase << 255 << ' '
              << std::uppercase << 255 << '\n';
    std::cout << std::dec << std::noshowbase << std::nouppercase;

    std::cout << std::boolalpha << true << ' ' << std::noboolalpha << true << '\n';
    std::cout << std::setfill('0') << std::setw(6) << -42 << ' '
              << std::internal << std::setw(6) << -42 << '\n';
}
```

```text
3.14 2.00
1.23e+04
12345.7
ff 0xff 0XFF
true 1
000-42 -00042
```

`std::setprecision`의 뜻은 표기에 따라 달라집니다. `fixed`와 `scientific`에서는 **소수점 아래** 자릿수이고, 기본 표기에서는 **유효 숫자** 수입니다. 그래서 같은 6이 `12345.7`을 만듭니다. `std::internal`은 부호와 숫자 사이를 채웁니다. 0으로 채울 때는 이것이 있어야 `-00042`가 됩니다.

## 남는 상태가 만드는 버그

조작자가 남는다는 것은 함수 하나가 바꾼 서식이 **부른 쪽으로 새어 나간다**는 뜻입니다.

```cpp
#include <iomanip>
#include <iostream>

// 레지스터 값을 16진수 네 자리로 찍는다
void dump(std::ostream& out, int reg)
{
    out << std::hex << std::setfill('0') << "0x" << std::setw(4) << reg << '\n';
}

// 서식 상태를 기억했다가 되돌린다
class FormatGuard {
public:
    explicit FormatGuard(std::ostream& out)
        : out_(out), flags_(out.flags()), precision_(out.precision()),
          fill_(out.fill())
    {
    }
    ~FormatGuard()
    {
        out_.flags(flags_);
        out_.precision(precision_);
        out_.fill(fill_);
    }
    FormatGuard(const FormatGuard&) = delete;
    FormatGuard& operator=(const FormatGuard&) = delete;

private:
    std::ostream& out_;
    std::ios_base::fmtflags flags_;
    std::streamsize precision_;
    char fill_;
};

void dump_safe(std::ostream& out, int reg)
{
    const FormatGuard guard(out);
    out << std::hex << std::setfill('0') << "0x" << std::setw(4) << reg << '\n';
}

int main()
{
    dump(std::cout, 0x1f);
    std::cout << 255 << ' ' << std::setw(6) << 7 << '\n';    // 10진수로 찍으려던 줄

    std::cout << std::dec << std::setfill(' ');
    dump_safe(std::cout, 0x1f);
    std::cout << 255 << ' ' << std::setw(6) << 7 << '\n';
}
```

```text
0x001f
ff 000007
0x001f
255      7
```

`dump`를 부른 뒤로는 `255`가 `ff`로, 빈칸이 `0`으로 찍힙니다. `std::cout`은 프로그램 전체가 함께 쓰므로, 멀리 떨어진 코드의 출력이 바뀝니다. 스트림을 인자로 받아 서식을 바꾸는 함수는 [소멸자에서 되돌리는](#/read/cpp-syntax/class-dtor) 위와 같은 보초를 둡니다. 진법과 맞춤, `boolalpha` 같은 것은 모두 `flags()` 안에 있고, 자릿수와 채움 글자만 따로 있습니다.

같은 까닭으로 [내 타입의 `operator<<`](#/read/cpp-syntax/op-stream) 안에서 `std::setw`를 기대하면 안 됩니다. `std::cout << std::setw(10) << pin`의 너비는 `operator<<` 안의 **첫 `<<` 하나**에만 듭니다. 너비를 지키려면 안에서 문자열을 먼저 만들고 그것을 한 번에 내보냅니다.

## 입력 쪽 조작자

```cpp
#include <iomanip>
#include <iostream>
#include <sstream>
#include <string>

int main()
{
    // 16진수로 읽기. 0x 가 있어도 없어도 된다
    std::istringstream hex_in("ff 0x1A");
    int a = 0;
    int b = 0;
    hex_in >> std::hex >> a >> b;
    std::cout << a << ' ' << b << '\n';

    // 진법 표시를 지우면 접두어를 보고 고른다 (0x 는 16, 0 은 8)
    std::istringstream any("0x1A 010 10");
    int c = 0;
    any.unsetf(std::ios::basefield);
    any >> a >> b >> c;
    std::cout << a << ' ' << b << ' ' << c << '\n';

    // 공백이 든 문자열을 따옴표로 싸서 쓰고, 그대로 되읽는다
    std::ostringstream out;
    const std::string room = "living room \"A\"";
    out << std::quoted(room) << ' ' << 21.5;
    std::cout << out.str() << '\n';

    std::istringstream in(out.str());
    std::string back;
    double value = 0;
    in >> std::quoted(back) >> value;
    std::cout << back << " / " << value << '\n';
}
```

```text
255 26
26 8 10
"living room \"A\"" 21.5
living room "A" / 21.5
```

`std::quoted`(C++14)는 `>>`가 공백에서 끊는 문제를 푸는 가장 간단한 길입니다. 쓸 때 따옴표로 싸고 안의 따옴표에 `\`를 붙이며, 읽을 때 거꾸로 합니다. 앞 페이지에서 본 [`std::ws`](#/read/cpp-stl/io-file)도 입력 조작자입니다. 날짜와 시각을 위한 `std::put_time`, `std::get_time`도 `<iomanip>`에 있지만, 새 코드에서는 [`<chrono>`의 서식](#/read/cpp-stl/chr-format)이 낫습니다.

## format과 견주기

[`std::format`](#/read/cpp-stl/str-format)은 서식을 **값마다** 적으므로 남는 상태가 없습니다.

| 하려는 일 | 조작자 | 서식 문자열 |
| --- | --- | --- |
| 너비 8, 오른쪽 맞춤 | `std::setw(8)` | `{:>8}` |
| 너비 8, 왼쪽 맞춤 | `std::left << std::setw(8)` | `{:<8}` |
| 소수점 아래 3자리, 0으로 채워 8칸 | `setfill('0')`, `setw(8)`, `fixed`, `setprecision(3)` | `{:08.3f}` |
| `0x`를 붙인 16진수 | `std::showbase << std::hex` | `{:#x}` |
| 양수에도 부호 | `std::showpos` | `{:+}` |
| 가운데 맞춤 | 없다 | `{:^8}` |

```cpp
#include <print>

int main()
{
    std::println("{:>8}|{:<8}|{:^8}|", "r", "l", "c");
    std::println("{:08.3f}|{:#x}|{:+}|{:#06x}", 3.14159, 255, 5, 255);
}
```

```text
       r|l       |   c    |
0003.142|0xff|+5|0x00ff
```

<Note>
새로 쓰는 코드는 `std::format`과 `std::print`로 씁니다. 조작자를 알아야 하는 까닭은 읽을 코드가 많기 때문이고, 고칠 때 가장 먼저 의심할 것은 "어디선가 `std::hex`를 켜고 끄지 않았다"입니다.
</Note>

## 정리

- 조작자는 스트림의 서식 상태를 바꾼다. `std::setw`만 한 번 듣고 사라지고, 진법·자릿수·채움 글자·맞춤은 계속 남는다
- 남는 상태는 함수 밖으로 새어 나간다. 스트림을 받아 서식을 바꾸는 함수는 `flags()`, `precision()`, `fill()`을 기억했다가 되돌린다
- `std::quoted`는 공백이 든 문자열을 쓰고 되읽게 해 준다. 새 코드의 서식은 상태가 남지 않는 `std::format`으로 쓴다
