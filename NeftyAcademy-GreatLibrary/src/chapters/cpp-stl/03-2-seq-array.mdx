[「array와 span」](#/read/cpp-syntax/ft-array-span)에서 `std::array`가 "값처럼 복사되고 비교되는 고정 길이 배열"이라는 것을 보았습니다. 힙을 쓰지 않으므로 작은 기기의 코드에서 `vector`만큼 자주 만납니다. 여기서는 초기화의 세부와, 표를 만들어 두는 쓰임을 봅니다.

## 초기화

`std::array`에는 생성자가 없습니다. 속에 C 배열 하나를 멤버로 가진 구조체이고, 구조체를 초기화하는 규칙을 그대로 따릅니다. 그래서 꼴이 여럿입니다.

```cpp
#include <array>
#include <print>
#include <tuple>

struct Point {
    int x;
    int y;
};

int main()
{
    std::array<int, 4> zeros{};             // 모두 0
    std::array<int, 4> partial = {1, 2};    // 1 2 0 0: 모자란 칸은 0
    std::array inferred = {1.5, 2.5};       // 타입과 개수를 추론: array<double, 2>
    auto bytes = std::to_array<unsigned char>({0xDE, 0xAD, 0xBE});  // 개수만 추론

    std::array<Point, 2> a = {{{1, 2}, {3, 4}}};    // 중괄호가 한 겹 더 든다
    std::array<Point, 2> b = {Point{1, 2}, Point{3, 4}};    // 타입을 적으면 한 겹

    std::println("{} {} {}", zeros[3], partial[3], inferred.size());
    std::println("{} {}", bytes.size(), sizeof bytes);
    std::println("{} {}", a[1].y, b[1].y);

    auto [first, second] = inferred;        // 길이를 알기에 풀어 받을 수 있다
    std::println("{} {} {}", first, second, std::get<0>(partial));
}
```

```text
0 0 2
3 3
4 4
1.5 2.5 1
```

- `std::array<int, 4> a;`처럼 중괄호 없이 선언한 지역 변수는 C 배열과 마찬가지로 **쓰레기 값**입니다. `{}`를 붙이는 습관을 들입니다.
- 원소가 구조체일 때 `{{1, 2}, {3, 4}}`라고 쓰면 "초기화 값이 너무 많다"는 오류가 납니다. 바깥 중괄호는 `std::array`, 그다음은 속의 C 배열, 그다음이 원소입니다. 헷갈리면 원소의 타입 이름을 적습니다.
- `std::to_array`는 원소 타입만 적고 개수는 세게 합니다. 바이트 표를 적을 때 편합니다.

## 컴파일 시간에 검사하는 표

`std::array`는 `constexpr`로 만들 수 있고 알고리즘도 `constexpr`입니다. 그래서 "정렬되어 있어야 하는 표"를 컴파일러에게 확인시킬 수 있습니다.

```cpp
#include <algorithm>
#include <array>
#include <print>
#include <string_view>

struct ErrorName {
    int code;
    std::string_view name;
};

// 코드 순으로 정렬해 둔 표. 읽기 전용 메모리에 놓이고, 실행 중에 만들어지지 않는다
constexpr std::array error_names = std::to_array<ErrorName>({
    {2, "ENOENT"},
    {5, "EIO"},
    {13, "EACCES"},
    {16, "EBUSY"},
    {110, "ETIMEDOUT"},
});
static_assert(std::ranges::is_sorted(error_names, {}, &ErrorName::code),
              "error_names 는 code 순서여야 한다");

constexpr std::string_view name_of(int code)
{
    const auto it =
        std::ranges::lower_bound(error_names, code, {}, &ErrorName::code);
    return it != error_names.end() && it->code == code ? it->name : "?";
}
static_assert(name_of(16) == "EBUSY");

int main()
{
    for (int code : {5, 110, 7})
        std::println("{:3} -> {}", code, name_of(code));
}
```

```text
  5 -> EIO
110 -> ETIMEDOUT
  7 -> ?
```

누가 표 중간에 순서를 어겨 한 줄을 끼워 넣으면 빌드가 멈춥니다. 이진 탐색은 정렬이 깨져 있으면 조용히 틀린 답을 내므로, 이 한 줄의 `static_assert`가 값을 합니다. 힙도 없고 시작할 때 도는 코드도 없는 "읽기 전용 `map`"으로 쓸 수 있습니다. 표를 계산해서 채우는 예는 [「constexpr 변수와 함수」](#/read/cpp-syntax/ct-constexpr)의 CRC 표에 있습니다.

## 길이가 타입의 일부

`std::array<int, 3>`과 `std::array<int, 4>`는 서로 다른 타입입니다. 여기서 따라오는 것이 둘 있습니다.

```cpp nocheck
void print(const std::array<int, 4>& values);       // 4칸짜리만 받는다

template <std::size_t N>
void print(const std::array<int, N>& values);       // 길이마다 함수가 하나씩 생긴다

void print(std::span<const int> values);            // 하나로 모든 길이를 받는다
```

길이를 가리지 않는 함수는 [`std::span`](#/read/cpp-stl/seq-span)으로 받습니다. 템플릿으로 받으면 쓰인 길이마다 같은 코드가 한 벌씩 만들어져 실행 파일이 커집니다.

여러 차원은 `std::array`를 겹칩니다. `vector`를 겹친 것과 달리 전체가 한 덩어리입니다.

```cpp
#include <array>
#include <print>

int main()
{
    std::array<std::array<int, 3>, 2> grid{};       // 2행 3열, 모두 0
    grid[1][2] = 5;
    std::println("sizeof {} = int {}개", sizeof grid, sizeof grid / sizeof(int));
    for (const auto& row : grid) {
        for (int cell : row)
            std::print("{} ", cell);
        std::println("");
    }
}
```

```text
sizeof 24 = int 6개
0 0 0
0 0 5
```

## 스택의 한계

`std::array`는 선언한 자리에 통째로 놓입니다. 지역 변수면 스택입니다.

| 환경 | 스택의 크기(기본값) |
| --- | --- |
| 리눅스의 메인 스레드 | 대개 8MB (`ulimit -s`) |
| 마이크로컨트롤러의 RTOS 태스크 | 수백 바이트에서 수 KB |

`std::array<double, 2'000'000> samples{};`를 함수 안에 두면 16MB이고, 라즈베리파이에서도 그 자리에서 죽습니다. 마이크로컨트롤러에서는 수백 바이트짜리 배열도 따져 봐야 합니다.

| 큰 배열을 둘 곳 | 적는 법 |
| --- | --- |
| 전역이나 정적 영역 | `static std::array<double, 2'000'000> samples{};` |
| 힙 | `auto samples = std::make_unique<std::array<double, 2'000'000>>();` |
| 길이가 실행 중에 정해진다 | `std::vector<double>` |

<Note>
C++26에는 "용량은 고정이고 길이는 변하는" `std::inplace_vector`가 들어옵니다. `std::array`처럼 힙을 쓰지 않으면서 `push_back`이 됩니다. GCC 14에는 아직 없습니다. 그 전에는 [「타입이 아닌 템플릿 인자」](#/read/cpp-syntax/tpl-nontype)에서 만든 것처럼 `std::array`와 길이 변수를 묶어 직접 만듭니다.
</Note>

## 정리

- `std::array`는 C 배열을 감싼 구조체다. `{}`로 초기화하고, 원소가 구조체면 중괄호가 한 겹 더 든다
- `constexpr` 표와 `static_assert`로 "정렬된 표"를 컴파일러가 지키게 할 수 있다
- 길이가 타입이다. 여러 길이를 받는 함수는 `std::span`으로, 큰 배열은 스택 밖에 둔다
