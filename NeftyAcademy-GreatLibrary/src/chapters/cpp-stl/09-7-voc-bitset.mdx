`std::bitset<N>`은 **N개의 비트**를 담는 타입입니다. 길이가 템플릿 인자여서 컴파일할 때 정해지고, 힙을 쓰지 않습니다. 핀의 상태, 기능 표시, "이 칸을 썼는가" 같은 참·거짓의 묶음에 씁니다. 길이가 실행 중에 정해지는 것은 [`vector<bool>`](#/read/cpp-stl/seq-vector-bool)이었습니다.

## 켜고, 끄고, 세기

```cpp
#include <bitset>
#include <print>

int main()
{
    std::bitset<8> pins;                    // 모두 0
    pins.set(1);                            // 1번을 켠다
    pins.set(5);
    pins[7] = true;                         // 첨자로도
    std::println("{}", pins.to_string());   // 왼쪽이 높은 자리(7번)

    pins.flip(1);                           // 1번을 뒤집는다
    pins.reset(7);                          // 7번을 끈다
    std::println("{} / 켜진 것 {}개", pins.to_string(), pins.count());
    std::println("5번 {} 0번 {}", pins.test(5), pins.test(0));
    std::println("any {} all {} none {}", pins.any(), pins.all(), pins.none());

    const std::bitset<8> from_number(0b1010'0001);  // 수에서
    const std::bitset<8> from_text("00001111");     // 글에서
    std::println("{} {}", from_number.to_ulong(), from_text.to_ulong());
}
```

```text
10100010
00100000 / 켜진 것 1개
5번 true 0번 false
any true all false none false
161 15
```

| 하는 일 | 멤버 |
| --- | --- |
| 켜기, 끄기, 뒤집기 | `set(i)`, `reset(i)`, `flip(i)`. 인자가 없으면 전부 |
| 읽기 | `test(i)`는 범위를 검사한다. `[i]`는 검사하지 않는다 |
| 세기 | `count()`, `size()` |
| 묻기 | `any()`, `all()`, `none()` |
| 바꾸기 | `to_ulong()`, `to_ullong()`, `to_string()` |

`to_string()`과 글에서 만드는 생성자는 **오른쪽 끝이 0번**입니다. 수를 종이에 적는 방향과 같습니다. 배열처럼 0번이 왼쪽이라고 생각하면 뒤집혀 보입니다.

## 묶음끼리의 연산

비트 연산자가 묶음 전체에 한 번에 적용됩니다. "둘 다 켜진 것", "하나라도 켜진 것", "달라진 것"이 한 줄입니다.

```cpp
#include <bitset>
#include <print>

int main()
{
    const std::bitset<8> wanted("11110000");    // 켜져 있어야 하는 핀
    const std::bitset<8> actual("10110100");    // 실제로 읽은 상태

    std::println("둘 다 켜짐    {}", (wanted & actual).to_string());
    std::println("하나라도 켜짐 {}", (wanted | actual).to_string());
    std::println("서로 다름     {}", (wanted ^ actual).to_string());
    std::println("안 켜진 것    {}", (wanted & ~actual).to_string());
    std::println("왼쪽으로 2칸  {}", (actual << 2).to_string());

    const auto missing = wanted & ~actual;
    if (missing.any())
        std::println("켜져야 하는데 꺼진 핀이 {}개 있다", missing.count());
}
```

```text
둘 다 켜짐    10110000
하나라도 켜짐 11110100
서로 다름     01000100
안 켜진 것    01000000
왼쪽으로 2칸  11010000
켜져야 하는데 꺼진 핀이 1개 있다
```

`==`로 통째로 견줄 수도 있습니다. 이 연산들은 속에서 워드 단위로 돌기 때문에, 비트를 하나씩 도는 루프보다 훨씬 빠릅니다. 1,000칸짜리 `bitset`의 `&`는 워드 16개의 `&`입니다.

## 크기

```cpp
#include <bitset>
#include <print>

int main()
{
    std::println("bitset<8>    {}바이트", sizeof(std::bitset<8>));
    std::println("bitset<64>   {}바이트", sizeof(std::bitset<64>));
    std::println("bitset<65>   {}바이트", sizeof(std::bitset<65>));
    std::println("bitset<1000> {}바이트", sizeof(std::bitset<1000>));
}
```

```text
bitset<8>    8바이트
bitset<64>   8바이트
bitset<65>   16바이트
bitset<1000> 128바이트
```

GCC 14, 64비트의 결과입니다. `bitset<8>`이 1바이트가 아니라 **8바이트**입니다. 속이 `unsigned long`의 배열이기 때문입니다. 비트 여덟 개를 담으려고 `bitset<8>`을 구조체 멤버로 수천 개 두면 기대의 여덟 배를 씁니다.

## 정수 하나와 고르기

비트가 64개 이하이면 `std::uint8_t`나 `std::uint32_t` 하나에 `&`, `|`, `<<`로 직접 다루는 길도 있습니다.

| | `std::bitset<N>` | 정수와 비트 연산 |
| --- | --- | --- |
| 크기 | 워드 단위로 올림 | 딱 맞게 고른다 (`uint8_t`는 1바이트) |
| 64비트 넘게 | 된다 | 안 된다 |
| 읽기 쉬움 | `pins.set(5)`, `pins.count()` | `pins \|= 1u << 5` |
| 레지스터, 통신 패킷과 주고받기 | `to_ulong()`으로 바꿔야 한다 | 그대로 |
| 범위 검사 | `test`, `set`은 벗어나면 예외 | 없다 |

하드웨어 레지스터의 값이나 패킷의 표시 바이트처럼 **폭이 규격으로 정해진 것**은 그 폭의 정수가 맞고, 세는 일은 [`<bit>`의 `std::popcount`](#/read/cpp-stl/num-bit)가 합니다. 프로그램 안에서만 쓰는 표시의 묶음, 특히 64개가 넘는 것은 `bitset`이 편합니다. [`enum class`로 만든 표시](#/read/cpp-syntax/types-enum)를 첨자로 쓰면 이름이 붙은 표시 집합이 됩니다.

<Note>
`bitset`에는 "켜진 비트만 차례로 도는" 표준 멤버가 없습니다. `for (std::size_t i = 0; i < b.size(); ++i) if (b[i])`로 돕니다. 켜진 것이 드문 큰 묶음에서 이것이 느리면, `std::uint64_t`의 배열에 `std::countr_zero`를 쓰는 편이 빠릅니다.
</Note>

## 정리

- `std::bitset<N>`은 길이가 타입에 정해진 비트 묶음이다. `set`, `reset`, `flip`, `test`, `count`
- `&`, `|`, `^`, `~`가 묶음 전체에 적용된다. 글로 바꾸면 오른쪽 끝이 0번이다
- 속은 워드의 배열이어서 `bitset<8>`도 8바이트다. 폭이 정해진 레지스터 값에는 그 폭의 정수를 쓴다
