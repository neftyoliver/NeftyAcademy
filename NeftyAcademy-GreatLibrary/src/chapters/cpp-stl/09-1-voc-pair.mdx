이름 없이 값을 묶는 타입이 둘 있습니다. `std::pair`는 둘을, `std::tuple`은 몇 개든 묶습니다. 직접 만들어 쓰는 일보다 표준 라이브러리가 돌려주는 것을 **받는** 일이 더 많습니다. [`map`의 원소](#/read/cpp-stl/assoc-map), `insert`의 결과, `minmax`의 결과가 모두 `pair`입니다.

## 만들고 꺼내기

```cpp
#include <print>
#include <string>
#include <tuple>
#include <utility>

std::pair<int, std::string> find_pin() { return {17, "led"}; }

std::tuple<int, std::string, double> read_sensor() { return {3, "temp", 23.5}; }

int main()
{
    const std::pair p = find_pin();
    std::println("{} {}", p.first, p.second);       // pair 는 first 와 second

    const auto t = read_sensor();
    std::println("{} {} {}", std::get<0>(t), std::get<1>(t), std::get<double>(t));

    // 풀어 받는 것이 가장 읽기 좋다
    const auto [channel, name, value] = read_sensor();
    std::println("{} {} {}", channel, name, value);

    int id = 0;
    std::string label;
    std::tie(id, label) = find_pin();               // 이미 있는 변수에 풀어 넣는다
    std::tie(id, std::ignore) = find_pin();         // 쓰지 않을 자리는 ignore
    std::println("{} {}", id, label);
}
```

```text
17 led
3 temp 23.5
3 temp 23.5
17 led
```

| 꺼내는 법 | 쓰는 때 |
| --- | --- |
| `p.first`, `p.second` | `pair`만 |
| `std::get<번호>(t)`, `std::get<타입>(t)` | 번호는 컴파일할 때 정해져야 한다. 타입은 그 타입이 하나뿐일 때 |
| `auto [a, b, c] = t;` | [새 변수로 풀어 받기](#/read/cpp-syntax/types-binding) |
| `std::tie(a, b) = t;` | 이미 있는 변수에 넣기 |

## tie로 견주기

`pair`와 `tuple`은 **앞에서부터 차례로** 견줍니다. 첫째가 같으면 둘째를 봅니다. `std::tie`는 변수들의 참조를 `tuple`로 묶어 주므로, 멤버 여럿으로 순서를 정하는 일이 한 줄이 됩니다.

```cpp
#include <algorithm>
#include <print>
#include <string>
#include <tuple>
#include <vector>

struct Task {
    int priority;
    int deadline;
    std::string name;
};

// 우선순위가 높은 것 먼저, 같으면 마감이 이른 것, 그것도 같으면 이름순
bool before(const Task& a, const Task& b)
{
    return std::tie(b.priority, a.deadline, a.name)
         < std::tie(a.priority, b.deadline, b.name);
}

int main()
{
    std::vector<Task> tasks = {
        {1, 50, "log"}, {5, 30, "motor"}, {5, 10, "brake"}, {1, 50, "blink"},
    };
    std::ranges::sort(tasks, before);
    for (const auto& t : tasks)
        std::print("{} ", t.name);
    std::println("");
}
```

```text
brake motor blink log
```

내림차순으로 볼 멤버는 `a`와 `b`를 **맞바꿔** 적습니다. 위에서 `priority`가 그렇습니다. 손으로 `if (a.priority != b.priority) …`를 겹쳐 쓰다 한 줄을 틀리면 [엄격한 순서의 규칙](#/read/cpp-stl/assoc-compare)이 깨지는데, `tie`로 쓰면 그럴 일이 없습니다. 타입에 순서가 하나로 정해져 있으면 [`operator<=>`를 `= default`](#/read/cpp-syntax/op-compare)로 주는 것이 더 간단합니다.

## apply: 묶어 둔 인자로 부르기

`std::apply(함수, 튜플)`은 튜플을 풀어 함수의 인자로 넘깁니다. 인자를 **담아 두었다가 나중에 부르는** 코드에 씁니다.

```cpp
#include <print>
#include <string>
#include <tuple>

void set_pwm(int channel, double duty, const std::string& note)
{
    std::println("채널 {} 듀티 {:.0f}% ({})", channel, duty * 100, note);
}

int main()
{
    // 지금은 인자만 적어 둔다
    const std::tuple<int, double, std::string> pending = {2, 0.75, "fan"};

    // 나중에, 적어 둔 인자로 부른다
    std::apply(set_pwm, pending);

    // 람다와 함께: 튜플의 원소를 모두 더한다
    const auto sum = std::apply([](auto... values) { return (values + ...); },
                                std::tuple{1, 2.5, 3});
    std::println("{}", sum);
}
```

```text
채널 2 듀티 75% (fan)
6.5
```

[가변 인자 템플릿](#/read/cpp-syntax/tpl-variadic)으로 받은 인자들을 멤버에 보관하려면 `std::tuple<Args...>`에 담고, 쓸 때 `std::apply`로 풉니다. `std::thread`와 `std::bind`가 속에서 하는 일이 이것입니다.

## 크기와 배치

```cpp
#include <print>
#include <tuple>
#include <utility>

int main()
{
    std::println("pair<char, int>        {}", sizeof(std::pair<char, int>));
    std::println("tuple<char, int, char> {}", sizeof(std::tuple<char, int, char>));
    std::println("tuple<int, char, char> {}", sizeof(std::tuple<int, char, char>));
}
```

```text
pair<char, int>        8
tuple<char, int, char> 12
tuple<int, char, char> 8
```

`pair`와 `tuple`도 [채움 바이트](#/read/cpp-syntax/life-alignment)가 들어가는 평범한 구조체입니다. 다만 `tuple`의 원소가 메모리에 어떤 순서로 놓이는지는 구현이 정합니다. GCC는 **뒤의 원소부터** 놓습니다. `tuple`을 통신 패킷이나 파일의 배치로 쓰면 안 되는 까닭입니다. 그런 데에는 멤버 순서가 보장되는 구조체를 씁니다.

## 구조체와 고르기

| | `pair`, `tuple` | 구조체 |
| --- | --- | --- |
| 멤버의 이름 | 없다. `first`, `get<1>` | 있다 |
| 비교, 해시 준비 | 이미 되어 있다 (`<`, `==`) | `= default`로 한 줄 |
| 템플릿에서 "아무 타입 몇 개" | 된다 | 안 된다 |
| 읽는 사람 | `get<2>(t)`가 무엇인지 찾아봐야 한다 | `t.deadline`이라고 읽힌다 |

함수가 값 둘 셋을 돌려줄 때 `tuple`이 먼저 떠오르지만, **이름이 붙을 만한 것이면 구조체**가 낫습니다. `std::pair<int, int>`를 돌려주는 함수는 어느 쪽이 행이고 어느 쪽이 열인지 부르는 쪽이 외워야 합니다. `pair`와 `tuple`은 타입이 템플릿 인자로 정해지는 일반 코드, 그리고 그 자리에서 잠깐 묶었다 푸는 데에 씁니다.

<Note>
`map`에 넣을 원소를 그 자리에서 만들 때, 열쇠와 값이 각각 생성자 인자를 여럿 받으면 `m.emplace(std::piecewise_construct, std::forward_as_tuple(열쇠 인자…), std::forward_as_tuple(값 인자…))`처럼 씁니다. 길어서 눈에 띄는데, 대부분은 [`try_emplace(열쇠, 값 인자…)`](#/read/cpp-stl/assoc-map)로 같은 일이 됩니다.
</Note>

## 정리

- `pair`는 둘, `tuple`은 여럿을 이름 없이 묶는다. 받을 때는 구조적 바인딩으로 푼다
- `std::tie`로 멤버 여럿의 순서 비교를 한 줄로 쓴다. `std::apply`는 묶어 둔 인자로 함수를 부른다
- 이름이 붙을 만한 값의 묶음은 구조체로 만든다. `tuple`의 메모리 배치는 구현이 정한다
