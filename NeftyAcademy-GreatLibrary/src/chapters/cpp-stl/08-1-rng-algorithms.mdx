## 레인지란

**레인지**(range)는 "처음과 끝을 내줄 수 있는 것"입니다. `std::ranges::begin(r)`과 `std::ranges::end(r)`이 되면 레인지입니다.

| 레인지인 것 | 예 |
| --- | --- |
| 컨테이너 | `vector`, `map`, `string` |
| C 배열 | `int a[4]` |
| 빌려 보는 것 | `string_view`, `span` |
| 뷰 | `std::views::iota(1, 5)`, `v \| std::views::filter(…)` |
| 반복자와 끝을 묶은 것 | `std::ranges::subrange(first, last)` |

레인지를 받는 함수는 [콘셉트](#/read/cpp-syntax/con-standard)로 적습니다. "한 번 훑을 수 있는 아무것"이면 `std::ranges::input_range`입니다.

```cpp
#include <array>
#include <list>
#include <print>
#include <ranges>
#include <string_view>
#include <vector>

// 무엇이든 한 번 훑을 수 있으면 받는다
void show(std::string_view label, std::ranges::input_range auto&& values)
{
    std::print("{:8}", label);
    for (const auto& v : values)
        std::print("{} ", v);
    std::println("");
}

int main()
{
    const std::vector<int> v = {1, 2, 3};
    const std::list<double> l = {1.5, 2.5};
    const int c[] = {7, 8};
    show("vector", v);
    show("list", l);
    show("배열", c);
    show("iota", std::views::iota(10, 14));
    show("글자", std::string_view("abc"));
}
```

```text
vector  1 2 3
list    1.5 2.5
배열    7 8
iota    10 11 12 13
글자    a b c
```

`auto&&`로 받는 것이 요령입니다. 컨테이너는 참조로, 그 자리에서 만든 뷰는 임시 객체로 들어옵니다.

## 달라진 네 가지

`std::ranges::`의 알고리즘은 옛 것에 이름공간만 붙인 것이 아닙니다.

| | 옛 알고리즘 | `std::ranges::` |
| --- | --- | --- |
| 넘기는 것 | 반복자 둘 | 레인지 하나 (반복자 둘도 된다) |
| 견줄 것 고르기 | 비교 람다를 쓴다 | 프로젝션을 더 줄 수 있다 |
| 요건이 안 맞을 때 | 라이브러리 속에서 긴 오류 | [문 앞에서 짧은 오류](#/read/cpp-stl/it-category) |
| 끝의 타입 | 처음과 같아야 한다 | [센티널](#/read/cpp-stl/it-sentinel)도 된다 |

없는 것도 있습니다. [실행 정책](#/read/cpp-stl/alg-parallel)을 받지 않고, [`<numeric>`의 알고리즘](#/read/cpp-stl/alg-numeric)은 대부분 옛 꼴뿐입니다.

## 프로젝션

프로젝션은 "원소를 견주거나 검사하기 **전에** 거치는 함수"입니다. 멤버를 가리키는 포인터를 그대로 줄 수 있습니다.

```cpp
#include <algorithm>
#include <cmath>
#include <print>
#include <string>
#include <vector>

struct Device {
    int id;
    std::string name;
    double load;

    bool busy() const { return load > 0.8; }
};

int main()
{
    std::vector<Device> devices = {
        {17, "led", 0.1}, {4, "fan", 0.9}, {22, "camera", 0.95}, {9, "sensor", 0.3},
    };

    std::ranges::sort(devices, {}, &Device::name);              // 멤버 변수로
    for (const auto& d : devices)
        std::print("{} ", d.name);
    std::println("");

    const auto fan = std::ranges::find(devices, 4, &Device::id);    // id 가 4 인 것
    std::println("id 4 -> {}", fan->name);

    const auto heaviest = std::ranges::max_element(devices, {}, &Device::load);
    std::println("가장 바쁜 것 {}", heaviest->name);

    // 멤버 함수도 된다. 조건 자리에 그대로
    std::println("바쁜 것 {}개", std::ranges::count_if(devices, &Device::busy));

    // 람다도 된다: 부하가 0.5 에 가까운 순서로
    std::ranges::sort(devices, {},
                      [](const Device& d) { return std::abs(d.load - 0.5); });
    std::println("부하가 0.5 에 가장 가까운 것 {}", devices.front().name);
}
```

```text
camera fan led sensor
id 4 -> fan
가장 바쁜 것 camera
바쁜 것 2개
부하가 0.5 에 가장 가까운 것 sensor
```

옛 방식으로 같은 일을 하면 줄마다 `[](const Device& a, const Device& b) { return a.name < b.name; }` 같은 람다를 씁니다. 길기도 하지만 `a`와 `b`를 한쪽만 바꿔 쓰는 실수가 생깁니다. 프로젝션은 **무엇으로 견줄지**와 **어떻게 견줄지**를 나눠 적게 해 줍니다. 비교 자리의 `{}`는 "기본 비교 그대로"입니다.

`find`의 프로젝션은 특히 쓸모가 있습니다. `find(devices, 4, &Device::id)`는 "원소에서 `id`를 꺼낸 것이 4와 같은 것"입니다. 돌려주는 것은 여전히 **원소**의 반복자입니다.

## 결과를 컨테이너로 모으기

C++23의 `std::ranges::to`는 레인지의 원소로 컨테이너를 만듭니다. 뷰로 걸러 낸 결과를 `vector`로 굳힐 때 씁니다.

```cpp
#include <map>
#include <print>
#include <ranges>
#include <set>
#include <string>
#include <vector>

int main()
{
    const std::vector<int> readings = {41, 73, 12, 98, 55, 73, 12};

    // 원소 타입은 추론하게 두고 컨테이너의 종류만 적는다
    const auto unique = readings | std::ranges::to<std::set>();
    const auto doubled = readings
                       | std::views::transform([](int r) { return r * 2; })
                       | std::ranges::to<std::vector>();
    std::println("{}개 가운데 서로 다른 것 {}개", readings.size(), unique.size());
    std::println("{} {}", doubled.front(), doubled.back());

    const std::map<std::string, int> pins = {{"led", 17}, {"fan", 4}};
    const auto names = pins | std::views::keys | std::ranges::to<std::vector>();
    std::println("{} {}", names[0], names[1]);
}
```

```text
7개 가운데 서로 다른 것 5개
82 24
fan led
```

`std::ranges::to<std::vector>()`는 GCC 14에서 됩니다. 컨테이너 쪽에서 레인지를 받는 `v.append_range(r)`, `std::vector<int> v(std::from_range, r)`도 C++23에 들어왔지만 이것은 GCC 15부터입니다.

<Note kind="warn">
레인지 알고리즘에 **임시 컨테이너**를 넘기면 돌려받은 반복자를 쓸 수 없습니다. `std::ranges::find(make_vector(), 3)`은 컴파일되지만, 결과를 `*`로 읽으려는 순간 오류가 납니다. 컨테이너가 이미 사라졌기 때문에 일부러 막아 둔 것입니다. [「댕글링과 빌린 레인지」](#/read/cpp-stl/rng-dangling)에서 봅니다.
</Note>

## 정리

- 레인지는 처음과 끝을 내줄 수 있는 것이다. 받는 함수는 `std::ranges::input_range auto&&`로 적는다
- 프로젝션으로 "무엇으로 견줄지"를 따로 적는다. 멤버를 가리키는 포인터를 그대로 넘긴다
- `std::ranges::to`로 레인지를 컨테이너로 굳힌다. 실행 정책과 수치 알고리즘은 아직 옛 꼴을 쓴다
