`std::stack`과 `std::queue`는 스스로 원소를 담지 않습니다. 다른 컨테이너를 속에 두고, 그 인터페이스 가운데 **몇 개만** 밖으로 내놓습니다. 이런 것을 컨테이너 어댑터라고 합니다. 할 수 있는 일을 일부러 줄여서, "이것은 스택으로만 쓴다"는 뜻을 타입으로 말합니다.

| | `stack` | `queue` |
| --- | --- | --- |
| 넣기 | `push` | `push` |
| 다음에 나올 것 보기 | `top()` | `front()` |
| 빼기 | `pop()` | `pop()` |
| 나오는 순서 | 나중에 넣은 것이 먼저 | 먼저 넣은 것이 먼저 |

둘 다 `empty()`와 `size()`가 있고, **반복자가 없습니다.** 가운데를 보거나 차례로 돌 수 없습니다.

## stack: 괄호 짝 맞추기

"가장 최근에 연 것을 먼저 닫는다"는 구조가 스택입니다.

```cpp
#include <print>
#include <stack>
#include <string_view>

bool balanced(std::string_view text)
{
    std::stack<char> open;
    for (char c : text) {
        if (c == '(' || c == '[' || c == '{') {
            open.push(c);
        } else if (c == ')' || c == ']' || c == '}') {
            if (open.empty())
                return false;               // 닫는데 열린 것이 없다
            const char expected = c == ')' ? '(' : c == ']' ? '[' : '{';
            if (open.top() != expected)
                return false;               // 짝이 다르다
            open.pop();
        }
    }
    return open.empty();                    // 닫지 않은 것이 남았는가
}

int main()
{
    for (std::string_view text : {"{a[0] = f(x);}", "(]", "((", ")"})
        std::println("{:16} {}", text, balanced(text));
}
```

```text
{a[0] = f(x);}   true
(]               false
((               false
)                false
```

`pop()`은 **아무것도 돌려주지 않습니다.** 값을 보려면 `top()`, 빼려면 `pop()`으로 두 번에 나눠 부릅니다. 하나로 합쳐 "빼면서 돌려주기"로 만들면, 돌려주는 값을 복사하다 예외가 났을 때 원소가 이미 빠져 사라지기 때문입니다. 빈 스택에 `top()`이나 `pop()`을 부르는 것은 정의되지 않은 동작이므로 `empty()`를 먼저 봅니다.

## queue: 너비 우선 탐색

"먼저 발견한 곳부터 차례로 처리한다"가 큐입니다. 격자 지도에서 가장 짧은 길의 걸음 수를 구하는 너비 우선 탐색이 대표적인 쓰임입니다.

```cpp
#include <array>
#include <print>
#include <queue>
#include <string_view>
#include <vector>

constexpr std::array<std::string_view, 5> grid = {
    "S..#....",
    ".#.#.##.",
    ".#...#..",
    ".####.#.",
    "......#G",
};

int shortest_steps()
{
    struct Cell {
        int row;
        int col;
        int steps;
    };
    const int rows = static_cast<int>(grid.size());
    const int cols = static_cast<int>(grid[0].size());
    std::vector<char> visited(grid.size() * grid[0].size());
    std::queue<Cell> frontier;
    frontier.push({0, 0, 0});
    visited[0] = true;

    while (!frontier.empty()) {
        const Cell here = frontier.front();     // 가장 먼저 넣은 칸
        frontier.pop();
        if (grid[here.row][here.col] == 'G')
            return here.steps;
        constexpr int moves[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        for (const auto& move : moves) {
            const int r = here.row + move[0];
            const int c = here.col + move[1];
            if (r < 0 || r >= rows || c < 0 || c >= cols || grid[r][c] == '#')
                continue;
            if (visited[r * cols + c])
                continue;
            visited[r * cols + c] = true;
            frontier.push({r, c, here.steps + 1});
        }
    }
    return -1;      // 갈 수 없다
}

int main()
{
    std::println("가장 짧은 길: {}걸음", shortest_steps());
}
```

```text
가장 짧은 길: 15걸음
```

큐에서는 가까운 칸이 먼저 나오므로, 목적지를 처음 만났을 때의 걸음 수가 가장 짧은 길입니다. 같은 코드에서 `queue`를 `stack`으로 바꾸면 깊이 우선 탐색이 되고, 길은 찾지만 가장 짧다는 보장이 사라집니다.

## 속의 컨테이너 고르기

둘째 템플릿 인자가 속에 둘 컨테이너이고, 기본값은 둘 다 [`deque`](#/read/cpp-stl/seq-deque)입니다.

```cpp
#include <deque>
#include <list>
#include <print>
#include <queue>
#include <stack>
#include <utility>
#include <vector>

int main()
{
    using VectorStack = std::stack<int, std::vector<int>>;
    std::println("stack<int>              {}바이트", sizeof(std::stack<int>));
    std::println("stack<int, vector<int>> {}바이트", sizeof(VectorStack));

    std::vector<int> storage;
    // 자리를 미리 잡은 vector 를
    storage.reserve(1000);
    std::stack<int, std::vector<int>> fast(std::move(storage));     // 속으로 넘긴다
    fast.push(1);
    fast.emplace(2);
    std::println("top {} size {}", fast.top(), fast.size());

    // 넣을 때 시간이 튀지 않는 큐
    std::queue<int, std::list<int>> steady;
    steady.push(1);
    std::println("front {}", steady.front());
}
```

```text
stack<int>              80바이트
stack<int, vector<int>> 24바이트
top 2 size 2
front 1
```

| 어댑터 | 속에 둘 수 있는 것 | 권하는 것 |
| --- | --- | --- |
| `stack` | `deque`, `vector`, `list` | `vector`. 한쪽 끝만 쓰므로 가장 가볍다 |
| `queue` | `deque`, `list` | 대개 `deque` 그대로 |

`stack`은 뒤에만 넣고 빼므로 `vector`로 충분합니다. GCC의 `deque`는 [비어 있어도 576바이트를 잡고](#/read/cpp-stl/seq-deque) 시작하므로, 스택을 많이 만드는 코드에서는 차이가 납니다. `queue`는 앞에서 빼야 해서 `vector`를 쓸 수 없습니다.

<Note>
이 둘은 스레드 사이에서 그대로 쓸 수 없습니다. 한 스레드가 넣고 다른 스레드가 빼는 작업 큐는 잠금과 조건 변수를 더해야 하고 [「mutex와 lock」](#/read/cpp-stl/conc-mutex)에서 만듭니다. 길이가 정해진 큐가 필요한 작은 기기에서는 할당이 없는 [링 버퍼](#/read/cpp-syntax/tpl-nontype)가 더 맞습니다.
</Note>

## 정리

- `stack`과 `queue`는 다른 컨테이너를 감싸 넣기, 보기, 빼기만 남긴 어댑터다. 돌 수 없다
- `pop()`은 값을 돌려주지 않는다. `top()`이나 `front()`로 보고 나서 뺀다. 비었는지 먼저 본다
- 속의 컨테이너는 둘째 인자로 바꾼다. `stack`에는 `vector`가 가볍다
