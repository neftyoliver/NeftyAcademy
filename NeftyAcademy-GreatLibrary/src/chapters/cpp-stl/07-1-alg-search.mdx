`<algorithm>`의 알고리즘은 백 개가 넘지만 몇 갈래로 나뉩니다. 첫 갈래는 범위를 **읽기만** 하는 것들입니다. 찾고, 세고, 묻습니다. 이 장의 예제는 컨테이너를 통째로 받는 `std::ranges::` 쪽으로 씁니다. `std::ranges::find(v, x)`는 `std::find(v.begin(), v.end(), x)`와 같은 일을 합니다.

## 찾기, 세기, 묻기

```cpp
#include <algorithm>
#include <print>
#include <vector>

int main()
{
    const std::vector<double> temps = {21.5, 22.0, 22.1, 35.7, 22.3, 22.3, 21.9};
    const auto too_hot = [](double t) { return t > 30.0; };

    // 찾기: 반복자를 돌려준다. 못 찾으면 end()
    if (const auto it = std::ranges::find_if(temps, too_hot); it != temps.end())
        std::println("처음 30도를 넘은 것: {}번째, {}", it - temps.begin(), *it);

    // 세기
    std::println("22.3인 것 {}개, 22도 미만 {}개", std::ranges::count(temps, 22.3),
                 std::ranges::count_if(temps, [](double t) { return t < 22.0; }));

    // 묻기: bool
    std::println("하나라도 뜨거운가 {}", std::ranges::any_of(temps, too_hot));
    std::println("모두 뜨거운가 {}", std::ranges::all_of(temps, too_hot));
    std::println("뜨거운 것이 없는가 {}", std::ranges::none_of(temps, too_hot));
    // C++23
    std::println("22.0이 있는가 {}", std::ranges::contains(temps, 22.0));

    // 가장 작은 것과 큰 것
    const auto [coldest, hottest] = std::ranges::minmax_element(temps);
    std::println("최저 {} ({}번째)", *coldest, coldest - temps.begin());
    std::println("최고 {} ({}번째)", *hottest, hottest - temps.begin());
}
```

```text
처음 30도를 넘은 것: 3번째, 35.7
22.3인 것 2개, 22도 미만 2개
하나라도 뜨거운가 true
모두 뜨거운가 false
뜨거운 것이 없는가 false
22.0이 있는가 true
최저 21.5 (0번째)
최고 35.7 (3번째)
```

| 알고리즘 | 돌려주는 것 |
| --- | --- |
| `find(값)`, `find_if(조건)`, `find_if_not(조건)` | 처음 맞는 원소의 반복자. 없으면 `end()` |
| `count(값)`, `count_if(조건)` | 개수 |
| `all_of`, `any_of`, `none_of` | `bool` |
| `min_element`, `max_element`, `minmax_element` | 반복자. 값이 아니라 **자리**를 준다 |
| `min`, `max`, `minmax` | 값 |

읽을 것이 셋 있습니다.

- 찾기의 결과는 **쓰기 전에** `end()`와 견줍니다. `*std::ranges::find(v, x)`를 바로 쓰면 없을 때 정의되지 않은 동작입니다.
- 빈 범위에서 `all_of`와 `none_of`는 `true`, `any_of`는 `false`입니다. "모두 통과했다"가 "아무것도 검사하지 않았다"일 수 있습니다. 비어 있을 수 있는 범위라면 `empty()`를 따로 봅니다.
- 실수를 `==`로 찾는 `find(22.3)`과 `count(22.3)`은 값이 **정확히** 같을 때만 맞습니다. 계산을 거친 실수에는 `find_if`로 허용 범위를 줍니다.

<Note>
[`map`, `set`](#/read/cpp-stl/assoc-map), [`unordered_map`](#/read/cpp-stl/assoc-unordered)에서 열쇠를 찾을 때는 이 알고리즘이 아니라 **멤버** `find`, `contains`를 씁니다. 알고리즘은 처음부터 하나씩 견주는 O(n)이고, 멤버는 구조를 써서 O(log n)이나 O(1)입니다.
</Note>

## 무늬 찾기

원소 하나가 아니라 **이어진 몇 개**를 찾는 것이 `search`입니다. 수신 버퍼에서 프레임의 시작 표시를 찾는 일이 그 쓰임입니다.

```cpp
#include <algorithm>
#include <array>
#include <cstdint>
#include <print>
#include <vector>

int main()
{
    const std::vector<std::uint8_t> stream = {0x00, 0x13, 0xAA, 0x55,
                                              0x03, 0x10, 0x20, 0x30};
    const std::array<std::uint8_t, 2> marker = {0xAA, 0x55};

    // 맞은 구간을 돌려준다
    const auto found = std::ranges::search(stream, marker);
    if (!found.empty()) {
        const auto index = found.begin() - stream.begin();
        std::println("시작 표시: {}번째부터 {}바이트", index, found.size());
    }

    // 같은 값이 연달아 나오는 첫 자리 (센서가 멈췄는가)
    const std::vector<int> readings = {512, 514, 513, 513, 513, 520};
    const auto stuck = std::ranges::adjacent_find(readings);
    std::println("같은 값이 이어지는 곳: {}번째", stuck - readings.begin());

    // 여러 후보 가운데 아무거나 처음 나오는 자리
    const std::vector<char> line = {'k', 'e', 'y', ' ', '=', ' ', '1'};
    const std::array separators = {'=', ':'};
    const auto sep = std::ranges::find_first_of(line, separators);
    std::println("구분자: {}번째", sep - line.begin());
}
```

```text
시작 표시: 2번째부터 2바이트
같은 값이 이어지는 곳: 2번째
구분자: 4번째
```

`std::ranges::search`는 반복자 하나가 아니라 **맞은 구간**을 돌려줍니다. 못 찾으면 빈 구간입니다. 글자를 찾을 때는 [`std::string_view`의 찾기 멤버](#/read/cpp-stl/str-string)가 같은 일을 더 편하게 합니다.

## 두 범위 견주기

```cpp
#include <algorithm>
#include <print>
#include <vector>

int main()
{
    const std::vector<int> expected = {1, 2, 3, 4, 5};
    const std::vector<int> actual = {1, 2, 9, 4, 5};

    std::println("같은가 {}", std::ranges::equal(expected, actual));

    const auto [in_expected, in_actual] = std::ranges::mismatch(expected, actual);
    if (in_expected != expected.end()) {
        const auto index = in_expected - expected.begin();
        std::println("{}번째에서 갈린다", index);
        std::println("기대 {}, 실제 {}", *in_expected, *in_actual);
    }

    // 조건을 주어 견준다: 차이가 1 이하이면 같다고 본다
    const std::vector<int> noisy = {1, 3, 3, 3, 6};
    const auto close = [](int a, int b) { return a - b <= 1 && b - a <= 1; };
    std::println("거의 같은가 {}", std::ranges::equal(expected, noisy, close));
}
```

```text
같은가 false
2번째에서 갈린다
기대 3, 실제 9
거의 같은가 true
```

`mismatch`는 처음으로 다른 자리를 양쪽 범위에서 하나씩, 반복자 둘로 돌려줍니다. 테스트에서 "어디가 다른지"를 알려 줄 때, 설정 두 벌의 차이를 찾을 때 씁니다.

<Note kind="warn">
옛 `std::equal(a.begin(), a.end(), b.begin())`처럼 둘째 범위의 **끝을 주지 않는** 꼴이 있습니다. `b`가 더 짧으면 `b`의 끝을 넘어 읽습니다. 반복자 넷을 다 넘기거나 `std::ranges::equal(a, b)`를 씁니다. 길이가 다르면 바로 `false`입니다.
</Note>

## 정리

- 찾기는 반복자를, 세기는 개수를, 묻기는 `bool`을 준다. 찾은 반복자는 `end()`와 견준 뒤에 쓴다
- 빈 범위에서 `all_of`는 참이다. 실수는 `==`가 아니라 조건으로 찾는다
- 이어진 무늬는 `search`, 두 범위의 차이는 `mismatch`. 연관 컨테이너에서는 멤버 `find`를 쓴다
