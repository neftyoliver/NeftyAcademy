둘째 갈래는 범위의 **내용을 바꾸는** 알고리즘입니다. 이 갈래를 쓸 때 늘 떠올릴 것이 하나 있습니다. [알고리즘은 칸의 개수를 바꾸지 못합니다.](#/read/cpp-stl/ov-parts) 쓰는 쪽은 받을 자리를 마련해 줘야 하고, "지우는" 알고리즘은 사실 지우지 않습니다.

## 복사와 변형

```cpp
#include <algorithm>
#include <cstdint>
#include <iterator>
#include <print>
#include <vector>

int main()
{
    // 12비트 ADC
    const std::vector<std::uint16_t> raw = {0, 1024, 2048, 3072, 4095};

    // 변형: 원소마다 함수를 적용한 결과를 다른 곳에 쓴다
    std::vector<double> volts(raw.size());                  // 받을 칸을 먼저 만든다
    std::ranges::transform(raw, volts.begin(),
                           [](std::uint16_t r) { return r * 3.3 / 4095; });
    for (double v : volts)
        std::print("{:.2f} ", v);
    std::println("");

    // 두 범위를 짝지어 변형한다
    const std::vector<double> offsets = {0.01, 0.01, 0.02, 0.02, 0.03};
    std::ranges::transform(volts, offsets, volts.begin(),
                           [](double v, double o) { return v - o; });

    // 조건에 맞는 것만 복사: 몇 개가 될지 모르므로 back_inserter
    std::vector<double> high;
    std::ranges::copy_if(volts, std::back_inserter(high),
                         [](double v) { return v > 1.5; });
    std::println("1.5V 를 넘는 것 {}개", high.size());

    // 채우기와 바꾸기
    std::vector<int> buffer(6);
    std::ranges::fill(buffer, -1);
    std::ranges::generate(buffer, [n = 0]() mutable { return n++ * 10; });
    std::ranges::replace(buffer, 30, 33);
    for (int b : buffer)
        std::print("{} ", b);
    std::println("");
}
```

```text
0.00 0.83 1.65 2.48 3.30
1.5V 를 넘는 것 3개
0 10 20 33 40 50
```

| 알고리즘 | 하는 일 |
| --- | --- |
| `copy`, `copy_if`, `copy_n` | 다른 곳에 복사한다 |
| `move` | 다른 곳으로 옮긴다 (원소마다 `std::move`) |
| `transform` | 함수를 적용한 결과를 쓴다. 제자리에도 된다 |
| `fill`, `generate` | 같은 값으로, 함수가 내는 값으로 채운다 |
| `replace`, `replace_if` | 값이나 조건이 맞는 원소를 새 값으로 바꾼다 |
| `reverse`, `shuffle` | 뒤집는다, 무작위로 섞는다 |

출력 쪽에 **칸이 있어야 한다**는 것이 이 갈래의 첫 규칙입니다. 개수를 알면 위의 `volts`처럼 미리 만들고, 모르면 [`std::back_inserter`](#/read/cpp-stl/it-adaptors)를 씁니다.

## remove와 unique는 지우지 않는다

`std::remove`는 남길 원소를 앞으로 당겨 모으고, **남길 것이 끝나는 자리**를 돌려줍니다. 컨테이너의 크기는 그대로입니다.

```cpp
#include <algorithm>
#include <print>
#include <vector>

void show(const char* label, const std::vector<int>& v)
{
    std::print("{:22}", label);
    for (int x : v)
        std::print("{} ", x);
    std::println("(size {})", v.size());
}

int main()
{
    std::vector<int> v = {3, 0, 1, 0, 0, 4};

    const auto tail = std::ranges::remove(v, 0);    // 버릴 꼬리 구간을 돌려준다
    show("remove 뒤", v);
    v.erase(tail.begin(), tail.end());              // 꼬리를 실제로 지운다
    show("erase 뒤", v);

    std::vector<int> w = {3, 0, 1, 0, 0, 4};
    std::erase(w, 0);                               // C++20: 위의 둘을 한 번에
    show("std::erase", w);

    // 겹친 것 없애기: 정렬해서 같은 것을 이웃하게 만든 뒤 unique
    std::vector<int> ids = {7, 3, 7, 1, 3, 7};
    std::ranges::sort(ids);
    const auto duplicates = std::ranges::unique(ids);   // 이웃한 같은 것을 하나로
    ids.erase(duplicates.begin(), duplicates.end());
    show("sort, unique, erase", ids);
}
```

```text nocheck
remove 뒤             3 1 4 0 0 4 (size 6)
erase 뒤              3 1 4 (size 3)
std::erase            3 1 4 (size 3)
sort, unique, erase   1 3 7 (size 3)
```

`remove` 뒤의 `0 0 4`는 **버려진 꼬리**입니다. 그 자리에 무엇이 남는지는 정해져 있지 않고(위는 GCC 14의 결과), 쓰면 안 됩니다. `erase`를 빼먹으면 지운 줄 알았던 원소가 그대로 남은 컨테이너를 들고 다니게 됩니다.

| 하려는 일 | C++20부터 | 그 전 |
| --- | --- | --- |
| 값이 같은 것 지우기 | `std::erase(v, 값)` | `v.erase(std::remove(…), v.end())` |
| 조건에 맞는 것 지우기 | `std::erase_if(v, 조건)` | `v.erase(std::remove_if(…), v.end())` |
| 겹친 것 지우기 | `sort`, `unique`, `erase` | 같다 |

새 코드에서는 `std::erase`와 `std::erase_if`를 씁니다. 모든 표준 컨테이너에 있고, 컨테이너마다 맞는 방법으로 지웁니다. `unique`는 **이웃한** 같은 것만 하나로 줄이므로 먼저 정렬해야 합니다. 순서를 지키면서 겹친 것을 빼려면 본 것을 [`set`](#/read/cpp-stl/assoc-map)에 적어 가며 `erase_if`합니다.

## 나누기와 돌리기

```cpp
#include <algorithm>
#include <print>
#include <vector>

void show(const char* label, const std::vector<int>& v)
{
    std::print("{:18}", label);
    for (int x : v)
        std::print("{} ", x);
    std::println("");
}

int main()
{
    std::vector<int> v = {1, 2, 3, 4, 5, 6, 7, 8};

    // 조건에 맞는 것을 앞으로 모은다. 양쪽 모두 원래 순서를 지킨다
    const auto is_even = [](int x) { return x % 2 == 0; };
    const auto rest = std::ranges::stable_partition(v, is_even);
    show("stable_partition", v);
    std::println("짝수가 아닌 것은 {}번째부터", rest.begin() - v.begin());

    // 돌리기: 가운데로 지정한 원소가 맨 앞에 오게 한다
    std::vector<int> w = {1, 2, 3, 4, 5, 6};
    std::ranges::rotate(w, w.begin() + 2);
    show("rotate", w);

    // 구간 하나를 다른 자리로 옮기는 것도 rotate 한 번이다: [1, 3) 을 뒤로
    std::vector<int> u = {1, 2, 3, 4, 5, 6};
    std::rotate(u.begin() + 1, u.begin() + 3, u.end());
    show("2 3 을 맨 뒤로", u);
}
```

```text
stable_partition  2 4 6 8 1 3 5 7
짝수가 아닌 것은 4번째부터
rotate            3 4 5 6 1 2
2 3 을 맨 뒤로    1 4 5 6 2 3
```

| 알고리즘 | 하는 일 |
| --- | --- |
| `partition` | 조건에 맞는 것을 앞으로. 순서는 지키지 않는다. 제자리에서 O(n) |
| `stable_partition` | 같은 일을 순서를 지키며. 임시 버퍼를 쓴다 |
| `rotate(처음, 가운데, 끝)` | `[처음, 가운데)`와 `[가운데, 끝)`의 자리를 맞바꾼다 |

`rotate`는 쓸모에 견주어 덜 알려진 알고리즘입니다. "목록에서 고른 항목을 위로 올린다", "버퍼의 앞부분을 처리했으니 남은 것을 앞으로 당긴다" 같은 일이 지우고 다시 넣는 대신 `rotate` 한 번으로 됩니다.

<Note kind="warn">
같은 컨테이너 안에서 겹치는 구간으로 `copy`를 할 때는 방향을 봅니다. 목적지가 원본의 **뒤쪽**에 겹치면 앞에서부터 복사하다가 아직 읽지 않은 원소를 덮어씁니다. 그때는 뒤에서부터 복사하는 `copy_backward`를 쓰거나, 옮기려는 것이 구간 이동이면 `rotate`를 씁니다.
</Note>

## 정리

- 쓰는 알고리즘에는 받을 칸을 먼저 마련한다. 개수를 모르면 `back_inserter`
- `remove`와 `unique`는 남길 것을 앞으로 모을 뿐이다. 새 코드에서는 `std::erase`, `std::erase_if`를 쓴다
- 조건으로 나누기는 `partition`, 구간 옮기기는 `rotate`
