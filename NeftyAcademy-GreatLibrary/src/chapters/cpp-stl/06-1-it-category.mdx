[「컨테이너, 반복자, 알고리즘」](#/read/cpp-stl/ov-parts)에서 `std::sort`가 `std::list`에는 쓸 수 없다는 것을 보았습니다. 반복자가 모두 같은 일을 할 수 있는 것은 아니기 때문입니다. 할 수 있는 일에 따라 등급이 나뉘고, 그것을 **범주**라고 합니다.

## 여섯 범주

| 범주 | 더해지는 능력 | 주는 것 |
| --- | --- | --- |
| 입력 | `*it`로 읽기, `++it`. **한 번만** 지나간다 | `istream_iterator` |
| 전진 | 같은 곳을 여러 번 지나가도 된다 | `forward_list`, `unordered_map` |
| 양방향 | `--it`로 뒤로 | `list`, `map`, `set` |
| 임의 접근 | `it + n`, `it2 - it1`, `it[n]`, `<` | `deque` |
| 연속 | 원소가 메모리에 줄지어 있다 | `vector`, `array`, `string`, `span`, 포인터 |
| 출력 | `*it = 값`으로 쓰기만 | `back_inserter`, `ostream_iterator` |

입력에서 연속까지는 층층이 쌓입니다. 연속 반복자는 임의 접근 반복자이기도 하고, 양방향이기도 합니다. 출력은 따로 있는 축입니다.

C++20은 이 범주를 [콘셉트](#/read/cpp-syntax/con-standard)로 만들었습니다. 타입에게 직접 물어볼 수 있습니다.

```cpp
#include <array>
#include <deque>
#include <forward_list>
#include <iterator>
#include <list>
#include <map>
#include <print>
#include <sstream>
#include <unordered_map>
#include <vector>

template <typename It>
const char* category_of()
{
    if (std::contiguous_iterator<It>)
        return "연속";
    if (std::random_access_iterator<It>)
        return "임의 접근";
    if (std::bidirectional_iterator<It>)
        return "양방향";
    if (std::forward_iterator<It>)
        return "전진";
    if (std::input_iterator<It>)
        return "입력";
    return "?";
}

int main()
{
    using ForwardList = std::forward_list<int>;
    using HashMap = std::unordered_map<int, int>;
    std::println("vector        {}", category_of<std::vector<int>::iterator>());
    std::println("int*          {}", category_of<int*>());
    std::println("deque         {}", category_of<std::deque<int>::iterator>());
    std::println("list          {}", category_of<std::list<int>::iterator>());
    std::println("map           {}", category_of<std::map<int, int>::iterator>());
    std::println("forward_list  {}", category_of<ForwardList::iterator>());
    std::println("unordered_map {}", category_of<HashMap::iterator>());
    std::println("istream       {}", category_of<std::istream_iterator<int>>());
}
```

```text
vector        연속
int*          연속
deque         임의 접근
list          양방향
map           양방향
forward_list  전진
unordered_map 전진
istream       입력
```

## 알고리즘이 바라는 범주

알고리즘마다 필요한 최소 범주가 있습니다.

| 알고리즘 | 바라는 범주 | 까닭 |
| --- | --- | --- |
| `find`, `count`, `copy`, `accumulate` | 입력 | 앞에서부터 한 번 훑으면 된다 |
| `replace`, `unique`, `rotate`, `search` | 전진 | 지나간 자리로 돌아와 다시 본다 |
| `reverse`, `copy_backward` | 양방향 | 뒤에서 앞으로 온다 |
| `sort`, `nth_element`, `shuffle` | 임의 접근 | 멀리 떨어진 칸을 바로 견주고 바꾼다 |

모자라는 반복자를 넘기면 컴파일되지 않습니다. 그때 무슨 말을 듣는지는 옛 알고리즘과 레인지 알고리즘이 크게 다릅니다.

```cpp nocheck
std::list<int> values = {3, 1, 2};
std::sort(values.begin(), values.end());    // 옛 알고리즘
std::ranges::sort(values);                  // 레인지 알고리즘
```

## 범주에 따라 달라지는 값

`std::next`, `std::advance`, `std::distance`는 모든 범주에서 쓸 수 있지만 값이 다릅니다. 임의 접근이면 덧셈 한 번, 아니면 한 칸씩 걷습니다.

```cpp
#include <iterator>
#include <list>
#include <print>
#include <ranges>
#include <vector>

// 어떤 범위든 받아 가운데 원소를 돌려준다
template <std::ranges::forward_range Range>
auto middle(Range& range)
{
    // list 면 끝까지 걸어서 센다
    const auto half = std::ranges::distance(range) / 2;
    return std::ranges::next(std::ranges::begin(range), half);
}

int main()
{
    std::vector<int> v = {1, 2, 3, 4, 5};
    std::list<int> l = {1, 2, 3, 4, 5};
    std::println("{} {}", *middle(v), *middle(l));

    auto it = l.begin();
    // 세 칸 걷는다. it + 3 은 list 에서 컴파일되지 않는다
    std::advance(it, 3);
    std::println("{} {}", *it, *std::prev(it));
}
```

```text
3 3
4 3
```

같은 `middle`이 `vector`에서는 O(1)이고 `list`에서는 O(n)입니다. 템플릿은 두 경우에 저마다 맞는 코드를 만들어 냅니다. `list`에서 `it + 3`이라고 쓸 수 없게 해 둔 것은, 비싼 일이 싼 것처럼 보이지 않게 하려는 설계입니다.

<Note>
범주는 **값**이 아니라 **할 수 있는 일**의 약속입니다. [`deque`](#/read/cpp-stl/seq-deque)의 반복자는 임의 접근이지만 `vector`의 것보다 느리고, 원소가 줄지어 있지 않아서 연속은 아닙니다. 포인터와 길이를 받는 C 함수에 넘길 수 있는 것은 연속 범주뿐입니다.
</Note>

## 정리

- 반복자는 입력, 전진, 양방향, 임의 접근, 연속으로 등급이 오르고, 출력은 따로다
- 알고리즘은 필요한 최소 범주를 요구한다. 레인지 알고리즘은 모자랄 때 그 까닭을 말해 준다
- `std::next`, `std::distance`는 어디서나 되지만 임의 접근이 아니면 O(n)이다
