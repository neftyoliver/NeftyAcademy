## accumulate와 초깃값

`std::accumulate(처음, 끝, 초깃값)`은 초깃값에 원소를 차례로 더합니다. 넷째 인자로 더하기 대신 할 일을 줄 수 있습니다.

```cpp
#include <functional>
#include <numeric>
#include <print>
#include <string>
#include <vector>

int main()
{
    const std::vector<double> h = {0.5, 0.5, 0.5, 0.5};
    std::println("초깃값 0   -> {}", std::accumulate(h.begin(), h.end(), 0));
    std::println("초깃값 0.0 -> {}", std::accumulate(h.begin(), h.end(), 0.0));

    const std::vector<int> big = {2'000'000'000, 2'000'000'000};
    std::println("초깃값 0LL -> {}", std::accumulate(big.begin(), big.end(), 0LL));

    const std::vector<int> f = {2, 3, 7};
    const int product = std::accumulate(f.begin(), f.end(), 1, std::multiplies{});
    std::println("곱 {}", product);

    const std::vector<std::string> words = {"gpio", "17", "high"};
    const std::string joined =
        std::accumulate(words.begin(), words.end(), std::string{},
                        [](std::string acc, const std::string& w) {
                            return acc.empty() ? w : std::move(acc) + "," + w;
                        });
    std::println("{}", joined);
}
```

```text
초깃값 0   -> 0
초깃값 0.0 -> 2
초깃값 0LL -> 4000000000
곱 42
gpio,17,high
```

첫 줄이 그 함정입니다. **결과의 타입은 원소가 아니라 초깃값이 정합니다.** `0`은 `int`이므로 0.5를 더할 때마다 소수점 아래가 버려져 끝까지 0입니다. 경고도 없습니다. `double`의 합에는 `0.0`, 큰 정수의 합에는 `0LL`을 줍니다. 셋째 줄에서 `0`을 주었다면 `int`가 넘쳐 정의되지 않은 동작이 됩니다.

C++23의 `std::ranges::fold_left`가 같은 일을 범위로 받습니다. 초깃값의 규칙도 같습니다.

## 평균과 분산

```cpp
#include <cmath>
#include <functional>
#include <numeric>
#include <print>
#include <vector>

int main()
{
    const std::vector<double> samples = {21.5, 22.0, 22.1, 21.8, 22.6};
    const double n = static_cast<double>(samples.size());

    const double mean = std::accumulate(samples.begin(), samples.end(), 0.0) / n;

    // transform_reduce: 원소마다 계산한 값을 더한다 (여기서는 편차의 제곱)
    const double squares = std::transform_reduce(
        samples.begin(), samples.end(), 0.0, std::plus{},
        [mean](double x) { return (x - mean) * (x - mean); });
    const double deviation = std::sqrt(squares / n);
    std::println("평균 {:.2f}, 표준편차 {:.3f}", mean, deviation);

    // inner_product: 두 범위를 짝지어 곱한 것의 합 (가중 평균)
    const std::vector<double> weights = {0.1, 0.1, 0.2, 0.2, 0.4};
    const double weighted =
        std::inner_product(samples.begin(), samples.end(), weights.begin(), 0.0);
    std::println("가중 평균 {:.2f}", weighted);
}
```

```text
평균 22.00, 표준편차 0.363
가중 평균 22.17
```

| 알고리즘 | 계산하는 것 |
| --- | --- |
| `accumulate(범위, 초깃값, 연산)` | 왼쪽부터 차례로 접는다 |
| `reduce(범위, 초깃값, 연산)` | 같은 일을 **순서를 정하지 않고**. [병렬로 돌릴 수 있다](#/read/cpp-stl/alg-parallel) |
| `transform_reduce(범위, 초깃값, 합치기, 바꾸기)` | 원소를 바꾼 뒤 접는다 |
| `inner_product(범위1, 범위2, 초깃값)` | 짝지어 곱한 것의 합 |

`reduce`는 순서를 바꿔 더해도 되는 연산(정수의 덧셈, 최댓값)에 씁니다. 실수의 덧셈은 순서에 따라 끝자리가 달라질 수 있고, 뺄셈처럼 순서가 뜻을 바꾸는 연산에는 쓸 수 없습니다.

## 누적 합과 이웃 차

```cpp
#include <numeric>
#include <print>
#include <vector>

void show(const char* label, const std::vector<int>& v)
{
    std::print("{:20}", label);
    for (int x : v)
        std::print("{} ", x);
    std::println("");
}

int main()
{
    // 엔코더가 0.1초마다 알려 준 누적 펄스 수
    const std::vector<int> counts = {0, 12, 30, 45, 45, 70};

    std::vector<int> deltas(counts.size());
    std::adjacent_difference(counts.begin(), counts.end(), deltas.begin());
    show("이웃 차 (속도)", deltas);

    std::vector<int> restored(deltas.size());
    std::partial_sum(deltas.begin(), deltas.end(), restored.begin());
    show("누적 합 (되돌리기)", restored);

    std::vector<int> index(5);
    std::iota(index.begin(), index.end(), 100);     // 100부터 1씩 늘려 채운다
    show("iota", index);
}
```

```text
이웃 차 (속도)      0 12 18 15 0 25
누적 합 (되돌리기)  0 12 30 45 45 70
iota                100 101 102 103 104
```

`adjacent_difference`는 "앞 원소와의 차"를 냅니다. 첫 원소는 그대로 복사됩니다. 누적된 값에서 구간별 변화를 얻을 때 쓰고, `partial_sum`은 그 반대입니다. 둘은 서로를 되돌립니다.

`iota`는 번호표를 만들 때 씁니다. 큰 구조체의 배열을 직접 정렬하는 대신, 번호의 배열을 만들어 "번호가 가리키는 원소"를 기준으로 번호만 정렬하는 것이 그 쓰임입니다.

## 작은 도구들

```cpp
#include <algorithm>
#include <climits>
#include <cmath>
#include <numeric>
#include <print>

int main()
{
    std::println("gcd {} lcm {}", std::gcd(48, 18), std::lcm(4, 6));

    const int a = INT_MAX;
    const int b = INT_MAX - 2;
    std::println("midpoint {}", std::midpoint(a, b));      // (a + b) / 2 는 넘친다

    std::println("lerp {} {}", std::lerp(10.0, 20.0, 0.25),
                 std::lerp(10.0, 20.0, 1.5));

    // 범위 안으로 끌어넣기: clamp(값, 아래, 위)
    std::println("clamp {} {} {}", std::clamp(120, 0, 100), std::clamp(-5, 0, 100),
                 std::clamp(42, 0, 100));
}
```

```text
gcd 6 lcm 12
midpoint 2147483646
lerp 12.5 25
clamp 100 0 42
```

- `(a + b) / 2`는 두 값이 클 때 더하는 순간 넘칩니다. 이진 탐색의 가운데를 구하는 코드에 오래 숨어 있던 버그가 이것입니다. `std::midpoint`는 넘치지 않게 계산합니다. 포인터 둘의 가운데도 구합니다.
- `std::lerp(a, b, t)`는 `a`에서 `b`로 `t`만큼 간 값입니다. `t`가 0과 1 밖이어도 바깥으로 이어서 계산합니다. `<cmath>`에 있습니다.
- `std::gcd`와 `std::lcm`은 타이머 주기 여럿이 다시 겹치는 때를 구하거나 분수를 약분할 때 씁니다.
- `std::clamp`는 `<algorithm>`에 있습니다. PWM 듀티나 모터 명령처럼 넘으면 안 되는 값을 내보내기 직전에 겁니다. `std::min(std::max(v, lo), hi)`를 손으로 쓰다 `min`과 `max`를 뒤바꾸는 실수가 없어집니다.

<Note>
범위를 받는 `std::ranges::` 꼴은 이 헤더의 알고리즘에는 대부분 없습니다. C++23에 `std::ranges::iota`와 `std::ranges::fold_left`가 들어왔을 뿐이고, 나머지는 `v.begin(), v.end()`를 적습니다.
</Note>

## 정리

- `accumulate`의 결과 타입은 초깃값이 정한다. 실수의 합에는 `0.0`, 큰 정수의 합에는 `0LL`
- 원소를 바꿔서 더하면 `transform_reduce`, 두 범위를 짝지어 곱해 더하면 `inner_product`
- 구간별 변화는 `adjacent_difference`, 누적은 `partial_sum`, 가운데 값은 `std::midpoint`
