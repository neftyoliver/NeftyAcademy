[정렬](#/read/cpp-stl/alg-sort)해 두면 할 수 있는 일이 더 있습니다. 두 묶음을 견주는 집합 연산이 한 번 훑기로 끝나고, 배열을 힙으로 다룰 수 있습니다. 순열은 "가능한 모든 순서"를 차례로 만들어 줍니다.

## 집합 연산

정렬된 두 범위를 나란히 걸으며 견줍니다. 양쪽 길이를 더한 만큼만 걸으므로 O(n + m)입니다.

```cpp
#include <algorithm>
#include <iterator>
#include <print>
#include <vector>

void show(const char* label, const std::vector<int>& v)
{
    std::print("{:12}", label);
    for (int x : v)
        std::print("{} ", x);
    std::println("");
}

int main()
{
    // I2C 버스를 훑어 찾은 장치 주소. 둘 다 정렬되어 있다
    const std::vector<int> before = {3, 7, 12, 19, 25};
    const std::vector<int> now = {3, 8, 12, 25, 31};

    std::vector<int> added;
    std::vector<int> removed;
    std::vector<int> kept;
    std::vector<int> all;
    std::ranges::set_difference(now, before, std::back_inserter(added));
    std::ranges::set_difference(before, now, std::back_inserter(removed));
    std::ranges::set_intersection(before, now, std::back_inserter(kept));
    std::ranges::set_union(before, now, std::back_inserter(all));

    show("새로 생김", added);
    show("사라짐", removed);
    show("그대로", kept);
    show("모두", all);
    std::println("모두 가 now 를 품는가 {}", std::ranges::includes(all, now));
}
```

```text
새로 생김   8 31
사라짐      7 19
그대로      3 12 25
모두        3 7 8 12 19 25 31
모두 가 now 를 품는가 true
```

| 알고리즘 | 결과 |
| --- | --- |
| `set_union(a, b)` | 어느 한쪽에라도 있는 것 |
| `set_intersection(a, b)` | 양쪽에 다 있는 것 |
| `set_difference(a, b)` | `a`에만 있는 것 |
| `set_symmetric_difference(a, b)` | 한쪽에만 있는 것 |
| `includes(a, b)` | `a`가 `b`의 원소를 모두 가졌는가 (`bool`) |

"지난번 상태와 이번 상태의 차이"를 구하는 일은 어디에나 있습니다. 붙어 있는 장치, 디렉터리의 파일, 구독자 목록이 그렇습니다. 두 겹의 `for`로 하나하나 찾으면 O(n × m)이지만, 정렬해 두고 이 알고리즘을 쓰면 한 번 훑기입니다.

<Note kind="warn">
입력이 **둘 다 같은 기준으로 정렬**되어 있어야 합니다. 그렇지 않으면 오류 없이 틀린 결과를 냅니다. 이름은 "집합"이지만 `std::set`을 받는 것이 아니라 정렬된 아무 범위나 받습니다. 정렬된 `vector`가 가장 잘 맞습니다.
</Note>

## 합치기

```cpp
#include <algorithm>
#include <iterator>
#include <print>
#include <vector>

int main()
{
    // 시각 순으로 정렬된 두 로그를 하나로
    const std::vector<int> sensor_log = {100, 300, 500};
    const std::vector<int> button_log = {200, 250, 600};
    std::vector<int> timeline;
    std::ranges::merge(sensor_log, button_log, std::back_inserter(timeline));
    for (int t : timeline)
        std::print("{} ", t);
    std::println("");

    // 한 배열 안에 정렬된 두 토막이 이어져 있을 때
    std::vector<int> halves = {1, 4, 9, 2, 3, 10};
    std::ranges::inplace_merge(halves, halves.begin() + 3);
    for (int v : halves)
        std::print("{} ", v);
    std::println("");
}
```

```text
100 200 250 300 500 600
1 2 3 4 9 10
```

`merge`는 정렬된 둘을 정렬된 하나로 만듭니다. `set_union`과 달리 양쪽에 다 있는 값을 **둘 다** 남깁니다. `inplace_merge`는 이미 정렬된 묶음 뒤에 새로 정렬한 묶음을 붙였을 때, 전체를 다시 정렬하지 않고 합칩니다.

## 힙을 직접 다루기

[`priority_queue`](#/read/cpp-stl/adp-priority)가 속에서 쓰는 것이 힙 알고리즘입니다. 힙은 따로 있는 자료 구조가 아니라, 배열의 원소를 **놓는 규칙**입니다. 맨 앞이 언제나 가장 큰 값이고, i번째의 자식이 2i+1번째와 2i+2번째입니다.

```cpp
#include <algorithm>
#include <print>
#include <vector>

void show(const char* label, const std::vector<int>& v)
{
    std::print("{:12}", label);
    for (int x : v)
        std::print("{} ", x);
    std::println("");
}

int main()
{
    std::vector<int> v = {30, 10, 50, 20, 40};
    // 배열을 힙 규칙에 맞게 다시 놓는다. O(n)
    std::ranges::make_heap(v);
    show("make_heap", v);

    v.push_back(60);                        // 뒤에 붙이고
    std::ranges::push_heap(v);              // 제자리로 올린다. O(log n)
    show("push_heap", v);

    std::ranges::pop_heap(v);               // 가장 큰 것을 맨 뒤로 보낸다. O(log n)
    std::println("가장 큰 것 {}", v.back());
    v.pop_back();                           // 실제로 뺀다
    show("pop 뒤", v);

    std::ranges::sort_heap(v);              // 힙을 정렬된 배열로 바꾼다
    show("sort_heap", v);
}
```

```text
make_heap   50 40 30 20 10
push_heap   60 40 50 20 10 30
가장 큰 것 60
pop 뒤      50 40 30 20 10
sort_heap   10 20 30 40 50
```

`push_heap`과 `pop_heap`은 원소를 넣거나 빼지 않습니다. `push_back`으로 붙인 것을 제자리로 올리고, 가장 큰 것을 맨 뒤로 보낼 뿐입니다. [앞에서 본 것](#/read/cpp-stl/ov-parts)과 같은 까닭입니다. 알고리즘은 칸의 개수를 바꾸지 못합니다.

직접 다루면 `priority_queue`가 막아 둔 일을 할 수 있습니다. 원소를 옮겨 꺼내고, 전체를 훑어보고, 내용을 한꺼번에 고친 뒤 `make_heap`으로 다시 세웁니다.

## 모든 순서 만들어 보기

```cpp
#include <algorithm>
#include <print>
#include <string>
#include <vector>

int main()
{
    // 정렬된 채로 시작
    std::vector<std::string> tasks = {"read", "send", "sleep"};
    int count = 0;
    do {
        std::println("{} -> {} -> {}", tasks[0], tasks[1], tasks[2]);
        ++count;
    } while (std::ranges::next_permutation(tasks).found);
    std::println("{}가지", count);

    const std::vector<int> a = {1, 2, 2, 3};
    const std::vector<int> b = {2, 3, 1, 2};
    std::println("순서만 다른가 {}", std::ranges::is_permutation(a, b));
}
```

```text
read -> send -> sleep
read -> sleep -> send
send -> read -> sleep
send -> sleep -> read
sleep -> read -> send
sleep -> send -> read
6가지
순서만 다른가 true
```

`next_permutation`은 범위를 "사전 순서로 바로 다음 순열"로 바꾸고, 마지막 순열이었으면 처음으로 되돌리며 거짓을 알립니다. 그래서 **정렬된 상태에서 시작해야** 모든 순서를 한 번씩 봅니다. 원소가 n개면 n!가지이므로 10개 남짓까지만 쓸 수 있습니다. 작은 문제에서 "모든 경우를 다 해 보는" 답을 먼저 만들어, 더 빠른 알고리즘의 결과를 검증하는 데 좋습니다.

`is_permutation`은 두 범위가 순서만 다르고 내용이 같은지를 봅니다. 순서가 정해지지 않은 결과를 테스트할 때 씁니다.

## 정리

- 정렬된 두 범위의 합, 교, 차는 `set_union`, `set_intersection`, `set_difference`로 한 번 훑어 구한다
- 힙은 배열에 원소를 놓는 규칙이다. `push_heap`, `pop_heap`은 자리만 바꾸고 넣고 빼는 것은 컨테이너가 한다
- `next_permutation`은 정렬된 상태에서 시작해 모든 순서를 차례로 만든다
