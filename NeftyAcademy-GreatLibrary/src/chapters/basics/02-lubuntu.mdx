루분투(Lubuntu)는 **우분투에 가벼운 데스크톱(LXQt)을 얹은 공식 변형판**입니다. 커널과 패키지 저장소는 우분투와 같아서, 우분투용 설명이 거의 그대로 통합니다.

## 설치 전에

- 설치 USB로 부팅하면 먼저 **라이브 세션**(설치하지 않고 USB에서 그대로 돌아가는 상태)이 뜹니다. 여기서 와이파이·화면·소리가 되는지 먼저 확인하세요
- 다른 OS와 같이 쓸 거라면 **중요한 파일은 미리 백업**
- 노트북은 전원을 꽂아 두기

## 설치 프로그램 따라가기

설치 프로그램(Calamares)은 대략 이 순서로 묻습니다.

1. **언어** — 한국어를 고르면 설치 후 화면도 한국어
2. **위치·시간대** — 서울
3. **키보드 배치** — 한국어(101/104키 호환)
4. **디스크** — 아래 절 참고
5. **사용자** — 이름, 컴퓨터 이름, 암호. 이 암호가 `sudo` 암호가 됩니다
6. 요약 확인 → 설치 → 다시 시작, USB 빼기

## 디스크 고르기

| 고르는 것 | 뜻 |
| --- | --- |
| 디스크 지우기 | 디스크 전체를 루분투로. 가장 간단 |
| 나란히 설치 | 기존 OS 옆에 공간을 나눠 설치. 부팅할 때 고르게 됨 |
| 수동 파티션 | 직접 나누기. ESP(FAT32, `/boot/efi`)와 `/`(ext4)는 꼭 필요 |

<Note kind="warn">
「디스크 지우기」는 그 디스크의 **모든 것**을 지웁니다. 디스크가 여러 개면 어느 디스크인지 크기와 이름으로 꼭 확인하세요.
</Note>

## 처음 켠 다음

```sh
sudo apt update          # 저장소 목록 새로 받기
sudo apt full-upgrade    # 깔린 것 모두 최신으로
```

한글 입력은 설정에서 입력기(fcitx5 등)에 한국어를 추가하면 됩니다.
