다른 회사가 만든 램을 메인보드에 꽂고, 아무 가게에서 산 USB 메모리를 노트북에 꽂아도 그냥 됩니다. 모양, 전압, 신호의 박자, 주고받는 말의 순서가 **규격**으로 정해져 있기 때문입니다. [「POSIX와 ISO C」](#/read/basics/std-posix-c)가 소프트웨어의 약속이라면, 이 쪽은 하드웨어의 약속을 봅니다.

## 누가 정하나

하드웨어 규격은 대부분 관련 회사들이 모인 단체가 정합니다. 회원사는 초안을 함께 고치고, 완성된 규격으로 만든 제품은 시험을 거쳐 로고를 붙입니다.

| 단체 | 정하는 규격 |
| --- | --- |
| USB-IF | USB, USB Type-C 커넥터, USB 전원 공급(PD) |
| PCI-SIG | PCI Express(PCIe) |
| JEDEC | 램(DDR, LPDDR), 플래시 메모리의 전기적 규격 |
| IEEE | 이더넷(802.3), Wi-Fi(802.11), 실수 형식(754) |
| Wi-Fi Alliance | Wi-Fi 인증과 "Wi-Fi 7" 같은 세대 이름 |
| Bluetooth SIG | 블루투스 |
| VESA, HDMI Forum | 디스플레이포트, HDMI |
| UEFI Forum | UEFI 펌웨어, ACPI(전원과 장치 정보) |

IEEE처럼 누구나 규격 문서를 살 수 있는 공적 표준 기구도 있고, 회원만 초안을 보는 업계 단체도 있습니다. 어느 쪽이든 목적은 같습니다. **한 회사가 혼자 정하면 그 회사 부품끼리만 맞기** 때문입니다.

## 세대와 이름

규격은 몇 해마다 새 판이 나오고, 판마다 빨라집니다. 대부분 **옛 판과 호환**되게 만들어서, 새 장치를 옛 슬롯에 꽂으면 옛 속도로 동작합니다.

| 규격 | 세대가 바뀌는 모습 | 2026년의 흔한 것 |
| --- | --- | --- |
| PCIe | 3.0 → 4.0 → 5.0 → 6.0 → 7.0, 세대마다 레인 하나의 빠르기가 두 배 | 소비자용 4.0·5.0, 8.0은 2028년 완성 목표로 초안 단계 |
| DDR 램 | DDR3 → DDR4 → DDR5, 세대가 바뀌면 슬롯 모양이 달라 섞어 꽂을 수 없다 | DDR5 |
| Wi-Fi | 802.11n(Wi-Fi 4) → ac(5) → ax(6) → be(7) | Wi-Fi 6·7 |
| 블루투스 | 4.x → 5.x → 6.x, 2025년부터 1년에 두 번 개정 | 5.x 칩, 규격은 6.x |
| HDMI | 1.4 → 2.0 → 2.1 → 2.2, 2.2는 최대 96Gbps | 2.1 |

[「버스와 입출력」](#/read/basics/arch-bus-io)에서 PCIe 레인 하나가 3세대에 약 1GB/s, 5세대에 약 4GB/s라고 했습니다. PCI-SIG는 3년마다 두 배라는 일정을 지켜 왔고, 7.0은 2025년에 완성됐습니다. 8.0은 2026년 5월에 0.5 초안이 회원에게 공개됐습니다.

Wi-Fi는 IEEE의 802.11 뒤에 붙는 영문자가 원래 이름이고, 사람이 기억하기 어려워서 Wi-Fi Alliance가 2018년부터 "Wi-Fi 6" 같은 숫자 이름을 붙였습니다. 블루투스는 버전 숫자보다 기능 이름으로 알리라고 Bluetooth SIG가 권합니다. 같은 "블루투스 5.3" 칩이라도 어떤 기능을 켰는지에 따라 할 수 있는 일이 다르기 때문입니다.

<Note kind="warn">
커넥터 모양과 규격은 다른 것입니다. USB Type-C 포트는 USB 2.0 속도일 수도, 40Gbps일 수도 있고, 화면 출력이나 충전을 못 할 수도 있습니다. HDMI 포트도 모양만으로 2.0인지 2.1인지 알 수 없습니다. 제품 설명서의 규격 표를 봐야 합니다. USB 이름이 얽힌 사정은 [「USB」](#/read/basics/terms-usb)에서 따로 풉니다.
</Note>

## 저장 장치의 규격

SSD는 겉모양과 속의 말이 따로 정해져 있어서 헷갈리기 쉽습니다.

| 층 | 규격 | 뜻 |
| --- | --- | --- |
| 생김새 | 2.5인치, M.2(2280 등) | 크기와 커넥터. 2280은 폭 22mm, 길이 80mm |
| 전선 | SATA, PCIe | 신호가 지나가는 길 |
| 말 | AHCI, NVMe | OS와 장치가 주고받는 명령의 형식 |

같은 M.2 자리에 꽂히는 SSD도 SATA로 말하는 것과 PCIe·NVMe로 말하는 것이 있고, 빠르기는 다섯 배 넘게 차이 납니다. SATA는 처음부터 회전하는 HDD를 위해 만든 규격이라 최대 약 600MB/s에서 멈췄고, NVMe는 플래시 메모리에 맞춰 명령을 수만 개씩 동시에 줄 세울 수 있게 새로 만든 말입니다.

## 상자와 부팅의 규격

부품 말고도 PC를 PC로 만드는 규격이 있습니다.

- **ATX.** 인텔이 1995년에 정한 메인보드와 케이스, 전원 공급 장치의 크기와 나사 구멍 위치입니다. 덕분에 아무 케이스에나 아무 메인보드를 넣을 수 있습니다. 작은 것은 마이크로 ATX, 미니 ITX라고 부릅니다
- **UEFI.** 전원을 켰을 때 장치를 초기화하고 OS를 불러오는 펌웨어의 규격입니다. 옛 BIOS를 대신했고, [「설치 도구와 부팅」](#/read/basics/boot)에서 그 순서를 봤습니다
- **ACPI.** OS가 장치의 목록을 알아내고, 화면을 끄고, 잠자기에 들어가고, 배터리를 읽는 방법을 정한 규격입니다

<Note>
라즈베리파이 같은 ARM 보드는 이런 PC 규격을 대부분 따르지 않습니다. 부팅은 보드 회사가 정한 방식으로 하고, 장치 목록은 ACPI 대신 "디바이스 트리"라는 파일로 커널에 알려 줍니다. 그래서 PC용 리눅스 설치 USB는 라즈베리파이에서 부팅되지 않고, 보드마다 맞춘 이미지를 써야 합니다. [「마이크로컨트롤러와 라즈베리파이」](#/read/basics/modern-mcu-sbc)에서 이어집니다.
</Note>

## 정리

- 하드웨어 규격은 회사들이 모인 단체나 IEEE 같은 표준 기구가 정하며, 덕분에 다른 회사의 부품끼리 맞물린다
- 규격은 세대마다 빨라지지만 대개 옛 세대와 호환되고, DDR 램처럼 세대가 바뀌면 섞어 쓸 수 없는 것도 있다
- 커넥터 모양과 그 안의 규격은 따로이며, SSD는 생김새(M.2), 전선(PCIe), 말(NVMe)을 각각 확인해야 한다
