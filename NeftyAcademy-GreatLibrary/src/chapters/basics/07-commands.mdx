터미널 명령어 중에는 <strong>유닉스 계열이면 어디서나 되는 것(POSIX)</strong>과 **리눅스에서만 되는 것**이 섞여 있습니다. 구분해 두면 맥이나 BSD, 라즈베리파이에서 무엇이 그대로 통할지 미리 알 수 있습니다.

## POSIX란

POSIX는 "유닉스처럼 생긴 OS라면 이 정도는 갖추자"는 IEEE 표준입니다. 셸(`sh`)의 문법, 기본 명령어, 그리고 C 함수(`fork`, `open` 등)까지 정합니다. 리눅스와 맥은 대부분 따르고, 윈도우는 따르지 않습니다(그래서 WSL·MSYS2가 있습니다).

## 권한과 chmod +x

`ls -l`의 맨 앞 열 글자는 **종류 + 주인·그룹·나머지의 권한**입니다.

```text
-rwxr-xr--  1 nefty nefty  120  run.sh
│└┬┘└┬┘└┬┘
│ │  │  └ 나머지: 읽기만
│ │  └ 그룹: 읽기·실행
│ └ 주인: 읽기·쓰기·실행
└ 종류: - 파일, d 폴더, l 링크
```

| 글자 | 파일에서 | 폴더에서 |
| --- | --- | --- |
| r | 읽기 | 목록 보기 |
| w | 고치기 | 안에 만들기·지우기 |
| x | **실행** | 들어가기(`cd`) |

```sh
chmod +x run.sh     # 모두에게 실행 권한 더하기
chmod u+x run.sh    # 주인에게만
chmod 755 run.sh    # 숫자로: 주인 rwx(7), 그룹 r-x(5), 나머지 r-x(5)
```

## 스크립트 실행하기

```sh
#!/bin/sh
echo "hello"
```

첫 줄 `#!`(셔뱅)은 "이 파일은 `/bin/sh`로 읽어라"는 뜻입니다. 실행 권한을 주고 `./run.sh`로 실행합니다. 앞에 `./`가 필요한 이유는, 셸은 명령을 **`PATH`에 적힌 폴더에서만** 찾고 지금 폴더는 보안상 거기 없기 때문입니다.
