| 층 | 되는 곳 | 예 |
| --- | --- | --- |
| 표준 C (ISO C23) | 윈도우·맥·리눅스·마이크로컨트롤러 | `printf`, `malloc`, `strlen`, `qsort` |
| POSIX | 리눅스·맥·BSD (윈도우는 WSL·MSYS2로) | `fork`, `pipe`, `pthread_create`, `open` |
| 리눅스 전용 | 리눅스만 | `epoll_wait`, `timerfd_create` |
| 데스크톱 | 그 그래픽 환경이 있는 곳 | `wl_display_connect`, `gtk_window_new` |

## 누가 이 함수들을 주나

- **컴파일러**: GCC, Clang. 같은 소스를 둘 다로 컴파일해 보면 경고를 더 많이 잡습니다
- **C 라이브러리(libc)**: 표준 C와 POSIX 함수의 실제 구현. 우분투는 **glibc**, 알파인은 **musl**
- **커널**: libc 함수가 결국 부탁하는 곳(시스템 콜)
- **그 밖의 라이브러리**: GTK 같은 것. OS 패키지 매니저로 `-dev` 패키지를 깝니다

## 빌드 도구

| 도구 | 역할 |
| --- | --- |
| make | `Makefile`에 적힌 규칙대로, 바뀐 파일만 다시 빌드 |
| CMake | 여러 OS용 빌드 파일(Makefile, Ninja 등)을 만들어 주는 도구 |
| Ninja | CMake가 만든 빌드를 빠르게 돌리는 실행기 |
| pkg-config | "GTK를 쓰려면 이 옵션을 붙여라"를 알려 줌: `pkg-config --cflags --libs gtk4` |

## 수업 전에 깔아 둘 것 (우분투 계열)

```sh
sudo apt-get install build-essential gdb git cmake ninja-build pkg-config \
  clang llvm lld clangd clang-format clang-tidy bear \
  valgrind strace ltrace manpages-dev manpages-posix-dev
```

<Note kind="tip">
`man 3 printf`는 C 함수 설명서, `man 3p printf`는 POSIX가 정한 설명서입니다(`manpages-posix-dev`). 숫자 3은 "라이브러리 함수" 장이라는 뜻입니다.
</Note>
