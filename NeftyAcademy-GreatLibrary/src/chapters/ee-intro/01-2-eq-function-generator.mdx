**함수 발생기**(function generator)는 정해진 모양으로 오르내리는 전압을 만들어 주는 장비입니다. 회로에 넣을 시험 신호를 만들 때 쓰고, 그 결과는 다음 쪽의 [「오실로스코프」](#/read/ee-intro/eq-oscilloscope)로 봅니다. 손잡이는 많아 보여도 정하는 것은 몇 가지뿐입니다.

| 설정 | 뜻 | 예 |
| --- | --- | --- |
| 파형 | 오르내리는 모양 | 사인, 네모, 세모(톱니), 펄스 |
| 주파수 f | 1초에 몇 번 되풀이하나(Hz) | 1kHz면 1초에 1000번 |
| 진폭 | 가운데에서 봉우리까지 | 1V |
| 오프셋 | 가운데 선을 위아래로 옮기기 | +0.5V |

주기 T는 한 번 되풀이하는 데 걸리는 시간으로, **T = 1/f**입니다. 1kHz의 주기는 1ms입니다. 네모파에는 한 주기 중 높은 시간의 비율인 **듀티비**(duty cycle)도 정할 수 있습니다. 50%면 높음과 낮음이 같은 길이입니다.

## 같은 "1V"가 셋

전압의 크기를 말하는 방법이 여러 가지라 헷갈리기 쉽습니다.

- **진폭**(amplitude): 가운데에서 봉우리까지. 위 그림에서 1V
- **Vpp**(peak-to-peak): 봉우리에서 골까지. 진폭의 두 배, 2V
- **실효값**(RMS): 같은 저항에서 같은 열을 내는 직류 전압. 제곱의 평균의 제곱근으로 구하고, **파형마다 다릅니다**

```python
import math

N = 100_000                          # 한 주기를 이만큼 잘게 나눈다
VPP = 2.0                            # 봉우리에서 골까지 2V (진폭 1V)

def sine(t):     return 1.0 * math.sin(2 * math.pi * t)
def square(t):   return 1.0 if t < 0.5 else -1.0
def triangle(t): return 4 * t - 1 if t < 0.5 else 3 - 4 * t

for name, f in [("사인파", sine), ("네모파", square), ("세모파", triangle)]:
    xs = [f(k / N) for k in range(N)]
    rms = math.sqrt(sum(x * x for x in xs) / N)    # 제곱의 평균의 제곱근
    print(f"{name}: Vpp {VPP:.1f}V, 실효값(RMS) {rms:.3f}V")

# 발생기 속 저항 50Ω과 바깥 부하의 전압 나누기
RS = 50.0
V_INSIDE = 2.0                       # 50Ω 부하에 1V가 걸리도록 속에서 2V를 낸다
for rl, what in [(50.0, "50Ω 부하"), (1e6, "오실로스코프 1MΩ")]:
    v = V_INSIDE * rl / (RS + rl)
    print(f"{what}에 걸리는 전압 {v:.3f}V")
```

```text
사인파: Vpp 2.0V, 실효값(RMS) 0.707V
네모파: Vpp 2.0V, 실효값(RMS) 1.000V
세모파: Vpp 2.0V, 실효값(RMS) 0.577V
50Ω 부하에 걸리는 전압 1.000V
오실로스코프 1MΩ에 걸리는 전압 2.000V
```

앞의 세 줄은 Vpp가 같아도 실효값이 다르다는 것을 보여 줍니다. 사인파는 진폭 ÷ √2(0.707), 세모파는 진폭 ÷ √3(0.577)이고, 네모파는 늘 봉우리에 있으니 진폭 그대로입니다. 멀티미터의 교류 전압 칸은 보통 실효값을 보여 주므로, 발생기 화면의 Vpp와 숫자가 다른 것이 정상입니다. 발생기마다 진폭 단위를 Vpp, Vrms 중에서 고를 수 있으니 무엇으로 맞춰져 있는지 먼저 봅니다.

## 두 배 함정: 50Ω 출력

대부분의 함수 발생기는 출력 단자 안쪽에 **50Ω 저항**이 직렬로 들어 있는 것처럼 동작합니다. 그리고 화면의 숫자는 "바깥에 50Ω 부하를 달았을 때 거기 걸리는 전압"을 기준으로 보여 줍니다.

</Figure>

속에서 2V를 내면 50Ω 부하에는 반씩 나뉘어 1V가 걸립니다. 그런데 오실로스코프의 입력은 1MΩ으로 매우 커서, 속저항 50Ω에는 거의 전압이 걸리지 않고 **2V가 거의 다** 보입니다. 위 계산의 마지막 두 줄입니다. 화면에는 1V라고 써 있는데 오실로스코프에는 2V가 보이는 일이 이것입니다. 전압이 저항의 비율대로 나뉘는 까닭은 [「옴의 법칙」](#/read/ee-intro/ohm)에서 봅니다.

해결은 발생기의 출력 부하 설정을 **High-Z**(높은 임피던스)로 바꾸는 것입니다. 그러면 발생기가 "부하가 매우 크다"고 보고 화면의 숫자를 실제로 보일 전압에 맞춰 줍니다. 회로에 따라 실제 부하가 50Ω일 때만 50Ω 설정을 씁니다.

<Note kind="warn">
발생기 출력을 회로에 이을 때는 **먼저 출력을 끄고** 잇고, 진폭을 작게 시작해서 올립니다. 오프셋을 잊고 큰 직류가 섞인 신호를 넣으면 부품이 망가질 수 있습니다. 출력 단자끼리 맞닿게(합선) 하지 말고, 발생기 땅(검은 집게)과 회로의 땅을 같은 곳에 잇습니다.
</Note>

## 정리

- 함수 발생기에서는 파형, 주파수(T = 1/f), 진폭, 오프셋, 네모파의 듀티비를 정한다
- 진폭, Vpp(진폭의 두 배), 실효값(사인파는 진폭 × 0.707)은 서로 다른 크기이고, 실효값은 파형마다 다르다
- 발생기는 속에 50Ω이 있는 것처럼 동작하므로, 1MΩ 오실로스코프에 바로 이으면 50Ω 설정의 두 배가 보이며 High-Z 설정으로 맞춘다
