## 풀이

**끝에서부터 줄이기.** N4에는 아래 2R과 끝막이 2R이 나란히 있으니 2k ∥ 2k = **1kΩ**입니다. N3에서 오른쪽을 보면 직렬 R 1k에 그 1k가 이어져 2kΩ이고, 이것이 N3의 아래 2R과 나란히 있으니 다시 2k ∥ 2k = **1kΩ**입니다. 몇 칸을 가도 같은 일이 되풀이되어, **어느 마디에서 보아도 1kΩ = R**입니다.

그래서 (가) 입력 저항은 **1kΩ**, 전원 전류는 8V / 1k = **8mA**이고, (다) 칸을 늘려도 입력 저항은 그대로 R입니다.

**전압은 반씩.** N1에서 N2 쪽으로 가는 길은 직렬 R(1k)과, N2에서 본 1k로 된 전압 나누기입니다. 위아래가 같으니 **N2 = N1의 절반**입니다. 같은 이유로 N3 = N2의 절반, N4 = N3의 절반입니다. 8V, 4V, 2V, 1V가 되고, 아래 2R로 흐르는 전류도 4, 2, 1, 0.5mA로 반씩 줄어듭니다. 끝막이로 나머지 0.5mA가 흘러, 다 더하면 8mA로 전원 전류와 맞습니다.

## 코드로 확인

반복되는 구조는 반복문으로 계산하면 칸 수를 바꿔도 그대로 쓸 수 있습니다.

```python
def parallel(a, b):
    return a * b / (a + b)

R = 1000.0
V = 8.0
N = 4                                   # 마디 N1~N4

# 오른쪽 끝에서부터 "그 마디에서 오른쪽(과 아래)을 본 저항"을 쌓아 온다
r_right = 2 * R                         # N4: 끝막이 2R
looks = [0.0] * N
for k in range(N - 1, -1, -1):
    looks[k] = parallel(2 * R, r_right) # 마디 k: 아래 2R ∥ 오른쪽
    r_right = R + looks[k]              # 한 칸 왼쪽에서 보면 직렬 R이 붙는다
print(f"입력 저항 {looks[0]:.0f}Ω, 전원 전류 {V / looks[0] * 1000:.1f}mA")

# 왼쪽부터 마디 전압: 직렬 R과 다음 마디가 본 저항의 전압 나누기
v = V
for k in range(N):
    print(f"N{k + 1} {v:.3f}V, 아래 2R로 {v / (2 * R) * 1000:.2f}mA")
    if k + 1 < N:
        v = v * looks[k + 1] / (R + looks[k + 1])
```

```text
입력 저항 1000Ω, 전원 전류 8.0mA
N1 8.000V, 아래 2R로 4.00mA
N2 4.000V, 아래 2R로 2.00mA
N3 2.000V, 아래 2R로 1.00mA
N4 1.000V, 아래 2R로 0.50mA
```

`N = 8`로 바꾸면 마지막 마디는 8V / 2⁷ = 0.0625V가 되고, 입력 저항은 여전히 1000Ω입니다.

## 어디에 쓰나: DAC

마디마다 전류가 정확히 반씩 줄어든다는 것은, 각 2R 가지가 **이진수의 한 자리**처럼 1, ½, ¼, ⅛의 무게를 갖는다는 뜻입니다. 실제 R-2R DAC는 위 회로를 조금 바꿔, 각 2R의 아래 끝을 스위치로 "기준 전압" 또는 "땅"에 이어 디지털 값의 각 비트를 표현하고, 끝에서 비트 값에 비례하는 전압을 얻습니다. 값이 두 종류(R과 2R)뿐이라 칩 안에서 정확히 맞춰 만들기 쉬운 것이 장점입니다. 저항 오차가 크면 비트의 무게가 어긋나므로, 직접 만들 때는 1% 이하 오차의 저항을 고르고 2R은 같은 R 두 개를 직렬로 써서 맞추기도 합니다.

<Note>
"오른쪽을 보면 얼마인가"처럼 회로의 일부를 저항 하나로 바꿔 보는 생각은 이후 문제들에서 계속 씁니다. [「문제 7」](#/read/ee-intro/dc-problem-7)의 테브난 등가 회로는 이것을 전원이 있는 회로로까지 넓힌 것입니다.
</Note>

## 정리

- 사다리 회로는 끝에서부터 "그 마디에서 본 저항"을 한 칸씩 쌓아 오면 줄이기로 풀린다
- R-2R 사다리는 어느 마디에서 보아도 R로 보여, 마디 전압과 가지 전류가 한 칸마다 정확히 반씩 줄어든다
- 이 이진 무게 덕분에 R과 2R 두 값만으로 DAC를 만들 수 있으며, 반복 구조는 반복문으로 계산해 칸 수를 쉽게 바꾼다
