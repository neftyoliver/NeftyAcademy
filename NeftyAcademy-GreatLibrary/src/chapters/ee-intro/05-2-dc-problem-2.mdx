[「문제 1」](#/read/ee-intro/dc-problem-1)은 병렬 한 번으로 풀렸습니다. 이번에는 직렬과 병렬이 겹겹이 섞인 회로를 **줄였다가 다시 펼치는** 순서를 연습합니다. 대부분의 저항 회로는 이 방법만으로 풀립니다.

## 문제

<Figure caption="10V, R1 1kΩ 뒤에서 R2와 (R3 + R4)가 나란히">
  <Circuit spec="B 0,2 0,0 10V; R 0,0 2,0 R1 1kΩ; D 2,0; T 2,-0.32 A; R 2,0 2,2 R2 6kΩ; W 2,0 4,0; R 4,0 4,1 R3 2kΩ; D 4,1; T 4.55,1 B; R 4,1 4,2 R4 4kΩ; W 4,2 0,2; D 2,2; G 0,2" label="10볼트 전지와 1킬로옴 R1, 마디 A에서 6킬로옴 R2와, 2킬로옴 R3와 4킬로옴 R4의 직렬 가지가 병렬로 땅에 이어진 회로" />
</Figure>

- (가) 전원에서 본 전체 저항과 전원 전류는?
- (나) 마디 A와 B의 전압(땅 기준)은?
- (다) 저항 네 개가 쓰는 전력은 각각 얼마이고, 합은 전원이 내는 전력과 같은가?

<Note kind="tip">
실마리: 가장 **안쪽**, 곧 다른 것이 끼어들지 않은 묶음부터 하나로 합칩니다. R3와 R4는 사이에 갈림길이 없으니 직렬입니다.
</Note>

## 풀이: 줄이기

1. R3 + R4 = 2k + 4k = **6kΩ** (직렬, 오른쪽 가지)
2. 그 6kΩ과 R2 6kΩ이 A와 땅 사이에 나란히 있으니 병렬: 6k ∥ 6k = **3kΩ**. 같은 값 둘의 병렬은 반입니다
3. R1과 직렬: 1k + 3k = **4kΩ**. 전원 전류는 10V / 4k = **2.5mA**

## 풀이: 다시 펼치기

1. A 아래 전체가 3kΩ이고 2.5mA가 흐르니, **A는 7.5V**입니다. R1에는 2.5V가 걸립니다
2. A에서 R2로 7.5V / 6k = **1.25mA**, 오른쪽 가지로 7.5V / 6k = **1.25mA**가 갈라집니다. 합이 2.5mA로 맞습니다
3. 오른쪽 가지에서 R4에 1.25mA × 4k = 5V가 걸리니 **B는 5.0V**입니다. R3에는 나머지 2.5V가 걸립니다

전력은 P = I²R로, R1 6.25mW, R2 9.375mW, R3 3.125mW, R4 6.25mW이고 합은 25mW입니다. 전원은 10V × 2.5mA = 25mW를 내므로 **에너지가 맞습니다**. 검산할 때 아주 좋은 방법입니다.

## 코드로 확인

```python
def parallel(a, b):
    return a * b / (a + b)

V = 10.0
R1, R2, R3, R4 = 1e3, 6e3, 2e3, 4e3

r34 = R3 + R4                    # 오른쪽 가지: 직렬
r_a = parallel(R2, r34)          # A 아래 전체: 병렬
r_total = R1 + r_a               # 전원에서 본 전체
i = V / r_total
v_a = i * r_a
i2, i34 = v_a / R2, v_a / r34
v_b = i34 * R4
print(f"오른쪽 가지 {r34:.0f}Ω, A 아래 {r_a:.0f}Ω, 전체 {r_total:.0f}Ω")
print(f"전체 전류 {i * 1e3:.2f}mA, A {v_a:.2f}V, B {v_b:.2f}V")
print(f"R2로 {i2 * 1e3:.2f}mA, 오른쪽 가지로 {i34 * 1e3:.2f}mA")

powers = {"R1": i**2 * R1, "R2": i2**2 * R2, "R3": i34**2 * R3, "R4": i34**2 * R4}
for name, p in powers.items():
    print(f"  {name} {p * 1e3:.3f}mW")
total = sum(powers.values())
print(f"저항들의 합 {total * 1e3:.3f}mW, 전원이 낸 {V * i * 1e3:.3f}mW")
```

```text
오른쪽 가지 6000Ω, A 아래 3000Ω, 전체 4000Ω
전체 전류 2.50mA, A 7.50V, B 5.00V
R2로 1.25mA, 오른쪽 가지로 1.25mA
  R1 6.250mW
  R2 9.375mW
  R3 3.125mW
  R4 6.250mW
저항들의 합 25.000mW, 전원이 낸 25.000mW
```

## 실험해 보기

빵판에서는 1kΩ, 6.8kΩ(또는 5.6kΩ 두 개 대신 쓸 수 있는 값), 2.2kΩ, 3.9kΩ처럼 가까운 표준 값으로 꾸밉니다. 값이 달라졌으니 위 코드의 숫자를 바꿔 다시 계산하고, 멀티미터로 A와 B를 재서 견줍니다. 저항의 오차(흔히 ±1%나 ±5%)만큼 차이가 나는 것이 정상입니다.

<Note>
줄이기는 "어느 두 저항이 직렬 또는 병렬인가"를 바르게 알아보는 데 달려 있습니다. **직렬**은 둘 사이의 마디에 다른 것이 이어지지 않아 같은 전류가 지나는 것, **병렬**은 양 끝이 같은 두 마디에 이어져 같은 전압이 걸리는 것입니다. 이 둘 중 어느 것도 아닌 회로는 [「문제 4」](#/read/ee-intro/dc-problem-4)의 브리지처럼 줄이기로 풀리지 않습니다.
</Note>

## 정리

- 직렬·병렬이 섞인 회로는 안쪽 묶음부터 하나씩 합쳐 전체 저항과 전원 전류를 구한다
- 다시 거꾸로 펼치며 각 묶음에 걸리는 전압과 갈라지는 전류를 구하고, 마디에서 전류의 합이 맞는지 확인한다
- 저항들의 전력 합이 전원의 전력과 같은지 보는 에너지 검산으로 실수를 잡는다
