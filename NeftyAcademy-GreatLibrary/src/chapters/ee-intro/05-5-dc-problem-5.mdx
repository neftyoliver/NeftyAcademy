- (가) 마디 A와 B의 전압은?
- (나) R3에는 어느 방향으로 얼마의 전류가 흐르나?

<Note kind="tip">
실마리: 땅을 0V로 정하면 모르는 것은 V_A와 V_B 두 개뿐입니다. 각 마디에서 **나가는 전류의 합 = 0**(들어오는 것은 음수로)을 쓰면 식이 두 개 나옵니다.
</Note>

## 풀이: 손으로

저항을 kΩ, 전류를 mA로 쓰면 숫자가 깔끔합니다. 각 저항으로 나가는 전류는 (내 마디 전압 − 건너편 전압) / 저항입니다.

**마디 A**: (V_A − 12)/2 + V_A/4 + (V_A − V_B)/2 = 0. 양변에 4를 곱해 정리하면 **5V_A − 2V_B = 24**

**마디 B**: (V_B − V_A)/2 + V_B/3 + (V_B − 6)/1 = 0. 양변에 6을 곱해 정리하면 **−3V_A + 11V_B = 36**

첫 식에서 V_A = (24 + 2V_B)/5를 둘째 식에 넣으면 49V_B = 252, **V_B = 36/7 ≈ 5.143V**이고 **V_A = 48/7 ≈ 6.857V**입니다. (나) R3에는 A가 더 높으니 A에서 B로 (48/7 − 36/7)/2 = 6/7 ≈ **0.857mA**가 흐릅니다.

방향을 미리 맞힐 필요는 없습니다. 모든 전류를 "내 마디에서 나가는 쪽"으로 똑같이 적으면, 실제 방향은 답의 부호가 알려 줍니다.

## 풀이: 행렬에 찍기

식을 정리하면 늘 **G · V = I** 모양이 됩니다. G는 마디들 사이의 컨덕턴스(1/R), V는 모르는 마디 전압, I는 마디로 밀어 넣는 전류입니다. 그리고 G는 저항 하나씩 보며 **찍어 넣는** 규칙으로 만들 수 있습니다.

- 저항 R이 마디 a와 b 사이에 있으면, G[a][a]와 G[b][b]에 1/R을 더하고, G[a][b]와 G[b][a]에서 1/R을 뺀다
- 한쪽이 땅이면 땅 쪽은 행렬에 없으니 G[a][a]에만 더한다
- 전압원 V가 저항 R을 거쳐 마디로 들어오면, 땅으로 가는 저항 R과 마디로 V/R만큼 밀어 넣는 전류원으로 바꿔 생각한다(노턴 변환)

```python
import numpy as np

# 마디 번호: 0은 땅, 1은 A, 2는 B
# 저항: (마디, 마디, 옴)
resistors = [(1, 0, 4e3),   # R2: A-땅
             (1, 2, 2e3),   # R3: A-B
             (2, 0, 3e3)]   # R4: B-땅
# 저항을 거친 전압원: (마디, 전압, 직렬 저항) — 다른 끝은 땅
sources = [(1, 12.0, 2e3),  # V1 12V, R1 2k를 거쳐 A로
           (2, 6.0, 1e3)]   # V2 6V,  R5 1k를 거쳐 B로

n = 2
G = np.zeros((n, n))
I = np.zeros(n)

def stamp(a, b, r):
    """저항 하나를 행렬에 '찍는다'. 땅(0)은 행렬에 없다."""
    g = 1 / r
    for p in (a, b):
        if p:
            G[p - 1, p - 1] += g
    if a and b:
        G[a - 1, b - 1] -= g
        G[b - 1, a - 1] -= g

for a, b, r in resistors:
    stamp(a, b, r)
for node, v, r in sources:       # 전압원+직렬 저항 = 전류원 v/r와 저항 r(노턴)
    stamp(node, 0, r)
    I[node - 1] += v / r

print("G (mS) =\n", np.round(G * 1e3, 4))
print("I (mA) =", np.round(I * 1e3, 4))
va, vb = np.linalg.solve(G, I)
print(f"A {va:.4f}V, B {vb:.4f}V")

# 검산: 마디마다 들어오는 전류 - 나가는 전류 = 0
in_a = (12 - va) / 2e3
out_a = va / 4e3 + (va - vb) / 2e3
print(f"마디 A: 들어옴 {in_a * 1e3:.4f}mA, 나감 {out_a * 1e3:.4f}mA")
print(f"R3로 A에서 B로 {(va - vb) / 2e3 * 1e3:.4f}mA")
```

```text
G (mS) =
 [[ 1.25   -0.5   ]
 [-0.5     1.8333]]
I (mA) = [6. 6.]
A 6.8571V, B 5.1429V
마디 A: 들어옴 2.5714mA, 나감 2.5714mA
R3로 A에서 B로 0.8571mA
```

G의 첫 줄 [1.25, −0.5]는 손으로 세운 첫 식 5V_A − 2V_B = 24를 4로 나눈 것과 같습니다(단위 mS). 회로가 커져도 `resistors`와 `sources` 목록만 늘리면 되고, 마디가 100개라도 똑같이 풀립니다.

<Note>
SPICE가 하는 일이 위의 "찍기"를 일반화한 **수정 마디 해석**(MNA)입니다. 저항이 없는 전압원처럼 전류원으로 바꿀 수 없는 소자는, 그 전류를 모르는 값으로 하나 더 놓아 행렬을 키우는 식으로 다룹니다. 다이오드처럼 옴의 법칙을 따르지 않는 소자가 있으면, 직선으로 근사해 풀고 다시 고치기를 되풀이합니다(뉴턴 방법).
</Note>

## 정리

- 마디 해석은 땅을 정하고, 나머지 마디 전압을 모르는 값으로 놓고, 마디마다 나가는 전류의 합 = 0을 세워 푼다
- 모든 전류를 같은 방향 약속으로 적으면 실제 방향은 답의 부호가 알려 준다
- 식은 늘 G·V = I 모양이고, 저항과 전원을 행렬에 찍어 넣는 규칙으로 기계적으로 만들 수 있으며 SPICE도 이 방법을 쓴다
