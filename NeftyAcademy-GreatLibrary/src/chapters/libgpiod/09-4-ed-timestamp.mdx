이벤트에는 에지가 난 시각이 나노초로 적혀 있습니다. 이 시각은 프로그램이 이벤트를 읽은 때가 아니라 커널이 에지를 알아챈 때입니다. 신호의 폭과 간격을 재는 일이 이 숫자 하나로 풀립니다. 남는 것은 어느 시계로 찍게 할지를 고르는 일입니다.

## 찍히는 때와 읽는 때

아래 예제는 일부러 게으르게 굽니다. 1초에 한 번만 들여다보고, 그사이에 쌓인 이벤트를 꺼내 찍힌 시각과 읽은 시각의 차이를 적습니다. 감지기는 [「에지 감지 켜기」](#/read/libgpiod/ed-request)의 것과 같습니다.

```c gpiosim=pir
// 1초에 한 번만 들여다보면서, 이벤트가 찍힌 시각과 신호가 머문 시간을 적는다
#define _POSIX_C_SOURCE 200809L              // clock_gettime과 localtime_r을 쓰려고
#include <gpiod.h>
#include <inttypes.h>
#include <stdio.h>
#include <string.h>
#include <threads.h>
#include <time.h>

enum { SENSOR = 23, ROOM = 8 };              // GPIO 23, 헤더의 핀 16
static const uint64_t SECOND = 1'000'000'000;

// 두 방향의 에지를 보는 입력으로 요청한다. 타임스탬프는 clock의 시계로 찍힌다
static struct gpiod_line_request* request_edges(struct gpiod_chip* chip,
                                                unsigned int offset,
                                                enum gpiod_line_clock clock) {
    struct gpiod_line_settings* settings = gpiod_line_settings_new();
    struct gpiod_line_config* config = gpiod_line_config_new();
    struct gpiod_line_request* request = nullptr;
    if (settings && config) {
        gpiod_line_settings_set_direction(settings, GPIOD_LINE_DIRECTION_INPUT);
        gpiod_line_settings_set_edge_detection(settings, GPIOD_LINE_EDGE_BOTH);
        gpiod_line_settings_set_event_clock(settings, clock);
        gpiod_line_config_add_line_settings(config, &offset, 1, settings);
        request = gpiod_chip_request_lines(chip, nullptr, config);
    }
    gpiod_line_config_free(config);
    gpiod_line_settings_free(settings);
    return request;
}

// 그 시계의 지금을 나노초로 읽는다
static uint64_t now_ns(clockid_t id) {
    struct timespec now;
    clock_gettime(id, &now);
    return (uint64_t)now.tv_sec * SECOND + (uint64_t)now.tv_nsec;
}

// 타임스탬프를 적는다. 벽시계의 것이면 날짜와 시각으로 바꿔서 적는다
static void print_stamp(uint64_t at, bool realtime) {
    if (!realtime) {
        printf("%" PRIu64 ".%03" PRIu64 "초", at / SECOND, at / 1'000'000 % 1000);
        return;
    }
    time_t seconds = (time_t)(at / SECOND);
    struct tm local;
    char text[32];
    localtime_r(&seconds, &local);
    strftime(text, sizeof text, "%Y-%m-%d %H:%M:%S", &local);
    printf("%s.%03" PRIu64, text, at / 1'000'000 % 1000);
}

// 이벤트 하나를 적는다. 내려가는 에지면 신호가 머문 시간도 적는다
static void report(struct gpiod_edge_event* event, uint64_t read_at,
                   bool realtime) {
    static uint64_t rose_at;                 // 마지막으로 올라간 시각. 0이면 모른다
    uint64_t at = gpiod_edge_event_get_timestamp_ns(event);
    bool rising =
        gpiod_edge_event_get_event_type(event) == GPIOD_EDGE_EVENT_RISING_EDGE;
    print_stamp(at, realtime);
    printf("  %-7s  %3" PRIu64 "ms 뒤에 읽음\n", rising ? "rising" : "falling",
           (read_at - at) / 1'000'000);
    if (rising) {
        rose_at = at;
    } else if (rose_at != 0) {
        printf("    머문 시간 %" PRIu64 "ms\n", (at - rose_at) / 1'000'000);
    }
}

int main(int argc, char** argv) {
    // 인수로 realtime을 주면 벽시계로, 아니면 단조 시계로 찍게 한다
    bool realtime = argc > 1 && strcmp(argv[1], "realtime") == 0;
    enum gpiod_line_clock clock =
        realtime ? GPIOD_LINE_CLOCK_REALTIME : GPIOD_LINE_CLOCK_MONOTONIC;
    clockid_t same_clock = realtime ? CLOCK_REALTIME : CLOCK_MONOTONIC;

    struct gpiod_chip* chip = gpiod_chip_open("/dev/gpiochip0");
    if (!chip) {
        perror("/dev/gpiochip0");
        return 1;
    }
    struct gpiod_line_request* sensor = request_edges(chip, SENSOR, clock);
    gpiod_chip_close(chip);
    struct gpiod_edge_event_buffer* buffer = gpiod_edge_event_buffer_new(ROOM);
    if (!sensor || !buffer) {
        perror("요청");
        return 1;
    }
    for (int pass = 0; pass < 5; ++pass) {
        thrd_sleep(&(struct timespec){.tv_sec = 1}, nullptr);  // 1초에 한 번만 본다
        while (gpiod_line_request_wait_edge_events(sensor, 0) == 1) {
            int count = gpiod_line_request_read_edge_events(sensor, buffer, ROOM);
            uint64_t read_at = now_ns(same_clock);
            for (int i = 0; i < count; ++i) {
                report(gpiod_edge_event_buffer_get_event(buffer, (unsigned long)i),
                       read_at, realtime);
            }
        }
    }
    gpiod_edge_event_buffer_free(buffer);
    gpiod_line_request_release(sensor);
}
```

```text
핀|   1.200s  감지기 → HIGH
5001.200초  rising   800ms 뒤에 읽음
핀|   2.700s  감지기 → LOW
5002.700초  falling  300ms 뒤에 읽음
    머문 시간 1500ms
핀|   4.100s  감지기 → HIGH
핀|   4.200s  감지기 → LOW
5004.100초  rising   900ms 뒤에 읽음
5004.200초  falling  800ms 뒤에 읽음
    머문 시간 100ms
```

- **찍힌 시각은 늦게 읽어도 그대로다**: 프로그램은 이벤트를 0.3초에서 0.9초 늦게 읽었습니다. 타임스탬프에는 핀이 바뀐 1.2초, 2.7초, 4.1초, 4.2초가 그대로 적혀 있습니다
- **머문 시간은 두 타임스탬프의 차이다**: 1500ms와 100ms가 그대로 나왔습니다. 읽은 시각으로 셈했다면 1000ms와 0ms가 됐을 것입니다
- **같은 시계와 견준다**: 기본 시계로 찍힌 타임스탬프는 `clock_gettime(CLOCK_MONOTONIC)`이 돌려주는 값과 같은 시계의 것입니다. 지금에서 타임스탬프를 빼면 얼마나 묵은 이벤트인지가 나옵니다
- **`_POSIX_C_SOURCE`**: `clock_gettime`은 C 표준이 아니라 POSIX의 함수입니다. `-std=c23`으로 컴파일할 때에는 첫 머리 파일보다 앞에서 이 매크로를 정의해야 선언이 보입니다([「컴파일과 링크」](#/read/libgpiod/st-build))

## 시계 셋

| 값 | 시계 | 쓰임 |
| --- | --- | --- |
| `GPIOD_LINE_CLOCK_MONOTONIC` | 보드가 켜진 뒤로 흐른 시간. 기본값 | 간격, 폭, 주파수 |
| `GPIOD_LINE_CLOCK_REALTIME` | 1970년부터 센 달력의 시각 | 기록에 남길 날짜와 시각 |
| `GPIOD_LINE_CLOCK_HTE` | 하드웨어가 찍는 시각 | 그런 하드웨어가 있을 때 |

- **`gpiod_line_settings_set_event_clock`**: settings에 위의 값 가운데 하나를 적습니다
- **단조 시계는 건너뛰지 않는다**: 누가 시각을 고쳐도 뛰지 않고 뒤로 가지도 않습니다. 두 이벤트 사이를 재는 데 맞는 시계입니다
- **벽시계는 건너뛸 수 있다**: 시각을 맞추는 순간 앞으로도 뒤로도 뜁니다. 벽시계의 타임스탬프 둘을 빼서 간격을 재면, 그사이에 시각이 맞춰졌을 때 엉뚱한 값이 나옵니다
- **HTE는 하드웨어가 있어야 한다**: 리눅스 커널 문서는 지원하는 하드웨어와 그 기능을 넣어 빌드한 커널이 있어야 하고, 없으면 요청이 `EOPNOTSUPP`로 거절된다고 적습니다. 라즈베리파이에서 되는지는 확인하지 못했습니다
- **줄 정보에 보인다**: `gpioinfo`는 기본이 아닌 시계를 `event-clock=realtime`처럼 적습니다([「gpiodetect와 gpioinfo」](#/read/libgpiod/tl-detect))

## 벽시계로 찍기

같은 프로그램에 `realtime`을 주면 타임스탬프가 벽시계의 것으로 바뀝니다.

```text
핀|   1.200s  감지기 → HIGH
2026-11-23 09:00:01.200  rising   800ms 뒤에 읽음
핀|   2.700s  감지기 → LOW
2026-11-23 09:00:02.700  falling  300ms 뒤에 읽음
    머문 시간 1500ms
핀|   4.100s  감지기 → HIGH
핀|   4.200s  감지기 → LOW
2026-11-23 09:00:04.100  rising   900ms 뒤에 읽음
2026-11-23 09:00:04.200  falling  800ms 뒤에 읽음
    머문 시간 100ms
```

- **날짜와 시각으로 바꿔 적는다**: 나노초를 10억으로 나눈 몫이 `time_t`입니다. 그것을 `localtime_r`과 `strftime`으로 바꿨습니다
- **켜진 직후의 벽시계는 틀릴 수 있다**: 4에는 꺼져 있는 동안 가는 시계가 없습니다. 네트워크에서 시각을 받기 전에 찍힌 타임스탬프는 틀린 시각을 가리킵니다([「첫 부팅과 갱신」](#/read/sbc-start/os-first-boot))
- **간격도 날짜도 필요하면**: 단조 시계로 찍고, 적을 때에만 벽시계로 옮깁니다. 지금의 벽시계에서 지금의 단조 시계를 뺀 값을 타임스탬프에 더합니다

## 타임스탬프의 정밀함

- **단위가 나노초일 뿐이다**: 타임스탬프는 커널이 인터럽트를 받아 처리하기 시작할 때 읽은 시계입니다. 핀이 바뀐 순간과의 사이에는 인터럽트가 처리되기까지의 지연이 끼어 있고, 그 지연은 그때그때 다릅니다([「사용자 공간에서 얼마나 정확한가」](#/read/libgpiod/tm-jitter))
- **디바운스를 켜면 늦게 찍힌다**: 거르는 기간을 적은 줄의 타임스탬프는 에지가 난 때가 아니라 그 기간이 끝난 때입니다([「디바운스」](#/read/libgpiod/ed-debounce))
- **뺄셈은 정수로 한다**: 타임스탬프는 `uint64_t`입니다. 차이를 먼저 구하고 나서 밀리초나 초로 바꿉니다. 벽시계의 나노초는 `double`에 다 들어가지 않습니다

<Note>
예제는 이 책의 흉내 칩에서 돌린 것이고, 감지기의 출력은 대본으로 넣었습니다. `핀|`으로 시작하는 줄은 흉내 칩이 핀의 전압이 바뀔 때 적은 것입니다. 흉내 칩의 시계는 가상입니다. 켠 지 5000초 된 보드로, 벽시계는 2026년 11월 23일 0시(UTC)에서 시작하게 꾸몄고, 둘째 출력의 9시는 한국 시각으로 바꿔 적힌 것입니다. 두 시계의 성질은 clock_getres(2)에, HTE의 조건은 리눅스 커널 문서에 적혀 있습니다. 진짜 libgpiod 2.2.4의 머리 파일로 x86-64와 aarch64에서 컴파일되는지 따로 확인했고, 보드에서 돌려 보지는 못했습니다.
</Note>

## 정리

- 타임스탬프는 커널이 에지를 알아챈 때에 찍힌다. 프로그램이 늦게 읽어도 달라지지 않는다
- 기본은 켜진 뒤로 흐른 시간을 재는 단조 시계다. 간격과 폭은 이 시계의 차이로 잰다
- 날짜와 시각이 필요하면 벽시계로 찍는다. 벽시계는 건너뛸 수 있어서 간격을 재는 데는 쓰지 않는다
