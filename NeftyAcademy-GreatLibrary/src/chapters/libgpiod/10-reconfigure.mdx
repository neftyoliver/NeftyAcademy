줄의 설정은 요청할 때 한 번 정하고 끝나는 것이 아닙니다. 평소에는 입력으로 듣다가 필요할 때 출력으로 바꾸는 선이 있고, 어떤 때에만 에지를 지켜봐야 하는 감지기가 있습니다. 그럴 때 줄을 놓았다가 다시 요청하지 않고, 쥔 채로 설정만 바꾸는 함수가 있습니다.

## 다시 설정하는 함수와 규칙

- **`gpiod_line_request_reconfigure_lines`**: 요청과 새 line_config를 받아, 줄을 놓지 않은 채 설정을 바꿉니다. 성공하면 0, 실패하면 -1입니다
- **쥔 채로 바뀐다**: 놓았다가 다시 요청하는 것과 달리 빈틈이 없습니다. 그사이에 다른 프로그램이 줄을 가져가거나 핀이 엉뚱한 상태를 거칠 일이 없습니다
- **요청한 줄을 모두, 같은 차례로 적는다**: 새 config에는 요청할 때의 줄 전부를 그때의 차례대로 담습니다. 하나라도 빠지거나 차례가 다르면 libgpiod가 `EINVAL`로 거절합니다([「gpiod_chip_request_lines」](#/read/libgpiod/rq-request))
- **바꿀 수 있는 것**: 방향, 바이어스, 드라이브, 액티브 로, 에지 감지, 디바운스, 이벤트 시계, 출력값입니다. line_settings에 적는 것 전부입니다
- **바꿀 수 없는 것**: 어떤 줄을 쥐는지, 소비자 이름, 이벤트 버퍼의 크기입니다. 요청할 때 굳는 것들이라, 바꾸려면 놓고 다시 요청합니다

## 경보를 켜고 끄는 예제

아래 예제는 표시등과 감지기를 한 요청에 쥐고, 1초마다 경보를 켰다 껐다 합니다. 경보가 켜진 동안에만 감지기의 에지를 보고 표시등을 켭니다. 감지기는 매 초의 가운데에 0.1초 동안 HIGH를 냅니다.

```c gpiosim=alarm
// 표시등과 감지기를 한 요청에 쥐고, 경보를 켜고 끌 때마다 두 줄을 다시 설정한다
#include <errno.h>
#include <gpiod.h>
#include <stdio.h>
#include <string.h>
#include <threads.h>

enum { LED = 17, SENSOR = 23, ROOM = 8 };    // GPIO 17은 핀 11, GPIO 23은 핀 16

// 두 줄의 설정을 담은 config를 만든다. 담는 차례는 언제나 LED, SENSOR다
static struct gpiod_line_config* make_config(bool armed) {
    struct gpiod_line_settings* led = gpiod_line_settings_new();
    struct gpiod_line_settings* sensor = gpiod_line_settings_new();
    struct gpiod_line_config* config = gpiod_line_config_new();
    if (led && sensor && config) {
        // 표시등: 경보가 켜져 있는 동안 켠다. 출력값도 설정의 일부다
        gpiod_line_settings_set_direction(led, GPIOD_LINE_DIRECTION_OUTPUT);
        gpiod_line_settings_set_output_value(
            led, armed ? GPIOD_LINE_VALUE_ACTIVE : GPIOD_LINE_VALUE_INACTIVE);
        // 감지기: 경보가 켜져 있는 동안에만 에지를 본다
        gpiod_line_settings_set_direction(sensor, GPIOD_LINE_DIRECTION_INPUT);
        gpiod_line_settings_set_edge_detection(
            sensor, armed ? GPIOD_LINE_EDGE_RISING : GPIOD_LINE_EDGE_NONE);
        gpiod_line_config_add_line_settings(config, &(unsigned int){LED}, 1, led);
        gpiod_line_config_add_line_settings(config, &(unsigned int){SENSOR}, 1,
                                            sensor);
    }
    gpiod_line_settings_free(sensor);
    gpiod_line_settings_free(led);
    return config;
}

// 감지기 한 줄만 담은 config. 요청에는 두 줄이 들어 있으므로 받아들여지지 않는다
static struct gpiod_line_config* make_partial_config(void) {
    struct gpiod_line_settings* sensor = gpiod_line_settings_new();
    struct gpiod_line_config* config = gpiod_line_config_new();
    if (sensor && config) {
        gpiod_line_settings_set_edge_detection(sensor, GPIOD_LINE_EDGE_RISING);
        gpiod_line_config_add_line_settings(config, &(unsigned int){SENSOR}, 1,
                                            sensor);
    }
    gpiod_line_settings_free(sensor);
    return config;
}

int main(void) {
    struct gpiod_chip* chip = gpiod_chip_open("/dev/gpiochip0");
    if (!chip) {
        perror("/dev/gpiochip0");
        return 1;
    }
    struct gpiod_line_config* config = make_config(false);
    struct gpiod_line_request* lines =
        config ? gpiod_chip_request_lines(chip, nullptr, config) : nullptr;
    gpiod_line_config_free(config);
    gpiod_chip_close(chip);
    struct gpiod_edge_event_buffer* buffer = gpiod_edge_event_buffer_new(ROOM);
    if (!lines || !buffer) {
        perror("요청");
        return 1;
    }
    config = make_partial_config();
    if (config && gpiod_line_request_reconfigure_lines(lines, config) < 0) {
        printf("한 줄만 적은 설정: %s\n", strerror(errno));
    }
    gpiod_line_config_free(config);

    bool armed = false;
    for (int second = 1; second <= 4; ++second) {
        thrd_sleep(&(struct timespec){.tv_sec = 1}, nullptr);
        int events = 0;                      // 지난 1초 동안 온 이벤트
        unsigned long last = 0;
        while (gpiod_line_request_wait_edge_events(lines, 0) == 1) {
            int count = gpiod_line_request_read_edge_events(lines, buffer, ROOM);
            for (int i = 0; i < count; ++i, ++events) {
                last = gpiod_edge_event_get_line_seqno(
                    gpiod_edge_event_buffer_get_event(buffer, (unsigned long)i));
            }
        }
        printf("%d초까지 경보 %s: 이벤트 %d개", second, armed ? "켬" : "끔",
               events);
        if (events > 0) printf(", 마지막 번호 %lu", last);
        printf("\n");

        armed = !armed;                      // 줄을 쥔 채로 설정만 바꾼다
        config = make_config(armed);
        if (!config || gpiod_line_request_reconfigure_lines(lines, config) < 0) {
            perror("다시 설정하기");
        }
        gpiod_line_config_free(config);
    }
    gpiod_edge_event_buffer_free(buffer);
    gpiod_line_request_release(lines);
}
```

```text
한 줄만 적은 설정: Invalid argument
핀|   0.500s  감지기 → HIGH
핀|   0.600s  감지기 → LOW
1초까지 경보 끔: 이벤트 0개
핀|   1.000s  표시등 → HIGH
핀|   1.500s  감지기 → HIGH
핀|   1.600s  감지기 → LOW
2초까지 경보 켬: 이벤트 1개, 마지막 번호 1
핀|   2.000s  표시등 → LOW
핀|   2.500s  감지기 → HIGH
핀|   2.600s  감지기 → LOW
3초까지 경보 끔: 이벤트 0개
핀|   3.000s  표시등 → HIGH
핀|   3.500s  감지기 → HIGH
핀|   3.600s  감지기 → LOW
4초까지 경보 켬: 이벤트 1개, 마지막 번호 2
핀|   4.000s  표시등 → LOW
```

- **끈 동안에는 이벤트가 생기지 않는다**: 0.5초와 2.5초에도 감지기는 HIGH를 냈습니다. 그러나 에지 감지가 꺼져 있어서 커널은 아무것도 적지 않았습니다. 받아서 버리는 것과 달리 프로그램도 커널도 깨어나지 않습니다
- **번호는 이어진다**: 두 번째 이벤트의 줄 번호가 2입니다. 다시 설정해도 같은 요청이어서 번호를 처음부터 다시 세지 않습니다([「이벤트 버퍼」](#/read/libgpiod/ed-buffer))
- **출력값도 다시 적는다**: 표시등은 방향이 바뀌지 않는데도 매번 설정에 담았고, 켤지 끌지를 `gpiod_line_settings_set_output_value`로 적었습니다. 적지 않으면 inactive로 나갑니다
- **한 줄만 적으면 거절된다**: 감지기만 담은 config는 `EINVAL`이었습니다. 바꾸지 않을 줄도 지금의 설정대로 다시 적어야 합니다
- **값만 바꿀 때에는 쓰지 않는다**: 출력의 값만 바꾸는 일은 `gpiod_line_request_set_value`가 합니다([「LED 켜기」](#/read/libgpiod/out-led))

## 옛 설정을 갈아치운다는 것

- **빠뜨린 것은 기본값이 된다**: 새 settings는 옛 설정에 덧붙지 않습니다. 단추 줄에 에지 감지만 적어서 다시 설정하면 액티브 로와 디바운스가 사라집니다. 요청할 때 쓴 함수로 settings를 통째로 다시 만드는 것이 안전합니다
- **방향을 적지 않은 줄은 바뀌지 않는다**: 커널은 방향이 적히지 않은 줄을 건너뜁니다. 오류도 나지 않습니다. 액티브 로만 적은 settings로는 아무 일도 일어나지 않으므로, 방향을 늘 함께 적습니다
- **풀은 매번 적는다**: 바이어스를 적지 않으면 커널은 풀을 새로 걸지도 풀지도 않습니다. 앞서 건 풀이 남아 있으리라고 기대지 않습니다([「바이어스 설정」](#/read/libgpiod/in-bias))
- **입력을 출력으로 바꾸면**: 에지 감지는 꺼지고, 줄은 settings에 적은 출력값으로 곧바로 나갑니다. 이미 버퍼에 들어 있던 이벤트는 남아서 그 뒤에도 읽을 수 있습니다
- **지켜보는 쪽에 알림이 간다**: 다시 설정된 줄마다 줄 정보가 바뀌었다는 이벤트가 나갑니다([「줄 정보 읽기」](#/read/libgpiod/ch-info))
- **도중에 실패하면 되돌려지지 않는다**: 설정 자체가 틀렸으면 커널은 아무 줄도 건드리지 않고 거절합니다. 그러나 줄을 하나씩 바꿔 가다가 실패하면 앞의 줄들은 바뀐 채로 남습니다. 실패한 뒤에는 줄 정보를 다시 읽거나, 놓고 새로 요청합니다

## 놓고 다시 요청하는 길

| | 다시 설정하기 | 놓고 다시 요청하기 |
| --- | --- | --- |
| 줄 | 내내 쥐고 있다 | 잠깐 놓는다 |
| 그사이 핀의 상태 | 앞의 것에서 새것으로 바로 | 정해져 있지 않다 |
| 줄의 구성, 이름, 버퍼 크기 | 못 바꾼다 | 바꿀 수 있다 |
| 쌓인 이벤트와 번호 | 남는다 | 사라지고 1부터 다시 |

- **양방향 선이 본래의 쓰임이다**: 리눅스 커널 문서는 입력과 출력을 오가는 선을 이 기능을 둔 까닭으로 들고, 에지 감지를 켜고 끄는 데에도 쓸 수 있다고 적습니다
- **빠르게 오가는 선은 다른 일이다**: 1-Wire처럼 방향을 아주 빠르게 바꿔 가며 말하는 선은 이 함수를 불러서는 따라가지 못합니다([「커널 드라이버에 맡길 것들」](#/read/libgpiod/tm-kernel))
- **놓는 쪽이 맞을 때**: 줄을 더하거나 빼야 할 때, 버퍼를 키워야 할 때입니다. 놓은 동안의 핀은 책임질 수 없다는 것을 셈에 넣습니다([「놓아주기」](#/read/libgpiod/rq-release))

<Note>
예제는 이 책의 흉내 칩에서 돌린 것이고, 감지기의 출력은 대본으로 넣었습니다. `핀|`으로 시작하는 줄은 흉내 칩이 핀의 전압이 바뀔 때 적은 것입니다. 줄을 모두 같은 차례로 적어야 한다는 것은 libgpiod 2.2.4의 소스에서, 방향 없는 줄을 건너뛰는 것과 이벤트와 번호가 남는 것, 되돌리지 않는 것은 리눅스 커널의 문서와 소스에서 읽었습니다. 흉내 칩은 그대로 따르게 만든 것이고, 보드에서 확인한 것은 아닙니다. 진짜 libgpiod 2.2.4의 머리 파일로 x86-64와 aarch64에서 컴파일되는지 따로 확인했습니다.
</Note>

## 정리

- `gpiod_line_request_reconfigure_lines`는 줄을 쥔 채로 설정을 바꾼다. 요청한 줄을 모두, 같은 차례로 적는다
- 새 설정은 옛 설정을 통째로 갈아치운다. 방향을 적지 않은 줄은 바뀌지 않는다
- 줄의 구성과 소비자 이름, 버퍼 크기는 바꿀 수 없다. 그것은 놓고 다시 요청할 일이다
