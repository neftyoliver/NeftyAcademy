줄을 요청할 때 적는 것은 오프셋이라는 숫자입니다. 그런데 `gpioinfo`를 보면 줄마다 `GPIO17`이나 `ID_SDA` 같은 이름이 붙어 있고, 도구들은 그 이름으로 줄을 찾습니다. 프로그램에서도 이름을 오프셋으로 바꿔 쓸 수 있습니다. 숫자를 코드에 박는 것보다 낫겠다 싶지만, 이름에는 이름대로 조심할 것이 있습니다.

## 이름으로 오프셋 얻기

```c gpiosim
// 줄을 이름으로 찾는다. 있는 이름은 보드마다 다르다
#include <errno.h>
#include <gpiod.h>
#include <stdio.h>
#include <string.h>

// 이름 여럿 가운데 이 칩에 있는 첫 이름의 오프셋을 돌려준다. 없으면 -1
static int find_any(struct gpiod_chip* chip, const char* const names[], size_t n) {
    for (size_t i = 0; i < n; ++i) {
        int offset = gpiod_chip_get_line_offset_from_name(chip, names[i]);
        if (offset >= 0) return offset;
        if (errno != ENOENT) return -1;      // 못 찾은 것이 아니라 다른 오류다
    }
    errno = ENOENT;
    return -1;
}

int main(void) {
    struct gpiod_chip* chip = gpiod_chip_open("/dev/gpiochip0");
    if (!chip) {
        perror("/dev/gpiochip0");
        return 1;
    }
    const char* const ask[] = {"GPIO17", "GPIO4", "GPIO_GCLK", "ID_SDA", "gpio17"};
    for (size_t i = 0; i < sizeof ask / sizeof ask[0]; ++i) {
        int offset = gpiod_chip_get_line_offset_from_name(chip, ask[i]);
        if (offset >= 0)
            printf("%-10s %d\n", ask[i], offset);
        else
            printf("%-10s -1  %s\n", ask[i], strerror(errno));
    }
    // 헤더의 핀 7은 4에서는 GPIO_GCLK, 5에서는 GPIO4라는 이름이다
    const char* const pin7[] = {"GPIO4", "GPIO_GCLK"};
    printf("pin 7      %d\n", find_any(chip, pin7, 2));
    gpiod_chip_close(chip);
}
```

```text
GPIO17     17
GPIO4      -1  No such file or directory
GPIO_GCLK  4
ID_SDA     0
gpio17     -1  No such file or directory
pin 7      4
```

- **`gpiod_chip_get_line_offset_from_name`**: 그 칩에서 이름이 같은 줄의 오프셋을 돌려줍니다. 없으면 -1을 돌려주고 `errno`를 `ENOENT`로 둡니다. 글귀가 파일이 없다고 나오는 것은 그 번호의 풀이가 원래 그래서입니다
- **글자 그대로 같아야 한다**: `gpio17`은 찾지 못했습니다. 대문자와 소문자를 가립니다
- **0번부터 차례로 훑는다**: 부를 때마다 줄의 정보를 하나씩 커널에 물어 가며 견줍니다. 한 번 찾아 변수에 두고 쓰고, 되풀이되는 자리에서 다시 부르지 않습니다
- **같은 이름이 둘이면 앞의 것**: 커널은 이름이 겹치는 것을 막지 않습니다. 이 함수는 처음 만난 줄을 돌려줍니다
- **이름 없는 줄은 찾을 수 없다**: 그런 줄은 오프셋으로만 가리킵니다
- **위는 4의 결과다**: `GPIO4`라는 이름이 4에는 없습니다. 같은 핀이 `GPIO_GCLK`로 불립니다

같은 프로그램을 5에서 돌리면 둘째와 셋째 줄이 뒤바뀝니다.

```text
GPIO17     17
GPIO4      4
GPIO_GCLK  -1  No such file or directory
ID_SDA     0
gpio17     -1  No such file or directory
pin 7      4
```

- **`find_any`가 한 일**: 헤더의 핀 7을 두 이름으로 차례로 찾아서, 두 보드에서 같은 4를 얻었습니다. 이름으로 찾으려면 이런 수고가 따릅니다
- **못 찾은 것과 오류를 가른다**: `ENOENT`가 아닌 `errno`는 이름이 없다는 뜻이 아닙니다. 그때는 다음 이름으로 넘어가지 않고 돌아갑니다

## 이름은 어디서 오나

| 헤더의 핀 | 오프셋 | 4의 이름 | 5의 이름 |
| --- | --- | --- | --- |
| 3 | 2 | `SDA1` | `GPIO2` |
| 7 | 4 | `GPIO_GCLK` | `GPIO4` |
| 8 | 14 | `TXD1` | `GPIO14` |
| 11 | 17 | `GPIO17` | `GPIO17` |
| 27 | 0 | `ID_SDA` | `ID_SDA` |

- **보드를 설명하는 디바이스 트리에 적혀 있다**: `gpio-line-names`라는 항목에 보드를 만든 쪽이 오프셋 차례로 이름을 적어 둡니다. 커널은 그것을 그대로 내줍니다
- **그래서 보드마다 다르다**: 4의 이름은 그 핀의 대표 기능을 따랐고, 5의 이름은 헤더의 줄을 번호로 불렀습니다. 오프셋은 두 보드에서 같습니다([「핀 번호: 헤더, BCM, 줄 오프셋」](#/read/libgpiod/gp-numbering))
- **내 보드의 이름은 `gpioinfo`로 본다**: 글이나 책에 적힌 이름을 믿지 말고 그 보드에서 찍어 봅니다. 커널이 바뀌면서 이름이 달라질 수도 있습니다

## 이름과 오프셋 가운데 고르기

| 상황 | 권하는 쪽 |
| --- | --- |
| 헤더의 핀을 쓰는 라즈베리파이 프로그램 | 오프셋. 모델이 달라도 같다 |
| 직접 만든 보드나 캐리어 보드 | 디바이스 트리에 붙인 이름 |
| 보드 안의 줄 | 이름. 오프셋은 보드의 개정마다 다를 수 있다 |
| 남에게 건네는 도구 | 둘 다 받게 한다 |

- **헤더에는 오프셋이 낫다**: GPIO 번호가 곧 오프셋이고 핀 지도와 바로 맞춰 볼 수 있습니다. 이 책의 예제가 `enum { LED = 17 };`처럼 적는 까닭입니다
- **이름이 빛나는 곳은 내 보드다**: 디바이스 트리에 `RELAY_1`, `DOOR_SENSOR`처럼 역할을 이름으로 붙여 두면, 보드를 고쳐 그 선이 다른 핀으로 옮겨 가도 코드는 그대로입니다
- **여러 칩에 걸쳐 찾으려면**: 이 함수는 칩 하나만 봅니다. 도구들처럼 칩을 번호 차례로 열어 가며 찾습니다([「라즈베리파이 5에서 깨진 것들」](#/read/libgpiod/hs-pi5)의 예제가 칩을 훑는 꼴입니다)
- **찾은 다음에는 요청한다**: 오프셋을 얻었으면 나머지는 숫자로 적었을 때와 같습니다([「gpiod_chip_request_lines」](#/read/libgpiod/rq-request))

<Note>
예제는 이 책의 흉내 칩에서 4와 5의 줄 이름으로 한 번씩 돌린 것입니다. 4의 이름은 리눅스 커널의 4 Model B 디바이스 트리에서, 5의 이름은 커널의 RP1 바인딩 문서에서 옮겨 넣었습니다. 함수가 줄을 0번부터 훑는다는 것과 첫 줄을 돌려준다는 것은 libgpiod 2.2.4의 소스에서 읽었습니다. 진짜 머리 파일로 x86-64와 aarch64에서 컴파일되는지 따로 확인했고, 보드에서 이름을 찍어 보지는 못했습니다.
</Note>

## 정리

- `gpiod_chip_get_line_offset_from_name`은 칩의 줄을 훑어 이름이 같은 첫 줄의 오프셋을 준다. 없으면 -1과 `ENOENT`다
- 이름은 디바이스 트리에서 오고 보드마다 다르다. 4와 5의 헤더는 오프셋은 같고 이름이 다르다
- 헤더의 핀에는 오프셋을, 직접 만든 보드에는 역할을 담은 이름을 쓴다
