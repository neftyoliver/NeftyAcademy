지금까지의 출력은 HIGH도 내고 LOW도 냈습니다. 이것을 푸시풀이라고 합니다. 한 선에 장치가 하나씩 물려 있을 때는 이것으로 충분합니다. 그런데 한 선을 여러 장치가 함께 쓰려면, 한쪽이 HIGH를 내는 동안 다른 쪽이 LOW를 내는 일이 없어야 합니다. 그래서 선을 당기기만 하고 밀지는 않는 출력이 있습니다.

## 드라이브 세 가지

| 드라이브 | active를 쓰면 | inactive를 쓰면 | 선에 있어야 하는 것 |
| --- | --- | --- | --- |
| 푸시풀 | HIGH를 낸다 | LOW를 낸다 | 없다 |
| 오픈 드레인 | 선을 놓는다 | LOW로 당긴다 | 풀업 |
| 오픈 소스 | HIGH로 민다 | 선을 놓는다 | 풀다운 |

- **놓는다는 것**: 핀이 선에 아무 힘도 쓰지 않는 것입니다. 그때 선의 전압은 풀 저항과 선에 물린 다른 장치가 정합니다
- **기본은 푸시풀이다**: 드라이브를 적지 않으면 푸시풀입니다
- **출력에만 붙는다**: 입력으로 요청하는 줄에 드라이브를 적으면 요청이 거절됩니다([「gpiod_chip_request_lines」](#/read/libgpiod/rq-request))

## 한 선을 함께 쓰기

아래 예제는 GPIO 22를 오픈 드레인으로 쥡니다. 그 선에는 다른 장치도 물려 있어서, 1초에 선을 LOW로 당겼다가 2초에 놓습니다.

```c gpiosim=shared
// 오픈 드레인: 선을 LOW로 당기거나 놓기만 한다. 놓은 선은 풀업이 HIGH로 올린다
#include <gpiod.h>
#include <stdio.h>
#include <threads.h>

enum { WIRE = 22 };                          // GPIO 22, 헤더의 핀 15

static void nap(long ms) {
    thrd_sleep(&(struct timespec){.tv_sec = ms / 1000,
                                  .tv_nsec = ms % 1000 * 1'000'000},
               nullptr);
}

int main(void) {
    struct gpiod_chip* chip = gpiod_chip_open("/dev/gpiochip0");
    struct gpiod_line_settings* settings = gpiod_line_settings_new();
    struct gpiod_line_config* config = gpiod_line_config_new();
    if (!chip || !settings || !config) {
        perror("준비");
        return 1;
    }
    // 출력, 오픈 드레인, 칩 안의 풀업. 첫 값 active는 선을 놓는다는 뜻이다
    unsigned int offset = WIRE;
    gpiod_line_settings_set_direction(settings, GPIOD_LINE_DIRECTION_OUTPUT);
    gpiod_line_settings_set_drive(settings, GPIOD_LINE_DRIVE_OPEN_DRAIN);
    gpiod_line_settings_set_bias(settings, GPIOD_LINE_BIAS_PULL_UP);
    gpiod_line_settings_set_output_value(settings, GPIOD_LINE_VALUE_ACTIVE);
    gpiod_line_config_add_line_settings(config, &offset, 1, settings);
    struct gpiod_line_request* wire =
        gpiod_chip_request_lines(chip, nullptr, config);
    gpiod_line_config_free(config);
    gpiod_line_settings_free(settings);
    gpiod_chip_close(chip);
    if (!wire) {
        perror("요청");
        return 1;
    }
    printf("놓은 채로 읽는다: %d\n", gpiod_line_request_get_value(wire, WIRE));
    nap(1500);
    printf("놓은 채로 읽는다: %d\n", gpiod_line_request_get_value(wire, WIRE));
    nap(1000);
    printf("놓은 채로 읽는다: %d\n", gpiod_line_request_get_value(wire, WIRE));

    printf("내가 당긴다\n");
    gpiod_line_request_set_value(wire, WIRE, GPIOD_LINE_VALUE_INACTIVE);
    nap(500);
    printf("내가 놓는다\n");
    gpiod_line_request_set_value(wire, WIRE, GPIOD_LINE_VALUE_ACTIVE);
    gpiod_line_request_release(wire);
}
```

```text
핀|   0.000s  GPIO 22 → HIGH
놓은 채로 읽는다: 1
핀|   1.000s  GPIO 22 → LOW
놓은 채로 읽는다: 0
핀|   2.000s  GPIO 22 → HIGH
놓은 채로 읽는다: 1
내가 당긴다
핀|   2.500s  GPIO 22 → LOW
내가 놓는다
핀|   3.000s  GPIO 22 → HIGH
```

- **`gpiod_line_settings_set_drive`**: `GPIOD_LINE_DRIVE_OPEN_DRAIN`을 줍니다. 풀업은 `gpiod_line_settings_set_bias`로 칩 안의 것을 켰습니다
- **놓은 선은 풀업이 올린다**: 요청하자마자 HIGH가 된 것은 내가 낸 것이 아니라 풀업이 올린 것입니다
- **놓고 있는데 0이 읽혔다**: 1.5초에 읽은 값입니다. 나는 선을 놓고 있으므로, LOW라면 다른 장치가 당기고 있다는 뜻입니다. 오픈 드레인의 선은 쓰면서 동시에 남의 말을 들을 수 있습니다
- **누구든 당기면 LOW다**: 선은 모두가 놓았을 때에만 HIGH입니다. 둘이 한꺼번에 당겨도 둘 다 LOW로 당길 뿐이라 서로 맞서지 않습니다
- **푸시풀이었다면**: 내가 HIGH를 내는 동안 다른 장치가 LOW로 당기는 1초부터 2초 사이에 두 출력이 맞붙어 큰 전류가 흘렀을 것입니다([「3.3V, 전류 한계, 보호 저항」](#/read/libgpiod/gp-electrical))

## 어디에 쓰나

- **여러 장치가 물리는 버스**: I2C와 1-Wire의 선이 오픈 드레인입니다. 그 버스들을 GPIO로 직접 흉내 낼 때 이 드라이브를 씁니다([「비트뱅잉」](#/read/libgpiod/tm-bitbang))
- **함께 쓰는 알림 선**: 여러 칩이 인터럽트나 리셋 선 하나를 나눠 쓸 때, 어느 칩이든 당기면 모두가 알게 됩니다
- **오픈 소스는 드물다**: 방향이 반대일 뿐 같은 원리입니다. 풀다운이 달린 선을 여럿이 HIGH로 미는 회로에 씁니다

## 풀업과 조심할 점

- **풀업이 없으면 HIGH가 없다**: 놓은 선을 올려 줄 것이 없으면 선은 떠 있습니다. 칩 안의 풀업을 켜거나 바깥에 저항을 답니다
- **칩 안의 풀업은 약하다**: 수십 kΩ이라 선이 천천히 올라갑니다. 빠른 신호나 긴 선에는 바깥에 몇 kΩ짜리를 답니다([「풀업과 풀다운」](#/read/libgpiod/gp-pull))
- **풀업은 3.3V로만 건다**: 놓은 선의 전압은 풀업이 이어진 전원의 전압입니다. 5V에 이으면 라즈베리파이의 핀에 5V가 걸립니다. 핀은 그것을 견디지 못합니다
- **커널이 흉내 낼 수도 있다**: 칩에 오픈 드레인 기능이 없으면 커널이 줄을 놓을 때 입력으로 돌리는 식으로 같은 일을 합니다. 프로그램에서 보이는 것은 같습니다
- **`gpioinfo`에 보인다**: 그 줄에 `drive=open-drain`이 붙습니다

<Note>
예제는 이 책의 흉내 칩에서 돌린 것이고, 같은 선에 물린 다른 장치는 대본으로 넣었습니다. `핀|`으로 시작하는 줄은 흉내 칩이 선의 전압이 바뀔 때 적은 것입니다. 오픈 드레인인 줄을 읽으면 흉내 칩은 선의 실제 전압을 돌려주는데, 진짜 보드에서 무엇이 돌아오는지는 드라이버에 달렸다고 커널 문서가 적고 있어 보드에서 확인해야 합니다. 커널이 드라이브를 흉내 낸다는 것은 커널 문서의 줄 요청 대목에 있습니다. 진짜 libgpiod 2.2.4의 머리 파일로 x86-64와 aarch64에서 컴파일되는지 따로 확인했습니다.
</Note>

## 정리

- 푸시풀은 HIGH와 LOW를 다 내고, 오픈 드레인은 LOW로 당기거나 놓고, 오픈 소스는 HIGH로 밀거나 놓는다
- 오픈 드레인의 선은 풀업이 있어야 HIGH가 되고, 누구든 당기면 LOW다. 여러 장치가 맞붙지 않고 한 선을 쓴다
- 풀업은 3.3V에만 잇는다. 놓은 채로 읽으면 다른 장치가 당기고 있는지를 안다
