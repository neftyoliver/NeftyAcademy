입력은 바깥의 회로가 핀에 건 전압을 0과 1로 읽는 일입니다. 읽는 함수는 하나이고 쓰기보다 간단합니다. 어려운 것은 언제 읽느냐입니다. 읽은 값은 읽은 그 순간의 것일 뿐이라, 읽지 않은 사이에 벌어진 일은 프로그램이 알지 못합니다.

## 읽기

아래 예제는 움직임 감지기의 출력을 0.5초마다 읽습니다. 감지기는 한 번은 1.5초 동안, 한 번은 0.1초 동안 HIGH를 냅니다.

```c gpiosim=pir
// 감지기의 출력을 0.5초마다 읽어, 값이 바뀌었을 때만 적는다
#include <gpiod.h>
#include <stdio.h>
#include <threads.h>

enum { SENSOR = 23 };                        // GPIO 23, 헤더의 핀 16

// 줄 하나를 입력으로 요청한다
static struct gpiod_line_request* request_input(struct gpiod_chip* chip,
                                                unsigned int offset,
                                                const char* consumer) {
    struct gpiod_line_settings* settings = gpiod_line_settings_new();
    struct gpiod_line_config* config = gpiod_line_config_new();
    struct gpiod_request_config* request_config = gpiod_request_config_new();
    struct gpiod_line_request* request = nullptr;
    if (settings && config && request_config) {
        gpiod_line_settings_set_direction(settings, GPIOD_LINE_DIRECTION_INPUT);
        gpiod_line_config_add_line_settings(config, &offset, 1, settings);
        gpiod_request_config_set_consumer(request_config, consumer);
        request = gpiod_chip_request_lines(chip, request_config, config);
    }
    gpiod_request_config_free(request_config);
    gpiod_line_config_free(config);
    gpiod_line_settings_free(settings);
    return request;
}

int main(void) {
    struct gpiod_chip* chip = gpiod_chip_open("/dev/gpiochip0");
    if (!chip) {
        perror("/dev/gpiochip0");
        return 1;
    }
    struct gpiod_line_request* sensor = request_input(chip, SENSOR, "motion");
    gpiod_chip_close(chip);
    if (!sensor) {
        perror("요청");
        return 1;
    }
    const struct timespec half = {.tv_nsec = 500'000'000};
    enum gpiod_line_value before = GPIOD_LINE_VALUE_INACTIVE;
    int changes = 0;
    for (int tick = 0; tick <= 10; ++tick) {
        enum gpiod_line_value now = gpiod_line_request_get_value(sensor, SENSOR);
        if (now == GPIOD_LINE_VALUE_ERROR) {
            perror("읽기");
            break;
        }
        if (now != before) {
            printf("%d.%d초에 읽으니 %s\n", tick / 2, tick % 2 * 5,
                   now == GPIOD_LINE_VALUE_ACTIVE ? "active" : "inactive");
            ++changes;
        }
        before = now;
        thrd_sleep(&half, nullptr);
    }
    printf("11번 읽었고 값이 바뀐 것은 %d번\n", changes);
    gpiod_line_request_release(sensor);
}
```

```text
핀|   1.200s  감지기 → HIGH
1.5초에 읽으니 active
핀|   2.700s  감지기 → LOW
3.0초에 읽으니 inactive
핀|   4.100s  감지기 → HIGH
핀|   4.200s  감지기 → LOW
11번 읽었고 값이 바뀐 것은 2번
```

- **`request_input`**: 방향만 입력으로 적어 요청합니다. 출력 때의 도우미와 한 줄이 다릅니다
- **`gpiod_line_request_get_value`**: 요청 객체와 오프셋을 받아 `GPIOD_LINE_VALUE_ACTIVE`나 `GPIOD_LINE_VALUE_INACTIVE`를 돌려줍니다. 실패하면 `GPIOD_LINE_VALUE_ERROR`이고 그 값은 -1입니다
- **늦게 안다**: 감지기는 1.2초에 HIGH가 됐지만 프로그램은 1.5초에 읽고서야 알았습니다. 읽는 간격만큼은 늦을 수 있습니다
- **짧은 것은 놓친다**: 4.1초부터 4.2초까지의 신호는 4.0초와 4.5초의 읽기 사이에 지나갔습니다. `핀|` 줄에는 있지만 프로그램은 본 적이 없습니다

## 여러 줄을 한 번에

- **`gpiod_line_request_get_values`**: 요청에 든 모든 줄을 배열에 채워 줍니다. 차례는 config에 줄을 붙인 차례입니다([「여러 줄 한꺼번에 쓰기」](#/read/libgpiod/out-multi))
- **`gpiod_line_request_get_values_subset`**: 오프셋의 배열로 고른 줄만 읽습니다
- **같은 때의 값이 필요할 때**: 하나씩 따로 읽으면 그 사이에 한쪽이 바뀔 수 있습니다. 두 줄의 조합에 뜻이 있는 로터리 엔코더나 여러 열을 함께 보는 키패드에서는 한 번에 읽습니다([「로터리 엔코더」](#/read/libgpiod/pj-encoder))

## 값이 정해지는 조건

- **문턱이 둘이다**: 핀의 전압이 0.8V 아래면 LOW, 2.0V 위면 HIGH입니다. 그 사이의 전압은 어느 쪽으로 읽힐지 정해져 있지 않습니다
- **떠 있는 핀은 읽을 것이 없다**: 아무것도 이어지지 않은 입력은 풀 저항이 정해 줍니다. 풀도 없으면 손을 가까이 대는 것만으로 값이 바뀝니다([「바이어스 설정」](#/read/libgpiod/in-bias))
- **3.3V를 넘는 신호는 바로 잇지 않는다**: 5V를 내는 센서의 출력은 저항 둘로 나눠서 받습니다. 1kΩ과 2kΩ으로 나누면 3.3V가 됩니다([「3.3V, 전류 한계, 보호 저항」](#/read/libgpiod/gp-electrical))
- **읽는 값은 논리값이다**: 액티브 로로 요청한 줄은 LOW일 때 active로 읽힙니다([「액티브 로」](#/read/libgpiod/out-active-low))

## 훑어 읽기의 한계

- **상태를 알면 되는 것에는 충분하다**: 문이 열려 있는지, 물이 차 있는지, 스위치가 어느 쪽인지처럼 지금의 상태가 궁금한 것은 가끔 읽어도 됩니다
- **간격은 신호보다 짧게**: 놓치지 않으려면 신호가 머무는 가장 짧은 시간의 절반보다 자주 읽어야 합니다. 0.1초짜리를 잡으려면 0.05초마다 읽어야 하고, 그만큼 CPU를 깨웁니다
- **언제 바뀌었는지가 중요하면 에지를 쓴다**: 단추를 누른 순간, 펄스의 수, 두 신호 사이의 시간은 커널이 바뀌는 순간을 잡아 주게 합니다. 프로그램은 자고 있다가 일이 생겼을 때만 깹니다([「에지 감지 켜기」](#/read/libgpiod/ed-request))

<Note>
예제는 이 책의 흉내 칩에서 돌린 것이고, 감지기의 출력은 대본으로 넣었습니다. `핀|`으로 시작하는 줄은 흉내 칩이 핀의 전압이 바뀔 때 적은 것입니다. 문턱의 전압은 라즈베리파이 문서의 4와 5에 대한 값입니다. 진짜 libgpiod 2.2.4의 머리 파일로 x86-64와 aarch64에서 컴파일되는지 따로 확인했고, 보드와 감지기로 돌려 보지는 못했습니다.
</Note>

## 정리

- 줄을 입력으로 요청하고 `gpiod_line_request_get_value`로 읽는다. 돌아오는 것은 active, inactive, 오류 가운데 하나다
- 읽은 값은 그 순간의 것이다. 읽는 간격보다 짧은 신호는 놓치고, 변화는 간격만큼 늦게 안다
- 지금의 상태가 궁금하면 훑어 읽고, 바뀐 순간이 궁금하면 에지를 쓴다
