단추를 누르면 정말 신호가 들어오는지, 한 번 눌렀는데 몇 번으로 보이는지는 프로그램을 짜기 전에 알아 두는 편이 좋습니다. `gpiomon`은 줄의 에지를 기다렸다가 일어난 시각과 함께 한 줄씩 찍습니다. 입력 쪽 회로를 확인하는 도구이고, 신호의 박자를 재는 간단한 계측기이기도 합니다.

## gpiomon: 에지 지켜보기

```sh
gpiomon GPIO27                          # 양쪽 에지를 찍는다. Ctrl+C로 끝낸다
gpiomon -e falling -b pull-up GPIO27    # 풀업을 켜고 내려가는 에지만
gpiomon -n 3 GPIO27                     # 세 번 찍고 끝난다
gpiomon --idle-timeout 10s GPIO27       # 10초 동안 조용하면 끝난다
gpiomon -p 5ms GPIO27                   # 디바운스 5ms
gpiomon --localtime GPIO17 GPIO27       # 여러 줄을, 시각은 사람의 시계로
gpiomon -q -n 1 -e falling GPIO27       # 찍지 않고 첫 에지까지 기다리기만 한다
```

- **한 줄의 꼴**: 시각, `rising`이나 `falling`, 줄의 이름입니다. 시각은 커널이 에지를 잡은 때이고, 기본은 커널의 단조 시계로 잰 초입니다
- **`-e`**: `rising`, `falling`, `both` 가운데 하나이고 기본은 `both`입니다
- **에지는 논리값으로 센다**: `-l`로 액티브 로를 켜면 `rising`과 `falling`이 뒤바뀝니다([「에지 감지 켜기」](#/read/libgpiod/ed-request))
- **끝내는 길 셋**: `-n`은 그 수만큼 찍었을 때, `--idle-timeout`은 그동안 에지가 없을 때 끝냅니다. 둘 다 없으면 Ctrl+C입니다. `--idle-timeout`은 2.1에서 들어왔습니다
- **`-q`**: 아무것도 찍지 않습니다. `-n 1`과 함께 쓰면 단추가 눌릴 때까지 스크립트를 세워 두는 명령이 됩니다
- **`--localtime`과 `--utc`**: 시각을 날짜와 시로 찍습니다. 이때는 실시간 시계로 잽니다([「타임스탬프와 시계 고르기」](#/read/libgpiod/ed-timestamp))
- **`-F`**: 찍는 꼴을 정합니다. `%S`는 초, `%E`는 에지의 이름, `%l`은 줄 이름, `%o`는 오프셋, `%c`는 칩입니다. `gpiomon -F "%S %E %l"`처럼 씁니다
- **`gpiomon`도 줄을 쥔다**: 지켜보는 동안 다른 프로그램은 그 줄을 요청할 수 없고, 내 프로그램이 쥔 줄은 `gpiomon`으로 볼 수 없습니다

## 단추의 떨림을 재 보기

단추의 접점은 붙고 떨어질 때 잠깐 튑니다. 아래 예제는 `gpiomon`의 뼈대를 libgpiod로 짠 것입니다. GPIO 27과 GND 사이의 단추를 한 번 눌렀다 떼는 것을 디바운스 없이 지켜보고, 한 번 더 눌렀다 떼는 것을 디바운스 5ms로 지켜봅니다.

```c gpiosim=bounce
// gpiomon의 뼈대: 단추의 에지를 기다렸다가 찍는다. 디바운스 없이 한 번, 넣고 한 번
#include <gpiod.h>
#include <inttypes.h>
#include <stdio.h>

enum { BUTTON = 27, ROOM = 16 };             // GPIO 27은 헤더의 핀 13

// GPIO 27의 양쪽 에지를 찍는다. 2초 동안 조용하면 끝내고 찍은 수를 돌려준다
static int watch(struct gpiod_chip* chip, unsigned long debounce_us) {
    struct gpiod_line_settings* settings = gpiod_line_settings_new();
    struct gpiod_line_config* config = gpiod_line_config_new();
    struct gpiod_edge_event_buffer* buffer = gpiod_edge_event_buffer_new(ROOM);
    if (!settings || !config || !buffer) return -1;
    gpiod_line_settings_set_bias(settings, GPIOD_LINE_BIAS_PULL_UP);
    gpiod_line_settings_set_edge_detection(settings, GPIOD_LINE_EDGE_BOTH);
    gpiod_line_settings_set_debounce_period_us(settings, debounce_us);
    unsigned int offset = BUTTON;
    gpiod_line_config_add_line_settings(config, &offset, 1, settings);
    struct gpiod_line_request* request =
        gpiod_chip_request_lines(chip, nullptr, config);
    gpiod_line_config_free(config);
    gpiod_line_settings_free(settings);
    if (!request) {
        perror("요청");
        gpiod_edge_event_buffer_free(buffer);
        return -1;
    }
    int count = 0;
    const int64_t idle_ns = 2'000'000'000;
    while (gpiod_line_request_wait_edge_events(request, idle_ns) == 1) {
        int n = gpiod_line_request_read_edge_events(request, buffer, ROOM);
        for (int i = 0; i < n; ++i) {
            struct gpiod_edge_event* event =
                gpiod_edge_event_buffer_get_event(buffer, (unsigned long)i);
            uint64_t ns = gpiod_edge_event_get_timestamp_ns(event);
            bool rising = gpiod_edge_event_get_event_type(event) ==
                          GPIOD_EDGE_EVENT_RISING_EDGE;
            printf("%" PRIu64 ".%09" PRIu64 "  %-7s  \"GPIO27\"\n",
                   ns / 1'000'000'000, ns % 1'000'000'000,
                   rising ? "rising" : "falling");
            ++count;
        }
    }
    gpiod_edge_event_buffer_free(buffer);
    gpiod_line_request_release(request);
    return count;
}

int main(void) {
    struct gpiod_chip* chip = gpiod_chip_open("/dev/gpiochip0");
    if (!chip) {
        perror("/dev/gpiochip0");
        return 1;
    }
    puts("gpiomon --idle-timeout 2s -b pull-up GPIO27");
    printf("-- 한 번 눌렀다 뗐는데 에지는 %d번\n", watch(chip, 0));

    puts("gpiomon --idle-timeout 2s -b pull-up -p 5ms GPIO27");
    printf("-- 한 번 눌렀다 뗐고 에지는 %d번\n", watch(chip, 5'000));
    gpiod_chip_close(chip);
}
```

```text
gpiomon --idle-timeout 2s -b pull-up GPIO27
5001.000000000  falling  "GPIO27"
5001.000400000  rising   "GPIO27"
5001.000900000  falling  "GPIO27"
5001.002100000  rising   "GPIO27"
5001.003000000  falling  "GPIO27"
5001.250000000  rising   "GPIO27"
5001.250600000  falling  "GPIO27"
5001.251300000  rising   "GPIO27"
-- 한 번 눌렀다 뗐는데 에지는 8번
gpiomon --idle-timeout 2s -b pull-up -p 5ms GPIO27
5004.008000000  falling  "GPIO27"
5004.256300000  rising   "GPIO27"
-- 한 번 눌렀다 뗐고 에지는 2번
```

- **한 번이 여덟 번으로 보였다**: 누를 때 3ms 사이에 에지가 다섯, 뗄 때 1.3ms 사이에 셋입니다. 에지를 그대로 세는 프로그램은 한 번 누른 것을 여러 번으로 압니다
- **시각의 차이가 재려던 값이다**: 첫 에지와 마지막 에지 사이가 떨림의 길이입니다. 여러 번 눌러 보고 가장 긴 것을 찾습니다
- **디바운스는 그보다 넉넉하게**: 가장 긴 떨림이 3ms였으므로 5ms를 줬고, 에지가 누름 하나와 뗌 하나로 줄었습니다
- **대가는 늦어지는 시각**: 둘째의 `falling`은 떨림이 끝나고 5ms 뒤의 시각입니다. 커널은 선이 그 기간 동안 조용했을 때에야 이벤트를 냅니다. 기간을 길게 잡을수록 반응이 늦고, 기간보다 짧게 눌린 것은 보이지 않습니다
- **프로그램에도 같은 설정이 있다**: 여기서 잰 값을 그대로 가져가 씁니다([「디바운스」](#/read/libgpiod/ed-debounce))

## gpionotify: 줄의 임자 지켜보기

```sh
gpionotify GPIO17                         # 쥐일 때, 놓일 때, 설정이 바뀔 때 한 줄씩
gpionotify -e requested -n 1 -q GPIO17    # 누가 쥘 때까지 기다린다
gpionotify -F "%E %l %C" GPIO17           # 쥔 프로그램의 소비자 이름까지
```

- **찍는 것**: 시각, `requested`나 `released`나 `reconfigured`, 줄의 이름입니다
- **줄을 쥐지 않는다**: 줄의 정보가 바뀌는 것만 지켜봅니다. 그래서 다른 프로그램을 막지 않고, 남이 쥔 줄도 볼 수 있습니다([「줄 정보 읽기」](#/read/libgpiod/ch-info))
- **쓰임새**: 뒤에서 도는 프로그램이 줄을 쥐었는지를 스크립트에서 기다릴 때, 내가 쓰려는 줄을 어느 프로그램이 가져가는지 알아낼 때 씁니다

## 1.6의 문법

| 하려는 일 | 2 | 1.6 |
| --- | --- | --- |
| 양쪽 에지 보기 | `gpiomon GPIO27` | `gpiomon gpiochip0 27` |
| 내려가는 에지만 | `gpiomon -e falling GPIO27` | `gpiomon -f gpiochip0 27` |
| 찍지 않기 | `-q` | `-s` |
| 디바운스 | `-p 5ms` | 없다 |

- **1.6의 한 줄**: `event: FALLING EDGE offset: 27 timestamp: [    5001.000000000]` 꼴입니다
- **`gpionotify`**: 1.6에는 없습니다

<Note>
예제는 진짜 `gpiomon`이 아니라 같은 일을 하는 짧은 프로그램을 이 책의 흉내 칩에서 돌린 것이고, 진짜 libgpiod 2.2.4의 머리 파일로 x86-64와 aarch64에서 컴파일되는지만 따로 확인했습니다. 단추의 떨림은 대본으로 넣은 것이라 그 길이와 횟수는 지어낸 값입니다. 진짜 단추는 단추마다, 누를 때마다 다릅니다. 디바운스가 낀 이벤트의 시각은 커널 문서에 적힌 대로 기간이 끝난 때로 했습니다. 풀업을 막 켠 순간의 변화가 에지로 잡히는지는 보드에서 봐야 알 수 있고, 흉내 칩은 요청 때문에 생긴 변화를 이벤트로 치지 않습니다. 옵션과 출력의 꼴은 2.2.4의 도구 소스와 문서, 1.6.3의 것은 그 판의 도구에서 확인했습니다.
</Note>

## 정리

- `gpiomon`은 줄을 쥐고 에지마다 시각, 방향, 이름을 찍는다. `-n`, `--idle-timeout`, `-q`로 스크립트에서 기다리는 데 쓴다
- 디바운스 없이 지켜보면 단추의 떨림이 보이고, 에지 사이의 시각 차이로 디바운스 기간을 정한다
- `gpionotify`는 줄을 쥐지 않고, 그 줄이 쥐이고 놓이는 것을 알려 준다
