배선을 마치고 가장 먼저 쳐 보는 두 명령입니다. `gpioset`으로 LED가 켜지면 선과 저항이 맞는 것이고, `gpioget`으로 단추의 값이 바뀌면 입력 쪽이 맞는 것입니다. 둘 다 처음 쓰는 사람을 놀라게 하는 버릇이 하나씩 있습니다. `gpioset`은 끝나지 않고, `gpioget`은 읽기만 한다면서 줄의 방향을 바꿉니다.

## gpioget: 읽기

```sh
gpioget GPIO27                  # "GPIO27"=inactive
gpioget --numeric GPIO27        # 0
gpioget GPIO5 GPIO6 GPIO27      # 여러 줄을 한 번에
gpioget -c 0 27                 # 칩과 오프셋으로
gpioget -b pull-up -l GPIO27    # 풀업을 켜고, LOW일 때 active라고 읽는다
```

- **값은 `active`와 `inactive`**: 전압이 아니라 논리값입니다. `-l`을 붙이면 LOW가 `active`입니다([「액티브 로」](#/read/libgpiod/out-active-low))
- **`--numeric`**: `1`과 `0`으로 찍습니다. 셸 스크립트에서 견주기 좋습니다
- **`-b`**: `pull-up`, `pull-down`, `disabled` 가운데 하나입니다. 적지 않으면 바이어스를 건드리지 않습니다. 저항 없이 단추와 선 두 가닥만으로 시험할 때 씁니다([「바이어스 설정」](#/read/libgpiod/in-bias))
- **`-p`**: 줄을 쥔 뒤 읽기까지 기다릴 시간입니다. 풀을 막 켠 선이 자리를 잡을 틈을 줍니다. `-p 10ms`처럼 적습니다
- **여러 줄**: 같은 칩의 줄은 요청 하나로 쥐어 한 번에 읽습니다. 값은 적은 차례대로 나옵니다

## gpioset: 내기

```sh
gpioset GPIO17=1                  # 켜고 붙들고 있는다. Ctrl+C로 끝낸다
gpioset GPIO17=1 GPIO22=0         # 여러 줄
gpioset -t 500ms GPIO17=1         # 0.5초마다 뒤집는다. 1초에 한 번 깜빡인다
gpioset -t 200ms,800ms GPIO17=1   # 0.2초 켜고 0.8초 끄기를 되풀이한다
gpioset -t 100ms,0 GPIO17=1       # 0.1초 켰다가 끄고 끝난다
gpioset -p 2s -t0 GPIO17=1        # 2초 동안 붙들었다가 끝난다
gpioset -z GPIO17=1               # 켜 놓고 터미널에서 물러난다
```

- **끝나지 않는 것이 정상이다**: 프로세스가 끝나면 줄이 놓이고, 놓인 줄이 값을 지킨다는 보장이 없습니다. 그래서 도구는 값을 낸 채로 줄을 쥐고 기다립니다. 도움말에도 그렇게 적혀 있습니다
- **값을 적는 말**: `1`과 `0`, `active`와 `inactive`, `on`과 `off`가 같은 뜻입니다
- **`-t`**: 기다릴 시간을 쉼표로 늘어놓습니다. 시간이 지날 때마다 값을 뒤집습니다. 마지막이 `0`이면 거기서 끝나고, 아니면 처음으로 돌아갑니다
- **시간의 단위**: 단위가 없으면 밀리초입니다. `us`, `ms`, `s`를 붙일 수 있고, 2.2부터는 분을 뜻하는 `m`도 됩니다
- **`-z`**: 값을 낸 뒤 뒤로 물러나 계속 쥐고 있습니다. 끝낼 때는 `pkill gpioset`입니다
- **그 밖의 옵션**: `-l`은 액티브 로, `-b`는 바이어스, `-d open-drain`은 드라이브, `-C`는 `gpioinfo`에 보일 소비자 이름입니다. `-i`는 프롬프트에서 `set`, `get`, `toggle`을 치는 대화 모드인데 빌드할 때 켠 꾸러미에만 있습니다

## 두 도구의 버릇

아래 예제는 두 터미널에서 벌어지는 일을 프로그램 하나로 따라 합니다. `gpioset`이 하는 요청과 `gpioget`이 하는 요청을 같은 차례로 냅니다.

```c gpiosim
// gpioset과 gpioget이 줄에 하는 일을 한 프로그램 안에서 차례로 따라 한다
#include <errno.h>
#include <gpiod.h>
#include <stdio.h>
#include <string.h>
#include <threads.h>

enum { LED = 17 };                           // GPIO 17, 헤더의 핀 11

// 줄을 그 방향으로 쥔다. 출력으로 쥐면 값을 active로 낸다
static struct gpiod_line_request* hold(struct gpiod_chip* chip,
                                       enum gpiod_line_direction direction,
                                       const char* who) {
    struct gpiod_line_settings* settings = gpiod_line_settings_new();
    struct gpiod_line_config* config = gpiod_line_config_new();
    struct gpiod_request_config* request_config = gpiod_request_config_new();
    struct gpiod_line_request* request = nullptr;
    unsigned int offset = LED;
    if (settings && config && request_config) {
        gpiod_line_settings_set_direction(settings, direction);
        gpiod_line_settings_set_output_value(settings, GPIOD_LINE_VALUE_ACTIVE);
        gpiod_line_config_add_line_settings(config, &offset, 1, settings);
        gpiod_request_config_set_consumer(request_config, who);
        request = gpiod_chip_request_lines(chip, request_config, config);
    }
    gpiod_request_config_free(request_config);
    gpiod_line_config_free(config);
    gpiod_line_settings_free(settings);
    return request;
}

// gpioget이 하는 일: 쥐고, 읽고, 놓는다
static void get(struct gpiod_chip* chip, enum gpiod_line_direction direction) {
    struct gpiod_line_request* request = hold(chip, direction, "gpioget");
    if (!request) {
        printf("gpioget: unable to request lines: %s\n", strerror(errno));
        return;
    }
    enum gpiod_line_value v = gpiod_line_request_get_value(request, LED);
    printf("\"GPIO17\"=%s\n", v == GPIOD_LINE_VALUE_ACTIVE ? "active" : "inactive");
    gpiod_line_request_release(request);
}

int main(void) {
    struct gpiod_chip* chip = gpiod_chip_open("/dev/gpiochip0");
    if (!chip) {
        perror("/dev/gpiochip0");
        return 1;
    }
    puts("[1] 터미널 A: gpioset GPIO17=1");
    struct gpiod_line_request* set =
        hold(chip, GPIOD_LINE_DIRECTION_OUTPUT, "gpioset");

    puts("[2] 터미널 B: gpioget GPIO17");
    get(chip, GPIOD_LINE_DIRECTION_INPUT);

    thrd_sleep(&(struct timespec){.tv_sec = 3}, nullptr);
    puts("[3] 터미널 A: 3초 뒤에 Ctrl+C");
    gpiod_line_request_release(set);

    puts("[4] 터미널 B: gpioget --as-is GPIO17");
    get(chip, GPIOD_LINE_DIRECTION_AS_IS);

    puts("[5] 터미널 B: gpioget GPIO17");
    get(chip, GPIOD_LINE_DIRECTION_INPUT);

    gpiod_chip_close(chip);
}
```

```text
[1] 터미널 A: gpioset GPIO17=1
핀|   0.000s  GPIO 17 → HIGH
[2] 터미널 B: gpioget GPIO17
gpioget: unable to request lines: Device or resource busy
[3] 터미널 A: 3초 뒤에 Ctrl+C
[4] 터미널 B: gpioget --as-is GPIO17
"GPIO17"=active
[5] 터미널 B: gpioget GPIO17
핀|   3.000s  GPIO 17 → LOW
"GPIO17"=inactive
```

- **[2] 쥔 줄은 읽을 수도 없다**: `gpioset`이 붙들고 있는 동안에는 `gpioget`도 그 줄을 요청하지 못합니다. 쥐인 줄의 값은 줄을 요청하지 않는 [「pinctrl」](#/read/libgpiod/tl-pinctrl)로 봅니다
- **[3] 끝낸 뒤에도 HIGH다**: `핀|` 줄이 새로 나오지 않았습니다. 라즈베리파이의 커널은 놓은 줄의 상태를 그대로 둡니다. 다른 보드에서는 처음 상태로 돌아갈 수 있고, 라즈베리파이에서도 `config.txt`에 `dtparam=strict_gpiod`를 적으면 입력으로 돌아갑니다([「놓아주기」](#/read/libgpiod/rq-release))
- **[4] `--as-is`**: 방향을 건드리지 않고 읽습니다. 출력으로 남아 있는 줄이라 낸 값이 그대로 읽힙니다
- **[5] 그냥 읽으면 입력이 된다**: `gpioget`은 줄을 입력으로 요청합니다. 핀이 값을 내기를 그만두자 보드의 풀다운이 선을 LOW로 끌어내렸고, 켜 두었던 등이 꺼졌습니다
- **그래서**: 출력으로 쓰는 줄을 들여다볼 때는 `--as-is`를 붙입니다
- **켜고 바로 끝내기**: `gpioset -t0 GPIO17=1`은 값을 내고 곧 끝납니다. 라즈베리파이에서는 [3]처럼 값이 남지만, 그것에 기대는 스크립트는 다른 보드에서 돌지 않습니다

## 1.6의 문법

| 하려는 일 | 2 | 1.6 |
| --- | --- | --- |
| 읽기 | `gpioget GPIO27` | `gpioget gpiochip0 27` |
| 켜서 붙들기 | `gpioset GPIO17=1` | `gpioset -m signal gpiochip0 17=1` |
| 2초만 켜기 | `gpioset -p 2s -t0 GPIO17=1` | `gpioset -m time -s 2 gpiochip0 17=1` |
| 풀업을 켜고 읽기 | `gpioget -b pull-up GPIO27` | `gpioget -B pull-up gpiochip0 27` |

- **줄은 칩과 오프셋으로만**: 1.6의 두 도구는 이름을 받지 않습니다
- **1.6의 `gpioset`은 바로 끝난다**: 기본이 값을 내고 끝나는 것입니다. 붙들게 하려면 `-m signal`이나 `-m wait`를 줍니다
- **1.6의 `gpioget`은 숫자만 찍는다**: `1`이나 `0`입니다
- **같은 글자, 다른 뜻**: 1.6의 `gpioset`에서 `-b`는 바이어스가 아니라 뒤로 물러나라는 뜻입니다. 바이어스는 대문자 `-B`입니다

<Note>
예제는 진짜 도구를 돌린 것이 아니라, 두 도구가 내는 요청을 같은 차례로 내는 프로그램을 이 책의 흉내 칩에서 돌린 것입니다. `핀|`으로 시작하는 줄은 흉내 칩이 핀의 전압이 바뀔 때 적은 것이고, [2]의 오류 글귀는 도구의 소스에 있는 것을 옮겼습니다. 출력인 줄을 읽었을 때 무엇이 나오는지는 커널 문서가 드라이버에 달렸다고 적고 있고, 흉내 칩은 마지막에 낸 값을 돌려주게 했습니다. 옵션은 libgpiod 2.2.4의 도구 소스와 문서에서, 1.6.3의 것은 그 판의 도구를 `--help`로 돌려 확인했습니다. 보드에서 돌려 보지는 못했습니다.
</Note>

## 정리

- `gpioget`은 줄을 쥐고 읽고 놓는다. 값은 논리값이고, `-b`로 풀을 켜고 `--numeric`으로 숫자를 받는다
- `gpioset`은 값을 낸 채 줄을 붙들고 끝나지 않는다. `-t`로 깜빡임과 펄스를 만들고 `-z`로 뒤에 둔다
- `gpioget`은 줄을 입력으로 바꾼다. 출력으로 쓰는 줄은 `--as-is`로 읽고, 남이 쥔 줄은 읽을 수 없다
