LED 넷에 숫자를 2진수로 띄운다고 합시다. 7에서 8로 넘어갈 때는 네 줄이 모두 바뀝니다. 한 줄씩 네 번 쓰면 그 사이에 6, 4, 0 같은 엉뚱한 숫자가 잠깐씩 지나갑니다. 줄들을 한 요청에 담아 두면 호출 한 번으로 넷을 함께 쓸 수 있습니다.

## 넷을 한꺼번에

```c gpiosim
// LED 넷에 숫자를 2진수로 띄운다: 줄 넷을 한 요청으로 쥐고 호출 한 번에 쓴다
#include <gpiod.h>
#include <stdio.h>
#include <threads.h>

enum { COUNT = 4 };
static const unsigned int leds[COUNT] = {17, 27, 22, 23};   // 핀 11, 13, 15, 16

// 숫자의 비트를 값의 배열로 편다. 0번 비트가 배열의 첫 칸, 곧 17번 줄이다
static void spread(unsigned int number, enum gpiod_line_value values[COUNT]) {
    for (int bit = 0; bit < COUNT; ++bit)
        values[bit] = (number >> bit & 1) ? GPIOD_LINE_VALUE_ACTIVE
                                          : GPIOD_LINE_VALUE_INACTIVE;
}

int main(void) {
    struct gpiod_chip* chip = gpiod_chip_open("/dev/gpiochip0");
    struct gpiod_line_settings* settings = gpiod_line_settings_new();
    struct gpiod_line_config* config = gpiod_line_config_new();
    if (!chip || !settings || !config) {
        perror("준비");
        return 1;
    }
    enum gpiod_line_value values[COUNT];
    gpiod_line_settings_set_direction(settings, GPIOD_LINE_DIRECTION_OUTPUT);
    gpiod_line_config_add_line_settings(config, leds, COUNT, settings);
    spread(0b1001, values);                  // 첫 값은 줄마다 다르게 줄 수 있다
    gpiod_line_config_set_output_values(config, values, COUNT);

    puts("요청: 첫 값 1001");
    struct gpiod_line_request* row =
        gpiod_chip_request_lines(chip, nullptr, config);
    gpiod_line_config_free(config);
    gpiod_line_settings_free(settings);
    gpiod_chip_close(chip);
    if (!row) {
        perror("요청");
        return 1;
    }
    const struct timespec half = {.tv_nsec = 500'000'000};
    for (unsigned int number = 6; number <= 8; ++number) {
        thrd_sleep(&half, nullptr);
        printf("전부 쓰기: %u\n", number);
        spread(number, values);
        gpiod_line_request_set_values(row, values);
    }
    thrd_sleep(&half, nullptr);
    puts("둘만 쓰기: 17번과 23번을 active로");
    const unsigned int two[] = {17, 23};
    const enum gpiod_line_value on[] = {GPIOD_LINE_VALUE_ACTIVE,
                                        GPIOD_LINE_VALUE_ACTIVE};
    gpiod_line_request_set_values_subset(row, 2, two, on);

    gpiod_line_request_get_values(row, values);
    printf("읽은 값(17, 27, 22, 23): %d %d %d %d\n", values[0], values[1],
           values[2], values[3]);
    spread(0, values);
    gpiod_line_request_set_values(row, values);   // 모두 끄고 놓는다
    gpiod_line_request_release(row);
}
```

핀|   0.000s  GPIO 23 → HIGH
전부 쓰기: 6
핀|   0.500s  GPIO 17 → LOW
핀|   0.500s  GPIO 27 → HIGH
핀|   0.500s  GPIO 22 → HIGH
핀|   0.500s  GPIO 23 → LOW

- **줄 넷을 한 번에 붙인다**: `gpiod_line_config_add_line_settings`에 오프셋의 배열과 개수를 넘겼습니다. 넷이 같은 성질을 갖습니다
- **`gpiod_line_config_set_output_values`**: 첫 값을 줄마다 다르게 줍니다. settings에 적은 첫 값보다 이것이 앞섭니다. 예제는 1001로 시작했습니다
- **`gpiod_line_request_set_values`**: 요청에 든 모든 줄의 값을 배열로 받습니다. 배열의 길이는 줄의 수와 같아야 합니다
- **`gpiod_line_request_set_values_subset`**: 몇 줄만 씁니다. 오프셋의 배열과 값의 배열을 짝지어 넘기고, 적지 않은 줄은 건드리지 않습니다
- **`gpiod_line_request_get_values`**: 같은 차례로 모든 줄을 읽습니다([「값 읽기」](#/read/libgpiod/in-read))
- **같은 시각에 바뀌었다**: 6을 쓸 때와 8을 쓸 때 네 줄의 `핀|`이 같은 시각에 찍혔습니다

## 값의 차례

- **배열의 칸은 붙인 차례를 따른다**: `values[0]`은 config에 맨 먼저 붙인 줄의 값입니다. 오프셋이 작은 순서가 아닙니다. 예제의 차례는 17, 27, 22, 23입니다
- **오프셋의 배열을 한 곳에 둔다**: 예제는 `leds`를 config에 붙일 때도, 주석에도, 비트를 펴는 차례에도 씁니다. 차례를 두 군데에 따로 적으면 언젠가 어긋납니다
- **요청에 물어볼 수도 있다**: `gpiod_line_request_get_requested_offsets`가 요청 안의 차례대로 오프셋을 채워 줍니다
- **subset은 짝으로 가리킨다**: 오프셋과 값을 나란히 적으므로 차례를 틀릴 일이 없습니다. 몇 줄만 다룰 때에는 이쪽이 읽기 쉽습니다

## 한꺼번에의 뜻

- **커널에 가는 부탁이 하나다**: 네 번 부르는 것보다 빠르고, 내 프로그램 안에서는 그 사이에 다른 일이 끼어들 틈이 없습니다
- **핀이 같은 순간에 바뀐다는 약속은 아니다**: 커널 문서는 거기까지 적지 않습니다. 칩과 드라이버에 달린 일입니다
- **받는 쪽이 민감하면 신호를 하나 더 둔다**: 값을 싣는 줄들을 먼저 세워 놓고, 지금 읽으라는 줄 하나를 따로 움직입니다. 글자 LCD와 시프트 레지스터가 그렇게 받습니다
- **한 요청 안에서만 된다**: 따로 요청한 줄이나 다른 칩의 줄은 호출 한 번으로 묶을 수 없습니다. 함께 쓸 줄은 처음부터 한 요청에 담습니다([「gpiod_chip_request_lines」](#/read/libgpiod/rq-request))

## 어디에 쓰나

- **숫자와 무늬**: 7세그먼트 표시기의 일곱 줄, 글자 LCD의 데이터 네 줄
- **차례대로 도는 무늬**: 스테퍼 모터의 코일 네 줄. 모터는 핀이 직접 몰 수 없으므로 사이에 트랜지스터가 들어갑니다([「릴레이와 트랜지스터 몰기」](#/read/libgpiod/out-relay))
- **훑기**: 키패드의 행을 하나씩 켜 가며 열을 읽습니다([「키패드 훑기」](#/read/libgpiod/pj-keypad))
- **전류의 합을 센다**: 줄 여럿을 한꺼번에 켜면 전류도 한꺼번에 흐릅니다. LED 넷에 4.5mA씩이면 18mA이고, 모든 핀을 합한 한도는 50mA입니다([「3.3V, 전류 한계, 보호 저항」](#/read/libgpiod/gp-electrical))

<Note>
예제는 이 책의 흉내 칩에서 돌린 것이고, `핀|`으로 시작하는 줄은 흉내 칩이 핀의 전압이 바뀔 때 적은 것입니다. 흉내 칩은 호출 한 번에 실린 줄들을 같은 시각에 바꾸지만, 진짜 보드에서 네 핀이 얼마나 가깝게 바뀌는지는 재 보지 못했습니다. 값의 차례가 config에 붙인 차례라는 것은 libgpiod 2.2.4의 머리 파일에 적힌 설명과 소스에서 확인했습니다. 진짜 머리 파일로 x86-64와 aarch64에서 컴파일되는지 따로 확인했습니다.
</Note>

## 정리

- 함께 바꿀 줄은 한 요청에 담고 `gpiod_line_request_set_values`로 호출 한 번에 쓴다
- 값의 배열은 config에 줄을 붙인 차례를 따른다. 몇 줄만 쓸 때는 오프셋과 값을 짝지어 넘기는 subset을 쓴다
- 호출이 하나라는 것이지 핀이 같은 순간에 바뀐다는 약속은 아니다
