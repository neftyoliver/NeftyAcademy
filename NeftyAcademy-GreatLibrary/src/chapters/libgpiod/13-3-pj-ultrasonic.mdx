초음파 거리 센서는 소리를 쏘고 메아리가 돌아올 때까지의 시간을 잽니다. 흔한 HC-SR04는 그 시간을 핀 하나가 HIGH인 폭으로 알려 줍니다. 폭을 재는 일은 시간에 민감하지만, 에지 이벤트의 타임스탬프를 쓰면 프로그램이 늦게 깨어도 맞게 잴 수 있습니다.

## 센서가 하는 일과 배선

| 다리 | 잇는 곳 | 하는 일 |
| --- | --- | --- |
| VCC | 핀 2 (5V) | 전원. 15mA쯤 쓴다 |
| Trig | 핀 16 (GPIO 23) | 10µs 넘는 HIGH 펄스를 주면 재기 시작한다 |
| Echo | 분압해서 핀 18 (GPIO 24) | 소리가 다녀온 시간만큼 HIGH를 낸다 |
| GND | 핀 6 (GND) | 0V |

```text
Echo ----[ 1kΩ ]----+---- 핀 18 (GPIO 24)
                    |
                 [ 2kΩ ]
                    |
                   GND
```

- **재는 차례**: 트리거를 받으면 센서는 40kHz의 소리를 여덟 번 쏘고 에코를 올립니다. 메아리를 들으면 에코를 내립니다
- **폭이 곧 거리다**: 거리는 폭에 소리의 빠르기를 곱하고 반으로 나눈 값입니다. 340m/s로 치면 1cm마다 58µs쯤이고, 잴 수 있는 2cm에서 4m까지의 폭은 0.12ms에서 23.5ms입니다
- **에코는 5V다**: 5V로 도는 센서의 에코는 5V까지 올라갑니다. GPIO에 그대로 이으면 핀이 상할 수 있습니다. 저항 둘로 나누면 5V의 3분의 2인 3.3V가 됩니다([「3.3V, 전류 한계, 보호 저항」](#/read/libgpiod/gp-electrical))
- **3.3V로 도는 것도 있다**: 3.3V에서 5V까지 받는 변종(HC-SR04-33 같은 것)은 3.3V로 돌리면 에코도 3.3V라고 합니다. 가진 부품의 문서를 봅니다
- **쉬어 가며 잰다**: 앞에 쏜 소리의 메아리가 다음 번에 섞이지 않도록, 문서는 한 번 재는 주기를 60ms보다 길게 잡으라고 권합니다

## 타임스탬프로 재기

```c gpiosim=sonar
// 초음파 거리 센서(HC-SR04 꼴): 트리거를 치고 에코가 HIGH였던 폭을 이벤트로 잰다
#define _POSIX_C_SOURCE 200809L              // clock_nanosleep을 쓰려고
#include <gpiod.h>
#include <stdint.h>
#include <stdio.h>
#include <time.h>

enum { TRIGGER = 23, ECHO = 24 };            // 핀 16, 18. 에코는 분압해서 받는다
enum { ROUNDS = 6 };
static const int64_t SECOND = 1'000'000'000;
static const int64_t CYCLE = 100'000'000;    // 100ms마다 한 번 잰다
static const int64_t PATIENCE = 60'000'000;  // 메아리를 기다려 주는 시간
static const int64_t TOO_WIDE = 25'000'000;  // 4m를 넘는 폭은 믿지 않는다

static int64_t now_ns(void) {
    struct timespec now;
    clock_gettime(CLOCK_MONOTONIC, &now);
    return now.tv_sec * SECOND + now.tv_nsec;
}

static void sleep_until(int64_t when) {
    struct timespec at = {.tv_sec = when / SECOND, .tv_nsec = when % SECOND};
    clock_nanosleep(CLOCK_MONOTONIC, TIMER_ABSTIME, &at, nullptr);
}

// 트리거는 LOW를 내는 출력으로, 에코는 두 방향의 에지를 듣는 입력으로 요청한다
static struct gpiod_line_request* request_sensor(struct gpiod_chip* chip) {
    struct gpiod_line_settings* trigger = gpiod_line_settings_new();
    struct gpiod_line_settings* echo = gpiod_line_settings_new();
    struct gpiod_line_config* config = gpiod_line_config_new();
    struct gpiod_request_config* request_config = gpiod_request_config_new();
    struct gpiod_line_request* request = nullptr;
    if (trigger && echo && config && request_config) {
        gpiod_line_settings_set_direction(trigger, GPIOD_LINE_DIRECTION_OUTPUT);
        gpiod_line_settings_set_direction(echo, GPIOD_LINE_DIRECTION_INPUT);
        gpiod_line_settings_set_edge_detection(echo, GPIOD_LINE_EDGE_BOTH);
        gpiod_line_config_add_line_settings(config, &(unsigned int){TRIGGER}, 1,
                                            trigger);
        gpiod_line_config_add_line_settings(config, &(unsigned int){ECHO}, 1, echo);
        gpiod_request_config_set_consumer(request_config, "sonar");
        request = gpiod_chip_request_lines(chip, request_config, config);
    }
    gpiod_request_config_free(request_config);
    gpiod_line_config_free(config);
    gpiod_line_settings_free(echo);
    gpiod_line_settings_free(trigger);
    return request;
}

// 한 번 잰다. 에코의 폭(ns)을 돌려주고, 메아리가 없으면 0을 돌려준다
// *by_wake에는 프로그램이 깨어난 시각으로 잰 폭을 적는다(견주어 보려고)
static int64_t measure(struct gpiod_line_request* sensor,
                       struct gpiod_edge_event_buffer* buffer, int64_t* by_wake) {
    // 트리거를 10us 넘게 HIGH로 두었다가 내린다
    gpiod_line_request_set_value(sensor, TRIGGER, GPIOD_LINE_VALUE_ACTIVE);
    struct timespec pulse = {.tv_nsec = 10'000};
    clock_nanosleep(CLOCK_MONOTONIC, 0, &pulse, nullptr);
    gpiod_line_request_set_value(sensor, TRIGGER, GPIOD_LINE_VALUE_INACTIVE);

    const int64_t give_up = now_ns() + PATIENCE;
    uint64_t rose = 0;                       // 에코가 올라간 때의 타임스탬프
    int64_t rose_seen = 0;                   // 그 이벤트를 읽은 때의 시계
    for (;;) {
        int64_t left = give_up - now_ns();
        if (left <= 0) return 0;
        if (gpiod_line_request_wait_edge_events(sensor, left) <= 0) return 0;
        int count = gpiod_line_request_read_edge_events(sensor, buffer, 1);
        if (count <= 0) return 0;
        const int64_t seen = now_ns();
        struct gpiod_edge_event* event =
            gpiod_edge_event_buffer_get_event(buffer, 0);
        const uint64_t at = gpiod_edge_event_get_timestamp_ns(event);
        if (gpiod_edge_event_get_event_type(event) ==
            GPIOD_EDGE_EVENT_RISING_EDGE) {
            rose = at;
            rose_seen = seen;
        } else if (rose != 0) {
            *by_wake = seen - rose_seen;
            return (int64_t)(at - rose);
        }
    }
}

int main(void) {
    struct gpiod_chip* chip = gpiod_chip_open("/dev/gpiochip0");
    if (!chip) {
        perror("/dev/gpiochip0");
        return 1;
    }
    struct gpiod_line_request* sensor = request_sensor(chip);
    gpiod_chip_close(chip);
    struct gpiod_edge_event_buffer* buffer = gpiod_edge_event_buffer_new(1);
    if (!sensor || !buffer) {
        perror("요청");
        return 1;
    }
    const int64_t origin = now_ns();
    for (int i = 0; i < ROUNDS; ++i) {
        sleep_until(origin + i * CYCLE);
        int64_t by_wake = 0;
        const int64_t width = measure(sensor, buffer, &by_wake);
        if (width == 0 || width > TOO_WIDE) {
            printf("%d번째: 메아리가 없다\n", i + 1);
            continue;
        }
        // 소리가 다녀온 시간에 340m/s를 곱하고 반으로 나눈다
        printf("%d번째: 에코 %.3fms, %5.1fcm (깨어난 때로 재면 %.3fms, %5.1fcm)\n",
               i + 1, (double)width / 1e6, (double)width * 340.0 / 2.0 / 1e7,
               (double)by_wake / 1e6, (double)by_wake * 340.0 / 2.0 / 1e7);
    }
    gpiod_edge_event_buffer_free(buffer);
    gpiod_line_request_release(sensor);
}
```

```text
1번째: 에코 1.471ms,  25.0cm (깨어난 때로 재면 1.471ms,  25.0cm)
2번째: 에코 1.471ms,  25.0cm (깨어난 때로 재면 1.471ms,  25.0cm)
3번째: 에코 5.882ms, 100.0cm (깨어난 때로 재면 2.882ms,  49.0cm)
4번째: 에코 1.471ms,  25.0cm (깨어난 때로 재면 0.000ms,   0.0cm)
5번째: 메아리가 없다
6번째: 에코 5.882ms, 100.0cm (깨어난 때로 재면 5.882ms, 100.0cm)
```

- **트리거는 넉넉히 친다**: 10µs를 자라고 해도 프로그램은 그보다 늦게 깹니다. 센서가 바라는 것은 10µs를 넘는 폭이므로 길어지는 것은 괜찮습니다([「사용자 공간에서 얼마나 정확한가」](#/read/libgpiod/tm-jitter))
- **폭은 두 타임스탬프의 차다**: 올라가는 에지의 타임스탬프를 적어 두었다가, 내려가는 에지의 타임스탬프에서 뺍니다. 타임스탬프는 커널이 에지를 알아챈 때 찍은 것입니다([「타임스탬프와 시계 고르기」](#/read/libgpiod/ed-timestamp))
- **괄호 안은 틀린 방법이다**: 견주어 보려고, 이벤트를 읽은 때에 프로그램이 읽은 시계로도 폭을 쟀습니다. 제때 깬 1, 2, 6번째에는 두 값이 같습니다
- **3번째는 3ms 늦게 깼다**: 올라가는 에지를 3ms 늦게 읽었습니다. 깨어난 때로 재면 폭이 2.882ms, 49cm입니다. 타임스탬프로 잰 값은 그대로 100cm입니다
- **4번째는 두 에지가 다 지나갔다**: 깼을 때에는 1.471ms짜리 펄스가 이미 끝나 있었습니다. 두 이벤트를 잇달아 읽어 폭이 0으로 나옵니다. 타임스탬프로는 25cm입니다
- **값을 읽어서 재면 더 나쁘다**: 에코를 되풀이해 읽으며 HIGH인 동안을 세는 방법은 깨어난 때로 재는 것과 같은 틀림에 더해, CPU 하나를 통째로 씁니다

## 믿지 않을 값

- **메아리가 없을 때**: 5번째에는 60ms를 기다려도 이벤트가 오지 않아 그만두었습니다. 기다림에 시한을 주지 않으면 프로그램이 거기서 멈춥니다([「기다리고 읽기」](#/read/libgpiod/ed-wait))
- **너무 넓은 폭**: 진짜 센서는 메아리가 없으면 에코를 올렸다가 38ms쯤 뒤에 스스로 내린다고 적은 글이 있습니다. 예제는 25ms를 넘는 폭을 메아리가 없는 것으로 칩니다
- **하나만 믿지 않는다**: 비스듬한 면, 천, 좁은 물체는 메아리를 흩뜨립니다. 여러 번 재서 가운데 값을 쓰면 튀는 값 하나에 속지 않습니다
- **소리의 빠르기**: 340m/s는 어림값입니다. 공기가 따뜻할수록 소리는 빨라지므로, 온도를 모르면 몇 퍼센트는 틀릴 수 있습니다
- **느린 신호라서 된다**: 이 방법이 통하는 것은 한 번 재는 데 에지가 둘뿐이기 때문입니다. 에지가 쉴 새 없이 오는 신호는 이벤트가 버퍼에 쌓이다 넘치고, 타임스탬프의 오차도 폭에 견주어 커집니다([「비트뱅잉」](#/read/libgpiod/tm-bitbang))

<Note>
예제는 이 책의 흉내 칩에 붙인 흉내 센서로 돌린 것입니다. 흉내 센서는 트리거가 내려간 0.5ms 뒤에 에코를 올리고, 거리를 340m/s로 셈한 시간 뒤에 내립니다. 메아리가 없으면 에코를 올리지도 않습니다. 이 셋은 제가 정한 것이고 진짜 센서를 잰 값이 아닙니다. 물체의 거리와 두 번의 늦음도 대본으로 넣었습니다. 진짜 libgpiod 2.2.4의 머리 파일로 x86-64와 aarch64에서 컴파일되는지 확인했고, 센서를 단 보드에서 돌려 보지는 못했습니다. 커널이 에지를 알아채고 타임스탬프를 찍기까지 걸리는 시간도 재지 못했습니다. 그 시간이 두 에지에서 다르면 그만큼 폭이 틀립니다. 3.3V의 트리거를 5V로 도는 센서가 HIGH로 읽는지도 보드에서 확인할 일입니다.
</Note>

## 정리

- 센서는 소리가 다녀온 시간을 에코의 HIGH 폭으로 낸다. 5V 에코는 저항 둘로 나눠서 받는다
- 폭은 두 에지의 타임스탬프를 빼서 구한다. 프로그램이 늦게 깨어도 타임스탬프는 달라지지 않는다
- 기다림에는 시한을 주고, 너무 넓은 폭과 튀는 값은 버린다
