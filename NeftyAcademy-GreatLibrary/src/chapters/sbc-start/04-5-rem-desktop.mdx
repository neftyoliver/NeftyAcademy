대부분의 일은 글자 화면으로 됩니다. 그래도 카메라가 찍는 것을 눈으로 확인하거나, 창이 뜨는 프로그램을 만들거나, 보드에서 도는 웹 화면을 봐야 할 때가 옵니다. 모니터를 붙이지 않고 PC에서 보드의 화면을 보는 길은 넷이고, 보려는 것의 크기가 다릅니다.

| 길 | 보이는 것 | 조건 |
| --- | --- | --- |
| VNC | 보드의 데스크톱 전체 | 데스크톱 판의 OS, 같은 네트워크 |
| Raspberry Pi Connect | 브라우저 안의 데스크톱이나 셸 | 인터넷과 Raspberry Pi ID |
| `ssh -Y` | 프로그램 하나의 창 | PC에 X 서버 |
| `ssh -L` | 보드의 웹 화면 | 보드의 프로그램이 웹으로 화면을 낼 때 |

## VNC

VNC는 보드의 데스크톱을 통째로 PC의 창에 띄웁니다. Raspberry Pi OS의 데스크톱 판에는 wayvnc라는 VNC 서버가 들어 있고, 켜기만 하면 됩니다.

1. 보드에서 `sudo raspi-config`를 띄워 Interface Options의 VNC를 켭니다. 데스크톱에서는 Control Centre의 Interfaces 탭에 같은 스위치가 있습니다
2. PC에 VNC 클라이언트를 깝니다. 문서는 TigerVNC로 설명합니다
3. 클라이언트에 보드의 주소를 넣고 붙습니다. 인증서를 믿겠느냐는 경고가 뜨면 Yes를 고릅니다
4. 보드의 사용자 이름과 암호를 넣습니다

- **Lite에서는 안 된다**: 문서는 VNC가 Lite 판과 맞지 않는다고 적습니다. 띄울 데스크톱이 없기 때문입니다. [「Raspberry Pi OS, 우분투, 그 밖의 배포판」](#/read/sbc-start/os-choices)에서 Lite를 골랐다면 아래의 다른 길을 씁니다
- **처음 켤 때는 못 쓴다**: 처음 켠 보드에 들어가는 길은 SSH와 Raspberry Pi Connect뿐이고, VNC는 그 뒤에 켭니다
- **마우스가 안 보이면**: 문서는 TigerVNC의 Options에서 Input의 "Show dot when no cursor"를 켜 두라고 적습니다

## Raspberry Pi Connect

Raspberry Pi Connect는 브라우저로 보드에 들어가는 라즈베리파이의 서비스입니다. 보드와 PC가 다른 네트워크에 있어도 되고, 공유기 설정을 건드릴 필요가 없습니다.

| 클라이언트 | 되는 것 | 들어 있는 판 |
| --- | --- | --- |
| Connect | 화면 공유와 원격 셸 | 데스크톱 판과 Full |
| Connect Lite | 원격 셸 | Lite |

```sh
rpi-connect on          # 켠다
rpi-connect signin      # 찍어 주는 주소를 열어 Raspberry Pi ID로 들어간다
rpi-connect status      # 상태를 본다
loginctl enable-linger  # 로그인하지 않은 채로도 원격 셸이 살아 있게 한다
```

그 뒤에는 어느 PC에서든 connect.raspberrypi.com에 들어가 Devices에서 보드를 고릅니다.

- **화면 공유의 조건**: Wayland로 도는 데스크톱이 이미 떠 있어야 합니다. 모니터 없이 쓰는 보드라면 자동 로그인을 켜 둡니다
- **Lite에서도 셸은 된다**: 멀리 떨어진 곳에 설치한 보드에 SSH로 닿을 수 없을 때 쓸 수 있는 길입니다
- **어떻게 이어지나**: 문서는 브라우저와 보드를 될 수 있으면 직접 잇고, 안 되면 암호화된 중계를 거친다고 적습니다. 주고받는 내용은 끝에서 끝까지 암호화됩니다
- **Imager에서 미리**: [「모니터 없이 설정하기: Wi-Fi, SSH, 사용자」](#/read/sbc-start/os-headless)의 Raspberry Pi Connect 칸에서 정해 두면 처음 켤 때부터 붙습니다
- **값**: 혼자 쓰는 계정은 무료입니다

## 창 하나만 가져오기

데스크톱 전체가 아니라 프로그램 하나의 창만 필요하다면 SSH가 그 창을 PC로 넘겨줍니다.

```sh
ssh -Y sensor      # X11 넘겨받기를 켜고 들어간다
geany &            # 보드에서 띄운 창이 PC의 화면에 뜬다
```

- **PC에 X 서버가 있어야 한다**: 리눅스 데스크톱에는 있습니다. macOS와 Windows에는 따로 깔아야 합니다
- **느리다**: 창을 그리는 명령이 하나하나 네트워크를 건너므로 움직임이 많은 화면에는 맞지 않습니다

## 웹 화면 받기

보드의 프로그램이 웹 서버로 화면을 낸다면 브라우저만 있으면 됩니다. 같은 네트워크에서는 `http://sensor-01.local:8080`처럼 바로 엽니다. 프로그램이 보드 안에서만 받도록(`127.0.0.1`) 띄워져 있거나 포트를 밖으로 열고 싶지 않다면 SSH로 포트를 넘겨받습니다.

```sh
ssh -L 8080:localhost:8080 sensor    # PC의 8080 을 보드의 8080 에 잇는다
```

이 창을 열어 둔 동안 PC의 브라우저에서 `http://localhost:8080`을 열면 보드의 화면이 나옵니다. 센서 값을 그래프로 보여 주는 화면은 이 방식이 가장 가볍습니다. 보드에는 데스크톱이 필요 없고, PC에는 브라우저만 있으면 됩니다.

## 무엇을 고를까

- **Lite로 간다면**: 평소에는 SSH, 웹 화면이 있으면 포트 넘겨받기, 멀리 있는 보드에는 Connect의 원격 셸을 씁니다
- **창이 뜨는 프로그램을 만든다면**: 데스크톱 판을 올리고 VNC나 Connect의 화면 공유를 씁니다
- **잠깐 눈으로 확인할 뿐이라면**: 모니터를 한 번 붙이는 것이 가장 빠를 때도 있습니다

<Note>
이 쪽의 순서와 명령은 문서에서 옮겼고 직접 해 보지는 못했습니다. `ssh -L`의 8080은 본보기이며, 내 프로그램이 여는 포트 번호로 바꿉니다. VNC를 인터넷 쪽으로 직접 열어 두지 않습니다. 집 밖에서 들어가야 한다면 Connect를 쓰거나 SSH로 먼저 들어간 뒤 그 안에서 넘겨받습니다.
</Note>

## 정리

- 데스크톱 전체는 VNC나 Raspberry Pi Connect로 보고, 둘 다 데스크톱 판의 OS에서 된다
- Lite에서는 Connect의 원격 셸과 SSH를 쓰고, 화면이 필요하면 프로그램이 웹으로 내게 해서 `ssh -L`로 받는다
- 프로그램 하나의 창은 `ssh -Y`로 가져올 수 있지만 느리다
