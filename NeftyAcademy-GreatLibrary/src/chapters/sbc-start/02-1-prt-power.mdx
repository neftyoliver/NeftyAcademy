전원은 준비물 가운데 가장 싸지만, 까닭 모를 고장을 가장 자주 만드는 것도 전원입니다. 보드가 저절로 다시 켜지거나 USB 장치가 끊겼다 붙을 때 먼저 볼 곳이 여기입니다. 이 쪽은 보드마다 어떤 전원을 꽂는지, USB-C 충전기에 적힌 와트를 왜 그대로 믿으면 안 되는지, 전원이 모자란지를 보드에서 어떻게 확인하는지를 봅니다.

## 보드마다 다른 단자와 전원

| 보드 | 전원 단자 | 공식 전원 | 출력 |
| --- | --- | --- | --- |
| 5, 500, 500+ | USB-C | 27W USB-C 전원 | 5.1V 5A |
| 4 Model B, 400 | USB-C | 15W USB-C 전원 | 5.1V 3A |
| Zero 2 W와 3 이하 | micro USB | 12.5W micro USB 전원 | 5.1V 2.5A |

- **5V가 아니라 5.1V**: 문서는 모든 보드에 5.1V 전원을 요구하고, 이 전압을 전원이 아니라 플러그 끝에서 잰 값으로 따지라고 적습니다. 케이블에서 떨어지는 몫을 미리 셈하라는 뜻입니다
- **단자가 같다고 같은 전원이 아니다**: 4와 5는 둘 다 USB-C이지만 필요한 전류가 3A와 5A로 다릅니다. 4용 전원으로도 5는 켜집니다. 다만 아래에서 보듯 USB 포트가 묶입니다
- **Zero 2 W의 micro USB는 둘**: 하나는 전원을 받고, 다른 하나는 USB 장치를 꽂는 OTG 단자입니다. 전원은 전원 쪽에 꽂습니다. 문서의 표가 Zero 2 W에 권하는 전류는 2A이고, 공식 micro USB 전원은 2.5A까지 냅니다
- **45W 공식 전원**: 공식 전원에는 노트북에도 쓰는 45W짜리가 있습니다. 이것도 5.1V 5A 줄을 내놓습니다

보드와 주변 장치가 실제로 먹는 전류는 [「사양 읽는 법: SoC, 램, 저장 장치, 전력」](#/read/sbc-start/brd-specs)의 표에 있습니다.

## 와트가 아니라 5V 줄의 전류

USB-C 충전기는 꽂힌 기기와 먼저 말을 주고받습니다. 충전기가 "이 전압에서 이만큼의 전류를 낼 수 있다"는 줄을 여럿 내놓으면 기기가 그 가운데 하나를 고릅니다. 이 약속이 USB-PD(Power Delivery)입니다.

큰 와트는 전압을 올려서 만듭니다. 규격의 표를 따르는 충전기는 15W를 넘으면 9V 줄을, 27W를 넘으면 15V 줄을, 45W를 넘으면 20V 줄을 더하는데, 5V 줄의 전류는 3A에서 더 늘지 않습니다. 라즈베리파이는 5V로 도는 보드라서 높은 전압의 줄은 쓸 데가 없습니다. 상자에 적힌 와트가 아니라 5V 줄에 적힌 전류가 보드가 얻는 전부입니다.

```c
// 전원이 내놓는 전압·전류 목록에서 라즈베리파이 5가 얻는 것을 따져 본다
#include <stdio.h>

struct offer { int mv, ma; };                // 내놓는 한 줄: 전압(mV)과 전류(mA)
struct supply {
    const char* name;
    int watts;                               // 상자에 적힌 와트
    struct offer offers[5];                  // 빈 자리는 {0, 0}
};

// 5V 줄에서 가장 큰 전류를 찾는다. 5는 5V만 받으므로 다른 줄은 쓰지 못한다
static int current_at_5v(const struct supply* s) {
    int best = 0;
    for (int i = 0; i < 5 && s->offers[i].mv; ++i) {
        const struct offer* o = &s->offers[i];
        if (o->mv >= 4750 && o->mv <= 5250 && o->ma > best) best = o->ma;
    }
    return best;
}

static const char* verdict(int ma) {
    if (ma >= 5000) return "USB 포트에 1.6A까지";
    if (ma >= 3000) return "USB 포트에 600mA까지, USB 부팅은 꺼진다";
    return "부팅에 필요한 3A에 못 미친다";
}

int main(void) {
    const struct supply supplies[] = {
        {"공식 27W 전원", 27,
         {{5100, 5000}, {9000, 3000}, {12000, 2250}, {15000, 1800}}},
        {"공식 45W 전원", 45,
         {{5100, 5000}, {9000, 5000}, {12000, 3750}, {15000, 3000},
          {20000, 2250}}},
        {"65W 노트북 충전기", 65,
         {{5000, 3000}, {9000, 3000}, {15000, 3000}, {20000, 3250}}},
        {"공식 15W 전원(4용)", 15, {{5100, 3000}}},
        {"5V 2A 충전기", 10, {{5000, 2000}}},
    };
    printf("표기  5V에서   전원: 라즈베리파이 5가 얻는 것\n");
    for (size_t i = 0; i < sizeof supplies / sizeof supplies[0]; ++i) {
        int ma = current_at_5v(&supplies[i]);
        printf("%3dW  %4dmA   %s: %s\n", supplies[i].watts, ma,
               supplies[i].name, verdict(ma));
    }
}
```

```text
표기  5V에서   전원: 라즈베리파이 5가 얻는 것
 27W  5000mA   공식 27W 전원: USB 포트에 1.6A까지
 45W  5000mA   공식 45W 전원: USB 포트에 1.6A까지
 65W  3000mA   65W 노트북 충전기: USB 포트에 600mA까지, USB 부팅은 꺼진다
 15W  3000mA   공식 15W 전원(4용): USB 포트에 600mA까지, USB 부팅은 꺼진다
 10W  2000mA   5V 2A 충전기: 부팅에 필요한 3A에 못 미친다
```

- **65W 충전기가 15W 전원이 된다**: 5V 줄이 3A이기 때문입니다. 5는 켜지지만 4용 전원을 꽂았을 때와 같은 처지가 됩니다
- **5A 줄이 있어야 USB가 풀린다**: 5는 전원이 5V에서 5A를 낼 수 있을 때에만 USB 포트들에 1.6A까지 내줍니다. 그렇지 않으면 600mA로 묶고, 처음 켤 때 OS가 그렇다고 알려 줍니다
- **3A 전원에서는 USB 부팅이 꺼져 있다**: USB에 꽂은 SSD로 부팅하려면 `config.txt`에 `usb_max_current_enable=1`을 적습니다. 부팅이 멈췄을 때 전원 버튼을 한 번 누르면 그 한 번만 넘어갑니다. 전원이 그 전류를 버티는지는 적은 사람이 책임집니다
- **케이블도 5A를 버텨야 한다**: 보통의 USB-C 케이블은 3A까지이고, 5A는 그렇게 만들어 표시한 케이블에서만 흐릅니다

## 전원이 모자랄 때

전원이 모자란 보드는 꺼지기보다 이상해집니다. 느려지고, USB 장치를 놓치고, 가끔 다시 시작합니다. 증상만으로는 알기 어려우므로 보드에게 묻습니다.

```sh
vcgencmd get_throttled                      # throttled=0x0 이면 깨끗하다
sudo dmesg | grep -i voltage                # 저전압 기록이 남았는지
vcgencmd pmic_read_adc EXT5V_V              # 5: 보드에 들어오는 전압
vcgencmd get_config usb_max_current_enable  # 5: USB 한도가 올라갔는지
```

셋째 명령에 대해 문서가 보여 주는 출력은 이렇습니다.

```text
EXT5V_V volt(24)=5.06520000V
```

- **0x1과 0x10000**: `get_throttled`의 값은 비트 무늬입니다. 0번 비트(0x1)는 지금 저전압이라는 뜻이고, 16번 비트(0x10000)는 켠 뒤로 저전압이 한 번이라도 있었다는 뜻입니다. 나머지 비트는 [「온도와 스로틀링 확인하기」](#/read/sbc-start/care-thermal)에서 풉니다
- **문턱은 4.63V**: B+ 이후의 보드는 Zero 계열을 빼고, 전압이 4.63V(±5%) 아래로 내려가면 알아채서 커널 로그에 남깁니다. 로그에는 `Undervoltage detected!`가 찍히고, 전압이 돌아오면 `Voltage normalised`가 찍힙니다
- **Zero는 알려 주지 않는다**: Zero 계열에는 이 감지가 없습니다. 문서는 켜진 Zero에 USB 장치를 꽂으면 전압이 떨어져 다시 시작할 수 있다고 적습니다
- **5의 전압계**: 5는 전원 관리 칩(PMIC)에 든 ADC로 들어오는 전압을 잽니다. USB 장치로 나가는 전류는 이 칩을 거치지 않아서 여기에 보이지 않습니다
- **고치는 순서**: 전원을 공식 것으로 바꾸고, 다음으로 케이블을 보고, 그래도 남으면 전류를 많이 먹는 USB 장치를 전원이 따로 달린 허브로 옮깁니다

## 케이블과 그 밖의 길

- **케이블의 저항**: 전선에서 사라지는 전압은 전류에 저항을 곱한 값입니다. 가는 길과 오는 길을 합쳐 0.1Ω이면 3A에서 0.3V, 5A에서 0.5V가 사라집니다. 5.1V에서 0.5V를 빼면 4.6V이고, 이는 저전압 문턱보다 낮습니다. 전류가 큰 5에서 케이블이 더 중요한 까닭입니다
- **붙어 나오는 케이블**: 공식 전원은 굵은 케이블이 붙은 채로 나옵니다. 충전기와 케이블을 따로 살 때에는 길이가 짧고 5A라고 표시된 것을 고릅니다
- **구멍이 여럿인 충전기**: 다른 기기를 꽂으면 충전기가 약속을 다시 맺습니다. 문서는 꺼 둔 보드가 이때 켜질 수 있다고 적습니다. 보드에는 전원 하나를 통째로 주는 편이 낫습니다
- **헤더의 5V 핀과 PoE**: 40핀 헤더의 5V 핀으로도 전원을 넣을 수 있고, 이더넷 케이블로 전원을 받는 PoE HAT이 이 길을 씁니다. 5는 PoE+(802.3at), 4 Model B와 3 Model B+는 PoE(802.3af)이고 어느 쪽이든 HAT이 있어야 합니다
- **말을 하지 않는 전원**: USB-PD로 말하지 않는 전원을 5에 쓸 때에는 부트로더 설정 `PSU_MAX_CURRENT`로 협상을 건너뛰고 용량을 정해 줄 수 있습니다([「부트로더 EEPROM과 부팅 순서」](#/read/sbc-start/cfg-eeprom))

<Note>
예제는 문서에 적힌 규칙(5V에서 5A면 USB에 1.6A, 아니면 600mA, 부팅에는 3A)을 옮긴 셈이고, 보드와 충전기가 실제로 주고받는 말을 흉내 낸 것은 아닙니다. 65W 충전기의 줄은 규격의 표를 따라 지은 것이어서 제품마다 다를 수 있습니다. 내 충전기가 5A를 내놓는지는 5에 꽂고 `vcgencmd get_config usb_max_current_enable`로 묻는 것이 확실합니다. 이 쪽의 명령과 출력은 문서에서 옮겼고, 보드에서 돌려 보지는 못했습니다.
</Note>

## 정리

- 보드마다 전원이 다르다. 5는 5.1V 5A, 4는 5.1V 3A, Zero 2 W는 micro USB로 5.1V 2.5A를 받는다
- USB-C 충전기는 와트가 아니라 5V 줄의 전류로 고른다. 5는 5A 줄이 있는 전원에서만 USB 한도를 1.6A로 올린다
- 전원이 의심스러우면 `vcgencmd get_throttled`와 커널 로그의 저전압 기록부터 본다
