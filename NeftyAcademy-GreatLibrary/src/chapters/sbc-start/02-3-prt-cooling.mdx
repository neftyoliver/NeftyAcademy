라즈베리파이는 뜨거워져도 망가지지 않습니다. 대신 느려집니다. 칩이 스스로 속도를 낮춰 열을 줄이기 때문이고, 이것을 스로틀링이라고 합니다. 방열판과 팬은 보드를 지키려고 다는 것이 아니라 속도를 지키려고 다는 것입니다. 이 쪽은 언제 느려지는지, 무엇을 달면 얼마나 식는지, 5의 팬이 어떻게 도는지를 봅니다.

## 뜨거워지면 생기는 일

- **80도부터 늦춘다**: 칩의 온도가 80도에서 85도 사이면 Arm 코어의 속도를 차츰 낮춥니다. 85도에 닿으면 코어와 GPU를 함께 낮춥니다
- **85도는 모든 보드의 한도**: 이 값은 설정으로 낮출 수는 있어도 높일 수는 없습니다
- **방열판은 필수가 아니다**: 문서는 스로틀링이 있으므로 방열판이 없어도 칩이 열로 상하지 않는다고 적습니다. 방열판이나 작은 팬은 스로틀링을 줄여 성능을 올립니다

5를 내놓을 때 라즈베리파이가 직접 잰 값이 있습니다. 네 코어에 부하를 계속 거는 `stress --cpu 4`로 시험한 것입니다.

| 5에 단 것 | 한가할 때 | 부하를 계속 걸 때 |
| --- | --- | --- |
| 아무것도 없음 | 65도쯤 | 85도를 넘겨 스로틀링이 이어진다 |
| 팬이 든 공식 케이스 | 48도쯤 | 72도쯤, 뚜껑을 닫으면 74도쯤 |
| Active Cooler | 45도쯤 | 60도쯤, 높을 때 62~63도 |

- **평소에는 없어도 된다**: 그 글은 평범한 쓰임새라면 식히는 장치가 선택이라고 적습니다. 커널을 빌드하는 일처럼 무거운 부하가 오래 이어질 때 스로틀링이 걸립니다
- **방열판만으로는 오래 못 버틴다**: Active Cooler의 팬 선을 뽑고 시험하자 부하를 건 지 200초쯤에 스로틀링이 시작됐습니다. 방열판은 열을 잠시 받아 줄 뿐이고, 내보내는 것은 바람입니다
- **느려져도 4보다는 빠르다**: 글은 스로틀링이 걸린 5가 걸리지 않은 4보다 빠르다고 적습니다. 식히지 않고 써도 해가 되지는 않습니다

## 5의 팬 단자와 온도 표

5에는 팬을 꽂는 4핀 단자가 40핀 헤더와 USB 2.0 단자 사이에 있습니다. 핀은 5V, PWM(속도를 정하는 신호), GND, Tach(팬이 도는 속도를 알려 오는 신호)입니다. 켤 때 펌웨어가 팬을 돌려 보고, Tach로 도는 것이 확인되면 온도에 따라 속도를 조절하기 시작합니다. 팬은 꽂기만 하면 됩니다.

문서의 기본 표는 50도에서 30%, 60도에서 50%, 67.5도에서 70%, 75도에서 100%입니다. 식을 때에는 문턱보다 5도 더 내려가야 속도를 줄입니다. 이 5도가 히스테리시스입니다. 아래 예제는 이 표를 그대로 옮겨, 온도가 올랐다가 내려올 때 팬이 어떻게 도는지 보여 줍니다.

```c
// 5의 팬 제어를 흉내 낸다: 문서의 온도 표와 5도의 히스테리시스
#include <stdio.h>

// 문턱은 1000분의 1도로 적는다. dtparam=fan_temp0=55000 에 쓰는 단위와 같다
static const int trip_mc[] = {50000, 60000, 67500, 75000};
static const int speed_pct[] = {0, 30, 50, 70, 100};
enum { TRIPS = 4, HYST_MC = 5000 };

// level 은 지금 넘어 있는 문턱의 수(0~4)다. 온도를 보고 새 level 을 돌려준다
static int next_level(int level, int temp_mc) {
    while (level < TRIPS && temp_mc >= trip_mc[level])
        ++level;                             // 문턱에 닿으면 한 단 올린다
    while (level > 0 && temp_mc <= trip_mc[level - 1] - HYST_MC)
        --level;                             // 문턱보다 5도 아래라야 내린다
    return level;
}

int main(void) {
    const double trace[] = {45, 52, 64, 70, 76, 72, 69, 64, 62, 54, 46, 44};
    int level = 0;
    for (size_t i = 0; i < sizeof trace / sizeof trace[0]; ++i) {
        int before = level;
        level = next_level(level, (int)(trace[i] * 1000));
        printf("%4.1f도  팬 %3d%%%s\n", trace[i], speed_pct[level],
               level > before ? "  올림" : level < before ? "  내림" : "");
    }
}
```

```text
45.0도  팬   0%
52.0도  팬  30%  올림
64.0도  팬  50%  올림
70.0도  팬  70%  올림
76.0도  팬 100%  올림
72.0도  팬 100%
69.0도  팬  70%  내림
64.0도  팬  70%
62.0도  팬  50%  내림
54.0도  팬  30%  내림
46.0도  팬  30%
44.0도  팬   0%  내림
```

- **같은 64도, 다른 속도**: 올라가는 길의 64도에서는 50%이고, 내려오는 길의 64도에서는 70%입니다. 70%로 올린 문턱(67.5도)보다 5도 낮은 62.5도 아래로 내려가야 줄이기 때문입니다
- **히스테리시스가 없다면**: 온도가 문턱 바로 위아래를 오갈 때마다 팬이 빨라졌다 느려졌다 합니다. 켜는 문턱과 끄는 문턱을 벌려 두는 것은 센서 값으로 무엇을 켜고 끄는 프로그램에서 늘 쓰는 수법입니다
- **문턱 바꾸기**: `config.txt`에 `dtparam=fan_temp0=55000`을 적으면 55도까지 팬이 돌지 않습니다. 문턱은 `fan_temp0`에서 `fan_temp3`까지 넷이고, 뒤에 `_hyst`와 `_speed`를 붙인 이름으로 히스테리시스와 속도를 정합니다([「dtoverlay로 기능 켜기」](#/read/sbc-start/cfg-overlays))
- **팬의 전류**: 팬 단자의 전류는 USB 포트들과 같은 한도에서 나갑니다([「전원: 5V 5A와 USB-PD」](#/read/sbc-start/prt-power))

## 무엇을 달까

| 보드 | 부품 | 붙는 곳 |
| --- | --- | --- |
| 5 | Active Cooler | 보드의 구멍 둘과 팬 단자 |
| 5 | 팬이 든 공식 케이스 | 팬 단자 |
| 4 | 공식 케이스에 Case Fan | 뚜껑, 40핀 헤더의 5V와 GND와 GPIO 14 |

- **Active Cooler**: 알루미늄 방열판에 송풍 팬을 얹은 것입니다. 열을 옮기는 패드가 붙어 있고, 스프링이 든 누름 핀으로 보드에 고정합니다. 한번 달면 떼지 않습니다. 제품 쪽은 떼어 내면 핀과 패드가 상한다고 적습니다
- **SSD를 함께 달 때**: M.2 HAT+는 Active Cooler 위에 올라갑니다. 그렇게 얹고 잰 값은 한가할 때 49도쯤, 부하에서 64도쯤입니다. 공식 케이스 안에는 M.2 HAT+ Compact가 들어갑니다([「microSD와 NVMe」](#/read/sbc-start/prt-storage))
- **4의 Case Fan**: 공식 케이스의 뚜껑에 끼우고 선 셋을 40핀 헤더에 꽂습니다. 데스크톱의 Raspberry Pi Configuration에서 Performance 탭의 Fan을 켜고, 핀(기본 14)과 켜질 온도(기본 80도)를 정합니다. 설정하기 전에는 보드가 켜져 있는 내내 돕니다
- **GPIO 14는 시리얼 콘솔의 핀**: 이 핀은 시리얼 콘솔이 글자를 내보내는 핀이기도 합니다. 둘을 함께 쓰려면 팬의 신호선을 다른 GPIO로 옮기고 설정의 핀 번호를 맞춥니다([「시리얼 콘솔」](#/read/sbc-start/rem-serial))
- **세워 두기**: 문서는 보드를 세워 두면 바람이 잘 통해 열이 조금 더 빠진다고 적습니다

## 재 보기

```sh
vcgencmd measure_temp     # temp=47.2'C 같은 꼴로 나온다
vcgencmd get_throttled    # 0x4 비트가 서 있으면 지금 스로틀링 중이다
```

문서는 리눅스 쪽에서 읽는 온도가 부정확할 수 있고 `vcgencmd`가 칩의 온도를 바로 읽어 정확하다고 적습니다. 온도를 오래 지켜보는 법은 [「온도와 스로틀링 확인하기」](#/read/sbc-start/care-thermal)에서 봅니다.

<Note>
팬의 온도 표는 출처에 따라 다릅니다. 2023년에 5를 내놓을 때의 글은 60도에서 켜져 67.5도에서 빨라지고 75도에서 끝까지 돈다고 적었고, 지금의 문서는 50도에서 30%로 시작하는 위의 표를 싣습니다. 예제는 지금의 문서를 따랐습니다. 보드에서 돌려 보지는 못했으므로, 내 보드의 팬이 표와 다르게 돈다면 깔린 소프트웨어의 판이 다른 것으로 보고 `vcgencmd measure_temp`로 직접 확인합니다.
</Note>

## 정리

- 뜨거워진 보드는 망가지지 않고 느려진다. 80도부터 코어를 늦추고 85도가 한도다
- 5는 평소에는 식히지 않아도 되지만, 무거운 일을 오래 시키려면 Active Cooler나 팬이 든 케이스를 단다
- 5의 팬은 꽂기만 하면 온도 표대로 돌고, 식을 때에는 문턱보다 5도 더 내려가야 느려진다
