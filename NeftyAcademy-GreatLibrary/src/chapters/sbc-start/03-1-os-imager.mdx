라즈베리파이의 보드에는 OS가 들어 있지 않습니다. PC에서 microSD에 OS를 써 넣어야 하고, 그 일을 하는 공식 도구가 Raspberry Pi Imager입니다. 받아서 압축을 풀고 카드에 쓰고 제대로 쓰였는지 확인하는 일을 한 번에 해 줍니다. 2025년 11월에 나온 2.0부터 화면이 단계를 차례로 밟는 꼴로 바뀌었고, 이 쪽은 그 순서를 따릅니다.

## 깔기

| PC의 OS | 까는 법 |
| --- | --- |
| Windows, macOS | 라즈베리파이의 Software 쪽에서 설치 파일을 받는다 |
| Raspberry Pi OS | `sudo apt install rpi-imager` |
| 그 밖의 리눅스 | AppImage 파일을 받아 실행 권한을 주고 실행한다 |

Imager는 OS의 목록을 품고 있지 않습니다. 켤 때마다 라즈베리파이의 서버에서 목록 파일을 받아 옵니다. 그래서 프로그램을 새로 깔지 않아도 늘 최신 OS가 보이고, 그 대신 쓰는 동안 PC가 인터넷에 이어져 있어야 합니다.

## 여섯 단계

| 단계 | 하는 일 |
| --- | --- |
| Device | 보드를 고른다. 뒤의 OS 목록이 그 보드에 맞는 것으로 걸러진다 |
| OS | OS를 고른다. 그 보드에 권하는 것이 맨 위에 있다 |
| Storage | OS를 쓸 카드를 고른다 |
| Customisation | 호스트 이름, 사용자, Wi-Fi, SSH를 미리 정한다 |
| Writing | 요약을 확인하고 쓴다. 다 쓰면 검증한다 |
| Done | 카드를 뽑아 보드에 꽂는다 |

- **Device를 먼저 고르는 까닭**: 5에서 돌지 않는 옛 OS나, 32비트 칩이 든 옛 보드에서 돌지 않는 64비트 OS를 고르지 않게 목록을 걸러 줍니다
- **Use Custom**: OS 목록의 이 항목으로 PC에 받아 둔 이미지 파일을 쓸 수 있습니다
- **Exclude system drives는 켜 둔다**: Storage 단계의 이 선택은 PC의 디스크를 목록에서 빼 줍니다. 문서는 이것을 끄면 내 자료를 지우고 PC를 못 쓰게 만들 수 있다고 경고합니다
- **Customisation은 건너뛸 수 있다**: 건너뛰면 OS가 처음 켜질 때 같은 것을 화면에서 묻습니다. 모니터 없이 쓸 보드라면 여기서 정해야 합니다([「모니터 없이 설정하기: Wi-Fi, SSH, 사용자」](#/read/sbc-start/os-headless))

## 쓰기와 검증

- **카드의 내용은 모두 지워진다**: Write를 누르면 경고가 뜨고, "I understand, erase and write"를 눌러야 시작합니다. PC가 관리자 권한을 물으면 허락합니다
- **검증**: 다 쓴 뒤 카드에 제대로 쓰였는지 확인합니다. 몇 분이 더 걸리고 건너뛸 수도 있지만, 문서는 하기를 권합니다. 불량 카드나 접촉이 나쁜 리더는 여기서 드러납니다
- **끝난 뒤**: Done이 뜨면 Finish를 누르고 카드를 뽑습니다. 왼쪽 아래의 App Options에 다 쓰면 카드를 꺼내 주는 선택(Eject media when finished)이 있습니다

## 이미지 파일을 직접 받았다면

OS 이미지는 라즈베리파이의 내려받기 쪽에서 `.img.xz` 파일로도 받을 수 있습니다. 여러 장을 쓰거나 인터넷이 느린 곳에서 쓸 때 편합니다. 그 쪽에는 파일마다 SHA256 해시가 적혀 있습니다. 받은 파일의 해시를 계산해 견주면 받는 도중에 깨지지 않았는지 알 수 있습니다.

```sh
sha256sum 받은_이미지.img.xz        # 리눅스, macOS는 shasum -a 256
Get-FileHash 받은_이미지.img.xz     # Windows의 PowerShell
```

확인한 파일은 OS 단계의 Use Custom으로 고릅니다. 압축은 풀지 않아도 됩니다.

## 카드 리더 없이 올리기

4 Model B 이후의 주력 보드와 400, 500, 500+는 보드 스스로 Imager를 받아 띄울 수 있습니다. Network Install이라고 합니다.

- **필요한 것**: 모니터, 키보드, 이더넷 케이블, 비어 있는 저장 장치
- **시작하는 법**: 빈 카드를 꽂고 켜거나, Shift 키를 누른 채 켭니다. 보드가 이더넷으로 설치 프로그램을 받아 오고, 그 뒤는 PC의 Imager와 같습니다
- **쓸 수 없는 때**: 화면 없이 쓸 계획이거나 Zero 2 W라면 이 길은 없습니다. PC와 리더로 씁니다

<Note>
화면의 낱말은 Imager의 판에 따라 조금씩 달라집니다. 이 쪽은 2026년 11월의 문서가 설명하는 2.0 계열을 따랐고, 직접 실행해 확인하지는 못했습니다. 2.0보다 옛 판은 지금의 Raspberry Pi OS에 미리 정한 설정을 넣지 못할 수 있으므로, 오래전에 깔아 둔 Imager가 있다면 새로 받습니다.
</Note>

## 정리

- OS는 PC의 Raspberry Pi Imager로 카드에 쓴다. 보드, OS, 카드를 고르고 설정을 미리 정한 뒤 쓰고 검증한다
- 쓰면 카드의 내용이 모두 지워진다. PC의 디스크가 목록에 뜨지 않게 Exclude system drives를 켜 둔다
- 이미지를 따로 받았다면 SHA256 해시를 견줘 확인하고 Use Custom으로 쓴다
