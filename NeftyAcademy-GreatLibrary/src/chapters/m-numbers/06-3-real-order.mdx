실수는 수직선의 점이므로 왼쪽과 오른쪽이 있습니다. 순서의 성질은 유리수에서와 똑같습니다([「유리수의 크기와 수직선」](#/read/m-numbers/rat-order)). 새로 필요한 것은 "어디부터 어디까지"를 적는 기호입니다. 해석학의 문장은 거의 모두 구간에 대한 것이기 때문입니다.

## 소수로 견주기

두 실수를 소수로 적어 앞자리부터 견줍니다. 처음으로 다른 자리에서 숫자가 큰 쪽이 큽니다.

$$
\sqrt{2} = 1.4142\cdots \; < \; 1.4150 \; < \; \frac{17}{12} = 1.4166\cdots
$$

- **음수는 반대**: $-1.42 < -1.41$입니다. 0에서 먼 쪽이 작습니다
- **9가 끝없이 이어지는 표기만 조심한다**: $0.4999\cdots$와 $0.5$는 첫 자리가 달라도 같은 수입니다([「끝없는 소수」](#/read/m-numbers/real-decimal))
- **제곱해서 견주기**: 양수끼리는 제곱해도 순서가 그대로입니다. $\sqrt{10}$과 $3.2$는 10과 10.24를 견주면 됩니다

## 구간

<Def title="구간">
두 실수 사이에 있는 실수를 모두 모은 것을 **구간**이라고 합니다. 끝점을 넣으면 대괄호로, 빼면 소괄호로 적습니다.
</Def>

| 기호 | 뜻 | 이름 |
| --- | --- | --- |
| $[a, b]$ | $a \le x \le b$ | 닫힌 구간 |
| $(a, b)$ | $a < x < b$ | 열린 구간 |
| $[a, b)$ | $a \le x < b$ | 반열린 구간 |
| $(a, \infty)$ | $x > a$ | 끝없는 구간 |
| $(-\infty, b]$ | $x \le b$ | 끝없는 구간 |

<Figure caption="[1, 4). 속이 찬 점은 들어가고, 속이 빈 점은 들어가지 않습니다">
  <NumLine x={[-0.6, 5.6]} step={1} ranges={[{ from: 1, to: 4, open: [false, true], color: 1 }]} />
</Figure>

<Figure caption="(2, ∞). 2는 들지 않고, 오른쪽으로 끝없이 이어집니다">
  <NumLine x={[-0.6, 5.6]} step={1} ranges={[{ from: 2, open: [true, false], color: 0 }]} />
</Figure>

- **$\infty$는 수가 아니다**: 끝이 없다는 표시입니다. 그 쪽에는 끝점이 없으므로 늘 소괄호를 씁니다
- **구간의 길이**: $[a, b]$와 $(a, b)$의 길이는 모두 $b - a$입니다. 끝점 둘은 길이에 보태는 것이 없습니다
- **가운데와 반지름으로 적기**: $|x - c| < r$은 구간 $(c - r, c + r)$입니다. 가운데가 $c$이고 반지름이 $r$입니다([「절댓값」](#/read/m-numbers/int-abs))
- **집합으로 적기**: $[1, 4)$를 $\{x \mid 1 \le x < 4\}$로도 적습니다([「집합과 원소」](#/read/m-sets/set))

## 끝점 하나의 차이

$[0, 1]$에는 가장 큰 수 1이 있습니다. $(0, 1)$에는 가장 큰 수가 없습니다. 1보다 작은 어떤 수 $x$를 잡아도 $x$와 1의 평균이 $x$보다 크고 여전히 1보다 작기 때문입니다.

- **끝이 있는 것과 끝을 갖는 것은 다르다**: $(0, 1)$은 1에서 막혀 있지만, 그 막힌 곳이 구간 안에 없습니다
- **가장 큰 수 대신 쓰는 것**: 이럴 때 1을 "가장 작은 위쪽 경계"라고 부릅니다. 이 장의 마지막 쪽이 이 개념으로 실수의 빈틈없음을 적습니다([「빈틈이 없다는 것」](#/read/m-numbers/real-complete))

## 어느 구간에나 유리수와 무리수가 있다

<Thm title="유리수와 무리수의 조밀성">
$a < b$인 어느 두 실수 사이에도 유리수가 있고, 무리수도 있습니다.
</Thm>

<Proof>

**유리수.** $b - a$가 양수이므로 $\frac{1}{n} < b - a$인 자연수 $n$이 있습니다. 수직선에 $\frac{1}{n}$ 간격으로 눈금 $\frac{m}{n}$을 찍으면, 눈금 사이가 구간보다 좁으므로 구간을 건너뛸 수 없습니다. 적어도 하나가 $a$와 $b$ 사이에 듭니다.

**무리수.** $a - \sqrt{2}$와 $b - \sqrt{2}$ 사이에 유리수 $q$가 있습니다. 양쪽에 $\sqrt{2}$를 더하면 $a < q + \sqrt{2} < b$이고, $q + \sqrt{2}$는 무리수입니다([「수직선의 빈자리와 무리수」](#/read/m-numbers/real-line)).

</Proof>

<Ex title="사이의 수 찾기">
$\sqrt{2}$와 $\sqrt{3}$ 사이의 유리수 하나와 무리수 하나를 적으세요.

<Sol>

$\sqrt{2} = 1.414\cdots$이고 $\sqrt{3} = 1.732\cdots$입니다. 유리수로는 $1.5 = \frac{3}{2}$가 있습니다. $1.5^2 = 2.25$가 2와 3 사이이기 때문입니다. 무리수로는 $\sqrt{2.5}$가 있습니다. 2.5가 2와 3 사이이고, $2.5 = \frac{5}{2}$는 유리수의 제곱이 아닙니다.

</Sol>
</Ex>

## 구간끼리 겹치기

<Figure caption="파란 [1, 4]와 주황 [3, 6]. 함께 드는 곳은 초록으로 칠한 [3, 4]이고, 합치면 [1, 6]입니다">
  <NumLine x={[-0.6, 7.6]} step={1} ranges={[{ from: 1, to: 4, color: 1, label: '[1, 4]' }, { from: 3, to: 6, color: 0, label: '[3, 6]' }, { from: 3, to: 4, color: 2 }]} />
</Figure>

연립부등식의 답은 구간의 겹친 곳입니다. $1 \le x \le 4$이고 $3 \le x \le 6$이면 $3 \le x \le 4$입니다([「연립부등식과 영역」](#/read/m-equations/regions)).

<Note>
첫 식의 세 소수와 $\sqrt{10} < 3.2$, 예제의 네 값은 프로그램으로 확인했습니다. 정리의 유리수 쪽은 길이가 0.001부터 3까지인 구간 2000개를 마구잡이로 만들어, 증명대로 잡은 $n$의 눈금이 구간 안에 드는지 확인했습니다. 증명에서 $\frac{1}{n} < b - a$인 $n$이 있다는 것은 아르키메데스 성질이고, 실수에서는 빈틈이 없다는 성질에서 나옵니다. 예제에서 $\frac{5}{2}$가 유리수의 제곱이 아닌 까닭은, 기약분수를 제곱하면 분자와 분모가 모두 제곱수가 되기 때문입니다.
</Note>

## 요점

- 실수는 소수의 앞자리부터 견준다. 순서의 성질은 유리수에서와 같다
- 구간은 끝점을 넣으면 대괄호, 빼면 소괄호로 적는다. $\infty$ 쪽은 늘 소괄호이다
- 어느 두 실수 사이에도 유리수와 무리수가 모두 있다
