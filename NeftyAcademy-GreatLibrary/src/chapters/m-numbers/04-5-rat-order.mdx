자연수는 자릿수와 앞자리만 보면 크기를 알 수 있습니다. 분수는 $\frac{3}{5}$과 $\frac{5}{8}$ 가운데 어느 쪽이 큰지 한눈에 보이지 않습니다. 이 쪽은 분수의 크기를 견주는 방법 넷과, 유리수에서 순서가 갖는 성질을 봅니다.

오른쪽에 있는 수가 큽니다. 정수에서 쓰던 규칙 그대로입니다([「0과 음수」](#/read/m-numbers/int-negative)).

## 견주는 방법 넷

| 방법 | 보기 | 까닭 |
| --- | --- | --- |
| 분모가 같으면 분자를 본다 | $\frac{3}{7} < \frac{5}{7}$ | 조각의 크기가 같고 수가 다르다 |
| 분자가 같으면 분모를 본다 | $\frac{3}{8} < \frac{3}{5}$ | 조각의 수가 같고, 분모가 클수록 조각이 작다 |
| 통분한다 | $\frac{3}{4} = \frac{9}{12} < \frac{10}{12} = \frac{5}{6}$ | 조각의 크기를 맞춘다 |
| 기준과 견준다 | $\frac{7}{8} < \frac{8}{9}$ | 1까지 남은 것이 $\frac{1}{8}$과 $\frac{1}{9}$이다 |

통분을 줄여 쓴 것이 엇갈려 곱하기입니다([「같은 분수: 약분과 통분」](#/read/m-numbers/rat-equal)).

<Thm title="엇갈려 곱해 견주기">
분모 $b$, $d$가 양수일 때, $\frac{a}{b} < \frac{c}{d}$인 것은 $ad < bc$인 것과 같습니다.
</Thm>

두 분수를 분모 $bd$로 통분하면 $\frac{ad}{bd}$와 $\frac{bc}{bd}$이고, 분모가 같으므로 분자를 견주면 됩니다.

<Ex title="3/5과 5/8">
$\frac{3}{5}$과 $\frac{5}{8}$ 가운데 어느 쪽이 큽니까.

<Sol>

엇갈려 곱하면 $3 \times 8 = 24$이고 $5 \times 5 = 25$입니다. $24 < 25$이므로 $\frac{3}{5} < \frac{5}{8}$입니다. 차는 $\frac{25}{40} - \frac{24}{40} = \frac{1}{40}$입니다.

</Sol>
</Ex>

## 음수가 섞이면

$$
-\frac{2}{3} < -\frac{1}{2} < 0 < \frac{1}{2} < \frac{2}{3}
$$

음수끼리는 0에서 먼 쪽이 작습니다. $\frac{2}{3}$이 $\frac{1}{2}$보다 크므로 $-\frac{2}{3}$는 $-\frac{1}{2}$보다 왼쪽에 있습니다.

## 순서의 성질

- **셋 가운데 꼭 하나**: 두 유리수 $x$, $y$에 대해 $x < y$, $x = y$, $x > y$ 가운데 하나만 성립합니다
- **이어진다**: $x < y$이고 $y < z$이면 $x < z$입니다
- **더해도 그대로**: $x < y$이면 $x + z < y + z$입니다
- **양수를 곱해도 그대로**: $x < y$이고 $z > 0$이면 $xz < yz$입니다
- **음수를 곱하면 뒤집힌다**: $x < y$이고 $z < 0$이면 $xz > yz$입니다

앞의 넷은 자연수에서 보던 것입니다([「크기와 수직선」](#/read/m-numbers/nat-order)). 마지막이 음수가 생기면서 새로 나온 성질입니다. $-1$을 곱하는 것은 수직선을 0을 가운데 두고 뒤집는 것이므로([「정수의 곱셈과 나눗셈」](#/read/m-numbers/int-mul)) 왼쪽과 오른쪽이 바뀝니다.

<Figure caption="2 < 3의 양쪽에 −1을 곱하면 −2 > −3. 뒤집으면 오른쪽에 있던 수가 왼쪽으로 갑니다">
  <NumLine x={[-4.4, 4.4]} step={1} points={[{ at: 2, label: '2', color: 1 }, { at: 3, label: '3', color: 0 }, { at: -2, label: '−2', color: 1 }, { at: -3, label: '−3', color: 0 }]} />
</Figure>

- **역수를 잡아도 뒤집힌다**: 양수 $x < y$에 대해 $\frac{1}{x} > \frac{1}{y}$입니다. $2 < 3$이고 $\frac{1}{2} > \frac{1}{3}$입니다. 분자가 같으면 분모가 큰 쪽이 작다는 것과 같은 말입니다

부등식을 풀 때 음수를 곱하거나 나누면 부등호의 방향을 바꾸는 것이 이 성질입니다([「부등식」](#/read/m-equations/inequality)).

## 아무리 작아도 모으면 넘는다

<Thm name="성질" title="아르키메데스 성질">
양의 유리수 $x$, $y$가 있으면, $x$가 아무리 작고 $y$가 아무리 커도 $nx > y$인 자연수 $n$이 있습니다.
</Thm>

$x = \frac{a}{b}$, $y = \frac{c}{d}$로 적고 분모와 분자가 모두 자연수라고 하면, $n = bc + 1$로 잡을 수 있습니다. $nx = \frac{(bc + 1)a}{b}$는 $ca$보다 크고, $ca$는 $c$ 이상이며, $c$는 $\frac{c}{d}$ 이상이기 때문입니다.

- **끝없이 큰 유리수는 없다**: 어느 유리수보다도 큰 자연수가 있습니다
- **끝없이 작은 양의 유리수도 없다**: 어느 양의 유리수보다도 작은 $\frac{1}{n}$이 있습니다
- **당연해 보여도 성질이다**: 이 성질이 성립하지 않는 수의 체계도 만들 수 있습니다. 실수에서는 빈틈이 없다는 성질에서 따라 나옵니다([「빈틈이 없다는 것」](#/read/m-numbers/real-complete))

<Note>
표의 네 부등식과 예제, 음수가 섞인 부등식 줄은 프로그램의 분수 셈으로 확인했습니다. 순서의 성질 다섯과 엇갈려 곱해 견주기, 역수를 잡으면 뒤집힌다는 것은 분자가 $-9$부터 9까지이고 분모가 1부터 9까지인 분수들에 넣어 확인했습니다. 아르키메데스 성질의 $n = bc + 1$은 분자와 분모가 1부터 12까지인 모든 $x$, $y$에서 $nx > y$인 것을 확인했습니다. 셋 가운데 꼭 하나와 이어진다는 성질은 정수의 같은 성질에서 따라 나오며, 여기서는 증명하지 않았습니다.
</Note>

## 요점

- 분모가 양수일 때 $\frac{a}{b} < \frac{c}{d}$는 $ad < bc$와 같다
- 부등식의 양쪽에 양수를 곱하면 그대로이고, 음수를 곱하면 방향이 뒤집힌다
- 아무리 작은 양수도 거듭 더하면 어떤 수든 넘는다. 이것이 아르키메데스 성질이다
