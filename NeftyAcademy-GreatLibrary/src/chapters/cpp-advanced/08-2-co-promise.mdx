[세 낱말](#/read/cpp-advanced/co-keywords)의 뜻은 반환 타입이 채운다고 했습니다. 채우는 자리가 반환 타입 안의 `promise_type`입니다. 이 페이지에서는 컴파일러가 그 타입의 함수를 **언제** 부르는지를 찍어 보고, 프레임을 가리키는 핸들을 다룹니다.

## 컴파일러가 본문을 감싸는 모양

코루틴 `R f(인자)`를 만나면 컴파일러는 `R::promise_type`을 찾고, 본문을 아래 모양으로 감쌉니다. 실제 코드가 아니라 뜻을 적은 것입니다.

```cpp nocheck
{
    // 프레임을 잡고 인자를 복사한 다음
    promise_type promise;
    auto result = promise.get_return_object();   // 부른 쪽이 받을 것
    co_await promise.initial_suspend();
    try {
        // 내가 쓴 본문
    } catch (...) {
        promise.unhandled_exception();
    }
    co_await promise.final_suspend();
}   // 여기에 닿으면 프레임이 사라진다
```

프레임 하나에 프라미스 객체 하나가 들어 있습니다. 코루틴과 바깥이 값을 주고받는 **우체통**입니다. 이름이 같을 뿐 [`std::promise`](#/read/cpp-advanced/asy-future)와는 다른 것입니다.

## 부르는 순서를 찍어 본다

```cpp
#include <coroutine>
#include <exception>
#include <print>
#include <stdexcept>
#include <utility>

struct Answer {
    struct promise_type {
        int value = 0;
        std::exception_ptr error;

        promise_type() { std::println("  1. 프라미스 객체가 생긴다"); }
        ~promise_type() { std::println("  9. 프라미스 객체가 사라진다"); }
        Answer get_return_object()
        {
            std::println("  2. get_return_object");
            auto self = std::coroutine_handle<promise_type>::from_promise(*this);
            return Answer{self};
        }
        std::suspend_always initial_suspend() noexcept
        {
            std::println("  3. initial_suspend");
            return {};
        }
        void return_value(int v)
        {
            std::println("  6. return_value({})", v);
            value = v;
        }
        void unhandled_exception()
        {
            std::println("  6. unhandled_exception");
            error = std::current_exception();
        }
        std::suspend_always final_suspend() noexcept
        {
            std::println("  7. final_suspend");
            return {};
        }
    };

    explicit Answer(std::coroutine_handle<promise_type> h) : handle_(h) {}
    Answer(Answer&& other) noexcept : handle_(std::exchange(other.handle_, {})) {}
    ~Answer()
    {
        if (handle_) {
            std::println("  8. destroy");
            handle_.destroy();
        }
    }

    int get()
    {
        if (!handle_.done())
            handle_.resume();
        if (handle_.promise().error)
            std::rethrow_exception(handle_.promise().error);
        return handle_.promise().value;
    }

private:
    std::coroutine_handle<promise_type> handle_;
};

Answer compute()
{
    std::println("  5. 본문이 돈다");
    co_return 42;
}

Answer broken()
{
    std::println("  5. 본문이 돌다가 던진다");
    throw std::runtime_error("계산 실패");
    co_return 0;   // 이 줄이 있어서 코루틴이다
}

int main()
{
    {
        Answer a = compute();
        std::println("  4. 부른 쪽으로 돌아왔다. 본문은 아직 돌지 않았다");
        std::println("값 {}", a.get());
    }
    std::println("----");
    try {
        Answer b = broken();
        std::println("  4. 부른 쪽으로 돌아왔다");
        b.get();
    } catch (const std::exception& e) {
        std::println("받은 예외: {}", e.what());
    }
}
```

```text

  2. get_return_object
  3. initial_suspend
  4. 부른 쪽으로 돌아왔다. 본문은 아직 돌지 않았다
  5. 본문이 돈다
  6. return_value(42)
  7. final_suspend
값 42
  8. destroy
  9. 프라미스 객체가 사라진다
----

  2. get_return_object
  3. initial_suspend

  6. unhandled_exception
  7. final_suspend

```

본문에서 새어 나온 예외는 부른 쪽으로 **저절로 가지 않습니다.** `unhandled_exception()`이 받아서 담아 두고, `get()`이 다시 던졌습니다. 예외가 난 뒤에도 `final_suspend`는 불립니다.

| 함수 | 불리는 때 | 정하는 것 |
| --- | --- | --- |
| 생성자 | 프레임을 잡은 직후 | 코루틴의 인자를 받는 생성자가 있으면 그것이 쓰인다 |
| `get_return_object()` | 본문보다 먼저 | 부른 쪽이 받는 객체. 보통 핸들을 넣어 준다 |
| `initial_suspend()` | 본문 직전 | 곧바로 돌지, 멈춘 채로 돌려줄지 |
| `yield_value(v)` | `co_yield v` | 내준 값을 어디에 둘지 |
| `await_transform(e)` | `co_await e`마다. 있을 때만 | 기다릴 것을 바꾸거나, 못 기다리게 막는다 |
| `return_value(v)`, `return_void()` | `co_return` | 결과를 어디에 둘지. 둘 가운데 하나만 둔다 |
| `unhandled_exception()` | 본문에서 예외가 새어 나올 때 | 담아 둘지, 끝낼지 |
| `final_suspend()` | 본문이 끝난 뒤 | 프레임을 스스로 치울지, 주인에게 맡길지 |

## 코루틴 핸들

`std::coroutine_handle<P>`는 프레임을 가리키는 **포인터**입니다. 크기는 8바이트이고, 복사해도 프레임은 하나입니다. 소유하지 않으므로 스스로 `destroy`하지도 않습니다.

| 함수 | 하는 일 | 조심할 것 |
| --- | --- | --- |
| `resume()` | 멈춘 자리에서 이어 돌린다 | 끝난 코루틴에 부르면 미정의 동작 |
| `done()` | `final_suspend`에서 멈춰 있는가 | 멈춰 있는 코루틴에만 물을 수 있다 |
| `destroy()` | 프레임을 없앤다. 살아 있던 지역 변수의 소멸자가 불린다 | 두 번 부르면 안 된다 |
| `promise()` | 프레임 안의 프라미스 객체 | |
| `from_promise(p)` | 프라미스 객체에서 핸들을 만든다 | 그 프레임의 프라미스 객체여야 한다 |
| `address()`, `from_address(p)` | `void*`로 바꾸고 되돌린다 | C API의 콜백 인자로 넘길 때 쓴다 |

`coroutine_handle<>`(꺾쇠가 빈 것)는 프라미스 타입을 모르는 핸들입니다. `resume`, `done`, `destroy`만 됩니다. 어떤 코루틴이든 담을 수 있어서 [어웨이터](#/read/cpp-advanced/co-keywords)가 받는 것이 이 타입입니다.

예제의 `Answer`처럼 **핸들을 감싼 타입이 프레임의 주인**이 되는 것이 보통입니다. [`unique_ptr`](#/read/cpp-advanced/sp-unique)와 같은 모양입니다. 복사를 막고, 옮기면 넘겨주고, 소멸자에서 `destroy`합니다.

## 두 군데의 선택

| 고르는 곳 | `suspend_never` | `suspend_always` |
| --- | --- | --- |
| `initial_suspend` | 부르는 순간 첫 멈춤까지 돈다 | 멈춘 채로 돌아온다. 누가 `resume`해야 돈다 |
| `final_suspend` | 끝나면 프레임이 **스스로 사라진다** | 프레임이 남는다. 주인이 `destroy`해야 한다 |

결과를 프레임에서 꺼내야 하는 타입은 `final_suspend`에서 멈춰야 합니다. 스스로 사라지는 코루틴의 핸들을 들고 있으면 이렇게 됩니다.

```cpp norun
#include <coroutine>
#include <print>

struct Loose {
    struct promise_type {
        Loose get_return_object()
        {
            return {std::coroutine_handle<promise_type>::from_promise(*this)};
        }
        std::suspend_never initial_suspend() noexcept { return {}; }
        std::suspend_never final_suspend() noexcept { return {}; }
        void return_void() {}
        void unhandled_exception() {}
    };
    std::coroutine_handle<promise_type> handle;
};

Loose quick() { co_return; }

int main()
{
    Loose job = quick();                     // 이미 끝나서 프레임이 없다
    std::println("{}", job.handle.done());   // 사라진 프레임을 읽는다
}
```

<Note>
`promise_type`은 `std::coroutine_traits<R, 인자…>`를 거쳐 찾습니다. 기본은 `R::promise_type`이고, 내 것이 아닌 타입을 코루틴의 반환 타입으로 쓰고 싶으면 `coroutine_traits`를 특수화합니다.
</Note>

## 정리

- 컴파일러는 본문을 `initial_suspend`와 `final_suspend` 사이에 끼우고, 값과 예외를 프라미스 객체의 함수로 보낸다
- 핸들은 프레임을 가리키는 8바이트 포인터다. 소유하지 않으므로 감싼 타입이 `destroy`를 책임진다
- `final_suspend`에서 멈추지 않으면 프레임이 스스로 사라진다. 결과를 꺼내는 타입은 멈추게 한다
