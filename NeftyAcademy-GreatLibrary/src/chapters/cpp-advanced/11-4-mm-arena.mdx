[`malloc`의 값](#/read/cpp-advanced/mm-new)은 "어떤 크기든, 어떤 순서로든 돌려받을 수 있다"는 일반성에서 나옵니다. 그 일반성이 필요 없으면 훨씬 단순한 할당기를 쓸 수 있습니다. 둘을 만듭니다. **한꺼번에 버리는** 아레나와, **같은 크기만** 다루는 풀입니다. [코루틴의 프레임](#/read/cpp-advanced/co-cost)에 달았던 풀을 제대로 만드는 자리이기도 합니다.

## 아레나: 앞에서부터 잘라 주고 통째로 버린다

```cpp
#include <cstddef>
#include <cstdint>
#include <initializer_list>
#include <new>
#include <print>
#include <string_view>
#include <type_traits>
#include <utility>
#include <vector>

// 앞에서부터 잘라 주는 아레나. 낱개로는 돌려받지 않는다
class Arena {
public:
    explicit Arena(std::size_t block_size = 4096) : block_size_(block_size) {}
    Arena(const Arena&) = delete;
    Arena& operator=(const Arena&) = delete;
    ~Arena()
    {
        for (const Block& block : blocks_)
            ::operator delete(block.begin);
    }

    void* allocate(std::size_t size, std::size_t align)
    {
        std::uintptr_t at = aligned(next_, align);
        if (at + size > reinterpret_cast<std::uintptr_t>(end_)) {
            next_block(size + align);
            at = aligned(next_, align);
        }
        next_ = reinterpret_cast<std::byte*>(at + size);
        return reinterpret_cast<void*>(at);
    }

    // 소멸자를 부르지 않으므로, 부를 필요가 없는 타입만 받는다
    template <typename T, typename... Args>
        requires std::is_trivially_destructible_v<T>
    T* make(Args&&... args)
    {
        void* place = allocate(sizeof(T), alignof(T));
        return ::new (place) T{std::forward<Args>(args)...};
    }

    // 글을 복사해 넣고 그것을 보는 뷰를 준다
    std::string_view copy(std::string_view text)
    {
        char* place = static_cast<char*>(allocate(text.size(), 1));
        text.copy(place, text.size());
        return {place, text.size()};
    }

    // 내준 것을 모두 잊는다. 블록은 그대로 두고 다시 쓴다
    void reset()
    {
        current_ = 0;
        next_ = blocks_.empty() ? nullptr : blocks_[0].begin;
        end_ = blocks_.empty() ? nullptr : blocks_[0].begin + blocks_[0].size;
    }

    std::size_t blocks() const { return blocks_.size(); }

private:
    struct Block {
        std::byte* begin;
        std::size_t size;
    };

    static std::uintptr_t aligned(std::byte* p, std::size_t align)
    {
        return (reinterpret_cast<std::uintptr_t>(p) + align - 1) & ~(align - 1);
    }

    void next_block(std::size_t at_least)
    {
        // 이미 가진 블록 가운데 다음 것이 충분하면 그것을 쓴다
        while (current_ + 1 < blocks_.size()) {
            ++current_;
            if (blocks_[current_].size >= at_least) {
                next_ = blocks_[current_].begin;
                end_ = next_ + blocks_[current_].size;
                return;
            }
        }
        const std::size_t size = at_least > block_size_ ? at_least : block_size_;
        next_ = static_cast<std::byte*>(::operator new(size));
        end_ = next_ + size;
        blocks_.push_back({next_, size});
        current_ = blocks_.size() - 1;
    }

    std::size_t block_size_;
    std::size_t current_ = 0;
    std::byte* next_ = nullptr;
    std::byte* end_ = nullptr;
    std::vector<Block> blocks_;
};

// 아레나에 지은 나무. 노드를 하나씩 지우지 않고 통째로 버린다
struct Node {
    std::string_view word;
    int count;
    Node* left;
    Node* right;
};

Node* insert(Arena& arena, Node* root, std::string_view word)
{
    if (root == nullptr)
        return arena.make<Node>(arena.copy(word), 1, nullptr, nullptr);
    if (word == root->word)
        ++root->count;
    else if (word < root->word)
        root->left = insert(arena, root->left, word);
    else
        root->right = insert(arena, root->right, word);
    return root;
}

void print(const Node* node)
{
    if (node == nullptr)
        return;
    print(node->left);
    std::print("{}={} ", node->word, node->count);
    print(node->right);
}

void count_words(Arena& arena, std::initializer_list<std::string_view> words)
{
    Node* root = nullptr;
    for (std::string_view word : words)
        root = insert(arena, root, word);
    print(root);
    std::println("/ 블록 {}개", arena.blocks());
}

int main()
{
    Arena arena;
    count_words(arena, {"temp", "humid", "temp", "press"});
    arena.reset();   // 다음 것은 같은 메모리에 다시 짓는다
    count_words(arena, {"wind", "wind", "rain"});
}
```

```text
humid=1 press=1 temp=2 / 블록 1개
rain=1 wind=2 / 블록 1개
```

할당은 포인터를 정렬에 맞춰 올리고 크기만큼 미는 것이 전부입니다. 돌려받는 함수는 **없습니다.** 노드와 글자들이 한 블록에 차례로 놓이고, `reset()` 한 번에 모두 사라집니다.

| 설계에서 정한 것 | 까닭 |
| --- | --- |
| `make`는 소멸자가 할 일이 없는 타입만 받는다 | 아레나는 소멸자를 부르지 않는다. `std::string` 멤버가 있으면 그 속의 힙이 샌다. 그래서 글도 아레나에 복사하고 `string_view`로 든다 |
| 블록이 모자라면 새 블록을 잡는다. 큰 요청은 그 크기의 블록을 따로 잡는다 | 처음에 정한 크기에 묶이지 않는다 |
| `reset()`은 블록을 돌려주지 않고 다시 쓴다 | 주기마다 되풀이할 때 둘째 바퀴부터는 `operator new`를 부르지 않는다 |

## 풀: 같은 크기를 낱개로

수명이 제각각이라 통째로 버릴 수 없으면 풀을 씁니다. 빈칸들을 **칸 자신 안에 적은 포인터**로 이어 둡니다.

```cpp
#include <cstddef>
#include <memory>
#include <new>
#include <print>
#include <string>
#include <utility>
#include <vector>

// 같은 타입의 객체를 낱개로 만들고 돌려받는 풀
template <typename T>
class Pool {
public:
    explicit Pool(std::size_t chunk_size = 256) : chunk_size_(chunk_size) {}
    Pool(const Pool&) = delete;
    Pool& operator=(const Pool&) = delete;

    template <typename... Args>
    T* create(Args&&... args)
    {
        if (free_ == nullptr)
            refill();
        Slot* slot = free_;
        free_ = slot->next;
        try {
            return ::new (slot) T{std::forward<Args>(args)...};
        } catch (...) {
            slot->next = free_;   // 생성자가 던지면 칸을 도로 넣는다
            free_ = slot;
            throw;
        }
    }
    void destroy(T* object) noexcept
    {
        object->~T();
        Slot* slot = reinterpret_cast<Slot*>(object);
        slot->next = free_;
        free_ = slot;
    }
    std::size_t chunks() const { return chunks_.size(); }

private:
    // 비어 있을 때는 다음 빈칸을 가리키고, 차 있을 때는 T가 산다
    union Slot {
        Slot* next;
        alignas(T) std::byte storage[sizeof(T)];
    };

    void refill()
    {
        chunks_.push_back(std::make_unique<Slot[]>(chunk_size_));
        Slot* chunk = chunks_.back().get();
        for (std::size_t i = chunk_size_; i-- > 0;) {
            chunk[i].next = free_;
            free_ = &chunk[i];
        }
    }

    std::size_t chunk_size_;
    Slot* free_ = nullptr;
    std::vector<std::unique_ptr<Slot[]>> chunks_;
};

struct Session {
    int id;
    std::string user;   // 소멸자가 있는 멤버도 괜찮다
};

int main()
{
    Pool<Session> sessions(4);
    Session* a = sessions.create(1, "kim");
    Session* b = sessions.create(2, "lee");
    const Session* where = a;
    sessions.destroy(a);
    Session* c = sessions.create(3, "park");
    std::println("없앤 칸을 다시 받았는가: {}", c == where);

    std::vector<Session*> many;
    for (int i = 0; i < 10; ++i)
        many.push_back(sessions.create(10 + i, "guest-with-a-rather-long-name"));
    std::println("12개가 살아 있다. 덩어리 {}개", sessions.chunks());

    for (Session* s : many)
        sessions.destroy(s);
    sessions.destroy(b);
    sessions.destroy(c);
}
```

```text
없앤 칸을 다시 받았는가: true
12개가 살아 있다. 덩어리 3개
```

`Slot`이 요령입니다. 칸이 비어 있을 때는 그 메모리에 "다음 빈칸"의 주소를 적고, 차 있을 때는 같은 자리에 `T`가 삽니다. 빈칸 목록을 위한 메모리가 따로 들지 않습니다. 만들기는 목록의 머리를 떼는 것, 없애기는 머리에 붙이는 것입니다. 아레나와 달리 소멸자를 부르므로 `std::string` 멤버가 있어도 됩니다.

## 잰 값

32바이트 노드입니다. x86-64, GCC 14, `-O2`이고 만들고 없애는 것을 합친 값입니다.

| 방식 | 한 주기에 1,000개를 만들고 버리기 | 100만 개를 만들어 두었다 버리기 |
| --- | --- | --- |
| `new`와 `delete` | 14.5 ns | 26 ns와 12 ns |
| 아레나와 `reset()` | 0.8 ns | 6 ns와 0 ns. 첫 바퀴는 16 ns |
| 풀 | 1.6 ns | 6 ns와 4 ns |
| `pmr`의 단조 자원과 `release()` | 1.4 ns | 8 ns |

왼쪽 열이 할당기 자체의 값입니다. 아레나는 `new`의 **18분의 1**입니다. 오른쪽 열에서는 차이가 줄어듭니다. 100만 개는 32 MB라서 캐시에 들어가지 않고, 새 메모리에 쓰는 값이 할당기의 값을 덮기 때문입니다. 첫 바퀴의 16 ns는 운영체제에서 메모리를 처음 받아 오는 값입니다. Clang 20에서는 아레나 2.2 ns, 풀 1.9 ns였습니다.

## 맞는 자리와 함정

| | 아레나 | 풀 |
| --- | --- | --- |
| 맞는 일 | 요청 하나, 프레임 하나, 파싱 한 번처럼 **함께 태어나 함께 사라지는** 것들 | 연결, 세션, 타이머처럼 **같은 타입이 들고 나는** 것들 |
| 낱개로 돌려받기 | 안 된다 | 된다 |
| 메모리가 줄어드는 때 | 아레나가 사라질 때 | 풀이 사라질 때. 한 번 늘어난 덩어리는 남는다 |

| 함정 | 생기는 일 | 대비 |
| --- | --- | --- |
| `reset()` 뒤에 옛 포인터를 쓴다 | 다른 객체가 들어앉은 메모리를 읽는다. 블록은 살아 있으므로 ASan도 그냥은 못 잡는다 | 포인터가 아레나보다 오래 살지 않게 한다. [선언 순서](#/read/cpp-advanced/res-ownership)가 안전장치다 |
| 풀에 같은 것을 두 번 돌려준다 | 빈칸 목록이 꼬여 같은 칸이 두 번 나간다 | 디버그 빌드에서 칸에 표시를 남겨 검사한다 |
| 여러 스레드가 함께 쓴다 | 둘 다 잠금이 없다 | 스레드마다 하나씩 둔다. 잠금 없는 빈칸 목록은 [ABA 문제](#/read/cpp-advanced/atm-aba)를 만난다 |

<Note>
직접 만들기 전에 [표준의 자원](#/read/cpp-stl/mem-allocator)으로 되는지 먼저 봅니다. 단조 자원이 아레나, 풀 자원이 풀에 해당하고, 컨테이너에 바로 꽂히며 잰 값도 비슷했습니다. 직접 만들 까닭은 타입이 붙은 인터페이스와 블록을 쥔 채 되감기 정도입니다. 낱개의 포인터 대신 [번호와 세대를 가진 핸들](#/read/cpp-advanced/res-ownership)을 내주면 첫째와 둘째 함정을 실행 중에 잡을 수 있습니다.
</Note>

## 정리

- 아레나는 포인터를 미는 것으로 할당하고 통째로 버린다. 주기마다 1,000개를 만드는 일에서 `new`의 18분의 1이었다
- 풀은 빈칸을 칸 자신에 적은 포인터로 잇는다. 같은 타입을 낱개로 만들고 돌려받는 데 1.6 ns였다
- 수명이 같은 것은 아레나에, 같은 타입이 들고 나면 풀에 둔다. 되감은 뒤의 포인터와 스레드는 직접 지킨다
