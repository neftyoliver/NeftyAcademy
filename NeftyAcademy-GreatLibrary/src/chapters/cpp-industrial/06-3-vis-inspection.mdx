[「OpenCV」](#/read/cpp-industrial/vis-opencv)에서 부품 하나를 재 보았습니다. 실제 검사 장비는 이것을 매일 수만 번, 위치와 각도가 조금씩 다른 부품마다 같은 정밀도로 해야 하고, 결과는 "치수가 몇 mm"가 아니라 "합격인가 불합격인가"여야 합니다. 그래서 검사는 대개 같은 단계를 거칩니다.

1. **찍기**: 트리거에 맞춰 이미지를 받는다
2. **찾기**: 부품이 어디에 어떤 각도로 놓였는지 찾는다
3. **재기**: 찾은 위치와 각도를 기준으로 검사 영역을 옮겨 놓고 잰다
4. **환산과 판정**: 화소를 mm로 바꾸고 공차와 비교한다
5. **알리기**: 합격·불합격을 PLC에 알리고, 불합격 이미지와 일부 합격 이미지를 남긴다

## 생산품 20개 검사

지름 5.0 ± 0.1mm 구멍을 검사합니다. 생산품은 위치와 각도가 제각각이고, 공정의 흩어짐 때문에 몇 개는 공차를 벗어납니다. 먼저 지름을 정확히 아는 기준 부품으로 측정의 치우침을 구한 뒤 판정했습니다.

```cpp pkg=opencv4
// 검사 파이프라인: 부품 찾기 → 부품 기준으로 재기 → mm로 환산 → 공차 판정
#include <opencv2/imgproc.hpp>
#include <cmath>
#include <cstdio>
#include <vector>

// 보정판으로 미리 구한 값: 1화소 = 0.1mm
constexpr double kMmPerPx = 0.1;
constexpr double kNominal = 5.0, kTol = 0.1;     // 구멍 지름 5.0 ± 0.1mm

cv::Mat makePart(cv::RNG& rng, double holeMm, double angle, cv::Point2f center) {
    cv::Mat img(480, 640, CV_8UC1, cv::Scalar(30));
    cv::Point2f c[4];
    cv::RotatedRect({center, {300, 180}, float(angle)}).points(c);
    std::vector<cv::Point> poly(c, c + 4);
    cv::fillConvexPoly(img, poly, cv::Scalar(200));
    // 1/16화소 단위로 그린다(shift = 4)
    const int s = 16;
    const int radius = int(std::lround(holeMm / kMmPerPx / 2 * s));
    cv::circle(img, cv::Point(int(center.x * s), int(center.y * s)), radius,
               cv::Scalar(30), cv::FILLED, cv::LINE_8, 4);
    cv::Mat noise(img.size(), CV_8SC1);
    rng.fill(noise, cv::RNG::NORMAL, 0, 12);
    cv::add(img, noise, img, cv::noArray(), CV_8UC1);
    return img;
}

double measureHole(const cv::Mat& img) {         // 구멍 지름(mm), 못 찾으면 -1
    cv::Mat blur, bin;
    cv::GaussianBlur(img, blur, {5, 5}, 0);
    cv::threshold(blur, bin, 0, 255, cv::THRESH_BINARY | cv::THRESH_OTSU);
    std::vector<std::vector<cv::Point>> contours;
    std::vector<cv::Vec4i> h;
    cv::findContours(bin, contours, h, cv::RETR_CCOMP, cv::CHAIN_APPROX_NONE);
    for (size_t i = 0; i < contours.size(); ++i)
        if (h[i][3] >= 0 && cv::contourArea(contours[i]) > 100)   // 판 안의 구멍
            return std::sqrt(4 * cv::contourArea(contours[i]) / CV_PI) * kMmPerPx;
    return -1;
}

int main() {
    cv::RNG rng(2026);
    // 1) 지름을 아는 기준 부품(5.000mm)으로 측정의 치우침을 구한다
    const cv::Mat golden = makePart(rng, kNominal, 0, {320, 240});
    const double bias = measureHole(golden) - kNominal;
    std::printf("기준 부품 측정 치우침 %+.3fmm\n", bias);

    // 2) 생산품 20개: 위치와 각도가 제각각이고, 몇 개는 구멍이 공차를 벗어난다
    int truth[2][2] = {}, rawWrong = 0;          // [실제 불량][판정 불량]
    for (int n = 0; n < 20; ++n) {
        const double hole = kNominal + rng.gaussian(0.07);     // 공정의 흩어짐
        const double angle = rng.uniform(-30.0, 30.0);
        const cv::Point2f at(rng.uniform(280.f, 360.f), rng.uniform(200.f, 280.f));
        const double raw = measureHole(makePart(rng, hole, angle, at));
        const double mm = raw - bias;            // 보정한 값으로 판정한다
        const bool bad = std::fabs(hole - kNominal) > kTol;
        const bool judgedBad = raw < 0 || std::fabs(mm - kNominal) > kTol;
        rawWrong += (std::fabs(raw - kNominal) > kTol) != bad;
        ++truth[bad][judgedBad];
    }
    std::printf("보정 후: 양품→양품 %d, 양품→불량 %d, 불량→불량 %d, 불량→양품 %d\n",
                truth[0][0], truth[0][1], truth[1][1], truth[1][0]);
    std::printf("보정 없이 판정했다면 틀린 판정 %d개\n", rawWrong);
}
```

```text
기준 부품 측정 치우침 +0.188mm
보정 후: 양품→양품 14, 양품→불량 3, 불량→불량 3, 불량→양품 0
보정 없이 판정했다면 틀린 판정 16개
```

- **부품 기준으로**: 부품이 어디에 어떤 각도로 있든, 판의 윤곽 안에 든 구멍을 찾아 재므로 결과가 같습니다. 화면의 고정된 자리를 재는 검사는 부품이 조금만 밀려도 엉뚱한 곳을 잽니다
- **환산과 보정**: 화소 크기(0.1mm)는 눈금이 정확한 보정판을 찍어 미리 구하고, 처리 과정이 만드는 치우침(+0.188mm)은 기준 부품으로 구해 뺐습니다. 보정 없이 판정했다면 치우침이 공차의 두 배 가까이 되어 20개 중 16개를 잘못 판정했습니다
- **두 가지 틀림**: 양품을 불량으로 버리는 것(잘못 버림)과 불량을 양품으로 보내는 것(놓침)은 비용이 다릅니다. 보정 후에도 공차 경계 바로 안쪽의 양품 3개가 측정 잡음 때문에 불량으로 판정되었고, 놓친 불량은 없었습니다. 놓침이 더 비싼 검사라면 일부러 공차보다 조금 좁게 판정(가드 밴드)해 잘못 버림을 감수합니다

<Note>
검사 장비를 들여놓기 전에는 측정 시스템 분석(MSA)으로 같은 부품을 여러 번, 여러 사람이 재었을 때 결과가 얼마나 흩어지는지 봅니다. 흩어짐이 공차에 비해 크면 판정을 믿을 수 없습니다. 생산 중에는 찍기, 처리, 알리기를 다른 스레드에서 줄지어 돌려 처리량을 높이되, 결과는 프레임 번호 순서대로 PLC에 보내야 엉뚱한 부품이 버려지지 않습니다([「조명과 트리거」](#/read/cpp-industrial/vis-trigger)).
</Note>

## 정리

- 검사는 찍기, 찾기, 부품 기준으로 재기, 환산과 판정, 알리기의 단계를 거치며, 부품의 위치와 각도를 먼저 찾아야 결과가 흔들리지 않는다
- 화소 크기는 보정판으로, 처리 과정의 치우침은 기준 부품으로 구해 보정하며, 보정이 없으면 판정이 크게 틀린다
- 잘못 버림과 놓침은 비용이 달라 가드 밴드로 균형을 잡고, 측정의 흩어짐이 공차에 비해 작은지 미리 확인한다
