**OpenCV**는 가장 널리 쓰이는 오픈 소스 컴퓨터 비전 라이브러리이고(Apache 2.0), C++로 쓰여 있습니다. 필터, 이진화, 윤곽, 기하 변환, 카메라 보정, 특징점, 딥러닝 추론까지 머신 비전의 기본 도구가 거의 다 들어 있습니다. 상용 비전 라이브러리를 쓰는 현장에서도 시험과 보조 처리에는 OpenCV를 함께 쓰는 경우가 많습니다.

## 부품 하나 재기

부품 사진 대신, 10도 기운 판에 구멍 두 개가 뚫린 이미지를 직접 그리고 잡음을 더했습니다. 그 이미지에서 판의 위치와 각도, 구멍의 위치와 지름을 재는 것이 전형적인 비전 검사의 뼈대입니다.

```cpp pkg=opencv4
// OpenCV 기본: 합성한 부품 이미지에서 윤곽을 찾아 위치, 각도, 구멍 크기를 잰다
#include <opencv2/imgproc.hpp>
#include <cmath>
#include <cstdio>
#include <vector>

int main() {
    // 640x480 흑백 이미지: 10도 기운 판(밝음), 구멍 둘(어두움), 그리고 잡음
    cv::Mat img(480, 640, CV_8UC1, cv::Scalar(30));
    cv::RotatedRect plate({320, 240}, {300, 180}, 10);
    cv::Point2f c[4];
    plate.points(c);
    std::vector<cv::Point> poly(c, c + 4);
    cv::fillConvexPoly(img, poly, cv::Scalar(200));
    cv::circle(img, {250, 228}, 20, cv::Scalar(30), cv::FILLED);
    cv::circle(img, {390, 252}, 26, cv::Scalar(30), cv::FILLED);
    cv::Mat noise(img.size(), CV_8SC1);
    cv::RNG rng(7);
    rng.fill(noise, cv::RNG::NORMAL, 0, 12);
    cv::add(img, noise, img, cv::noArray(), CV_8UC1);

    // 다듬기 → 이진화(문턱값은 오츠 방법이 알아서) → 윤곽
    cv::Mat blur, bin;
    cv::GaussianBlur(img, blur, {5, 5}, 0);
    const double th =
        cv::threshold(blur, bin, 0, 255, cv::THRESH_BINARY | cv::THRESH_OTSU);
    std::vector<std::vector<cv::Point>> contours;
    // 바깥 윤곽과 그 안의 구멍을 구분한다
    std::vector<cv::Vec4i> hierarchy;
    cv::findContours(bin, contours, hierarchy, cv::RETR_CCOMP,
                     cv::CHAIN_APPROX_SIMPLE);
    std::printf("오츠 문턱값 %.0f, 윤곽 %zu개\n", th, contours.size());

    for (size_t i = 0; i < contours.size(); ++i) {
        const double area = cv::contourArea(contours[i]);
        if (area < 100) continue;                // 잡음 조각은 버린다
        const cv::Moments m = cv::moments(contours[i]);
        const cv::Point2f center(m.m10 / m.m00, m.m01 / m.m00);
        if (hierarchy[i][3] < 0) {               // 부모가 없으면 판의 바깥 윤곽
            const cv::RotatedRect r = cv::minAreaRect(contours[i]);
            std::printf("판: 중심 (%.1f, %.1f), 크기 %.0fx%.0f, 각도 %.1f도\n",
                        center.x, center.y, std::max(r.size.width, r.size.height),
                        std::min(r.size.width, r.size.height), r.angle);
        } else {                                 // 부모가 있으면 구멍
            std::printf("구멍: 중심 (%.1f, %.1f), 지름 %.1f\n", center.x, center.y,
                        std::sqrt(4 * area / CV_PI));
        }
    }

    // 관심 영역: 복사가 아니라 같은 메모리
    cv::Mat roi = img(cv::Rect(0, 0, 100, 100));
    roi.setTo(255);
    std::printf("ROI에 쓴 뒤 원본 (0,0) = %d, 같은 데이터: %s\n",
                img.at<uchar>(0, 0), roi.data == img.data ? "예" : "아니요");
}
```

```text
오츠 문턱값 113, 윤곽 3개
판: 중심 (320.0, 240.0), 크기 301x182, 각도 10.0도
구멍: 중심 (390.0, 252.0), 지름 52.8
구멍: 중심 (250.0, 228.0), 지름 40.8
ROI에 쓴 뒤 원본 (0,0) = 255, 같은 데이터: 예
```

- **다듬고 나서 이진화**: 잡음이 있는 이미지를 그대로 이진화하면 경계가 지저분하고 작은 조각이 생깁니다. 가우시안 흐림으로 먼저 다듬었습니다. 문턱값은 손으로 정하지 않고 **오츠 방법**이 밝기 분포에서 두 무리를 가장 잘 나누는 값(113)을 골랐습니다. 조명이 조금 바뀌어도 따라가므로 고정 문턱값보다 튼튼합니다
- **윤곽과 계층**: `RETR_CCOMP`는 윤곽을 바깥 경계와 그 안의 구멍 두 층으로 정리해 줍니다. 부모가 없는 윤곽이 판이고, 부모가 있는 윤곽이 구멍입니다. 넓이가 아주 작은 윤곽은 잡음으로 보고 버립니다
- **모멘트로 재기**: 윤곽의 모멘트에서 무게 중심을, 넓이에서 같은 넓이의 원의 지름을 얻었습니다. 그린 값(중심, 반지름 20과 26)에 비해 지름이 조금 큰 것은 흐림과 이진화가 경계를 한두 화소 옮겼기 때문입니다. 실제 검사에서는 이런 치우침을 아는 크기의 기준 부품으로 보정합니다
- **최소 넓이 사각형**: `minAreaRect`는 윤곽을 감싸는 가장 작은 회전 사각형을 주므로 판의 각도 10도를 그대로 얻습니다. 로봇이 부품을 집으러 갈 때 필요한 값이 바로 이 중심과 각도입니다

## cv::Mat과 메모리

`cv::Mat`은 머리(크기, 형식, 보폭)와 화소 데이터로 되어 있고, 데이터는 참조 횟수로 나눠 씁니다. 복사 생성이나 대입은 머리만 복사하고 같은 화소를 가리킵니다. 위에서 왼쪽 위 100×100 영역(ROI)을 꺼내 255로 칠하자 원본도 바뀌었습니다. ROI는 큰 이미지의 일부만 처리할 때 복사 없이 쓸 수 있어 편리하지만, 독립된 사본이 필요하면 `clone()`을 불러야 합니다. 이미지를 다른 스레드에 넘길 때 이 차이를 잊으면 같은 화소를 두 스레드가 동시에 고치게 됩니다.

<Note>
검사 장비에서는 같은 처리를 매 프레임 되풀이하므로, 결과를 담을 `cv::Mat`을 루프 밖에서 한 번 만들어 두고 다시 씁니다. 크기와 형식이 같으면 OpenCV 함수들은 새로 할당하지 않고 그 메모리에 씁니다. 이것이 [「메모리 잠금과 할당 금지」](#/read/cpp-industrial/rt-memory)의 원칙을 비전 처리에 적용하는 방법입니다.
</Note>

## 정리

- OpenCV는 C++로 된 컴퓨터 비전 라이브러리로, 이미지는 머리와 참조 횟수로 공유되는 화소 데이터로 된 cv::Mat이다
- 다듬은 뒤 오츠 방법으로 이진화하고, 윤곽의 계층으로 바깥 경계와 구멍을 나누며, 작은 윤곽은 잡음으로 버린다
- 모멘트에서 중심을, 넓이에서 지름을, 최소 넓이 사각형에서 각도를 얻고, 처리에 따른 치우침은 기준 부품으로 보정한다
