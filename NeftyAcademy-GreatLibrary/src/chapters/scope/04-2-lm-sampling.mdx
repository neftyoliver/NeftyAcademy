디지털 오실로스코프는 신호를 일정한 간격으로 찍은 점으로 기록하고, 점 사이를 이어 그립니다. 1초에 몇 번 찍는지가 샘플링 속도입니다. 1GS/s는 1초에 10억 번입니다. 찍는 간격보다 빨리 변하는 것은 점 사이에 빠져 보이지 않고, 때로는 있지도 않은 느린 파형으로 나타납니다.

## 드물게 찍으면 생기는 가짜 파형

<Figure caption="900kHz 사인파(CH1)를 1초에 1000만 번 찍은 것(CH2)과 100만 번 찍은 것(CH3). 아랫줄은 100kHz로 보인다">
  <Scope tdiv={2e-6} dt={5e-8} traces={[{ name: '신호', data: fast, vdiv: 1, pos: 2.5 }, { name: '10MS/s', data: at10M, vdiv: 1, pos: 0 }, { name: '1MS/s', data: at1M, vdiv: 1, pos: -2.5 }]} />
</Figure>

```python
def seen(f_signal, f_sample):
    """f_sample 로 찍은 점들이 그리는 주파수"""
    folded = f_signal % f_sample
    return min(folded, f_sample - folded)

for fs in (10e6, 2e6, 1e6):
    print(f"900kHz를 {fs / 1e6:.0f}MS/s로: 한 주기에 {fs / 900e3:.1f}점, "
          f"화면에는 {seen(900e3, fs) / 1e3:.0f}kHz")
```

```text
900kHz를 10MS/s로: 한 주기에 11.1점, 화면에는 900kHz
900kHz를 2MS/s로: 한 주기에 2.2점, 화면에는 900kHz
900kHz를 1MS/s로: 한 주기에 1.1점, 화면에는 100kHz
```

- **한 주기에 두 점은 넘어야 한다**: 신호 주파수의 두 배보다 느리게 찍으면 점들이 다른 주파수의 파형을 그립니다. 이것을 에일리어싱이라고 합니다
- **두 점으로는 모양을 모른다**: 2.2점이면 주파수는 맞지만 높이와 모양은 믿을 수 없습니다. 가운데 줄처럼 한 주기에 열 점쯤은 있어야 사인파로 보입니다
- **가짜는 멀쩡하게 생겼다**: 아랫줄은 깨끗한 100kHz 사인파입니다. 화면만 봐서는 가짜인 줄 알 수 없습니다. 자동 측정도 자신 있게 100kHz라고 읽습니다
- **대역폭과 짝을 이룬다**: 장비의 가장 빠른 샘플링 속도는 대역폭의 2.5배는 넘어야 한다는 지침이 있습니다. 100MHz 장비가 1GS/s인 것은 그래서입니다

## 가로를 넓히면 느리게 찍는다

사양서의 샘플링 속도는 가장 빠를 때의 값입니다. 한 번에 담을 수 있는 점의 수(기록 길이)가 정해져 있으므로, 화면에 긴 시간을 담으면 찍는 간격이 벌어집니다.

```python
max_rate, memory = 1e9, 10_000      # 가장 빠르게 1GS/s, 한 번에 1만 점
for t_div in (1e-6, 1e-4, 1e-2, 1.0):
    screen = 10 * t_div             # 화면 전체의 시간
    rate = min(max_rate, memory / screen)
    print(f"{t_div * 1e3:8.3f}ms/칸: {rate / 1e3:10.0f}kS/s, "
          f"가짜 없이 보이는 한계 {rate / 2 / 1e3:9.1f}kHz")
```

```text
   0.001ms/칸:    1000000kS/s, 가짜 없이 보이는 한계  500000.0kHz
   0.100ms/칸:      10000kS/s, 가짜 없이 보이는 한계    5000.0kHz
  10.000ms/칸:        100kS/s, 가짜 없이 보이는 한계      50.0kHz
1000.000ms/칸:          1kS/s, 가짜 없이 보이는 한계       0.5kHz
```

- **10ms/칸에서는 100kS/s다**: 이 장비로 10ms/칸에 놓고 1MHz 신호를 보면 가짜 파형이 나옵니다. 1GS/s 장비라는 것은 소용이 없습니다
- **지금의 샘플링 속도는 화면에 적혀 있다**: 가로 설정 옆에 지금 몇 S/s로 찍고 있는지 나옵니다. 가로를 돌릴 때 이 숫자를 함께 봅니다
- **기록 길이가 길면 덜 떨어진다**: 한 번에 1000만 점을 담는 장비는 같은 10ms/칸에서 100MS/s를 지킵니다([「기록 길이와 확대」](#/read/scope/lm-memory))

## 알아채는 법

- **가로를 돌려 본다**: 시간/칸을 한 단 바꿨을 때 진짜 신호는 주기가 그대로이고 화면의 주기 수만 달라집니다. 가짜는 주파수가 엉뚱하게 바뀌거나 모양이 무너집니다
- **트리거가 안 잡힌다**: 가짜 파형은 화면에서 천천히 흐르는 일이 많습니다. 트리거는 진짜 신호에 걸리는데 그려지는 점은 다른 박자이기 때문입니다
- **있을 수 없는 주파수**: 회로에 12MHz 수정이 있는데 화면에 37kHz 사인파가 나오면 의심합니다. 회로도에서 나올 수 있는 주파수를 먼저 떠올립니다
- **빠르게 당겨서 확인한다**: 가로를 당겨 한 주기가 화면에 몇 칸이 되게 놓고 주파수를 다시 읽습니다. 처음 읽은 값과 다르면 처음 것이 가짜입니다
- **봉우리 검출 모드**: 느리게 찍는 동안에도 점 사이의 최대와 최소를 기록해 주는 모드가 있는 장비가 많습니다. 좁은 펄스를 놓치지 않으려 할 때 켭니다

<Note>
그림은 수식으로 만든 900kHz 사인파를 정한 간격으로 뽑아 점 사이를 곧은 선으로 이은 것입니다. 진짜 장비는 점 사이를 부드러운 곡선으로 메우는 방식을 쓰는 일이 많아서, 한 주기에 두세 점뿐이어도 사인파처럼 그려 줍니다. 둘째 표의 장비(1GS/s, 1만 점)는 셈하려고 정한 것입니다. 가로 설정에 따라 샘플링 속도가 어떻게 바뀌는지는 장비의 화면에서 직접 확인합니다.
</Note>

## 정리

- 오실로스코프는 점을 찍어 잇는다. 신호 주파수의 두 배보다 느리게 찍으면 있지도 않은 느린 파형이 그려진다
- 가로를 넓히면 기록 길이의 한계 때문에 샘플링 속도가 떨어진다. 지금의 속도는 화면에 적혀 있다
- 의심스러우면 가로를 돌려 본다. 진짜 신호는 주기가 달라지지 않는다
