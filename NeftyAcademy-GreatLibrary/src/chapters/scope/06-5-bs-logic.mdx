앞의 세 쪽에서 화면의 높낮이를 눈으로 따라가며 바이트를 읽었습니다. 두세 바이트는 그렇게 읽을 수 있지만, 센서를 초기화하는 수십 바이트를 그렇게 읽을 수는 없습니다. 그 일을 맡는 장비가 로직 분석기입니다. 다만 이 장비는 오실로스코프가 보여 주던 것 가운데 여러 가지를 보여 주지 않습니다.

## 무엇이 다른가

| | 오실로스코프 | 로직 분석기 |
| --- | --- | --- |
| 적는 것 | 전압의 모양 | 문턱으로 가른 0과 1 |
| 채널 | 둘에서 넷 | 여덟이나 열여섯, 그 이상 |
| 한 번에 담는 길이 | 화면 몇 장 | 표본 하나가 한 비트라 훨씬 길다 |
| 잘하는 일 | 높이, 변, 울림, 잡음 보기 | 긴 대화를 값으로 풀어 읽기 |

- **입력마다 비교기가 하나 있다**: 로직 분석기는 선의 전압을 문턱과 견주어 위면 1, 아래면 0으로 적습니다. 전압이 얼마였는지는 버립니다
- **풀어 읽는 것은 프로그램이 한다**: 어느 채널이 SCL이고 SDA인지 알려 주면, 시작 조건과 주소와 ACK를 찾아 파형 아래에 값으로 적어 줍니다. UART와 SPI도 같습니다
- **선을 많이 본다**: SPI의 네 선에 인터럽트 선과 리셋 선까지 함께 물려, 무엇이 먼저였는지를 한 화면에서 봅니다

## 문턱이 지우는 것

<Figure caption="같은 선을 세 가지로 본 것. CH1은 오실로스코프가 본 전압이고, D0과 D1은 값이 바뀌는 문턱이 1.2V인 분석기와 1.8V인 분석기가 적은 것이다. 가로 커서는 그 두 문턱">

- **다 오르지 못한 펄스는 있기도 하고 없기도 하다**: 가운데의 1.49V짜리 펄스가 D0에는 좁은 펄스로 적히고 D1에는 아예 없습니다. 어느 쪽 화면에도 그것이 반쪽짜리였다는 표시는 없습니다
- **맞붙은 출력이 멀쩡해 보인다**: 오른쪽 펄스의 가운데는 두 출력이 맞붙어 1.65V에 머문 곳입니다. D0은 이것을 긴 HIGH 하나로, D1은 펄스 둘로 적습니다. 둘 다 깨끗한 네모입니다([「논리 레벨과 문턱」](#/read/scope/bs-levels))
- **느린 변은 자리가 옮겨진다**: 왼쪽 펄스가 D0에는 10.55µs, D1에는 9.85µs 폭으로 적힙니다. 변이 누워 있으면 문턱의 자리에 따라 변의 시각이 달라집니다
- **울림과 잡음은 문턱을 넘을 때에만 보인다**: 넘지 않으면 없는 것으로, 넘으면 까닭 모를 좁은 펄스로 적힙니다
- **깨끗한 화면이 깨끗한 선은 아니다**: 분석기의 화면은 늘 반듯합니다. 선이 반듯한지는 오실로스코프로 봐야 압니다

## 표본 속도

<Figure caption="HIGH가 0.3µs인 1MHz 클럭 여덟 개. D0은 4MS/s로, D1은 2.5MS/s로 표본을 뽑은 분석기가 적은 것이다">
  <Scope tdiv={1e-6} dt={1e-8} traces={[{ name: 'CH1 클럭', data: laClock, vdiv: 2, pos: 1.8 }, { name: 'D0 4MS/s', data: laFast, vdiv: 1, pos: -0.8, logic: true }, { name: 'D1 2.5MS/s', data: laSlow, vdiv: 1, pos: -3, logic: true }]} />
</Figure>

```python
def pulses_seen(rate, phase, f=1e6, high=0.3, count=8):
    n, prev, t = 0, 0, phase             # 표본을 하나씩 뽑으며 오르는 변을 센다
    while t < (count + 1) / f:
        k = t * f                        # 몇째 주기의 어디쯤인가
        v = 1 if k < count and k % 1 < high else 0
        n += 1 if v and not prev else 0
        prev, t = v, t + 1 / rate
    return n

for rate in (24e6, 4e6, 2.5e6, 2e6):
    seen = [pulses_seen(rate, p / 50 / rate) for p in range(50)]
    print(f"{rate / 1e6:4.1f}MS/s: 펄스 8개가 {min(seen)}~{max(seen)}개로 보인다. "
          f"변의 자리는 {1e9 / rate:.0f}ns까지 어긋난다")
```

```text
24.0MS/s: 펄스 8개가 8~8개로 보인다. 변의 자리는 42ns까지 어긋난다
 4.0MS/s: 펄스 8개가 8~8개로 보인다. 변의 자리는 250ns까지 어긋난다
 2.5MS/s: 펄스 8개가 4~8개로 보인다. 변의 자리는 400ns까지 어긋난다
 2.0MS/s: 펄스 8개가 0~8개로 보인다. 변의 자리는 500ns까지 어긋난다
```

- **표본과 표본 사이는 모른다**: 2.5MS/s의 분석기는 0.4µs마다 한 번 봅니다. 0.3µs짜리 HIGH가 그 사이에 통째로 들어가면 없던 일이 됩니다. 그림의 D1에는 여덟 개 가운데 넷만 남았습니다
- **네 배를 넘게 잡는다**: 디지털 신호는 그 신호보다 네 배 넘게 빠른 속도로 뽑으라는 지침이 있습니다. 100kHz의 I2C에는 1MS/s 넘게, 1MHz의 SPI에는 4MS/s 넘게입니다
- **느리게 오르는 선에는 더 빠르게**: 풀업이 올리는 선은 문턱 위에 머무는 시간이 반 주기보다 짧습니다. 예제가 HIGH를 주기의 30%로 둔 까닭입니다
- **변의 자리는 표본 간격만큼 흐리다**: 두 선의 변 가운데 어느 쪽이 먼저였는지를 가리려면, 표본 간격이 그 차이보다 작아야 합니다
- **넉넉하면 가장 빠르게 둔다**: 속도를 높이면 같은 시간에 표본이 더 쌓일 뿐입니다. 담을 수 있는 길이가 모자랄 때에만 낮춥니다

## 싼 USB 분석기와 sigrok

- **여덟 채널, 가장 빠르게 24MS/s**: 가장 흔한 싼 분석기의 사양입니다. 네 배의 지침대로면 6MHz쯤의 클럭까지 봅니다
- **문턱이 고정이다**: 0.8V 아래를 LOW로, 2.0V 위를 HIGH로 적습니다. 3.3V와 5V의 논리에는 맞지만, 1.8V로 도는 선은 HIGH가 문턱에 닿지 않습니다
- **5.25V를 넘기면 안 된다**: 입력이 견디는 전압이 그만큼입니다. RS-232 선이나 12V의 신호를 그대로 물리면 분석기가 상할 수 있습니다([「UART 프레임 읽기」](#/read/scope/bs-uart))
- **GND부터 잇는다**: 분석기의 GND 선을 보드의 GND에 잇습니다. 분석기도 USB를 거쳐 PC의 접지에 이어지므로, 접지의 주의는 오실로스코프와 같습니다([「접지 집게가 닿는 곳」](#/read/scope/pb-ground))
- **sigrok과 PulseView**: sigrok은 이런 장비를 다루는 공개 소프트웨어이고 PulseView가 그 화면입니다. 장치를 고르고, 표본 속도와 개수를 정해 받은 뒤, UART나 I2C나 SPI의 해독기를 채널에 붙이면 파형 아래에 값이 적힙니다
- **둘을 합친 장비도 있다**: 오실로스코프에 디지털 채널을 더한 것을 MSO라고 부릅니다. 한 선의 모양과 여러 선의 값을 같은 시간축에서 봅니다

## 둘을 쓰는 순서

- **모양을 먼저 본다**: 새로 이은 선은 오실로스코프로 높이와 변과 울림부터 봅니다. 문턱 사이에 머무는 곳이 없어야 분석기가 적은 0과 1을 믿을 수 있습니다
- **내용은 분석기로 읽는다**: 모양이 멀쩡하면 분석기로 길게 받아, 주소와 레지스터와 순서가 데이터시트와 같은지 봅니다([「로직 분석기로 보기」](#/read/i2c-dev/tr-analyzer))
- **가끔 한 비트가 틀리면 되돌아간다**: 분석기에 까닭 모를 좁은 펄스가 보이거나 해독이 가끔 깨지면, 그 선을 다시 오실로스코프로 봅니다
- **둘 다 없을 때**: 프로그램이 받은 값을 그대로 찍어 보는 것이 첫걸음입니다. 파형을 읽는 연습은 장비 없이도 할 수 있습니다([「시뮬레이터의 파형을 오실로스코프처럼 읽기」](#/read/scope/pr-sim))

<Note>
첫 그림의 전압은 [「논리 레벨과 문턱」](#/read/scope/bs-levels)의 두 그림을 이어 붙인 것이고, D0과 D1은 그 전압을 1.2V와 1.8V에서 가른 계산입니다. 진짜 분석기의 값이 0.8V와 2.0V 사이의 어디에서 바뀌는지는 장비마다 다르고, 두 문턱은 견주어 보려고 고른 값입니다. 둘째 그림과 예제도 계산이며 표본을 뽑는 때가 조금도 흔들리지 않는다고 놓았습니다. 장비를 찍은 화면이 아닙니다. 싼 분석기의 사양은 참고 문서의 sigrok과 SparkFun의 글에서 옮겼고, 제품마다 다를 수 있습니다.
</Note>

## 정리

- 로직 분석기는 문턱으로 가른 0과 1을 여러 선에서 길게 적고, 프로그램이 그것을 주소와 값으로 풀어 준다
- 문턱 사이의 전압, 느린 변, 울림은 분석기의 화면에서 사라진다. 반듯한 화면이 반듯한 선을 뜻하지는 않는다
- 표본 속도는 신호의 네 배를 넘게 잡는다. 모양은 오실로스코프로 먼저 보고, 내용은 분석기로 읽는다
