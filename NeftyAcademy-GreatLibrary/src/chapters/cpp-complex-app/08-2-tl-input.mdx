펜은 마우스보다 많은 것을 알려 줍니다. 자리 말고도 누르는 압력, 기울기, 돌린 각도가 오고, 화면을 한 번 그리는 사이에 여러 번 옵니다. 붓 도구는 이 표본들을 받아 획 하나를 만듭니다. 획을 그린다는 것은 붓 모양을 길을 따라 되풀이해 찍는 일입니다. 예제는 들쭉날쭉하게 들어온 표본 14개로 획을 만듭니다.

```cpp
// 펜 획: 들쭉날쭉한 표본을 고른 간격의 점으로 바꾸고, 압력으로 굵기를 정한다
#include <algorithm>
#include <cmath>
#include <print>
#include <string>
#include <vector>

struct Sample { double x, y, pressure; };    // 펜이 알려 온 자리와 압력(0~1)
using Stroke = std::vector<Sample>;

const Stroke kInput{                         // 천천히, 빠르게, 다시 천천히 그었다
    {2, 7, 0.10}, {3, 7, 0.15}, {4, 6.8, 0.2}, {6, 6.2, 0.3}, {9, 5, 0.45},
    {15, 3, 0.7}, {24, 2, 0.95}, {36, 3.5, 1.0}, {45, 6, 0.8}, {51, 7.5, 0.55},
    {54, 8, 0.4}, {56, 8.2, 0.3}, {57, 8.2, 0.2}, {58, 8.2, 0.1}};

double radius(double pressure, double gamma = 1) {   // 압력 곡선
    return 0.4 + 2.6 * std::pow(pressure, gamma);
}
double gap(const Sample& a, const Sample& b) {
    return std::hypot(b.x - a.x, b.y - a.y);
}
double narrowest(const Stroke& dabs) {       // 이웃한 두 점 사이의 가장 좁은 간격
    double least = 1e9;
    for (std::size_t i = 1; i < dabs.size(); ++i)
        least = std::min(least, gap(dabs[i - 1], dabs[i]));
    return least;
}

Stroke spaced(const Stroke& in, double spacing, bool carry = true) {
    Stroke out{in.front()};
    double left = spacing;                   // 다음 점까지 남은 거리
    for (std::size_t i = 1; i < in.size(); ++i) {
        const Sample &a = in[i - 1], &b = in[i];
        double length = gap(a, b), at = 0;
        if (!carry && i > 1) left = 0;       // 잘못된 판: 구간마다 새로 센다
        for (; at + left <= length; left = spacing) {
            double t = (at += left) / length;    // 자리와 압력을 함께 보간한다
            out.push_back({std::lerp(a.x, b.x, t), std::lerp(a.y, b.y, t),
                           std::lerp(a.pressure, b.pressure, t)});
        }
        left -= length - at;                 // 남은 거리는 다음 구간으로 넘긴다
    }
    return out;
}

void paint(const char* title, const Stroke& dabs) {
    std::vector<std::string> grid(11, std::string(62, ' '));
    for (const Sample& dab : dabs)
        for (int y = 0; y < 11; ++y)
            for (int x = 0; x < 62; ++x) {   // 글자 칸은 세로가 가로의 두 배
                double d = std::hypot(x - dab.x, 2 * (y - dab.y));
                if (d <= radius(dab.pressure)) grid[y][x] = '#';
            }
    std::println("{}: 점 {}개, 가장 좁은 간격 {:.2f}칸", title, dabs.size(),
                 narrowest(dabs));
    for (std::string& row : grid) {
        row.erase(row.find_last_not_of(' ') + 1);
        if (!row.empty()) std::println("{}", row);
    }
}

int main() {
    paint("표본마다 점 하나", kInput);
    paint("1.5칸마다 점 하나", spaced(kInput, 1.5));
    Stroke wrong = spaced(kInput, 1.5, false);
    std::println("구간마다 새로 세면 점 {}개, 가장 좁은 간격 {:.2f}칸",
                 wrong.size(), narrowest(wrong));

    Stroke every3;                           // 프레임마다 마지막 표본만 받았다면
    for (std::size_t i = 0; i < kInput.size(); i += 3)
        every3.push_back(kInput[i]);
    every3.push_back(kInput.back());
    Stroke line = spaced(every3, 0.05);
    double worst = 0;
    for (const Sample& s : kInput) {         // 버린 표본과 새 꺾은선 사이의 거리
        double best = 1e9;
        for (const Sample& d : line) best = std::min(best, gap(s, d));
        worst = std::max(worst, best);
    }
    std::println("표본을 셋에 하나만 받으면 획이 최대 {:.1f}칸 벗어난다", worst);
    for (double g : {0.5, 1.0, 2.0})
        std::println("지수 {:.1f}: 압력 0.25, 0.5, 0.75일 때 {:.2f} {:.2f} {:.2f}",
                     g, radius(0.25, g), radius(0.5, g), radius(0.75, g));
}
```

- **표본마다 찍으면 끊긴다**: 표본은 시간에 맞춰 오므로, 빨리 그은 가운데에서는 사이가 벌어집니다. 첫 그림처럼 점이 따로 놉니다
- **간격은 길을 따라 잰다**: 표본을 이은 꺾은선 위를 걸으며 1.5칸마다 찍습니다. 구간이 끝나고 남은 거리는 다음 구간으로 넘깁니다. 실제 붓에서는 이 간격을 붓 너비에 대한 비율로 정합니다. GIMP의 붓 간격이 그런 값입니다
- **구간마다 새로 세면**: 표본이 촘촘한 느린 곳에 점이 몰립니다. 39개여야 할 점이 47개가 되고 가장 좁은 간격은 0.04칸입니다. 반투명한 붓이라면 그곳만 진해집니다. 손의 속도와 장치의 표본 빈도가 그림에 새어 든 것입니다
- **압력은 보간하고 곡선을 거친다**: 표본 사이에 찍는 점은 압력도 보간합니다. 압력을 굵기로 바꾸는 곡선은 느낌을 정합니다. 지수 0.5에서는 살짝만 눌러도 굵어지고, 2에서는 세게 눌러야 굵어집니다. Krita에는 태블릿 전체에 거는 압력 곡선이 설정에 있습니다
- **표본을 버리지 않는다**: 프레임마다 마지막 표본만 받으면 굽은 곳이 깎여 획이 1.1칸까지 벗어납니다. 운영체제와 브라우저는 움직임 사건을 합쳐서 주기도 합니다. 합쳐지기 전의 표본은 웹에서는 `getCoalescedEvents`로, Windows에서는 `GetPointerPenInfoHistory`로 꺼냅니다

## 펜이 주는 것

같은 값이 플랫폼마다 다른 범위로 옵니다. 받자마자 한 가지 단위로 맞춰 둡니다.

| 값 | Windows `POINTER_PEN_INFO` | 웹 포인터 이벤트 | Wayland 태블릿 |
|---|---|---|---|
| 압력 | 0~1024 | 0~1 | 0~65535 |
| 기울기 | 축마다 -90~90도 | 축마다 -90~90도 | 도 |
| 돌린 각도 | 0~359도 | 0~359도 | 시계 방향의 도 |

- **압력을 못 재는 장치**: 마우스로도 그릴 수 있어야 합니다. 웹은 압력을 못 재는 장치에서 누른 동안 0.5를 주고, Windows는 0을 줍니다. 어느 쪽이든 붓이 쓸 기본 압력은 도구가 정합니다
- **가까이 온 것과 닿은 것**: 펜은 닿기 전부터 사건을 냅니다. Wayland에서는 `proximity_in`이 먼저 오고 닿으면 `down`이 옵니다. 한 번에 바뀐 값들은 `frame`이 올 때까지 모아서 하나로 봅니다. 닿기 전의 자리로는 붓의 윤곽을 그려 줍니다
- **지우개 쪽 끝**: 펜을 뒤집은 것도 알려 옵니다. Wayland에서는 종류가 지우개인 다른 도구가 가까이 온 것으로 옵니다. 지우개로 잠깐 바꿨다가 돌아오는 일은 [「도구 상태 기계」](#/read/cpp-complex-app/tl-state)의 잠깐 쓰는 도구와 같습니다
- **macOS에서는 마우스 사건에 실려 온다**: 드라이버는 펜의 점 사건을 거의 언제나 마우스 사건의 하위 종류로 보냅니다. 압력만 바뀔 때처럼 태블릿 사건으로 따로 오는 경우도 있어서, 두 길을 한 처리기로 모읍니다
- **손떨림 보정**: 자리의 표본을 평균해 선을 매끄럽게 합니다. Krita의 스태빌라이저는 입력을 평균하고, 그 대신 선이 커서보다 조금 뒤에서 따라옵니다. 매끄러움과 지연을 맞바꾸는 것입니다
- **앞질러 그리기**: 웹의 `getPredictedEvents`는 다음에 올 자리를 예측해 줍니다. 그 자리까지 미리 그렸다가 실제 표본이 오면 버립니다. 예측한 점은 문서에 넣지 않습니다
- **획 하나가 실행 취소 한 단계**: 누름에서 뗌까지가 명령 하나입니다. 획이 닿은 타일만 전의 것을 간직하고([「그림의 자료 구조: 레이어 트리와 타일」](#/read/cpp-complex-app/doc-layers)), 점을 찍은 곳만 다시 그립니다([「무효화와 다시 그리기」](#/read/cpp-complex-app/rnd-invalidate))

<Note>
마우스로만 시험하면 압력, 근접, 지우개, 합쳐진 표본을 다루는 코드는 한 번도 실행되지 않습니다. 태블릿에서 받은 표본을 파일로 적어 두었다가 도구에 다시 흘려 넣으면, 장치 없이도 같은 획이 나오는지 견줄 수 있습니다. 예제가 표본의 배열에서 시작하는 것도 그래서입니다. 압력이 이상할 때는 가공하기 전의 값부터 봅니다. Krita의 태블릿 시험 창은 설정의 곡선을 거치지 않은 사건을 그대로 보여 줍니다.
</Note>

## 정리

- 획은 붓 모양을 길을 따라 고른 간격으로 찍은 것이다. 간격은 꺾은선의 길이로 재고 남은 거리를 구간 너머로 넘겨야 속도와 표본 빈도가 그림에 드러나지 않는다
- 표본 사이의 점은 압력도 보간하고, 압력은 곡선을 거쳐 굵기가 된다. 합쳐진 표본을 버리면 굽은 곳이 깎인다
- 압력과 기울기의 범위, 근접과 닿음을 알리는 방식은 플랫폼마다 다르다. 받는 곳에서 한 가지 꼴로 맞추고 도구는 그 꼴만 본다
