[「글 조판: 줄 나눔과 쪽 나눔」](#/read/cpp-complex-app/lay-text)은 낱말의 너비를 이미 안다고 쳤습니다. 그 너비를 내놓는 것이 셰이핑입니다. 글자 하나가 글리프 하나이고 너비는 글자마다 정해져 있다는 생각은 고정폭 영문에서만 맞습니다. 셰이핑은 글자의 줄을 받아 글꼴에 든 글리프의 줄과 그 자리로 바꿉니다.

```cpp
// 셰이핑: 글자가 글리프가 되는 길(글꼴별 런, 합자, 커닝, 결합 표시)과 클러스터
#include <map>
#include <print>
#include <string>
#include <vector>

using Text = std::u32string;
constexpr char32_t kAcute = U'́';           // 앞 글자 위에 얹는 결합 표시

std::string utf8(char32_t c) {
    if (c < 0x80) return {char(c)};
    if (c < 0x800) return {char(0xC0 | c >> 6), char(0x80 | (c & 0x3F))};
    return {char(0xE0 | c >> 12), char(0x80 | (c >> 6 & 0x3F)),
            char(0x80 | (c & 0x3F))};
}

struct Font {
    std::string name;
    std::map<char32_t, int> advance;             // 가진 글자와 그 글리프의 너비
    std::map<Text, int> ligature;                // 두 글자를 대신하는 글리프의 너비
    std::map<Text, int> kern;                    // 글자 쌍 사이를 조정하는 양
};

struct Glyph {
    std::string name;
    std::size_t cluster;                         // 이 글리프가 나온 첫 글자의 번호
    int advance;                                 // 다음 글리프까지 나아가는 거리
    int dx = 0;                                  // 그릴 때만 옮기는 양
};

struct Run { const Font* font; std::size_t begin, end; };

std::vector<Run> itemize(const std::vector<Font>& fonts, const Text& t) {
    std::vector<Run> runs;
    for (std::size_t i = 0; i < t.size(); ++i) {
        const Font* use = &fonts.back();
        for (auto f = fonts.rbegin(); f != fonts.rend(); ++f)
            if (f->advance.contains(t[i])) use = &*f;        // 앞의 글꼴이 먼저다
        if (t[i] == kAcute && !runs.empty()) use = runs.back().font;
        if (runs.empty() || runs.back().font != use) runs.push_back({use, i, i});
        runs.back().end = i + 1;
    }
    return runs;
}

std::vector<Glyph> shape(const Run& r, const Text& t) {
    const Font& f = *r.font;
    std::vector<Glyph> out;
    for (std::size_t i = r.begin; i < r.end; ++i) {
        Text pair = t.substr(i, i + 2 <= r.end ? 2 : 1);
        if (t[i] == kAcute) {                    // 너비 없이 앞 글리프에 얹는다
            out.push_back({"´", out.back().cluster, 0, -out.back().advance / 2});
        } else if (f.ligature.contains(pair)) {  // 두 글자가 글리프 하나로
            out.push_back({utf8(pair[0]) + utf8(pair[1]), i, f.ligature.at(pair)});
            ++i;
        } else {
            out.push_back({utf8(t[i]), i, f.advance.at(t[i])});
            if (f.kern.contains(pair)) out.back().advance += f.kern.at(pair);
        }
    }
    return out;
}

int main() {
    std::vector<Font> fonts(2);
    fonts[0] = {"Latin", {}, {{U"fi", 7}}, {{U"AV", -2}, {U"VA", -2}}};
    for (char32_t c : Text(U"aceilmnostv ")) fonts[0].advance[c] = 6;
    for (char32_t c : Text(U"fi")) fonts[0].advance[c] = 4;
    for (char32_t c : Text(U"AV")) fonts[0].advance[c] = 8;
    fonts[1] = {"Hangul", {{U'한', 12}, {U'글', 12}}, {}, {}};

    Text text = U"office AVA é 한글";
    std::size_t glyphs = 0, bytes = 0;
    for (char32_t c : text) bytes += utf8(c).size();
    std::string stops;                           // 캐럿이 설 수 있는 자리
    int x = 0, count = 0;
    for (const Run& r : itemize(fonts, text)) {
        std::vector<Glyph> gs = shape(r, text);
        std::string names, widths;
        for (const Glyph& g : gs) {
            names += std::format(" {}:{}", g.name == " " ? "_" : g.name, g.cluster);
            widths += std::format(" {}", g.advance);
        }
        for (std::size_t k = 0, end = 0; k < gs.size(); k = end) {
            std::size_t first = gs[k].cluster;   // 클러스터 하나의 글리프들
            int width = 0;
            for (end = k; end < gs.size() && gs[end].cluster == first; ++end)
                width += gs[end].advance;
            std::size_t next = end < gs.size() ? gs[end].cluster : r.end;
            int parts = 0;                       // 그 안에서 캐럿이 설 글자의 수
            for (std::size_t i = first; i < next; ++i) parts += text[i] != kAcute;
            for (int p = 0; p < parts; ++p)
                stops += std::format(" {}", x + width * p / parts);
            x += width, count += parts;
        }
        glyphs += gs.size();
        std::println("런 {} [{}, {}):{}", r.font->name, r.begin, r.end, names);
        std::println("  너비{}", widths);
    }
    std::println("UTF-8 {}바이트, 코드 포인트 {}개, 글리프 {}개, 줄 너비 {}", bytes,
                 text.size(), glyphs, x);
    std::println("캐럿이 서는 글자 {}개의 앞과 줄 끝:{} {}", count, stops, x);
}
```

```text
런 Latin [0, 14): o:0 f:1 fi:2 c:4 e:5 _:6 A:7 V:8 A:9 _:10 e:11 ´:11 _:13
  너비 6 4 7 6 6 6 6 6 8 6 6 0 6
런 Hangul [14, 16): 한:14 글:15
  너비 12 12
UTF-8 21바이트, 코드 포인트 16개, 글리프 15개, 줄 너비 97
캐럿이 서는 글자 15개의 앞과 줄 끝: 0 6 10 13 17 23 29 35 41 47 55 61 67 73 85 97
```

- **글꼴별 런**: 글꼴 하나가 모든 글자를 갖고 있지는 않습니다. `itemize`는 목록의 앞 글꼴부터 그 글자를 가진 것을 찾고, 글꼴이 같은 구간으로 글을 나눕니다. 결합 표시는 자기가 얹힐 글자의 글꼴을 따라갑니다. 실제로는 스크립트나 방향이 바뀌는 곳에서도 나눕니다
- **합자**: f와 i가 글리프 하나가 됐습니다. 그래서 코드 포인트는 16개인데 글리프는 15개입니다
- **커닝**: A와 V가 만나면 사이를 2만큼 당깁니다. A의 너비가 8일 때도 있고 6일 때도 있으므로, 글자 너비를 더해서는 줄 너비가 나오지 않습니다
- **결합 표시**: ´는 너비가 0이고 앞 글리프 위로 옮겨 그릴 양(`dx`)만 있습니다. 글꼴에 é가 통째로 들어 있으면 글리프 하나로 끝나지만, 없으면 이렇게 얹습니다
- **클러스터**: 글리프마다 자기가 나온 첫 글자의 번호를 들고 있습니다. 합자는 2이고, ´는 e와 같은 11입니다. 글리프에서 글자로 돌아가는 길은 이것뿐입니다. 캐럿을 놓을 때, 선택한 범위를 칠할 때, 마우스로 찍은 자리의 글자를 찾을 때 씁니다
- **캐럿이 서는 자리**: 클러스터의 경계에 서고, 합자처럼 글자가 둘 든 클러스터는 너비를 글자 수로 나눠 10과 13에 섭니다. e와 ´ 사이에는 서지 않습니다
- **길이가 넷**: 같은 글이 21바이트, 코드 포인트 16개, 캐럿이 서는 글자 15개, 글리프 15개입니다. 뒤의 둘은 수만 같고 경계가 다릅니다. 편집기의 좌표가 이 가운데 무엇인지는 층마다 정해 둬야 합니다. 문서 모델은 바이트나 코드 단위의 오프셋을, 캐럿은 글자를, 그리기는 글리프를 씁니다

## 셰이핑 앞뒤의 일

| 걸음 | 하는 일 | 맡는 라이브러리의 보기 |
| --- | --- | --- |
| 런 나누기 | 글꼴, 스크립트, 방향이 같은 구간으로 자른다 | 레이아웃 엔진이 직접 |
| 방향 정하기 | 오른쪽에서 왼쪽으로 가는 글을 가린다 | ICU, fribidi |
| 셰이핑 | 글자를 글리프와 자리로 바꾼다 | HarfBuzz, Uniscribe, CoreText |
| 줄 나눔 | 끊을 자리를 찾고 고른다 | ICU의 break iterator |
| 래스터 | 글리프의 윤곽선을 픽셀로 바꾼다 | FreeType |

- **HarfBuzz**: `hb_shape()`에 글꼴과 코드 포인트가 든 버퍼를 넘기면, 버퍼의 내용이 순서와 자리가 잡힌 글리프로 바뀝니다. 버퍼에는 글의 방향, 스크립트, 언어를 적어 둡니다. 설명서는 하지 않는 일도 적어 둡니다. 방향 정하기, 글꼴이나 크기가 섞인 글 다루기, 줄 나눔과 양쪽 맞춤입니다. 속성이 다른 구간은 따로따로 셰이핑해서 이어 붙입니다
- **클러스터 수준**: HarfBuzz의 기본 수준에서는 결합 표시가 앞 글자의 클러스터로 들어가고, 합자가 되면 클러스터도 합쳐집니다. 예제가 흉내 낸 것이 이것입니다
- **끊으면 달라지는 자리**: 줄을 끊으면 그 자리의 합자가 풀리거나 글자의 모양이 달라질 수 있습니다. HarfBuzz는 거기서 끊으면 다시 셰이핑해야 하는 글리프에 `UNSAFE_TO_BREAK` 표시를 답니다. 줄 나눔은 표시가 없는 자리에서는 셰이핑한 결과를 그대로 잘라 쓰고, 있는 자리에서만 다시 합니다
- **영문 밖에서는**: 아랍 글자는 낱말 안의 자리에 따라 네 모양 가운데 하나를 고릅니다. 타밀 글자에는 자음과 모음 기호가 만나면 글리프 하나로 바꿔야 하는 쌍이 있습니다. 설명서가 드는 보기들입니다
- **그린 것은 캐시에**: 래스터는 비싸므로 결과를 글꼴, 글리프 번호, 크기를 열쇠로 모아 둡니다([「2D 가속 그리기」](#/read/cpp-complex-app/rnd-2d)의 아틀라스). 열쇠에 물리 크기가 들어가므로 배율이 바뀌면 새로 그립니다([「고해상도」](#/read/cpp-complex-app/rnd-hidpi))

<Note>
문자열 처리의 버그는 대개 길이를 섞어 쓰는 데서 나옵니다. 바이트 오프셋으로 받은 자리에 글자 수만큼 더하거나, 코드 단위 하나를 지워 글자의 반쪽을 남기는 식입니다. 지우기, 캐럿 옮기기, 선택은 캐럿이 서는 글자의 경계에서만 하게 막아 두면 이런 일이 없습니다. UTF-16 코드 단위와 글자의 차이는 [「QString과 유니코드」](#/read/cpp-qt/core-string)에 있습니다.
</Note>

## 정리

- 셰이핑은 글자의 줄을 글리프의 줄과 자리로 바꾼다. 합자, 커닝, 결합 표시 때문에 글자와 글리프는 하나씩 짝지어지지 않는다
- 글리프가 든 클러스터 번호로 글자로 돌아가고, 캐럿과 선택과 마우스 판정이 여기에 기댄다
- 셰이핑 엔진은 속성이 같은 한 구간만 다룬다. 런 나누기, 방향, 줄 나눔, 래스터는 그 앞뒤에서 따로 한다
