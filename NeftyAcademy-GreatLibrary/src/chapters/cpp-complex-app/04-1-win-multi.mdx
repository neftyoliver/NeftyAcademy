큰 프로그램은 문서 여러 개를 창 여러 개에 보여 주고, 문서 하나를 여러 곳에서 보여 주기도 합니다. 이때 네 가지를 갈라 두어야 합니다. 데이터를 가진 **문서**, 문서를 보여 주는 **뷰**, 뷰를 담는 **탭**, 탭을 담는 **창**입니다. 버그는 대개 이 가운데 둘을 하나로 뭉쳐 놓은 곳에서 납니다.

```cpp
// 창, 탭, 뷰, 문서: 문서 하나를 여러 뷰가 볼 때 열기, 닫기, 명령이 가는 곳
#include <memory>
#include <print>
#include <string>
#include <vector>

struct Doc {
    std::string name;
    bool modified = false;
};

struct View {                                    // 탭 하나에 뷰 하나
    std::shared_ptr<Doc> doc;                    // 뷰들이 문서를 함께 쥔다
    int scroll = 0;                              // 뷰마다 따로인 상태
};

struct Window {
    int id;
    std::vector<View> tabs;
    std::size_t active = 0;
};

class App {
public:
    void open(const std::string& name) {         // 이미 열린 문서면 그 탭으로 간다
        for (std::size_t w = 0; w < windows_.size(); ++w)
            for (std::size_t t = 0; t < windows_[w].tabs.size(); ++t)
                if (windows_[w].tabs[t].doc->name == name) return focus(w, t);
        if (windows_.empty()) windows_.push_back({next_id_++, {}, 0});
        add(windows_[front_], {std::make_shared<Doc>(name), 0});
    }
    void new_view() {                            // 같은 문서를 새 창에서 한 번 더
        windows_.push_back({next_id_++, {}, 0});
        add(windows_.back(), {view().doc, 0});
        front_ = windows_.size() - 1;
    }
    void detach() {                              // 탭을 떼어 새 창으로 옮긴다
        View v = take();
        windows_.push_back({next_id_++, {}, 0});
        add(windows_.back(), std::move(v));
        front_ = windows_.size() - 1;
    }
    void close() {                               // 지금 탭을 닫는다
        View v = take();
        if (v.doc.use_count() == 1 && v.doc->modified)  // 마지막 뷰일 때만 묻는다
            std::println("  '{}'을 저장할지 묻는다", v.doc->name);
        if (windows_.empty()) std::println("  마지막 창이 닫혔다");
    }
    void focus(std::size_t w, std::size_t t) { front_ = w, windows_[w].active = t; }
    void edit() { view().doc->modified = true; }
    void save() {                                // 명령은 앞 창의 지금 탭으로 간다
        std::println("  저장: {}", view().doc->name);
        view().doc->modified = false;
    }
    void show(const char* what) const {
        std::print("{:<18}", what);
        for (std::size_t w = 0; w < windows_.size(); ++w) {
            std::print("{}창{}:", w == front_ ? "  >" : "   ", windows_[w].id);
            for (std::size_t t = 0; t < windows_[w].tabs.size(); ++t) {
                const Doc& d = *windows_[w].tabs[t].doc;
                std::string label = d.name + (d.modified ? "*" : "");
                if (t == windows_[w].active) label = "[" + label + "]";
                std::print(" {}", label);
            }
        }
        std::println("{}", windows_.empty() ? "  (창 없음)" : "");
    }

private:
    View& view() { return windows_[front_].tabs[windows_[front_].active]; }
    void add(Window& w, View v) {
        w.tabs.push_back(std::move(v));
        w.active = w.tabs.size() - 1;
    }
    View take() {                                // 지금 탭을 빼내고, 빈 창은 없앤다
        Window& w = windows_[front_];
        View v = std::move(w.tabs[w.active]);
        w.tabs.erase(w.tabs.begin() + static_cast<std::ptrdiff_t>(w.active));
        if (w.active > 0) --w.active;
        if (w.tabs.empty()) {
            windows_.erase(windows_.begin() + static_cast<std::ptrdiff_t>(front_));
            front_ = 0;
        }
        return v;
    }
    std::vector<Window> windows_;
    std::size_t front_ = 0;
    int next_id_ = 1;
};

int main() {
    App app;
    app.open("a.txt"), app.open("b.txt"), app.show("둘을 엶");
    app.open("a.txt"), app.show("a.txt를 또 엶");
    app.new_view(), app.show("새 창으로 보기");
    app.edit(), app.show("창2에서 고침");
    app.close(), app.show("창2를 닫음");
    app.focus(0, 1), app.detach(), app.show("b.txt를 떼어 냄");
    app.save();
    app.focus(0, 0), app.save(), app.edit(), app.show("창1로 가서 고침");
    app.close(), app.show("a.txt를 닫음");
    app.close(), app.show("b.txt를 닫음");
}
```

```text
둘을 엶             >창1: a.txt [b.txt]
a.txt를 또 엶       >창1: [a.txt] b.txt
새 창으로 보기       창1: [a.txt] b.txt  >창2: [a.txt]
창2에서 고침         창1: [a.txt*] b.txt  >창2: [a.txt*]
창2를 닫음          >창1: [a.txt*] b.txt
b.txt를 떼어 냄      창1: [a.txt*]  >창3: [b.txt]
  저장: b.txt
  저장: a.txt
창1로 가서 고침     >창1: [a.txt*]   창3: [b.txt]
  'a.txt'을 저장할지 묻는다
a.txt를 닫음        >창3: [b.txt]
  마지막 창이 닫혔다
b.txt를 닫음        (창 없음)
```

- **뷰는 문서를 가리키고 자기 상태를 가진다**: 문서는 뷰들이 함께 쥡니다. 창2에서 고치자 창1의 탭에도 `*`가 붙었습니다. 스크롤, 확대, 선택은 뷰마다 따로입니다([「선택 모델」](#/read/cpp-complex-app/doc-selection))
- **열 때는 이미 열린 것부터 찾는다**: 같은 파일로 문서 객체를 둘 만들면 한쪽의 저장이 다른 쪽에서 고친 것을 덮어씁니다. 둘째 뷰는 "새 창으로 보기"처럼 따로 둔 명령으로만 만듭니다
- **닫을 때는 마지막 뷰인지 본다**: 뷰가 둘일 때 하나를 닫는 것은 묻지 않고 닫습니다. 마지막 뷰를 닫을 때에만 저장할지 묻습니다. 예제에서는 `shared_ptr`의 참조 수가 곧 뷰의 수입니다
- **탭을 떼어도 문서는 모른다**: 탭을 다른 창으로 옮기는 일은 뷰를 옮기는 일입니다. 문서도, 뷰가 가진 스크롤과 선택도 그대로입니다
- **명령은 앞 창의 지금 탭으로 간다**: "저장"이 무엇을 저장할지는 초점이 정합니다. 창3이 앞일 때는 b.txt가, 창1로 간 뒤에는 a.txt가 저장되었습니다([「실제 프로그램들의 구조」](#/read/cpp-complex-app/ana-cases))
- **마지막 창**: 마지막 창이 닫힐 때 프로그램을 끝낼지는 플랫폼의 관습을 따릅니다. macOS에서는 창이 없어도 떠 있는 프로그램이 흔하고, 끝낼지를 프로그램이 정합니다

## 상태가 사는 곳

| 상태 | 사는 곳 |
| --- | --- |
| 내용, 실행 취소 기록, 고쳤는지 | 문서 |
| 스크롤, 확대, 선택과 커서 | 뷰 |
| 탭의 차례, 지금 탭, 자리와 크기 | 창 |
| 최근 파일, 설정, 지금 고른 도구 | 프로그램 |

새 상태를 더할 때마다 이 표의 어느 줄인지 먼저 정합니다. 확대 배율을 문서에 두면 한 문서를 두 창에서 볼 때 한쪽을 확대하면 다른 쪽도 커지고, 실행 취소 기록을 뷰에 두면 창마다 되돌리는 차례가 달라집니다.

## 실제 틀

- **MFC**: 창 하나에 문서 하나인 SDI와, 큰 창 안에 문서 창을 여럿 두는 MDI를 모두 받칩니다. 문서가 뷰의 목록을 가지며, 한 문서에 뷰를 여럿 두는 길이 셋입니다. "새 창"은 처음의 틀 창과 뷰를 한 벌 더 만들고, 동적 분할은 한 창을 같은 뷰 여럿으로 나누며, 정적 분할은 처음부터 서로 다른 뷰를 나란히 둡니다. 실제 크기와 확대한 모습을 나란히 보여 주는 비트맵 편집기가 정적 분할의 보기입니다
- **Cocoa**: 프로그램에 하나뿐인 `NSDocumentController`가 문서들을 만들고, 문서가 `NSWindowController`를 창마다 하나씩 만들어 가집니다
- **VS Code**: 탭을 담는 편집기 묶음을 나눠 같은 파일을 나란히 고칠 수 있고, 탭을 창 밖으로 끌면 떠 있는 창이 됩니다. 한 창에서 고친 것은 그 편집기가 열린 다른 창에 바로 나타납니다

<Note>
창이 여럿이면 "지금 문서"가 무엇인지가 흔들립니다. 도구 상자나 찾기 창처럼 초점을 가져가는 창이 앞에 와도 명령은 문서 창으로 가야 합니다. 그래서 초점을 가진 창과 따로, 마지막으로 앞에 있던 문서 창을 기억해 둡니다. 예제의 `front_`가 그 자리이고, 떠 있는 패널은 이 값을 바꾸지 않아야 합니다([「도킹 패널」](#/read/cpp-complex-app/win-docking)).
</Note>

## 정리

- 문서는 데이터를, 뷰는 스크롤과 선택 같은 보는 쪽의 상태를 가지며, 한 문서를 여러 뷰가 함께 쥔다
- 같은 파일을 열면 이미 있는 문서를 찾아 쓰고, 저장할지는 마지막 뷰를 닫을 때에만 묻는다
- 탭 떼어 내기는 뷰를 창 사이에서 옮기는 일이고, 명령은 마지막으로 앞에 있던 문서 창의 지금 탭으로 보낸다
