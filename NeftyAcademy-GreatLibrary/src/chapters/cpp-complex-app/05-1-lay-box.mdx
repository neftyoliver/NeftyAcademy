단추와 입력란의 자리를 픽셀로 적어 두면 창 크기, 글꼴 크기, 번역된 글의 길이 가운데 하나만 바뀌어도 화면이 깨집니다. 레이아웃 엔진은 자리를 받지 않습니다. 바라는 크기, 최소와 최대, 늘고 주는 몫만 받고 자리는 셈합니다. 한 줄만 다루는 작은 엔진으로 뼈대를 봅니다.

```cpp
// 한 줄짜리 레이아웃 엔진: 재기는 아래에서 위로, 놓기는 위에서 아래로
#include <algorithm>
#include <cmath>
#include <format>
#include <print>
#include <string>
#include <vector>

struct Node {
    std::string name;
    double basis = 0, grow = 0, shrink = 0;      // 바라는 너비, 늘고 주는 몫
    double min = 0, max = 1e9;
    int pad = 0;                                 // 묶음의 안쪽 여백
    std::vector<Node> kids;
    double wish = 0;                             // 잰 결과
    bool dirty = true;
    int x = 0, w = 0;                            // 놓인 자리
};

int measured = 0;
double measure(Node& n) {                        // 얼마가 필요한가(캐시한다)
    if (!n.dirty) return n.wish;
    ++measured, n.dirty = false, n.wish = n.basis;
    if (n.kids.empty()) return n.wish;
    n.wish = n.min = 2 * n.pad;                  // 묶음: 여백 + 자식들
    for (Node& k : n.kids) n.wish += measure(k), n.min += k.min;
    return n.wish;
}

// CSS 플렉스박스의 길이 정하기를 줄인 것: 나눠 주고, 한도에 걸린 것은 얼리고, 다시
std::vector<double> flex(const std::vector<Node>& kids, double space) {
    std::size_t n = kids.size();
    std::vector<double> size(n), raw(n);
    std::vector<bool> frozen(n);
    double sum = 0;
    for (std::size_t i = 0; i < n; ++i) {
        sum += kids[i].wish;
        size[i] = std::clamp(kids[i].wish, kids[i].min, kids[i].max);
    }
    bool growing = sum < space;
    auto weight = [&](std::size_t i) {           // 줄 때는 큰 것이 더 많이 준다
        if (frozen[i]) return 0.0;
        return growing ? kids[i].grow : kids[i].shrink * kids[i].wish;
    };
    for (;;) {
        double free = space, total = 0, violation = 0;
        for (std::size_t i = 0; i < n; ++i)
            free -= frozen[i] ? size[i] : kids[i].wish, total += weight(i);
        if (total == 0) return size;             // 더 나눌 데가 없다
        for (std::size_t i = 0; i < n; ++i) {
            if (weight(i) == 0) continue;
            raw[i] = kids[i].wish + free * weight(i) / total;
            size[i] = std::clamp(raw[i], kids[i].min, kids[i].max);
            violation += size[i] - raw[i];
        }
        for (std::size_t i = 0; i < n; ++i) {    // 한도에 걸린 쪽을 얼린다
            if (weight(i) == 0) continue;
            bool hit = violation > 0 ? size[i] > raw[i] : size[i] < raw[i];
            if (violation == 0 || hit) frozen[i] = true;
        }
    }
}

void arrange(Node& n, int x, int w) {            // 부모가 자리와 크기를 정해 준다
    n.x = x, n.w = w;
    if (n.kids.empty()) return;
    std::vector<double> size = flex(n.kids, w - 2 * n.pad);
    double edge = x + n.pad;
    for (std::size_t i = 0; i < n.kids.size(); ++i) {
        int from = static_cast<int>(std::lround(edge));  // 가장자리를 칸에 맞춘다
        edge += size[i];
        arrange(n.kids[i], from, static_cast<int>(std::lround(edge)) - from);
    }
}

void paint(const Node& n, std::string& line, char fill) {
    if (n.x + n.w > static_cast<int>(line.size())) line.resize(n.x + n.w, ' ');
    if (!n.kids.empty()) {
        line.replace(n.x, n.w, std::string(n.w, fill));
        for (const Node& k : n.kids) paint(k, line, ':');
    } else if (!n.name.empty() && n.w >= 2) {
        std::string label = "[" + n.name + std::string(n.w, ' ');
        line.replace(n.x, n.w, label.substr(0, n.w - 1) + "]");
    }
}

bool touch(Node& n, const std::string& name, double basis) {
    bool hit = n.name == name;                   // 바뀐 곳에서 뿌리까지 더럽힌다
    if (hit) n.basis = basis;
    for (Node& k : n.kids) hit = touch(k, name, basis) || hit;
    return n.dirty = n.dirty || hit;
}

void layout(Node& root, int width) {
    measured = 0;
    measure(root);
    arrange(root, 0, width);
    std::string line(width, ' ');
    paint(root, line, ' ');
    int over = static_cast<int>(line.size()) - width;
    std::println("{:>2}칸 |{}| 잰 노드 {}{}", width, line, measured,
                 over > 0 ? std::format(", {}칸 넘침", over) : "");
}

Node leaf(std::string name, double basis, double grow = 0, double shrink = 0,
          double min = 0, double max = 1e9) {
    Node n;
    n.name = std::move(name), n.basis = basis, n.grow = grow, n.shrink = shrink;
    n.min = min, n.max = max;
    return n;
}

int main() {
    Node group;
    group.pad = 1, group.kids = {leaf("B", 3), leaf("I", 3)};
    Node root;
    root.kids = {leaf("File", 6), leaf("search", 14, 1, 1, 8, 24), group,
                 leaf("", 0, 2), leaf("Close", 7)};
    for (int width : {50, 66, 36, 30, 24}) layout(root, width);
    touch(root, "search", 20);
    layout(root, 50);
}
```

```text
50칸 |[File][search           ]:[B][I]:          [Close]| 잰 노드 8
66칸 |[File][search                ]:[B][I]:                     [Close]| 잰 노드 0
36칸 |[File][search      ]:[B][I]: [Close]| 잰 노드 0
30칸 |[File][search ]:[B][I]:[Close]| 잰 노드 0
24칸 |[File][search]:[B][I]:[Close]| 잰 노드 0, 5칸 넘침
50칸 |[File][search               ]:[B][I]:      [Close]| 잰 노드 2
```

- **재기는 아래에서 위로**: `measure`에서 잎은 바라는 너비를 말하고, 묶음은 여백에 자식들의 것을 더해 말합니다
- **놓기는 위에서 아래로**: `arrange`에서 부모는 받은 너비 안에서 자식의 자리와 크기를 정합니다. 자식은 자기 자리를 정하지 않습니다
- **남는 칸은 몫대로**: 50칸에서는 15칸이 남아 search와 빈 칸이 1 대 2로 나눠 가졌습니다
- **한도에 걸리면 얼리고 다시 나눈다**: 66칸에서 search는 최대인 24칸에 걸렸습니다. 그 크기로 얼리고 남은 칸을 빈 칸이 모두 가졌습니다. 나누기가 한 번에 끝나지 않고 되풀이인 까닭입니다
- **모자라면 주는 몫대로**: 30칸에서는 줄어도 된다고 한 search만 줄었습니다. 24칸에서는 search가 최소인 8칸에 걸려 5칸이 넘칩니다. 넘침은 엔진이 풀 수 없고, 자르거나 스크롤하거나 접어 넣는 정책이 맡습니다
- **가장자리를 칸에 맞춘다**: 크기를 하나씩 반올림하면 합이 어긋납니다. 가장자리의 누적 위치를 반올림하고 그 차이를 크기로 삼아 틈도 겹침도 없게 합니다
- **바뀐 길만 다시 잰다**: 창 너비만 바뀔 때는 잰 값을 그대로 쓰고 놓기만 다시 합니다. search의 내용이 길어졌을 때는 search와 뿌리, 두 노드만 다시 쟀습니다

묶음의 `pad`는 박스 모델의 안쪽 여백입니다. 상자는 안에서부터 내용, 안쪽 여백, 테두리, 바깥 여백으로 이루어지고, 너비라는 말이 그 가운데 어디까지를 가리키는지 엔진 전체에서 하나로 정해 둬야 합니다.

## 세 가지 방식

| 방식 | 부모와 자식이 주고받는 것 | 보기 |
| --- | --- | --- |
| 두 번 훑기 | 바라는 크기가 올라오고, 자리가 내려간다 | WPF |
| 제약 내려보내기 | 최소와 최대가 내려가고, 고른 크기가 올라온다 | Flutter |
| 연립 방정식 | 뷰 사이의 관계를 식으로 적고 풀이기가 푼다 | Auto Layout |

- **WPF**: 자식마다 재기와 놓기를 한 번씩 거칩니다. 재기에서 자식의 `DesiredSize`가 정해지고, 놓기에서 부모가 사각형을 줍니다. 자식은 받은 자리를 다 채우지 않아도 됩니다. 배치에 영향을 주는 속성에 표시를 달아 그 속성이 바뀔 때만 다시 계산하고, `UseLayoutRounding`을 켜면 가장자리가 픽셀 가운데에 걸려 흐려지는 일을 막습니다
- **Flutter**: 문서가 외우라고 권하는 규칙이 "제약은 내려가고, 크기는 올라오고, 자리는 부모가 정한다"입니다. 제약은 너비와 높이의 최소와 최대, 네 수입니다
- **CSS 플렉스박스**: 예제의 `flex`가 줄여 옮긴 것입니다. 명세는 늘릴지 줄일지를 먼저 정하고, 몫이 0인 것을 얼린 다음, 남는 공간을 몫대로 나누고 최소와 최대로 자릅니다. 자른 양의 합이 양수면 최소에 걸린 것을, 음수면 최대에 걸린 것을 얼리고 되풀이합니다. 줄일 때의 몫에는 바탕 크기를 곱합니다
- **Yoga**: 플렉스박스를 C++20으로 구현한, 다른 프로그램에 끼워 넣는 엔진입니다. 시험의 기대값은 같은 HTML을 Chrome에 그려서 얻습니다
- **Auto Layout**: 제약 하나가 일차식 하나입니다. 제약마다 1에서 1000까지의 우선순위가 있고 1000은 꼭 지켜야 하는 것입니다. 풀이가 여럿이면 모호한 배치, 하나도 없으면 풀 수 없는 배치라고 부릅니다
- **Qt**: 위젯의 크기 힌트와 늘어나는 몫으로 배치합니다([「레이아웃」](#/read/cpp-qt/wid-layout))

<Note>
한 줄짜리 예제에서는 재기가 한 번에 끝나지만, 줄을 바꾸는 글은 그렇지 않습니다. 글의 높이는 너비가 정해져야 알 수 있고, 그 너비는 놓기에서 정해집니다. 그래서 실제 엔진의 재기는 "너비가 이만큼이라면 높이는 얼마인가"를 묻는 꼴이 되고, 같은 노드를 다른 너비로 여러 번 재는 일이 생깁니다. 잰 결과를 너비와 함께 캐시해 두는 까닭입니다([「글 조판: 줄 나눔과 쪽 나눔」](#/read/cpp-complex-app/lay-text)).
</Note>

## 정리

- 레이아웃은 아래에서 위로 바라는 크기를 재고, 위에서 아래로 부모가 자식의 자리와 크기를 정하는 두 걸음이다
- 남거나 모자란 공간은 몫대로 나누되, 최소와 최대에 걸린 것은 그 크기로 얼리고 나머지끼리 다시 나눈다
- 가장자리의 누적 위치를 칸에 맞춰 틈과 겹침을 없애고, 잰 값을 캐시해 바뀐 노드에서 뿌리까지만 다시 잰다
