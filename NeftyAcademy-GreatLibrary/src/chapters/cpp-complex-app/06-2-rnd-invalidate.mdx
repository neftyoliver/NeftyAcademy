화면의 대부분은 대부분의 시간 동안 그대로입니다. 시계의 숫자 하나가 바뀔 때 창 전체를 다시 그리는 것은 낭비입니다. 무효화는 여기가 낡았다고 적어만 두는 일이고, 다시 그리기는 그 기록을 모아 한 번에 처리하는 일입니다. 어디가 낡았는지는 그리는 쪽이 아니라 바꾼 쪽이 압니다.

```cpp
// 무효화: 바뀐 곳만 모아서 다시 그리기, 버퍼가 두 장일 때 빠뜨리지 않기
#include <algorithm>
#include <print>
#include <string>
#include <vector>

struct Rect {                                    // 끝은 들어가지 않는다
    int x0, y0, x1, y1;
    int area() const { return std::max(0, x1 - x0) * std::max(0, y1 - y0); }
};
Rect meet(Rect a, Rect b) {
    return {std::max(a.x0, b.x0), std::max(a.y0, b.y0), std::min(a.x1, b.x1),
            std::min(a.y1, b.y1)};
}
Rect join(Rect a, Rect b) {
    return {std::min(a.x0, b.x0), std::min(a.y0, b.y0), std::max(a.x1, b.x1),
            std::max(a.y1, b.y1)};
}
bool near(Rect a, Rect b) {                      // 겹치거나 맞닿았다
    return a.x0 <= b.x1 && b.x0 <= a.x1 && a.y0 <= b.y1 && b.y0 <= a.y1;
}

struct Region {                                  // 겹치거나 맞닿은 것끼리만 합친다
    std::vector<Rect> rects;
    void add(Rect r) {
        for (std::size_t i = 0; i < rects.size();) {
            if (!near(rects[i], r)) { ++i; continue; }
            r = join(rects[i], r), rects.erase(rects.begin() + i), i = 0;
        }
        rects.push_back(r);
    }
};

constexpr int kW = 48, kH = 8;
constexpr Rect kAll{0, 0, kW, kH};
enum { Pick = 5, Clock, Cursor };                // 고른 줄, 시계, 커서의 번호

struct Widget { Rect r; char ink; };
using Widgets = std::vector<Widget>;
struct Cost { int cells = 0, calls = 0; };

void paint(std::string& screen, const Widgets& ws, Rect clip, Cost& cost) {
    for (const Widget& w : ws) {                 // 뒤에 있는 것부터
        Rect r = meet(w.r, clip);
        if (r.area() == 0) continue;             // 걸치지 않는 위젯은 부르지 않는다
        ++cost.calls, cost.cells += r.area();
        for (int y = r.y0; y < r.y1; ++y)
            for (int x = r.x0; x < r.x1; ++x) screen[y * kW + x] = w.ink;
    }
}

std::string full(const Widgets& ws) {
    std::string screen(kW * kH, ' ');
    Cost unused;
    paint(screen, ws, kAll, unused);
    return screen;
}

struct Frame {
    const char* what;
    Widgets ws;
    std::vector<Rect> damage;                    // 이 프레임에 무효가 된 사각형들
};

int main() {
    Widgets ws = {
        {kAll, ' '}, {{0, 0, kW, 1}, '='},               // 바탕, 도구 모음
        {{0, 1, 16, 7}, ':'}, {{16, 1, kW, 7}, '.'},     // 목록, 편집기
        {{0, 7, kW, 8}, '-'}, {{0, 2, 16, 3}, '#'},      // 상태 줄, 고른 줄
        {{40, 0, 48, 1}, '0'}, {{17, 6, 18, 7}, '|'}};   // 시계, 커서
    std::string first = full(ws);
    for (int y = 0; y < kH; ++y) std::println("{}", first.substr(y * kW, kW));

    std::vector<Frame> frames;
    std::vector<Rect> damage;
    auto ink = [&](int i, char c) { ws[i].ink = c, damage.push_back(ws[i].r); };
    auto down = [&](int i) {                     // 옛 자리와 새 자리가 모두 무효다
        damage.push_back(ws[i].r);
        ++ws[i].r.y0, ++ws[i].r.y1;
        damage.push_back(ws[i].r);
    };
    auto end = [&](const char* what) {
        frames.push_back({what, ws, damage}), damage.clear();
    };
    ink(Clock, '1'), ink(Cursor, '_'), end("시계와 커서");
    down(Pick), end("고른 줄을 한 칸 아래로");
    down(Pick), ink(Clock, '2'), ink(Cursor, '|'), end("셋 다");

    auto row = [](const char* how, Cost c, bool same) {
        std::println("  {}: 칠한 칸 {:3}, 그리기 호출 {}, 그림 {}", how, c.cells,
                     c.calls, same ? "같음" : "다름");
    };
    std::string all = first, box = first, parts = first;
    for (const Frame& f : frames) {
        std::string truth = full(f.ws);
        Cost a, b, c;
        Rect one = f.damage[0];
        Region region;
        for (Rect r : f.damage) one = join(one, r), region.add(r);
        paint(all, f.ws, kAll, a);
        paint(box, f.ws, one, b);
        for (Rect r : region.rects) paint(parts, f.ws, r, c);
        std::println("{}: 무효 요청 {}번, 합치면 사각형 {}개", f.what,
                     f.damage.size(), region.rects.size());
        row("전체      ", a, all == truth);
        row("상자 하나 ", b, box == truth);
        row("사각형마다", c, parts == truth);
    }

    std::println("버퍼 두 장을 번갈아 쓸 때");
    for (bool with_last : {false, true}) {
        std::string buffer[2] = {first, first}, result;
        std::vector<Rect> last;
        for (std::size_t n = 0; n < frames.size(); ++n) {
            std::string& back = buffer[(n + 1) % 2];  // 두 프레임 전의 그림이 있다
            Region region;
            for (Rect r : frames[n].damage) region.add(r);
            if (with_last)
                for (Rect r : last) region.add(r);
            Cost c;
            for (Rect r : region.rects) paint(back, frames[n].ws, r, c);
            result += back == full(frames[n].ws) ? " 같음" : " 다름";
            last = frames[n].damage;
        }
        const char* how = with_last ? "지난 프레임의 것까지" : "이번 프레임의 것만";
        std::println("  {}:{}", how, result);
    }
}
```

- **적어 두고 나중에 한 번**: 상태를 바꾼 코드는 무효 사각형만 남깁니다. 그리기는 프레임에 한 번이고, 그 사이에 요청이 몇 번 왔든 합쳐서 처리합니다. Qt의 `update()`가 이렇게 일합니다([「위젯 직접 그리기」](#/read/cpp-qt/paint-custom))
- **옮길 때는 두 곳**: 고른 줄이 내려가면 옛 자리와 새 자리가 모두 무효입니다. 옛 자리를 빠뜨리면 지워지지 않은 줄이 남습니다
- **상자 하나로 합치면**: 시계와 커서는 멀리 떨어진 작은 두 곳인데, 둘을 감싸는 상자는 443칸을 칠합니다. 따로 그리면 27칸입니다
- **사각형 여럿으로**: `Region`은 겹치거나 맞닿은 것끼리만 합칩니다. 줄을 옮긴 프레임에서는 두 요청이 사각형 하나가 됐습니다. 사각형마다 위젯을 다시 훑으므로 호출은 늘어납니다. 셋째 프레임은 9번으로, 전체를 그릴 때의 8번보다 많습니다. 사각형 수에 한도를 두고 넘으면 가까운 것끼리 합치는 까닭입니다
- **걸친 것은 뒤에서부터 다**: 시계 한 곳을 고치려 해도 그 자리에 걸친 바탕, 도구 모음, 시계를 순서대로 다시 그립니다. 그리기는 무효 영역으로 잘라서 그 밖을 건드리지 않습니다
- **버퍼가 두 장이면**: 번갈아 쓰는 버퍼의 뒤쪽에는 두 프레임 전의 그림이 있습니다. 이번 프레임의 무효 영역만 그리면 지난 프레임의 변화가 빠져 그림이 틀립니다. 지난 프레임의 것까지 합쳐 그려야 맞습니다

타일 캐시가 있으면 무효 사각형에 걸친 타일을 모든 단계에서 버리는 일이 여기에 더해집니다([「캔버스: 확대와 타일 렌더링」](#/read/cpp-complex-app/lay-canvas)).

## 운영체제와 프레임워크에서

- **Windows**: `InvalidateRect`는 창의 갱신 영역에 사각형을 더합니다. 무효가 된 곳은 그 영역에 쌓이고, 시스템은 큐에 다른 메시지가 없을 때 영역이 비어 있지 않으면 `WM_PAINT`를 보냅니다
- **Android**: 소프트웨어로 그릴 때는 무효 영역에 걸친 뷰를 바뀌지 않았어도 모두 다시 그립니다. 하드웨어 가속에서는 뷰마다 그리기 명령을 표시 목록에 적어 두고, 무효가 된 뷰의 목록만 다시 적습니다. 나머지는 적어 둔 목록을 그대로 다시 내보냅니다
- **레이어**: 같은 문서는 뷰를 텍스처에 그려 두는 하드웨어 레이어도 설명합니다. 그 뷰가 `invalidate()`를 부르기 전에는 그리기 코드가 돌지 않고, 투명도 같은 애니메이션은 텍스처에 바로 적용됩니다. 비디오 메모리를 쓰므로 애니메이션 동안에만 켜라고 합니다
- **DXGI**: `Present1`에 더러운 사각형과 스크롤 사각형을 넘깁니다. 스크롤 사각형은 앞 프레임의 그림을 옮겨 쓰고 새로 드러난 줄만 그리게 해 줍니다. 더러운 사각형 안의 픽셀은 모두 새것이어야 하고, 버퍼가 여러 장일 때 앞 프레임과 겹치는 곳을 채우는 일은 앱의 몫입니다
- **EGL**: `EGL_EXT_buffer_age` 확장의 `EGL_BUFFER_AGE_EXT`는 뒤 버퍼의 그림이 몇 프레임 전의 것인지 알려 줍니다. 0이면 내용을 믿을 수 없고, n이면 n 프레임 전의 것입니다. 앱은 지난 몇 프레임의 변경 영역을 기억해 두었다가 나이만큼 합쳐서 고칩니다

<Note>
무효화의 버그는 두 가지입니다. 덜 무효화하면 낡은 그림이 남고, 더 무효화하면 그림은 맞지만 느립니다. 뒤의 것은 눈에 보이지 않으므로 다시 그린 곳을 보여 주는 도구가 필요합니다. Chrome 개발자 도구의 Paint flashing은 다시 칠한 곳을 초록색으로 번쩍이게 합니다. 직접 만드는 렌더러에도 같은 것을 넣어 두면, 커서가 깜박일 때 창 전체가 번쩍이는 일을 바로 알아챕니다.
</Note>

## 정리

- 상태를 바꾸는 코드는 무효 사각형만 적고, 그리기는 프레임마다 모아서 한 번 한다. 움직인 것은 옛 자리와 새 자리가 모두 무효다
- 무효 영역은 상자 하나보다 사각형 몇 개로 들고 있어야 멀리 떨어진 작은 변경이 싸다
- 버퍼를 번갈아 쓰면 뒤 버퍼가 낡은 만큼의 무효 영역을 합쳐서 그려야 한다
