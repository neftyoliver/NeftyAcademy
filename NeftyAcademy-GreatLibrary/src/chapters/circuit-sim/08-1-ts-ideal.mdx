시뮬레이터는 넷리스트에 적힌 것만 셈합니다. 전압원은 얼마를 끌어가도 전압이 그대로이고, 다이오드는 몇 암페어가 흘러도 타지 않으며, 선에는 저항이 없습니다. 답이 실제와 어긋나는 것은 대개 셈이 틀려서가 아니라, 넷리스트가 실제 회로보다 단순해서입니다. 이 쪽은 이상적인 부품이 숨기는 것을 세 가지 보기로 꺼내 봅니다.

## 적지 않은 것은 없다

| 넷리스트의 것 | 실물에 더 있는 것 |
| --- | --- |
| 전압원 | 낼 수 있는 전류의 한계, 안쪽의 저항 |
| 저항 | 견디는 전력, 오차 |
| 커패시터와 인덕터 | 직렬 저항, 견디는 전압과 전류 |
| 반도체의 모델 | 최대 전류와 전력, 맞춰 보지 않은 조건에서의 모습 |
| 선과 접지 | 저항, 인덕턴스, 옆 선과의 커패시턴스 |

## 전압원은 얼마든지 내준다

3장의 LED 회로를 둘 나란히 놓습니다. 하나는 전압원에 바로 잇고, 하나는 전압원과 회로 사이에 175Ω을 넣습니다.

```spice
핀의 전류: 이상적인 전원과 가장 나쁜 핀
V1 pin 0 3.3
R1 pin a 330
D1 a 0 RED
V2 src 0 3.3
Rpin src pin2 175
R2 pin2 a2 330
D2 a2 0 RED
.model RED D(IS=1e-18 N=1.9 RS=5)
.op
.end
```

```text
$ ngspice -b pin.cir
a2          1.767105e+00
pin2        2.768799e+00
a           1.794740e+00
pin         3.300000e+00
v1#branch   -4.56140e-03
v2#branch   -3.03544e-03
```

- **175Ω은 규격에서 나왔다**: 라즈베리파이 4의 핀은 4mA를 낼 때 HIGH의 전압이 2.6V까지 내려갈 수 있다고 되어 있습니다. 0.7V가 4mA에 내려가는 것은 175Ω이 안에 있는 것과 같습니다([「3.3V 논리와 전류 한계」](#/read/sbc-start/hdr-voltage))
- **가장 나쁜 핀에서는 전류가 3분의 1 줄어든다**: 이상적인 전원은 4.56mA를, 175Ω을 넣은 쪽은 3.04mA를 냅니다. 핀의 전압은 2.77V로 내려앉았습니다
- **이상적인 전원은 말리지 않는다**: `R1`을 82Ω으로 바꾸면 16.8mA, 47Ω이면 27.7mA, 10Ω이면 92mA가 흐른다고 답합니다. 핀의 전압은 그때에도 3.300V입니다. 핀 하나의 한도는 16mA입니다
- **전원에 기대는 답은 다시 돌려 본다**: 전압원 하나로 시작하되, 전원이 내는 전류가 답을 좌우하면 규격의 가장 나쁜 값을 저항으로 넣어 한 번 더 돌립니다

## 한계는 알려 줘야 지킨다

4장에서 1N4148에 10V를 걸었더니 13.8A가 흐른다는 답이 경고 없이 나왔습니다. 모델에 한계를 적고 검사를 켜면 ngspice가 알려 줍니다.

```spice
1N4148에 10V를 걸고 한계를 알려 주기
V1 a 0 10
D1 a 0 D4148
.model D4148 D(IS=4.352n N=1.906
+ RS=0.6458 BV=110 IBV=0.0001
+ CJO=0.7048p VJ=0.869 M=0.03
+ FC=0.5 TT=3.48n
+ id_max=0.2 bv_max=100)
.option warn=1
.op
.end
```

```text
$ ngspice -b limit.cir
Instance: d1 Model: d4148 Id=13.81 A at Vd=10 V has exceeded Id_max=0.2 A
a           1.000000e+01
v1#branch   -1.38145e+01
```

- **`.option warn=1`**: 부품이 한계 안에서 일하는지 살피는 검사를 켭니다. 적지 않으면 꺼져 있습니다
- **한계는 모델에 적는다**: `id_max`는 견디는 전류, `bv_max`는 거꾸로 걸 수 있는 전압입니다. 200mA와 100V는 Nexperia의 모델 파일 머리말에 적힌 값입니다
- **답은 바뀌지 않는다**: 13.8A는 그대로 나옵니다. 알림 한 줄이 더해질 뿐이고, 그 줄은 `has exceeded Id_max=0.2 A`로 끝납니다. 전원을 −105V로 바꾸면 `Vd=-105 V has exceeded Bv_max=100 V`라고 알립니다
- **부품마다 적을 수 있는 한계가 다르다**: 설명서에 따르면 다이오드에는 전류, 전력, 전압을, 트랜지스터에는 `ic_max`, `vce_max`, `pd_max` 같은 것을, 저항과 커패시터에는 `bv_max`를 적을 수 있습니다
- **적을 수 없는 한계는 눈으로 견준다**: 저항이 견디는 전력은 검사해 주지 않습니다. 소자의 표에 나오는 `p`를 부품의 정격과 견줍니다([「첫 넷리스트: 전압 분배기」](#/read/circuit-sim/nl-first))

## 맞춘 조건 밖에서는 틀린다

```spice
LED 모델 둘: 온도를 바꿔 가며 돌리기
V1 vcc 0 3.3
R1 vcc a 330
D1 a 0 RED
R2 vcc b 330
D2 b 0 RED2
.model RED D(IS=1e-18 N=1.9 RS=5)
.model RED2 D(IS=1e-18 N=1.9 RS=5
+ EG=2.3)
.dc temp -20 80 50
.print dc v(a) v(b)
.end
```

```text
$ ngspice -b ledtemp.cir
Index temp-sweep v(a) v(b)
0 -2.00000e+01 1.705954e+00 1.884658e+00
1 3.000000e+01 1.800579e+00 1.789096e+00
2 8.000000e+01 1.891586e+00 1.692041e+00
```

- **`RED`는 이 책이 3장에서 고른 모델이다**: 27°C에서 2V 가까이에 켜지도록 숫자 셋만 골랐습니다. 이 모델은 더워질수록 전압이 올라갑니다. −20°C에서 1.706V, 80°C에서 1.892V입니다
- **실제 LED는 반대다**: 온도가 오르면 순방향 전압이 내려갑니다. ROHM의 안내에는 1°C에 2mV쯤이라고 적혀 있습니다
- **까닭은 적지 않은 숫자다**: 온도에 따른 변화를 정하는 `EG`를 적지 않아서 실리콘의 값인 1.11이 쓰였습니다([「다이오드와 .model」](#/read/circuit-sim/dv-diode))
- **`EG=2.3`을 더한 `RED2`**: 80°C에서 1.692V로 내려갑니다. 100°C에 0.19V, 곧 1°C에 1.9mV입니다. 27°C에서의 답은 두 모델이 똑같이 1.794740V입니다
- **모델은 맞춰 본 곳에서만 믿는다**: 상온의 한 점에 맞춘 모델로 온도, 큰 전류, 빠른 변화를 물으면 틀린 답이 그럴듯한 숫자로 나옵니다. 제조사의 모델도 무엇에 맞췄는지를 파일의 머리말에서 읽습니다

## 그 밖에 숨은 것

- **`E` 한 줄로 흉내 낸 연산 증폭기**: 3.3V 전원으로 5.5V를 냈습니다. 전원의 범위와 속도는 부품의 모델에만 들어 있습니다([「연산 증폭기: 이상적 모델과 부품 모델」](#/read/circuit-sim/dv-opamp))
- **선과 접지**: 넷리스트의 마디는 한 점입니다. 실제 선의 인덕턴스가 만드는 울림은 그려 넣어야 나타납니다([「링잉과 오버슈트」](#/read/scope/sh-ringing))
- **코일의 저항**: 4장의 릴레이는 코일의 70Ω을 저항 하나로 따로 적었습니다. 인덕터와 커패시터에 딸린 저항은 이렇게 소자를 더해 적습니다([「트랜지스터 스위치」](#/read/circuit-sim/dv-bjt))
- **처음의 상태**: 과도 해석은 0초에 이미 자리를 잡은 회로에서 시작합니다. 전원이 올라오는 동안의 일은 전원을 `PULSE`로 그려야 보입니다([「과도 해석 (.tran)」](#/read/circuit-sim/an-tran))
- **부품마다의 차이**: 모델의 숫자는 대푯값 하나입니다. 다음 쪽에서 다룹니다([「부품 오차와 몬테카를로」](#/read/circuit-sim/ts-tolerance))

<Note>
넷리스트 셋은 ngspice 42로 돌린 결과이고, 저항을 82Ω, 47Ω, 10Ω으로 바꾼 경우, 전원을 −105V로 바꾼 경우, `.option warn=1`을 뺀 경우(알림이 나오지 않음), `EG`를 바꿔 가며 돌린 경우도 따로 돌려 확인했습니다. 175Ω은 규격의 한 점에서 제가 셈한 값이고, 실제 핀의 저항은 이보다 작을 수 있습니다. `EG=2.3`은 1°C에 2mV쯤 내려가도록 제가 맞춘 숫자이고 재료의 값이 아닙니다. LED가 온도에 따라 내려가는 정도는 부품마다 다릅니다. 출력의 빈칸은 화면에 맞게 줄였습니다.
</Note>

## 정리

- 넷리스트에 적지 않은 것은 셈에 없다. 전압원은 전류를 얼마든지 내고, 선에는 저항이 없다
- 모델은 한계를 모른다. `id_max` 같은 한계를 모델에 적고 `.option warn=1`을 켜면 넘었을 때 알려 준다
- 모델은 맞춰 본 조건에서만 맞다. 상온에 맞춘 LED 모델은 온도를 바꾸자 실제와 반대로 움직였다
