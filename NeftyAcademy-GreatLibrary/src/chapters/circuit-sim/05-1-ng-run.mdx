지금까지는 `ngspice -b 파일`이라고만 쳤습니다. 이 장은 ngspice라는 프로그램 자체를 다룹니다. 먼저 돌리는 방식 셋과, 결과가 어디로 나오는지를 봅니다.

## 세 가지 방식

| 방식 | 치는 것 | 하는 일 |
| --- | --- | --- |
| 배치 | `ngspice -b 파일` | 점으로 시작하는 줄들을 끝까지 돌리고 빠져나온다 |
| 대화형 | `ngspice 파일` | 넷리스트를 읽고 나서 명령을 기다린다 |
| `.control` 블록 | 넷리스트 안에 명령을 적어 둔다 | 읽자마자 그 명령들을 차례로 한다 |

- **배치는 글을 받아 글을 낸다**: 결과를 남기고 견주기 좋습니다. 이 책이 지금까지 쓴 방식입니다
- **대화형은 회로를 이리저리 살필 때 쓴다**: 한 번 읽어 둔 회로에 여러 가지를 물어봅니다
- **`.control` 블록은 그 둘 사이다**: 대화형에서 칠 명령을 넷리스트에 적어 둔 것입니다. 다음 쪽에서 봅니다

## 배치: 출력이 가는 곳

```sh
ngspice -b divider.cir                    # 결과를 화면에
ngspice -b divider.cir -o out.log         # 결과와 경고를 파일에
ngspice -b rc.cir -r rc.raw               # 파형을 raw 파일에
ngspice -b divider.cir > out.txt 2> warn.txt
echo $?                                   # 끝난 값
```

```spice fails
뽑을 것을 적지 않은 과도 해석
V1 in 0 PULSE(0 3.3 0 1u 1u 1 2)
R1 in out 1k
C1 out 0 1u
.tran 10u 5m
.end
```

```text
$ ngspice -b silent.cir
Note: No ".plot", ".print", or ".fourier" lines; no simulations run
```

- **결과와 경고는 다른 길로 나온다**: 표와 `.meas`의 결과는 표준 출력으로, 경고는 표준 오류로 나옵니다. `>`와 `2>`로 따로 받을 수 있습니다
- **`-o 파일`**: 결과와 경고를 모두 그 파일에 적습니다. 화면에는 프로그램의 머리말만 남습니다
- **`-r 파일`**: 모든 마디의 파형을 raw 파일에 적습니다. 이때는 `.meas`를 쓸 수 없고, ngspice가 `No .measure possible in batch mode (-b) with -r rawfile set!`이라고 알려 줍니다
- **뽑을 것이 없으면 돌지 않는다**: `.op`는 스스로 표를 찍지만, `.tran`, `.ac`, `.dc`는 `.print`나 `.meas`가 있어야 돕니다. 위의 넷리스트는 아무것도 돌리지 않고 끝납니다
- **끝난 값은 반쯤만 믿는다**: 넷리스트를 읽지 못했거나 해석이 실패하면 1입니다. 그러나 경고가 나왔거나 `.meas`가 실패한 것만으로는 0입니다. 자동으로 돌릴 때는 끝난 값과 `Error`로 시작하는 줄을 함께 봅니다

## 대화형: 살펴보기

```text nocheck
$ ngspice divider.cir
ngspice 1 -> run
ngspice 2 -> display
Here are the vectors currently active:
Name: op1 (Operating Point)
    in                  : voltage, real, 1 long [default scale]
    out                 : voltage, real, 1 long
    v1#branch           : current, real, 1 long
ngspice 3 -> print v(out)
v(out) = 3.333333e+00
ngspice 4 -> print v(out)/v(in)
v(out)/v(in) = 6.666667e-01
ngspice 5 -> alter r2 = 10k
ngspice 6 -> run
ngspice 7 -> print v(out)
v(out) = 2.500000e+00
ngspice 8 -> quit
ngspice-42 done
```

- **`run`**: 넷리스트에 적힌 점 줄의 해석을 돌립니다. `op`, `tran 10u 5m`처럼 해석을 명령으로 바로 칠 수도 있습니다
- **`display`**: 지금 가진 결과의 목록입니다. 결과 하나하나를 벡터라고 부릅니다
- **`print`는 식을 받는다**: `v(out)/v(in)`처럼 벡터끼리 셈해서 찍습니다
- **`alter`로 값을 고치고 다시 돌린다**: 파일을 고치지 않고 `R2`를 10kΩ으로 바꿔 보았습니다. 2.5V가 되었습니다
- **그 밖에 자주 쓰는 것**: `show r1`은 소자의 표를, `listing`은 ngspice가 읽은 넷리스트를 보여 줍니다. `plot v(out)`은 그림 창을 띄웁니다([「파형을 파일로 내고 그리기」](#/read/circuit-sim/ng-plot))

## 다른 프로그램에서 부르기

```python
import os, re, subprocess, tempfile

NETLIST = """RC 충전: C = {c}
V1 in 0 PULSE(0 3.3 0 1u 1u 1 2)
R1 in out 1k
C1 out 0 {c}
.tran 10u 10m
.meas tran t63 WHEN v(out)=2.086
.end
"""

def t63(c):
    with tempfile.TemporaryDirectory() as d:
        path = os.path.join(d, "rc.cir")
        with open(path, "w", encoding="utf-8") as f:
            f.write(NETLIST.format(c=c))
        r = subprocess.run(["ngspice", "-b", path],
                           capture_output=True, text=True)
    out = r.stdout + r.stderr
    if r.returncode != 0 or re.search(r"^Error", out, re.M):
        raise RuntimeError(out[-300:])        # 끝난 값과 Error 줄을 함께 본다
    return float(re.search(r"^t63\s*=\s*(\S+)", r.stdout, re.M).group(1))

for c in ("470n", "1u", "2.2u"):
    print(f"C = {c:>4}: 63%에 닿는 시각 {t63(c) * 1e3:.4f}ms")
```

```text
C = 470n: 63%에 닿는 시각 0.4705ms
C =   1u: 63%에 닿는 시각 1.0005ms
C = 2.2u: 63%에 닿는 시각 2.2005ms
```

- **넷리스트는 글이고 결과도 글이다**: 그래서 셸 스크립트나 파이썬에서 넷리스트를 만들어 넘기고 결과를 읽어 올 수 있습니다
- **`.meas`의 줄이 읽기 쉽다**: `이름 = 값`의 꼴이라 한 줄짜리 정규식으로 뽑힙니다
- **실패를 놓치지 않게 한다**: 끝난 값이 0이어도 `.meas`가 실패했을 수 있으므로, `Error`로 시작하는 줄이 있는지도 봅니다

<Note>
배치의 옵션과 끝난 값, 대화형의 화면, 파이썬 프로그램은 모두 ngspice 42에서 직접 돌려 본 것입니다. 대화형의 화면은 제가 쓰는 환경에서 명령을 차례로 넣어 얻은 것이고, 프로그램의 머리말과 알림 몇 줄을 뺐습니다. 제 환경에는 화면이 없어서 `plot`으로 그림 창을 띄워 보지는 못했습니다.
</Note>

## 정리

- 배치는 `-b`로 끝까지 돌리고 빠져나오고, 대화형은 프롬프트에서 `run`, `print`, `alter` 같은 명령을 받는다
- 배치의 결과는 표준 출력, 경고는 표준 오류로 나온다. `-o`는 파일로 받고, `-r`은 파형을 raw 파일로 낸다
- 끝난 값이 0이어도 경고와 실패한 `.meas`가 있을 수 있다. 자동으로 돌릴 때는 `Error` 줄을 함께 확인한다
