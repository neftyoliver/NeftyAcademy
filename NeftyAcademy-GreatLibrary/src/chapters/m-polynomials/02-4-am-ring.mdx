다항식끼리 더하고, 빼고, 곱하면 다항식입니다. 나누면 다항식이 아닐 수 있습니다. 정수가 꼭 그랬습니다. 이 닮음에 이름을 붙여 두면, 정수에서 증명한 것을 다항식에서 다시 증명할 때 무엇을 그대로 쓰고 무엇을 바꿔야 하는지가 보입니다.

## 닫혀 있는 셈

| 셈 | 정수 | 다항식 |
| --- | --- | --- |
| 덧셈, 뺄셈, 곱셈 | 답이 늘 정수이다 | 답이 늘 다항식이다 |
| 나눗셈 | $7 \div 2$는 정수가 아니다 | $(x^2 + 1) \div x$는 다항식이 아니다 |

정수와 다항식은 덧셈, 뺄셈, 곱셈에 닫혀 있고 나눗셈에는 닫혀 있지 않습니다([「닫혀 있다는 것」](#/read/m-numbers/sys-closed)).

## 규칙 여덟 가지

체의 규칙 아홉 가운데 여덟이 다항식에서 성립합니다([「셈의 규칙 아홉 가지」](#/read/m-numbers/sys-rules)).

| 규칙 | 덧셈 | 곱셈 |
| --- | --- | --- |
| 결합법칙 | 성립한다 | 성립한다 |
| 교환법칙 | 성립한다 | 성립한다 |
| 해도 그대로인 것 | 0 | 1 |
| 되돌리는 것 | 부호를 모두 바꾼 식 | 없을 수 있다 |

여기에 분배법칙을 더해 여덟입니다. 빠진 하나가 곱셈을 되돌리는 것, 곧 역수입니다.

<Thm title="역수가 있는 다항식">
다항식 가운데 곱해서 1이 되는 짝이 있는 것은 0이 아닌 상수뿐입니다.
</Thm>

<Proof>

$fg = 1$이라고 합니다. $f$와 $g$는 0이 아니므로 곱의 차수는 두 차수의 합이고([「차수의 셈」](#/read/m-polynomials/am-degree)), 1의 차수는 0입니다. 차수는 0 이상이므로 더해서 0이 되려면 둘 다 0이어야 합니다. 곧 $f$는 0이 아닌 상수입니다. 거꾸로 0이 아닌 상수 $c$에는 역수 $\frac{1}{c}$이 있습니다.

</Proof>

$x$의 역수 $\frac{1}{x}$은 다항식이 아닙니다. 정수 가운데 역수도 정수인 것이 1과 $-1$뿐인 것과 같은 사정입니다.

<Def title="환">
덧셈과 곱셈에 닫혀 있고 위의 여덟 규칙이 성립하는 모임을 **환**이라고 합니다. 정수 전체가 환이고, 다항식 전체도 환입니다.
</Def>

- **체는 환이다**: 여덟 규칙에 역수까지 갖춘 것이 체입니다. 유리수와 실수는 체이면서 환입니다
- **환에서 증명한 것은 두 곳에서 다 쓴다**: 여덟 규칙만 써서 증명한 사실은 정수에서도 다항식에서도 참입니다([「환의 뜻과 예」](#/read/m-rings/ring))
- **적는 법**: 계수가 실수인 $x$의 다항식 전체를 $\mathbb{R}[x]$로 적습니다. 계수를 유리수나 정수로 좁히면 $\mathbb{Q}[x]$, $\mathbb{Z}[x]$입니다([「다항식환」](#/read/m-rings/polynomial))

## 나란히 놓기

| 견줄 것 | 정수 | 다항식 |
| --- | --- | --- |
| 크기 | 절댓값 | 차수 |
| 역수가 있는 것 | 1과 $-1$ | 0이 아닌 상수 |
| 더 쪼갤 수 없는 것 | 소수 | 기약다항식 |
| 나눗셈 | 몫과 나머지 | 몫과 나머지 |
| 분수로 넓히면 | 유리수 | 유리식 |

- **역수가 있는 것은 인수로 세지 않는다**: $6 = 2 \times 3 = (-2) \times (-3)$을 같은 분해로 치듯이, $2x + 2 = 2(x + 1)$의 상수 2는 인수로 세지 않습니다([「더 쪼갤 수 없는 식」](#/read/m-polynomials/fc-irreducible))
- **넓히는 방법도 같다**: 정수의 분수가 유리수이고, 다항식의 분수가 유리식입니다([「유리식」](#/read/m-polynomials/re-define))

## 계수의 줄을 곱하기

다항식을 계수의 줄로 담으면([「동류항 모으기: 덧셈과 뺄셈」](#/read/m-polynomials/am-add)) 곱셈은 두 줄의 수를 하나씩 모두 곱해서, 차수가 같은 자리에 모으는 것입니다.

```python
def mul(p, q):
    r = [0] * (len(p) + len(q) - 1)
    for i, a in enumerate(p):
        for j, b in enumerate(q):
            r[i + j] += a * b
    return r

print(mul([1, 2], [1, 3]))
print(mul([1, -2, 3], [1, 4]))
```

```text
[1, 5, 6]
[1, 2, -5, 12]
```

- **줄의 길이**: 길이가 $m + 1$과 $n + 1$인 줄을 곱하면 길이가 $m + n + 1$입니다. 차수가 더해진다는 것과 같은 말입니다
- **자리가 차수를 정한다**: 앞에서 $i$째와 $j$째를 곱한 것은 $i + j$째 자리에 모입니다. 넓이 표에서 동류항이 비스듬히 놓이던 것입니다([「곱셈: 분배법칙과 넓이」](#/read/m-polynomials/am-mul))
- **이 셈의 이름**: 두 줄을 이렇게 엇갈려 곱해 모으는 것을 합성곱이라고 합니다. 신호에 필터를 거는 셈이 이것입니다([「합성곱과 필터」](#/read/m-signals/convolution))
- **큰 수의 곱셈**: 자리 숫자의 줄을 이렇게 곱한 다음 받아올림을 하면 수의 곱셈입니다([「자릿값과 다항식」](#/read/m-polynomials/term-place))

## 계수를 바꾸면

계수로 쓰는 수를 바꾸면 같은 식도 다르게 움직입니다. 계수를 2로 나눈 나머지 0과 1로만 셈해 봅니다.

$$
(x + 1)^2 = x^2 + 2x + 1 = x^2 + 1
$$

$2x$의 계수 2가 나머지로는 0이어서 가운데 항이 사라집니다. 0과 1만 쓰는 이 다항식은 컴퓨터의 비트열과 꼭 맞아서, 통신의 오류를 찾는 부호에 쓰입니다([「순환 부호」](#/read/m-coding/cyclic)).

<Note>
파이썬 코드는 실제로 돌린 출력입니다. 정리는 계수가 $-2$부터 2까지인 이차 이하의 다항식의 모든 쌍에서, 곱이 0이 아닌 상수가 되는 것은 둘 다 상수일 때뿐임을 확인했습니다. 계수를 2로 나눈 나머지로 셈한 $(x + 1)^2 = x^2 + 1$도 프로그램으로 확인했습니다. 여기서 환이라고 부른 것은 곱셈의 교환법칙이 성립하고 1이 있는 환입니다. 대수학의 책에서는 행렬처럼 곱셈의 교환법칙이 없는 것도 환에 넣고, 이 쪽의 것을 가환환이라고 따로 부릅니다.
</Note>

## 요점

- 다항식은 정수처럼 덧셈, 뺄셈, 곱셈에 닫혀 있고 나눗셈에는 닫혀 있지 않다
- 체의 아홉 규칙 가운데 역수만 빠진 여덟이 성립하는 모임이 환이다. 역수가 있는 다항식은 0이 아닌 상수뿐이다
- 계수의 줄로 보면 다항식의 곱셈은 두 줄을 엇갈려 곱해 모으는 합성곱이다
