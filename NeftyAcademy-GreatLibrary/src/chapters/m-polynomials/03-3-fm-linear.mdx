$(x + 2)(x + 5)$를 전개하면 $x^2 + 7x + 10$입니다. 7은 2와 5의 합이고 10은 곱입니다. 일차식 둘의 곱에서는 계수에 합과 곱이 나타납니다. 이 무늬를 알아 두면 전개가 빨라지고, 거꾸로 이차식을 쪼갤 때의 열쇠가 됩니다.

## 합과 곱이 나타난다

<Figure caption="(x + a)(x + b). 가운데의 두 직사각형 ax와 bx를 모으면 (a + b)x입니다">
  <AreaModel rows={[10, 5]} cols={[10, 7]} rowLabels={['x', 'a']} colLabels={['x', 'b']} cells={[['x^2', 'b*x'], ['a*x', 'a*b']]} width={190} height={140} />
</Figure>

<Thm name="공식" title="일차식 둘의 곱">

$$
(x + a)(x + b) = x^2 + (a + b)x + ab
$$

</Thm>

- **$(x + 2)(x + 5)$**: 합이 7, 곱이 10이므로 $x^2 + 7x + 10$입니다
- **$(x - 3)(x + 4)$**: 합이 1, 곱이 $-12$이므로 $x^2 + x - 12$입니다
- **$(x - 2)(x - 6)$**: 합이 $-8$, 곱이 12이므로 $x^2 - 8x + 12$입니다

앞의 두 공식은 이 공식의 특별한 경우입니다. $b = a$이면 합의 제곱이고, $b = -a$이면 합과 차의 곱입니다([「합의 제곱과 차의 제곱」](#/read/m-polynomials/fm-square), [「합과 차의 곱」](#/read/m-polynomials/fm-diff)).

## 부호 읽기

| 상수항 | 일차항의 계수 | 두 수 $a$, $b$ |
| --- | --- | --- |
| 양 | 양 | 둘 다 양수 |
| 양 | 음 | 둘 다 음수 |
| 음 | 어느 쪽이든 | 부호가 서로 다르다 |

곱이 양수이면 두 수의 부호가 같고, 음수이면 다릅니다([「정수의 곱셈과 나눗셈」](#/read/m-numbers/int-mul)). 그래서 전개한 식만 보고도 두 수의 부호를 압니다. 인수분해할 때 이 표를 거꾸로 읽습니다([「이차식의 인수분해」](#/read/m-polynomials/fc-quadratic)).

## x의 계수가 1이 아닐 때

<Figure caption="(ax + b)(cx + d). 가운데 항은 엇갈린 두 곱 ad와 bc의 합입니다">
  <AreaModel rows={[10, 5]} cols={[10, 7]} rowLabels={['a*x', 'b']} colLabels={['c*x', 'd']} cells={[['a*c*x^2', 'a*d*x'], ['b*c*x', 'b*d']]} width={190} height={140} />
</Figure>

<Thm name="공식" title="계수가 있는 일차식의 곱">

$$
\begin{aligned}
&(ax + b)(cx + d) \\
&= acx^2 + (ad + bc)x + bd
\end{aligned}
$$

</Thm>

- **앞은 앞끼리, 뒤는 뒤끼리**: $x^2$의 계수는 $ac$이고 상수항은 $bd$입니다
- **가운데는 엇갈려 곱해 더한다**: 바깥쪽의 곱 $ad$와 안쪽의 곱 $bc$를 더합니다
- **보기**: $(2x + 1)(3x - 2)$에서 $x^2$의 계수는 $2 \times 3 = 6$, 가운데는 $2 \times (-2) + 1 \times 3 = -1$, 상수항은 $-2$입니다. 답은 $6x^2 - x - 2$입니다

## 암산에 쓰기

- **십의 자리가 같은 두 수**: $23 \times 27$은 $(20 + 3)(20 + 7)$이므로 $400 + 200 + 21 = 621$입니다
- **일의 자리의 합이 10이면**: 십의 자리 숫자가 $n$이고 일의 자리 숫자가 $a$와 $10 - a$인 두 수의 곱은 $100n(n + 1) + a(10 - a)$입니다. $64 \times 66$은 $6 \times 7 = 42$ 뒤에 $4 \times 6 = 24$를 붙인 4224입니다
- **5로 끝나는 수의 제곱**: 같은 규칙으로 $35^2$은 $3 \times 4 = 12$ 뒤에 25를 붙인 1225입니다

## 일차식 셋

$$
\begin{aligned}
&(x + a)(x + b)(x + c) \\
&= x^3 + (a + b + c)x^2 \\
&\quad + (ab + bc + ca)x + abc
\end{aligned}
$$

- **계수에 나타나는 것**: 하나씩 더한 것, 둘씩 곱해 더한 것, 셋을 모두 곱한 것이 차례로 나옵니다
- **보기**: $(x + 1)(x + 2)(x + 3)$을 전개하면 $x^3 + 6x^2 + 11x + 6$입니다. $1 + 2 + 3 = 6$, $2 + 6 + 3 = 11$, $1 \times 2 \times 3 = 6$입니다
- **근과 계수로 이어진다**: 식의 값을 0으로 만드는 수 $-a$, $-b$, $-c$와 계수 사이의 이 관계는 뒤에서 다시 나옵니다([「삼차 이상의 근과 계수」](#/read/m-polynomials/rt-vieta))

<Ex title="빠르게 전개하기">
$(x - 4)(x + 9)$와 $(3x - 2)(x + 5)$를 전개하세요.

<Sol>

첫째는 합이 5, 곱이 $-36$이므로 $x^2 + 5x - 36$입니다. 둘째는 $x^2$의 계수가 3, 가운데가 $3 \times 5 + (-2) \times 1 = 13$, 상수항이 $-10$이므로 $3x^2 + 13x - 10$입니다.

</Sol>
</Ex>

<Note>
세 공식은 문자마다 작은 정수를 모두 넣어 양쪽이 같은지 확인했습니다(문자가 셋이나 넷일 때 $-3$부터 3까지, 다섯일 때 $-2$부터 2까지). 본문의 전개 넷과 예제의 둘, 암산 셋은 프로그램으로 확인했습니다. 일의 자리의 합이 10인 두 수의 규칙은 $n$과 $a$가 1부터 9까지인 모든 경우에서 확인했습니다. 뒤에 붙이는 수는 두 자리로 적습니다. $21 \times 29 = 609$에서는 6 뒤에 09를 붙입니다.
</Note>

## 요점

- $(x + a)(x + b) = x^2 + (a + b)x + ab$이다. 일차항의 계수는 합이고 상수항은 곱이다
- 상수항과 일차항의 계수의 부호에서 두 수의 부호를 읽을 수 있다
- $x$의 계수가 1이 아니면 가운데 항은 엇갈린 두 곱을 더한 $ad + bc$이다
