UI에는 "접힌 패널"과 "펼친 패널", "보통 버튼"과 "눌린 버튼"처럼 몇 가지 **상태**가 있습니다. 상태마다 속성 값들이 다르고, 상태가 바뀔 때 값이 툭 바뀌기보다 부드럽게 움직이면 사용자가 무슨 일이 일어났는지 따라갈 수 있습니다. QML은 이것을 선언으로 적습니다. 상태마다 다른 값을 적어 두고, 상태 사이를 어떻게 움직일지 적어 두면, 나머지는 엔진이 합니다.

## 패널 키우고 되돌리기

```cpp qt=Quick
#include <QGuiApplication>
#include <QQmlApplicationEngine>
#include <QTimer>
#include <cstdio>

void toStdout(QtMsgType, const QMessageLogContext&, const QString& m) {
    std::printf("[console] %s\n", qPrintable(m));
}

int main(int argc, char** argv) {
    qInstallMessageHandler(toStdout);
    QGuiApplication app(argc, argv);
    QQmlApplicationEngine engine;
    engine.loadData(R"(
import QtQuick

Window {
    width: 300; height: 200; visible: true
    Rectangle {
        id: panel; objectName: "panel"
        width: 80; height: 80; x: 10; y: 10; color: "steelblue"
        state: "작게"                                  // 지금 상태의 이름
        states: [
            State { name: "작게" },
            State {
                name: "크게"
                PropertyChanges {
                    target: panel; width: 200; x: 50; color: "tomato"
                }
            }
        ]
        transitions: Transition {                      // 상태가 바뀔 때의 움직임
            NumberAnimation { properties: "width,x"; duration: 120
                              easing.type: Easing.OutCubic }
            ColorAnimation { duration: 120 }
            onRunningChanged: if (!running)
                console.log("전환 끝:", panel.state, "폭", panel.width,
                            "x", panel.x, "색", panel.color)
        }
        // y가 바뀔 때마다 부드럽게
        Behavior on y { NumberAnimation { duration: 80 } }
    }
}
)");
    QObject* win = engine.rootObjects().value(0);
    QObject* panel = win->findChild<QObject*>("panel");

    QTimer::singleShot(0, [&] {
        panel->setProperty("state", "크게");
        std::printf("상태를 '크게'로 바꾼 직후 폭 %.0f(아직 움직이는 중)\n",
                    panel->property("width").toDouble());
    });
    QTimer::singleShot(400, [&] {
        panel->setProperty("state", "작게");          // 되돌리면 원래 값으로
        panel->setProperty("y", 100.0);                // Behavior가 붙은 속성
        std::printf("y를 100으로 대입한 직후 y=%.0f\n",
                    panel->property("y").toDouble());
    });
    QTimer::singleShot(800, [&] {
        std::printf("나중에 y=%.0f\n", panel->property("y").toDouble());
        app.quit();
    });
    return app.exec();
}
```

```text
상태를 '크게'로 바꾼 직후 폭 80(아직 움직이는 중)
[console] 전환 끝: 크게 폭 200 x 50 색 #ff6347
y를 100으로 대입한 직후 y=10
[console] 전환 끝: 작게 폭 80 x 10 색 #4682b4
나중에 y=100
```

애니메이션 중간의 값은 실행할 때마다 조금씩 다르므로, 출력에는 시작 직후와 끝난 뒤의 값만 찍었습니다.

## 상태

- `states`에 이름 붙은 `State`들을 두고, 각 상태에서 바뀌는 값만 `PropertyChanges`로 적습니다. "크게" 상태는 폭 200, x 50, 토마토색입니다
- `state` 속성에 이름을 넣으면 그 상태가 됩니다. 기본 상태로 돌아가면 `PropertyChanges`가 바꿨던 값이 **원래대로** 돌아옵니다. "작게"로 바꾸자 폭 80, x 10, 강철색이 되었습니다. [「속성 바인딩」](#/read/cpp-qt/qml-binding)에서 본 대입과 달리 원래 바인딩을 깨지 않습니다
- 상태에 `when: mouseArea.pressed` 같은 조건을 주면, 조건이 참일 때 저절로 그 상태가 됩니다. 상태를 코드로 바꾸는 일조차 없어집니다

## 움직임

- **Transition**은 상태가 바뀔 때 어떤 속성을 어떻게 움직일지 정합니다. `NumberAnimation`이 폭과 x를 120ms 동안 `OutCubic` 이징으로, `ColorAnimation`이 색을 움직였습니다. 상태를 바꾼 직후 폭은 아직 80이었고, 전환이 끝난 뒤에야 200이 되었습니다
- **이징**(easing)은 시간에 따른 진행 곡선입니다. `OutCubic`은 빠르게 출발해 천천히 멈추어, 화면 요소가 자연스럽게 자리에 앉는 느낌을 줍니다. `Linear`, `InOutQuad`, `OutBack`(살짝 지나쳤다 돌아옴) 등이 있습니다
- **Behavior**는 상태와 상관없이 "이 속성이 바뀔 때마다 항상 이렇게 움직여라"입니다. y에 100을 대입한 직후에는 여전히 10이었고, 잠시 뒤 100이 되었습니다. 값은 즉시 대입되지 않고 애니메이션이 그 값을 향해 갑니다

<Note>
애니메이션은 화면이 새로 그려질 때마다(보통 60Hz, 화면의 주사율) 진행되는데, Qt Quick은 이것을 렌더 스레드와 GPU 위에서 처리하도록 설계되어 있어 위젯 기반 애니메이션보다 매끄럽습니다. 다만 애니메이션 도중에 자바스크립트 처리기나 C++ 슬롯이 오래 걸리면 프레임이 밀립니다. 애니메이션 중간값으로 테스트하지 말고, 예제처럼 끝난 뒤의 값이나 `running` 상태를 확인하세요.
</Note>

## 정리

- 상태는 이름 붙은 속성 값 묶음이고, PropertyChanges로 바뀌는 값만 적으며 기본 상태로 돌아가면 원래 값으로 돌아온다
- Transition은 상태 사이의 움직임을, Behavior는 한 속성이 바뀔 때마다의 움직임을 정하고, 이징으로 진행 곡선을 고른다
- 애니메이션 중에는 값이 목표를 향해 움직이므로, 끝난 뒤의 값과 running 상태로 확인한다
