QML은 화면을 **선언**하는 언어입니다. "사각형을 만들고, 색을 정하고, 부모에 붙여라" 같은 명령을 차례로 쓰는 대신, "이런 사각형이 이 안에 있고, 폭은 부모의 절반이다"라고 화면의 모양과 관계를 적습니다. 동작은 자바스크립트로 쓰고, 무거운 일은 C++에 맡깁니다. Qt Quick은 QML로 적은 화면을 GPU로 그리는 모듈입니다. 휴대폰 앱, 자동차 계기판, 매끄러운 애니메이션이 필요한 데스크톱 앱이 주로 QML로 만들어집니다.

## 장보기 목록

QML은 보통 `.qml` 파일에 쓰지만, 예제를 하나로 묶으려고 C++ 문자열로 넣고 `QQmlComponent`로 읽었습니다.

```cpp qt=Quick
#include <QGuiApplication>
#include <QQmlComponent>
#include <QQmlEngine>
#include <QQuickItem>
#include <cstdio>

// console.log는 Qt 로그로 나온다. 예제 출력에 함께 보이도록 표준 출력으로 돌린다
void toStdout(QtMsgType, const QMessageLogContext&, const QString& msg) {
    std::printf("[console] %s\n", qPrintable(msg));
}

int main(int argc, char** argv) {
    qInstallMessageHandler(toStdout);
    QGuiApplication app(argc, argv);
    QQmlEngine engine;
    QQmlComponent comp(&engine);
    // 보통은 .qml 파일에 두지만, 예제를 한 파일로 만들려고 문자열로 넣는다
    comp.setData(R"(
import QtQuick

Item {                                  // 객체 = 타입 이름 { 속성들, 자식들 }
    id: root                            // id: 같은 파일 안에서 부르는 이름
    width: 300; height: 120
    property string title: "장보기"     // 새 속성 선언
    property int done: 0
    signal finished(int total)          // 새 시그널 선언

    function check() {                  // 자바스크립트 함수
        done += 1
        console.log("체크", done)
        if (done === list.count) finished(done)
    }

    component Badge: Rectangle {        // 이 파일 안에서만 쓰는 작은 부품
        property alias text: label.text
        width: 60; height: 24; radius: 12; color: "#e0e7ff"
        Text { id: label; anchors.centerIn: parent }
    }

    Badge { id: badge; objectName: "badge"; text: root.done + "/" + list.count }

    Repeater {                          // 모델 수만큼 자식을 만든다
        id: list
        model: ["우유", "달걀", "빵"]
        Text { text: (index + 1) + ". " + modelData; y: 30 + index * 20 }
    }

    onFinished: (total) => console.log("다 샀다:", total, "개")   // 시그널 처리기
    Component.onCompleted: console.log(title, "준비, 항목", list.count, "개")
}
)", QUrl("shopping.qml"));
    QObject* root = comp.create();
    if (!root) { std::printf("%s\n", qPrintable(comp.errorString())); return 1; }

    auto* badge = root->findChild<QObject*>("badge");
    std::printf("배지 글: %s\n", qPrintable(badge->property("text").toString()));
    for (int i = 0; i < 3; ++i) QMetaObject::invokeMethod(root, "check");
    std::printf("배지 글: %s\n", qPrintable(badge->property("text").toString()));
    delete root;
}
```

```text
[console] 장보기 준비, 항목 3 개
배지 글: 0/3
[console] 체크 1
[console] 체크 2
[console] 체크 3
[console] 다 샀다: 3 개
배지 글: 3/3
```

## 문법 조각들

- **객체**: `Item { ... }`처럼 타입 이름 뒤 중괄호 안에 속성과 자식을 씁니다. 안에 쓴 객체는 바깥 객체의 자식이 되어, 위젯의 부모·자식처럼 함께 그려지고 함께 사라집니다
- **id**: 같은 파일 안에서 객체를 부르는 이름입니다. `root.done`, `list.count`처럼 씁니다. id는 속성이 아니라서 바깥에서는 보이지 않습니다. C++에서 찾으려고 `objectName`을 따로 주었습니다
- **새 속성과 시그널**: `property string title`, `signal finished(int total)`로 선언합니다. QML에서 선언한 속성은 자동으로 `titleChanged` 같은 알림 시그널을 가집니다
- **함수**: `function check()` 안은 자바스크립트입니다. C++에서 `invokeMethod(root, "check")`로 불렀습니다. [「moc가 하는 일」](#/read/cpp-qt/obj-moc)의 메타 객체 정보가 QML 객체에도 똑같이 있기 때문입니다
- **시그널 처리기**: 시그널 `finished`에는 `onFinished` 처리기가 짝지어집니다. 인자는 `(total) => ...`처럼 함수 매개변수로 받는 것이 Qt 6의 권장 문법입니다. `Component.onCompleted`는 객체가 다 만들어졌을 때 한 번 불립니다

## 부품 만들기

- **인라인 컴포넌트**: `component Badge: Rectangle { ... }`는 그 파일 안에서 쓰는 작은 부품 타입을 만듭니다. 여러 파일에서 쓰려면 `Badge.qml` 파일로 빼면 파일 이름이 곧 타입 이름이 됩니다
- **alias**: `property alias text: label.text`는 안쪽 `Text`의 속성을 부품 바깥으로 내놓습니다. 부품을 쓰는 쪽은 `Badge { text: ... }`처럼 쓰고, 안의 구조는 몰라도 됩니다
- **Repeater**: 모델의 항목 수만큼 자식을 만듭니다. 각 자식 안에서는 `index`와 `modelData`로 자기 번호와 값을 압니다

배지의 글 `root.done + "/" + list.count`는 **바인딩**입니다. 한 번 계산하고 끝나는 대입이 아니라, `done`이 바뀔 때마다 다시 계산됩니다. 그래서 `check()`를 세 번 부르자 "0/3"이 "3/3"이 되었습니다. 이것이 QML의 핵심이고, 다음 장 [「속성 바인딩」](#/read/cpp-qt/qml-binding)의 주제입니다.

<Note>
`import QtQuick`처럼 판 번호 없이 가져오는 문법은 Qt 6부터입니다. Qt 5의 예제는 `import QtQuick 2.15`처럼 판을 붙이는데, Qt 6에서도 동작하지만 새 코드에서는 생략합니다. QML 파일은 `qmllint`로 검사하고 `qmlformat`으로 정리할 수 있습니다.
</Note>

## 정리

- QML은 객체 나무와 속성으로 화면을 선언하고, id로 같은 파일의 객체를 부르며, 동작은 자바스크립트로 쓴다
- property, signal, function으로 새 속성·시그널·함수를 선언하고, onXxx 처리기로 시그널에 반응한다
- 인라인 컴포넌트나 .qml 파일로 부품을 만들고 alias로 안쪽 속성을 내놓으며, 속성 값의 식은 바뀔 때마다 다시 계산되는 바인딩이다
