Qt의 문자열 `QString`은 유니코드 문자열입니다. 화면에 보이는 모든 글, 파일 이름, 설정 값이 `QString`으로 오갑니다. 안을 UTF-16으로 저장하기 때문에, `std::string`(보통 UTF-8 바이트)과는 길이를 세는 방법부터 다릅니다. 한글과 이모지가 섞인 글을 다루면 이 차이가 바로 드러납니다.

## 길이, 정규화, 서식

```cpp qt
#include <QCoreApplication>
#include <QLocale>
#include <QString>
#include <QStringView>
#include <QTextBoundaryFinder>
#include <cstdio>

int graphemes(const QString& s) {           // 사람이 보는 '글자' 수
    QTextBoundaryFinder f(QTextBoundaryFinder::Grapheme, s);
    int n = 0;
    while (f.toNextBoundary() != -1) ++n;
    return n;
}

int main(int argc, char** argv) {
    QCoreApplication app(argc, argv);
    QString hello = QStringLiteral("안녕 👋🏽");
    std::printf("'%s': length %lld(UTF-16 단위), UTF-8 %lld바이트, 글자 %d개\n",
                qPrintable(hello), (long long)hello.length(),
                (long long)hello.toUtf8().size(), graphemes(hello));

    // 한글은 완성형(NFC)과 풀어쓴 자모(NFD) 두 가지로 저장될 수 있다
    QString nfc = QStringLiteral("한글");
    QString nfd = nfc.normalized(QString::NormalizationForm_D);
    bool fixed = nfc == nfd.normalized(QString::NormalizationForm_C);
    std::printf("NFC 길이 %lld, NFD 길이 %lld, 그대로 같은가 %s, NFC로 맞추면 %s\n",
                (long long)nfc.length(), (long long)nfd.length(),
                nfc == nfd ? "예" : "아니오", fixed ? "같다" : "다르다");

    // 번역 가능한 서식: 자리 번호로 순서를 바꿀 수 있다
    QString msg = QString("%1님이 파일 %2개를 올렸습니다").arg("네프티").arg(3);
    std::printf("%s\n", qPrintable(msg));

    // 숫자를 글로: 로캘에 맞게
    double big = 1234567.891;
    std::printf("C %s / 한국 %s / 독일 %s\n",
                qPrintable(QLocale::c().toString(big, 'f', 2)),
                qPrintable(QLocale(QLocale::Korean).toString(big, 'f', 2)),
                qPrintable(QLocale(QLocale::German).toString(big, 'f', 2)));

    // 복사 없이 잘라 보기: QStringView
    QString line = "key = value ; comment";
    QStringView v(line);
    QStringView key = v.left(v.indexOf(u'=')).trimmed();
    QStringView rest = v.mid(v.indexOf(u'=') + 1);
    QStringView val = rest.left(rest.indexOf(u';')).trimmed();
    std::printf("키 '%s', 값 '%s'\n",
                qPrintable(key.toString()), qPrintable(val.toString()));

    // 대소문자 무시 비교와 분할
    bool same = QString("Qt").compare("qt", Qt::CaseInsensitive) == 0;
    std::printf("Qt == qt (대소문자 무시): %s\n", same ? "예" : "아니오");
    QStringList parts = QString("a,,b,c").split(',', Qt::SkipEmptyParts);
    std::printf("나누기: %s\n", qPrintable(parts.join(" | ")));
}
```

```text
NFC 길이 2, NFD 길이 6, 그대로 같은가 아니오, NFC로 맞추면 같다
네프티님이 파일 3개를 올렸습니다
C 1234567.89 / 한국 1,234,567.89 / 독일 1.234.567,89
키 'key', 값 'value'
Qt == qt (대소문자 무시): 예
나누기: a | b | c
```

## 길이는 세 가지다

"안녕 👋🏽"는 사람 눈에 네 글자(안, 녕, 빈칸, 손 흔드는 이모지)입니다. 그런데 `length()`는 7, UTF-8로는 15바이트였습니다.

- `QString::length()`는 **UTF-16 단위** 수입니다. 한글 음절과 빈칸은 1단위씩이지만, 이모지 👋는 BMP 밖의 문자라서 2단위(서로게이트 쌍), 피부색 수식자 🏽도 2단위입니다
- UTF-8로 바꾸면(`toUtf8()`) 한글 한 음절이 3바이트, 이모지는 4바이트씩입니다. 파일이나 네트워크로 보낼 때의 크기는 이것입니다
- 사람이 보는 **글자**(grapheme cluster)는 `QTextBoundaryFinder`로 셉니다. 커서를 한 칸 옮기거나 글자 수 제한을 둘 때는 이것을 써야 이모지를 반으로 자르지 않습니다

## 한글 정규화

같은 "한글"도 완성형 음절 두 개(NFC)로 저장될 수도, 자모 여섯 개(ㅎ ㅏ ㄴ ㄱ ㅡ ㄹ, NFD)로 저장될 수도 있습니다. 화면에는 똑같이 보이지만 `==`로 비교하면 **다르다**고 나옵니다. macOS의 파일 시스템이 파일 이름을 NFD에 가깝게 돌려주는 경우가 있어서, 윈도우에서 만든 "보고서.txt"와 맥에서 읽은 이름이 비교에 실패하는 일이 실제로 생깁니다. 사용자 입력이나 파일 이름을 비교하거나 검색하기 전에는 `normalized(QString::NormalizationForm_C)`로 맞추세요.

## 서식과 로캘

- `QString("%1님이 파일 %2개를").arg("네프티").arg(3)`처럼 자리 번호로 끼워 넣습니다. 번역할 때 언어마다 어순이 달라도 번호로 순서를 바꿀 수 있어서 `+`로 이어 붙이기보다 낫습니다. [「tr과 번역 파일」](#/read/cpp-qt/i18n-tr)에서 다시 봅니다
- 숫자를 사람에게 보여 줄 때는 `QLocale`로 바꿉니다. 같은 수가 한국에서는 "1,234,567.89", 독일에서는 "1.234.567,89"입니다. 반대로 파일 형식이나 프로토콜에 쓸 숫자는 `QLocale::c()`나 `QString::number`로 언제나 같은 모양을 씁니다

## 복사 없이 보기

`QStringView`는 문자열의 일부를 복사하지 않고 가리키는 가벼운 보기입니다. "key = value ; comment"에서 키와 값을 잘라 내는 동안 새 문자열을 만들지 않았습니다. 함수 매개변수로 `QStringView`를 받으면 `QString`, 문자열 리터럴(`u"..."`), 다른 보기 무엇이든 복사 없이 받을 수 있습니다. 다만 [「컨테이너와 암시적 공유」](#/read/cpp-qt/core-containers)의 `QString`과 달리 원본이 사라지면 보기도 무효가 되므로, 보관할 때는 `toString()`으로 복사합니다.

<Note>
`std::string`과 오갈 때는 인코딩을 분명히 하세요. `QString::fromStdString`과 `toStdString`은 UTF-8을 가정합니다. Windows API처럼 UTF-16을 쓰는 곳에는 `toStdWString`이나 `utf16()`을 씁니다. 예제의 `qPrintable`은 현재 로캘의 8비트 인코딩으로 바꾸는 디버깅용 도구입니다.
</Note>

## 정리

- QString은 UTF-16으로 저장되어 length는 UTF-16 단위 수이고, 사람이 보는 글자 수는 QTextBoundaryFinder로 센다
- 같은 한글도 NFC와 NFD가 있어 비교 전에 정규화해야 한다
- 서식은 arg의 자리 번호로, 사람에게 보일 숫자는 QLocale로 바꾸며, QStringView로 복사 없이 문자열 일부를 다룬다
