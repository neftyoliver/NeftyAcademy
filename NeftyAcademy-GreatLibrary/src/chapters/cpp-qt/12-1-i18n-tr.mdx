앱을 여러 언어로 내려면, 화면에 보이는 글을 코드에 박아 두지 않고 **번역 가능**하게 만들어야 합니다. Qt의 방식은 이렇습니다. 원문(보통 영어)을 `tr()`로 감싸 두면, 도구가 그 글들을 뽑아 번역 파일을 만들고, 번역가가 채운 파일을 앱이 실행 중에 불러와 `tr()`이 번역을 돌려주게 합니다.

## 업로드 알림 번역하기

```cpp qt
#include <QCoreApplication>
#include <QFile>
#include <QProcess>
#include <QTemporaryDir>
#include <QTranslator>
#include <cstdio>

class Uploader : public QObject {
    Q_OBJECT
public:
    QString status(int n, const QString& who) const {
        // 번역할 글은 tr()로 감싼다. %n은 개수(복수형), %1은 끼워 넣을 값
        return tr("%1 uploaded %n file(s)", nullptr, n).arg(who);
    }
    QString title() const { return tr("Upload"); }
    QString hint() const { return tr("Drop files here"); }   // 번역이 없는 글
};

// 번역가가 Qt Linguist로 채운 .ts 파일(보통은 lupdate가 소스에서 뽑아 만든다)
const char* ts = R"(<?xml version="1.0" encoding="utf-8"?>
<!DOCTYPE TS>
<TS version="2.1" language="ko_KR">
<context>
    <name>Uploader</name>
    <message numerus="yes">
        <source>%1 uploaded %n file(s)</source>
        <translation>
            <numerusform>%1님이 파일 %n개를 올렸습니다</numerusform>
        </translation>
    </message>
    <message>
        <source>Upload</source>
        <translation>올리기</translation>
    </message>
</context>
</TS>
)";

int main(int argc, char** argv) {
    QCoreApplication app(argc, argv);
    Uploader u;
    std::printf("번역 전: %s / %s / %s\n", qPrintable(u.title()),
                qPrintable(u.status(1, "Nefty")), qPrintable(u.status(3, "Nefty")));

    QTemporaryDir dir;
    QFile f(dir.filePath("app_ko.ts"));
    f.open(QIODevice::WriteOnly);
    f.write(ts);
    f.close();
    // lrelease: .ts(XML) -> .qm(앱이 읽는 이진 파일)
    QProcess::execute("/usr/lib/qt6/bin/lrelease",
                      {"-silent", dir.filePath("app_ko.ts"),
                       "-qm", dir.filePath("app_ko.qm")});

    QTranslator translator;
    if (!translator.load("app_ko", dir.path())) return 1;
    app.installTranslator(&translator);        // 이후의 모든 tr()에 적용된다

    std::printf("번역 후: %s\n", qPrintable(u.title()));
    for (int n : {1, 3}) std::printf("  %s\n", qPrintable(u.status(n, "네프티")));
    std::printf("번역이 없는 글은 원문: %s\n", qPrintable(u.hint()));
}
#include "main.moc"
```

```text
번역 전: Upload / Nefty uploaded 1 file(s) / Nefty uploaded 3 file(s)
번역 후: 올리기
  네프티님이 파일 1개를 올렸습니다
  네프티님이 파일 3개를 올렸습니다
번역이 없는 글은 원문: Drop files here
```

예제는 한 파일로 만들려고 `.ts` 내용을 문자열로 넣고, 실행 중에 `lrelease`를 불러 `.qm`을 만들었습니다. 실제로는 빌드 과정에서 만듭니다.

## 코드 쪽

- **tr()**: `QObject`를 상속한 클래스 안에서 `tr("Upload")`처럼 씁니다. 클래스 이름이 번역의 **문맥**이 되어, 같은 "Open"이라도 메뉴와 대화 상자에서 다르게 번역할 수 있습니다. QObject 밖에서는 `QCoreApplication::translate("문맥", "글")`을, QML에서는 `qsTr("Upload")`를 씁니다
- **복수형**: `tr("%1 uploaded %n file(s)", nullptr, n)`처럼 세 번째 인자로 개수를 주면 `%n`이 그 수가 되고, 언어마다 다른 복수형 규칙에 맞는 번역이 골라집니다. 영어는 단수·복수 두 꼴, 한국어는 한 꼴, 폴란드어나 러시아어는 셋 이상입니다. "file(s)"처럼 얼버무리지 않고 번역가가 정확한 꼴을 채울 수 있습니다
- **자리표시자**: `%1`은 `.arg()`로 끼울 값입니다. 번역문에서 순서를 바꿀 수 있습니다. 한국어 번역은 "%1님이 파일 %n개를"처럼 어순이 바뀌었습니다. 글을 `+`로 이어 붙이면 이것이 불가능하므로 절대 하지 않습니다

## 번역 흐름

1. **lupdate**가 소스(C++과 QML)에서 `tr()`, `qsTr()`의 글을 뽑아 언어별 `.ts` 파일(XML)을 만들거나 갱신합니다. 이미 번역된 글은 남기고, 바뀐 원문은 "확인 필요"로 표시합니다
2. 번역가는 **Qt Linguist**로 `.ts`를 열어 번역을 채웁니다. 문맥, 원문이 있는 소스 위치, 복수형 칸을 보여 줍니다
3. **lrelease**가 `.ts`를 앱이 빨리 읽는 이진 `.qm`으로 바꿉니다
4. 앱은 시작할 때 `QTranslator::load`로 `.qm`을 불러 `installTranslator`합니다. 그 뒤의 모든 `tr()`이 번역을 돌려줍니다. 번역이 없는 글("Drop files here")은 원문 그대로 나옵니다

CMake에서는 `qt_add_translations(app TS_FILES app_ko.ts app_ja.ts)`가 1번과 3번을 빌드 대상으로 만들고, `.qm`을 자원에 넣어 줍니다.

<Note>
사용자가 실행 중에 언어를 바꾸면, 이미 화면에 그려진 글은 저절로 바뀌지 않습니다. 위젯은 `QEvent::LanguageChange` 이벤트를 받아 글을 다시 설정해야 하고(Qt Designer가 만든 `retranslateUi()`가 이 일을 함), QML은 `QQmlEngine::retranslate()`를 부르면 `qsTr` 바인딩이 다시 계산됩니다. 날짜, 숫자, 통화 형식은 번역이 아니라 [「로캘」](#/read/cpp-qt/i18n-locale)의 일입니다.
</Note>

## 정리

- 화면의 글은 tr이나 qsTr로 감싸고, 클래스 이름이 번역 문맥이 된다
- 개수는 %n과 복수형 인자로, 끼울 값은 %1과 arg로 넘겨 언어마다 복수형과 어순을 바꿀 수 있게 한다
- lupdate로 .ts를 만들고 Linguist로 번역하고 lrelease로 .qm을 만들어 QTranslator로 불러온다
