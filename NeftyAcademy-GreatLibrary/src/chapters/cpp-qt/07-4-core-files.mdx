export const summary = '파일과 설정: QFile과 QTextStream, 안전한 저장 QSaveFile, QDir과 QFileInfo, QSettings, 표준 경로';

앱은 문서를 저장하고, 창 크기와 최근 파일 목록을 기억하고, 캐시를 둘 곳이 필요합니다. Qt는 이것들을 플랫폼과 상관없는 하나의 API로 제공합니다. 파일 경로의 구분자, 인코딩, "설정은 어디에 두는가" 같은 플랫폼 차이를 Qt가 흡수합니다.

## 메모 앱의 파일들

```cpp qt
#include <QCoreApplication>
#include <QDir>
#include <QFile>
#include <QFileInfo>
#include <QSaveFile>
#include <QSettings>
#include <QStandardPaths>
#include <QTemporaryDir>
#include <QTextStream>
#include <cstdio>

int main(int argc, char** argv) {
    QCoreApplication app(argc, argv);
    app.setOrganizationName("NeftyAcademy");  // 설정과 데이터 폴더 이름에 쓰인다
    app.setApplicationName("Notes");

    QTemporaryDir tmp;                         // 예제가 끝나면 지워지는 임시 폴더
    QDir dir(tmp.path());

    // 1) 글 쓰기: QSaveFile은 다 쓴 뒤에 한 번에 바꿔 끼운다
    {
        QSaveFile f(dir.filePath("메모.txt"));
        if (!f.open(QIODevice::WriteOnly | QIODevice::Text)) return 1;
        QTextStream out(&f);                   // Qt 6 기본 인코딩은 UTF-8
        out << "첫 줄\n" << "둘째 줄 " << 42 << "\n";
        if (!f.commit()) return 1;             // 여기서야 진짜 파일이 생긴다
    }
    // 2) 글 읽기: 한 줄씩
    QFile in(dir.filePath("메모.txt"));
    if (in.open(QIODevice::ReadOnly | QIODevice::Text)) {
        QTextStream s(&in);
        int n = 0;
        while (!s.atEnd()) std::printf("  %d: %s\n", ++n, qPrintable(s.readLine()));
    }
    // 3) 파일 정보와 폴더 훑기
    dir.mkpath("사진/2026");
    QFile(dir.filePath("사진/2026/a.jpg")).open(QIODevice::WriteOnly);
    QFileInfo info(dir.filePath("메모.txt"));
    std::printf("크기 %lld바이트, 확장자 %s\n", (long long)info.size(),
                qPrintable(info.suffix()));
    auto entries = dir.entryInfoList(QDir::NoDotAndDotDot | QDir::AllEntries,
                                     QDir::Name);
    for (const QFileInfo& e : entries)
        std::printf("  %s%s\n", qPrintable(e.fileName()), e.isDir() ? "/" : "");

    // 4) 설정: 키-값을 플랫폼에 맞는 곳에 저장한다(여기서는 INI 파일로)
    QString ini = dir.filePath("settings.ini");
    {
        QSettings s(ini, QSettings::IniFormat);
        s.setValue("window/width", 800);
        s.setValue("recent", QStringList{"a.txt", "b.txt"});
    }
    QSettings s(ini, QSettings::IniFormat);
    std::printf("설정: 폭 %d, 최근 %s, 없는 키는 기본값 %d\n",
                s.value("window/width").toInt(),
                qPrintable(s.value("recent").toStringList().join(",")),
                s.value("window/height", 600).toInt());

    // 5) 앱 데이터는 정해진 자리에: 경로는 플랫폼마다 다르다
    QString data =
        QStandardPaths::writableLocation(QStandardPaths::AppDataLocation);
    std::printf("앱 데이터 폴더 끝부분: %s\n",
                qPrintable(data.section('/', -2)));
}
```

```text
  1: 첫 줄
  2: 둘째 줄 42
크기 22바이트, 확장자 txt
  메모.txt
  사진/
설정: 폭 800, 최근 a.txt,b.txt, 없는 키는 기본값 600
앱 데이터 폴더 끝부분: NeftyAcademy/Notes
```

## 읽고 쓰기

- **QFile**은 파일을 열고 바이트를 읽고 씁니다. `QIODevice::Text`를 주면 줄 끝을 플랫폼에 맞게 바꿔 줍니다(Windows의 `\r\n`). 열기는 실패할 수 있으므로 반환값을 꼭 확인합니다
- **QTextStream**은 그 위에서 글과 숫자를 읽고 씁니다. Qt 6에서는 기본 인코딩이 **UTF-8**이라, 한글이 든 "첫 줄\n둘째 줄 42\n"이 22바이트가 되었습니다. 이진 데이터는 `QDataStream`이나 `QFile::write`로 다룹니다
- **QSaveFile**은 임시 파일에 다 쓴 다음 `commit()`에서 원래 파일과 한 번에 바꿔 끼웁니다. 저장하는 도중에 프로그램이 죽거나 디스크가 꽉 차도, 사용자의 원래 문서는 반쯤 쓴 상태로 망가지지 않습니다. 문서 저장에는 늘 이것을 쓰세요

## 폴더와 정보

- **QDir**은 폴더를 만들고(`mkpath`는 중간 폴더까지), 훑고, 경로를 이어 붙입니다(`filePath`). 경로는 어느 플랫폼에서든 `/`로 써도 됩니다. 사용자에게 보여 줄 때만 `QDir::toNativeSeparators`로 바꿉니다
- **QFileInfo**는 크기, 확장자, 수정 시각, 폴더인지 여부 같은 정보를 줍니다. 예제는 임시 폴더를 이름순으로 훑어 파일과 폴더를 구분해 찍었습니다
- **QTemporaryDir**와 `QTemporaryFile`은 겹치지 않는 이름의 임시 자리를 만들고, 객체가 사라질 때 지웁니다. 테스트에 특히 유용합니다

## 설정

**QSettings**는 키-값 설정 저장소입니다. 기본 생성자는 플랫폼의 관례를 따라 Windows는 레지스트리, macOS는 plist 파일, Linux는 `~/.config/조직/앱.conf`에 저장합니다. 예제는 위치를 정해 INI 형식으로 썼습니다. `window/width`처럼 `/`로 묶음을 만들고, 문자열 목록도 그대로 저장되며, 없는 키는 `value(키, 기본값)`의 기본값이 나옵니다. [「메인 윈도우, 메뉴, 도구 모음, 도킹」](#/read/cpp-qt/wid-mainwindow)의 `saveState()` 결과를 여기에 저장하면 창 배치가 다음 실행에도 남습니다.

## 표준 경로

데이터를 어디에 둘지 직접 정하지 말고 `QStandardPaths`에 물어보세요. `AppDataLocation`은 앱 데이터, `CacheLocation`은 지워도 되는 캐시, `DocumentsLocation`은 사용자의 문서 폴더입니다. 실제 경로는 플랫폼마다 다르지만, 조직 이름과 앱 이름(`setOrganizationName`, `setApplicationName`)으로 끝나는 것은 같습니다. 이 환경에서는 `…/NeftyAcademy/Notes`였습니다. 쓰기 전에 `QDir().mkpath(경로)`로 폴더를 만들어야 합니다.

<Note>
안드로이드와 iOS에서는 앱이 자기 데이터 폴더 밖의 파일에 마음대로 접근할 수 없습니다. 사용자가 고른 파일은 `QFileDialog`가 돌려주는 `content://` 같은 URL로 와서, 보통의 파일 경로처럼 다룰 수 없는 경우가 있습니다. 모바일을 생각한다면 경로를 직접 만들지 말고 `QStandardPaths`와 대화 상자의 결과를 그대로 쓰세요.
</Note>

## 정리

- QFile과 QTextStream으로 글을 읽고 쓰며 Qt 6의 기본 인코딩은 UTF-8이고, 문서 저장은 QSaveFile로 원자적으로 한다
- QDir과 QFileInfo로 폴더를 만들고 훑고 정보를 얻으며, 경로는 /로 써도 된다
- 설정은 QSettings에, 앱 데이터와 캐시는 QStandardPaths가 알려 주는 플랫폼별 자리에 둔다
