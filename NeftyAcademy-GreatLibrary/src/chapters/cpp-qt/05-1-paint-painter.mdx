Qt의 2D 그리기는 모두 `QPainter` 하나로 합니다. 그릴 대상은 `QImage`, 위젯, PDF 파일(`QPdfWriter`), 프린터, SVG 생성기 등 무엇이든 될 수 있고, 그리는 코드는 같습니다. 직접 만든 위젯도, 앞 장의 델리게이트도, 차트 라이브러리도 결국 이 API로 그립니다.

## 이미지에 그리고 확인하기

```cpp qt=Gui
#include <QGuiApplication>
#include <QImage>
#include <QPainter>
#include <QPainterPath>
#include <cstdio>

QString at(const QImage& img, int x, int y) { return img.pixelColor(x, y).name(); }

int main(int argc, char** argv) {
    QGuiApplication app(argc, argv);
    QImage img(200, 120, QImage::Format_ARGB32_Premultiplied);
    img.fill(Qt::white);

    // 그릴 대상: 이미지, 위젯, PDF, 프린터
    QPainter p(&img);
    // 1) 붓(채우기)과 펜(선)
    p.setPen(QPen(QColor("#1d4ed8"), 4));
    p.setBrush(QColor("#fde68a"));
    p.drawRect(10, 10, 60, 40);                // 채운 사각형 + 4px 테두리

    // 2) 좌표 변환: save/restore 사이에서만 유효하다
    p.save();
    p.translate(140, 40);                      // 원점을 옮기고
    p.rotate(45);                              // 돌린 좌표계에서
    p.setPen(Qt::NoPen);
    p.setBrush(QColor("#dc2626"));
    p.drawRect(-15, -15, 30, 30);              // 원점 중심 사각형 = 마름모
    p.restore();

    // 3) 경로: 선과 곡선을 이어 하나의 모양으로
    QPainterPath path;
    path.moveTo(20, 110);
    path.cubicTo(60, 60, 100, 160, 180, 90);
    p.setRenderHint(QPainter::Antialiasing);   // 가장자리를 부드럽게
    p.setPen(QPen(QColor("#16a34a"), 3));
    p.setBrush(Qt::NoBrush);
    p.drawPath(path);
    p.end();                                   // 그리기 끝(소멸자도 한다)

    std::printf("사각형 안 (40,30) %s, 테두리 (10,30) %s\n",
                qPrintable(at(img, 40, 30)), qPrintable(at(img, 10, 30)));
    std::printf("마름모 중심 (140,40) %s, 회전 전 모서리였던 (126,26) %s\n",
                qPrintable(at(img, 140, 40)), qPrintable(at(img, 126, 26)));
    QPointF mid = path.pointAtPercent(0.5);
    std::printf("곡선의 가운데 (%.0f,%.0f) %s\n", mid.x(), mid.y(),
                qPrintable(at(img, int(mid.x()), int(mid.y()))));
}
```

```text
사각형 안 (40,30) #fde68a, 테두리 (10,30) #1d4ed8
마름모 중심 (140,40) #dc2626, 회전 전 모서리였던 (126,26) #ffffff
곡선의 가운데 (85,108) #16a34a
```

## 펜과 붓

`QPainter`는 상태를 가진 그리기 도구입니다. **펜**(`setPen`)은 선과 테두리의 색, 두께, 모양(점선 등)을, **붓**(`setBrush`)은 안을 채우는 색이나 무늬, 그러데이션을 정합니다. `drawRect`는 붓으로 채우고 펜으로 테두리를 그립니다. 펜 두께 4는 사각형의 경계선을 가운데로 양쪽에 2씩 걸치므로, x=10 위치는 테두리 색이었습니다. 채우기만 하려면 `Qt::NoPen`, 선만 그리려면 `Qt::NoBrush`를 씁니다.

## 좌표 변환

빨간 사각형은 "원점을 (140, 40)으로 옮기고 45도 돌린 좌표계에서, 원점을 중심으로 한 30×30 사각형"으로 그렸습니다. 그래서 화면에는 마름모가 되었고, 돌리기 전이라면 왼쪽 위 모서리였을 (126, 26)은 흰색으로 남았습니다. 물체를 자기 좌표계에서 그리고 변환으로 배치하는 방식은 [「변환과 계층」](#/read/cpp-game-engine/math-transform)에서 본 계층 변환과 같습니다.

변환은 이후의 모든 그리기에 계속 적용되므로, `save()`와 `restore()`로 감싸 그 부분에서만 효과가 있게 했습니다. 펜과 붓도 함께 저장되고 복원됩니다. 이 짝을 잊으면 다음에 그리는 것들이 모두 돌아가 버립니다.

## 경로와 안티에일리어싱

- `QPainterPath`는 직선, 베지어 곡선, 호, 사각형, 글자 윤곽을 이어 하나의 모양으로 만듭니다. 한 번 만들어 여러 번 그리거나, 채우거나, 클리핑 영역으로 쓰거나, `contains()`로 점이 안에 있는지 물을 수 있습니다. `pointAtPercent(0.5)`로 곡선의 가운데 점을 얻어 그 화소가 초록인 것을 확인했습니다
- `setRenderHint(QPainter::Antialiasing)`은 가장자리를 반투명한 화소로 부드럽게 그립니다. 비스듬한 선과 곡선에는 거의 필수이고, 수평·수직 사각형은 끄는 편이 더 선명합니다

<Note>
`QImage`는 화소에 직접 접근할 수 있고 어느 스레드에서든 그릴 수 있어서, 썸네일 만들기나 서버에서 그림 생성 같은 일에 씁니다. `QPixmap`은 화면 표시에 맞게 최적화된 이미지라서 GUI 스레드에서만 다룹니다. 그리기 결과를 테스트할 때는 예제처럼 `QImage`에 그리고 화소를 읽으면 화면 없이도 확인할 수 있습니다.
</Note>

## 정리

- QPainter는 이미지, 위젯, PDF, 프린터에 같은 코드로 그리며, 펜은 선과 테두리, 붓은 채우기를 정한다
- translate·rotate·scale로 좌표계를 바꿔 그리고, save와 restore로 변환과 펜·붓 상태를 감싼다
- QPainterPath로 복잡한 모양을 만들고, 곡선에는 안티에일리어싱을 켜며, QImage에 그려 화소로 결과를 확인할 수 있다
