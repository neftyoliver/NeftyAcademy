[「moc가 하는 일」](#/read/cpp-qt/obj-moc)에서 `property("target")`으로 이름만 가지고 값을 읽었습니다. 그렇게 할 수 있는 것은 `Q_PROPERTY`로 선언한 **속성**입니다. 속성은 "값 하나와 그 값을 읽는 함수, 쓰는 함수, 바뀌었을 때 내는 시그널"을 한 이름으로 묶은 것입니다. QML이 C++ 객체의 값을 화면에 묶고, 애니메이션이 값을 서서히 바꾸고, 편집기가 속성 창을 그리는 것이 모두 이 정보를 씁니다.

## 전등 하나

```cpp qt
#include <QCoreApplication>
#include <QMetaProperty>
#include <QObject>
#include <QProperty>
#include <cstdio>

class Lamp : public QObject {
    Q_OBJECT
    // READ/WRITE 함수를 직접 쓰는 속성
    Q_PROPERTY(int brightness READ brightness WRITE setBrightness
               RESET resetBrightness NOTIFY brightnessChanged)
    // 멤버 변수에 바로 묶는 속성(게터·세터를 moc가 만들어 준다)
    Q_PROPERTY(QString room MEMBER m_room NOTIFY roomChanged)
    // 바뀌지 않는 속성
    Q_PROPERTY(QString model READ model CONSTANT)
public:
    int brightness() const { return m_b; }
    void setBrightness(int v) {
        v = qBound(0, v, 100);                 // 값 검사는 세터에서
        if (v == m_b) return;                  // 같은 값이면 알리지 않는다
        m_b = v;
        emit brightnessChanged(v);
    }
    void resetBrightness() { setBrightness(50); }
    QString model() const { return "LX-2"; }
signals:
    void brightnessChanged(int);
    void roomChanged();
private:
    int m_b = 50;
    QString m_room = "거실";
};

int main(int argc, char** argv) {
    QCoreApplication app(argc, argv);
    Lamp lamp;
    QObject::connect(&lamp, &Lamp::brightnessChanged,
                     [](int v) { std::printf("  알림: 밝기 %d\n", v); });

    lamp.setProperty("brightness", 80);        // 이름으로 쓰기
    lamp.setProperty("brightness", 80);        // 같은 값: 알림 없음
    lamp.setProperty("brightness", 250);       // 범위 밖: 100으로
    auto mp = lamp.metaObject()->property(
        lamp.metaObject()->indexOfProperty("brightness"));
    mp.reset(&lamp);                           // RESET 함수 호출
    lamp.setProperty("room", "부엌");
    bool ok = lamp.setProperty("model", "가짜"); // CONSTANT: 쓰기 실패
    std::printf("room=%s model=%s (model 쓰기 %s)\n",
                qPrintable(lamp.property("room").toString()),
                qPrintable(lamp.property("model").toString()),
                ok ? "성공" : "실패");

    // 선언하지 않은 이름: 동적 속성으로 객체에 붙는다
    lamp.setProperty("note", "현관 옆");
    std::printf("동적 속성 note=%s\n",
                qPrintable(lamp.property("note").toString()));

    // Qt 6의 QProperty: 다른 속성에 묶어 두면 자동으로 다시 계산된다
    QProperty<int> width(3), height(4);
    QProperty<int> area([&] { return width.value() * height.value(); });
    std::printf("넓이 %d", area.value());
    width = 10;
    std::printf(" -> 폭 10으로 바꾸자 넓이 %d\n", area.value());
}
#include "main.moc"
```

```text
  알림: 밝기 80
  알림: 밝기 100
  알림: 밝기 50
room=부엌 model=LX-2 (model 쓰기 실패)
동적 속성 note=현관 옆
넓이 12 -> 폭 10으로 바꾸자 넓이 40
```

## 선언의 조각들

- **READ / WRITE**: 게터와 세터를 지정합니다. 세터는 값 검사를 하기 좋은 곳입니다. 250을 넣었지만 `qBound`로 100이 되었습니다
- **NOTIFY**: 값이 바뀔 때 내보낼 시그널입니다. 세터에서 **값이 실제로 바뀔 때만** 내보내는 것이 규칙입니다. 같은 80을 두 번 넣었을 때 알림이 한 번뿐이었던 이유입니다. 이 규칙을 어기면 서로 묶인 두 속성이 끝없이 서로를 바꾸는 고리가 생길 수 있습니다
- **RESET**: 기본값으로 되돌리는 함수입니다. `QMetaProperty::reset`으로 불렀더니 50으로 돌아갔습니다
- **MEMBER**: 멤버 변수에 바로 묶으면 moc가 읽기와 쓰기를 만들어 줍니다. 검사가 필요 없는 단순한 값에 씁니다
- **CONSTANT**: 객체가 사는 동안 바뀌지 않는 값입니다. 쓰기 함수가 없으니 `setProperty`가 `false`를 돌려주었습니다

## 동적 속성

`note`는 선언한 적이 없는 이름인데, `setProperty`가 성공했습니다. 선언되지 않은 이름으로 쓰면 그 객체 하나에만 붙는 **동적 속성**이 됩니다. 스타일시트가 위젯을 고르는 표식으로 쓰거나(`[warning="true"]`), 객체에 잠깐 정보를 달아 둘 때 편리합니다. 다만 오타가 있어도 조용히 새 속성이 생기므로 남용하지 않습니다.

## Qt 6의 QProperty

마지막 부분은 Qt 6에서 들어온 `QProperty`입니다. `area`를 "폭 × 높이"라는 **바인딩**으로 만들어 두었더니, `width`를 바꾼 뒤 읽자 자동으로 40이 되었습니다. 값을 바꾸는 쪽이 의존하는 값들에게 알릴 필요가 없습니다. QML의 속성 바인딩([「속성 바인딩」](#/read/cpp-qt/qml-binding))을 C++에서도 쓸 수 있게 한 것입니다. QObject의 속성과 함께 쓰려면 `Q_OBJECT_BINDABLE_PROPERTY` 매크로와 `BINDABLE` 선언을 사용합니다.

<Note>
속성 값은 `QVariant`로 오갑니다. `property()`는 `QVariant`를 돌려주므로 `toInt()`, `toString()`처럼 꺼내 써야 하고, 사용자 정의 타입을 속성으로 쓰려면 그 타입이 메타 타입 시스템에 알려져 있어야 합니다. 자세한 내용은 [「QVariant」](#/read/cpp-qt/core-variant)에서 봅니다.
</Note>

## 정리

- Q_PROPERTY는 값과 게터, 세터, 알림 시그널, 기본값 함수를 한 이름으로 묶어 이름으로 읽고 쓰고 지켜볼 수 있게 한다
- 세터에서 값을 검사하고 실제로 바뀔 때만 알리며, 단순한 값은 MEMBER, 바뀌지 않는 값은 CONSTANT로 선언한다
- 선언하지 않은 이름은 동적 속성이 되고, Qt 6의 QProperty는 다른 값에 묶어 두면 자동으로 다시 계산된다
