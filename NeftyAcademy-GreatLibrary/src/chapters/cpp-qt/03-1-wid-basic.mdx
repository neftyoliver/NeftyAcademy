## 양식 만들기

```cpp qt=Widgets,Test
#include <QApplication>
#include <QCheckBox>
#include <QComboBox>
#include <QFormLayout>
#include <QIntValidator>
#include <QLabel>
#include <QLineEdit>
#include <QPushButton>
#include <QSlider>
#include <QSpinBox>
#include <QTest>
#include <QTimer>
#include <cstdio>

int main(int argc, char** argv) {
    QApplication app(argc, argv);
    QWidget w;
    auto* form = new QFormLayout(&w);

    auto* name = new QLineEdit;
    name->setPlaceholderText("이름");
    name->setMaxLength(10);
    auto* code = new QLineEdit;
    code->setValidator(new QIntValidator(0, 9999, code));   // 숫자 0~9999만
    auto* age = new QSpinBox;
    age->setRange(0, 120);
    auto* ageSlider = new QSlider(Qt::Horizontal);
    ageSlider->setRange(0, 120);
    auto* news = new QCheckBox("소식 받기");
    auto* city = new QComboBox;
    city->addItems({"대전", "서울", "부산"});
    auto* send = new QPushButton("보내기");
    send->setEnabled(false);                    // 이름을 써야 켜진다

    form->addRow("이름", name);
    form->addRow("우편 번호", code);
    form->addRow("나이", age);
    form->addRow("", ageSlider);
    form->addRow("", news);
    form->addRow("도시", city);
    form->addRow(send);

    // 위젯끼리 잇기: 스핀 상자와 슬라이더가 서로를 따라간다
    QObject::connect(age, &QSpinBox::valueChanged, ageSlider, &QSlider::setValue);
    QObject::connect(ageSlider, &QSlider::valueChanged, age, &QSpinBox::setValue);
    QObject::connect(name, &QLineEdit::textChanged, [send](const QString& t) {
        send->setEnabled(!t.trimmed().isEmpty());
    });
    QObject::connect(send, &QPushButton::clicked, [&] {
        std::printf("보냄: 이름=%s 우편=%s 나이=%d 소식=%s 도시=%s\n",
                    qPrintable(name->text()), qPrintable(code->text()),
                    age->value(), news->isChecked() ? "예" : "아니오",
                    qPrintable(city->currentText()));
    });
    w.show();

    QTimer::singleShot(0, [&] {                 // 사람 대신 QTest로 입력한다
        std::printf("처음: 보내기 버튼 %s\n",
                    send->isEnabled() ? "켜짐" : "꺼짐");
        QTest::keyClicks(name, "Nefty");
        std::printf("이름 입력 뒤: 보내기 버튼 %s\n",
                    send->isEnabled() ? "켜짐" : "꺼짐");
        QTest::keyClicks(code, "34a1x2");       // 글자는 검사기가 막는다
        ageSlider->setValue(29);                // 슬라이더를 움직이면 스핀 상자도
        news->click();
        city->setCurrentIndex(0);
        std::printf("우편 번호 칸: '%s', 나이 칸: %d\n",
                    qPrintable(code->text()), age->value());
        send->click();
        app.quit();
    });
    return app.exec();
}
```

```text
처음: 보내기 버튼 꺼짐
이름 입력 뒤: 보내기 버튼 켜짐
우편 번호 칸: '3412', 나이 칸: 29
보냄: 이름=Nefty 우편=3412 나이=29 소식=예 도시=대전
```

사람이 직접 입력하는 대신 Qt Test 모듈의 `QTest::keyClicks`로 키를 하나씩 눌렀습니다. 진짜 키 입력처럼 이벤트가 위젯에 전달되므로 검사기와 시그널이 실제와 똑같이 동작합니다. 이 방법은 [「Qt Test」](#/read/cpp-qt/qtest-unit)에서 UI 테스트를 쓸 때 다시 씁니다.

## 위젯마다 한 가지씩

- **QLineEdit**: `setPlaceholderText`는 빈 칸에 흐린 안내 글을, `setMaxLength`는 글자 수 한도를 정합니다. **검사기**(`QIntValidator`)를 붙이면 맞지 않는 입력은 아예 들어가지 않습니다. "34a1x2"를 쳤지만 글자는 막히고 "3412"만 남았습니다. 정규식 검사기 `QRegularExpressionValidator`도 있습니다
- **QSpinBox와 QSlider**: 범위가 있는 정수를 받습니다. 둘의 `valueChanged`를 서로의 `setValue`에 이어서, 슬라이더를 29로 옮기자 스핀 상자도 29가 되었습니다. 서로를 다시 바꾸는 고리처럼 보이지만, 값이 같으면 시그널을 내지 않으므로 끝없이 돌지 않습니다([「속성」](#/read/cpp-qt/obj-properties)의 규칙)
- **QCheckBox**: `isChecked()`로 상태를 읽고, `toggled(bool)` 시그널로 바뀔 때를 압니다. 하나만 고르는 선택지는 `QRadioButton`을 `QButtonGroup`으로 묶습니다
- **QComboBox**: `addItems`로 항목을 넣고 `currentText()`, `currentIndex()`로 읽습니다. 항목마다 보이지 않는 데이터(`addItem("대전", 30)`)를 붙여 두면 화면 글과 내부 값을 나눌 수 있습니다
- **QPushButton**: `setEnabled(false)`로 꺼 두었다가 이름 칸이 비지 않으면 켰습니다. 할 수 없는 동작의 버튼을 미리 꺼 두면 오류 대화 상자를 띄울 일이 줄어듭니다

## 양식 배치

`QFormLayout`은 "이름표 | 입력 칸" 두 열 양식을 만들어 줍니다. 이름표 열의 폭을 맞추고, 플랫폼마다 관례에 맞게(macOS는 이름표를 오른쪽 정렬) 배치합니다. 레이아웃은 다음 장 [「레이아웃」](#/read/cpp-qt/wid-layout)에서 자세히 봅니다.

<Note>
`QSpinBox::valueChanged`는 Qt 5에서 `int`판과 `QString`판 두 개로 오버로드되어 있어서 `qOverload<int>`가 필요했지만, Qt 6에서는 `int`판 하나만 남아 위 예제처럼 그냥 쓸 수 있습니다. 옛 예제를 옮길 때 자주 마주치는 차이입니다.
</Note>

## 정리

- 기본 위젯은 QLineEdit, QSpinBox, QSlider, QCheckBox, QComboBox, QPushButton, QLabel이며 각자 값을 읽는 함수와 바뀔 때의 시그널을 가진다
- 검사기로 맞지 않는 입력을 막고, 위젯끼리 시그널로 이어 서로 맞추며, 할 수 없는 동작의 버튼은 꺼 둔다
- QTest::keyClicks로 실제 키 입력을 흉내 내 위젯을 시험할 수 있다
