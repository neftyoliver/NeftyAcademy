선언이 끝난 뒤, 식 안에서 쓰는 `*`와 `&`를 봅니다. 여기서는 둘 다 <strong>연산자</strong>입니다.

## 두 연산자는 서로 반대

| 연산자 | 이름 | 하는 일 | 타입의 변화 |
| --- | --- | --- | --- |
| `&x` | 주소 구하기 | x가 놓인 칸의 주소 | `int` → `int *` |
| `*p` | 따라가기 (역참조) | p에 적힌 주소에 있는 칸 | `int *` → `int` |

`&`는 별을 하나 붙이고 `*`는 별을 하나 뗍니다. 그래서 `*&x`는 `x`와 같습니다.

```c
#include <stdio.h>

int main(void)
{
    int x = 10;
    int y = 20;
    int *p = &x;

    *p = 11;          // x가 11이 된다
    p = &y;           // 이제 p는 y를 가리킨다 (x는 그대로)
    *p = 21;          // y가 21이 된다

    printf("%d %d\n", x, y);    // 11 21
    return 0;
}
```

`p = …`는 **가리키는 곳을 바꾸고**, `*p = …`는 **가리키는 곳의 값을 바꿉니다**. 별이 있고 없고의 차이입니다.

## 같은 글자, 다른 뜻

| 글자 | 선언문에서 | 식에서 (값 하나 앞) | 식에서 (값 둘 사이) |
| --- | --- | --- | --- |
| `*` | 포인터 타입 표시 | 따라가기 | 곱하기 |
| `&` | (C에는 없음) | 주소 구하기 | 비트 AND |

```c
int *p = &x;       // 선언의 *, 주소 구하기 &
int z = *p * 2;    // 따라가기 *, 곱하기 *
```

## 왜 필요한가: 함수가 내 변수를 바꾸게 하려면

C의 함수는 인자의 <strong>복사본</strong>을 받습니다. 그래서 아래 함수는 아무 일도 하지 않습니다.

```c
void swap_wrong(int a, int b)
{
    int t = a;
    a = b;
    b = t;      // 복사본끼리 바꿨을 뿐
}
```

부른 쪽의 변수를 바꾸려면 변수 대신 **변수의 주소**를 넘깁니다.

```c
#include <stdio.h>

void swap(int *a, int *b)
{
    int t = *a;
    *a = *b;
    *b = t;
}

int main(void)
{
    int x = 1;
    int y = 2;
    swap(&x, &y);
    printf("%d %d\n", x, y);    // 2 1
    return 0;
}
```

주소도 복사되어 넘어가지만, 복사된 주소를 따라가면 같은 칸에 닿습니다. `scanf("%d", &n)`에 `&`가 붙는 이유도 같습니다. `scanf`가 `n`의 칸에 값을 써 넣어야 하기 때문입니다.

포인터를 넘기는 두 번째 이유는 크기입니다. 큰 구조체를 통째로 복사하는 대신 주소 8바이트만 넘깁니다.

## 구조체를 가리킬 때: 화살표

```c
struct point { int x; int y; };

struct point pt = { 1, 2 };
struct point *p = &pt;

(*p).x = 10;    // 따라간 다음 멤버 고르기
p->y = 20;      // 같은 뜻. 이렇게 쓴다
```

`.`이 `*`보다 먼저 붙기 때문에 `*p.x`라고 쓰면 `*(p.x)`가 되어 틀립니다. 괄호가 번거로워서 `->`가 생겼습니다. **변수면 점, 포인터면 화살표**입니다.

<Note kind="tip">
식이 헷갈리면 타입을 따져 보세요. `p`가 `int *`이면 `*p`는 `int`, `&p`는 `int **`입니다. 대입문 양쪽의 타입이 맞는지 보면 별을 붙일지 뗄지가 정해집니다.
</Note>

## 정리

- `&`는 주소를 구하고 `*`는 주소를 따라간다
- `p = …`는 가리키는 곳을, `*p = …`는 그곳의 값을 바꾼다
- 함수가 부른 쪽의 변수를 바꾸려면 주소를 넘긴다
