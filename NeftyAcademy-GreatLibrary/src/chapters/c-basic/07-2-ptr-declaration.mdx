포인터에서 가장 많이 헷갈리는 곳은 `*`가 **선언할 때**와 **쓸 때** 뜻이 다르다는 점입니다. 이 챕터는 선언문만 봅니다.

## 선언문의 *는 "포인터다"라는 표시

```c
int *p;
```

이 줄에서 `*`는 무언가를 따라가는 연산이 아닙니다. "p는 포인터"라고 타입을 적는 글자입니다. 이 줄이 하는 일은 `p`라는 변수를 만드는 것뿐이고, 어디도 따라가지 않습니다.

C의 선언은 <strong>쓰는 모습을 그대로 적는다</strong>는 원칙으로 만들어졌습니다. `int *p;`는 "식 `*p`를 계산하면 `int`가 나온다"는 뜻입니다. 그러니 `p`는 `int`를 가리키는 포인터입니다.

## 가장 큰 함정: 선언과 초기화가 한 줄에 있을 때

```c
int x = 42;
int *p = &x;
```

이 줄은 `*p`에 `&x`를 넣는 것처럼 보이지만, 그렇지 않습니다. 두 줄로 풀면 이렇습니다.

```c
int *p;     // p는 int 포인터
p = &x;     // p에 x의 주소를 넣는다   (*p = &x 가 아니다)
```

초깃값은 언제나 <strong>선언되는 변수</strong>(`p`)에 들어갑니다. `*`는 타입의 일부일 뿐입니다. 이것만 기억해도 포인터 혼란의 절반이 사라집니다.

| 줄 | `*`의 뜻 | 하는 일 |
| --- | --- | --- |
| `int *p = &x;` | 선언: p는 포인터 | `p`에 주소를 넣는다 |
| `*p = 7;` | 사용: 따라가기 | `p`가 가리키는 칸에 7을 넣는다 |

앞에 타입 이름(`int`, `char` 등)이 있으면 선언이고, 없으면 사용입니다.

## 별은 변수 이름에 붙는다

```c
int* p, q;      // p는 포인터, q는 그냥 int
int *p, *q;     // 둘 다 포인터
```

`int*`를 한 덩어리의 타입처럼 읽으면 첫 줄에서 속습니다. `*`는 타입이 아니라 **이름 쪽에** 붙습니다. 이 책이 `int *p`로 적는 이유입니다. 가장 안전한 방법은 한 줄에 포인터를 하나만 선언하는 것입니다.

## 선언 읽는 법

복잡한 선언은 <strong>이름에서 출발해서, 오른쪽을 먼저 보고, 그다음 왼쪽</strong>을 봅니다. 괄호가 있으면 괄호 안이 먼저입니다. 오른쪽의 `[]`(배열)와 `()`(함수)가 왼쪽의 `*`보다 먼저 붙습니다.

| 선언 | 읽기 |
| --- | --- |
| `int *p` | p는 포인터, `int`를 가리키는 |
| `int **pp` | pp는 포인터, `int` 포인터를 가리키는 |
| `int a[3]` | a는 3칸 배열, `int`의 |
| `int *a[3]` | a는 3칸 배열, `int` 포인터의 |
| `int (*pa)[3]` | pa는 포인터, `int` 3칸 배열을 가리키는 |
| `int f(int)` | f는 함수, `int`를 받아 `int`를 돌려주는 |
| `int *f(int)` | f는 함수, `int` 포인터를 돌려주는 |
| `int (*fp)(int)` | fp는 포인터, 함수를 가리키는 |

`int *a[3]`과 `int (*pa)[3]`의 차이가 괄호 하나입니다. 괄호가 없으면 `[3]`이 먼저 붙어 "배열"이 되고, 괄호가 있으면 `*`가 먼저 붙어 "포인터"가 됩니다.

## const가 붙으면

```c
const int *p;         // 가리키는 칸을 못 바꾼다 (*p = 1 안 됨, p = &y 됨)
int *const q = &x;    // 포인터 자체를 못 바꾼다 (*q = 1 됨, q = &y 안 됨)
const int *const r = &x;   // 둘 다 못 바꾼다
```

`const`가 `*`의 **왼쪽**에 있으면 가리키는 대상이, **오른쪽**에 있으면 포인터 자신이 고정됩니다. 함수 인자에서 보는 `const char *s`는 "이 함수는 글자열을 읽기만 한다"는 약속입니다.

<Note kind="tip">
읽기 어려운 선언을 만나면 `typedef`로 이름을 붙여 쪼개면 됩니다. [「const와 typedef」](#/read/c-basic/typedef) 챕터에서 다룹니다.
</Note>

## 정리

- 선언문의 `*`는 "포인터"라는 타입 표시, 따라가기가 아니다
- `int *p = &x;`는 `p`에 주소를 넣는다
- 선언은 이름에서 시작해 오른쪽 먼저, 그다음 왼쪽으로 읽는다
