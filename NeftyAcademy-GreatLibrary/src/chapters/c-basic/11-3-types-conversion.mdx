타입이 다른 값끼리 계산하거나 대입하면 C가 <strong>말없이</strong> 타입을 바꿉니다. 편리하지만, 규칙을 모르면 조용히 틀린 값이 나옵니다.

## 저절로 바뀌는 세 가지 경우

| 언제 | 규칙 |
| --- | --- |
| 작은 정수로 계산할 때 | `char`, `short`, `bool`은 먼저 `int`가 된다 (정수 승격) |
| 타입이 다른 둘을 계산할 때 | 더 넓은 쪽으로 맞춘다 (`int` + `double` → `double`) |
| 대입하거나 인자로 넘길 때 | 받는 쪽 타입으로 바뀐다 |

## 정수 승격

```c
#include <stdint.h>
#include <stdio.h>

int main(void)
{
    uint8_t a = 200;
    uint8_t b = 100;

    int sum = a + b;            // 300: int로 바뀐 뒤 더하므로 넘치지 않는다
    uint8_t cut = a + b;        // 44: 300을 8비트에 넣으며 잘린다

    printf("%d %d\n", sum, cut);
    printf("%zu\n", sizeof(a + b));     // 4: 결과는 int
    return 0;
}
```

`int`보다 작은 타입끼리의 계산은 `int`로 이루어집니다. 결과를 다시 작은 타입에 넣을 때 잘립니다.

## 부호 있는 것과 없는 것이 만나면

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    int n = -1;
    unsigned int u = 1;

    if (n < u)
        puts("-1 < 1");
    else
        puts("-1 >= 1 ?!");     // 이쪽이 찍힌다

    if (strlen("abc") - 5 > 0)
        puts("3 - 5 > 0 ?!");   // 이것도 찍힌다
    return 0;
}
```

`int`와 `unsigned int`가 만나면 `int` 쪽이 `unsigned`로 바뀝니다. `-1`은 4,294,967,295가 되어 1보다 큽니다. `strlen`은 부호 없는 `size_t`를 돌려주므로 `3 - 5`는 −2가 아니라 아주 큰 양수입니다.

<Note kind="warn">
이 실수는 "거꾸로 도는 반복문"에서 자주 나옵니다. `for (size_t i = n - 1; i >= 0; i--)`는 끝나지 않습니다. `size_t`는 0보다 작아질 수 없기 때문입니다. `-Wextra`가 이런 비교를 경고해 줍니다.
</Note>

## 대입하면서 잃는 것

| 바꾸는 방향 | 일어나는 일 |
| --- | --- |
| `double` → `int` | 소수점 아래를 버린다. 범위를 벗어나면 정의되지 않은 동작 |
| 큰 정수 → 작은 부호 없는 정수 | 위쪽 비트를 버린다 (`300` → `uint8_t` `44`) |
| 큰 정수 → 작은 부호 있는 정수 | 구현이 정한다. 흔한 컴파일러는 모두 위쪽 비트를 버린다 |
| `int` → `float` | 1,600만이 넘으면 정확하지 않을 수 있다 |
| `int` → `double` | 언제나 정확하다 |

## 직접 바꾸기: 형 변환

```c
int a = 7;
int b = 2;

double q = (double)a / b;           // 3.5: 나누기 전에 a를 double로
int percent = (int)(q * 100.0);     // 350
unsigned char low = (unsigned char)(0x1234 & 0xff);     // 0x34
```

`(타입)식`이 형 변환입니다. 두 가지 용도가 있습니다.

- 계산이 원하는 타입으로 이루어지게 한다 (`(double)a / b`)
- "값을 잃는 줄 알고 일부러 하는 것"임을 컴파일러와 읽는 사람에게 알린다

형 변환은 `/`보다 먼저 붙습니다. `(double)(a / b)`라고 쓰면 정수 나눗셈을 한 뒤에 바꾸므로 3.0이 됩니다.

## 포인터의 형 변환

```c
int x = 0x11223344;
void *any = &x;                 // 어떤 포인터든 void * 에 그냥 들어간다
int *back = any;                // void * 에서 꺼낼 때도 그냥 된다
unsigned char *bytes = (unsigned char *)&x;     // 바이트 단위로 들여다보기
```

`void *`는 "타입을 모르는 주소"입니다. 따라갈 수는 없고, 원래 타입의 포인터로 되돌려서 씁니다. 어떤 값이든 `unsigned char *`로 바꿔 바이트 단위로 읽는 것은 허용됩니다. 그 밖에 관계없는 타입의 포인터로 바꿔서 읽는 것(`float *`를 `int *`로)은 정의되지 않은 동작입니다.

## 경고 켜기

```sh
clang -std=c23 -Wall -Wextra -Wconversion conv.c
```

`-Wconversion`은 값을 잃을 수 있는 암시적 변환을 모두 알려 줍니다. 경고가 많이 나오지만, 장치와 바이트를 주고받는 코드에서는 켜 두는 편이 좋습니다. 일부러 하는 변환에는 형 변환을 적어 경고를 끕니다.

## 정리

- 작은 정수는 `int`로 승격되고, 다른 타입끼리는 넓은 쪽으로 맞춰진다
- 부호 있는 값과 없는 값을 비교하지 않는다
- 값을 잃는 변환은 형 변환으로 드러내 적는다
