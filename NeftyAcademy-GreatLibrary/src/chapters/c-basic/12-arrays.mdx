배열은 <strong>같은 타입의 값을 메모리에 나란히</strong> 놓은 것입니다. 포인터와의 관계는 「포인터와 배열」에서 봤으니, 여기서는 배열 자체의 기본만 짧게 정리합니다.

## 만들고 쓰기

```c
#include <stdio.h>

int main(void)
{
    int a[5] = { 10, 20, 30 };      // 나머지 두 칸은 0
    int b[] = { 1, 2, 3, 4 };       // 개수를 세어 4칸으로
    int c[8] = { 0 };               // 전부 0 (C23에서는 = {} 도 된다)

    a[4] = 50;
    printf("%d %d %d\n", a[0], a[3], a[4]);     // 10 0 50
    printf("%zu %zu\n", sizeof b / sizeof b[0], sizeof c);   // 4 32
    return 0;
}
```

- 번호는 **0부터** 시작합니다. 5칸 배열의 마지막은 `a[4]`입니다
- 초깃값을 일부만 주면 나머지는 0이 됩니다
- 초깃값을 아예 안 주면 지역 배열에는 쓰레기 값이 들어 있습니다

## 칸 수 구하기

```c
size_t n = sizeof a / sizeof a[0];
```

배열 전체의 바이트 수를 한 칸의 바이트 수로 나눕니다. 표준 라이브러리에 칸 수를 구하는 매크로는 없으므로 이 식을 그대로 쓰거나 직접 매크로로 만들어 둡니다.

```c
#define COUNT_OF(a) (sizeof (a) / sizeof (a)[0])
```

## C 배열이 하지 않는 것

| 하지 않는 것 | 대신 |
| --- | --- |
| 범위 검사 (`a[5]`를 막지 않는다) | 인덱스를 직접 확인한다 |
| 통째로 대입 (`a = b` 오류) | `memcpy(a, b, sizeof a)` |
| 통째로 비교 (`a == b`는 주소 비교) | `memcmp(a, b, sizeof a) == 0` |
| 자기 길이 기억하기 | 길이를 변수로 따로 들고 다닌다 |
| 크기 바꾸기 | `malloc`과 `realloc` |

<Note kind="warn">
배열 밖을 읽거나 쓰는 것은 정의되지 않은 동작입니다. 오류 메시지 없이 옆에 있는 변수를 망가뜨립니다. 반복문의 끝 조건은 `i <= n`이 아니라 `i < n`입니다.
</Note>

## 반복문과 함께

```c
#include <stdio.h>

int main(void)
{
    int temps[] = { 21, 23, 22, 25, 24 };
    size_t n = sizeof temps / sizeof temps[0];

    int max = temps[0];
    int sum = 0;
    for (size_t i = 0; i < n; i++) {
        if (temps[i] > max)
            max = temps[i];
        sum += temps[i];
    }
    printf("최고 %d, 평균 %.1f\n", max, (double)sum / (double)n);   // 최고 25, 평균 23.0
    return 0;
}
```

## 글자열

```c
char name[8] = "pi";    // 'p' 'i' '\0' 그리고 0 다섯 개
char msg[] = "hello";   // 6칸: 글자 5개와 '\0'
```

글자열은 `'\0'`으로 끝나는 `char` 배열입니다. 배열 크기는 **글자 수 + 1** 이상이어야 합니다. `strlen(msg)`는 5, `sizeof msg`는 6입니다.

## 2차원

```c
int grid[2][3] = {
    { 1, 2, 3 },
    { 4, 5, 6 },
};
grid[1][2] = 60;    // 둘째 줄, 셋째 칸
```

"3칸짜리 배열이 2개"입니다. 메모리에는 1 2 3 4 5 6 순서로 한 줄로 놓입니다. 함수에 넘기는 법과 더 깊은 내용은 「배열 심화」에서 다룹니다.

## 정리

- 배열은 같은 타입이 나란히 놓인 것, 번호는 0부터
- 길이를 스스로 기억하지 않고, 범위도 확인해 주지 않는다
- 대입과 비교는 `memcpy`와 `memcmp`로 한다
