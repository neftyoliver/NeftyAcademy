연산자는 값을 가지고 새 값을 만드는 기호입니다. 대부분 수학에서 보던 것이지만, 정수 나눗셈과 비트 연산, 그리고 우선순위에 함정이 있습니다.

## 산술

| 연산자 | 뜻 | 주의 |
| --- | --- | --- |
| `+` `-` `*` | 더하기, 빼기, 곱하기 | 부호 있는 정수가 넘치면 정의되지 않은 동작 |
| `/` | 나누기 | 정수끼리는 소수점 아래를 **버린다**: `7 / 2`는 3, `-7 / 2`는 −3 |
| `%` | 나머지 | 정수만. 부호는 왼쪽을 따른다: `-7 % 2`는 −1 |

0으로 나누는 것(`/`, `%`)은 정의되지 않은 동작이고, 보통 프로그램이 죽습니다.

## 비교와 논리

| 연산자 | 뜻 |
| --- | --- |
| `==` `!=` | 같다, 다르다 |
| `<` `<=` `>` `>=` | 크기 비교 |
| `&&` | 그리고 |
| <code>\|\|</code> | 또는 |
| `!` | 아니다 |

결과는 `int` 1(참) 또는 0(거짓)입니다. C에서는 **0이 거짓, 0이 아닌 모든 값이 참**입니다.

`&&`와 `||`는 왼쪽만으로 결과가 정해지면 오른쪽을 계산하지 않습니다(단락 평가). 이 성질을 안전장치로 씁니다.

```c
if (p != nullptr && p->value > 0)   // p가 널이면 오른쪽을 보지 않는다
```

<Note kind="warn">
`=`는 대입, `==`는 비교입니다. `if (x = 5)`는 x에 5를 넣고 언제나 참이 됩니다. `-Wall`이 경고해 줍니다.
</Note>

## 비트 연산

정수를 비트의 줄로 보고 다룹니다. 하드웨어 레지스터와 통신 프로토콜에서 날마다 씁니다.

| 연산자 | 뜻 | 예 (8비트) |
| --- | --- | --- |
| `&` | AND: 둘 다 1이면 1 | `0b1100 & 0b1010` → `0b1000` |
| <code>\|</code> | OR: 하나라도 1이면 1 | → `0b1110` |
| `^` | XOR: 서로 다르면 1 | → `0b0110` |
| `~` | NOT: 뒤집기 | `~0b00001111` → `0b11110000` |
| `<<` | 왼쪽으로 밀기 | `1 << 3` → `0b1000` (8) |
| `>>` | 오른쪽으로 밀기 | `0b1000 >> 2` → `0b0010` |

특정 비트 하나를 다루는 네 가지 관용구입니다.

```c
#include <stdint.h>
#include <stdio.h>

int main(void)
{
    uint8_t reg = 0b0000'0000;

    reg |= 1u << 3;             // 3번 비트 켜기      0000 1000
    reg |= 1u << 0;             // 0번 비트 켜기      0000 1001
    reg &= ~(1u << 3);          // 3번 비트 끄기      0000 0001
    reg ^= 1u << 7;             // 7번 비트 뒤집기    1000 0001

    if (reg & (1u << 0))        // 0번 비트가 켜져 있는가
        puts("0번 켜짐");

    printf("0x%02x\n", reg);    // 0x81

    uint16_t raw = 0x1234;
    uint8_t high = (uint8_t)(raw >> 8);       // 0x12
    uint8_t low = (uint8_t)(raw & 0xff);      // 0x34
    printf("%02x %02x\n", high, low);
    return 0;
}
```

| 주의할 것 | 이유 |
| --- | --- |
| 비트 연산은 `unsigned`로 | 음수를 오른쪽으로 밀면 결과가 구현마다 다르고, 왼쪽으로 밀면 정의되지 않은 동작 |
| 타입의 비트 수 이상으로 밀지 않는다 | `1 << 32`(32비트 `int`)는 정의되지 않은 동작. 64비트면 `1ull << 40` |
| `&`와 `&&`를 구분한다 | `&`는 비트마다, `&&`는 참·거짓으로 |

## 대입과 증감

```c
x += 3;     // x = x + 3. -= *= /= %= &= |= ^= <<= >>= 도 같다
i++;        // i를 1 늘린다
```

`i++`와 `++i`는 둘 다 `i`를 1 늘리지만, 식의 **값**이 다릅니다.

```c
int i = 5;
int a = i++;    // a는 5, i는 6 (옛 값을 내놓고 늘린다)
int b = ++i;    // b는 7, i는 7 (늘린 뒤 새 값을 내놓는다)
```

한 줄에 혼자 쓸 때는 차이가 없습니다. 한 식에서 같은 변수를 두 번 바꾸는 것(`i = i++ + 1`, `a[i] = i++`)은 정의되지 않은 동작이니 쓰지 않습니다.

## 그 밖의 연산자

| 연산자 | 뜻 | 예 |
| --- | --- | --- |
| `c ? a : b` | c가 참이면 a, 아니면 b | `int big = x > y ? x : y;` |
| `sizeof` | 타입이나 식의 크기(바이트) | `sizeof(int)`, `sizeof x` |
| `(타입)` | 형 변환 | `(double)n` |
| `,` | 왼쪽을 계산하고 버린 뒤 오른쪽 | `for (i = 0, j = n; …)` |
| `&` `*` `->` `.` `[]` | 주소, 따라가기, 멤버, 인덱스 | 포인터 챕터 참고 |

## 우선순위

먼저 붙는 순서입니다(위가 먼저).

| 순위 | 연산자 |
| --- | --- |
| 1 | `()` `[]` `->` `.` 뒤에 붙는 `++` `--` |
| 2 | 앞에 붙는 `!` `~` `++` `--` `-` `*` `&` `sizeof` `(타입)` |
| 3 | `*` `/` `%` |
| 4 | `+` `-` |
| 5 | `<<` `>>` |
| 6 | `<` `<=` `>` `>=` |
| 7 | `==` `!=` |
| 8 | `&` → `^` → <code>\|</code> |
| 9 | `&&` → <code>\|\|</code> |
| 10 | `? :` |
| 11 | `=` `+=` 등 |

외우기 어려운 곳이 함정입니다.

```c
if (flags & MASK == 0)      // flags & (MASK == 0) 으로 읽힌다
if ((flags & MASK) == 0)    // 이렇게 쓴다

x = a << 2 + 1;             // a << 3 이다
```

<Note kind="tip">
비트 연산과 비교, 시프트와 덧셈이 섞이면 무조건 괄호를 칩니다. 괄호는 공짜이고, 읽는 사람도 우선순위 표를 떠올릴 필요가 없습니다.
</Note>

## 정리

- 정수 나눗셈은 버림, 0이 거짓이고 나머지는 참
- 비트를 켜고(`|=`), 끄고(`&= ~`), 뒤집고(`^=`), 확인한다(`&`)
- 헷갈리면 괄호
