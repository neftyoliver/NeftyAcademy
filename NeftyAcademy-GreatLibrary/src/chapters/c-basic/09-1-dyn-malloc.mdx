지금까지의 변수는 크기가 컴파일할 때 정해졌고, 함수가 끝나면 사라졌습니다. 실행 중에 크기를 정하거나 함수가 끝난 뒤에도 남아야 하는 메모리는 `malloc`으로 직접 빌립니다.

## 세 가지 수명

| 종류 | 만드는 법 | 사는 동안 | 놓이는 곳 |
| --- | --- | --- | --- |
| 자동 | 함수 안의 지역 변수 | 그 블록이 끝날 때까지 | 스택 |
| 정적 | 전역 변수, `static` 변수 | 프로그램이 끝날 때까지 | 데이터 영역 |
| 동적 | `malloc` | `free`할 때까지 | 힙 |

스택은 빠르지만 작고(보통 8MB), 함수가 끝나면 자동으로 치워집니다. 힙은 크고 수명을 내가 정하는 대신 **치우는 것도 내 일**입니다.

## 빌리고 돌려주기

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    size_t n = 5;
    int *v = malloc(n * sizeof *v);     // int 5개 자리
    if (v == nullptr) {
        puts("메모리가 부족합니다");
        return 1;
    }

    for (size_t i = 0; i < n; i++)
        v[i] = (int)(i * i);
    for (size_t i = 0; i < n; i++)
        printf("%d ", v[i]);            // 0 1 4 9 16
    printf("\n");

    free(v);
    v = nullptr;
    return 0;
}
```

- `malloc(바이트 수)`는 그만큼의 메모리를 빌려 첫 칸의 주소를 돌려줍니다. 실패하면 널입니다
- 돌려받은 주소는 배열처럼 `v[i]`로 씁니다
- 다 쓰면 `free(v)`로 돌려줍니다

## n * sizeof *v

```c
int *v = malloc(n * sizeof *v);
```

`sizeof *v`는 "v가 가리키는 것 하나의 크기"입니다. `sizeof(int)`라고 써도 되지만, 나중에 `v`의 타입을 `long *`으로 바꾸면 한 곳은 고치고 한 곳은 잊기 쉽습니다. 변수에서 크기를 구하면 그럴 일이 없습니다.

`malloc`이 돌려주는 타입은 `void *`이고, C에서는 다른 포인터에 그냥 대입됩니다. `(int *)malloc(…)`처럼 형 변환을 적을 필요가 없습니다(C++에서는 필요합니다).

<Note kind="warn">
`malloc`이 준 메모리에는 **쓰레기 값**이 들어 있습니다. 읽기 전에 반드시 값을 넣으세요. 0으로 채워진 메모리가 필요하면 다음 챕터의 `calloc`을 씁니다.
</Note>

## 지켜야 할 규칙

| 규칙 | 어기면 |
| --- | --- |
| `malloc`한 것은 정확히 한 번 `free`한다 | 안 하면 <strong>누수</strong>, 두 번 하면 프로그램이 깨진다 |
| `free`한 뒤에는 쓰지 않는다 | 남의 것이 된 메모리를 망가뜨린다 |
| 빌린 크기를 넘지 않는다 | 힙의 다른 덩어리나 관리 정보를 덮어쓴다 |
| `free`에는 `malloc`이 준 주소를 그대로 넘긴다 | 중간 주소를 넘기면 깨진다 |

누수는 당장 티가 나지 않습니다. 하지만 며칠씩 켜 두는 프로그램(서버, IoT 장치)에서는 메모리가 조금씩 줄다가 어느 날 멈춥니다.

## 누가 치울지 정해 두기

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

// 돌려준 글자열은 부른 쪽이 free 해야 한다
char *make_label(const char *name, int id)
{
    size_t size = strlen(name) + 16;
    char *s = malloc(size);
    if (s != nullptr)
        snprintf(s, size, "%s#%d", name, id);
    return s;
}

int main(void)
{
    char *label = make_label("sensor", 3);
    if (label == nullptr)
        return 1;
    puts(label);        // sensor#3
    free(label);
    return 0;
}
```

지역 배열의 주소는 돌려줄 수 없지만 `malloc`한 메모리는 돌려줄 수 있습니다. 대신 "이 메모리는 누가 해제하는가"를 주석으로 분명히 적어 둡니다. 이 약속을 <strong>소유권</strong>이라고 부릅니다.

## 누수 찾기

```sh
clang -std=c23 -g -fsanitize=address leak.c -o leak
./leak
```

리눅스에서 ASan은 프로그램이 끝날 때 해제하지 않은 메모리와 그것을 빌린 줄을 알려 줍니다. `valgrind ./프로그램`도 같은 일을 합니다.

## 정리

- `malloc`으로 빌리고 `free`로 돌려준다. 짝이 맞아야 한다
- 크기는 `개수 * sizeof *포인터`로 적는다
- 결과가 널인지 확인하고, 누가 해제할지 정해 둔다
