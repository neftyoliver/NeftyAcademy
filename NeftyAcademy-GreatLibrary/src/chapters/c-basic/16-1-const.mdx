`const`는 "이 이름을 통해서는 값을 바꾸지 않겠다"는 약속입니다. 컴파일러가 약속을 지키는지 검사해 주고, 읽는 사람에게는 의도를 알려 줍니다.

## 바꿀 수 없는 변수

```c
const int max_retry = 3;
const double pi = 3.141592653589793;
```

초기화한 뒤에는 대입할 수 없습니다. `max_retry = 5;`는 컴파일 오류입니다.

## 포인터와 const

`const`가 어디에 붙느냐에 따라 고정되는 것이 다릅니다.

| 선언 | `*p = …` | `p = …` | 읽기 |
| --- | --- | --- | --- |
| `const int *p` | 안 됨 | 됨 | 읽기 전용인 `int`를 가리키는 포인터 |
| `int *const p` | 됨 | 안 됨 | 다른 곳을 가리킬 수 없는 포인터 |
| `const int *const p` | 안 됨 | 안 됨 | 둘 다 |

`*`를 기준으로 **왼쪽의 `const`는 가리키는 대상**, **오른쪽의 `const`는 포인터 자신**입니다. `const int *`와 `int const *`는 같은 뜻입니다.

## 함수 인자의 const

```c
#include <stdio.h>
#include <string.h>

// s를 읽기만 한다는 약속
size_t count_char(const char *s, char c)
{
    size_t n = 0;
    for (; *s != '\0'; s++)
        if (*s == c)
            n++;
    return n;
}

int main(void)
{
    char buf[] = "banana";
    printf("%zu\n", count_char(buf, 'a'));          // 3
    printf("%zu\n", count_char("hello", 'l'));      // 2
    return 0;
}
```

`const`가 가장 쓸모 있는 곳입니다. 함수 원형만 보고도 "이 함수는 내 데이터를 건드리지 않는다"는 것을 알 수 있습니다. 표준 라이브러리도 `strlen(const char *s)`, `memcpy(void *dest, const void *src, size_t n)`처럼 읽기만 하는 인자에 `const`를 붙여 둡니다.

`char *`는 `const char *`를 받는 함수에 그냥 넘길 수 있습니다(제약을 더하는 방향). 반대는 경고가 납니다.

## const는 "상수"가 아니다

```c nocheck
const int n = 4;
int a[n];               // C에서는 진짜 상수가 아니라서 가변 길이 배열이 된다
static int b[n];        // 오류
switch (x) { case n: … }    // 오류
```

C의 `const` 변수는 "읽기 전용 변수"일 뿐, 컴파일할 때 값이 정해지는 상수로 치지 않습니다(C++과 다른 점). 배열 크기나 `case`처럼 진짜 상수가 필요한 자리에는 아래 중 하나를 씁니다.

| 방법 | 예 | 특징 |
| --- | --- | --- |
| `enum` | `enum { BUF_SIZE = 256 };` | 정수만. 타입 검사가 되고 디버거에 이름이 보인다 |
| `#define` | `#define BUF_SIZE 256` | 어떤 값이든. 단순 치환이라 타입이 없다 |
| `constexpr` (C23) | `constexpr int buf_size = 256;` | 타입이 있는 진짜 상수. Clang은 19부터, GCC는 13부터 된다 |

## 글자열 상수

```c
const char *msg = "hello";      // 글자열 상수는 읽기 전용 영역에 놓인다
```

글자열 상수의 타입은 역사적인 이유로 `char[]`이지만, 내용을 고치면 정의되지 않은 동작이고 보통 프로그램이 죽습니다. 그래서 가리킬 때는 늘 `const char *`를 씁니다.

## const를 벗기면

```c nocheck
const int limit = 10;
int *p = (int *)&limit;     // 형 변환으로 const를 벗겼다
*p = 20;                    // 정의되지 않은 동작
```

처음부터 `const`로 만든 것을 형 변환으로 벗겨서 바꾸면 정의되지 않은 동작입니다. 컴파일러가 그 변수를 읽기 전용 메모리에 두었거나, 10이라는 값을 코드에 직접 박아 넣었을 수 있습니다.

<Note kind="tip">
읽기만 하는 포인터 인자에는 일단 `const`를 붙이세요. 나중에 떼기는 쉬워도, `const` 없이 퍼진 코드에 나중에 붙이는 것은 번거롭습니다. 그리고 `const`로 만든 전역 데이터는 플래시 메모리에 놓여서 작은 장치의 RAM을 아껴 줍니다.
</Note>

## 정리

- `const`는 읽기 전용이라는 약속, 컴파일러가 검사한다
- `*`의 왼쪽이면 대상이, 오른쪽이면 포인터가 고정된다
- 컴파일 시점 상수가 필요하면 `enum`, `#define`, `constexpr`
