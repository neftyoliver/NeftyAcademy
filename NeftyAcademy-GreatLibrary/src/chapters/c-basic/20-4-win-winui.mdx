<strong>WinUI 3</strong>는 윈도우의 최신 화면 도구입니다. Win32가 C API인 것과 달리 WinUI는 C로 쓸 수 없고, C++(C++/WinRT)이나 C#으로 씁니다. 그래서 이 챕터는 따라 치는 실습이 아니라, 같은 프로그램이 높은 층에서는 어떤 모양이 되는지 보는 구경입니다.

<Note kind="warn">
이 챕터의 코드는 빌드해서 실행해 보지 못했습니다. WinUI 3 프로젝트는 Visual Studio의 프로젝트 틀과 여러 생성 파일이 필요해서 파일 한두 개로는 컴파일되지 않습니다. 아래 코드는 그 틀에서 우리가 고치는 부분만 보인 것입니다.
</Note>

## 층이 어떻게 쌓여 있나

| 층 | 무엇 | 쓰는 언어 |
| --- | --- | --- |
| WinUI 3 (Windows App SDK) | 위젯, 배치, 애니메이션, XAML | C++, C# |
| WinRT | 객체 기반의 윈도우 API | C++, C#, Rust |
| COM | 언어에 상관없이 객체를 주고받는 약속 (ABI) | C로도 가능 |
| Win32 | 창, 메시지, 그리기 | C |

WinUI의 창도 맨 아래에서는 Win32의 창(`HWND`)이고, 메시지 루프도 그대로 돌고 있습니다. 프레임워크가 감춰 줄 뿐입니다.

## 프로젝트 만들기

Visual Studio에서 "WinUI 앱 개발" 작업 부하를 설치한 뒤, 새 프로젝트에서 "Blank App, Packaged (WinUI 3 in Desktop)"의 C++ 판을 고릅니다. 그러면 `MainWindow.xaml`, `MainWindow.xaml.h`, `MainWindow.xaml.cpp` 같은 파일이 만들어집니다.

## 화면: XAML

화면은 코드가 아니라 <strong>XAML</strong>이라는 문서로 적습니다.

```xml
<!-- MainWindow.xaml -->
<Window
    x:Class="Hello.MainWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    Title="Hello WinUI">

    <StackPanel Margin="16" Spacing="8">
        <StackPanel Orientation="Horizontal" Spacing="8">
            <TextBox x:Name="input" Width="220" PlaceholderText="여기에 입력" />
            <Button Content="Add" Click="OnAdd" />
        </StackPanel>
        <ScrollViewer Height="188">
            <TextBlock x:Name="log" TextWrapping="Wrap" />
        </ScrollViewer>
    </StackPanel>
</Window>
```

좌표가 하나도 없습니다. "세로로 쌓아라(`StackPanel`)", "간격은 8"처럼 **배치 규칙**을 적으면 창 크기가 바뀔 때 알아서 다시 놓입니다. `Click="OnAdd"`는 단추가 눌리면 부를 함수의 이름입니다.

## 동작: C++/WinRT

```cpp
// MainWindow.xaml.cpp 에서 우리가 쓰는 부분
void MainWindow::OnAdd(IInspectable const&, RoutedEventArgs const&)
{
    auto text = input().Text();
    if (text.empty())
        return;
    log().Text(log().Text() + text + L"\n");
    input().Text(L"");
}
```

`input()`과 `log()`는 XAML에서 `x:Name`으로 이름 붙인 위젯을 돌려주는 함수이고, 빌드할 때 자동으로 만들어집니다.

## Win32와 견주기

| | Win32 | WinUI 3 |
| --- | --- | --- |
| 언어 | C | C++, C# |
| 화면을 적는 법 | 좌표를 넣어 `CreateWindowExW` | XAML로 배치 규칙 |
| 단추가 눌리면 | `WM_COMMAND`를 `switch`로 | 이름 붙인 함수가 불린다 |
| 글자와 고해상도 화면 | 손이 많이 간다 | 기본으로 된다 |
| 빌드 | 파일 하나, 명령 한 줄 | Visual Studio 프로젝트 |
| 실행 파일 | 수십 KB, 어디서나 실행 | Windows App SDK가 함께 필요 |
| 어울리는 곳 | 작은 도구, 설치 프로그램, 낮은 층을 다루는 프로그램 | 요즘 모양의 응용 프로그램 |

## C 프로그램과 함께 쓰려면

장치를 다루는 로직을 C로 짜 두었다면, 그것을 정적 라이브러리나 DLL로 만들고 C++ 쪽에서 `extern "C"`로 선언해 부릅니다. [「심볼이란」](#/read/c-basic/symbols)에서 본 것처럼 C의 심볼 이름은 그대로라서 어느 언어에서든 붙일 수 있습니다. 화면은 플랫폼마다 다시 만들고, 핵심 로직은 C 한 벌로 두는 구조가 됩니다.

## 정리

- WinUI 3는 Win32 위에 쌓인 높은 층이고, C가 아니라 C++이나 C#으로 쓴다
- 화면은 XAML로 배치를 적고, 동작은 이름 붙인 함수로 잇는다
- C로 짠 로직은 라이브러리로 만들어 화면 쪽에서 부른다
