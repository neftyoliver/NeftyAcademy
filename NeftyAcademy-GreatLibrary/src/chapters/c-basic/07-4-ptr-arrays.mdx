배열과 포인터는 다른 것이지만, C에서는 거의 모든 자리에서 배열이 포인터로 바뀌어 쓰입니다. 그 규칙을 봅니다.

## 배열 이름은 첫 칸의 주소가 된다

```c
int a[4] = { 10, 20, 30, 40 };
int *p = a;         // &a[0] 과 같다
```

식 안에서 배열 이름을 쓰면 **첫 원소의 주소**로 바뀝니다. 그래서 `&` 없이 포인터에 넣을 수 있습니다.

## 포인터에 1을 더하면

```c
#include <stdio.h>

int main(void)
{
    int a[4] = { 10, 20, 30, 40 };
    int *p = a;

    printf("%d\n", *p);         // 10
    printf("%d\n", *(p + 1));   // 20
    printf("%d\n", p[2]);       // 30
    printf("%d\n", 3[a]);       // 40 (되긴 하지만 쓰지 않는다)
    return 0;
}
```

`p + 1`은 주소에 1을 더하는 게 아니라 <strong>한 칸 뒤</strong>를 뜻합니다. `int *`이면 4바이트, `double *`이면 8바이트가 더해집니다. 포인터의 타입이 필요한 이유입니다.

그리고 대괄호는 줄임말입니다.

```text
a[i]   ≡   *(a + i)
```

배열에 쓰든 포인터에 쓰든 똑같이 동작합니다. `3[a]`가 되는 것도 `*(3 + a)`와 같기 때문입니다.

## 그래도 배열은 포인터가 아니다

```c
int a[4];
int *p = a;

sizeof a;    // 16: 배열 전체
sizeof p;    // 8:  포인터 하나
```

| | 배열 `int a[4]` | 포인터 `int *p` |
| --- | --- | --- |
| 정체 | `int` 4개가 놓인 자리 그 자체 | 주소 하나를 담는 변수 |
| `sizeof` | 16 | 8 |
| 다른 곳을 가리키게 | 안 된다 (`a = …` 오류) | 된다 (`p = …`) |
| `&` 를 붙이면 | 배열 전체의 주소 (`int (*)[4]`) | 포인터 변수의 주소 (`int **`) |

배열이 포인터로 바뀌지 않는 자리는 `sizeof`와 `&` 두 곳입니다.

## 함수에 넘기면 길이가 사라진다

```c
#include <stdio.h>

int sum(const int *v, size_t n)     // int v[] 라고 써도 같은 뜻
{
    int total = 0;
    for (size_t i = 0; i < n; i++)
        total += v[i];
    return total;
}

int main(void)
{
    int a[4] = { 10, 20, 30, 40 };
    printf("%d\n", sum(a, sizeof a / sizeof a[0]));   // 100
    return 0;
}
```

함수 인자로 배열을 넘기면 첫 칸의 주소만 넘어갑니다. 함수 안에서는 몇 칸짜리인지 알 길이 없으므로 **길이를 따로** 넘깁니다. `sizeof a / sizeof a[0]`은 배열의 칸 수를 구하는 관용구인데, 배열이 보이는 곳(여기서는 `main`)에서만 쓸 수 있습니다.

<Note kind="warn">
함수 안에서 인자 `v`에 `sizeof`를 쓰면 배열 크기가 아니라 포인터 크기(8)가 나옵니다. 인자를 `int v[4]`라고 적어도 마찬가지입니다. 컴파일러가 경고해 줍니다.
</Note>

## 글자열은 char 배열

```c
char s[] = "hi";        // 배열: 'h' 'i' '\0' 세 칸. 고칠 수 있다
const char *t = "hi";   // 포인터: 읽기 전용 영역에 있는 "hi"를 가리킨다
```

C의 글자열은 끝에 `'\0'`(값 0)이 붙은 `char` 배열입니다. 길이를 따로 들고 다니지 않고 0이 나올 때까지를 글자열로 봅니다. `s`는 내 배열이라 `s[0] = 'H'`가 되지만, `t`가 가리키는 글자열 상수는 고치면 안 됩니다. 그래서 `const`를 붙입니다.

## 정리

- 식 안의 배열 이름은 첫 칸의 주소로 바뀐다
- `a[i]`는 `*(a + i)`, 포인터 덧셈은 칸 단위
- 함수에 배열을 넘길 때는 길이를 같이 넘긴다
