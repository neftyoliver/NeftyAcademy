포인터는 C에서 가장 어렵다고들 하지만, 정체는 단순합니다. <strong>주소를 담는 변수</strong>입니다. 이 챕터에서는 "주소"가 무엇인지만 확실히 해 둡니다.

## 메모리는 번호가 붙은 칸

메모리는 1바이트짜리 칸이 길게 늘어선 것이고, 칸마다 0번부터 번호가 붙어 있습니다. 그 번호가 <strong>주소</strong>입니다. 변수를 만들면 컴파일러가 빈 칸 몇 개를 그 변수의 자리로 정합니다.

```c
#include <stdio.h>

int main(void)
{
    int x = 42;
    printf("x의 값:  %d\n", x);
    printf("x의 주소: %p\n", (void *)&x);
    return 0;
}
```

```text
x의 값:  42
x의 주소: 0x7ffd3a5c1e4c
```

`&x`는 "x가 놓인 칸의 번호"입니다. `%p`는 주소를 찍는 서식이고, 주소 숫자는 실행할 때마다 달라집니다. 변수에는 늘 두 가지가 있습니다.

| | 뜻 | 쓰는 법 |
| --- | --- | --- |
| 값 | 칸 안에 들어 있는 것 | `x` |
| 주소 | 칸이 어디 있는지 | `&x` |

## 주소를 변수에 담으면 포인터

주소도 숫자이니 변수에 담을 수 있습니다. 주소를 담는 변수가 포인터입니다.

```c
int x = 42;
int *p = &x;    // p에 x의 주소를 담는다
```

## 주소를 따라가기

포인터 앞에 `*`를 붙이면 "그 주소로 가서 거기 있는 칸"이 됩니다.

```c
#include <stdio.h>

int main(void)
{
    int x = 42;
    int *p = &x;

    printf("%d\n", *p);   // 42: p가 가리키는 칸의 값
    *p = 7;               // p가 가리키는 칸에 7을 넣는다
    printf("%d\n", x);    // 7: x가 바뀌었다
    return 0;
}
```

`*p = 7`은 `p`를 바꾸지 않습니다. `p`에 적힌 주소로 **찾아가서** 그 칸을 바꿉니다. 그 칸이 `x`이므로 `x`가 7이 됩니다.

## 포인터의 크기

```c
printf("%zu %zu %zu\n", sizeof(char *), sizeof(int *), sizeof(double *));   // 8 8 8
```

무엇을 가리키든 포인터 자체는 주소 하나이므로 크기가 같습니다. 64비트 시스템에서는 8바이트입니다. 가리키는 타입(`int *`의 `int`)은 포인터의 크기가 아니라 <strong>따라갔을 때 몇 바이트를 어떻게 읽을지</strong>를 정합니다.

## 아무것도 가리키지 않는 포인터

```c
int *p = nullptr;    // C23. 그 전에는 NULL
if (p != nullptr)
    printf("%d\n", *p);
```

"아직 가리키는 곳이 없다"는 뜻으로 널 포인터를 씁니다. 널 포인터를 따라가면 프로그램이 그 자리에서 죽습니다(Segmentation fault). 따라가기 전에 널인지 확인하는 것이 기본입니다.

<Note kind="warn">
초기화하지 않은 포인터에는 쓰레기 주소가 들어 있습니다. 널은 따라가면 바로 죽어서 찾기 쉽지만, 쓰레기 주소는 엉뚱한 칸을 조용히 망가뜨립니다. 포인터는 만들 때 반드시 주소나 `nullptr`을 넣으세요.
</Note>

## 정리

- 주소는 메모리 칸의 번호, 포인터는 주소를 담는 변수
- `&x`는 x의 주소, `*p`는 p가 가리키는 칸
- 포인터에는 "어디"가 들어 있고, 그 "어디"에 진짜 값이 있다
