이 책은 C 소스를 **Clang**(LLVM의 C 컴파일러)으로 컴파일합니다. 첫 챕터에서는 가장 작은 프로그램을 만들어 실행 파일이 나오는 것까지만 봅니다.

## 준비

```sh
sudo apt install clang lld lldb
clang --version
```

`clang`은 컴파일러, `lld`는 LLVM의 링커, `lldb`는 디버거입니다. 버전이 18 이상이면 이 책의 예제(C23)를 그대로 쓸 수 있습니다.

## 가장 작은 프로그램

`mini.c`라는 파일을 만들고 아래 세 줄을 적습니다.

```c
int main(void)
{
    return 42;
}
```

```sh
clang mini.c -o mini
./mini
echo $?
```

화면에는 `42`만 나옵니다. `main`이 돌려준 값은 프로그램의 <strong>종료 코드</strong>가 되고, 셸은 방금 끝난 프로그램의 종료 코드를 `$?`에 넣어 둡니다. 관례로 0은 성공, 0이 아니면 실패입니다.

이 프로그램에는 `#include`도 `printf`도 없습니다. C 프로그램에 꼭 있어야 하는 것은 `main` 함수 하나뿐입니다.

## hello, world

```c
#include <stdio.h>

int main(void)
{
    puts("hello, world");
    return 0;
}
```

```sh
clang hello.c -o hello
./hello
```

`puts`는 글 한 줄을 화면에 내보내는 함수입니다. 우리가 만든 함수가 아니라 C 표준 라이브러리에 들어 있고, `#include <stdio.h>`가 "이런 함수가 있다"는 사실을 컴파일러에게 알려 줍니다. 이 줄이 하는 일은 다음 챕터에서 자세히 봅니다.

## 자주 쓰는 옵션

<Cmd means="결과 파일 이름. 안 주면 a.out">-o 이름</Cmd>
<Cmd means="C23 문법으로 읽기">-std=c23</Cmd>
<Cmd means="수상한 코드를 경고로 알려 주기. 늘 켠다">-Wall -Wextra</Cmd>
<Cmd means="디버거가 쓸 정보(줄 번호, 변수 이름)를 넣기">-g</Cmd>
<Cmd means="최적화 끄기 / 켜기">-O0, -O2</Cmd>
<Cmd means="링크하지 않고 .o 까지만">-c</Cmd>
<Cmd means="어셈블리(.s)까지만">-S</Cmd>
<Cmd means="전처리 결과만 화면에">-E</Cmd>

공부하는 동안에는 아래 한 줄을 기본으로 씁니다.

```sh
clang -std=c23 -Wall -Wextra -g hello.c -o hello
```

<Note kind="tip">
경고는 오류가 아니어서 실행 파일은 만들어집니다. 그래도 경고가 가리키는 줄은 대부분 진짜 실수입니다. 경고가 하나도 없는 상태를 유지하세요.
</Note>

## LLVM이 하는 일

Clang은 C를 곧바로 기계어로 바꾸지 않습니다. 먼저 <strong>LLVM IR</strong>이라는 중간 언어로 옮기고, LLVM이 그것을 다듬은 뒤 각 CPU의 기계어로 바꿉니다.

```c
int add(int a, int b)
{
    return a + b;
}
```

```sh
clang -O1 -S -emit-llvm add.c -o -
```

```llvm
define dso_local i32 @add(i32 noundef %0, i32 noundef %1) {
  %3 = add nsw i32 %1, %0
  ret i32 %3
}
```

`i32`는 32비트 정수, `%0`과 `%1`은 두 인자입니다. 이 중간 단계가 있어서 Clang 하나로 여러 CPU용 코드를 만들 수 있습니다. 앞쪽(C를 읽는 부분)은 그대로 두고 뒤쪽(기계어를 만드는 부분)만 갈아 끼우면 되기 때문입니다. [「어셈블리로 보는 아키텍처의 차이」](#/read/c-basic/asm) 챕터에서 `--target` 옵션으로 직접 해 봅니다.

## 정리

- C 프로그램은 `main`에서 시작하고, `main`이 돌려준 값이 종료 코드가 된다
- `clang 소스 -o 이름`이 기본이고, `-std=c23 -Wall -Wextra -g`를 붙여 쓴다
- Clang은 C를 LLVM IR로, LLVM은 IR을 기계어로 바꾼다
