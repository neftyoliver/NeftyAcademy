소수점이 있는 수는 `float`과 `double`로 다룹니다. 정수와 달리 <strong>대부분의 값을 정확히 담지 못한다</strong>는 점이 핵심입니다.

## 두 타입

| 타입 | 크기 | 믿을 수 있는 자릿수 | 범위(대략) |
| --- | --- | --- | --- |
| `float` | 4바이트 | 10진수 6~7자리 | ±3.4 × 10³⁸ |
| `double` | 8바이트 | 15~16자리 | ±1.8 × 10³⁰⁸ |

```c
double a = 3.14;        // 접미사가 없으면 double
float  b = 3.14f;       // f를 붙이면 float
double c = 1.5e3;       // 1500.0
```

특별한 이유가 없으면 `double`을 씁니다. `float`은 메모리가 아쉽거나, 값이 아주 많거나, `double` 연산이 느린 작은 CPU에서 씁니다.

## 정확하지 않다

```c
#include <stdio.h>

int main(void)
{
    double x = 0.1 + 0.2;
    printf("%d\n", x == 0.3);       // 0 (다르다)
    printf("%.17f\n", x);           // 0.30000000000000004

    float big = 16777216.0f;        // 2의 24제곱
    printf("%.1f\n", big + 1.0f);   // 16777216.0 (1을 더해도 그대로)
    return 0;
}
```

부동소수점 수는 2진수로 저장됩니다. 10진수의 1/3이 0.333…으로 끝나지 않듯, 0.1은 2진수로 끝나지 않는 소수라서 가장 가까운 값으로 반올림되어 들어갑니다. `float`은 유효 숫자가 24비트뿐이어서 1,600만이 넘으면 1 단위도 구별하지 못합니다.

저장하는 모양은 부호 1비트, 지수, 가수 셋으로 나뉩니다(IEEE 754). 자세한 구조는 「컴퓨터의 입문」의 표준 챕터에서 다룹니다.

## 비교하는 법

```c
#include <math.h>
#include <stdio.h>

bool nearly_equal(double a, double b, double tolerance)
{
    return fabs(a - b) <= tolerance;
}

int main(void)
{
    printf("%d\n", nearly_equal(0.1 + 0.2, 0.3, 1e-9));    // 1
    return 0;
}
```

`==`로 비교하지 않고 "차이가 충분히 작은가"를 봅니다. 허용 오차는 다루는 값의 크기에 맞춰 정합니다. 온도 센서라면 0.01도, 좌표라면 그 단위에 맞게 잡습니다.

## 특별한 값

| 값 | 생기는 경우 | 성질 |
| --- | --- | --- |
| `inf`, `-inf` | `1.0 / 0.0`, 너무 큰 수 | 어떤 수보다 크다(작다) |
| `nan` | `0.0 / 0.0`, `sqrt(-1.0)` | 자기 자신과도 같지 않다 (`x != x`가 참) |

`nan`이 한번 생기면 그 뒤의 계산 결과가 전부 `nan`이 됩니다. `<math.h>`의 `isnan(x)`, `isinf(x)`로 확인합니다.

## 정수와 섞일 때

```c
int a = 7;
int b = 2;

double wrong = a / b;           // 3.0: 정수끼리 나눈 뒤에 double이 된다
double right = (double)a / b;   // 3.5
int back = (int)3.99;           // 3: 소수점 아래를 버린다 (반올림이 아니다)
```

`a / b`는 둘 다 `int`라서 정수 나눗셈을 먼저 합니다. 한쪽을 `double`로 바꿔야 실수 나눗셈이 됩니다. 반올림하려면 `<math.h>`의 `round`나 `lround`를 씁니다.

## 찍는 법

| 서식 | 결과 (`3.14159`) |
| --- | --- |
| `%f` | `3.141590` |
| `%.2f` | `3.14` |
| `%e` | `3.141590e+00` |
| `%g` | `3.14159` (알아서 짧게) |

`printf`에 `float`을 넘기면 자동으로 `double`이 되므로 둘 다 `%f`입니다.

<Note kind="warn">
돈처럼 한 푼도 틀리면 안 되는 값에는 부동소수점을 쓰지 않습니다. 가장 작은 단위(원, 센트)의 정수로 다룹니다. 센서 값도 "0.1도 단위의 정수"로 보내는 프로토콜이 많습니다.
</Note>

## 작은 장치에서

값싼 마이크로컨트롤러에는 실수 연산 회로(FPU)가 없는 것이 많습니다. 그런 CPU에서 `double`을 쓰면 소프트웨어로 흉내 내느라 수십 배 느려지고 프로그램도 커집니다. 라즈베리파이처럼 FPU가 있는 기기에서는 걱정할 필요가 없습니다.

`<math.h>`의 함수를 쓰면 링크할 때 `-lm`을 붙입니다.

```sh
clang -std=c23 calc.c -o calc -lm
```

## 정리

- `double`이 기본, 값은 근삿값이다
- `==` 대신 허용 오차로 비교한다
- 정수 나눗셈과 버림에 주의하고, 정확해야 하는 값은 정수로 다룬다
