C 언어 자체에는 화면에 글자를 찍는 기능조차 없습니다. 그런 일은 모두 <strong>표준 라이브러리</strong>가 합니다. 전부를 훑는 것은 중급에서 하고, 여기서는 당장 쓰게 될 것만 고릅니다.

## 먼저 알아 둘 헤더

| 헤더 | 들어 있는 것 | 자주 쓰는 것 |
| --- | --- | --- |
| `<stdio.h>` | 입출력 | `printf`, `puts`, `fgets`, `snprintf`, `fopen`, `fclose` |
| `<stdlib.h>` | 메모리, 변환, 종료 | `malloc`, `free`, `strtol`, `qsort`, `exit` |
| `<string.h>` | 글자열과 메모리 덩어리 | `strlen`, `strcmp`, `memcpy`, `memset`, `strchr` |
| `<stdint.h>` | 크기가 정해진 정수 | `int32_t`, `uint8_t`, `uint64_t` |
| `<stddef.h>` | 기본 타입 | `size_t`, `offsetof` |
| `<ctype.h>` | 글자 분류 | `isdigit`, `isspace`, `toupper` |
| `<math.h>` | 수학 | `sqrt`, `sin`, `pow` (링크할 때 `-lm`) |
| `<assert.h>` | 가정 확인 | `assert` |
| `<errno.h>` | 오류 번호 | `errno` |

## printf의 서식

| 서식 | 타입 | 예 |
| --- | --- | --- |
| `%d` | `int` | `42` |
| `%u` | `unsigned` | `42` |
| `%ld`, `%lld` | `long`, `long long` | |
| `%zu` | `size_t` (`sizeof`, `strlen`의 결과) | |
| `%x` | 16진수 | `2a` |
| `%c` | 글자 하나 | `A` |
| `%s` | 글자열 (`char *`) | `hello` |
| `%f`, `%g` | `double` | `3.140000`, `3.14` |
| `%p` | 포인터 (`void *`) | `0x7ffd…` |
| `%%` | `%` 글자 | |

`%5d`는 다섯 칸에 맞춰, `%05d`는 빈칸을 0으로, `%.2f`는 소수 둘째 자리까지 찍습니다.

<Note kind="warn">
서식과 실제 인자의 타입이 다르면 정의되지 않은 동작입니다. `-Wall`이 켜져 있으면 컴파일러가 대부분 잡아 줍니다.
</Note>

## 글자열 다루기

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *a = "sensor";
    char buf[32];

    printf("%zu\n", strlen(a));                 // 6 ('\0'은 세지 않는다)
    printf("%d\n", strcmp(a, "sensor") == 0);   // 1 (같다)

    snprintf(buf, sizeof buf, "%s-%d", a, 7);   // buf 크기를 넘지 않게 만든다
    puts(buf);                                  // sensor-7

    const char *dash = strchr(buf, '-');        // '-'가 있는 곳의 주소, 없으면 널
    if (dash != nullptr)
        puts(dash + 1);                         // 7
    return 0;
}
```

글자열을 만들 때는 `snprintf`를 씁니다. 받을 배열의 크기를 알려 주므로 넘치지 않습니다. `strcpy`, `strcat`, `sprintf`는 크기를 확인하지 않아서 버퍼를 넘기 쉽습니다.

## 메모리 덩어리 다루기

```c
int a[4] = { 1, 2, 3, 4 };
int b[4];

memcpy(b, a, sizeof a);     // a를 b로 복사 (바이트 수)
memset(b, 0, sizeof b);     // b를 0으로 채움
memcmp(a, b, sizeof a);     // 같으면 0
```

`mem`으로 시작하는 함수는 `'\0'`을 신경 쓰지 않고 <strong>바이트 수</strong>만큼 일합니다. 구조체나 배열을 통째로 복사할 때 씁니다. 겹치는 구간을 복사할 때는 `memmove`를 씁니다.

## 입력 받기

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char line[64];

    printf("숫자: ");
    if (fgets(line, sizeof line, stdin) == nullptr)
        return 1;                       // 입력이 끝났다

    char *end;
    long n = strtol(line, &end, 10);    // 10진수로 읽기
    if (end == line) {
        puts("숫자가 아닙니다");
        return 1;
    }
    printf("두 배는 %ld\n", n * 2);
    return 0;
}
```

`fgets`는 한 줄을 읽되 배열 크기를 넘지 않습니다. `strtol`은 글자열을 숫자로 바꾸고, 어디까지 읽었는지를 `end`에 알려 줍니다. `end`가 처음 그대로면 숫자를 하나도 못 읽은 것입니다.

| 쓰지 않는 것 | 이유 | 대신 |
| --- | --- | --- |
| `gets` | 길이 제한이 없다. C11에서 표준에서 빠졌다 | `fgets` |
| `scanf("%s", s)` | 길이 제한이 없다 | `fgets`, 또는 `%31s`처럼 폭 지정 |
| `atoi` | 실패했는지 알 수 없다 | `strtol` |

## 파일

```c
#include <stdio.h>

int main(void)
{
    FILE *f = fopen("log.txt", "a");    // "r" 읽기, "w" 새로 쓰기, "a" 덧붙이기
    if (f == nullptr) {
        perror("log.txt");              // 왜 실패했는지 찍어 준다
        return 1;
    }
    fprintf(f, "temp=%d\n", 23);
    fclose(f);
    return 0;
}
```

`printf`는 사실 `fprintf(stdout, …)`입니다. `stdout`(화면), `stderr`(오류 출력), `stdin`(키보드)은 미리 열려 있는 파일입니다.

## 설명서 찾기

```sh
man 3 printf
man 3 strtol
```

`man`의 3번 장이 C 라이브러리 함수입니다. 함수 원형, 반환값, 오류일 때 무엇을 돌려주는지가 적혀 있습니다. 반환값을 확인하는 습관이 C 프로그램의 품질을 가릅니다.

## 정리

- 입출력은 `stdio.h`, 메모리와 변환은 `stdlib.h`, 글자열은 `string.h`
- 글자열은 `snprintf`로 만들고, 입력은 `fgets`와 `strtol`로 받는다
- 실패할 수 있는 함수의 반환값은 반드시 확인한다
