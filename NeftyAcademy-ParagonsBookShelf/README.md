# NeftyAcademy-ParagonsBookShelf

React로 만드는 **웹 책의 틀**. 내용은 넣지 않고 틀만 맡는다.

- 앞표지: **지도**(책=둥근 사각형, 챕터=번호 붙은 육각형, 하위 챕터(쪽)=원, 서가 안의 책=작은 사각형. 지도 위에 모양·줄의 뜻과 조작법을 적은 「지도 보는 법」이 붙고, 전화기에서는 접힌 채로 시작한다) / **목록**(카테고리 → 책 → 챕터 드롭다운) / **갤러리**(책 카드) / **자주 본 쪽**(열람 기록을 켰을 때) 보기, 호버 시 글로우·확대
- **서가**: `Book.books`에 책을 넣으면 책 속의 책이 된다. 서가를 열면 그 안의 책들이 다시 지도·목록·갤러리로 보인다. 몇 겹이든 된다
- **하위 챕터**: 챕터에 `children`을 주면 번호가 3.1, 3.2로 붙고, 지도에서는 챕터 둘레의 작은 원으로 보인다
- 지도의 배치는 저절로 정해진다. 책이 여러 권이면 지도 전체가 육각형이 되고, 책들은 양파 껍질처럼 겹겹이(한 겹에 여섯 권 안팎) 놓인다. 11권이면 두 겹, 19권이면 세 겹이다. 노드 사이의 간격은 어느 책에서나 같고, 책의 영역은 노드의 자리를 먼저 정한 뒤 그것을 감싸는 다각형으로 그려진다. 영역 사이의 틈은 어디서나 같다. 책을 더하거나 빼면 다시 계산된다(`src/onion.ts`). 책 한 권만 볼 때는 챕터가 책 둘레에 육각형을 그려 가며 6개, 12개, 18개… 순서로 놓인다
- 지도는 처음에 화면 높이 안에 다 들어오게 맞춰진다. 끌어서 옮기고, 휠이나 ＋/－ 단추, 전화기에서는 두 손가락으로 확대·축소한다(확대한 뒤에는 한 손가락으로 옮긴다). 확대하면 간격이 벌어지면서 책·챕터·하위 챕터의 노드와 글자도 함께 커지고(줄의 굵기는 그대로), 충분히 커지면 챕터, 그다음 하위 챕터의 노드 속에 제목이 들어간다
- 지도의 줄(읽는 순서, 상호 참조, 가운데에서 책으로)은 모두 육각형 결을 따라 60도로만 꺾이고 노드를 뚫지 않는다(`src/hexroute.ts`)
- **참조 줄**: 챕터의 `links`(본문에서 가리킨 다른 챕터)가 줄이 된다. 처음에는 하나도 긋지 않는다(수천 개를 다 그으면 지도가 늦게 뜬다). 챕터에 올리면(손가락으로는 한 번 누르면, 한 번 더 누르면 연다) 그 챕터를 **가리키는 쪽에서** 화살표가 흘러오고, 왼쪽 아래에 그 쪽들의 목록이 뜬다. `R` 키나 왼쪽 아래 단추로 방향을 뒤집으면 그 챕터가 **가리키는 쪽으로** 흘러간다. 한 번 그린 줄은 다른 챕터를 골라도 옅은 점선으로 남고, 「참조관계 지우기」 단추가 모두 지운다(쪽을 읽고 돌아와도 남아 있고, 화면을 새로 열면 비어 있다). 화살표가 흐르는 동안에는 그 밑의 점선을 가린다. 흐르는 줄과 화살촉의 크기는 화면 픽셀로 정해서, 책이 많아 지도가 커져도 같은 크기로 보인다. `Esc`는 고른 챕터만 푼다
- 같은 두 노드 사이에는 줄이 하나뿐이다(여러 번 가리켜도, 서로 가리켜도). 가리키는 쪽이 이 지도에 없는 책이면, 그 책(이나 그 책을 담은 서가)이 지도에 책 노드로 놓여 있을 때는 그 노드로 잇고, 아예 없을 때는 챕터 옆에 **화이트홀**을 그려 지도 밖으로 이어짐을 보인다
- 본문의 표: 칸 안의 한글은 낱말 단위로 끊고, 좁은 화면에서는 긴 코드를 칸 안에서 접는다. 그래도 넘치면 표가 옆으로 밀린다. 칸에 `bf-wide` 클래스를 붙이면 좁은 화면에서 예닐곱 글자 폭을 지킨다(문장이 든 칸이 한 낱말 폭으로 줄지 않게)
- 카테고리 고르기는 상단바 오른쪽에 늘 보임
- 반투명 상단바, 왼쪽 반투명 메뉴(차례·북마크·줄친 곳)
- 읽기 화면: 오른쪽 **스크롤 레일**(단락 눈금, 지금 단락, 줄친 곳·북마크 표시, 호버하면 그 높이의 단락 이름)
- 읽기 화면 맨 아래 **같이 보기**: 이 쪽을 가리키는 쪽들(같은 책이 먼저, 24개를 넘으면 나머지는 단추로 편다)
- 본문의 링크: 바깥(http, https)으로 가는 링크에는 ↗ 가 붙고 새 탭에서 열린다. 다른 쪽으로 가는 링크는 올리면 "책 › 챕터" 이름표가 뜬다. `class="bf-ref"` 인 링크는 코드 속 낱말에 걸린 개념 링크로, 글자색을 바꾸지 않고 옅은 점선 밑줄만 긋는다
- **열람 기록**: 켜 두면 쪽마다 연 횟수와 끝까지 읽은 때를 세이브 파일(JSON)에 적는다. 다 읽은 책은 지도와 갤러리에서 빛난다(아래 "열람 기록")
- **북마크**(단락 단위), **줄치기**(드래그 → 「줄치기」, 칠한 곳 누르면 「줄 지우기」)
- 주소는 해시(`#/read/책/챕터/단락`)라 HTML 한 파일을 `file://`로 열어도 그대로 동작
- 본문은 아무 React 컴포넌트(MDX 권장). 본문 안의 `<h2>`가 단락

## 쓰는 법

```tsx
import { BookApp, type Library } from 'neftyacademy-paragons-bookshelf';
import Intro from './chapters/intro.mdx';

const library: Library = {
  title: '내 책',
  storageKey: 'my-book',            // 같은 도메인의 다른 책과 겹치지 않게
  categories: [{ id: 'a', name: '기초', color: '#4f7f78' }],
  books: [
    {
      id: 'basics', title: '첫 권', category: 'a', firstNumber: 0,
      chapters: [
        { id: 'intro', title: '시작', summary: '한 줄 요약', Content: Intro },
        { id: 'next', title: '다음', draft: true },   // 아직 안 쓴 챕터
        { id: 'ptr', title: '포인터', children: [    // 하위 챕터 (id는 책 안에서 겹치지 않게)
          { id: 'ptr-decl', title: '선언문에서의 *', draft: true },
        ] },
      ],
    },
  ],
};

createRoot(root).render(<BookApp library={library} />);
```

본문 조각: `Note`(참고·요령·주의), `Figure`(그림+설명), `Term`(용어 풀이), `Cmd`(명령어와 뜻).
색은 `--bf-*` CSS 변수를 덮어써서 바꾼다(`src/style.css` 맨 위).

## 열람 기록

HTML 한 파일을 `file://`로 연 화면은 옆의 파일을 마음대로 읽고 쓸 수 없다. 그래서 사용자가 **한 번 파일을 골라 주는** 방식이다(File System Access API).

- 메뉴(왼쪽 위) → 「열람 기록」에서 켠다. 처음에는 「새 세이브 파일 만들기」로 자리를 고른다(이름은 `<storageKey>.save.json`. HTML 옆에 두면 된다). 이미 있는 세이브 파일은 「있는 세이브 파일 열기」로 잇는다
- 꺼 두면 아무것도 적지 않고 읽지도 않는다. 끄더라도 세이브 파일은 그대로 남는다
- 다음에 다시 열면 브라우저가 파일에 쓸 허락을 다시 묻는다. 이 물음은 단추를 눌러야 띄울 수 있어서, 상단바에 「기록 이어 쓰기」 단추가 뜬다. 한 번 누르면 이어진다
- 적는 것: 쪽마다 `views`(연 횟수), `last`(마지막으로 연 때), `done`(끝까지 읽은 때. 쪽의 끝이 화면에 1.2초 머물면 적는다). 책의 읽을 수 있는 쪽을 모두 끝까지 읽으면 그 책이 **완독**이다
- 여러 탭에서 같은 파일을 써도 서로 지우지 않는다(적기 전에 파일을 다시 읽어 합친다). 다른 도서관의 세이브 파일이나 세이브 파일이 아닌 JSON을 고르면 건드리지 않고 알려 준다
- 크롬과 엣지에서 된다. 파이어폭스와 사파리에는 이 API가 없어서 켤 수 없다(그 밖의 기능은 그대로 된다)

```json
{
 "app": "paragons-bookshelf",
 "version": 1,
 "library": "my-book",
 "updated": "2026-11-22T00:35:10.120Z",
 "pages": {
  "basics/intro": { "views": 3, "last": 1795307710120, "done": 1795300000000 }
 }
}
```

## 이 폴더에서

```sh
npm install
npm run dev          # 예시 책 (demo/)
npm run build:demo   # demo/dist/index.html 한 파일
npm run typecheck
```

## 다른 프로젝트에서 쓰기

책 프로젝트를 이 폴더 옆에 두고 `"neftyacademy-paragons-bookshelf": "file:../NeftyAcademy-ParagonsBookShelf"`로 의존한다. 그때 책 프로젝트의
`vite.config.ts`에 `resolve.dedupe: ['react', 'react-dom']`, `tsconfig.json`에 react 타입 `paths`를 넣어
React가 두 벌 잡히지 않게 한다(NeftyAcademy-GreatLibrary 참고).

## 메모

- 줄치기는 CSS Custom Highlight API로 칠한다(본문 DOM을 건드리지 않음). Chrome 105+, Safari 17.2+, Firefox 140+
- 북마크·줄치기·보기 설정은 브라우저 localStorage에만 저장된다(기기 사이 동기화 없음). 열람 기록만 세이브 파일에 적힌다
- 챕터 id를 바꾸면 그 챕터의 북마크·줄치기가 끊긴다
